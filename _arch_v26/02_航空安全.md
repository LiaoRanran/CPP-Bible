## 一、核心实践清单（8 条，含数字与流程）

### P1. ASRS：自愿/机密/无惩罚/独立——由中立第三方运营的未遂事件库

- **起源于一场本可避免的空难**：1974-12-01 TWA 514 撞山（华盛顿 Dulles，全员遇难）——六周前另一航司在同一进近犯过同一误解并侥幸脱险，但信息只在公司内部分享，**行业没有跨组织的未遂信息通道**。1976 年 NASA 运营 ASRS（FAA 出资、NASA 中立第三方）。【已查证】https://asrs.arc.nasa.gov/callback/cb_555.html
- **四原则（1976 至今未变）**：**Voluntary / Confidential / Non-Punitive / Independent**；法律依据 AC 00-46F + 14 CFR 91.25（免于处罚与执照处分的激励）。
- **量级**：现每月 >10,000 份、2023 年 10.6 万份、累计 **>230 万份**；已发出 **8,150+ 条安全警报**给有权整改的组织；身份信息**从未泄露**。
- **机制细节**：ID 条（姓名地址）撕下寄回本人作为"已报告凭证"，正文去标识化（时间地点泛化）；两名分析员 3 个工作日内初筛；**只聚焦前兆（precursors），与 NTSB 的事故调查互补**。
- **设计精髓**：报告系统必须由**不管考核、不管处罚**的机构持有，且报告本身换来免责——否则数据只会是表演。

### P2. 检查单：19 项、三段式、口头闭环——把关键步骤从记忆里拿走

WHO 外科安全检查单（Gawande/Haynes 2009，NEJM，8 国 8 院 ~7700 例）：
- **三段式**：**Sign In**（麻醉前）/ **Time Out**（切皮前）/ **Sign Out**（患者离开手术室前）；共 19 项。
- **效果**：死亡率 **1.5%→0.8%（相对降 47%）**、并发症 11.0%→7.0%（均 P<0.01）。【已查证】https://www.nejm.org/doi/full/10.1056/NEJMsa0810119
- **设计原则**：①**短**（19 项，一页）②只放"蠢但致命"的关键项 ③**口头确认 + 自报姓名角色**（授权护士喊停）④每段有强制暂停点。
- **已知实施坑**：外科医生缺席 Sign In、护士感到被胁迫、噪音——**检查单是团队工具不是打勾表格**；专科需本地化（眼科手术不能比手术还长）。

### P3. CRM：质询—主张—升级—接管，把"下级知道"强制转为"上级行动"

- **assert-escalate-override 三级协议**：①**Assert**——具体陈述（不说"油量好像有点低"，说"机长，油量低于最低标准，必须现在落地"）②**Escalate**——无响应则更直接重复 ③**Override**——极端情形**物理接管操纵**，文化明确授权且要求。【已查证】https://aviationrisklab.com/human-factors/captainitis-authority-gradient/
- **标准用语（standard phraseology）**：Tenerife 后 ICAO 1984 改革——**"takeoff"一词只允许出现在真实起飞许可中**；禁止用含糊的"OK"回复；关键许可必须**逐字 readback**，管制员必须 **hearback** 对照进程单，发现不符当场纠正（Annex 11 §3.7.3）。【已查证】ICAO Annex 11；Doc 4444
- **无菌驾驶舱（sterile cockpit，14 CFR 121.542，1981）**：滑行/起飞/着陆及 **10,000 英尺以下**禁止一切非必要活动与谈话。
- **跨文化适配**：Korean Air 801（1997）后强制英语为驾驶舱语言并按本土权威梯度重设计 CRM，1999 年后无致命事故。

### P4. 分层防御 + 黑匣子：不依赖单层，每层都假设会漏

- **Reason 瑞士奶酪模型（航空业原产地，ICAO Doc 9859 采纳）**：事故=组织影响/不安全监督/前置条件/不安全行为四层孔洞对齐；**"单点失效在深度防御系统里很少有后果"**（ICAO SMM 原文）。【已查证】ICAO Doc 9859
- **黑匣子（强制 >5,700kg）**：**FDR 25 小时**、数十至数千参数；**CVR 原 2 小时→2021 后新出厂 >27t 飞机 25 小时**（ICAO 强制）；抗 3400G、1100°C/1h；水下信标 37.5kHz/90 天；NTSB 推动延长的直接原因是**旧 2 小时数据在事件延迟发现后被覆盖**。
- **教训的双向性**：记录器的价值在**事后可重建**；记录窗口必须长于"发现问题的延迟"。

### P5. 渐进式认证：五阶段 + 委托边界 + 真人代表性测试

- FAA 型号合格审定五阶段：概念设计 → 需求定义 → 合规计划 → 实施（数千测试）→ **颁证后活动（持续适航）**；TIA 分阶段授权试飞。
- **MAX 血的教训（2020 DOT OIG）**：737 MAX 8 的 129 个试飞计划中 **62 个（48%）委托给波音 ODA**；对飞行员反应的假设基于**王牌试飞员**而非普通航线飞行员 → MCAS 两起空难（狮航 189 + 埃航 157 人）。改革要求：认证测试必须纳入**不同经验水平的航线飞行员**、FAA 须展示独立性。
- **核心思想**：不是"全对才飞"，而是**每个阶段只解锁下一阶段的权限**，且委托项必须显式登记（delegation 可见、可审计）。

### P6. LOSA：在正常航班上观察正常工作，前置发现"离经叛道常态化"

- ICAO Doc 9803：受训观察员以**同行身份**坐跳椅观察**正常商业航班**，no-jeopardy（观察到的错误不追责），按 **TEM 模型**（Threat 外部威胁 → Error 机组错误 → Undesired Aircraft State 非期望状态）编码。
- 十特征要点：管理层与工会**联合背书**、自愿参与、去标识机密、观察者独立于管理权威、数据只用于组织学习。
- **定位**：像"查胆固醇"——给组织提供安全性能的**诊断快照与先行指标**，直接针对"偏差正常化"（normalization of deviance）。实测示例：66% 航班滑行中出现 ≥3 个错误。

### P7. SMS 四组件十二要素：把安全当系统工程管理（Annex 19，强制）

| 组件 | 要素 |
|---|---|
| 1 安全政策与目标 | 管理层承诺 / 问责制 / 关键安全人员 / 应急计划 / 文件 |
| 2 安全风险管理 | 危险源识别 / 风险评估与缓解 |
| 3 安全保证 | **绩效监测与度量** / **变更管理** / 持续改进 |
| 4 安全促进 | 培训教育 / 安全沟通 |

要求：不论组织大小，**全部要素都适用**（可缩放但不可缺项）；配套**安全绩效指标 + 目标值**（SPI/SPT），并强制保护安全数据不被司法挪用（Annex 19 Amdt 2 新增"安全情报"章）。

### P8. 安全绩效的量化基线与分层差距

- **IATA 2025**：全行业总事故率 **1.32/百万架次**（约 76 万架次 1 起）；致命事故率 5 年均值 **1/560 万架次**（十年前为 1/350 万）；2024 年 4060 万班、7 起致命事故。
- **审计分层**：IOSA 认证航司事故率 0.92 vs 非 IOSA **1.70**（2024）；IATA 成员 0.72 vs 非成员 3.09（2025）；非洲 7.86 vs 北美 1.68——**同一套技术、不同系统成熟度，差距数倍**。
- **MRM（维修版 CRM）**：维修因素占事故约 12%、其中人为因素占 80%（FAA）；**Dirty Dozen**（Dupont）：沟通/分心/资源不足/压力/自满/团队/疲劳/时间压力/不坚定/意识/知识/不良潜规则；MEDA：80–90% 致因在**管理层可控范围**而非技师个人。

## 二、踩过的坑（5 条，含 4 个真实空难）

### F1. 特内里费 Tenerife（1977，583 死，史上最惨）——权威梯度 + 含糊用语 + 信道碰撞
KLM 机长（公司首席 747 教员）在雾中把**航线许可误当起飞许可**；副驾复诵含糊（"we are now at takeoff"），机械师两次试探问"Pan Am 还没清跑道吧？"被一句"Oh, yes"顶回；同频同时发射产生啸叫，Pan Am"我们还在跑道上"的警告被淹没。**所有数据都在驾驶舱里，唯独缺少把下级信息转成上级行动的机制。** 直接催生 CRM（NASA 1979 workshop、United 1981 首训）与标准用语改革。【已查证】NTSB AAR-78-16；ICAO RTF 改革 1984

### F2. United 173 波特兰（1978，10 死）——数据正确、沟通失效
机组 68 分钟排查一个**本不存在**的起落架问题（事后确认一直锁好）；油量危急 30 分钟，副驾与机械师**反复**用间接句式提醒（"getting a little low"），机长听见数据点没听见警报，四发耗尽。NTSB 原因认定同时点名：机长未响应 + 机组**未能完整沟通严重性**。航空史第一个 CRM 催化剂。【已查证】NTSB 报告原文（goflightmedicine/aerocorner 全文引用）

### F3. Colgan 3407 水牛城（2009，50 死）——无菌驾驶舱违规 + 自动化失配
进近阶段机组进行与飞行无关的谈话（**违反 121.542**），未监控空速；除冰配置下 Vref 少输 20 节；杆操作错误导致失速。NTSB 将"未遵守无菌驾驶舱"列为促成因素之一。
### F4. Aloha 243（1988）与维修人因——客舱顶部撕裂、乘务员牺牲
机身搭接处腐蚀疲劳裂纹失检（维修/检查体系失效），催生 MRM 与维修人因体系——**维修错误的特征是延迟引爆、跨班组**（一个班组的错，下一个班组放行）。
### F5. 737 MAX（2018-19，346 死）——委托认证与"测试飞行员代表性"失败
认证委托过度（48% 试飞计划委托厂商 ODA）+ 用王牌试飞员反应时间代表普通飞行员 + 告警系统单点依赖；**行业最成熟的认证体系也会在制度性利益冲突下失效**。
**行业元教训**：这些事故**没有一起是机械单点故障**——全部是沟通、文化、委托、注意力分配问题。

## 三、对阙疑的映射【类比推断】

| 航空实践 | 阙疑组件/机制对应 |
|---|---|
| P1 ASRS 四原则 + 中立第三方 | 未遂/"运气正确"报告通道必须独立于裁判者；报告即免责；阙疑 v25-B 的双台账中**自愿轨**应找"NASA 角色"（独立维护的去标识库），不能由规则团队自管 |
| ASRS 每月万份、230 万总量 | 报告文化的产出量级：有效系统里**未遂报告应远多于事故**；阙疑若逃逸报告 >> 未遂报告，说明通道设计错了（对照海因里希 1:29:300 的方向性预期） |
| P2 19 项检查单三段式 | gate/replay/人审的**关键控制点清单**：只保留少数"蠢但致命"项；每段强制暂停；口头闭环而非静默打勾 |
| 死亡率 1.5%→0.8% | 检查单的 ROI 量级证据：流程性工具可近腰斩严重错误，远超加规则的边际收益——支持 v25 阶段 1 先上清单类任务 |
| P3 assert 必须具体可行动 | 人审异议必须**带具体证据与请求动作**（"规则 R7 在本卡不适用，因为 X，建议 Y"），不接受"感觉不对"；升级路径要制度化到"可叫停合并" |
| readback/hearback 逐字+对照 | 人审/工具间的关键结论传递要求**复诵+对照原单**；AI 结论的消费方必须复述回显（防异步理解漂移） |
| "takeoff" 词汇保留 | 阙疑术语保留：`verified`/`pass` 等强词只在完整适切条件满足时可用，防止语义通胀（对应 v25-G felicity） |
| 无菌驾驶舱 | 人审判定窗口的**无中断区**：判定前后 N 分钟禁推送/禁闲聊（与临床 no interruption zone、v25-F HALT 合流） |
| P4 瑞士奶酪四层 | v21 分层防御的行业原版：逃逸=四层孔洞对齐；每次逃逸按 HFACS 四层归因（不安全行为/前置/监督/组织），不止改规则层 |
| FDR 25h / CVR 延长原因 | 阙疑台账保留窗口必须 > "发现问题的延迟"；当前 DecisionEvent 若无 TTL，等价于 CVR 只留 2 小时——延迟发现即证据蒸发（直接支持 v25 生命周期 stale 设计） |
| P5 五阶段认证 + 委托登记 | 新规则上线采用**阶段解锁**：影子模式 → 告警模式 → 可阻断模式，每阶段显式授权；自动化检查器委托第三方时 48% 这种委托比例必须可审计（对应 v25-A ODA 教训） |
| 试飞员代表性 | 校准/阈值测试必须用**普通审查者样本**而非设计者本人（F 方向 Dror 同构） |
| P6 LOSA 正常工作观察 | 对日常验证流水线做定期"跟班审计"（不追责、同行观察），找 workaround 与偏差正常化——阙疑目前只有出事后回看，没有正常态体检 |
| TEM 三态 | 误差流分类直接采用 Threat（外部：标准改版/编译器升级）→ Error（本系统错误）→ Undesired State（错误结论已出未放行） |
| P7 SMS 四组件 | 阙疑"安全管理体系"模板：政策（三难声明）/ 风险管理（MDL 准入）/ 保证（校准监测+变更管理）/ 促进（培训沟通）——v25 设计可按此 12 要素重组目录 |

| P8 绩效指标 SPI/SPT | 每个安全目标必须配可量化先行指标（不只滞后指标逃逸率）：冲突率、override 率、未遂上报率 |
| MRM Dirty Dozen | 人审错误归因清单直接借用（疲劳/压力/自满/不坚定……），用于评审 RCA 的因素勾选表 |

## 四、可直接搬的设计（5 条）

1. **ASRS 式报告凭证 + 去标识流程**：报告者获得不可追溯的"已提交凭证"，正文由独立分析员去标识；未遂库由非考核团队持有。
2. **三段式关键控制点检查单**：把 gate/release 压成一页 ≤19 项，三个强制暂停点，关键项口头/显式确认（谁确认留痕）。
3. **升级接管协议**：审查者异议的三级模板（陈述→升级→叫停），叫停权对所有角色开放且事后免追责（只要当时有具体证据）。
4. **记录窗口对齐发现延迟**：台账事件保留期按"问题平均发现周期"设定并定期复核，先实测 τ_d 再定保留窗口。
5. **新规则/检查器的阶段解锁 + 委托登记册**：影子→告警→阻断三段，任何"委托给自动化/外部"的判定列入 ODA 式登记，比例与边界公开。

## 五、不能直接搬的（4 条及原因）

1. **黑匣子硬件级抗毁标准**：3400G/1100°C 是物理灾难场景；阙疑的"黑匣子"是 append-only + 异地冗余即可，不必照搬硬件规格，但**可重建性原则**必须保留。
2. **逐字语音复诵**：人审是异步文本场景，照搬语音 readback 成本过高；用结构化回显（系统把理解的结论重放给提交者确认）替代。
3. **法定强制 SMS/Annex 19 的主权框架**：航空靠国家强制力；阙疑是组织内系统，采用其**结构**而非合规/取证机制（无外部监管授权）。
4. **海因里希固定比例 1:29:300**：该比例来自 1930 年代工业事故、争议极大（重大事故致因结构与小事故不同，Manuele 证伪其线性外推）；只继承"未遂远多于事故"的**方向**，不引用具体比例作为阙疑指标。
