## 一、核心实践清单（8 条，含数字与流程）

### P1. 误诊率基线：用"金标准复核"测量，且承认测量本身会漏

- **尸检（诊断准确性金标准）**：重大诊断不符（Goldman Class I+II）在尸检中占 **10–20%**；其中可能影响结局的 Class I 错误平均约 **10%**（Goldman 等综述）；2026 南非单中心重大不符率 **19.1%**（与全球汇总 19.3% 吻合）；柏林 1112 例 2010-13：无不符 73.9%（即约 26% 有不符）；49 项研究区间 4.9–49%，重大错误中位数 23.5%。【已查证】https://qualitysafety.bmj.com/content/qhc/22/Suppl_2/ii21.full.pdf ；https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0255490
- **总体诊断错误率**：Elstein 长期结论"诊断 10–15% 是错的"；Hopkins/Harvard 2023 跨疾病均值 **11.1%**（区间 1.5% 心梗 → 62% 脊髓脓肿）；标准化病人实测内科医生误诊 **13%**。
- **年度负担（美国）**：约 **79.5 万人/年**因诊断错误死亡或永久残疾（**37.1 万死亡 + 42.4 万残疾**）；约 1200 万成人/年遭遇门诊诊断错误（~5% 就诊），其中一半潜在有害；住院危重者 23% 有漏诊/延误（JAMA 2024，其中 17% 直接致害）。
- **结构集中**：血管事件/感染/癌症占严重伤害 **75%**；卒中、脓毒症、肺炎、VTE、肺癌 5 病占 38.7%；卒中漏诊 17.5%。
- **关键元教训**：尸检率暴跌后，行业失去了测量手段——**"0 检出"是因为没有金标准复核通道，不是因为没有错误**（Graber：autopsy data is the gold standard，几乎消失）。

### P2. 鉴别诊断（DDx）：强制并行假设、先排最危险

标准流程（NEJM Healer/Iowa 教学）：**数据采集 → 问题表征（1-2 句编码）→ 列 3-5 个候选假设 → 按"概率×风险"排序（先排致死性：rule-out worst scenario/red flags）→ 策略性检查（likelihood ratio 贝叶斯更新）→ 迭代到 leading hypothesis → 随访计划（safety-net）**。
- 双过程：System 1 模式识别（专家 5 分钟内最终诊断多在初始集合中；工作记忆约 5 项）+ System 2 假设演绎；**多数错误发生在 System 1**，需"理性覆盖"。
- **反过早闭合机制**："assume your working diagnosis is incorrect"——先假设当前诊断错了再找替代（Iowa Master Clinician）。
- **病史贡献 70–80% 的诊断**（最强工具，不是检查）。

### P3. 循证医学证据等级：GRADE 四级 + 五降级因素

| GRADE 确定性 | 含义 |
|---|---|
| High | 真实效应很接近估计值 |
| Moderate | 可能接近，但有被实质改变的可能 |
| Low | 真实效应可能与估计显著不同 |
| Very low | 估计很可能显著错误 |

降级五因素：**偏倚风险、不一致性、间接性、不精确性、发表偏倚**；升级因素：大效应量、剂量反应、残余混杂反向。经典金字塔：系统综述/Meta > RCT > 队列/病例对照 > 病例系列 > 专家意见（USPSTF A/B/C/D/I 建议分级）。**先定 PICO 再检索**，证据按"关键结局"逐条评级而非按整篇文献。【已查证】https://www.nhmrc.gov.au/file/23340/download

### P4. CDSS 的告警经济学：高敏低质必被无视，必须做告警精算

- **覆盖（override）率 49–96%，多数 >90%**；Samsung 急诊药物告警 2022 实测 **92.9%**；最危急告警 <2 秒被关；每多一条提醒，接受率降 **30%**；每班 50–100 条告警（部分专科 >300）。
- **对照实验（Sheba 2019）**：旧规则系统告警负担 37.1% 处方、临床相关率仅 16%、改变实践率 5.3%；概率 ML 系统：负担 **0.4%**、相关率 **85%**、改变实践率 **43%**。
- **定量结论**：砍 40% 告警，剩余告警响应率升 22%。行业立场："less is more"；厂商因责任把敏感度拉满是系统性根源。
- **CDSS"盲诊断"设计**：AI 用于**拓宽鉴别诊断、生成鉴别性提问、提示 don't-miss**，由医生独立判断后再参考（"cognitive forcing function"），而非先给结论。

### P5. 早期预警评分：可计算、全病因、分层响应，接受敏感度换可操作性

NEWS2（6 项生理参数，0-3 分）：NICE 脓毒症分层 **0 极低 / 1-4 低 / 5-6 中 / ≥7 高**；单参数 3 分即升级；分层决定监测频率与抗生素时间窗。
- 精度权衡实测：院前 NEWS2 对脓毒症敏感度 0.522/特异度 0.947/PPV 仅 0.216；NEWS≥3 敏感度 0.77/特异度 0.61；NEWS2≥2 敏感度 **0.87**/特异度仅 0.39——**阈值即政策：要敏感就接受大量假阳性，并按分层处置消化**。
- **全病因原则**：用不限定病因的恶化评分（NEWS2）而非疾病专用分，因为急性期诊断不确定；必须无需化验即可算、跨场景可沟通。

### P6. 自愿报告系统：与强制报告分离，无惩罚+机密+法律保护

IOM《To Err Is Human》确立**双轨**：强制系统（死亡/严重伤害，公开问责）与自愿系统（**未遂事件 near miss 为主**、机密、无罚款、法律 discoverability 保护）**必须分开运营**。成功四特征：报告者安全、有建设性响应、有专家资源学习、结果可传播。
- 实证（UVA 门诊）：非惩罚系统上线后年报告 5 → **100** 件（83% 是未遂），建议干预 75% 落地；Oak Harbor 海军医院：从个人追责转系统归因。
- 行业常量：**仅 10–20% 错误被报告；被报告的 90–95% 未造成伤害**；无触发器时约 90% 不良事件被漏掉。

### P7. 触发工具（GTT/Safer Dx）：两层记录审查，按线索定位而非全量人审

IHI GTT（2003）：护士一审按触发器（6 模块）筛记录 → 专家二审确认，NCC MERP A-I 伤害分级。**对越重伤害越准**（全部 AE 敏感度仅 0.41，F-I 重度显著更高）；肿瘤 ADE 触发器敏感度 91.8%/PPV 46%。Safer Dx 进一步做**诊断专用 e-trigger**（GTT 对诊断错误不敏感）。
- **Safer Dx 过程五维**：①医患接触 ②检查执行与解读 ③**随访追踪/异常结果闭环（closing the loop）** ④专科与转诊 ⑤患者因素；Safer Dx Instrument：13 项 1-7 分，前 12 项结构化评估过程、第 13 项给全局判定——**评的是过程而非结局**。

### P8. 独立复核与"物理不可能"设计

- **独立双查（IDC）**：两人**各自独立**计算/核对、互不知结果（防确认偏误），Campbell 等：真正独立时可截获 **93%** 给药错误；仅限高警示药（胰岛素/肝素/化疗/阿片），不泛化。
- **第二意见实证**：乳腺癌多学科肿瘤板复核 **42.8% 改诊断**、22.8% 发现新癌；病理判读在**边界类别**一致性崩塌（非典型增生对专家参照一致率仅 **48%**，DCIS 84%，明确浸润癌高一致）；6171 例强制二审 1.4% 有改变治疗的重大变更；头颈病理 7% 显著不同，其中 87% 改了治疗。**复核必须看原始材料（切片）而非报告副本。**
- **物理不可能设计**：长春新碱只装迷你袋不装注射器，使鞘内误注在物理上不可能——比流程提醒高一个层级。
- M&M 会议：季度、专门评审委员会选案、非追责、前瞻性展开（在决策点暂停匿名投票）、行动项跟踪表闭环。

## 二、踩过的坑（5 条，含 2 个真实失败案例）

### F1. Betsy Lehman 化疗 4 倍过量（Dana-Farber，1994）
39 岁记者，环磷酰胺方案为 **4 g/m² 分 4 天**（共 4 g/m²，每日 1630 mg）；住院医把"疗程总量"误读为"每日剂量"，实给 **16 g/m²（4 倍）**，患者死亡；第二名患者幸存但永久心脏损伤。**数十名医生/护士/药师经手，无一发现**。系统根因：手写医嘱无标准模板、方案文本歧义、医护拿不到方案原文、无剂量上限硬拦截。后果：JCAHO 察看（probation）、州卫生厅 33 页缺陷清单、机构全面重建医嘱系统。【已查证】https://connection.asco.org/doi/10.1200/JOP.19.00646 ；HBS 9-699-025
**坑的本质**：**歧义在源头（方案文本），下游所有人工复核全部失效**——错误穿过了所有"奶酪片"。

### F2. UCSF NEMO 少年 38.5 片事件（2013）
EHR 医嘱误录为"单次 38.5 片"复方新诺明，700 万美元发药机器人**忠实执行**；当班 float 护士觉得异常但未质疑，逐片喂服，患者癫痫发作、呼吸骤停（后幸存）。【已查证】同 ASCO 文献
**坑的本质**：**自动化只忠实放大输入，不提供合理性判断；权威系统输出压制一线质疑**（与 v26-B 航空 CRM 的反面完全同构）。

### F3. 告警疲劳的三十年轮回
1990s-2000s CPOE 在受控学术环境有效（严重用药错误可降 55%）；HITECH 354 亿美元推动 EHR 采用率 9.4%→96%，厂商为免责把敏感度拉满 → 50-100 告警/班 → override 90%+，连**危急告警也被 <2 秒关掉**。技术成功（生成了告警）、系统失败（改变不了行为）。
### F4. 只看结局不看过程
基于尸检/理赔的测量有后视偏差，且只捕获造成坏结局的错误；无结局的错误（被纠正的、无害的）系统性不可见 → 行业对"怎么错的"长期失明，直到 Safer Dx 转向过程测量。
### F5. 个人追责文化杀死报告
追责使报告者害怕"报告会成为过错证据"→ 报告枯竭 → 组织丧失学习来源；现代转向"bad systems, not bad people"（但同时保留对鲁莽违规的追责——just culture 不是无边界免责）。

## 三、对阙疑的映射【类比推断】

| 临床实践 | 阙疑组件/机制对应 |
|---|---|
| P1 尸检金标准复核 | 重建式 replay（v25-C）必须是"独立金标准通道"；无金标准通道的指标不得报告为检出率；阙疑"逃逸率 1/1406"只是被观测子集，需明示分母 |
| 10–15% 错误基线 | 阙疑"验证通过"应预期错误率是两位数百分比量级而非零；v23 三阈值（5%/20%/40%）与临床 11.1% 基线同量级，合理 |
| P2 DDx 3-5 并行假设 + 先排最危险 | 卡片验证应强制产出 ≥3 个"它可能错在哪"的候选失败模式并先排除高危类（等价于 ACH，见 F 方向）；当前 gate 是单一假设确认 |
| P3 GRADE 四级+五降级 | 证据精度 schema（v25-C）可直接采用 GRADE 四档与五降级因素（偏倚/不一致/间接/不精确/发表偏置）作为 source_class 评级 |
| P4 override 92.9% vs 0.4% 负担 | v23 疲劳线 40% 有了行业锚：**90% override 是死亡区**；阙疑告警准入应测"改变判决率"（对应临床"changed practice 43%"），低于阈值的规则告警下线 |
| P5 NEWS2 阈值即政策 | 阈值变更必须连同处置分层一起改；敏感度 0.87/特异度 0.39 的实证支持"高敏感筛查+分层消化"而非单点裁决 |
| P6 双轨报告分离 | 阙疑应把"逃逸（强制、可追责）"与"未遂/运气正确（自愿、无惩罚）"分两个台账通道；当前两者混在一起会压制未遂上报 |
| P7 过程评分（13 项→全局） | 评审/人审应评**验证过程**而非只看结论对错——Safer Dx Instrument 可直接改写为阙疑卡片审查清单 |
| P8 IDC 93% | v25-F 共识门的定量支撑：**真独立**双查 93% 拦截率；但仅限高危卡（成本约束），且必须各自先判（blind protocol） |
| 边界类别一致率 48% | 阙疑"边界卡片"（新域/新标准草案）应自动升级为强制二审，明确类别一致率随模糊度崩塌 |
| 复核看原始切片不看报告 | 人审/他验必须回到原始证据（编译记录/标准原文），不得基于上一手结论复核（与 v25-G 接地、v25-F 盲评合流） |
| 物理不可能设计 | 对高危错误用硬拦截（schema 层无法表达）而非告警——比加规则高一层 |
| 闭环异常结果 | 异常结果（击败器触发）必须有 owner 与关闭时限——"closing the loop"直接对应台账条目 resolution 字段 |

## 四、可直接搬的设计（5 条）

1. **Safer Dx 式过程审查清单**：把 13 项过程评估改为阙疑卡片"验证过程检查表"，最后一项才是全局判定——评过程不评结局，立即可用于人审。
2. **强制/自愿双台账**：逃逸走强制台账；未遂与"运气正确"走无惩罚自愿通道（并对上报者免疫）。
3. **DDx 失败模式字段**：每张高危卡验证时强制列 3-5 个候选失败模式 + 最危险项排除证据（结构化字段，非自由文本）。
4. **告警精算指标**：每条告警规则上线须报三数（负担率/相关率/改变判决率），定期淘汰；override 率 >90% 的告警自动进入复审。
5. **边界卡片强制二审 + 回到原始材料**：模糊度高的类别自动升级，复核者只见原始证据。

## 五、不能直接搬的（4 条及原因）

1. **尸检式全量金标准复核**：医学只在死亡后做、比例已暴跌；知识卡全量"尸检"成本无限（v25-D R(D) 已证），只能抽样+高风险子集。
2. **概率型 ML 告警直接替换规则**：Sheba 系统成功依赖院内实时数据与专职信息学团队；阙疑反馈死区时间 τ_d 以周计、标注稀薄，直接上 ML 告警会更差，先做规则告警精算。
3. **生理参数式评分**：NEWS2 建立在可连续客观测量的生命体征上；知识卡没有等价的实时标量流，分数只能用于分流不能用于判决。
4. **人体伤害分级直接套用**：NCC MERP A-I 是患者伤害分级；知识错误的"伤害"（误导下游）传导链不同，需自定义严重度，但"对越重事件测量越敏感"的原则可继承。
