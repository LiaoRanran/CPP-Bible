## 一、核心实践清单（8 条，含数字与流程）

### P1. 可采性前置：先问"能不能用"，再问"有多强"

法庭把判断切成**两道门**：**可采性（admissibility，法官决定）→ 分量/证明力（weight，事实认定者决定）**。不可采的证据**根本不进入第二步**，而不是"降权使用"。

- **传闻规则（FRE 801–802）**：庭外陈述用于证明所主张事实的真实性时**原则排除**，第一理由是"**陈述人无法被交叉询问**"。
- **FRE 803 的例外不是"许可清单"，而是"可靠性替代担保清单"**（共 23 项 + 807 残余例外）：【已查证】https://www.law.cornell.edu/rules/fre/rule_803

| 例外 | 担保机制（为什么可信） |
|---|---|
| (1) 当场印象 / (2) 惊呼 | **无暇编造**：事件与陈述的即时性 |
| (4) 医疗诊断陈述 | **强动机真实性**（患者不会对自己的医生撒谎） |
| (6) 常规业务记录 | **系统性核对 + 常规性**，且反方可推翻 |
| (8) 公共记录 | **法定职责 + 官方程序**（但**刑事案件排除警方观察记录**） |
| (16) 古老文书 | **时间先于争议**（1998-01-01 前，见 F4） |
| (18) 学术论著 | **同行审视 + 作者声誉**，但只可在专家在场时使用 |
| (22) 先前定罪判决 | **经审判或认罪 + 重罪级别**（排除 nolo contendere） |
| 807 残余例外 | 四要件：等效可信性担保 / 重要事实 / **比任何可合理取得的其他证据更具证明力** / 符合规则目的，且须**事前通知对方** |

- **链条断裂规则**：803(6) 要求信息提供者也处在"常规业务"中——**记录者合规但信息提供者不合规，链条即断**（Johnson v. Lutz：警方报告引用旁观者陈述不可采）；**为诉讼而制作的报告不是常规业务记录**（Palmer v. Hoffman）。
- **可推翻设计**：803(6)(E)/(7)/(8) 都写明"**反对方未能证明来源或情形表明缺乏可信性**"——**默认可采，举证责任在质疑方**。

### P2. 三档证明标准：把"错误代价"显式写进标准

| 档 | 标准 | 强度 |
|---|---|---|
| 民事 | **优势证据（preponderance）** | >50%，"更可能如此" |
| 中间 | **清楚且令人确信（clear and convincing）** | 显著高于优势、低于刑事 |
| 刑事 | **排除合理怀疑（beyond a reasonable doubt）** | Blackstone 本人把它量化为"**略高于 90%**"【已查证】https://www.wikiwand.com/en/Blackstone%27s_ratio |

- **为什么分三档**：不是为了"严谨"，而是**错误代价不对称**——刑事错判剥夺自由乃至生命，民事错判只是财产分配。Blackstone 表述为"**宁可放走十个有罪者，不可冤枉一个无辜者**"（10:1）；更早的 Fortescue（约 1470）用的是 **20:1**。【已查证】同上
- **中国法对应**：2012 年刑诉法第二次修改把"**排除合理怀疑**"写入，第 55 条第 2 款规定"证据确实、充分"应同时满足三条件——①定罪量刑的事实都有证据证明；②据以定案的证据均经法定程序查证属实；③**综合全案证据，对所认定事实已排除合理怀疑**。【已查证】https://www.spp.gov.cn/llyj/202505/t20250510_695264.shtml （最高人民检察院）
- **关键元教训**：**标准必须先声明代价配比，再选阈值**。没有 10:1 这种显式配比，"严格"只是形容词。

### P3. 举证责任：分清"谁先出牌"和"谁最终说服"

- **两分法**：**提出证据责任（burden of production）可以转移**；**说服责任（burden of persuasion）永不转移**——它只在最后阶段才起作用。【已查证】https://researchrepository.wvu.edu/cgi/viewcontent.cgi?article=3825&context=wvlr
- **刑事**：说服责任恒定在控方，不因被告提出抗辩而转移；被告只在**积极抗辩**（如正当防卫、不在场）上承担提出责任。
- **可采性层面**：803(6)(E) 把"不可信"的举证责任放在**反对方**——一旦提出方证明五项基础要件，**推定记录可靠**，质疑方须举证推翻（且**不需要提出积极性证据，论证即可**）。
- **关键元教训**：**举证责任的位置决定了系统的默认状态**。默认可采 + 反方推翻 = "默认信任，异议驱动"；默认不可采 + 提出方证明 = "默认不信任，证明驱动"。同一个系统里两套并存（传闻用后者，记录可信性用前者）。

### P4. 专家证人守门人（Daubert）：对"方法"而非对"人"做准入

法官是 **gatekeeper**，审前可用 motion in limine 排除。五要素【已查证】https://www.law.cornell.edu/wex/daubert_standard ：

1. 该理论/技术**可否被检验、是否已被检验**；
2. 是否经过**同行评审与发表**；
3. **已知或潜在的错误率**（known or potential rate of error）；
4. 是否存在并维持**控制其操作的标准**；
5. 是否在相关科学共同体中获得**普遍接受**。

- **演进**：Frye（1923）只问"普遍接受"→ Daubert（1993）改为方法论审查 → Joiner（1997）确立滥用裁量审查 → Kumho（1999）扩展到**非科学专家**（工程师等）；FRE 702 据此修订。三者合称"Daubert 三部曲"。

### P5. 雇佣枪手对策：FRE 706 法院指定专家（**威慑本身就是机制**）

FRE 706 要点【已查证】https://www.law.cornell.edu/rules/fre/rule_706 ：
- 法院可**依申请或依职权**指定专家，可要求双方提名；可指定双方一致同意的人**或自己选的人**（须本人同意）；
- 指定专家**必须向双方披露其发现**、**可被任何一方录取证言（deposed）**、**可被任何一方交叉询问**（包括传唤他的一方）；
- 报酬由**法院**确定（刑事案件从法定资金支付）；
- **法院可授权向陪审团披露"该专家由法院指定"**；
- 不限制当事人自行聘请专家（(e)）。

**最精妙的是咨询委员会的原话**，它解释了机制如何生效：

> "shopping for experts（**选购专家**）、某些专家的贪利……一直是深切关注的问题。尽管有观点认为法院指定的专家会获得一种他们不配拥有的'无误光环'……**实际指定发生的频率相对较低，但可以假定：这个程序'存在'本身就减少了对它的使用需求。法官在个案中指定专家的这一常在可能性，必然会对当事人的专家证人以及使用其服务的人产生清醒作用。**"

**即：机制的价值不在被调用，而在被调用的可能性所产生的威慑。**

### P6. 交叉询问：一套结构化的"证言可靠性检验清单"

NIJ 对专家证人的**六个攻击面**【已查证】https://nij.ojp.gov/nij-hosted-online-training-courses/law-101-legal-guide-forensic-expert/trial/cross-examination ：

| # | 攻击面 |
|---|---|
| 1 | **感知能力/应用不足**（没做足功课） |
| 2 | **对事实的记忆不充分** |
| 3 | **偏见、成见、对结果的利益关系、作证动机** |
| 4 | **品格、声誉、资质存疑** |
| 5 | **先前不一致的陈述或行为**（同类事实下在另案给出不同结论即可弹劾） |
| 6 | **与公认权威出版物/学术论著不一致** |

- **FRE 允许的四种弹劾理由**：①证明偏见；②先前不一致陈述（书面/口头、宣誓/未宣誓均可）；③先前定罪；④不诚实品格。
- **技术三要点**：①交叉询问**允许使用诱导性问题**（先陈述事实、要求证人同意）——这是与主询问的关键差别；②**好的交叉询问绝不让专家重复其结论**；③聚焦 **credibility / methodology / results** 并索取让步（concession）。
- **认识论内核**：交叉询问检验的不是"结论对不对"，而是**"这个结论是怎么来的、在什么条件下会变"**——与 v25 的"评过程不评结局"（A 方向 P7）完全合流。

### P7. 毒树之果：污染沿因果链传播，且有三个豁免阀门

- **起源**：Silverthorne Lumber Co. v. United States（**1920**）确立；"fruit of the poisonous tree"一词由 Frankfurter 大法官在 **Nardone v. United States（1939）** 中创造。【已查证】https://www.law.cornell.edu/wex/fruit_of_the_poisonous_tree
- **规则**：证据之树被污染，其果实亦被污染——**由可排除证据（如非法供述）衍生的证据同样不可采**。
- **三项例外**（符合则不排除）：①**独立来源**（independent source）；②**必然发现**（inevitable discovery）；③**基于可排除但自愿的被告证言**而发现的证据。附加：**善意例外**下主要证据可采时，其衍生果实也可能可采。【已查证】同上
- **中国法对应**：刑诉法第 56 条（非法方法收集证据应予排除）+ 第 60 条"**确认或者不能排除存在第 56 条情形的，对有关证据应当予以排除**"——**"不能排除"即排除**，举证责任在控方。【已查证】https://www.spp.gov.cn/spp/llyj/202209/t20220914_577240.shtml

### P8. 无罪推定 + 品格证据排除：把"默认态"设成代价低的一侧

- **无罪推定**：默认态 = 未被证明；**主张"有罪"的一方承担全部说服责任**，且标准最高（P2/P3）。它是 P2 的 10:1 配比在程序上的落地。
- **品格证据排除（FRE 404）**：禁止用"某人具有某种品格"证明"他在特定场合按该品格行事"——即**禁止"他以前这样所以这次也这样"**。
- **共同的工程含义**：**默认态的选取 = 错误代价配比的声明**。默认 pass 意味着"漏过错误比误杀正确更贵"；默认 block 则相反。阙疑必须先把这个数写出来。

## 二、踩过的坑（5 条，含 3 个真实失败案例）

### F1. Sally Clark 案（英国，1999–2003）：专家的统计被当成了证据

- 律师 Sally Clark 两名幼子相继猝死，1999 年被判谋杀。控方核心是儿科专家 **Roy Meadow 爵士**的证言：同一家庭连续两例婴儿猝死（SIDS）的概率约 **1/7300 万**。
- **两处硬错**：①把单例概率 1/8543 **平方**，隐含**独立性假设**——而 SIDS 存在共同的环境与遗传因素，事件高度相关；②**检察官谬误**：把 \(P(\text{证据}\mid\text{无辜})\) 当成 \(P(\text{无辜}\mid\text{证据})\)。【已查证】https://www.sciencedirect.com/sdfe/pdf/download/eid/3-s2.0-B9780443100383500108/first-page-pdf ；后续统计复核见 Fenton 等（2013）对该案的"第二个关键统计疏漏"
- **结局**：2003 年上诉撤销定罪、Clark 获释（R v Clark [2003] EWCA Crim 1020）；该案被视为"现代英国法律史上最大的不公"之一。
- **坑的本质**：**法官没有问 Daubert 第 3 个问题——"这个方法的已知错误率是多少、独立性假设是否被检验过"**。若问了，该证据进不了陪审团。**守门人机制存在的全部意义，就是拦住"看起来很专业、实际是错的"专家意见。**

### F2. 目击证词错认：最自信的证人，最不可靠的证据

- Innocence Project 数据：**被 DNA 洗冤的错案中，约 69% 起始于目击者认错了人**——错认是冤案的第一成因。【已查证】https://innocenceproject.org/eyewitness-misidentification/ ；https://drawingconclusions.org/
- **机制原因**：记忆可塑，且受**暗示性程序**（列队指认方式、警方反馈）污染；证人**主观确信度与实际准确率弱相关**。
- **坑的本质**：**置信度 ≠ 准确度**（与 D 方向 F4 的"精度 ≠ 准确度"完全同构）。任何把"我很确定"当作证据强度的制度都会系统性翻车。

### F3. 传闻链的二次加工污染（803(6) 的 Johnson v. Lutz / Palmer v. Hoffman）

- 记录本身合规，但**信息源不在常规流程内** → 链条断裂；**为诉讼准备**的报告 → 不是常规业务记录。
- **坑的本质**：**转述的每一跳都是新的噪声源，且下游无法检验上游**。这正是传闻规则的工程理由，而不是教条。

### F4. 例外条款会随技术环境老化：803(16) 与 ESI

- 古老文书例外（旧法：20 年以上）在电子化时代变成**大量不可靠电子存储信息的后门**——因为该例外**不要求任何可靠性证明**。2017 年修法把截止日硬性定为 **1998-01-01**，并明确："扫描不改变制备日期，但**内容在截止日后被修改的部分不适用**"。【已查证】同 FRE 803 条文与 2017 年委员会注释
- **坑的本质**：**准入规则必须定期复审，否则例外会吞掉原则**。

### F5. 排除规则的"成本错觉"与反修正

毒树之果长期被批评"放走罪犯"。行业的应对不是放弃，而是**加三个豁免阀门**（独立来源/必然发现/善意例外）来做比例平衡。**错误控制机制若不带比例原则，会被反向修正掉**——这与 A 方向"告警疲劳"、本方向 P2 的代价配比是同一条规律。

## 三、对阙疑的映射【类比推断】

| 司法机制 | 阙疑组件/机制对应 |
|---|---|
| P1 可采性前置（两步门） | 阙疑目前是"证据进来 → 加权 → 判决"，缺**准入门**。应加 `admissibility gate`：编译器实测/标准原文/可复现实验 = 可采；二次转述/AI 摘要/未注明来源 = **不采**（不是降权）。这是"降权"与"不采"的原则性差别 |
| 803 例外 = **可靠性替代担保** | 阙疑的 source_class 不应只给"可信度分数"，而应标注**担保类型**：即时性（当场记录）/系统性（有固定流程、可复核）/常规性（官方例行生成）/权威性（同行审视）。不同类型对应不同的失效模式 |
| 803(6) 链条断裂 | 证据 provenance 链每一跳都要记；**任一跳的提供者不在"常规流程"内，整条链降级**（与 v25-G 接地链检查直接合流，可复用其数据结构） |
| 803(8) 刑事案件排除警方观察记录 | 对**利益相关方自述其系统表现**的证据（如生成器自报的覆盖率）应默认不采，除非有独立复核——对应 v26 的独立重复（D 方向 P5）与 F 方向的独立性 |
| 默认可采 + 反方举证推翻 | 阙疑应明确**举证责任位置**：金标准类证据默认可采，质疑方须举证（论证即可，不必提出积极性证据）；非金标准类默认不采，提出方须证明 |
| P2 三档标准 + 10:1 | 阙疑判决应分三档：**block（刑事级，需最高强度）/ pass（民事级，优势证据）/ unknown（证据不足，记"不生效"≠无效，v25-G）**。并且**必须先写出错误代价比**：当前逃逸率 1/1406（≈0.07%）与自身免疫率 14.3% 意味着实际配比约 **1 : 200**——**必须显式声明这个配比是否可接受**，而不是默认接受 |
| Blackstone 略高于 90% | 若阙疑把"验证通过"类比刑事定罪，则 pass 的证据强度应 >90%；若类比民事，则 >50%。**现在阙疑没有这个数**——这就是 Horizon 60 断崖处"不知道该信到什么程度"的根因 |
| P3 提出责任可转移、说服责任不转移 | 阙疑中"**提出证据**"的责任可以自动/轮换（mutation 生成器、评审人轮换），但"**说服**"的责任**永不转移给工具**——最终说服责任始终在 Authority 人审。工具只能降低提出成本，不能承担说服责任 |
| P4 Daubert 五要素 | 对**验证器本身**（67 条 gate 规则集、mutation 生成器）做准入审查：可检验？同行评审？**已知错误率？**操作标准？社区接受？——**阙疑目前缺"错误率"字段**，这是最该补的一项 |
| P5 FRE 706（威慑即机制） | 阙疑 Authority 人审应设**系统指定评审人通道**（不由卡片提交者挑人），并**保留"可指定"这一可能性本身**。按咨询委员会的逻辑，这会让自选评审人的行为也变得克制 |
| 指定专家可被任何一方交叉询问 | 系统指定评审人的结论必须**可被复核、可被质疑**，且质疑方包括"传唤他的一方"——即评审结论不得因"是系统找的人"而免检 |
| P6 六攻击面 | 人审清单应逐项检查：①**感知能力**（是否看过原始材料，对应 A 方向 P8"复核看原始切片"）；②记忆（能否回溯结论来源）；③**利益关系/偏见**（评审人与卡作者是否同源 → v25-F 同源检测）；④资质；⑤**前后不一致**（该评审人历史判决的一致性 → CalibrationTracker 已有基础）；⑥**与权威文献不一致** |
| 诱导性问题 + 不让重复结论 | 人审界面**不得先展示 gate/AI 的结论**（v25-F blind_protocol 的流程化版本）；提问应设计为"陈述事实 + 要求确认"，而非开放式"你觉得对吗" |
| P7 毒树之果 | **污染沿因果链传播**：若一个 mutation 基于一条错误知识生成，则由它检出的所有"覆盖率提升/规则有效性"都不可采；需配三个阀门：**独立来源**（该结论另有独立证据）、**必然发现**（该错误无论如何都会被别的规则发现）、**善意**（生成时不知道基础有误） |
| 中国法"不能排除即排除" | 对证据合法性存疑时按**存疑从无**处理——对应阙疑：证据链完整性存疑的卡**默认不通过**，而不是"大概对就过" |
| P8 无罪推定 / 404 品格排除 | ①阙疑默认态应为 `unverified` 而非 `pass`，主张通过者承担说服责任；②**禁止"他以前错所以这次也错"**：卡片的历史错误记录不得作为本次判决依据（只可作为**抽检优先级**）——这是 404 的直接对应，也防止 Authority 账本被滥用为"前科偏见" |

## 四、可直接搬的设计（5 条）

1. **证据准入门（admissibility gate）**：来源分级 + **担保类型标注**；不采（而非降权）无担保来源。可在不动判决逻辑的前提下先做（阶段 1 级别）。
2. **三档判决 + 显式错误代价比**：block / pass / unknown 三档，并在台账里写明当前配比（逃逸率 : 自身免疫率 ≈ 1:200）与是否可接受。
3. **验证器 Daubert 自查表**（尤其"已知错误率"字段）：适用于新增 gate 规则与 mutation 生成器的准入。
4. **人审交叉询问清单（六攻击面）**：结构化字段替换自由文本意见；重点实现"同源/利益"与"前后不一致"两项自动预检。
5. **污染传播规则 + 三阀门**：一条知识被判定错误后，自动标记其**下游衍生结论**为 `tainted`，除非满足独立来源/必然发现/善意三条件之一。

## 五、不能直接搬的（4 条及原因）

1. **对抗制本身**：法庭的检验压力来自**利益对立的两造**。阙疑没有对立双方，照搬会得到"无人质疑"的空转。必须**人工制造对立**：mutation 生成器扮演反方 + 评审人轮换 + 系统指定通道（P5）。
2. **排除规则的惩罚性基础**：毒树之果的首要目的是**威慑警察违法取证**。阙疑没有"违法取证"概念，只能搬"**污染沿因果链传播**"这半边，惩罚性排除（明知可用也强制排除以示惩戒）不适用。
3. **陪审团**：法庭把"分量判断"外包给一个常识裁判者。阙疑没有等价物，不能用"交给人类直觉兜底"来替代——必须把分量判断也工程化（强度分档 + 校准追踪）。
4. **传闻规则的证人对质性前提**：传闻排除的第一理由是"陈述人无法出庭被盘问"。知识证据大多不是**证人陈述**而是**文书/实测**，直接套传闻规则会误伤（标准原文不是传闻，是文书证据）。应按**可复核性**（能否独立重跑/独立查原文）重构，而非按"是否可盘问"。
