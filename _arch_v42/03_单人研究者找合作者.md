# _arch_v42 · 03 单人研究者找合作者（方向 3）

> 核心问题：双非本科生、0 影响力，怎么找导师/合作者；冷邮件模板；HF Community Evals 机会；何时该找/何时自己扛。
> 诚实标注：【指南】；【社区】；【共识】；【推断】= 对阙疑的判断；【盲区】= 无法核实。

---

## 一、现实定位

- 单人 + 本科生 + 0 影响力，是 NeurIPS 投稿的最弱资历组合，但**不是否决项**：E&D/数据集 track 更看重 artifact 与方法，个人背书权重低于 main track【推断】。
- 合作者能补的三类缺口：方法论（统计/实验设计）、写作（英文学术语感）、独立复现（方向 02）。

## 二、冷邮件模板（可直接改）

主题：Replication/audit collaborator for a C++ knowledge-verification system (NeurIPS 2027 E&D)
正文要点：（1）一句话说清系统与研究问题；（2）已有什么硬证据（48 卡 / 452 账本 / Merkle）；（3）具体想要对方做什么（如独立复现或统计设计）；（4）低承诺：先一次 30 分钟 call【推断，模板来自 S13/S15】。

## 三、HF Community Evals 机会

- Hugging Face 有社区评测与 leaderboard 生态，可作为"发布 artifact + 吸引审计者"的渠道【推断，S14】。风险：曝光即暴露弱点，需先备好 threats 章节。

## 四、何时找 / 何时自己扛

- 找：需要独立复现、需要统计严谨性、需要母语级英文改写。
- 自己扛：系统实现、内部数据、账本维护——这些不可外包（护城河）。
