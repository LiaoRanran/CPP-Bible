怎么读这张表

  • 8 资产 OR：asan / ubsan / tsan / compiler-warn / wunsequenced / cross-compile / linker / compile-time 任一 catch 即 catch； 全部 unknown 才记 unknown（绝不当 miss）。
  • 命中资产：实际报出该缺陷的检测器（多资产命中 = 互补）。
  • 点"详情"可看逐资产判定、原始检测器输出摘要、出处链接与复现命令。
  • 年份 = NVD 首次发布年（如有）；无 CVE 的条目用项目披露年。

诚实声明：PoC 为最小重构（source-derived / reconstructed）， 不是原始项目上下文；部分样本在本地观测（如 sanitizer 超时）与环境相关，逐条在详情中标注。 CVE 描述、CVSS、发布时间均来自 NVD API 应答原文（在线验证记录见 data.html）。
