# 证据双轴词表（L1-L5 获取级 × GRADE 式断言把握度）

> 651 W0 产出（纯文档，零代码）。用途：把「证据从哪来」（获取级）与「这条断言有多可信」（把握度）
> 拆成**两个正交轴**，避免历史上把「有标准原文」直接当成「断言成立」。

## 一、为什么分两轴（一句话）

**获取级**说的是 *证据渠道*（我是在真机跑的，还是读的标准原文，还是人说的）；
**把握度**说的是 *该证据对某条断言的支撑强度*。同一份 L1 证据可以支撑一个高把握度断言，
也可以只支撑一个低把握度断言（例如「本机 gcc 13.1.0 下 -O2 未溢出」≠「所有编译器都未溢出」）。

## 二、轴 A · 获取级 L1-L5（acquisition level）

| 级 | 名称 | 定义 | 判据（可机器核对） | 例 |
|---|---|---|---|---|
| L1 | 实测 | 本机真编译器/真工具跑出的可复现输出 | 有 cmd + 输入哈希 + 输出 kv | 648 十卡 `gcc -std=c11 -O2` 输出 |
| L2 | 一手原文 | 标准/规范原文逐字片段，带条款锚点与字节偏移 | 有 clause_anchor + 偏移 + 原文 | `data/648_c_standard.md` N1570 6.7.6.3p7 |
| L3 | 二手权威 | 权威文档/教材/CW 对标准的转述（可能失真） | 有出处但不含条款原文 | cppreference 条目 |
| L4 | 社区/经验 | 博客、问答、口口相传 | 无稳定出处或不可复核 | 论坛回帖 |
| L5 | 未获取 | 只有断言，无任何外部证据 | 无 | 凭印象写的一句话 |

**规则**：L 级只描述渠道，**不自动**决定把握度；L 越低把握度上限越低（见下表映射默认值）。

## 三、轴 B · 把握度（GRADE 式：高/中/低/极低）

| 把握度 | 含义 | 默认起始（按最高获取级） |
|---|---|---|
| 高 high | 极不可能被新证据推翻 | 起始 L1 且断言范围=实测范围 |
| 中 moderate | 可能被新证据修正 | 起始 L2；或 L1 但断言外推 |
| 低 low | 很可能被新证据修正 | 起始 L3；或 L2 但跨版本外推 |
| 极低 very low | 基本不可依赖 | 起始 L4 / L5 |

### 升降级因子（对初始把握度做加减，可叠加）

**升级（最高升到「高」）**
| 因子 | 条件 | 幅度 |
|---|---|---|
| U1 多编译器一致 | ≥2 编译器/≥2 标准档一致 | +1 档 |
| U2 反例检索失败 | 主动搜反例（B4 工具）无命中 | +1 档 |
| U3 原文逐字 | 断言是标准原文的直接引用（非转述） | +1 档 |
| U4 交叉复算 | 独立工具/独立验证者复算一致 | +1 档 |

**降级（最低降到「极低」）**
| 因子 | 条件 | 幅度 |
|---|---|---|
| D1 外推 | 断言范围超出实测范围（版本/平台/优化档） | −1 档 |
| D2 实现定义 | 断言落在 standard 的 implementation-defined/unspecified 处 | −1 档 |
| D3 单点证据 | 仅 1 次运行 / 1 个样例 | −1 档 |
| D4 无锚点 | 有获取级但无条款锚点/偏移 | −1 档 |
| D5 时效过期 | `recheck_after` 已过（H7） | −1 档 |

## 四、合成规则（写卡/评级时用）

```
把握度 = clamp( 起始(最高获取级) + Σ升级 − Σ降级 , 极低..高 )
```
- **获取级取该断言引用证据里的最高级**（不能把 L1 与 L5 平均）。
- 每条断言**必须**同时记 `acquisition_level` 与 `assertion_confidence`，缺一不可（对应 T1 的 `unknown_reason`）。
- 两轴冲突时以**低者**为准并记降级理由（如 L1 但 D2 实现定义 ⇒ 中/低 + reason=`implementation_defined`）。

## 五、与现有产物的落地
- 648 十张 C 卡：获取级 = **L1**（真机实测）+ L2（N1570 原文）；把握度见 `data/651_h2_dual_axis_review.md`（H2 手标）。
- 649 std_refs 注册表：登记的是**证据本身**（L2 锚点），不是把握度——把握度属卡片/断言层。
