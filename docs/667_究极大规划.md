## 3. 数据扩展路径（47 → 80 → 150）

### 3.1 为什么"卡数"是主线，但**不是**第一优先

- 现在 47 张卡（37 实卡 + 10 草稿），目标 83 张（历史目标）。
- 但 **47 卡里 0 张有边界三元组**（656 D 实测）⇒ 四态判决**恒定 unknown**。
  ⇒ **先补边界，再扩卡**。否则 150 张卡也只是 150 个 unknown。

### 3.2 路径（B2 断言拆卡优先）

| 阶段 | 数量 | 来源（按优先级） | 每张必须带 | 验收 |
|---|---|---|---|---|
| **S1 回填** | 47 → 47 | 存量卡补 **边界三元组** + 真机证据 | 边界三元组（输入域/前提/失效条件） | unknown 比例从 100% 降到可复算的水平 |
| **S2 拆卡** | 47 → 80 | ① Book 既有断言（151 md 章）<br>② Benchmarks（33 cpp）<br>③ Appendix/ub（15 条 UB 示例）<br>④ misconceptions（80 md） | ① 真机编译/运行证据（落 `data/evidence_store/`，内容寻址）<br>② 边界三元组<br>③ 四态判决<br>④ provenance + `signed_by: none`（机器卡不代签） | `counts_659` 自动跟上；新卡 100% 有边界；gate 无新增 block |
| **S3 条件扩** | 80 → 150 | ⑤ 外部语料（cppreference / 标准条款）转卡<br>⑥ 真实缺陷夹具（15 条）转卡<br>⑦ 反例语义级扩展 | 同 S2 | 同 S2；**且 M0–M6 全绿** |

### 3.3 单卡生产成本与产能（**现实约束**）

- 单卡：选题 15min + 夹具/证据 30–60min + 边界 20min + 校验 15min ≈ **1.5–2 h**（含真机编译等待）。
- ⇒ 33 张新卡 ≈ **50–66 h 净工时**。按每周净投入 6–10 h 计 ≈ **6–10 周**。
  ⇒ 这是 M2 排在 2026-12（给 3 个月窗口）的原因。

### 3.4 数据可信度的三条硬要求（否则不如不扩）

1. **每张卡的证据必须能在新克隆里重跑**（命令 + 编译器版本落盘）；
2. **来源必须到可确证的层级**（类别级出处可，但须标 `verified_source`）；
3. **机器卡一律 `needs_review: true`**，不许以任何方式混入"已验证卡"计数。

## 4. 实验计划

### 4.1 ablation A–F（每组**先写假设**，再看结果）

| 组 | 去掉/改变什么 | 假设（预写） | 主指标 |
|---|---|---|---|
| **A** | Full（全系统） | 基线 | holdout 检出率 + external 分层率 |
| **B** | − 变异测试模块 | 内部自证指标消失，**外部检出率不变**（验证"变异率 ≠ 检测率"） | 外部检出率差值 CI |
| **C** | − Merkle / 供应链 | 可复算性下降（复现者失败点增多），检出率不变 | 复现失败点数 |
| **D** | − B1 头部层（证据获取） | 证据完整度下降 ⇒ unknown 比例上升 | unknown 比例 |
| **E** | − 边界三元组强制 | 四态退化，unknown 被误记为 pass ⇒ **假 pass 率上升**（坐实边界的必要性） | 假 pass 率 |
| **F** | **random-budget 对照** | 若 Full 的收益主要来自"更多尝试"，则 random-budget 会追平 | 同等预算下的检出率 |

### 4.2 baseline（budget-matched）

四个：**regex 哑基线**、**cppcheck**、**clang-tidy**、**sanitizer 组合**。
对齐条件（**必须写进产物**）：同一语料、同一编译档（**双档都要跑**）、同一判定粒度、
同一时间/调用预算；逐样本原始输出落盘。

### 4.3 分层（不许合并成一个漂亮数字）

- **盲态层**：真盲态样本（M5 后才有）单独报告；
- **非盲态层**：665 追加的 10 条、机器卡 16 张 —— 只能增大分母，**不得 Claim 外部效度**；
- **external 三层**：A 本地检测器 / B 跨编译器或测量类 / C 无本地检测器（当前 4/4 unknown，是**对照证据**不是失败）。

### 4.4 统计口径（M1 冻结，此后不改）

| 场景 | 方法 |
|---|---|
| 单比例 CI | **Clopper–Pearson 精确 95% CI**；Wilson 作敏感性分析；**禁用小样本 Wald** |
| 独立样本比较 | **Fisher / Boschloo** |
| 同批样本前后比较 | **精确 McNemar** |
| 多重比较 | 探索性 **BH-FDR**；确认性少量比较 **Holm**；检验族**预先定义** |
| 效应量 | 必须报差值 + CI，**不能只报 p** |
| 聚类相关 | 先数 source clusters、估 ICC/DEFF/n_eff；必要时聚合到源文件（**40 张同源卡 ≠ 40 个独立观测**） |
| IRR | 两人 Cohen's κ；多人/缺失 Krippendorff's α；**α ≥ 0.67** 才作 tentative 结论 |
| 样本量 | n=30 ⇒ CI 宽约 ±37pp；要 ±10pp 需 **n ≈ 93–104**（**这是 M5 定 100 的依据**） |

**红线（写进论文）**：不声称"显著优化"；不把 0/8 写"无效"；不把 6/6 裸写 100%；
不把变异 kill rate 称检测率；不把同源判据下的 F1=1.0 称"已校准"。

## 7. 外部复现节点（M6 的详细定义）

1. **复现包**：`REPLICATION.md` + 依赖锁（`requirements.lock.txt` / `uv.lock`）+ **单命令入口**；
2. **复现者**：1 名**未参与本项目**的人（同学 / 网友 / 开源 issue 求助），给匿名复现包；
3. **记录**：复现者日志（每一步的实际输出 + 失败点）原样入仓，**不改**；
4. **验收**：至少跑通"卡 `--check` + 一次编译证据 + 一次 holdout reveal"；
5. **诚实**：跑不通的地方写进论文 §Reproducibility 与 Threats 第三层（自证闭环）；
6. **主仓当前缺口**：拆仓（`queyi-core`）不在本仓 git 内 ⇒ 9 保护器、813 行内核**本仓无法独立复算**。
