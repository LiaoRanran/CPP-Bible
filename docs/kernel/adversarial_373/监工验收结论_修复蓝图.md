## 二、源码核实证据（最重四条，c1ceb13 快照）

### B9 签收前缀伪造（空名/空格名）—— P0
- `tools/gate_engine.py:815-816`：`by = str(meta.get("verified_by") or "")`；`if not by.startswith(need)` —— **只查前缀，不查冒号后非空、不查白名单**。
- `:396` `dal_reviewed_by` 同病；`:334` status_history 的 by 同病。
- `verified_by: human:`（空名）、`human: `（空格）、`human:任意名` 全部通过。
- 组合攻击：Writer 自写 `machine:`（空名）作前驱 → 再写 `human:`（空名）→ 状态链完整 → DAL C 自签 `dal_reviewed_by: human:` 豁免 → 零门槛 verified。
- **修法**：S1 + DAL + status_history 三处统一：`human:`/`machine:`/`redteam:` 冒号后必须非空且匹配维护者白名单（git log 作者或 `MAINTAINERS`）；空名/空格 → block。

### B3 .out 编造（声明键外自由域）—— P0
- `tools/atom_evidence_replay.py:758` `want_keys = actual.get("run_match_keys")`；`:784` 只核对 want_keys 在 .out 中逐字一致。
- **完全不校验**：.out 未声明的额外行、`expected:`/`falsification:` 散文里的数字是否在声明键中。
- 攻击：夹具只打印 `smoke=1`，.out 手写 `smoke=1` + 编造 `fabricated_leak=64`，expected 散文把编造数字写成主证 → replay confirm、gate 0 findings。
- **修法**：新增规则 `EV-OBSERVATION-VISIBLE`：`expected`/`falsification` 中每个数字 token 必须出现在 `actual` 声明键值或 .out 声明键值中，否则 warn→block。

### B2 恒真符号断言（跨编译器路径）—— P0
- `tools/atom_evidence_replay.py:535-538`：`contains` = `got = text出现次数; hit = got > 0`。
- **无任何"断言符号须在夹具源码中出现"的交叉验证**。`main`/`call`/`ret` 在任何 x86 汇编恒存在 → 跨编译器路径下整卡无实质证据 confirm。
- **修法**：新增规则 `EV-ASSERT-DISCRIMINATOR`：`contains/absent/contains_in/absent_in` 的断言文本必须是 fixture 源码中出现的标识符（解析 fixture 交叉验证）；通用符号不在夹具中 → warn→block。

### N4 借工件（张冠李戴）—— P0
- replay 执行 command 后校验 `artifact_sha256`，但 **command 可以是任意脚本**（`python _adv_borrow.py <dst>` 复制别卡 .asm），sha 用被借工件真值 → confirm。
- "工件与夹具同代"语义被"任意命令产生 artifact"击穿。
- **修法**：command 必须含编译器调用（g++/clang++/gcc）且输出路径与 artifact 字段一致；或 artifact 生成命令白名单；纯 cp/脚本复制 → block。

## 四、每条修复的验收标准（铁律）

每条修复必须满足，缺一不可：
1. **最小逃逸复现**：先用 TRAE 的攻击卡（在 `_adversarial/cards/` 或按报告复现）确认修复前确实逃逸。
2. **修工具**：改 `tools/gate_engine.py` 或 `tools/atom_evidence_replay.py`，最小改动。
3. **坏例被拦 + 干净例不误伤**：修复后，攻击卡 block/refute；现有 56 张合法卡全量 replay 仍 confirm（0 误伤）。
4. **毒样例**：在 `tests/poison/` 加阴阳配对（TRAE 的 `毒样例候选_P11-P21.md` 直接可用），poison_drill 全绿。
5. **pytest**：加规则级正反例测试，`pytest tests/` 全过。
6. **单独提交**：每条规则一个 commit，工具改动与内容改动分离；commit message 写清"修复 373-B9：签收空名伪造"。
7. **全门禁复跑**：gate / replay（双平台）/ poison / pytest / golden_lock / WSL 预检，全绿后才进下一条。
