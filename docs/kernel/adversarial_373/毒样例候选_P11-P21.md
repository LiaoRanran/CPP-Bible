# poison_candidates.md（毒样例候选清单，建设者收编；不直接改动 poison_drill.py）

> 每个成功逃逸对应一个候选毒样例（阳=坏例应被拦；阴=干净例必须放行）。
> 命名延续 P1–P10 序列：P11 起。所有候选以 `<rule>` 判定逻辑为前提，未实现的规则列为"候选规则"。

## P11 · 恒真通用符号断言（拦 B2-R1）→ 候选规则 `EV-ASSERT-DISCRIMINATOR`
- 阳：`artifact_assert: [{kind: contains, text: "main"}]`，fixture 中无 `main` 标识符（如纯函数库 TU）→ 应 warn/block
- 阴：`artifact_assert: [{kind: contains, text: "_Z4spinv"}]` 且 fixture 含 `spin` 符号 → 放行
- 判定逻辑：断言文本与 fixture 源码标识符（含修饰名前缀解）交叉验证

## P12 · 未声明键读数编造（拦 B3-R2）→ 候选规则 `EV-OBSERVATION-VISIBLE`
- 阳：`actual.run_match_keys: [smoke]`；`.out` 含 `fabricated_leak=64` 且 `expected`/`falsification` 引用该数字 → 拦
- 阴：数字全部出现在 `.out` 声明键值中 → 放行
- 判定逻辑：`expected`/`falsification` 的数字 token ⊆ 声明键值集合

## P13 · 零诊断无 -Werror（拦 B6-R3）→ 候选规则 `EV-NODIAG-WERROR`
- 阳：`expected`/`falsification` 含"零诊断/无警告"，command 无 `-Werror` → 拦
- 阴：同 claim 但 command 含 `-Werror` → 放行

## P14 · 签收前缀空名/空格（拦 B9-G2）→ 收编 `S1-AUTHOR-SELF-VERIFY`（改实现）
- 阳：`verified_by: human:`（空名）→ 拦
- 阴：`verified_by: human:liaoranran`（白名单名）→ 放行
- 阴-2：`verified_by: machine:gate` → 放行
- 判定逻辑：前缀后必须非空 + 匹配维护者白名单

## P15 · 借他卡工件（拦 N4-R5）→ 候选规则 `EV-ARTIFACT-GEN-TRACE`
- 阳：command 的 artifact 生成命令不是编译器调用（`python _adv_borrow.py …`）→ 拦
- 阴：`g++ … -S -o <artifact>` → 放行
- 判定逻辑：生成该 artifact 的命令 argv[0] ∈ 编译器白名单

## P16 · relations mapping-form 环（拦 N1-G3）→ 收编 `ATOM-REL-DAG`（改实现）
- 阳：A `- prerequisite: B` + B `- prerequisite: A`（mapping 写法）→ 拦出环
- 阴：dict 写法单向边 → 放行

## P17 · EV id 重复遮蔽（拦 N2-N1b）→ 候选规则 `EV-ID-UNIQUE`
- 阳：两张 EV 卡同 id（不同文件）→ 拦
- 阴：id 全库唯一 → 放行
- 判定逻辑：对齐 ATOM-ID-UNIQUE（stem==id + 全库唯一）

## P18 · 多编译器零实事声明（拦 N3-M11）→ 收编 `EV-MATRIX-UNBACKED`（改锚点）
- 阳：matrix 声明 [GCC, Clang]，命令仅 `g++ -o` 无双平台 `.out`/CI run 号 → 拦
- 阴：同 matrix + `Examples/...out` 两平台文件 → 放行
- 判定逻辑：删除`g\+\+\s+[^\n]*-o\s+`命令自证锚点

## P19 · 环境依赖值进 run_match（拦 B5-R6）→ 候选规则 `EV-NO-ENV-KEYS`
- 阳：`run_match_keys`/`.out` 键含 `nproc|user|hostname|date|time|cwd|path` 词根 → warn
- 阴：纯计数/行为键 → 放行

## P20 · 稻草人 falsification 同源自比（拦 B8-G5）→ 收编 `EV-FALSIFICATION-QUANT`（改实现）
- 阳：falsification 两取值相同字符串/同为 `&x` 同址描述 → warn
- 阴：两值不同 → 放行

## P21 · pedagogy 折叠块结构化静默（拦 N5-supp1）→ 收编 PED-*（改解析）
- 阳：`pedagogy: >-` 折叠字符串 → 3 条 PED-* 必须报缺（或解析器归一 dict）
- 阴：结构化 dict → 放行
