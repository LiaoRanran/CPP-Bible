# 认知偏差检查清单

> 来源：`References/architecture_架构演进/491_人的因素与认知偏差防护方案_*.md` §一（偏差风险表）与 §七（8 条清单）（494 任务 4）。
> 用途：**人审签署 / 架构决策前过一遍**。本项目单人决策、无 code review，「认可权唯人」是铁律，
> 但人也会犯错 —— 本清单是给"认可权"本身配的护栏（491 §一：系统的最终瓶颈是人）。
> 用法：逐条自问并把答案写进决策日志（491 的决策日志机制）；答不上来的条目即"未想清楚"。

---

## 决策前检查（8 条）

### 1. 确认偏误（Confirmation Bias）
- **本项目典型表现**：只看支持自己观点的证据，忽略反面证据 —— 例如只引用通过 replay 的卡，
  不检视 refute/`infra_error` 的历史记录。491 §一原表：「错误的 claim 被签署」。
- **自问**：我有没有只看支持自己观点的证据？**反面证据是什么**（具体到文件/命令/数字）？

### 2. 锚定效应（Anchoring）
- **本项目典型表现**：第一个数字/结论影响后续判断 —— 真实事故 **ALLOC-002**：夹具先输出
  「pool 元数据 32 B」，该数字锚定了后续全部口径判断，导致方向反转（口径实为"随规模变"）。
- **自问**：第一个数字/结论是不是影响了我的判断？**如果换个起点**（先看理论/先看反例）会怎样？

### 3. 沉没成本（Sunk Cost）
- **本项目典型表现**：已经花了很多时间，不愿意推翻重来 —— 卡膨胀了还继续加字段，不重构；
  批次做了一半发现问题却硬做完。491 §一原表：「卡膨胀了还继续加，不重构」。
- **自问**：继续下去是因为它正确，还是因为**不想浪费已投入**？如果从零开始会选这个方案吗？

### 4. 后见之明（Hindsight Bias）
- **本项目典型表现**：「我早就知道会这样」—— 红队发现的问题被低估为"显然"，
  从而**不记录**、不沉淀成规则（下一轮又会踩）。491 §一原表：「红队发现的问题被低估」。
- **自问**：这个结果是真的**事前**可预测的（有留痕证据），还是事后诸葛亮？

### 5. 过度自信（Overconfidence）
- **本项目典型表现**：觉得自己的架构设计很完善 —— 实证：**483 才发现六个盲区**；
  470 声称"闭合 7 个阻断级"，v5 严格口径实测只闭 3 个。
- **自问**：我有多确定（给个概率）？**如果错了代价是什么**？有没有独立的反方结论？

### 6. 权威偏误（Authority Bias）
- **本项目典型表现**：Agent/红队说的就信，不验证原文 —— 实证：371 红队误判 IFNDR 条款，
  若照单全收会写进卡的 claim。反向同样成立：**低位方的正确发现被忽略**（491 §三异议机制）。
- **自问**：Agent/红队/文档说的就一定对吗？**有没有核对原文/实测**（引用是否带行号与命令）？

### 7. 替代方案（Alternatives）
- **本项目典型表现**：只评估一个方案就动手 —— 例如直接把某规则升 block，未评估
  "先 warn 观察一期"这条替代路径；或修 bug 时只做最小补丁而不看根因修法。
  491 §七原清单：「除了这个方案，还有至少 2 个替代方案吗？」
- **自问**：**除了这个方案，还有至少 2 个替代方案吗**？各自代价与可逆性如何？

### 8. 最坏情况（Worst Case）
- **本项目典型表现**：只看顺利路径 —— 例如改门禁级别未先量存量误伤面（"预计 0 实测 6"已多次发生）；
  改原子/工件未评估"进程被杀时是否丢数据"（N4 工件被清空的真实事故）。
- **自问**：**如果这个决策错了，最坏后果是什么？能恢复吗**（回退方式是哪一行/哪条命令）？

## 与既有机制的接口（避免重复劳动）

| 机制 | 关系 |
|---|---|
| 决策日志（491） | 每次人审签署/架构决策填本清单 + 结论，落盘可回溯 |
| 预注册（491） | 「后见之明」的机器化对冲：预测先落盘再实验（371 预言冻结已有先例） |
| 异议机制（491） | 「权威偏误」的结构化对冲：低位方可正式提异议 |
| `verified_reason`（494 任务 5 / `ATOM-VERIFY-REASON`） | 「确认偏误/权威偏误」在**签署环节**的落点：签署必须写理由，不能只签名 |
| 对抗测试（368/373/402/452/470/480） | 外部审计：独立模型族 + 只读仓 + 探针留痕（491 §6.4） |

## 快速版（3 问，时间不够时用）

1. **反面证据**是什么？（对确认偏误）
2. 我在**不确定**的地方是不是用了肯定语气？（对过度自信/权威偏误）
3. 错了怎么**回退**？（对最坏情况/沉没成本）
