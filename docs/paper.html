论文

《演化中的验证器：失败驱动的 C++ 缺陷检测器组合演化》 （Evolving Verifiers: Failure-Driven Portfolio Evolution for C++ Defect Detection）。 目标会议：NeurIPS 2027 Evaluations & Datasets（双盲投稿准备中）。

摘要（机器摘要，非投稿全文）

静态与动态检测器各自的"盲区"已被反复观察，但少有人把验证器组合的选择本身 形式化为一个可在线演化的对象。阙疑提出：四态判决（pass/fail/unknown/contradict）+ append-only 账本 + Merkle 完整性 + 失败驱动演化算子 E。 E 在派生集（不含评估集信息）上以四分量（failure / novel / cost / redundancy） 迭代选择下一批检测器；在一套 1,147 样本 × 8 资产的全量判定矩阵上， E 的选择在评估集上相对预注册随机单点预算取得 +24.03pp（McNemar p ≈ 2e-41）， 且对 split、种子（5,000 次）与资产子集（255 个子集全枚举 + 精确 Shapley）稳健。 683 批次新增：110 条真实缺陷重构靶场（全部经 NVD API 在线验证 / 出处可追溯）、 跨工具链（clang 18 vs g++ 13.3）一致性与 operator 四分量全枚举消融。

贡献（贡献边界按 Claim Boundary 严格限定）

  1. 问题形式化：把"用哪些检测器"定义为在失败集上迭代的确定性算子 E； novelty 分量的字面定义与 failure 分量数学等价——此坍缩被如实证明并公开， 并给出让 novelty 成为独立信号的修复变体（unique 模式，683 消融验证）。
  2. 真实性极强的证据链：1,147 合成样本 × 8 资产全量实测矩阵（真实编译/运行为， 非重放）；判定口径（双档 -O0/-O2、TSan 退出码 66、检测器不可用 ⇒ unknown）全部冻结可复现。
  3. 真实靶场基准（683 新增）：110 条真实缺陷（≥15 项目、≥10 类型）， 每条带 CVE/issue/commit 出处、NVD 在线验证记录与最小重构 PoC 落盘。
  4. 诚实的失败解剖：≥30 条 miss 深度归因（检测器能力盲区 / 配置缺口 / 样本复杂度 / 不可复现），≥20 条超预期 catch 案例。
  5. 可审计性：append-only 账本 + Merkle 根 + 工具完整性 fail-closed 门禁； 论文每个数字可被脚本复算（verify_paper_numbers）。
