## 协议

打破"自己出题考自己"：验证器完全不知道错误是怎么生成的。

- **Agent A（生成）**：从知识断言库生成一批 C++ 知识断言（如"某 UB 在某优化级下未定义"）。
- **Agent B（反例/变异）**：对 A 的断言生成反例或变异（如构造看似合法但语义错的表述）。
- **Agent C（adversarial）**：专门找验证器的漏洞——尝试让验证器对错误断言判"通过"。

三者的生成过程对**验证器（gate）完全不可见**。验收时把 C 找到的"验证器漏掉的"作为 miss 计入。

- 各来源错误集合（A/B/C 各自产出的缺陷 id 清单）
- 交集与差异：A∩B、A∩C、B∩C、以及验证器 catch/miss 的归因
- 谁生成的、验证器是否知情（必须不知情）
