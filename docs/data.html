真实靶场的可追溯性（683）

  • NVD API 在线验证：109 个唯一 CVE 全部经 services.nvd.nist.gov/rest/json/cves/2.0 在线查询确认， 应答原文（描述 / CVSS / 发布时间 / references）冻结在 data/683_real_world_candidates_verified.json。
  • 修复链接：NVD references 中提取到 51 条真实 fix commit 链接、18 条 issue 链接、 16 条 PR 链接（逐条落在 benchmark JSON 的 refs_commit/refs_issue/refs_pr 字段）。
  • PoC 落盘：每条缺陷一个最小重构 data/real_world/RW-xxx.cpp （单文件，<200 行；头部注释内嵌元数据 = 单一事实源）。

PoC 是基于公开披露信息的最小重构（source-derived），不是原始项目代码， 也不含武器化利用链；目的是测"检测器在真实缺陷类别上的能力"，不是提供利用。
