## 2. 关键发现

### F1（全局）· 8 个页面**全部没有 `noscript` 降级**
JS 加载失败（离线 / CDN 断 / 脚本 404）时，页面将**白屏**——没有任何纯文字兜底。
**建议**：每个 `.html` 的 `<body>` 首个元素加
`<noscript><div class="fallback">本页需要 JavaScript。请启用后重试，或访问纯文本索引。</div></noscript>`。

### F2 · index / learn / starmap 缺 **loading**
- `index`：首屏数据未到时会空白（无 skeleton）。
- `learn` / `starmap`：图谱/学习页数据量大（starmap.js 69KB），加载期间无占位。
**建议**：统一用 `qy-panel` 组件渲染 skeleton 骨架（复用现有 `web/components/qy-panel.js`）。

### F3 · index / verify / card 缺 **empty**
筛选/查询无结果时无"无匹配项 + 清除筛选"提示。
**建议**：抽出公共 `renderEmpty(container, {onClear})`，4 处复用。

### F4 · verdicts / verify 的 error 态偏弱
`verdicts` 仅 js 1 处、`verify` 仅 1 处 error 处理；JSON 加载失败时可能静默空白。
**建议**：统一 `fetchJSON()` 包装——`catch` 里渲染错误卡片 + 重试按钮。

### F5 · index 三态全缺，优先级最高
`index` 是入口页，error/empty/offline 全无 ⇒ 任何异常都是白屏。**建议列为 P0**。
