# 单人 DSMB（E1，数据安全监查委员会的单人替代）

> 跨学科来源：临床医学。配合 序贯检验.md（D2）使用；本文件**只登记不新增代码门禁**（停止规则用 e-process 阈值实现）。

## 问题

临床试验有 DSMB：独立委员会看期中数据，决定**提前停止**（有效/有害/无效）而不膨胀一类错误。
单人项目没有委员会。替代不是"自己想看就看"，而是把 DSMB 的**规则预先写死**：

| DSMB 要素 | 单人替代 |
|---|---|
| 预先定义停止规则 | 在 PAP（PAP预注册.md）写死：e-value 阈值 1/α、**最多分析次数/时间点**、最大样本量（防无限扩样） |
| 期中分析登记 | 每次期中看数追加进 `data/671g/eprocess_ledger.jsonl`（append-only，哈希链 D6） |
| 独立监查 | 停止决策与日期入 git 留痕；无合作者时由"规则机器执行"替代（e-process 不依赖人忍住不偷看） |
| 报告 | 每次期中分析写一行结论（看了什么、e 值、是否停、为什么） |

## 单人停止规则（建议写进 PAP）

1. **有效早停**：sup e_t ≥ 1/α（α=0.05 ⇒ 20），且最少样本量（如 n≥20）已满足，才允许下有效结论；
2. **无效/无望早停**：预设最大样本量，达到后 e 值仍远低于阈值即停（省算力，不无限扩样）；
3. **任意期中分析**：e-process 允许任意次数 peek 不需 α 校正（这是换框架的全部意义），但**每次都登记**；
4. μ0、α、最大样本量**事先**钉死，事后改参数等同破盲（PAP 缺口）。
