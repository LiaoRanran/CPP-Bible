# 序贯检验（e-process / e-value）（D2）

> 工具 `tools/eprocess_671g.py`；红路径与一类错误仿真 `tests/test_d2_eprocess_671g.py`；
> 账本 `data/671g/eprocess_ledger.jsonl`（本批追加产物，不碰冻结的 452 账本）。
> **影响论文统计方法：只登记，不擅改论文。**

## 为什么

固定样本量检验不能边收数据边看：每 peek 一次都要 α-spending 校正，否则一类错误膨胀。
e-process 换框架后**天然支持任意时刻、任意次数的期中分析**。

## 定义

* H0：每个样本 Bernoulli(μ0)，μ0 事先钉死（如盲测检出率）；
* 复合备择：对 μ1 网格（默认 (0,1) 等距 0.05，剔除 μ0）做先验权重混合；
* 逐样本对数似然比 `log L = x·log(μ1/μ0)+(1−x)·log((1−μ1)/(1−μ0))`；
* 累积 e-value = 混合下的累积似然比乘积，空序列恒为 1；
* H0 下它是 e-process（非负上鞅，期望恒 1），Ville 不等式：
  **任意时刻 sup e_t ≥ 1/α 的概率 ≤ α**（α=0.05 ⇒ 阈值 20）——无需多重比较校正。

## 本仓仿真证据

`python tools/eprocess_671g.py --sim-type1 --n 100 --reps 2000 --mu0 0.5`
实测 H0 一类错误约 2.7% ≤ 5%（复合混合网格偏保守，含 Monte Carlo 噪声）；
H1 真率 0.8 时 200 样本内越过阈值，具备检出力。

## 用法

```bash
python tools/eprocess_671g.py --mu0 0.5 --seq 1 0 1 1 0
python tools/eprocess_671g.py --ledger data/671g/eprocess_ledger.jsonl --mu0 0.5 --x 1
```

账本 append-only，每个新判决追加一行 `{x, mu0, e_value_after, stop}`；哈希链由 D6 守。

## 边界（诚实）

* 这是**序贯证据框架**，不是要替换论文已冻结的固定样本 CP 区间——论文用哪个由论文批次定；
* μ0 必须事先钉死，事后改 μ0 等价于偷看（PAP 里登记，见 PAP预注册.md）；
* Ville 界对**复合混合**成立；若改成单一事后选 μ1 则界失效（那是另一个检验）。
