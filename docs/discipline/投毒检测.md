# 小样本投毒检测（D9，canary + 配对探针）

> 门禁：`G-POISON-DETECT`（L0）；工具 `tools/poison_detection_671g.py`；
> 配置 `data/671g/poison_canaries.json`；判决从 671a reveal 明细**只读**取；
> 测试 `tests/test_d9_poison_671g.py`。

## 两道独立探针

1. **Canary（金丝雀）**：数据集中预先埋入真值已知、判决稳定的样本（本批从 reveal 明细里 3 轮复现、
   机制明确的稳定样本选 canary，**不新增/不改原始样本**）。canary 被错判 ⇒ block。
   当前 5 条：h21（ubsan 溢出 catch）、h24（ubsan 除零 catch）、h26（asan UAF catch）、
   h32（asan double-free catch，非盲但 3 轮稳定）、h33（ubsan strict-alias miss，反向 canary）。
2. **配对反事实探针**：一对只有微小差异、按机制应当**同判**的样本，判决不一致 ⇒ block。
   当前 3 对：h22/h23（asan SEGV）、h27/h32（asan double-free）、h25/h30（asan 内存类 catch）。

## 为什么能抓投毒

小样本（holdout 40 / corpus 60）下，换掉/污染几个已知样本就能显著改率。Canary 是攻击者**不知道、也绕不开**
的固定真值点；配对探针判据不稳定即被污染——两道互补（一个盯真值翻转，一个盯机制不一致）。

## 边界

* 只从 `data/holdout/reveal_3_detail_671a.json` 读判决，**不碰 data/holdout/ 原始样本**（671a 红线）；
* canary 检测器漂移只 warn（如历史 reveal 用的检测器名变化），verdict 翻转才 block；
* 明细缺失 ⇒ unarmed（warn），不静默放行也不假装已检测。

## 用法

```bash
python tools/poison_detection_671g.py --check     # 当前 pass：5 canary 全对、3 对全一致
```
