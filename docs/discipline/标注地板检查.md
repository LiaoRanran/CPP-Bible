# 标注地板检查（D10，floor-check）

> 门禁：`G-TRAJECTORY-FLOOR`（L0；无标注批次时 unarmed，只 warn）；
> 工具 `tools/trajectory_floor_check_671g.py`；批次目录 `data/671g/labels/`；
> 测试 `tests/test_d10_floor_check_671g.py`。

## 规则

每个标注批次（人工/LLM 预标注）：

1. **随机抽 ≥10 条**（带 seed，可复现；批次不足 10 条全抽）；
2. 抽中的条由**独立复核**给真值（复核真值不来自标注者自己）；
3. 复核错误率 **>20% ⇒ 整批全部重标**（block；不许只挑错的那几条重标——错率说明整批不可信）；
4. 无复核记录 / 样本不足 ⇒ inconclusive（warn，不许当合格批次用）。

## 教训

8B 评委 400 条标错 397 条：低质量标注系统性毁掉训练/评估/论文。floor-check 与单人 IRR 替代
（单人IRR替代.md）互补：κ 守跨时间自洽，floor 守**绝对正确率地板**。

## 批次格式

`data/671g/labels/<batch>.json`：
`{batch_id, labels:[{id,label}], review:{seed, reviewed:[{id,label,truth,error}]}}`。

## 用法

```bash
python tools/trajectory_floor_check_671g.py --n 50 --seed 20261001   # 打印应抽的下标
python tools/trajectory_floor_check_671g.py --check
```

当前无标注批次 ⇒ unarmed warn；出现 LLM/人工标注批次时门禁自动 armed。
