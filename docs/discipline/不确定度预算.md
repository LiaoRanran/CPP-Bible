# 不确定度预算（E5，GUM 思路）

> 工具 `tools/uncertainty_budget_671g.py`；测试 `tests/test_e_671g.py`。

## 为什么

报检出率，不确定度不只是"样本量"。小样本 + 强检测器依赖 + 同源判据时，把点估计当精确值是系统性误导。
按计量学 GUM（《测量不确定度表示指南》）把不确定度拆成三个分量，方和根合成：

| 分量 | 来源 | 估计 |
|---|---|---|
| u_stat | 统计（抽样） | CP95 半宽 /1.96 |
| u_detector | 系统：检测器/仪器依赖 | FD vs 静态口径率差（pp）/2（上界） |
| u_environment | 系统：环境依赖 | unknown 样本占比（换台没检测器直接掉的比例，pp） |
| u_label | 标注 | κ 折算（κ=1→0，κ=0→50pp 上界），或重标分歧率/2 |
| u_sys | 系统合成 | sqrt(u_detector² + u_environment²) |
| **u_c** | **总合成** | **sqrt(u_stat² + u_sys² + u_label²)**（独立假设） |

## 用法

```bash
# holdout 盲测：87.5%(14/16) CP[61.65,98.45]，FD-静态差 81.3pp，1/30 unknown
python tools/uncertainty_budget_671g.py --k 14 --n 16 --cp-low 61.65 --cp-high 98.45 \
  --detector-gap 81.3 --unknown-frac 0.033 --kappa 1.0
```

## 读法（诚实）

* 合成扩展区间 ≈ 点估计 ±2u_c（近似 95%，**预算/上界**，不是精确 CI）；
* holdout 盲测的 u_c 主要由统计宽区间（小 n）+ 检测器依赖（81.3pp 口径差）贡献——
  这把"87.5% 很硬"显式变成"87.5% 带很大仪器依赖 + 小样本不确定"；
* 分量相关时（检测器与环境强相关）方和根**偏乐观**，此时必须声明并给相加的保守上界。
