# 单人隔周重标法（D7，零合作者 IRR 替代）

> 工具 `tools/retest_reliability_671g.py`；测试 `tests/test_d7_retest_671g.py`。

## 问题

标准 IRR 要两个以上标注者，单人项目没有合作者。替代：**同一标注者隔 ≥7 天、盲重标**同一批样本
（不看上轮标注），算 test-retest 的 Cohen κ：

* κ ≥ 0.8：标注稳定（pass）——只证明自洽，**不证明标对**；
* 0.6 ≤ κ < 0.8：warn，不一致项必须人审；
* κ < 0.6：block；样本 < 10：inconclusive（不许发布可靠性结论）；
* 间隔 < 7 天：rejected（测的是记忆不是稳定性）。

## 用法

```bash
python tools/retest_reliability_671g.py --round1 a,b,a,b --round2 a,b,b,b --ids 1,2,3,4 --gap-days 10
```

κ=1（完全一致）、κ=0（边际均匀下完全不一致）、经典例 po=.8 pe=.5 ⇒ κ=.6 都有锁定测试。

## 边界

* 这是**自洽性**地板，与 D10 floor-check（地板复核，防 8B 评委 400 错 397）互补，不互相替代；
* 重标必须盲（清缓存/不看第一轮）+ 隔周；否则测的是短期记忆；
* 当前 67 条规则/标注批次的 κ 历史数据：本批无新增人工标注批次，登记为"待有重标批次时启用"，不编造 κ 值。
