# 证据保管链 / 毒树之果（E4）

> 门禁：`G-EVIDENCE-CHAIN`（L0）；工具 `tools/evidence_chain_671g.py`；
> 登记 `data/671g/evidence_chain.json`；测试 `tests/test_e_671g.py`。

## 规则

每个**派生产物**登记：

* `parents`：直接来源文件列表 + 登记时的 sha256；
* `self_sha256`：产物自身哈希；
* 校验：来源必须存在、来源当前哈希必须等于登记哈希（来源改了产物没重跑 ⇒ 断链 block；产物改了没刷新链 ⇒ warn）；
* **毒树传播**：任一 parent（递归向上）被标 `poisoned` ⇒ 该产物 = **poisoned_fruit（毒树之果）**，
  不得用于结论。

## 本批登记的链

| 产物 | 直接来源 |
|---|---|
| data/671g_verified_numbers.json | 671a/665/656 等 reveal 与实验产物 |
| data/671g_per_sample_audit.json | holdout/corpus reveal 明细 + 变异/反事实产物 |
| data/env_671g.json | 机器实测（无文件 parent） |

复现命令：

```bash
python tools/evidence_chain_671g.py --add data/x.json --parent data/y.json
python tools/evidence_chain_671g.py --mark-poison data/contaminated.json
python tools/evidence_chain_671g.py --check
```

## 边界

* poison 标记只登记来源 id（悬空也 warn 显形），**不删除**任何文件；
* 哈希变了不自动判毒（正常迭代），只 warn 要求重跑；只有"来源在 poisoned 链上"才 block；
* 与 670c Merkle 目录根互补：Merkle 管受控目录快照，本工具管**分析产物的血缘**。
