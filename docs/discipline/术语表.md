# 术语表（671g B2 冻结）

> 本表是全仓工程文档（tools/ tests/ docs/discipline/ data 报告）的**规范术语**唯一事实源。
> 门禁：`G-TERMINOLOGY`（`tools/terminology_scan_671g.py --check`，红路径测试
> `tests/test_terminology_671g.py`）。本表自身、扫描器与其测试**自我排除**（它们需要引用废弃词才能定义它）。

## 1. 数据集 / 检测

| 规范术语 | 英文/代码名 | 废弃写法 | 含义与口径 |
|---|---|---|---|
| 检测器 | detector（asan/ubsan/tsan/compiler-warn/cross-compile/linker/wunsequenced…） | ~~探测器~~（缺陷检测语境） | 用来发现缺陷的仪器。**例外**：论证学里的"探测器"（argument probe，见 `tools/argument_audit.py` 的五个基础探测器）是**另一个词**，合法保留 |
| 判决 | verdict（catch/miss/unknown/not_error） | ~~判定~~（作名词指 verdict 时） | 对单个样本的四态结论。注意"判定"作普通动词仍可用 |
| 盲测集 / holdout | holdout（h1–h40） | ~~留出集~~、~~盲集~~（不推荐） | reveal 后才知真值的检测集。h1–h30 为盲测冻结；h31–h40 为 reveal 后并入，**非盲** |
| 外部语料 / corpus | external corpus（d3-* / d3e-*） | ~~外部库~~（不推荐） | 外部来源 C++ 样本集。d3-01–40 盲测；d3e-* 非盲 |
| catch / miss / unknown / not_error | 同 | — | 命中 / 漏报 / 本机无检测器（不进分母）/ 测量类本就非缺陷（不进分母） |
| 可测分母 | catch+miss | — | 主口径：`catch/(catch+miss)` |

## 3. 统计 / 门禁

| 规范术语 | 含义 |
|---|---|
| 口径（caliber） | 率的分母定义（可测 / 全样本 / 排除 unknown）。报率必须同时报口径 |
| 盲测冻结值 vs 累计值 | 盲测样本的率（支撑外部效度 claim）vs 盲测+非盲扩样合并的率（只描述样本构成）；两者并列，不得互相替换 |
| CP95 | Clopper–Pearson 95% 精确置信区间（单一实现 `tools/stat_bounds.py::cp_interval`） |
| e-value / e-process | 序贯检验的累积下注证据（见 docs/discipline/序贯检验.md） |
| PAP | Pre-Analysis Plan，预分析计划（见 docs/discipline/PAP预注册.md） |
| 规则钉扎 | 判决产物必须带 rules_version + rules_sha256（见 docs/discipline/规则版本钉扎.md） |
| 红路径测试 | 故意制造门禁声称能抓的问题，验证它真的变红；修复后变绿 |
