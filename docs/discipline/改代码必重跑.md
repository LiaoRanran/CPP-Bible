# 纪律：改了验证代码，必须重跑落盘（否则门禁红）

> 批次来源：667（发现）→ 668（修 + 立规）。
> 一句话：**改了"怎么测"就一定要重跑"测出来的数"；不重跑，产物里还是旧口径的数，
> 而任何引用它的文档都会变成假话。**

---

## 1. 这条纪律在防什么（两次真实的翻车，同一个失败模式）

| # | 批次 | 声称 | 产物里实际是 | 怎么发现的 |
|---|---|---|---|---|
| 1 | 666 A5 | holdout 检出率 **81.2%（13/16）**，口径"双档 -O0/-O2" | **66.7%（10/15）**，产物自述 **-O1 单档** | 667 阶段0 现算，`--check` 却报绿（它不比对这两个字段） |
| 2 | 666 A4 | 反事实 **F1=1.0（20 条）** | **F1=0.0（10 条）**，且 660 的另 10 条**没有真值标签** | 同上 |

两次都不是"能力变化"，而是**改了判定/口径的代码之后没有重跑生成器**：

* 666 把 `holdout_reveal_661.detect` 改成双档 → **没重跑** `holdout_reveal_3_665.py`；
* 666 把第三判据 `_MACHINE_MARKERS` 加进 `counterfactual_citation_658.py` → **没重跑** `counterfactual_extend_665.py`。

产物没变 ⇒ 报告和论文里的数字**没有来源**。668 重跑后的真实值是
**87.5%（14/16）**与 **F1=1.0（分母 10，且是上界）** —— 与当时的声称**都不同**。

## 2. 规矩（改口径三步，缺一步就不许引用）

> R6。任何改动"判定逻辑 / 档位 / 分母 / 阈值 / 关键字"的提交，必须**在同一次提交里**做完三件事：

1. **重跑**：用生成器重新产出受影响的产物（`data/*.json`、`web/data/*.json`、报告 md）。
2. **作废旧值**：在产物与文档里写明旧值是什么、为什么作废（**不许静默替换**）。
3. **纳入 `--check`**：把新数字加进工具的漂移比对范围，并做一次
   **射程自检**（"故意改一个数 ⇒ 必须变红"）。少这一步，`--check` 就是假绿。

**判据**：一条命令能证明"落盘 == 现算"。做不到 ⇒ 该数字只能标 ❌，不得进论文。

## 3. 什么算"验证代码"（触发本纪律的改动清单）

| 类别 | 例子 |
|---|---|
| 检测器 / 判定器 | `holdout_reveal_661.detect`、`counterfactual_citation_658.counterfactual`、`gate_engine.RULES` |
| 编译档 / 运行参数 | `OPT_LEVELS`（`-O0/-O2`）、超时、`setarch -R` |
| 分母与排除规则 | `unknown` / `not_error` 是否计入分母 |
| 样本集合 | 新增/删除样本、样本标签（`planted`/`ground_truth`） |
| 复算路径 | 判据的关键字表、token 重叠阈值 |

改动以上任一 ⇒ 所有**由它产出的数字**全部作废，直到重跑。

## 5. 什么时候可以**不**重跑

只有一种：**产物里已经声明了旧口径，且引用处明确写着"旧值作废、不可引用"**。
例如 `data/holdout_reveal_3_665.json::opt_sensitivity` 保留的 `-O0/-O1` 对照，
它在产物里被标为"历史对照，保留作证据" —— 这类**标注过的历史值**允许存在。

反之，"文档里写新口径、产物里是新口径、但没人重跑"**永远不允许**。
