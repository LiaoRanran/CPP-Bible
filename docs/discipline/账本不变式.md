# 账本 10 条不变式（D6）

> 门禁：`G-LEDGER-INVARIANTS`（L0）；工具 `tools/ledger_invariants_671g.py`；
> 账本 `data/671g/ledger_671g.jsonl`（append-only）；PBT `tests/test_d6_ledger_pbt_671g.py`（hypothesis）。
> **不碰**冻结的 452 账本（`data/authority/decision_event_v2_ledger.jsonl`）。

## 10 条不变式

| INV | 内容 | 红路径 |
|---|---|---|
| INV-01 | schema=queyi-ledger/671g | 改 schema |
| INV-02 | 必填 seq_idx/ts/kind/payload/prev_hash/hash/rules_version | 删字段 |
| INV-03 | seq_idx 严格 0..n−1，不重复不跳号 | 改序号 |
| INV-04 | ts 非递减 | 回改时间 |
| INV-05 | r[n].prev_hash == r[n−1].hash（链连接） | 改 prev_hash |
| INV-06 | hash=sha256(prev_hash+规范化记录)，**改任一字段断链** | 改 payload 不重算 |
| INV-07 | 只暴露 `append_record` 写入口，无改/删历史 API | API 面审计 |
| INV-08 | kind=verdict 时 verdict ∈ catch/miss/unknown/not_error | 写 "maybe" |
| INV-09 | payload.cards_total 只许不减（单调性） | 卡数回退 |
| INV-10 | 每条 rules_version 必须等于现行 manifest（D1 联动） | 规则变了旧账本 |

## 机制

* 哈希链：`hash_i = sha256(prev_hash_i + canonical(record_i 去掉 hash))`，genesis 为 `GENESIS`；
* 唯一写入口 `append_record` 自动接链（INV-07 追加性由 API 缺失 + INV-05/06 共同保证）；
* PBT：hypothesis 随机生成合法链恒通过；任意单点篡改（非法 verdict/链/时间/版本/序号）必被抓；
* 参考值（671f v32/63）：656 变异测试曾杀 15.3% 变异体——PBT 用随机生成守住"改账本"这一类。
