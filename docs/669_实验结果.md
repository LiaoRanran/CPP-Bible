## 2. E2 口径消融（caliber ablation）

**问题**：审稿人一定会问"你的分母怎么来的"。三条臂共用**同一份原始计数**，只变口径：

| 臂 | holdout 真错 | external |
|---|---|---|
| A（主口径：unknown 剔除） | **87.5%**（14/16） | **43.8%**（14/32） |
| B（保守：unknown 记 miss） | 82.4%（14/17） | 37.8%（14/37） |
| C（最保守：unknown + not_error 都进分母） | 82.4%（14/17） | 35.0%（14/40） |
| Δ（A − B） | **+5.1pp** | **+6.0pp** |
| Δ（A − C） | +5.1pp | **+8.8pp** |

**读法**：口径选择对 external 的影响（最多 8.8pp）**大于**层间的部分差异（例如 B 层 12.5% 的 CI 上界 52.7%）
——所以"报率不报口径"等于让读者在 35.0%–43.8% 之间自由发挥。本批把两个口径**同时**写进
产物（`denominator` + `rate_pct_all_samples`）与论文（§4 表 + 文首口径说明）。

## 3. 没做的实验（**登记，不编数字**）

| 基线 | 为什么没做 | 需要什么接口 |
|---|---|---|
| B1 `Rule-only`（静态门禁在 holdout/corpus 上的检出率） | 主仓 holdout/corpus 判定走**外部 sanitizer 仪器**（`holdout_reveal_661.detect` / `external_corpus_662.detect` 都是"WSL g++ 编译并运行"）；主仓**没有**"仅静态规则"的可执行路径 | 拆仓验证器暴露 `detect_static(sample) -> verdict` |
| B2 `Full-non-failure` / B3 `budget-matched random` | 资产选择接口在拆仓验证器 `queyi-verifier` 里（主仓不可见）；没有接口就没有对照 | 拆仓暴露 `select_assets(pool, n, strategy, seed) -> [asset]`；随机臂必须带种子与分配表 |

**红线**：不为了"有 baseline 可写"而用主仓里某个近似物**冒充** B3 —— 那会把"没做对照"伪装成"做了对照"。

## 4. 与 668 的关系

668 修掉了两个"改了代码没重跑"的假数字（holdout 87.5%、反事实分母 10）。本批（669 P3）
