让验证器在失败中演化

阙疑（Queyi）是一个四态判决（pass / fail / unknown / contradict）+ append-only 账本 + Merkle 完整性 + failure-driven evolution 的 C++ 缺陷检测框架。 本站在 683 批次更新：新增 真实靶场基准（可追溯 CVE/issue 重构）、跨工具链验证、 operator 全枚举消融与开源发布材料。

它解决什么问题

不是"再训一个模型"

阙疑把"用哪些检测器（8 个真实资产）"本身当作可演化的对象： 上一轮的失败样本驱动下一轮资产组合（operator E：failure / novel / cost / redundancy 四分量）。

四态判决，不留"猜"

catch / miss / unknown / contradict 严格区分：检测器不可用时是 unknown（不进伪造的 miss），双实现冲突时是 contradict。

可审计的账本

append-only 账本 + Merkle 根 + 每次判定的原始输出留存； 本仓库所有数字可由脚本逐条复算。

真实靶场，不只是合成样本

683 新增 真实靶场基准： 每条缺陷带 CVE/NVD 在线验证记录、修复 commit 链接与最小可复现 PoC。
