# 5 分钟演示脚本（在线演示 / 答辩 / 面试）

> 场景：`python -m http.server 8000 --directory web`，浏览器打开 `http://localhost:8000/index.html`。
> 按下面顺序点，每步说一句"做什么 + 展示什么"。**总时长约 5 分钟**（含 30s 缓冲）。
> 每节都标了「关键数字」和「交互点」，照着点即可。

---

## 0. 开场（30s）
- **点**：首页 `index.html`（导航「总览」）。
- **说**："这是一个可被独立验收的 C++ 知识验证器——每条结论都绑定证据和复现步骤，你可以亲手验证，而不是先信我。"
- **关键数字**：**42 实卡**（台账 52 张 − 草稿 10）/ **67 门禁规则** / **452 权威账本事件（零改）** / **holdout 检出 87.5%（14/16）** / **变异杀死率 97.35%（110/113）** / **31 条判决** / **178 节点·1093 边**。
- **展示**：首屏一句定位 + 核心指标条 + 接地网络示意。

## 1. 卡库：证据绑定长什么样（60s）
- **点**：导航「卡库」。
- **说**："每张卡不只有结论，还标了四态、证据 id、先修。"
- **交互点**（按顺序，每个 10–15s）：
  1. **搜索**：输入 `RAII`（或选「域 = MEM」）→ 展示全文搜索（断言/证据/标签，多词 AND）。
  2. **高级筛选**：四态 × 证据强度 × domain × cpp_standard（维度内 OR、维度间 AND）。
  3. **批量对比**：勾选 **2–3 张**卡 → 并排对比 9 行（断言/四态/证据/边界/标准/先修…），差异行标 `≠`。**勾第 4 张会被拒绝** —— 说明规则是真的。
  4. **证据链**：点某张卡的详情 → 树状图 `卡 → 证据 id → 证据文件 → sanitizer 输出`；缺字段显示"未记录/未入库"，**不编造**。
  5. **关系图**：滚到关系图 → 点一个节点 → 高亮其前置依赖并联动证据链。
- **关键数字**：实卡 42；证据索引 63 条；先修边 2 条、相关边 158（默认关）。

## 2. 学习台：怎么帮人记住（60s）
- **点**：导航「学习」。
- **说**："基于学习科学三件事：**间隔重复（SM-2）+ 主动回忆 + 错例驱动**。"
- **交互点**：
  1. **学习路径**：顶部三阶段 SVG 流程图（前置关系 → 断言/四态/证据 → 自测），当前阶段高亮，"已学几张/共几张"实时变。
  2. **快捷键**：按 <kbd>空格</kbd> 揭晓答案 → 按 <kbd>3</kbd> 评分"良好" → <kbd>→</kbd> 下一张。（<kbd>1</kbd>–<kbd>4</kbd> = 忘记/困难/良好/完美；焦点在搜索框时快捷键不抢键。）
  3. **错例牌组**：切牌组到「错例牌组」→ 展示五段式：**错误断言 → 反例代码 → sanitizer 输出 → 正确断言 → 自测**。指出页面显式标了"机器生成 · 未签"，且写明"正确断言"是**由反例文字派生**的（来源字段可查）—— 机器卡没有"正确断言"字段，我们不假装它有。
  4. **SM-2 可视化**：滚动到「掌握度曲线与薄弱点」→ 曲线是按历史事件**重放 SM-2 状态**得到的；右边热力图按域聚合，红框 = 有失败记录。
  5. **统计/持久化**：仪表盘展示 已学/掌握/薄弱/待复习/未学/**连续天数**；点「导出进度」下载 JSON（进度只在 localStorage，不出本机）。
- **关键数字**：错例牌组 **16 张**（全部带反例源码，14 张有 sanitizer 输出）；前端 **599 条断言**全绿。

## 3. 实验结果：数字怎么现算（45s）
- **点**：导航「实验结果」。
- **说**："所有图表都是**真数据现算**，页面加载时 fetch 台账，不写死。"
- **交互点**：
  1. **点任一根柱子** → 明细面板出现 `k / n = 5 / 16`、**Wilson 置信区间 14.2%–55.6%**、以及逐样本列表。
  2. **切数据集**（全部 / holdout / corpus / defect）与**切口径**（三臂）→ 柱数实时变。
  3. **指两张显示"待670a生成"的图**：baseline 对比与口径消融 —— **数据还没落盘，我们标待生成而不编数字**。
- **关键数字**：5 张图（检出率对比带 CI 误差线 / 口径消融 / 演化曲线 / 检测器构成饼图 / 能力构成雷达）；Wilson 与 `tools/stat_bounds.py` **逐值对齐**。

## 4. 判决页：诚实的口径（40s）
- **点**：导航「判决与数字」。
- **说**："注意 unknown **不降级**为 fail。"
- **交互点**：
  1. **时间线**：31 条判决（`data-state` 着色）；指出**落盘顺序 ≠ 时间顺序**（落盘按 seq，夹具其实更早）——表格看不出来，时间线看得出来。
  2. **四态分布变化**：切 按日期 / 按来源 / 5 条窗口 三种分桶。
  3. **漂移条**：中点为零、正右负左，逐条写"哪个指标漂移了多少"。
  4. **对比表**：32 个指标「声明值 vs 现算值 vs 差异」，超容差标红；点「只看不一致」过滤。
- **关键数字**：31 条 = 16 机器卡 + 15 缺陷夹具；四态 **pass 12 / pass_with_exception 0 / fail 0 / unknown 19**；四态切换 7 次。

## 5. 星图：知识怎么接地（30s）
- **点**：导航「星图」。
- **交互点**：
  1. 滚轮缩放 / 拖拽平移（**Canvas 渲染**，不是 SVG）。
  2. **悬停聚类标签** → 显示该 domain 的卡·命题·误解数与平均证据强度。
  3. **搜索框输入 `ATOM-MEM`** → 高亮压暗，回车依次居中定位。
  4. 指出边的**粗细 = 关系强度**。
- **关键数字**：**178 节点 / 1093 边**；**7 个 domain 聚类**（mem 115 / lang 19 / conc 14 / ub 14 / hist 9 / emb 4 / cpp 3）；布局只在加载时算一次（60–130ms），防重叠把最近点对从 1.56px 提到 **15.97px**。

## 6. 验哈希：离线可复核（20s）
- **点**：导航「验哈希」→ 拖入一个 `web/data/` 下的 JSON（或演示批量）。
- **说**："浏览器用 Web Crypto 重算 sha256，和台账逐字节比对；全程本机、离线、文件不出机器。"
- **展示**：结果条（ok / bad / skip）+ 可导出 CSV。

## 7. 收尾（15s）
- **说**："这是一个'信任可被中断'的知识验证系统：断言 → 证据 → 复现 → 判决，每一环你都能自己验。想自己跑数字，看 `REPLICATION.md`，或者一条命令 `python tools/reproduce_all_670c.py`。"
- **点**：回首页展示"无后端 / 无追踪 / 数据现算"脚注。

| **"数字可信吗？"** | 三条：① 数字**现算**、来源文件与分子分母随值一起给；② 669d 做过独立复现审计并固化成 **6 条 P0 门禁**（`python tools/run_669d_gate.py` 可自查）；③ 670c 加了**漂移监控**（关键数字超 ±10% 且无实验记录就标红）。 |
| **"怎么复现？"** | 读 **[REPLICATION.md](REPLICATION.md)**（环境含 WSL 必须的原因、逐条命令与预期数字+CI、常见问题）；一键 `python tools/reproduce_all_670c.py`。 |

## 附：670c3–670c5 新增演示点（各约 10s）

- **noscript 降级**：浏览器禁用 JS → 每页显示纯 HTML 兜底（项目定位 + 核心数字），**不是白屏**。
- **入口页三态**：停掉本地服务器刷新首页 → 错误卡 + 重试按钮（3 次后提示 `python -m http.server`）；数据为空 → "暂无数据"；指标为 0 → 显示 `--`。
- **键盘导航**：按 `?` 打开快捷键帮助；`g`+`c` 跳卡库；`/` 聚焦搜索框；`j`/`k` 在卡片间移动焦点；`Esc` 关闭弹窗。
- **可访问性**：`Tab` 遍历 → 焦点环 2px `#d97757`；首个可聚焦元素是"跳到主内容"链接。
- **响应式**：窗口缩到 375px → 无横向滚动、触控目标 ≥44px、弹窗近全屏。
