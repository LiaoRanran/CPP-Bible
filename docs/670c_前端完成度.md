## 二、逐页功能与交互

### A1 学习页 `learn.html` + `js/learn_engine.js`
- **学习路径可视化**：三阶段（前置关系 → 断言/四态/证据 → 自测）内联 SVG 流程图，当前阶段高亮、已完成阶段走完成色，节点显示 `done/total · 百分比`。
- **错例驱动学习**：新增 `web/data/err_deck_670c.json`（由 [tools/web_err_deck_670c.py](tools/web_err_deck_670c.py) 从 665 机器卡 + 反例源码生成，16 张）。每张错例卡五段式：**错误断言 → 反例代码 → sanitizer 输出 → 正确断言 → 自测**；未签的机器卡在页面上显式标「机器生成 · 未签」并写明正确断言的来源字段。
- **间隔重复调度（SM-2）可视化**：下次复习文案（未开始 / 该复习了 / 今天 / 明天 / N 天后）、掌握度曲线（用 sm2 **重放**历史事件，逐时刻快照已掌握张数）、按域聚合的薄弱热力图（level 0–3 + 红框标有失败记录的域）。
- **统计仪表盘**：已学 / 掌握 / 薄弱 / 待复习 / 未学 / **连续天数**。
- **持久化**：localStorage `qy-learn-progress-v1`；导出带 schema/时间/条数；导入**逐条校验**、坏条目跳过并计数、默认「更靠前的进度优先」合并（不会被旧档案回退），可 `prefer:'imported'`。
- **键盘快捷键**：<kbd>空格</kbd> 揭晓、<kbd>←</kbd>/<kbd>→</kbd> 上/下一张、<kbd>1</kbd>–<kbd>4</kbd> 评分（忘记/困难/良好/完美）。判定逻辑是纯函数 `handleKey`：未揭晓时 1–4 **不评分**（防止没看答案就打分）；焦点在 input/select 时不抢键。
- **顺手修的 669c 遗留 bug**：SM-2 回忆失败会把 `reps` 重置为 0，而 669c 用 `reps>0` 判「已学」⇒ **昨天刚答错的卡被算成「未学」**，既不计入薄弱也不进「待复习」。改为 `isTouched()`（成功重复 / 失败 / 有历史事件任一），并补了 4 条断言锁死。

## 四、给 670a 的 baseline 字段契约（页面按此渲染）

页面以 `web/` 为文档根，请写到 `web/data/experiments/`（或写到 `data/experiments/` 后跑 `tools/web_experiments_sync_670c.py` 同步）：

```json
{ "schema": "queyi-baseline/v1", "arm": "static", "label": "Static（静态规则）",
  "generated_at": "…", "source": "tools/xxx.py",
  "datasets": {
    "holdout": { "k": 5, "n": 16, "rate_pct": 31.3, "wilson_lo_pct": 14.2, "wilson_hi_pct": 55.6,
                 "samples": [ { "id": "H-001", "verdict": "catch", "note": "" } ] },
    "corpus":  { "k": 6, "n": 32 },
    "defect":  { "k": 3, "n": 12 } },
  "detectors": { "sanitizer": 9, "compiler-warn": 6, "cross-compile": 3, "perf": 1, "compile-time": 1 },
  "evolution": [ { "batch": "656", "mutation_pct": 61.2, "holdout_pct": 50.0, "note": "" } ],
  "note": "…" }
```

- 三键名固定 `holdout`/`corpus`/`defect`（别名可容忍：external→corpus、真错→holdout、缺陷注入→defect）。
- `k/n` 必有；`rate_pct`/`wilson_*_pct` 可缺（前端用 k/n 现算同式 Wilson）。
- **`n=0` ⇒ 率与区间留 `null`**（页面画 n/a 幽灵柱，**绝不填 0**）。
- `samples` 可选（无则明说「未附逐样本清单」）；`detectors` 缺 ⇒ 饼图回退并标 pending；`evolution` 缺 ⇒ 只画有真实值的批次，其余空心点、**不插值**。
