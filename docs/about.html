关于

阙疑（Queyi）是一个独立研究工作与配套仓库：把"用哪些检测器"当作可在失败 中演化的对象，并以极端的可审计性要求约束每一步（四态判决、账本、Merkle、 工具完整性 fail-closed）。

Ran Liao（阿信 / LiaoRanran）· Hefei University · 独立研究（无机构资助）。

AI 使用声明（必须透明）

  • 本项目的实验脚本、数据分析与文档由作者主导、AI 辅助完成； 人类作者负责科学判断、方向决策与最终验收（每条 AI 产出都按验收协议检查）。
  • 真实靶场 PoC 是基于公开披露信息（NVD / 项目公告 / 修复 commit）的最小重构， 由 AI 辅助撰写、由固定工具链实测检验其行为；原始项目代码未被复制。
  • CVE 元数据（描述 / CVSS / 时间）全部取自 NVD API 应答原文，无人工转述。
  • 仓库内所有数字可由脚本逐条复算（verify_paper_numbers）， 任何与论文/网站不一致都是 bug。

诚实边界（摘自 Claim Boundary）

  • 检测器组合演化是一个工程化形式化 + 治理的贡献，不是新算法理论； novelty 分量的字面定义与 failure 等价（数学坍缩）——已被证明并公开， unique 修复变体在 683 消融中作为探索性结果报告。
  • 样本主体为合成/半合成语料；真实靶场（110 条）以重构方式引入外部效度， 不声称等价于原始项目上下文。
  • 工具链敏感性：见 Results 的跨工具链一节； 任何 >10pp 的差异都被强制披露。
