# 07 · 调研→门禁规则映射

> 基准：当前门禁规则来自 `data/_gate_rules.json`（67 条，paper §4 称与 `gate_engine.RULES` 两源一致）。
> 现有规则覆盖：原子 frontmatter、证据卡、 provenance、四态、DAL、署名、冲突关系、教学 advice 等。
> 目标：把调研中的**验证方法/最佳实践**映射成「应新增的门禁」；**重点=防复发门禁**——「改了代码没重跑就红」。

---

## 1. 当前门禁清单（按类别，节选关键）
- 原子：`ATOM-FM-REQUIRED`/`ATOM-ID-FORMAT`/`ATOM-VERIFIED-BOUND`/`ATOM-NO-UNVERIFIED`/`ATOM-STATUS-TRANSITION`/`ATOM-DAL-MATCH`/`ATOM-CLAIM-STRUCTURED`/`ATOM-GRAY-ZONE`/`ATOM-MISCONCEPTION-*`
- 证据：`EV-FM-REQUIRED`/`EV-FALSIFICATION`/`EV-MATRIX`/`EV-ARTIFACT-VERSION-MATCH`/`EV-ZERO-DIAG-WERROR`/`EV-ASSERT-COUNT-BELOW-BASELINE`/`EV-SELF-SATISFIED-ASSERT`
- 署名：`S1-AUTHOR-SELF-VERIFY`/`S1-GIT-AUTHOR-BINDING`
- 教学：`PED-*`/`HYBRID-TEACHING-DEPTH`/`HUMAN-GOLDEN-REVIEW`（advice）

**盲区**：现有规则**没有一条检查「统计口径/CI/分母/对照/baseline/盲态」**——即论文成立所需的方法学约束，当前门禁完全不拦。这正是 668「81.2% 假绿」的根因（`web_metrics_666 --check` 不比率）。

---

## 2. 应新增门禁（调研→门禁映射）

### G-STATS-FROZEN（统计计划冻结）
- 来源：`_arch_v44/07_统计方法精确指南.md`；A08
- 检查什么：任何报告检出率/比例的文档或产物，必须经 `tools/stats_667.py` 出 CI，且方法=预注册（`research/10_analysis_plan.md`）。
- 实现：`ci_check.py` 扫描 `\d+/\d+` 断言，缺 `ci_method` 字段即 block；方法不在白名单（CP/Wilson/Fisher/Boschloo/McNemar）即 warn。
- 优先级：P0｜防复发：改数字不重算 CI → 红。

### G-NO-WALD（禁止裸 Wald 区间）
- 来源：`_arch_v47/32` §三（Wald 最小覆盖 0.0075）
- 检查什么：文档/产物中禁止出现 `±1.96*sqrt(p(1-p)/n)` 式裸 Wald 区间。
- 实现：正则检测 `1\.96` 紧跟 `sqrt` 且上下文为比例区间 → block。
- 优先级：P1。

### G-DENOMINATOR（率必须带分母）
- 来源：`_arch_v47/31` §六；A13
- 检查什么：所有 `rate` 字段必须伴 `denominator` 与 `numerator`。
- 实现：`web_metrics_666.py --check` 比对三字段；缺 denominator → block。
- 优先级：P0｜防复发：改分子不更分母 → 红（直接堵 43.8% 类错误）。

### G-RATE-CONSISTENCY（率与计数一致性）
- 来源：`667_全量复盘.md` A4/N1；A02
- 检查什么：产物里的 rate 必须等于 numerator/denominator，且与 `--check` 基准一致；含射程自检（故意改一个值必红）。
- 实现：`web_metrics_666.py` 增三字段比对 + 自检注入。
- 优先级：P0｜防复发：改 detect 档位没重跑 → 红（堵 81.2% 假绿）。

### G-CI-PRESENT（所有 k/n 带 CP CI）
- 来源：`_arch_v47/32` §七；A15
- 检查什么：`research/` 中 `\d+/\d+` 断言须带 `95% CI [lo, hi]`（Clopper–Pearson）。
- 实现：`ci_check.py` 缺 CI 即 block；`6/6` 必须有下界（54.1%）。
- 优先级：P1。

### G-BOUNDARY-REQUIRED（卡边界三元组必填）
- 来源：`667_究极大规划.md` M2-B2；A11
- 检查什么：每张原子卡 `claim_boundary` 含 `input_domain`/`precondition`/`failure_mode`。
- 实现：`boundary_backfill_657.py --check` 集成进 gate（缺 → block）。
- 优先级：P0｜防复发：拆卡/改卡不补边界 → 四态恒 unknown 且不 false-pass。

### G-MACHINE-NEEDS-REVIEW（机器卡无人工签判红）
- 来源：`paper_v0.4.md` §5（❌「机器卡已验证」）；A31
- 检查什么：`status` 含 `verified` 但无 `human:*` 签名 → block；机器卡强制 `needs_review:true`。
- 实现：`gate_engine.py` 走 `is_verified()`/`level_of()`，禁散落 `status=="verified"` 比较。
- 优先级：P1｜防复发：Writer 自填 `verified` 绕过人审 → 红。

### G-BASELINE-EXISTS（报检出率须有对照）
- 来源：`_arch_v44/25`；A03
- 检查什么：论文 §4 报「阙疑检出率」须同时有 ≥1 个 budget-matched baseline 的逐样本输出。
- 实现：扫描 `data/baseline_*.json` 存在且非空集 → 否则 warn（投稿前须 block）。
- 优先级：P0。

### G-ABLATION-REGISTERED（ablation 须预注册假设）
- 来源：`_arch_v42/05`；A04
- 检查什么：每个 ablation 变体在 `research/ablation_plan.md` 有预写「回答什么问题」。
- 实现：扫描 plan 中 Full/-X/random-budget 条目齐全 → 否则 warn。
- 优先级：P1。

### G-IR-R（账本 IRR 报告须存在）
- 来源：`667_全量复盘.md` R6；A06
- 检查什么：`data/irr_report.json` 存在且 κ≥0.67。
- 实现：`inter_rater_667.py` 输出进 gate；缺失/低于阈值 → block（投稿前）。
- 优先级：P0。

### G-REPLICATION（单命令复现可跑）
- 来源：`_arch_v42/02`；A07
- 检查什么：`REPLICATION.md` 存在且 `python -m queyi.replicate` 在干净克隆可跑通。
- 实现：CI 中跑 replicate，非绿 → block。
- 优先级：P1。

### G-CLUSTER-CI（聚类样本报 n_eff）
- 来源：`_arch_v47/37`；A20
- 检查什么：样本按 source 聚类时，CI 须用 n_eff（非 n）。
- 实现：`stats_667.py --cluster` 输出 n_eff；文档未报 → warn。
- 优先级：P2。

### G-OTS-STAMPED（真锚定或显式占位）
- 来源：`667_全量复盘.md` N-OTS；A40
- 检查什么：`.ots` 须为真 attestation 或显式占位登记（非静默缺失）。
- 实现：`tool_integrity.py --check` 增 OTS 状态断言。
- 优先级：P2。

## 3. 防复发门禁优先级排序（「改了没重跑就红」）
| 门禁 | 堵的复发错误 | 优先级 |
|---|---|---|
| G-RATE-CONSISTENCY | 81.2% 假绿（改档位不重跑） | P0 |
| G-DENOMINATOR | 43.8% 分母错 | P0 |
| G-STATS-FROZEN | 换方法不冻结 | P0 |
| G-BOUNDARY-REQUIRED | 拆卡不补边界 | P0 |
| G-BASELINE-EXISTS | 无对照报检出率 | P0 |
| G-IR-R | 账本零复核 | P0 |
| G-CI-PRESENT | 裸点估计 | P1 |
| G-MACHINE-NEEDS-REVIEW | 机器卡冒充人审 | P1 |
| G-NO-WALD | Wald 灾难区间 | P1 |
| G-ABLATION-REGISTERED | 水 ablation | P1 |
| G-REPLICATION | 不可复现 | P1 |
| G-CLUSTER-CI | 聚类低估方差 | P2 |
| G-OTS-STAMPED | 锚定缺失 | P2 |

> 落地顺序建议：先 G-DENOMINATOR + G-RATE-CONSISTENCY（最小改动，直接堵已暴露的两个假绿），再 G-STATS-FROZEN + G-CI-PRESENT（需 A08 工具先落地），其余随对应任务卡推进。
