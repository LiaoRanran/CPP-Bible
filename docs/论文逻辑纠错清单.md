## 2. 🟠 过度声明与红线自违反

### B6 · 「显著优于」违反论文自设红线（**最值得注意**）

论文自设红线：
- §7.6 L515–516：「在 n≥103–173（配对）达标前，**任何情形都只能写"方向性观察"，不得写"显著优于"**」
- 附录 B L682：「红线：**不声称"显著优化"**」

但论文自身多处写「显著」：

| 位置 | 原文 |
|---|---|
| 摘要 L28 | "**显著高于**静态口径臂 4.8%" |
| 摘要 L30 | "在同批样本上**显著优于**静态口径与同预算随机验证资产" |
| §9.1 #5 L563 | "在同批样本上 FD **显著高于** Static 与 Random（真 B3）" |
| §10 L599 | "FD **显著优于**静态口径臂与同预算随机验证资产（真 B3）" |
| §10 L601 | "它确实…**显著**更好" |

**判定**：这是**红线作用域不清**导致的自我违反。严格读法：§7.6 红线语境是 **A0−A5 ablation**（未跑）；
而 §6.5 的 baseline 对比**确实达到 p<0.05**（精确 McNemar p≤6.1×10⁻⁵）。两者不冲突，
但**论文未声明红线的适用边界**，读者会认为论文违反了自己的纪律。
**修法（二选一，推荐 a）**：
- (a) **在 §7.6 红线处显式限定作用域**：「本条红线仅适用于 **A0−A5 ablation**（未跑）；
  §6.5 的 baseline 对比因 p≤6.1×10⁻⁵ 且 c=0，可写"显著"，但**幅度**仍只能读区间」。
- (b) 把 §6.5/§9.1/§10 的「显著」降级为「方向稳健、p<0.05（小样本）」。

### B7 · 「p≤3.1×10⁻⁵」对「Static + Random」合并陈述**不成立**

| 位置 | 原文 |
|---|---|
| 中文稿 §9.1 #5 L563 | "FD 显著高于 Static **与 Random**（真 B3）\| 配对精确 McNemar **p≤3.1×10⁻⁵**、Cohen's h ≥0.81" |

**修法**：中文稿 L563/L599、英文稿 L770/L808 的「Static 与 Random」合并句，
