# 3 分钟读懂「祈易 QueYi」

> 给第一次听说这个项目的陌生人。读完你应知道：它是什么、解决什么痛点、为什么可信、怎么用。

## 一句话
**祈易是一个 C++ 知识库，但每张"知识卡片"都附带能让你亲手验证的证据和复现步骤——你可以不信作者，只信你自己跑出来的结果。**

## 它解决什么痛点？
学 C++（尤其嵌入式/底层）时，你常遇到两类坑：
1. **书上说的 vs 编译器实际做的**——很多"常识"只在某个编译器/优化档下成立，换个环境就翻车。
2. **"权威结论"无法验证**——教程说"这样做对"，但你没法 30 秒确认它到底对不对。

祈易的做法：每条结论都绑定 **「真机编译/运行输出」作为证据**，外加 **复现清单**（用哪个编译器版本、跑什么命令、输入什么、期望得到什么）。你点开就能重跑。

## 它长什么样？
- **卡库**：42 张实卡（内存、并发、未定义行为、语言特性等；台账共 52 张，其中 10 张草稿不进教学台账），按四态 / 证据强度 / 域 / C++ 标准筛选，支持**全文搜索**、**2–3 张并排对比**、**证据链树状图**（卡 → 证据 id → 证据文件 → sanitizer 输出）与**前置关系图**。
- **学习台**：把卡片变成可复习的牌组，用**间隔重复（SM-2）+ 主动回忆 + 错例驱动**帮你记住；有学习路径三阶段流程图、掌握度曲线、薄弱知识点热力图、连续天数；**16 张机器卡的反例**做成"错例牌组"（错误断言 → 反例代码 → sanitizer 输出 → 正确断言）；支持空格揭晓、←/→ 翻卡、1–4 评分。进度存你本机。
- **实验结果**：检出率（带 Wilson 置信区间误差线）、口径消融、系统演化、检测器构成、能力构成雷达——数字都现算自真实台账，分母和口径一起给，不玩"只报好看的"。
- **判决页**：31 条判决的时间线、四态分布变化、漂移检测可视化，以及**声明值 vs 现算值 vs 差异**对比表（超容差的单元格标红）。
- **星图**：178 节点 / 1093 边的"知识接地网络"用 Canvas 真实渲染，7 个 domain 聚类带标签，可搜索定位、可看关系强度（边粗细）。
- **验哈希**：用浏览器对工件重算 sha256，和台账逐字节比对——离线可用，文件不出本机。

## 为什么可信？（三条铁律）
1. **unknown 不等于 fail**：测不了或不确定的样本，老实干写"未知"，绝不偷偷算成通过。
2. **低分常是测量配置错**：曾有几个"漏报"只是因为编译档位没开对，双档（-O0/-O2）一开就抓住。
3. **账本不可改**：452 条权威标注事件一条都不动（红线）；外部语料扩样样本没做盲态，所以**不**拿来吹外部效度。

## 怎么用？
```bash
python -m http.server 8000 --directory web
# 打开 http://localhost:8000/index.html
```
不需要装任何东西，不需要联网（图表是自带 SVG/Canvas 画的）。

## 想自己复现数字？
- 一键：`python tools/reproduce_all_670c.py`（门禁 → holdout → corpus → 变异 → 反事实 → fast 测试），产物 `data/reproduction_report_670c.json`。
- 逐步 + 环境要求 + 预期数字 + 常见问题：**[REPLICATION.md](REPLICATION.md)**。
- 数据完整性：`data/dataset_hashes_670c.json`（SHA256 清单）。
- 数据元数据：`data/croissant_670c.json`（Croissant 格式）。

## 它现在到哪一步了？
- 已经能跑、能验、能学（上面那些页面都是真的）。前端 6 个页面共 **599 条 Node 真求值断言 + 8 页 jsdom 结构冒烟**，全绿（`cd web && npm test`）。
- 论文在写（`research/paper_v0.6.md`，投向 NeurIPS 的 E&D 赛道），讲的是"如何把知识验证做成可被独立验收的系统"这个方法论。
- **baseline 对比和 ablation 消融实验还在做**，实验页相应位置标注了"待670a生成"，没有编造数据。
- 仓库拆分：内核层已完成（CPP-Bible 侧为薄 wrapper），判决/变异层仍是两侧各一份完整实现（已知债务，见 README_v2「拆分边界」）。
