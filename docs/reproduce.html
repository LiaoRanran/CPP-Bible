复现

三条路径：① 纯 Python 复算（不需要编译器，几分钟）；② 全量真实检测（需要 WSL g++ 13.3 + MinGW g++ 13.1 + clang，数十分钟）；③ Docker（论文/门禁/数据链自检）。

① 纯 Python 复算（无编译器依赖）

# A5 主端点 + 消融（复用冻结矩阵，不重跑检测）
python data/676f_analysis.py
python tools/analyze_682_sensitivity.py --stage all
python tools/analyze_683_oc.py --stage all      # 16+16 配置消融 + 7 基线

# 论文数字一致性（105+ 个数字逐个对账）
python tools/verify_paper_numbers.py
python tools/paper_quality_gate_670c2.py

② 真实靶场全链（需要编译器）

# 1) CVE 在线验证（NVD API；断点续跑；~10 分钟）
python tools/collect_realworld_683.py --stage verify

# 2) 真实靶场 8 资产检测（110 样本 × 8 资产；增量 checkpoint）
python data/realworld_683_runner.py --stage manifest
python data/realworld_683_runner.py --stage detect
python data/realworld_683_runner.py --stage merge

# 3) 跨工具链 / 跨平台（clang 18 vs g++ 13.3；Windows vs WSL）
python tools/cross_toolchain_683.py --stage b1
python tools/cross_toolchain_683.py --stage b2
python tools/cross_toolchain_683.py --stage report

③ Docker（论文编译 + 门禁 + 数据完整性）

docker compose build
docker compose run --rm queyi python -m pytest tests -x -q
docker compose run --rm queyi tectonic -X compile research/latex/queyi_neurips2027_v1.1.tex
