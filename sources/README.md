# sources/ — L0 原料层（只读归档）

**定位**（DRQ-1 选 A，全新搭建）：存放原始素材、引用原文、编译器原始输出的**只读快照**。

## 硬规则

1. **不可变**：写入即冻结。需要修正 → 新增新时间戳快照，旧快照保留，绝不原地改。
2. 快照路径：`sources/_snapshot/{YYYYMMDD-HHMM}/...`。
3. 存量 147 章导入为只读快照（`sources/_snapshot/{ts}/Book/...`），后续**从 L0 萃取原子**，不直接修改 `Book/` 原始 md。
4. 本目录不参与站点发布（mkdocs exclude）。
5. 引用原文需标注来源与获取日期；转引必须标"转引自 X，未核原出处"（防伪多源，见 G2.2）。
