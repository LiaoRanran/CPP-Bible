## 一、v24-v25 概念整合矩阵（四层排列）

行 = 认知层级（数学基础 → 哲学定位 → 生物实现 → 工程设计），列 = 方向。每格只列 v25 的**设计级产物**（v24 概念层不重复）。

### 第一层：数学基础（什么是不可能的）

| 方向 | 硬上限 | 关键定理/公式 |

### 跨方向收敛（v25 新增的三条）

1. **"判决"降级，"流"升格**：A（近似必然）、B（生命周期）、C（误差信号）、E（回路）四路独立指向同一结论——**判决是一时输出，误差流与生命周期才是系统本体**。
2. **一切强度必须挂边界与死区时间**：@B 边界（A）+ γ≤f(τ_d)（E）+ hard-easy 分域（F）——无强度不是常数。
3. **公共性与接地是信任的两个前提**：de Bruijn 可独立重查（A）、规则不可私下遵循（G）、独立复核（F）三路合流。

## 二、阙疑 v2 核心对象模型（七对象）

```
                    ┌─────────────────────────────────────┐
                    │  Ledger（台账，append-only+hash 链） │ ← 承载一切事件（底层）
                    └─────────────────────────────────────┘
                                    ▲ 记录
        ┌───────────────┬───────────┼───────────┬───────────────┐
        │               │           │           │               │
   ┌────┴────┐    ┌─────┴─────┐ ┌───┴───┐ ┌─────┴─────┐ ┌───────┴──────┐
   │  Rule   │    │ProofObject│ │ErrorFlow│ │Lifecycle │ │ConflictDetector│
   │（可改对象）│   │（判定产物）│ │（学习源）│ │（状态机） │ │（元层·独立）   │
   └────┬────┘    └───────────┘ └─────────┘ └───────────┘ └──────────────┘
        │                                                      ┌──────────────┐
        └── 约束：hard_core/belt 标签 · 三难声明 · 接地报告    │Calibration   │
            · MDL 盈亏 · 续期状态                              │Tracker（元层）│
                                                              └──────────────┘
```

| 对象 | 定义 | 关键字段/接口 | 来源 |
|---|---|---|---|
| **Rule** | 唯一可改对象 | hard_core\|belt；三难声明（sacrificed/external_oracle）；grounding_coverage；MDL 边际盈亏；renewal_due | A/B/D/G |
| **ProofObject** | 判定产物（一等公民） | claim（含边界 B）+ evidence_tree + checker + provenance(trusted:false) | A |
| **ErrorFlow** | 学习信号源 | 逃逸/自身免疫/**运气正确（承重集空）**/缺省负信号；信用分配（归因到最早可预测点） | A/B/C |
| **Lifecycle** | 状态机 | draft→verified→stale→disputed→retired(+复活条件)；evidence_age_median；ttl | B |
| **ConflictDetector** | 元层监控（**不 import 判决代码**） | detect(evidence,rule_matches)→{type∈RR/ER/EE/欠定, strength C} | C |
| **CalibrationTracker** | 元层监控 | update(p,truth)；level∈L0-L3；ECE/Reliability（分域报告） | C/F |
| **Ledger** | 底层持久化 | append-only + hash 链 + attestation；不删历史 | A/B/E |

**对象间核心关系（六条边）**：
1. Rule 的每次改动 → Ledger（含预注册的新预测——B 的进步判据）；
2. ProofObject 的边界 B 老化 → Lifecycle 转 stale（C/A）；
3. ErrorFlow 的逃逸事件 → DefeaterLedger 新条目 + 反哺 Rule 候选（但经 MDL 门与冷却期）；
4. ConflictDetector 输出 → 只触发分流与强度提升，**永不直接改判**（INV-C1）；
5. CalibrationTracker 的 L2 禁言 → 该验证器置信度字段清空（门控 Rule 消费）；
6. Lifecycle 转移 → Ledger 事件（可审计的每一次状态变更）。

   ▼
[冲突检测层]（C，独立模块）
   │  C>θ ⇒ 补偿性调整（升级复核/提高检查强度）；不改判
   ▼

   │
   ▼ 判决 + 证据集

   │
   ▼ 三/四态结论：pass@B / block@B / unknown@B（边界三元组必附）
[适切条件检查]（G）── 不满足 ⇒ 记"不生效"（≠ 无效）
   │
   ▼
[Lifecycle FSM]（B）→ verified（+ 击败器台账 ≥1 条 + TTL + 消费者登记）
   │
   ├─[CalibrationTracker]（C/F）── 真值回填 ⇒ ECE 更新 ⇒ L1 重校准 / L2 禁言 / L3 降级

   ├─[BiasAudit]（F）── 周期五偏差扫描（同源/散度/表述/盲审/校准）
   │
   ▼ 周期扫描（三线并发）
   ├─ 边界漂移（B 三元组变）⇒ stale ──重查──▶ verified / disputed
   ├─ 击败器触发（三线扫描 B）⇒ disputed
   └─ 证据年龄（半衰期 B）⇒ stale
   │
   ▼

   │
   ▼
retired（+ resurrection_condition）──新证据──▶ draft（可复活，不留死档）
   │
   ▼

## 五、v21-v24 全部结论的最终排序

**立刻做（高确定性 × 低成本）——9 项**：
① 边界三元组回填；② τ_d 测量；③ blind_protocol；④ 击败器种子台账；⑤ 冲突检测器影子；⑥ 校准追踪器报告模式；⑦ anti-windup + 告警预算；⑧ MDL 基线评分；⑨ 术语接地盘点。
*理由：全部"只加数据/保护，不改判决"，失败成本近零，且互为后续任务的前置输入。*

**研究原型（中确定性或高成本）——7 项**：
① 重建式 replay（高风险子集先行）；② MRAC 参考模型 + 自适应律（需先有 τ_d 与 S）；③ RD 曲线完整化（R 口径未定）；④ 硬核/保护带正式发布（需审计）；⑤ 权威的 Gettier 承重集全量检测（反事实重跑成本）；⑥ 多验证者共识门的组织落地；⑦ 隐喻审计制度化。
*v21-v24 的以下结论降入"维持现状"：供应链信任（SLSA/Sigstore）、拜占庭 n≥3f+1、攻击面 L1-L8 主体结构、预测编码不作底座。*

**死路（v25 确认，共 37 条，归三类）**：
- **理论否决（数学/信息论）**：自证闭环（哥德尔第二）；有限化逃逸（Trakhtenbrot）；逃逸率=0/D=0（Rice + R→∞ 双证）；Kol 复杂度直接测量（不可计算）；终极统一检查器（Hilbert 变体）；全系统形式化（Flyspeck 成本）。
- **机制否决（控制/认知）**：开环观测器；高增益崇拜；无视死区时间调参；放任 L2 无刹车（死亡漩涡）；装饰性击败器；偷看式 replay；冲突信号判决化；精度加权万能论；校准聚合幻觉；无反馈的校准自信；AI 先出现再"复核"；一致同意当佐证；偏差知识自我免疫。
- **语义/哲学否决**：隐喻入判据；私人验证标准；符号循环当语义；pass 当纯描述；事后解释即进步；白鞋式确认为主证据；可证伪性作划界；"有用即真"滑坡。

**需 632+ 批次实测回填的参数清单（12 个）**：θ_conflict≈0.3；θ_safe=0.8；θ1(ECE)=0.10；divergence 连续 N=5；λ(损失厌恶)=2 的决策折扣；τ_d（待测）；γ_max 系数；证据年龄阈值（按 domain_class）；告警预算速率；novelty_rate 判定阈值；半衰期域表；MDL 编码长度定义。

## 六、对"同行没有的强度"的定义（五项）

单独任何一项都平庸——**合起来是一种口径**：从"判决结果系统"转向"**误差流 + 生命周期系统**"（v24 顶层建议）的完整落地。

1. **带边界的四态结论**：`pass@B / block@B / unknown@B / stale`——边界三元组（mutation 集哈希+数量+生成器版本）附着于一切结论。业界验证器只报 pass/fail，**没有一家报"在什么边界内成立"**（A-3 给出理论根据）。
2. **误差流五类学**：逃逸 / 自身免疫 / **运气正确（Gettier 类：承重集为空）** / 缺省负信号 / 冲突事件——尤其"运气正确"是全新增错误类（业界三态指标全部不覆盖"结论对而过程错"，B-1）。
3. **元层三件套同时在线**：独立冲突检测层（不改判）+ 验证器校准追踪（ECE + L3 降级 + 禁言）+ 证据精度加权（逆方差 + divergence 侦测）——三个"对自身认知的认知"机制并行（C 全部）。
4. **可计算的正反馈刹车**：MDL 边际判据（新规则省出的数据描述长必须超过自身成本）+ 规则续期制（反禀赋效应）+ RD 曲线报告——给"规则膨胀"装上可计算而非靠感觉的刹车（D/E）。
5. **人机信任的工程化防线**：先判后揭 + 盲评 + 共识门（独立性核验，分歧率过低视作危险）+ 个人校准反馈——人审不再靠"水平"而靠**协议**（F）。

**一句话定义**：阙疑 v2 的独有强度 = **"一个知道自己不知道什么、知道自己何时可能错、并且在边界变化时会主动重新验证的知识系统"**——三件在业界实践中都罕见，且这三件恰好是 v25 七方向收敛到的同一个点。
