## 一、精确表述

### D-1 知识的信息含量：自信息、熵与 VOI

**自信息 / 熵（精确形式）**：
- 自信息：`I(x) = log₂(1/p(x))`（"惊异度"：越不可能的事件信息量越大）；
- 熵：`H(X) = E[log₂(1/p(X))] = −Σ p log₂ p`（期望惊异）。
【已查证】https://inst.eecs.berkeley.edu/~ee126/sp24/notes/info_theory.pdf ；https://handwiki.org/wiki/Information_content

**关键区分：信息量 ≠ 价值**。**VOI（信息价值）**才是决策相关的度量：
- `EVPI = E[有完美信息下的最优期望收益] − E[无完美信息下的最优期望收益]`（完美信息期望价值）；
- `EVSI ≤ EVPI`（样本信息的价值上界）；
- **判据（工程原文）**：信息只有在**能改变决策**时才有价值——"信息只有能改变决策、改善期望结果、减少后悔或防止不可接受的失败时才有价值"。【已查证】https://sustainablecatalyst.com/value-of-information-and-when-to-wait/

**阙疑知识信息含量（设计对象）**：
```
card.IC    = −log₂ P(verdict(card))            # 单卡惊异度（先验下）
card.ΔH    = H(verdict) − H(verdict | card 结论)  # 判别信息量：该卡结论减少的判决不确定性
set.H_rem  = Σ_{未验证卡片} H(verdict_i)        # 库的残余不确定性（coverage 的信息论刻画）
VOI(evidence e) = 过期判决中 ev 会翻转的比例      # EVSI 的阙疑化：e 改变判决的实证频率
```

**VOI 门的直接推论**：一条证据若对任何相关卡片的判决都不产生影响（VOI ≈ 0），不必采集或不必入账——这是证据采集优先级排序的理论依据，也让"证据通胀"有了刹车。

### D-2 规则 MDL 评分：给规则膨胀装上刹车

**MDL 原理（精确形式）**：选择使**数据压缩总长最小**的模型：`L(D; M) = L(M) + L(D | M)`（模型描述长 + 模型下数据描述长）；two-part codes；Rissanen 1978 与 BIC 独立同年、渐近同值；现代版本（NML）已超越 `(k/2)log n` 的经典近似。核心直觉：**能压缩数据的模型更接近真结构**。【已查证】https://www.cs.helsinki.fi/u/ttonteri/pub/roosmdlencyc2016.pdf ；https://aipedia.org/mdl-tutorial/

**Kolmogorov 结构函数（深化）**：`K(x) = min{ |p| : M(p) = x }`（最短程序长度，**不可计算**）；结构函数描述"模型复杂度上界 ↔ 模型能覆盖的数据量"的关系，把总信息分成**结构信息（有用规律）+ 意外信息（随机残余）**；sophistication = 最有意义的规律描述。【已查证】https://arxiv.org/pdf/0809.2754v2 ；https://arxiv.org/pdf/cs/0204037 ；https://static.aminer.org/pdf/PDF/001/109/981/meaningful_information.pdf

**阙疑规则 MDL 判据（v25 核心设计，把"规则膨胀"变成可计算问题）**：
```
L(R)    = Σ_r |r| 的编码长度（参数+条件+动作，共享结构计折扣）
L(D|R)  = −Σ_d log P_R(correct(d))（错误解释成本：错判/漏判的负对数似然）
边际判据：接纳规则 r ⟺ [L(R) + L(D|R)] − [L(R∪{r}) + L(D|R∪{r})] > 0
          （新规则节省的数据描述长度必须超过自身描述长度）
```

**结构函数的阙疑借义**：
- **规则 = 结构信息**（压缩错误解释）；**逐案例外 = 意外信息**（豁免四元组、逐卡记录只能逐案记忆）；
- ⟹ **豁免数量持续增长 = 结构信息不足的信号**——每条豁免都是"规则库没能压缩掉的意外信息"；豁免率上升应触发规则重设计而非继续攒豁免。这是对 v23 豁免机制的新诊断维度。

**偏置警告（前车之鉴）**：信息增益 `IG(S,a) = H(S) − H(S|a)` 与互信息数学等价，但**偏好高基数属性**（ID3 病），需增益率（C4.5）修正。【已查证】http://cs.nju.edu.cn/liyf/aml26/Lecture06.pdf ⟹ 任何单一信息指标都有系统偏置，**必须配修正项**，不得单指标裁决。

### D-3 证据互信息评分：证据到底有多支持命题

**互信息（精确形式）**：`I(E; P) = H(P) − H(P|E) = Σ P(e,p) log[P(e,p)/(P(e)P(p))]`（观测 E 降低的 P 的不确定性）；单点版本 `PMI(e,p) = log[P(p|e)/P(p)]`。【已查证】https://deepml.app/course/math/09-information-theory/03-mutual-information/notes ；https://computationallinguistics.com/Pointwise_Mutual_Information

**阙疑证据评分（设计对象）**：
```
MI_score(e, P) = H(P) − H(P | e)          # e 降低的命题不确定性（比特）
nMI            = MI_score / H(P) ∈ [0,1]  # 归一化："承载了命题不确定性的百分之多少"
```

**三条工程限定**：
1. **必须用实证频次估计**（该证据出现时命题为真的历史频率），禁止主观赋值；小样本用平滑；
2. **PMI 的低频偏置**：罕见共现的 PMI 虚高，需 PPMI 截断或平滑——与 D-2 的 IG 偏置同类，**同一病，必须用同类修正**；
3. **MI 与 precision 独立**（C 方向接口）：一个源可以"信息量大但不可靠"（高 MI 低 precision）或反之；两个维度分开记账。
**阙疑应用**：①证据采集优先级（nMI 高者先取）；②承重证据核算——B 方向"最小承重集"中的证据应有高 nMI（低 nMI 的"证据"不可能是承重的）。

### D-4 率失真框架：近似验证的理论支撑

**率失真定理（精确形式）**：`R(D) = min_{P(x̂|x): E[ρ(x,x̂)] ≤ D} I(X; X̂)`——在平均失真不超过 D 的约束下所需的最小比特率；**D = 0（无损）一般要求无限率**；R(D) 是**理论下界**，不考虑具体编码方法；任何实际方案的点都在曲线之上。【已查证】https://web.stanford.edu/class/ee398a/handouts/lectures/04-RateDistortionTheory.pdf ；https://technav.ieee.org/topic/rate-distortion/ ；Shannon 1959 原文口径

**阙疑映射（v25 核心设计）**：

| RD 概念 | 阙疑对应 | 说明 |
|---|---|---|
| 源 X | 完整正确知识集 | 不可数、未知 |
| 表示 X̂ | 系统实际掌握的知识 | 67 规则 + 卡片库 |
| 失真 ρ | 判决不匹配率 | 逃逸率、自身免疫率的统一定义 |
| 率 R | 总验证成本 | 规则数×评估成本 + 人审时间 + 重查成本 |
| R(D) 曲线 | **根本权衡下界** | D↓ ⇒ R 指数上升（对多数真实源） |

**两个独立结论在此汇合**：A 方向 Rice 定理（逃逸率非零的判定论根因）与 D 方向的 D→0 ⇒ R→∞（成本论根因）是**同一件事的两种证明**。v23 四指标（coverage/recall/自身免疫/horizon）可读作 (R, D) 空间中的坐标——四指标报告的形式化升级。

**第二模型：验证即信道（纠错设计）**：
- 信道容量 `C = max I(输入; 输出)`；Shannon 定理：只要传输率 R < C，存在编码使错误率任意低。
- **冗余 = 独立验证路径**（双实现、他验三件套、human 抽样）——**提高 C 比放大单通道强度更优**（Shannon 的结构性建议）。
- **设计启示（反直觉）**：编码史显示代数块码（结构化冗余）长期未达容量，**概率编码（turbo/LDPC）才逼近**——冗余的**设计方式**（长码、随机化、跨跨度）比冗余**数量**更重要。阙疑对应：多条短规则的堆叠不如一条跨长跨度的统计校验；重复同构验证（同源多角色）不增加 C（v21"退化≠冗余"的信息论版本）。【已查证】https://arxiv.org/pdf/cs/0611112

**PCC 与 log loss 两个接口**：
- **PCC（Necula）**：代码携带机器可检查的安全证明——"检查易、构造难"的不对称是核心杠杆（把难度推给生成端）。与 A 方向 ProofObject 同构，为"卡带证据"提供第二来源。【已查证】https://people.eecs.berkeley.edu/~necula/Papers/marktoberdorf.pdf
- **log loss（proper scoring rule）**：`H(p,q) = H(p) + KL(p‖q)`；"自信且错"的惩罚趋于无穷。【已查证】https://aiwiki.ai/wiki/log_loss ⟹ 阙疑的置信评分必须用 log loss 类 proper 分数，**accuracy 无法度量校准**（C 方向 ECE 的补充）。

## 二、阙疑重构草图

### 2.1 对象模型（新增五对象）

- **CardInformationProfile**：IC / ΔH / nMI 集（每卡）；
- **RuleMDLReport**：L(R)、L(D|R)、边际盈亏账（每规则）；
- **ChannelDesign**：独立通道清单（双实现/他验/人抽）+ 通道独立性核验；
- **RDCurve**：实测 (R, D) 点集 + 报告；
- **VOIGate**：证据采集准入判定。

### 2.2 数据流

```
候选证据 → [VOI 门]（EVSI≈0 ⇒ 不采集，直接归档为"低价值"）
        → [MI 评分]（nMI 排序，决定采集优先级）
        → 入验证 → 判决 → 错误事件
        → [规则 MDL 审计]（新规则边际盈亏 / 豁免率诊断）
        → [RD 曲线]（(R,D) 点更新，与 v23 四指标并列报告）
```

### 2.3 关键不变量

- **INV-D1（VOI 门）**：不改变任何判决的证据不采集/不入账（EVSI≈0 判据）。
- **INV-D2（MDL 边际）**：新规则必须通过"节省 > 成本"判据；豁免率上升触发规则重设计而非继续攒豁免。
- **INV-D3（容量优先）**：冗余投入优先增加**独立通道**（提高 C），而非提高单通道权重（放大 R 噪声）。
- **INV-D4（非主观评分）**：MI/MDL 分数必须来自实证频次与可计算量，禁止主观赋值。
- **INV-D5（proper 评分）**：置信质量用 log loss / Brier 类 proper 分数评估，禁止用 accuracy 替代。

## 四、迁移路径（67 规则 / 419 工具过渡）

- **阶段 0（纯报告）**：对现有 67 规则算 MDL 基线（L(R)、错误解释成本 L(D|R)），对现有豁免执行率做趋势诊断（结构信息不足信号）。
- **阶段 1（VOI 回测）**：`voi_gate.py` 对历史证据回测"该证据是否曾改变判决"，输出 VOI 分布——不改流程，只做统计。
- **阶段 2（MI 排序上线）**：证据采集走 nMI 排序；与现有人工优先级对照校准。
- **阶段 3（RD 曲线并列报告）**：`rd_curve.py` 输出 (R,D) 点与 v23 四指标合册。
- **不做**：用 Kolmogorov 复杂度直接测规则（不可计算，只能 MDL 近似）；追求 D=0（无限率，与 Rice 独立否决）；单指标裁决规则（偏置未修正前）。

## 五、死路复核

- **新死路 V18：Kol 复杂度直接测量**——K(x) 不可计算；一切只能经 MDL/NML 近似。
- **新死路 V19：单指标裁决**——IG 的基数偏置（ID3→C4.5 的教训）证明：未修正的信息指标会导致系统性错误选择。
- **新死路 V20：以 accuracy 评置信**——proper scoring rule 要求下，accuracy 对校准完全不敏感（confidence 与 accuracy 的关系被抹平）。
- **新死路 V21：靠放大单通道保质量**——Shannon 视角下应提高容量 C（独立通道）而非提高单通道权重。
- 与 A 方向合流：D→0 ⇒ R→∞ 是"逃逸率=0"的信息论版否决。

## 六、置信度与诚实声明

- **高置信**：熵/自信息/互信息/PMI 定义（Berkeley 讲义、HandWiki、多来源）；MDL（Rissanen 1978；Helsinki 百科条目）；率失真定理（Stanford EE398A 讲义、IEEE 通行口径）；Shannon 信道编码极限与编码史（Costello & Forney 综述）；PCC（Necula 原文）；log loss/cross-entropy 关系（多来源一致）；Kolmogorov 结构函数（Grünwald & Vitányi、Vereshchagin & Vitányi、Vitányi "Meaningful Information"）。
- **中置信**：阙疑版 MI/MDL 公式与 VOI 门为【类比推断】（首版工程化）；"豁免率=结构信息不足信号"为调研者推导，未见外部文献直接支持。
- **待验证**：RD 曲线的阙疑实测点（R 与 D 的实际量化口径）未定义；通道独立性核验方法待设计。
- **边界**：本文件给框架与原型规格；R(D) 的具体函数形式对不同"知识源"未知，只能用实测点+定性形状（凸、单调递减）。
