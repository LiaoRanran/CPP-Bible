## 一、精确表述

### E-1 反馈回路分析：阙疑自己的正负回路图

**基础（回路闭环传递）**：闭环 `Vout/Vin = H(s)/[1 + T(s)]`，环路增益 `T(s) = G(s)H(s)`。**自激振荡条件（巴克豪森）**：`|T| = 1` 且 `arg T = −180°`（奈奎斯特轨迹过 (−1, j0)）；工程三级实证（同一 SPICE 电路）：增益 27dB → 指数衰减；29.32dB → 稳定正弦振荡；33dB → 发散至限幅。【已查证】https://bbs.eeworld.com.cn/thread-1367255-1-1.html ；https://www.cnblogs.com/harold-lu/p/15736804.html

**阙疑的实际回路登记（v25 新增，逐条判别正负）**：

| # | 回路 | 类型 | 信号链 | 风险 |
|---|---|---|---|---|
| L1 | 逃逸 → 规则修补 → 逃逸降 | **负反馈**（纠错） | 逃逸事件→规则更新 | 延迟 = 死区时间（E-2） |
| L2 | 规则增 → 假阳性增 → 豁免增 → 有效覆盖降 → 逃逸增 → 规则再增 | **正反馈**（自我强化） | 见下 | **Limits to Growth** |
| L3 | 验证通过 → 信任升 → 复核减 → 校验减 | **正反馈**（信任自增强） | 信任→少查→更信任 | 信任塌缩缺失 |
| L4 | 人审推翻 → 验证器校准 → 判决质量升 | 负反馈 | 人审→校准 | 依赖人审状况感知（E-3） |
| L5 | 豁免 → 到期复查 | 负反馈（长延迟） | 到期→重查 | 豁免率↑ = 结构信息不足（D-2 接口） |
| L6 | 告警量 ↑ → 响应率 ↓ → 信噪比 ↓ → 需更多告警 | **正反馈**（脱敏） | 告警疲劳 | 疲劳线 40%（v23 参数） |

**L2 = 阙疑的 Limits to Growth（精准识别）**：增长回路（规则数→检出）与约束回路（规则数→假阳性→豁免→覆盖↓）叠加，**推更大的力只会撞上约束**——系统动力学标准对策是**移除约束而非加大推力**（引用原口径："respond to them with structural change rather than brute-force acceleration"）。阙疑的结构性对策：D 方向 MDL 边际判据（规则准入）+ 豁免率诊断（约束信号）。【已查证】https://thesystemsthinking.com/limits-to-growth-archetype-systems-thinking/

**L2/D5 与蚂蚁死亡漩涡的结构同构（v25 深化）**：
- 死亡漩涡的机制三要素（1921 Beebe 首次记录于圭亚那，圆周约 365 米、单圈约 2.5 小时；1936 Schneirla 论文）：**① 局部规则自我强化**（跟随信息素并留下更多信息素）；**② 无法感知全局**（行军蚁近乎全盲）；**③ 循环无退出条件**（不停下就永远转下去）。【已查证】https://this-amazing-world.com/army-ant-death-spiral-collective-behavior/ ；https://baike.com/wiki/蚂蚁死亡漩涡
- **阙疑的映射**：① "有逃逸就加规则"是局部规则；② 没有人在看**规则总数/豁免总数的全局量**；③ 停止条件不存在（规则只加不删）。**处置三件套**（逐一拆解三要素）：全局信号看板（规则数/豁免率/RD 曲线——v23 四指标的第三用途）+ MDL 准入（增加成本）+ 主动退役（出口条件）。

### E-2 稳定性判据 → 规则更新回路的增益约束

**精确判据（工程口径）**：相位裕度 PM = 穿越频率处相位与 −180° 的差；增益裕度 GM = 相位 −180° 处的增益衰减。**PM < 45° 基本不稳，45–60° 可接受，60° 左右是甜点（更大则响应慢）；GM > 10dB 安全**；穿越频率越高响应越快但越难稳。【已查证】https://m.elecfans.com/article/8367411.html ；https://m.fanyedu.com/interview/321.html

**死区时间（dead time）——稳定性的头号敌人**：死区时间 = 输入改变到输出可测之间的纯延迟，**产生相位滞后、限制可用的最大增益**；长死区过程的控制器需要"相对快的积分时间 + 很小的比例增益"。【已查证】https://www.controlloop.co.za/ls/ls4.htm（原文："Deadtime is the 'enemy' of feedback control, as it results in phase lag"）；https://web.stanford.edu/class/archive/ee/ee392m/ee392m.1056/Lecture11_IMC.pdf（Smith Predictor 补偿）

**阙疑映射（机制级）**：
```
环增益      T  ≈ γ × S      （γ = 更新幅度；S = 灵敏度：单位规则改动对错误率的影响）
相位滞后    φ ≈ −ω·τ_d      （τ_d = 反馈死区时间 = 逃逸发生 → 检测 → 修补 → 生效的周期）
增益上限    γ_max ≈ PM_avail / (S × τ_d)   （量级判据，非精确公式）
```
**可操作推论**：阙疑的反馈延迟 τ_d 以周计（逃逸→修补周期），**因此更新必须小步**——一次性大改（"这次把 20 条规则全改了"）在死区时间长的系统里必然振荡（今天加规则 A 修逃逸，几周后发现它造成假阳性又删掉——规则来回修改的振荡形态）。

**积分饱和（windup）映射（v25 新增）**：执行器饱和时积分器继续累积 → 恢复后大超调。**阙疑的"执行器"= 人审队列**：队列满时，新的规则修改信号继续累积 → 队列清空后一次性释放 → 大震荡。**anti-windup 对应 = 队列饱和时更新信号冻结/回算衰减**（back-calculation）。【已查证】https://www.iacsengineering.com/integral-windup/ ；https://arxiv.org/html/2606.01959

### E-3 观测器设计：真实状态估计

**Luenberger 观测器（精确形式）**：
```
系统：ẋ = Ax + Bu，y = Cx
观测器：x̂̇ = Ax̂ + Bu + L(y − Cx̂)
误差动态：ė = (A − LC)e        （L 可配置误差极点）
```

**四个洞见及其阙疑映射**：
1. **开环观测器（纯模型外推）不实用**：误差按 A 演化，A 不稳定则发散——"只看模型不看测量"是死路。【已查证】https://faculty.washington.edu/chx/teaching/me547/2_5_observer_and_observerStateFeedback.pdf
2. **修正增益 L 的权衡**：高增益观测器跟踪快但**放大传感器噪声**；低增益滤波好但滞后。【已查证】https://scipedia.bohrium.com/en/sciencepedia/feynman/keyword/observer_based_controller
3. **可观测性（Kalman rank 判据）**：观测矩阵满秩才能重建全部状态；**存在根本不可观测的状态**。【已查证】https://uomustansiriyah.edu.iq/media/lectures/5/5_2019_02_11!09_54_36_AM.pdf
4. **分离原理（Kalman 1960）**：观测器与控制器可**独立设计**（"先算最优估计 x̂，再算 u(t|x̂)"）——工程上大幅简化。【已查证】https://www.cds.caltech.edu/~murray/books/AM08/pdf/am08-outputfbk_30Jan08.pdf

**阙疑观测器（设计对象）**：
```
真实状态 x   = 全库知识的实际正确率（不可直接观测）
观测量 y     = 抽样检测 / 逃逸事件 / 人审结果（部分、带噪）
估计律：x̂ ← x̂_model + L·(y − ŷ_model)
    L 大 ⇔ 信任观测（观测频率高、噪声小）；L 小 ⇔ 信任模型
不可观测清单 = { 不产生任何可观测信号的错误类型 }   # 必须显式登记
```
**洞见 3 的直接应用**：v24 D6"0% 检出的四归因"中的"未送审"类错误 = **数学上不可观测的状态**——不是"没检出"，是"没有被观测通道覆盖"。观测器方法论要求把它们**显式列入不可观测清单**，而不是假装已知。分离原理的推论：**指标测量系统（观测器）与规则更新系统（控制器）解耦设计**，二者不必耦合。

### E-4 自适应更新算法：MRAC 式规则置信度更新

**MRAC 结构（精确）**：参考模型（理想响应 y_m）+ 被控对象（实际输出 y）+ 误差 e = y − y_m + 自适应律。
- **MIT 规则**：`J(θ) = ½e²`，`θ̇ = −γ·∂J/∂θ = −γ·e·(∂y/∂θ)`（负梯度方向调整参数）；
- **Lyapunov 版**：用 Lyapunov 函数证明收敛——**有稳定性保证，优于纯启发式的 MIT 版**；
- 自适应增益 γ：太大 → 振荡/失稳；太小 → 收敛慢。【已查证】https://pdfs.semanticscholar.org/a5fd/1200a17659d78123ea21e32e7e90381270a8.pdf ；https://zenodo.org/records/1329547/files/1037.pdf?download=1

**阙疑自适应更新（设计对象）**：
```
参考模型 y_m = "理想验证器响应"（显式定义：逃逸率目标、误报目标、响应时间目标——当前阙疑只有阈值，没有理想响应轨迹）
误差      e = y_m − y_actual
自适应律  θ̇ = γ · e · (∂y/∂θ)       # θ = 规则参数/权重；小步更新
约束      γ ≤ γ_max(τ_d)（E-2）      # 死区时间约束
收敛验证  更新律必须附 Lyapunov 类收敛论证（不得只凭经验调参）
```

**三条附加教训**：
1. **固定增益的"静默退化"**：固定 PID"被调一次就永远那样"，对象漂移时"performance degrades quietly until someone notices"——**不更新的验证器 = 静默退化器**（对应 B 方向生命周期 stale 状态的机制层理由）。【已查证】https://dev.to/01888927bd0e8aa92caca/model-reference-adaptive-control-letting-a-controller-learn-the-plant-5d6a
2. **串级控制（cascade）**：内环快（抑制小扰动）+ 外环慢（设定目标）；内环先行，外环把内环的输入当"理想值"。阙疑的天然串级：**证据层快速校验（内环）与规则层慢速更新（外环）分层**——证据级扰动由内环快速吸收，不要每次都惊动规则层（当前阙疑是"任何异常都可能触发规则讨论"，等于跳过内环）。【已查证】https://www2.et.byu.edu/~tom/classes/436/ClassNotes/Class34(Cascade%20Control).pdf
3. **信任校准的镜像风险（人机侧）**：automation bias（过度信任自动输出）与 algorithm aversion（过度不信任）都是失准；被动监控者（passive monitor）的**状况感知在 comprehension/projection 层坍塌**（perception 层几乎不降）。⟹ **人审若只是"看结论点通过"，状况感知必然坍塌**——人审界面必须迫使人重建"为什么"（对应 v24"人审 Authority"的界面要求）。【已查证】https://leifheaney.com/systems-engineering/lessons/trust-and-situation-awareness/ ；https://dl.acm.org/doi/fullHtml/10.1145/975817.975844
4. **告警疲劳的系统设计立场**：EEMUA 191 建议稳态每操作员每 10 分钟 ≤1 告警；"告警疲劳不是人的问题，是系统设计失败"——**告警预算（alarm budget）必须显式**（v23 疲劳线 40% 的控制论加强版）。【已查证】https://tractian.com/en/glossary/alert-fatigue ；https://resistancezero.com/article-2.html

## 二、阙疑重构草图

### 2.1 对象模型（新增四对象）

- **LoopMap**：回路登记表（类型 / 增益 / 死区时间 / 所属正或负反馈）；
- **StabilityReport**：γ 上限、τ_d 实测、振荡检测（规则来回修改的检测器）；
- **StateObserver**：x̂ 估计 + L 参数 + **不可观测清单**；
- **AdaptiveUpdater**：参考模型 + 自适应律（γ 受约束）+ windup 保护。

### 2.2 数据流

```
观测事件（抽样/逃逸/人审）→ StateObserver（x̂ 估计 + 不可观测清单更新）
    → 与 ReferenceModel 比较（e = y_m − ŷ）
    → AdaptiveUpdater（θ̇ = γ·e·∂y/∂θ，γ ≤ γ_max(τ_d)）
    → 规则参数/权重小步更新 → 新判决
    → [人审队列]（饱和 ⇒ anti-windup：更新信号冻结）
    → 新观测（经 τ_d 延迟）→ 闭环
并行：[LoopMap 扫描]（正反馈回路的平衡机制在位检查）
```

### 2.3 关键不变量

- **INV-E1（增益-延迟约束）**：`γ ≤ PM_avail/(S·τ_d)`——延迟越长更新越小（死区时间的代价）。
- **INV-E2（anti-windup）**：人审队列饱和时更新信号冻结，不累积。
- **INV-E3（观测器非开环）**：状态估计必须含 L 修正项；纯模型外推状态视为无效。
- **INV-E4（不可观测清单）**：不产生可观测信号的错误类型必须显式登记，不得假装已知。
- **INV-E5（正反馈刹车）**：每条正反馈回路（L2/L3/L6）必须有在位的平衡回路；无刹车即告警。
- **INV-E6（告警预算）**：告警量超过显式预算（速率上限）即触发设计复审，而非继续提高阈值。

## 四、迁移路径（现有流水线过渡）

- **阶段 0（回路登记）**：把现有机制画成 E-1 回路图（只登记，不改逻辑）；重点标注 L2 正反馈的现状参数。

- **不做**：开环观测器（纯模型指标）；高增益崇拜（大改快改）；在 τ_d 未测之前调 γ。
