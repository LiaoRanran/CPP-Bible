## 一、精确表述

### G-1 意义理论：真值条件 vs 使用论 → 知识卡的意义是什么

**Frege（1892）Sinn/Bedeutung（精确区分）**：`Bedeutung`（reference/指称）= 词所指的**对象**；`Sinn`（sense/涵义）= 指称该对象的**方式**。"晨星=昏星"与"晨星=晨星"指称相同而**认知意义不同**（cognitive significance）——这是 Frege 的核心论据。【已查证】https://handwiki.org/wiki/Philosophy:Sense_and_reference ；http://faculty.washington.edu/smcohen/453/FregeDisplay.pdf

**真值条件语义（精确形式）**：句子的意义 = 使其为真的条件（"The meaning of a sentence is given by the conditions that must obtain in order for the sentence to be true"）；词的意义 = 它对所在句子真值条件的贡献。【已查证】https://iep.utm.edu/mean-c-s/

**使用论（Wittgenstein, PI 1953）**：**意义即使用**——词的意义是它在**语言游戏**中的用法；反"奥古斯丁图画"（语言≠名称-对象配对）；家族相似（无需统一本质）；语言游戏嵌在**生活形式**中。【已查证】https://plato.stanford.edu/entries/Wittgenstein/ ；https://www.studyguides.com/study-methods/overview/cmp54c3hyj7iq01negstabsuy

**阙疑的可操作综合（v25 核心设计）**——一张卡的"意义"由两层构成：
```
卡的意义 = 真值条件层（什么世界状态下它为真……= 边界 B + 内容命题）
         + 使用角色层（它在系统中被谁消费、能改变什么判决、触发什么检查）
```
- **Frege 分层的直接应用**：知识卡**标题（Sinn）与内容（Bedeutung）可以不同**——两条卡可以指称同一事实而认知路径不同（一个给新手、一个给专家；一个按标准条款、一个按编译器行为）。**这不是冗余**——除非使用角色也相同（那才是真冗余，退化≠冗余的语义学判据）。
- **使用论的应用**：阙疑现状只检查真值条件层（内容对不对），不检查使用角色层（这张卡被谁用、用了会怎样）。**"孤儿卡"（无人消费的卡）= 使用角色的缺失 = 意义不完整**（与 D 方向 INV-D1"不改变判决的证据不采集"同源）。

### G-2 言语行为：验证通过是"以言行事"

**Austin 三层（1955 哈佛讲座 / 1962 出版）与 Searle 的扩展（1969）**：
- **locutionary**（说了什么）、**illocutionary**（说话时做了什么——断言/警告/承诺/宣布）、**perlocutionary**（说后产生的效果）；
- **performative utterance（以言行事）**："我宣布……"一说出即完成行为；
- **felicity conditions（适切条件）**：制度性行为在条件不满足时**不生效**（不是"为假"，是"失效"——如没有资格的司仪宣布的婚礼无效而不假）。【已查证】https://plato.stanford.edu/ENTRIES/speech-acts/ ；https://aura-lab.siue.edu/theories/speech-act-theory/
- **Searle 制度性事实**：由**集体同意**维持的事实（"X 在语境 C 中算作 Y"）；机构性地位依赖程序的持续承认。【已查证】https://studyguides.com/study-methods/overview/cmp4a7ib0i64m01neiz3axkq7

**阙疑映射（核心设计）**：`"验证通过"不是描述事实，是执行制度性行为`——它把卡片从 draft 赋格为 verified，赋予"可入链、可被消费"的制度地位。三条推论：

1. **验证结论有适切条件而非仅真值**：一条 pass 在"检查器不可信 / 边界陈旧 / 审查未盲评"时不是"错误的 pass"，而是**不生效的 pass**（felicity failure）。⟹ 为 v25 A 方向的"边界三元组"提供语言哲学根据：**缺边界的 pass = 适切条件未满足 = 无效的言语行为**（两条独立路径（Rice 的近似性、Austin 的适切性）指向同一处置）。
2. **程序是意义的一部分**：verified 的地位依赖被集体接受的程序（gate/replay/台账）；**改变程序即改变什么算"通过"**——程序不能悄悄改（否则构成改义而非改进）。
3. **pass 是承诺不只是断言**：illocutionary force = 系统承诺按该卡行动；pass 错误不止是事实错误，还是**承诺违背**（追责口径的升级）。

### G-3 符号接地：规则里的"内存屏障"接在哪里

**Harnad 1990（精确表述）**：符号接地问题 = 形式符号系统的语义解释如何成为系统**内在**而非**寄生于观察者头脑**？"纯符号操作的意义只能来自其它无意义符号"——类比"只用中文字典学中文"（无限回退）；候选解法：**符号表征最终接地于非符号表征**（感知/运动）。【已查证】https://www.southampton.ac.uk/~harnad/Papers/Harnad/harnad90.sgproblem.html
**机器人学实例**：symbol anchoring——把抽象符号锚定到低层结构（Cassie/SNePS；概率锚定在噪声数据下的符号学习）。【已查证】http://www.cse.buffalo.edu/~shapiro/Papers/anchoring.pdf ；https://www.frontiersin.org/articles/10.3389/frobt.2020.00100/full
**2025-26 形式化尝试**：符号接地的逻辑极限研究（"纯符号失败平凡、静态接地不完备"）。【已查证】https://arxiv.org/html/2509.20409

**阙疑接地检测（设计对象）**——规则中每个术语（"内存屏障""序列点""未定义行为"）必须有**接地路径**：

| 接地类型 | 阙疑实例 | 强度 |
|---|---|---|
| 感知/执行接地 | 在编译器/硬件上实际运行观察到的行为 | 最强 |
| 规范文本接地 | 标准条款精确引用（编号+版本） | 强 |
| 测试接地 | 可复现的用例（能触发该术语指称的现象） | 强 |
| 引用链接地 | 只引用其它术语（"X 是 Y 的一种"） | **弱——纯符号循环** |

**检测方法（接地链检查）**：对规则中每个术语沿引用链回溯——终止于"执行/规范文本/测试"者接地成立；形成闭环（A 依赖 B、B 依赖 A）者**未接地**（中文字典问题的工程检出）。输出：**接地覆盖度 = 有接地路径的术语数 / 总术语数**。
**寄生语义警告（Harnad 问题的阙疑版）**：阙疑的语义今天主要寄生于人类维护者头脑（"我们知道'内存屏障'什么意思"）；**AI 生成规则时这条寄生链断裂**（AI 无接地基础）⟹ 接地检查必须作为 AI 生成内容的强制前置——与 A 方向 ProofObject 的 `evidence_tree` 合流（evidence_tree 正是接地路径的记录格式）。

### G-4 概念隐喻：隐喻如何影响理解与验证

**Lakoff-Johnson 1980（精确表述）**：隐喻的本质是"**用一种事物理解和体验另一种事物**"（understanding and experiencing one kind of thing in terms of another）；隐喻是**源域到目标域的系统映射**，是思维机制而非修辞装饰。【已查证】https://mikeydoes.com/glossary/conceptual-metaphor/ ；https://pdfs.semanticscholar.org/7b4e/08fd19802c88972cd225e39bec6bb3dff1ee.pdf
**科学隐喻的双刃**：theory-constitutive metaphor 传统（隐喻可构成理论内容）vs 误导风险（天体物理术语"从引人入胜到误导"）。【已查证】https://amazoniainvestiga.info/index.php/amazonia/article/download/1777/2084?inline=1

**技术债隐喻的完整解剖（Metaphorex，作为隐喻审计的范本）**：
- **Transfers（成立部分）**：利息随时间复利；借未来收入支持当下行动；破产 = 利息支付超过服务能力。
- **Limits（失效部分）**：① **"财务债有可量化的本金和利率，代码捷径没有可聚合的测量单位"**（无单位可加总）；② **"债暗示有债权人要求偿还，但没有外部方强迫团队重构"**（无债权人）；③ **"还债产生解脱感，重构很少提供可比回报时刻"**（无清偿时刻）。【已查证】https://www.metaphorex.org/entries/technical-debt/ ；技术债隐喻史（Ward Cunningham 1992，专为与非技术利益相关者沟通而造）【已查证】https://www.infoq.cn/article/managing-technical-debt

**阙疑的隐喻审计（v25 新增纪律）**：阙疑自身使用大量隐喻（"逃逸""自身免疫""毒样例""豁免""死亡漩涡"）——每个隐喻必须做同样的 Transfers/Limits 分解：
- **"自身免疫"的 Limits**：生物免疫有克隆选择（抗体自行变异优化），阙疑规则不会自变异；器官有再生修复，卡片不会自愈——**过度延伸会误以为系统能自修复**。
- **"逃逸"的 Limits**：军事逃逸有**意图主体**（敌人会适应性对抗），错误大多是无主体的自然过程——**用"敌人在适应"框架思考分布漂移会导致过度归因**（F 方向"威胁框架"的镜像警告）。
- **纪律（写成不变量）**：隐喻只能出现在解释性文本与发现阶段，**不得进入验证判据**——判据必须是可计算量（MDL/D 方向、ECE/C 方向）。审计时检查判据文本中是否含隐喻词表。

### G-5 私人语言与规则遵循 → 验证的公共性

**私人语言论证（Wittgenstein PI §243-）**：只为一个人理解的语言不融贯；**规则不能被"私下遵循"**——因为私下无法区分"遵守规则"与"自以为遵守规则"；规则需要公共标准与持续的共同实践。【已查证】https://handwiki.org/wiki/Philosophy:Private_language_argument
**形式语义的对照**：denotational semantics 以 `〚·〛`（"denotation of"）把语法对象映射到数学对象（意义=映射的像）；operational semantics 以"程序怎么运行"定义意义；两者分离（"是什么" vs "做什么"）。【已查证】http://users.csc.calpoly.edu/~gfisher/classes/530/lectures/4.html ；https://academicweb.nd.edu/~dchiang/teaching/pl/2025/semantics.html
**阙疑推论**："这条卡对不对只有我知道怎么判"是私人语言问题——**验证标准必须公共可执行**（第三方独立执行得同一结果）。这与 A 方向 de Bruijn 判据（可独立重查）、F 方向 Dror 独立复核**三路合流到同一原则：验证是公共行为**。另外，"为卡片定义 〚·〛"（映射到可判定语义对象）与 A-1 的"降级到可判定片段"是同一动作的两种表述——语言学与判定论在此互为镜像。

## 二、阙疑重构草图

### 2.1 对象模型（新增四对象）

- **MeaningProfile**：每卡双分——真值条件（边界 B + 命题）+ 使用角色（消费者/触发者清单）；
- **FelicityCheck**：适切条件三件套（检查器可信状态 / 边界新鲜度 / 审查合规记录）；
- **GroundingReport**：术语接地图（接地路径 + 未接地清单 + 覆盖度）；
- **MetaphorAudit**：隐喻清单 + Transfers/Limits 分解 + 判据污染检查。

### 2.2 数据流

```
卡片 → [术语接地检查]（未接地 ⇒ 阻断）→ 验证（A 方向）→ [适切条件检查]
    → 通过（制度性行为）⇒ verified 地位（带边界 B + 承诺语义）
    → [使用角色登记]（消费者清单；孤儿卡 ⇒ 告警队列）
    → 台账
离线：[MetaphorAudit]（隐喻分解 + 判据污染扫描）——不进判据
```

### 2.3 关键不变量

- **INV-G1（接地前置）**：含未接地术语的规则不得进入生产；术语须回溯到规范文本/执行观察/测试之一。
- **INV-G2（适切条件）**：pass 生效须满足三件（检查器可信、边界新鲜、审查合规）；不满足时记"**不生效**"（区别于"无效"——保留记录、修复条件后可复议）。
- **INV-G3（使用角色）**：每张 verified 卡必须登记消费者；孤儿卡进告警队列。
- **INV-G4（隐喻不入判据）**：隐喻仅限解释文本与发现阶段；判据须为可计算量（扫描判据文本中的隐喻词表）。
- **INV-G5（公共可执行）**：每条规则必须能被第三方独立执行；私人知识不得作为规则（个人语言论证的工程化）。

## 四、迁移路径（现有规则与卡片过渡）

- **阶段 0（术语盘点）**：从 67 规则提取术语清单，人工标注接地状态（规范条款/测试/纯引用）——纯调查，产出首版接地覆盖度。
