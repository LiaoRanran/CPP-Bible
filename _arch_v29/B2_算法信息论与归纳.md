# 方向 B2：算法信息论与归纳

> 核心问题：**"简单""随机""学到了"如何被精确地量化？归纳的通用最优解是什么？** 对应阙疑"规则集质量度量"与"学习先验"。
> 检索：15 次（Kolmogorov 不变性、Solomonoff 归纳、MDL、Martin-Löf 随机、Chaitin Ω、NCD、Bennett 逻辑深度、算法概率、MDL-Occam、Kolmogorov-ML、Levin 搜索、压缩-泛化、sophistication、AIT 综述、逻辑深度-知识价值）。
> 边界：v25 已提 MDL，本轮**深挖数学基础**；与 B1 不可判定、C1 统计学习不重复。

## 一、核心概念清单（≥10 条）

- **Kolmogorov 复杂度 K(x)**：字符串 x 的最短描述（程序）长度。不变性定理保证换通用机只差 O(1) 常数，使其成良好度量；但**本身不可计算**（见 B1）。
- **Solomonoff 归纳 (1964)**：基于 K(x) 定义**通用先验**——假设的可信度 ∝ 2^(-K(假设))。在所有可计算分布上**最优**（误差界只差常数倍），是"贝叶斯 + 奥卡姆"的算法化。
- **最小描述长度（MDL, Rissanen 1978）**：选使"模型描述长度 + 数据在模型下编码长度"最小的模型——把奥卡姆剃刀变成可操作算法；与贝叶斯、两阶段编码等价。
- **Martin-Löf 随机性**：一个序列是随机的，当且仅当它通过对所有可计算统计检验（随机性测试）。与"不可压缩"（K(x)≈|x|）和"不可预测"三种刻画等价。
- **Chaitin 常数 Ω**：通用机停机概率，是一个具体不可计算的实数，且算法随机——蕴含不可判定性的信息论形式。
- **归一化压缩距离（NCD）**：用通用压缩器近似 K，定义 NCD(x,y)= (C(xy)-min(C(x),C(y)))/max(C(x),C(y))，用于聚类/相似性（"压缩即相似"）。
- **Bennett 逻辑深度（1988）**：一个对象的复杂度=从其最短描述生成它所需的**计算时间**。区分"简单随机"（如全 0）与"深层有序"（如生命、知识）——深度度量"蕴含的计算量"。
- **算法概率 / 通用分布**：Solomonoff 通用分布 μ(x)=Σ 2^(-|p|) over p 输出 x；是所有可计算分布的通用混合，预测最优。
- **Levin 通用搜索 (1973)**：对一大类问题，时间开销只比最优算法慢一个**可乘常数**（非指数）——理论最优但常数巨大，实际无用，但揭示"最优搜索"的极限。
- **压缩-泛化连接**：近年工作（如"监督学习即有损压缩"）把泛化误差与压缩率挂钩；MDL 给出表示学习泛化保证（NeurIPS 2023）。
- **Sophistication（精妙度, Koppel）**：Kolmogorov 结构函数把最短程序拆成"有用模型 + 残差"，衡量对象中**有意义的规律量**，区分随机噪声与深层结构。
- **AIT 经典教材**：Li & Vitányi *An Introduction to Kolmogorov Complexity* 是领域圣经。

## 二、对阙疑的映射（全标【类比推断】）

- **Kolmogorov → "规则集的最小描述长度"作为规则质量度量【类比推断】**：阙疑的自我进化要评判"规则集是否变得更精简"。K(x)（不可算但可近似）提供理论靶——好的规则集应能以更短的程序/更少比特描述同一验证行为；可用 gzip/NCD 近似监控规则集"体积"是否膨胀。
- **Solomonoff → 攻击分布的通用先验【类比推断】**：v21/v23 的攻击分布是未知先验。Solomonoff 通用先验 2^(-K(h)) 是"对所有可计算攻击模型的最优加权"——阙疑的防御调度可按"假设越短（越简单）越先验可信"分配验证资源，是奥卡姆式防御预算分配。
- **MDL → 规则选择的奥卡姆准则【类比推断】**：新规则是否被采纳，应按 MDL——"规则描述成本 + 它带来的误报/漏报编码节省"最小才接受。这把 v25 CalibrationTracker 的"规则是否值得保留"变成可计算（近似）准则，避免规则无限膨胀。
- **Martin-Löf 随机 → "彻底随机的攻击无法被规律捕捉"【类比推断】**：若攻击序列是 Martin-Löf 随机的（无规律），则任何规则（可计算测试）都无法比随机猜更好——提示阙疑对纯随机攻击只能靠覆盖率硬扛，不可指望"学出规律"。
- **逻辑深度 → "知识的价值=生成它的计算量"【类比推断】**：阙疑积累的知识（规则、判例、误解图）是有"逻辑深度"的——它们由大量验证/试错计算压缩而来。深度高的知识比浅层规则更值钱，应优先保护、复用；对应 v25 Ledger 中"经验资产"的估值。
- **Levin 搜索 → "最优但常数巨大"的警示【类比推断】**：理论上存在对所有验证问题近最优的搜索，但常数大到不可用。阙疑不要追求理论最优搜索，而用启发式（如 v21 的 AISI 式调度）换实际可行。
- **NCD → 规则/卡片语义相似性度量【类比推断】**：阙疑 65 条 object 语义审查、W2 命题-误解图，可用 NCD（基于压缩）度量两张卡片是否"语义相近/冗余"，帮助去重与聚类，呼应 v25 冲突检测。
- **Sophistication → "有意义规律 vs 噪声"的判别【类比推断】**：阙疑从经验中提炼规则时，应区分真正的精妙结构（sophistication 高）与偶然拟合（随机残留），避免把噪声当规律写入规则集。

## 三、净新增（v21-v28 没有的洞察，≥3 条）

1. **MDL 给"规则取舍"一个可操作数学准则**：v25 只说"监控规则质量"，本轮给出具体判据——接纳规则当且仅当它降低总描述长度（模型+残差），直接对抗规则膨胀。
2. **逻辑深度把"知识价值"量化**：阙疑沉淀的经验资产可按生成所需计算量估值，深者优先复用/保护——这是之前轮次未触及的"知识经济学"。
3. **Solomonoff 先验给出防御预算分配的奥卡姆基础**：越简单的攻击假设先验越重，阙疑可按规则/假设的 K 长度排序分配验证算力。
4. **Martin-Löf 随机划出"规律可学"的硬边界**：纯随机攻击不可被任何规则捕捉，阙疑须接受此类攻击只能靠覆盖硬抗。

## 四、设计原则（1-2 条，可操作）

- **D-B2-1：规则集采用 MDL 采纳准则**——新规则/新假设仅当其使"规则描述长度 + 残差编码长度"下降才入集；用 gzip 近似 K 做日常监控，防止规则无限膨胀。
- **D-B2-2：按假设简洁度分配验证预算**——越短（越简单）的攻击假设/规则先验权重越高，优先验证与保留；深层知识（高逻辑深度）优先复用。

## 五、失败教训与死路（≥5 条）

- **Kolmogorov 复杂度不可计算（B1 已证）**：只能近似（压缩器/NCD），近似有偏差且依赖压缩器选择——阙疑不能把 K 当精确优化目标。
- **MDL 编码选择主观**：不同通用机/压缩器给出不同描述长度，MDL 结论对编码敏感；阙疑用 MDL 须固定编码标准并标注主观性。
- **Solomonoff 不可计算且常数巨大**：通用先验涉及对所有程序求和，实际不可算；只能取其近似（如短的、可枚举假设），不能当真实先验跑。
- **Levin 搜索理论最优但不可用**：常数倍最优掩盖了天文数字的常数，阙疑不可寄望通用搜索解决验证调度。
- **Martin-Löf 随机攻击不可学**：对真正随机的对抗，任何规则都无优于随机的表现；阙疑须接受"覆盖率硬扛"而非"学出规律"。
- **NCD 依赖压缩器质量**：弱压缩器（如 gzip）在语义层面近似粗糙，NCD 用于语义聚类可能失真，需更强语义编码器。
