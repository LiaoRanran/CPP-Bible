## 二、跨方向收敛的核心洞察（≥5 条）

1. **"自我进化"在数学上受三重约束**：C1 可学习性（部分不可判定）+ C2 偏置必要性（NFL）+ C4 灾难性遗忘——进化不是"越学越强"的直线，而是"偏置引导 + 抗遗忘 + 不可判定残留"的螺旋。
2. **对抗环境须弃 i.i.d./期望效用，改用在线+minimax**：C1 非平稳在线学习 + C3 minimax 遗憾 + C3 鲁棒决策三路合流——阙疑在自适应攻击下，决策准则应是"最坏遗憾最小 + 分布鲁棒"，而非历史分布最优。
3. **偏置是进化的隐形骨架，须显式化与可回退**：C2 指出任何学习都押注结构假设；阙疑的 v20 object 语义、v25 框架即架构偏置，应列为清单，失配即降级（呼应 C2 负迁移红线）。
4. **Ledger 判例=经验回放缓冲，双记忆=快/慢整合**：C4 把 v25 已有资产转化为抗遗忘机制——新规则校准混入历史判例，并设快存/慢整合双通道，是"越用越强"的可行形态。
5. **人审是有限理性满意解者，需去框架化与偏误清单**：C3 揭示人审受损失厌恶/框架效应/经验-描述鸿沟污染；阙疑须把人审当"需防护的有限理性 agent"，而非完美 oracle（呼应 B1 把人审建模为 oracle 但标其局限）。
6. **校准退化的根因是分布偏移 + 灾难性遗忘**：C1 偏移 + C4 遗忘共同解释 v23 的"校准为何会烂"——必须持续重校准 + 抗遗忘双保险。

## 三、对阙疑 642+ 的设计建议（排序）

1. **进化按 C1 在线无遗憾 + C3 minimax 遗憾决策**：防御调度用 multiplicative weights 类，判决阈值取最坏遗憾最小且损失不对称（漏报>>误报）。
2. **建立显式归纳偏置清单（C2）并设失配降级**：把领域先验列为可审表，偏置错配即回退更弱偏置。
3. **抗遗忘架构（C4）：双记忆 + 回放 + 重要性锁定**：Ledger 判例作回放，关键旧规则设重要性保护，新攻击族可加模块不覆写。
4. **人审去框架化 + 偏误清单（C3）**：统一呈现、强制反对意见、对照确认/可得性偏误复核。
5. **持续重校准对抗分布偏移（C1+C4）**：检测攻击分布漂移即触发重校准，防静态校准慢性失效。
