# 方向 D2：科学哲学

> 核心问题：**阙疑"越用越聪明"本质是一场科学实践——它的"理论（规则）"该如何被证伪、进化、承认不可通约？** 对应阙疑"自我进化 + 反思 + 元治理"。
> 检索：15 次（库恩范式转移、波普证伪、拉卡托斯研究纲领、费耶阿本德怎么都行、科学实在论、奎因-迪昂整体论、不可通约、女性主义认识论、社会认识论、归纳问题、精致证伪、可重复危机、科学中的价值、科学多元主义、贝叶斯确证）。
> 边界：v24 已提拉卡托斯/波普尔/Gettier，本轮**补全科学哲学全谱系**；与 D1 知识表示、B4 逻辑不重复。

## 一、核心概念清单（≥10 条）

- **库恩《科学革命的结构》(1962)**：科学非累积而是"常规科学（范式内解谜）→ 反常累积 → 危机 → 革命（范式转移）"。范式（paradigm）是共同体共享的"世界观+工具+标准"。
- **波普证伪主义**：理论不能被证实只能被证伪；科学靠"大胆猜想+严厉试错"（conjectures and refutations）。可证伪性是科学与非科学的划界。
- **拉卡托斯研究纲领（1970）**：硬核（不可否证的内核）+ 保护带（可调整的辅助假设）+ 启发法。纲领分"进步的"（有新预测被证实）与"退化的"（只能事后补救）。是对波普的精致化。
- **费耶阿本德《反对方法》(1975)**："怎么都行（anything goes）"——无普适科学方法，进步靠多元、甚至违背规则；对方法垄断的 anarchism 批判。
- **科学实在论 vs 反实在论**：理论中的不可见实体（如电子）是否"真实存在"？反实在论质疑"推论到最佳解释"。
- **奎因-迪昂论题（整体论/不充分决定性）**：理论不能单独被证据检验，而是与整个信念网一起；同一证据可支撑多个理论——单个规则无法被单条反例孤立证伪。
- **不可通约性（Incommensurability）**：不同范式的概念/标准不可直接比较，科学家"不可相互理解"；meaning variance 使跨范式比较困难。
- **女性主义认识论/立场论**：知识受社会位置（性别等）影响；主张"情境知识"(situated knowledge) 与"强客观性"(strong objectivity，Harding)——多元视角提升客观性。
- **社会认识论**：知识是社会性地生产/组织的，求真依赖制度设计（如同侪评审、Open Science）；认识主体是复数。
- **归纳问题（休谟）**：从"过去常如此"推"未来必如此"无逻辑辩护；波普以演绎证伪回避，但仍未彻底解决。
- **可重复危机（Replication Crisis）**：心理学等大量结果无法复现，催生 preregistration、Open Science；哲学上质疑"可重复是否真能支撑认知权威"。
- **科学中的价值（非认知价值）**：理论选择不仅靠证据，也受社会/伦理/实用价值影响（如安全优先）；"价值无涉理想"受挑战。
- **科学多元主义**：某些现象需多个互补理论；合法地允许多理论并存，而非追求单一范式。
- **贝叶斯确证理论**：证据 e 确证 H 当 P(H|e)>P(H)；把"确证"当概率更新——对应阙疑的 Bayesian 校准（呼应 C3）。

## 二、对阙疑的映射（全标【类比推断】）

- **库恩范式 → 阙疑的"v 版本世界观"即范式【类比推断】**：v21-v28 每一版（v19-v28）是阙疑的"常规科学"阶段，在 v20 的 65 条 object 本体（D1）这一"范式"内解谜。重大重构（如 v21 信任根独立革命）即"范式转移"。这给阙疑历史一个元叙事：进化不是线性，而是范式内累积+偶发革命。
- **波普证伪 → "反例即进化的燃料"【类比推断】**：v25 的击败器台账/反例正是阙疑的"证伪事件"。阙疑应主动寻求证伪（如对抗性攻击生成），而非只收集确认——波普提醒"确认不增信、证伪才推进"。对应 v21 AISI 的攻击生成即"主动试错"。
- **拉卡托斯研究纲领 → 规则集的"硬核+保护带"结构【类比推断】**：阙疑的硬核=信任根独立等不可动摇原则；保护带=具体规则、校准参数（可调整）。当某规则被反例击破，应先调保护带（改规则）而非否证硬核。进步/退化判据提示：若阙疑只事后打补丁而无新预测能力，即"退化纲领"，须警惕。
- **费耶阿本德 → "元治理"应允许多元试探【类比推断】**：v26 元治理若只守一套方法会僵化。费耶阿本德暗示：阙疑自我进化应允许"异端"规则/非常规验证路径并行试探，用结果而非教条筛选——但须设安全边界（呼应 v21 不可越界）。
- **奎因-迪昂 → 单条反例不能孤立否证一条规则【类比推断】**：阙疑规则不是孤立假说，而是嵌在"本体+语义框架+其他规则"整体中。一条反例可能意味着保护带错而非规则错——提醒 v25 冲突检测须做"定位归责"（ErrorFlow），而非机械删规则。
- **不可通约 → 范式转移期"新旧规则不可直接比较"【类比推断】**：v21 革命后，旧版规则与新版语义可能不可通约（meaning variance），直接对比误报率会失真。须重定义度量基线，而非硬比。
- **女性主义/强客观性 → 多验证者即"多元立场增强客观性"【类比推断】**：Harding 的强客观性主张边缘视角提升客观。阙疑 A3 多验证者、v23 人审，正是用多元立场（机+人、异质验证者）对抗单点偏差，符合"多元提升客观"的哲学。
- **社会认识论 → 阙疑的治理是"知识生产制度"【类比推断】**：v26 元治理本质是社会认识论的制度设计——同侪评审类比人审、Open Science 类比 Ledger 公开可审计、preregistration 类比规则预先注册防事后篡改。
- **可重复危机 → 阙疑须"可重复验证"防自欺【类比推断】**：阙疑若只报"某次验证通过"而无可重复记录，会陷入可重复危机式自欺。Ledger + provenance（A1）正是"可重复+过程留痕"的解药。
- **科学中的价值 → "安全优先"是非认知价值【类比推断】**：C3 的损失不对称（漏报>>误报）本质是"安全"这一非认知价值主导理论选择——科学哲学承认价值合法介入，阙疑可正名"安全优先"为刻意的价值选择而非偏置。
- **贝叶斯确证 → 校准的确认逻辑【类比推断】**：C3 贝叶斯决策 + D2 贝叶斯确证同源；阙疑"证据提升某卡片置信"即 P(H|e)>P(H) 的更新，把验证器当确证机器。
- **科学多元主义 → 允许多验证范式并存【类比推断】**：阙疑不必强求单一验证范式，可并存静态分析/动态/语义/人审多"理论"，对复杂对象互补覆盖。

## 三、净新增（v21-v28 没有的洞察，≥3 条）

1. **阙疑历史是"库恩式范式演化"而非线性累积**：v19-v28 的跃迁有了元叙事框架，重大重构=范式转移，旧版规则需用新基线重评（不可通约）。
2. **拉卡托斯"硬核/保护带"给出规则集的结构化防御**：被反例击破时优先调保护带而非否证硬核，并提供"进步/退化纲领"自诊断。
3. **可重复危机直接对应阙疑的"自欺风险"**：Ledger+provenance 是科学可重复性在工程上的解药，赋予 v25 Ledger 以科学哲学正当性。
4. **"安全优先"可被正名为合法的非认知价值**：不必为损失不对称辩护为"偏置"，而是科学哲学承认的价值介入。

## 四、设计原则（1-2 条，可操作）

- **D-D2-1：规则集按硬核+保护带组织，设进步/退化自诊断**：信任根独立等为硬核不可动；具体规则/参数为保护带可调整；定期评"是否仍产出新预测/新覆盖"，退化即触发重构。
- **D-D2-2：以可重复+多元立场对抗自欺**：所有 VerificationRun 强制 Ledger 留痕（过程+工具+commit），多异质验证者交叉，防可重复危机式自欺。

## 五、失败教训与死路（≥5 条）

- **把"确认"当"证明"（波普）**：阙疑若只收集通过案例会自我麻痹；必须主动寻求证伪（对抗攻击）。
- **单反例机械删规则（忽视奎因-迪昂）**：反例可能源于保护带/语义框架错，须归责而非盲目删规则。
- **范式转移后硬比旧指标（不可通约）**：新版语义变后，旧误报率基线失真，须重建度量。
- **元治理教条化（反费耶阿本德）**：只守一套方法会退化；须允许多元试探但有安全边界。
- **可重复缺失致自欺**：无 Ledger 留痕则无法复现验证，重蹈可重复危机。
- **把"安全优先"误当偏置而羞于声明**：科学哲学承认非认知价值合法，阙疑应正名而非遮掩。
