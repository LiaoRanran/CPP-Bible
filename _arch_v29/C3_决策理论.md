# 方向 C3：决策理论

> 核心问题：**在不确定下，阙疑的"开火/不开火/升级人审"究竟应按什么准则做？人审与人类判断又有哪些系统性偏误？** 对应阙疑"判决策略 + 人审偏误治理"。
> 检索：15 次（期望效用 vNM、前景理论、Ellsberg 模糊厌恶、minimax 遗憾、贝叶斯决策、多臂老虎机、有限理性满意解、框架效应、经验vs描述决策、MDP、均值方差、处方分析、鲁棒决策、认知偏误、Knight 风险/不确定性）。
> 边界：v23 已提软警报/校准，本轮**补决策准则与偏误**；与 C1 在线学习、A3 共识不重复。

## 一、核心概念清单（≥10 条）

- **期望效用理论（vNM, 1944）**：在独立性等公理下，理性agent 应选期望效用最大化的行动；是规范决策（normative）的基准。
- **前景理论（Kahneman-Tversky, 1979）**：描述性（descriptive）理论——人围绕参考点评估**变化**、**损失厌恶**（loss aversion，同等损失比收益感受更重）、对概率非线性加权。挑战 vNM 的规范性。
- **风险 vs 不确定性（Knight, 1921）**：风险=概率可量化；不确定性（Knightian）= 概率不可知。阙疑面对的攻击多属后者。
- **Ellsberg 悖论（模糊厌恶）**：人在已知概率（风险）与未知概率（模糊）间系统性偏好前者，违背主观期望效用——决策者对"未知的不确定性"极度厌恶。
- **minimax 遗憾（Savage, 1951）**：选使"最坏情况下的遗憾（机会损失）"最小的行动，而非最坏损失——更稳健的不确定性决策准则。
- **贝叶斯决策理论**：在状态后验 p(state|data) 与损失 λ(action|state) 下，选期望损失最小的行动；把"不确定"用概率显式建模。
- **多臂老虎机（MAB）与探索-利用权衡**：ε-greedy / UCB / Thompson Sampling 在序贯中平衡"试新"与"用已知最优"——是防御调度、攻击生成的天然模型。
- **有限理性与满意解（Bounded Rationality / Satisficing, Simon）**：人非完全理性，受信息、算力、时间限制，取"够好"而非"最优"——阙疑的人审决策正是此模型。
- **框架效应（Tversky-Kahneman, 1981）**：同一问题不同表述引发不同决策——阙疑向人审呈现"命中/误报"的方式会系统性影响判断。
- **经验 vs 描述决策（Description-Experience Gap, Hertwig）**：从描述得概率 vs 从自身体验学得，对稀有事件权重不同——人审基于"见过多少案例"会误判稀有攻击。
- **MDP 与序贯决策（Bellman）**：状态-动作-奖励下的序贯最优，是 AISI 自适应验证的框架。
- **均值-方差（Markowitz）**：仅用均值与方差刻画风险偏好，简化决策——阙疑可在"误报率均值+方差"上做权衡。
- **鲁棒决策（Robust / DRO）**：在不确定性集合（uncertainty set）上取最差情形最优，而非点估计——对抗分布偏移（呼应 C1）。
- **认知偏误与启发式（Kahneman 双系统）**：可得性、锚定、确认偏误等系统性偏差——人审的主要污染源。

## 二、对阙疑的映射（全标【类比推断】）

- **minimax 遗憾 → 阙疑判决的稳健准则【类比推断】**：阙疑不能假设攻击分布已知（Knightian 不确定性）。与其用期望效用（需准概率），不如用 **minimax regret**——选使"最坏误报/漏报损失"最小的策略。这给 v23 的"开火阈值"一个不依赖精确概率的稳健准则。
- **贝叶斯决策 → 把校准器当损失函数【类比推断】**：v23 的 CalibrationTracker 本质是贝叶斯决策：给定后验"此卡为真的概率"与损失（误报 vs 漏报不对称），选期望损失最小动作（开火/人审）。损失函数应设成**漏报（安全漏洞）代价 >> 误报（打扰）**，即损失厌恶式不对称。
- **前景理论/损失厌恶 → 人审的"怕漏报"偏置可利用【类比推断】**：人审天然损失厌恶（怕放过真 bug 比怕误报更难受）。阙疑可利用此设计：把"不开火"的框架设为"你将为漏报负责"，比"开火"更易触发谨慎——但须防反向的过度开火（见失败教训）。
- **Ellsberg 模糊厌恶 → 对未知攻击的保守【类比推断】**：人审对"新型攻击（概率未知）"会极度保守甚至拒绝判断。阙疑应把"未知攻击"显式路由到多验证者/人审，而非让单点压注。
- **框架效应 → 人审面板的呈现设计【类比推断】**：v23 人审队列的呈现方式（"已命中 X 次" vs "可能漏报 Y 次"）会改判断。应统一、无偏的呈现规范，避免框架操纵。
- **经验-描述鸿沟 → 稀有攻击的人审误判【类比推断】**：人审若只见过少量某类攻击，会系统性低估其概率（描述-经验鸿沟）。阙疑须用统计（而非人审直觉）做稀有事件校准，人审只做定性。
- **MAB → 攻击生成/验证调度的探索利用【类比推断】**：阙疑的"先生成哪些攻击、先验证哪些规则"是 MAB——用 Thompson Sampling 平衡"试新攻击模式"与"用已知高效验证"，对应 v21 AISI 的自适应。
- **有限理性满意解 → 人审不应追求最优【类比推断】**：v23 人审是有限理性agent，阙疑不应期望其输出"最优判决"，而应设计"够好且可复核"的满意解流程，降低认知负荷。
- **鲁棒决策 → 抗分布偏移的判决【类比推断】**：C1 指出攻击会漂移。阙疑判决准则应在"最坏分布"上仍稳健（DRO），而非只在历史分布最优——与 C1 鲁棒学习呼应。
- **Knight 风险/不确定性 → 阙疑的两层判定【类比推断】**：对可量化风险（已知类型误报率）用概率决策；对不可知不确定性（新型攻击）用 minimax/保守路由——区分两层是判决架构关键。
- **认知偏误 → 人审治理清单【类比推断】**：v23 人审需显式对抗确认偏误、可得性偏误（如近期案例权重过大），应在流程中设"反对意见必填"等机制。
- **均值-方差 → 误报率的风险刻画【类比推断】**：阙疑可用均值-方差框架管理软警报率：不只看平均误报，还看其波动，对高波动源更保守。

## 三、净新增（v21-v28 没有的洞察，≥3 条）

1. **minimax regret 提供不依赖精确概率的稳健判决准则**：阙疑面对 Knightian 不确定性，不必硬估攻击概率，直接用最坏遗憾最小化定阈值。
2. **损失不对称是校准的核心旋钮**：漏报代价应设远高于误报（安全优先），这把 v23 的"软警报率"从经验调参变成有理论依据的偏好设定。
3. **人审是有限理性满意解者，需流程减负与偏误清单**：不再把人审当完美 oracle，而是需要框架防护的有限理性agent。
4. **描述-经验鸿沟解释人审对稀有攻击的系统性低估**：必须用统计而非人审直觉处理稀有事件。

## 四、设计原则（1-2 条，可操作）

- **D-C3-1：判决用 minimax-regret + 不对称损失**：硬开火阈值按"最坏遗憾最小"设定，且漏报损失 >> 误报损失；未知攻击一律路由多人审。
- **D-C3-2：人审需去框架化 + 偏误清单**：统一无偏呈现，强制"反对意见必填"，并对照确认/可得性偏误清单复核，避免有限理性陷阱。

## 五、失败教训与死路（≥5 条）

- **期望效用需准概率，阙疑常不满足**：vNM 要求已知概率，而攻击多属 Knightian 不确定性，直接套期望效用会高估确定性。
- **损失厌恶反向下溢为过度开火**：利用人审怕漏报可能致"凡疑即报"，淹没人审；须设误报成本防滥用。
- **框架效应可操纵人审**：呈现方式不慎会系统性偏置判决，须标准化呈现。
- **经验-描述鸿沟致稀有事件误判**：人审基于少量案例会低估稀有攻击，不能把稀有事件判断交给人审直觉。
- **MAB 探索成本**：过度探索（试低效攻击）浪费验证算力；须控制探索率。
- **有限理性者做不出最优**：指望人审"完美判决"不现实，流程须为满意解而非最优设计。
