# 方向 B4：逻辑学

> 核心问题：**如何用更丰富的逻辑形式刻画"应当/可能/时间/知识/可废止"——从而让阙疑的判决与规则更精确地表达？** 对应阙疑"规则是规范而非事实、判决可被新证据推翻、时间有效性"。
> 检索：15 次（模态逻辑 Kripke、时态逻辑 LTL/CTL、道义逻辑、非单调/缺省推理、相干逻辑、多值/模糊逻辑、可废止推理、次协调逻辑、直觉主义逻辑、认知逻辑、可证性逻辑 GL、答案集编程、情境演算、公共知识、动态逻辑）。
> 边界：v24 已提 Gettier/拉卡托斯/波普尔，本轮**补形式逻辑工具箱**；与 D2 科学哲学、D4 数学基础不重复。

## 一、核心概念清单（≥10 条）

- **模态逻辑与 Kripke 语义**：在可能世界 W + 可达关系 R 上定义必然 □/可能 ◇。是道义、时态、认知、动态逻辑的通用框架（Kripke 1963）。
- **时态逻辑（LTL/CTL/CTL*）**：LTL 线性的"最终/一直/直到"；CTL 分支时间的"存在/所有路径"；是模型检测（A3）的规格语言（Clarke/Emerson/Sifakis）。
- **道义逻辑（Deontic Logic）**：规范模态——应当 O、允许 P、禁止 F。用于规范推理、多智能体规范系统；"counts-as"构成性规范。
- **非单调逻辑与缺省推理（Reiter, 1980）**：新信息可撤回旧结论（闭世界假设、缺省）。是常识/可废止推理的形式基础。
- **相干逻辑（Relevance Logic）**：要求前提在结论中实际被使用，避免经典实质蕴涵悖论（"假命题推出一切"）。属次协调逻辑分支。
- **多值逻辑与模糊逻辑（Łukasiewicz, Zadeh）**：真值不止真假，模糊逻辑用 [0,1] 连续度处理"边界状况"与连锁悖论（sorites）。
- **可废止推理（Defeasible Reasoning, Pollock）**：结论随新信息可被放大或撤回；是人工智能中论证（argumentation）的理论根源。
- **次协调逻辑（Paraconsistent Logic）与双面真理论**：拒绝"爆炸原理"（ex contradictione quodlibet），允许矛盾存在而不推出一切；dialetheism 主张某些矛盾为真。
- **直觉主义逻辑（BHK 解释）**：拒绝排中律，证明即构造（呼应 A2 Curry-Howard、B3 依赖类型）；是构造数学的核心。
- **认知逻辑（Epistemic Logic）**：K"知道"、B"相信"、分布式知识、公共知识；基于 Kripke 多主体认知模型。
- **可证性逻辑（GL, Gödel-Löb）**：□ 表示"在算术中可证"，Löb 公理 □(□A→A)→□A；Solovay 定理给出算术可证性的完备刻画。
- **答案集编程（ASP, Gelfond-Lifschitz）**：声明式逻辑编程，基于稳定模型语义，适合 NP-难组合搜索（如配置、调度）。
- **情境演算（Situation Calculus, McCarthy）**：用 situation 表示动作与状态变化，推理动作后果；是行动推理经典框架。
- **公共知识逻辑（Fagin-Halpern-Moses-Vardi）**：公共知识（everyone knows that everyone knows...）是协调/协议的必要条件，但实践中难以真正达成（公共知识悖论）。
- **动态逻辑（PDL, Harel-Kozen-Tiuryn）**：模态逻辑的"程序"扩展，推理"执行程序后性质是否成立"，是 Hoare 逻辑的前驱。

## 二、对阙疑的映射（全标【类比推断】）

- **道义逻辑 → "规则是规范而非事实"的形式化【类比推断】**：阙疑的规则应是"应当/允许/禁止"而非"事实陈述"。O/P/F 模态让规则显式区分"规范约束"与"经验断言"，避免把 v25 Rule 误当成客观真理——这是 v21 规则语义精确化的逻辑底座。
- **非单调/可废止 → "新证据可推翻旧判决"的逻辑基础【类比推断】**：v25 的 ConflictDetector/击败器台账本质是"旧判决被新证据击败"。非单调逻辑给出严谨形式：阙疑的判决应是缺省结论，遇反例（counterexample）即撤回，而非经典逻辑式的永久成立。
- **时态逻辑 → "规则在时间维度上的有效性"【类比推断】**：v21 规则有生命周期（Lifecycle）。时态逻辑让"规则在 t 时刻生效/失效""某性质最终须成立"可形式化，作为规则时效性的规格语言。
- **次协调逻辑 → "系统含矛盾但不崩溃"的容错【类比推断】**：阙疑在自我进化中可能暂时持有互相冲突的规则/判例。次协调逻辑允许在不触发爆炸的前提下保留矛盾、局部处理，比经典逻辑更适合"未收敛"的进化中系统。
- **相干逻辑 → "判决须基于相关前提"【类比推断】**：v27 关注错误归因；相干逻辑强制判决的每个前提实际被使用，防止"无关前提推出判决"的虚假论证，提升 v25 ErrorFlow 归因质量。
- **认知逻辑 → "多验证者知道/相信什么"的建模【类比推断】**：A3 多验证者的"共识"可用认知逻辑的分布式/公共知识刻画——何时达成公共知识、何人知道何人知道，是判决聚合（v22 多验证者）的形式化工具。
- **可证性逻辑 GL → "验证器自证"的元逻辑【类比推断】**：阙疑若要让验证器证明"已证明 X"，可证性逻辑刻画 □ 的自指与 Löb 公理，警示自证循环的边界（呼应 A2 验证器的自举）。
- **模糊逻辑 → "置信度/软警报"的连续化【类比推断】**：v23 软警报率、CalibrationTracker 的置信度可用 [0,1] 真值表达边界状况，比二值"命中/未命中"更贴合人审的不确定判断。
- **答案集编程 → "规则/配置搜优"的声明式引擎【类比推断】**：阙疑的规则冲突求解、攻击生成调度可表述为 ASP 稳定模型，让"满足所有约束的配置"被自动搜出。
- **情境演算 → "验证动作后果"推理【类比推断】**：阙疑每次 VerificationRun 是"动作→新状态"，情境演算可推理"执行某验证后系统进入何状态"，辅助闭环规划。

## 三、净新增（v21-v28 没有的洞察，≥3 条）

1. **道义逻辑把"规则=规范"正式落地**：v21-v25 一直没说清规则是规范还是事实；道义模态 O/P/F 给出精确区分，直接影响规则冲突解决策略。
2. **非单调逻辑是"判决可撤回"的严谨底座**：之前阙疑的击败器台账是启发式；非单调/缺省推理提供"结论随反例撤回"的公理基础。
3. **次协调逻辑为"进化中矛盾"提供安全容器**：阙疑自我进化期必有冲突规则，次协调逻辑避免单矛盾拖垮全局，比经典逻辑务实。
4. **认知逻辑的公共知识悖论警示多验证者共识难度**：Fagin-Halpern-Moses 指出公共知识在实践中难达成，提醒阙疑"多验证者完全一致"是奢侈品，需降级为分布式知识。

## 四、设计原则（1-2 条，可操作）

- **D-B4-1：规则以道义模态 + 非单调缺省双标注**——每条规则显式 O/P/F 且声明为可废止（默认成立、遇反例撤回），使规范性与可进化性同时成立。
- **D-B4-2：矛盾按次协调而非经典处理**——阙疑内核在规则冲突期容忍局部矛盾（拒绝爆炸），优先局部消解，避免全局失效。

## 五、失败教训与死路（≥5 条）

- **非单调逻辑计算复杂性高**：缺省/非单调推理多为高复杂度（常 co-NP 乃至更高），阙疑若实时用需限制规模或近似。
- **多值/模糊逻辑哲学争议**：真值连续化在"硬判决"场景易沦为主观调参；阙疑软警报可用但硬开火仍需二值清晰边界。
- **公共知识难达成（悖论）**：Fagin-Halpern-Moses 证明实践中公共知识几乎不可实现；阙疑不可把设计建立在"多验证者完全共知"上。
- **次协调逻辑工程工具少**：虽有理论，现成可用的次协调推理引擎稀缺，阙疑落地需自建轻量实现。
- **时态逻辑规格写错难发现**：LTL/CTL 规格若写得不符意图，模型检测"通过"也是假通过（呼应 A2 spec gap）。
- **可证性逻辑的自指循环风险**：□ 自指易构造 Henkin/Löb 式循环，阙疑自证设计须规避"证明自己可证"的陷阱。
