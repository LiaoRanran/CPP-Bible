# 方向 C1：统计学习理论

> 核心问题：**"学会了"这件事能否被严格界定？泛化有没有上界？样本要多大？** 对应阙疑"自我进化的可学习性 + 校准上界"。
> 检索：15 次（PAC/Valiant、VC 维、ERM/SRM、可学习性充要条件、在线学习遗憾界、Boosting、Rademacher、分布偏移、PAC-Bayes、realizable/agnostic、margin 理论、样本复杂度、NFL、DL 双重下降、一致收敛）。
> 边界：v23 已提校准/泛化误差，本轮**补理论根基**；与 B1 不可判定、C2 归纳偏置不重复。

## 一、核心概念清单（≥10 条）

- **PAC 学习（Valiant, 1984）**：以概率 1-δ 学得误差 ≤ ε 的假设，即"可能近似正确"。定义了"可学习"的量化门槛。
- **VC 维（Vapnik-Chervonenkis）**：假设类的容量度量；泛化误差上界 ∝ √(VC/n)。VC 有限 ⇒ 一致收敛可保证泛化，是统计学习理论基石。
- **经验/结构风险最小化（ERM/SRM, Vapnik）**：ERM 最小化训练误差；SRM 在训练误差上加复杂度惩罚（正则化）以兼顾泛化——深度学习的正则即其后代。
- **可学习性的充要条件**：有限假设类一定 PAC 可学；无限类当且仅当 VC 维有限。但**学习性本身在某些情况下不可判定**（与 B1 呼应）。
- **在线学习与遗憾界（Regret）**：放弃 i.i.d. 假设，序列决策下衡量"累计损失 vs 最优固定策略之差"。Multiplicative Weights / 无遗憾算法是"在线对抗学习"核心——与阙疑动态攻击环境同构。
- **Boosting（Freund-Schapire）**：弱学习者（略优于随机）可提升为强学习者；AdaBoost/Gradient Boosting 的误差界与 margin 相关。
- **Rademacher 复杂度**：基于随机噪声拟合能力的复杂度度量，给出数据依赖的泛化界，常比 VC 更紧。
- **分布偏移（Covariate/Label Shift）与域自适应**：训练与测试分布不同（P≠Q）。经典 PAC 假设 i.i.d.，偏移下泛化界失效——须显式建模漂移。
- **PAC-Bayes 界（McAllester）**：对**分布**而非单假设给泛化界，可解释深度学习的贝叶斯泛化，比 VC 更数据依赖、更紧（但 Livni-Moran 指出其局限）。
- **realizable vs agnostic PAC**：realizable 假设存在零误差目标；agnostic 不假设存在，只求逼近最优。阙疑大多数场景是 agnostic（无完美规则）。
- **margin 理论**：SVM/Boosting 的泛化来自大间隔，为"为什么过拟合少"提供解释。
- **样本复杂度（Sample Complexity）**：达到 (ε,δ) 所需样本数上界，与 VC、维数、误差互为权衡——"多少数据才够学"的定量答案。
- **没有免费午餐定理（NFL, Wolpert-Macready 1997）**：对所有可能函数平均，任何算法表现等价——**无先验偏置则无最优算法**。
- **双重下降（Double Descent）**：DL 在中度过参数化时测试误差先升后降，传统 VC 难以解释（Nagarajan 等指一致收敛不足以解释 DL 泛化）。

## 二、对阙疑的映射（全标【类比推断】）

- **PAC + 样本复杂度 → "自我进化学多少样本才稳"的上界【类比推断】**：阙疑规则从经验中进化，等价于"从攻击样本学规则"。PAC 样本复杂度给出"至少多少反例才能以高置信学得某规则类"的定量下限——v23 的"需要多少误报才校准"第一次有了理论公式。
- **VC 维 → 规则类的容量上限【类比推断】**：阙疑的规则集可视为假设类，VC 维衡量其表达力/过拟合风险。规则无限膨胀会推高 VC 维、恶化泛化——呼应 B2 的 MDL"规则膨胀"约束，从泛化角度二次确认"规则集要小"。
- **可学习性不可判定 → "能否学会正确验证"的部分不可知【类比推断】**：C1 揭示"某概念类是否可学"本身可能不可判定，与 B1 合流——阙疑"能否从经验学全验证"无法先验保证，须接受部分不可知 + 人审兜底。
- **在线学习遗憾界 → 对抗环境下的最坏保证【类比推断】**：阙疑面对的是**对抗性**攻击分布（非 i.i.d.）。在线学习的"无遗憾"算法（如 multiplicative weights）给阙疑防御调度一个理论保证：长期累计损失逼近最优静态策略——对应 v21 的 AISI 式自适应。
- **分布偏移 → 攻击分布漂移的显式建模【类比推断】**：v23 关注的是"校准是否退化"。C1 的分布偏移理论指出：当攻击者改变手法（P_train≠P_test），旧校准必失效。阙疑必须持续重校准并检测偏移，而非一次性校准。
- **NFL → "无先验则无最优规则"【类比推断】**：Wolpert 的 NFL 证明没有普适最优算法。阙疑的"通用验证器"若声称对所有攻击最优，直接撞 NFL——必须从具体攻击先验（领域知识）出发，而非追求普适。
- **PAC-Bayes → 规则集的贝叶斯泛化上界【类比推断】**：阙疑规则集可视为"假设分布"，PAC-Bayes 给出其泛化的数据依赖上界，比 VC 更贴合"带置信度的规则"场景（呼应 v23 置信度）。
- **Boosting → "弱规则组合成强验证"【类比推断】**：v23/v25 的简单规则可由 Boosting 组合成强判别器（如误报率聚合），margin 理论解释为何组合后更稳。
- **双重下降 → 规则数量非越多越好【类比推断】**：DL 的 double descent 提示"中等复杂度最优、过复杂反而回弹"。阙疑规则集在"恰好够覆盖"与"过度堆砌"间也应有这样的甜点——为规则规模提供经验-理论双支撑。
- **agnostic PAC → 阙疑是"无完美规则"的世界【类比推断】**：阙疑不假设存在零误报规则集（realizable 不成立），应在 agnostic 框架下设计算法，只求逼近最优而非达到完美。

## 三、净新增（v21-v28 没有的洞察，≥3 条）

1. **样本复杂度把"校准所需样本数"量化**：v23 的"需要多少反例才校准"第一次有了 PAC 公式化上界。
2. **对抗环境应切换到在线学习框架**：阙疑的攻击是非 i.i.d. 对抗分布，PAC 的 i.i.d. 假设失效，须用在线遗憾界（无遗憾算法）保证最坏情形。
3. **分布偏移使"一次性校准"在数学上破产**：攻击手法漂移必然让静态校准失效，阙疑必须持续重校准——这是 v23 校准退化问题的理论根因。
4. **NFL 从优化角度再证"通用最优验证器"不可能**：与 B1 Rice 互补，阙疑必须依赖领域先验。

## 四、设计原则（1-2 条，可操作）

- **D-C1-1：规则集规模按 VC/样本复杂度约束**——给定可用攻击样本量，按 PAC 样本复杂度反推可容纳的规则 VC 维上限，规则集过大即触发 MDL 裁剪（呼应 B2）。
- **D-C1-2：防御调度用无遗憾在线算法**——把攻击生成/验证选择建模为在线学习，采用 multiplicative weights 类无遗憾策略，保证长期累计损失逼近最优静态策略。

## 五、失败教训与死路（≥5 条）

- **i.i.d. 假设在对抗环境失效**：经典 PAC 要求样本独立同分布，阙疑的攻击是自适应对抗的，直接套 PAC 会高估泛化——须用在线/对抗学习框架。
- **分布偏移让静态校准必衰**：一次校准无法应对手法漂移，阙疑若不做持续重校准会慢性失效。
- **NFL：无先验则无最优**：追求"对所有攻击最优的规则"必败，须绑定领域先验。
- **VC 维不可直接算 DL**：深度网络 VC 维巨大，传统界过松；阙疑若用神经网络规则需依赖 PAC-Bayes/经验而非 VC。
- **双重下降反直觉**：规则/模型越多测试误差可能反弹，盲目加规则反而害泛化。
- **可学习性本身可能不可判定**：不能先验保证"能学会正确验证"，须接受部分不可知 + 人审 oracle（B1）。
