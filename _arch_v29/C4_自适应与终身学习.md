# 方向 C4：自适应与终身学习

> 核心问题：**阙疑要"持续进化、越用越强"，但会不会学新忘旧、被新攻击洗脑？** 对应阙疑"自我进化的稳定性-可塑性困境"。
> 检索：15 次（灾难性遗忘、EWC、经验回放、突触智能、LwF、稳定性-可塑性困境、非平稳在线学习、MAML 元学习、负迁移、概念漂移、生成回放、CL 综述、task-free CL、海马记忆回放、渐进网络）。
> 边界：v21 已提"自我进化"，本轮**补持续学习机制与陷阱**；与 C1 在线学习、C2 元偏置不重复。

## 一、核心概念清单（≥10 条）

- **灾难性遗忘（Catastrophic Forgetting）**：神经网络顺序学新任务时，旧知识被新梯度覆盖而骤降；是持续学习的核心难题（Paris 2019 综述）。
- **EWC（弹性权重巩固, Kirkpatrick 2017）**：用 Fisher 信息矩阵估计参数重要性，对重要参数加二次惩罚，防止偏离——正则化类代表。
- **经验回放（Experience Replay）**：保留少量旧样本（replay buffer）与新数据混合训练，模拟海马回放；最简单有效的抗遗忘法。
- **突触智能（Synaptic Intelligence, Zenke 2017）**：在线上累计"参数对旧任务的重要性"，按需局部巩固，比 EWC 更精细。
- **LwF（Learning without Forgetting, 2016）**：只用新任务数据，用知识蒸馏保留旧任务输出——不需存旧样本。
- **稳定性-可塑性困境（Stability-Plasticity Dilemma）**：网络须同时"守住旧知识（稳定）"与"学新概念（可塑）"，二者冲突；Nature 2024 指出深度持续学习会"丧失可塑性"（loss of plasticity）。
- **非平稳在线学习（Non-stationary Online Learning）**：分布随时间漂移（concept drift），动态遗憾（dynamic regret）最小化是原则方法（ICML 2024 小波自适应）。
- **MAML 元学习（Finn 2017）**：学会"快速适应新任务"的初始化，少量样本即可微调——给持续学习"快速吸收新攻击模式"的范式。
- **负迁移（Negative Transfer）**：源域知识不适配目标域反而损害；与 C2 偏置错配同源——错误的历史经验比没有更糟。
- **概念漂移（Concept Drift）**：数据流中分布随时变；需检测+适应（DriftSurf 等风险竞争算法）。
- **生成回放（Generative Replay）**：训练生成模型产出"伪旧样本"代替真实旧数据，解决隐私/存储；在 Class-IL 场景几乎唯一有效。
- **Task-Free Continual Learning（自 2018）**：现实无明确任务边界，数据流式到达，何时巩固知识需自决——更贴阙疑的"持续流"。
- **海马-新皮层双记忆（Complementary Learning Systems）**：生物用海马快速存新、新皮层慢整合；双记忆网络（TMN）模拟此做持续学习。
- **渐进网络（Progressive Networks, Rusu 2016）**：每学新任务加一列网络、冻结旧的、加横向连接——架构类抗遗忘，但列数随任务增长。

## 二、对阙疑的映射（全标【类比推断】）

- **灾难性遗忘 → "自我进化"会洗掉旧规则【类比推断】**：v21 的"越用越强"隐含陷阱——若阙疑用可训练模型学新攻击，可能把旧漏洞模式覆盖掉（灾难性遗忘）。必须显式抗遗忘，否则"进化"实为"失忆式更新"。
- **EWC/突触智能 → 规则参数的重要性锁定【类比推断】**：阙疑的规则集可类比神经网络权重，每条旧规则"重要性"应被估计（如命中高危漏洞的频率/Fisher 类比），更新时对这些规则加保护，避免被新经验冲掉。
- **经验回放 → Ledger 判例回放缓冲【类比推断】**：v25 的 Ledger/判例可充当 replay buffer——训练/校准新规则时混入历史判例，防止新攻击模式覆盖旧经验；对应"从过去误报漏报中学"。
- **LwF → 不存旧样本的知识蒸馏【类比推断】**：阙疑若受隐私限制不能存旧代码样本，可保留"旧验证器的输出分布"作蒸馏目标，新验证器在学新攻击时仍匹配旧行为——抗遗忘且省存储。
- **稳定性-可塑性困境 → 阙疑的核心张力【类比推断】**：阙疑要在"守旧（不丢已验证能力）"与"纳新（吸收新攻击）"间平衡。Nature 2024 的"丧失可塑性"警示：一味守旧会僵化。须有机制动态调稳定/可塑权重。
- **概念漂移/非平稳 → 攻击手法漂移须在线适应【类比推断】**：C1 已证分布偏移使静态校准失效。C4 的机制（动态遗憾、DriftSurf）给阙疑"持续重校准"以算法支撑——与 C1、C3 鲁棒决策合流。
- **MAML → 快速吸收新型攻击范式【类比推断】**：阙疑遇新型攻击族时，应能用少量样本快速微调（meta-initialization），而非从头学——提升"对抗适应性"。
- **负迁移 → 错误历史经验比没有更糟【类比推断】**：与 C2 偏置错配同源。阙疑若把不适配当前代码库的历史规则强行迁移，会负迁移；须做迁移适宜性检测。
- **生成回放 → 不泄露源码的伪判例【类比推断】**：阙疑验证涉及私有代码，真实样本不可留存。生成回放用"伪样本"代替，既抗遗忘又保隐私——契合安全约束。
- **Task-Free CL → 无任务边界的持续流【类比推断】**：阙疑面对的是攻击流而非"第 N 个任务"，须用 task-free 范式（何时巩固、如何判断概念变更），而非批量任务式训练。
- **双记忆系统 → 快存/慢整合两路【类比推断】**：阙疑可设"快记忆（新攻击即时入缓冲）"+"慢整合（周期性提炼成稳定规则）"双通道，模仿海马-新皮层，平衡时效与稳固。
- **渐进网络 → 规则"加列不覆写"【类比推断】**：学新攻击族时新增规则模块而非改写旧规则（冻结旧列），从架构上杜绝遗忘——但须防列数膨胀（呼应 B2/MDL 规则膨胀）。

## 三、净新增（v21-v28 没有的洞察，≥3 条）

1. **"自我进化"的首要风险是灾难性遗忘，而非不进化**：v21 只说"越用越强"，本轮揭示不抗遗忘的进化=丢失历史能力，须把抗遗忘列为进化架构的一等公民。
2. **Ledger 判例即 replay buffer，可直接拿来抗遗忘**：v25 的判例库天然是经验回放素材，新规则校准时混入即可防覆盖——把已有资产变成持续学习机制。
3. **Task-Free + 双记忆是阙疑进化的正确形态**：无任务边界的攻击流 + 快/慢双通道整合，比"定期重训"更契合实际。
4. **生成回放解决"隐私 vs 抗遗忘"两难**：私有代码不能存，用伪样本回放，既守密又抗遗忘。

## 四、设计原则（1-2 条，可操作）

- **D-C4-1：进化架构默认双记忆 + 回放**：快通道即时吸收新攻击入缓冲，慢通道周期提炼稳定规则；新规则校准强制混入历史判例回放，阻断灾难性遗忘。
- **D-C4-2：旧规则设重要性锁定与迁移检测**：用重要性估计（命中高危频率/Fisher 类比）保护关键旧规则；新经验迁移前做适宜性检测，防负迁移。

## 五、失败教训与死路（≥5 条）

- **灾难性遗忘让"进化"变"失忆"**：不抗遗忘的在线更新会悄悄丢掉旧漏洞识别力，且难察觉——阙疑若只追新攻击必踩。
- **EWC 累积惩罚过度限制可塑性**：Fisher 正则累加会锁死网络，新任务学不动；阙疑规则保护须设上限，避免僵化。
- **经验回放需存储，隐私场景受限**：真实代码样本回放违反安全约束，须改用生成回放（增复杂度）。
- **负迁移：错误历史比没有更糟**：强行迁移不适配规则损害当前验证，须检测适宜性。
- **渐进网络列数随任务膨胀**：每新攻击族加一列不可持续，须配列合并/裁剪（MDL 约束）。
- **Task-Free 的"何时巩固"难决**：无任务边界时自行判断概念变更易误判，巩固太频/太疏都伤；需可靠的漂移检测。
