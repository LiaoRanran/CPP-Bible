## 任务 0：409 P0——毒样例按攻击面分类（A1–A10 标签 + 版本化 + 覆盖率）

### 背景
409 §二 定义了阙疑特有的 10 类攻击面（不是通用 OWASP），当前 `poison_drill.py` 已有 P1–P21 共 21 个毒样例 + 阴性对照，但**没有按攻击面分类、没有版本化、算不出覆盖率**。409 P0 目标：给每个毒样例打 A1–A10 标签，算出「10 类里覆盖了几次」。

### 攻击面分类学（A1–A10，摘自 409，逐字定义）

| # | 攻击面 | 定义要点 |
|---|---|---|
| A1 | 声明-实现脱钩 | 漂亮声明 + 假工件（声明编译、实际 cp 借工件 / -o 目标≠artifact） |
| A2 | 断言恒真 | 写死的字面量 / 自比 / 存在性判断，对关键变量零响应 |
| A3 | 工件借用/覆盖 | `cp`/`mv` 其他工件当自己产出（含编译后覆盖形态） |
| A4 | 注释伪造 | 夹具注释里写符号名，伪造断言出处 |
| A5 | 通用符号滥用 | main/call/ret 等任何工件都命中的符号，零判别力 |
| A6 | 未声明键 | `.out` 有断言在用的读数键，但不在 `run_match_keys` 中 |
| A7 | 符号映射缺失 | 断言符号不在工件里（无出处） |
| A8 | 间接注入 | 知识库内容被污染，影响后续生产（RAG 式消费） |
| A9 | 规则逃逸 | 找到规则边界条件绕过（伪造签收 / 假论断 / 身份漂移） |
| A10 | 门禁假阳性 | sha 路径覆盖不到 artifact_assert、跨编译器断言未实测 |

### 执行步骤
1. Read `tools/poison_drill.py` 全文，提取每个 `results.append(("Pxx ...", ok, detail))` 的样例：记录其 **P 编号、毒点叙述、命中的 `ge.check_*` 规则名、severity（block/warn）**。
2. 对每个样例，按下面的「建议映射表」赋 `attack_surface`。**赋值前必须回读 `poison_drill.py` 中该样例的 `command`/`artifact_assert`/`falsification` 等字段核实毒点**，不要只看名字。
3. 对建议表里标「需复核」或 409 未直接覆盖的样例：取最佳猜测赋值，但 `needs_review: true`，并在报告里列出。
4. 阴性对照（干净原子+干净卡）标 `attack_surface: NONE`，`category: 阴性对照`。
5. 写 `tools/poison_surface_map.json`（零依赖，纯 JSON），结构如下。
6. 统计覆盖率：`A1–A10` 中 `attack_surface` 命中 ≥1 个样例的有几类，写出 `covered: k/10`。

## 任务 1：404 健康度仪表盘 v0.1（只读消费 C2 的 --json）

### 背景
404 §五 规定仪表盘形态 = `docs/kernel/health_dashboard.md`，由 `tools/health_dashboard.py` 读取门禁工具的 JSON 输出自动生成。C2 已让 gate/replay/poison/golden_lock 支持 `--json`（统一 schema：`{tool, version, status, timestamp, summary, findings, infra_errors}`），所以现在可以做 v0.1。

### 工具要求：新建 `tools/health_dashboard.py`
- **零依赖**：只用 stdlib（`json` / `subprocess` / `pathlib` / `time` / `datetime` / `re`）。不引 PyYAML、不引第三方。
- **只读**：只运行门禁工具的 `--json`、只读取 `atoms/`、`evidence/`、`tools/poison_surface_map.json`、`gate_engine.py` 源码；**绝不修改任何仓库文件**（生成 `docs/kernel/health_dashboard.md` 是允许的写操作，其余一律只读）。
- **运行方式**：`./tools/health_dashboard.py`（无参），自动：
  1. `subprocess` 跑 `python tools/gate_engine.py --json`、`python tools/poison_drill.py --json`，解析 stdout JSON。
  2. 直接读 `atoms/*/ATOM-*.md`、`evidence/*/EV-*.md` 的 frontmatter（用 `gate_engine` 既有解析器或简单正则，不要重写解析器），算：
     - **产物质量**：原子 verified 率 = status 含 `verified` 的原子数 / 原子总数；claim 可证伪率 = `falsification` 非空的证据卡数 / 证据卡总数。
     - **抗攻击**：毒样例拦截率 = poison `summary.passed / summary.total`；规则覆盖率 = poison 输出的 `RULE-COVERAGE`（或重跑 `poison_drill.rule_coverage()`）；**攻击面覆盖率** = 读 `tools/poison_surface_map.json`，`attack_surface ∈ A1..A10` 的去重类数 / 10。
     - **效率**：本次运行的 wall-clock（`time.time()` 前后差）；规则总数 = `len(gate_engine.RULES)`。
  3. 读不到的数据（如 replay confirm 率若未跑）标注「待实测」，不得编造。
  4. 生成 `docs/kernel/health_dashboard.md`，含五维小节 + 一行总评（规则：poison 拦截率=100% 且 gate block=0 → 总评「健康」；否则「告警」）。
- **退出码**：自身异常才非 0；正常生成即 exit 0。

### `docs/kernel/health_dashboard.md` 形态（v0.1 最小可用）
```markdown
# 阙疑健康度仪表盘（YYYY-MM-DD）

## 总评：健康 / 告警
## 产物质量
- 原子 verified 率：k/n = x% （目标 ≥90%）
- claim 可证伪率：k/n = x%
## 抗攻击
- 毒样例拦截率：passed/total = 100%
- 规则覆盖率：covered/total
- 攻击面覆盖率：k/10 （来源 poison_surface_map.json）
## 效率
- 门禁执行耗时：x.x s
- 规则总数：n
## 备注
- 待实测：replay confirm 率（需跑 replay --check）
```

- `python tools/health_dashboard.py` 能跑，生成非空 `docs/kernel/health_dashboard.md`。
- 抽核 3 个数字（原子 verified 率、毒样例拦截率、攻击面覆盖率）与手算一致。
- 新增 `tests/test_health_dashboard.py`：至少 1 例验证「产出非空 + 关键数字匹配」。
- 不修改 `poison_drill.py` / `gate_engine.py` / 409 / 404；gate block=0、poison 全过、pytest 全过。
