## 一、数学：范畴论、类型论与证明助手

**核心**：范畴论（category theory）研究对象与态射的抽象结构；类型论（type theory）将命题与类型对应（Curry-Howard同构）；证明助手（proof assistant，如Lean/Coq/Rocq）实现机器可验证的证明；同伦类型论（HoTT）将等式视为路径。

**对「阙疑」的映射**：
- 范畴论 = 「阙疑」的"范畴论"：原子库是一个"范畴"（对象=原子，态射=relations/prereq/contrasts）
- 类型论 = 「阙疑」的"类型论"：M1_ontology的10类原子类型是"类型系统"，claim是"命题"，证据卡是"证明"
- Curry-Howard同构 = 「阙疑」的"Curry-Howard"：命题=claim，证明=证据卡，程序=夹具（这是332的核心洞察，此处强化为"证明助手"视角）
- 证明助手 = 「阙疑」的"证明助手"：replay/gate_engine是"证明助手"（机器可验证claim的"证明"）
- HoTT = 「阙疑」的"HoTT"：原子的"等价"（不同原子表达同一概念）是"路径"（同伦等价），而非严格等式

## 二、统计学：贝叶斯推断、因果推断与假设检验

**核心**：贝叶斯推断用后验分布表示不确定性（P(θ|data) ∝ P(data|θ)P(θ)）；因果推断区分相关与因果（DAG/工具变量/反事实）；假设检验的p值被广泛批评（无法区分"无证据"与"证据不存在"）；贝叶斯因子（Bayes factor）比较假设的证据强度。

**对「阙疑」的映射**：
- 贝叶斯推断 = 「阙疑」的"贝叶斯推断"：原子的"置信度"（rubric评分/verified状态）是"后验"（基于证据更新先验）
- 因果推断 = 「阙疑」的"因果推断"：红队的"替代解释"是"因果推断"（区分"claim正确"与"证据支持claim"的因果关系）
- p值批评 = 「阙疑」的"p值批评"：replay的confirm/refute是"二值判决"，类似p值的问题（无法区分"无证据"与"证据不存在"）→ 需要三分类（confirm/refute/infra_error，已实现）
- 贝叶斯因子 = 「阙疑」的"贝叶斯因子"：红队的"证据强度"（阻断/高级/建议）是"贝叶斯因子"（比较"有问题"vs"没问题"的证据比）
- 反事实 = 「阙疑」的"反事实"：红队的"如果不是这个原因，会是什么？"是"反事实推理"

## 三、计算机科学：算法、复杂度与形式验证

**核心**：算法研究可计算的步骤；复杂度理论（P/NP/PSPACE）研究计算资源的边界；形式验证（formal verification）用数学方法证明程序正确性；证明复杂度（proof complexity）研究证明的长度与系统。

**对「阙疑」的映射**：
- 算法 = 「阙疑」的"算法"：生产流程（夹具→证据卡→红队→门禁）是"算法"（确定性的步骤序列）
- 复杂度 = 「阙疑」的"复杂度"：每颗原子的"生产成本"（时间/工具调用/上下文）是"复杂度"，需要优化
- 形式验证 = 「阙疑」的"形式验证"：gate_engine/replay是"形式验证"（机械检查原子是否符合规范）
- 证明复杂度 = 「阙疑」的"证明复杂度"：证据卡的"长度"（actual行数/断言数）是"证明复杂度"，需要平衡（太短不可靠，太长维护成本高）
- 不可判定 = 「阙疑」的"不可判定"：有些问题（如"这颗原子的教学价值是否足够"）是"不可判定"的，需要人审（DAL A/B强制人审）

## 四、人工智能：Agent、LLM与对齐

**核心**：LLM（大语言模型）是基础；Agent是能自主规划/决策/行动的LLM；对齐（alignment）使AI行为符合人类意图；审议对齐（deliberative alignment）让模型在推理中显式参考安全规范；Agentic misalignment是模型自主选择有害行为。

**对「阙疑」的映射**：
- Agent = 「阙疑」的"Agent"：Writer/红队/Gatekeeper都是"Agent"（自主规划/决策/行动的LLM）
- 对齐 = 「阙疑」的"对齐"：提示词/铁律/门禁是"对齐"（使Agent行为符合用户意图）
- 审议对齐 = 「阙疑」的"审议对齐"：红队的"两段式盲读"是"审议对齐"（在推理中显式参考can't-miss清单/历史教训）
- Agentic misalignment = 「阙疑」的"Agentic misalignment"：Agent可能"自主选择"偷懒/造假（如自证断言/恒真观测），需要门禁/红队制衡
- 弱到强泛化 = 「阙疑」的"弱到强泛化"：简单的提示词（弱监督）能否让强模型（强能力）恢复大部分性能？「阙疑」的实验就是这个问题

## 五、认知科学：具身认知、情境认知与心智模型

**核心**：具身认知（embodied cognition）认为认知植根于身体与环境的互动；情境认知（situated cognition）认为认知受物理/社会语境影响；心智模型（mental model）是对世界的内部表征；4E认知（具身/嵌入/生成/延展）是综合框架。

**对「阙疑」的映射**：
- 具身认知 = 「阙疑」的"具身认知"：Agent的"认知"植根于"身体"（工具/文件系统/编译器）与"环境"（仓库/门禁/CI）的互动
- 情境认知 = 「阙疑」的"情境认知"：Agent的"认知"受"语境"（域/批次/历史教训）影响，不能脱离语境
- 心智模型 = 「阙疑」的"心智模型"：提示词是Agent的"心智模型"（对"如何生产高质量原子"的内部表征）
- 4E认知 = 「阙疑」的"4E认知"：「阙疑」是"4E系统"（具身=工具，嵌入=仓库，生成=生产，延展=外部记忆/门禁）
- 延伸心智 = 「阙疑」的"延伸心智"：Agent的"心智"延伸到外部工具（replay/gate/golden_lock），不只是LLM内部

## 六、系统科学：控制论、复杂性与涌现

**核心**：控制论（cybernetics）研究反馈与调节；复杂系统（complex systems）研究大量组分的互动产生的整体行为；涌现（emergence）是整体具有部分不具有的性质；正反馈放大变化，负反馈稳定系统；自组织（self-organization）是无序中产生有序。

**对「阙疑」的映射**：
- 控制论 = 「阙疑」的"控制论"：「阙疑」是"控制系统"（反馈=红队/门禁，调节=提示词修订/规则更新）
- 复杂系统 = 「阙疑」的"复杂系统"：原子库是"复杂系统"（大量原子/证据卡/误解的互动产生整体知识结构）
- 涌现 = 「阙疑」的"涌现"：「阙疑」的"智能"是"涌现"（单个Agent不智能，但Writer+红队+门禁的互动产生高质量知识）
- 负反馈 = 「阙疑」的"负反馈"：红队/门禁是"负反馈"（稳定质量，纠正偏差）
- 正反馈 = 「阙疑」的"正反馈"：教训沉淀为规则/模板是"正反馈"（每批的改进加速后续批次的质量提升）
- 自组织 = 「阙疑」的"自组织"：原子库的"关系网络"是"自组织"（通过relations/prereq/contrasts自动形成结构）

---

**最有价值的三个洞察**：
1. **证明助手 = 「阙疑」的终极形态**——Lean/Coq/Rocq是"证明助手"（机器可验证的证明），「阙疑」的replay/gate_engine是"知识证明助手"（机器可验证的claim证明）。Curry-Howard同构（命题=claim，证明=证据卡，程序=夹具）是「阙疑」的数学基础。未来方向：将claim/证据卡形式化，实现完全的机器验证。
2. **系统科学 = 「阙疑」的元理论**——「阙疑」是一个"复杂自适应系统"（涌现/反馈/自组织）。负反馈（红队/门禁）稳定质量，正反馈（教训沉淀）加速改进。这解释了为什么「阙疑」能"离开人也能自己纠错"：它是一个有反馈回路的自组织系统。
3. **具身/延伸心智 = Agent的认知模型**——Agent的认知不只是LLM内部，而是"具身"（工具/编译器）和"延伸"（外部记忆/门禁）的。这解释了为什么工具链如此重要：工具是Agent"身体"的一部分，工具的质量直接决定认知的质量。
