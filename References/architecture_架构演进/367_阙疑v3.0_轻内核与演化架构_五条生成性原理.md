## 一、五条生成性原理（九层/八角色的压缩）

整个体系不可再分的内核只有五条。v1.x/v2.0的所有机制——replay、sha、红队、四级状态、认知环、理论综合、范式监控、边界地图、毒样例——都是这五条在具体场景的**实例**，不是常驻机构。

### P1｜独立可证伪（Independent Falsifiability）
> 任何主张，必须能被一条**独立于主张生产者**的验证路径，锚定到**机械硬事实**。

- 衍生：replay、sha256、artifact_assert、红队两段式盲读、claim强度检查、预测题实测
- **判断链硬度梯度**（解决"小人谬误"）：
  `机械硬事实（退出码/hash/汇编符号/进程终止） > 确定性工具（gate/replay/poison） > 结构化人/LLM评审（红队） > 个人判断`
- 铁则：任何评审结论必须能沿梯度向下追溯到硬事实；追溯不到的，标记为**悬置判断（unresolved）**，不得冒充结论。监督到此终止，不再加"监督监督者"的第九层。

### P2｜发现-辩护分离（Context Separation）
> 发现的语境允许狂野、融合、偶然；辩护的语境必须对抗、隔离、严谨。两者用不同组织方式，互不污染。

- 发现语境 = **单脑流动 + 强制视角切换**（六顶帽：观察→发散类比→自我反驳→设计→推演→综合），保留视角间的意外连接
- 辩护语境 = **多脑对抗 + 物理隔离**（生产者/红队异质、盲读、KPI对立）
- 狂野的产物只是**候选假设**；进入verified必须过完整辩护关。发现侧不设质量门（会扼杀创造），辩护侧不开后门（会纵容错误）。

### P3｜错误必沉淀且可遗传（Error Crystallization）
> 每个**真实发生过**的错误，必须变异为一条可执行约束 + 一个毒样例，并能跨域遗传；规则本身持续接受红队的绕过攻击。

- 衍生：PAT跨域模式库、gate规则进化、双环/三环学习、毒样例体系、规则覆盖度
- 约束：新规则必须同时交阳性毒样例（抓得住）和阴性毒样例（不误伤），否则不合并
- 只对**真实失败**立法（见P5的演化协议），不对想象风险立法

### P4｜认知预算下的信息增益最大化（Bounded Inquiry）
> 注意力/token/时间是稀缺资源。下一个动作永远投给"预期信息增益÷成本"最高者；验证强度按风险（DAL）购买；并明确知道何时停止。

- 衍生：研究优先级评分、DAL分级验证、有限理性、停止规则
- **停止规则**（治无限内卷）：当"再加固一轮的预期边际收益 < 同等成本投入真实生产/验证的预期收益"时，停止架构、回到生产。判据可量化：连续两轮批判新增P0=0且工程线有待验证产物 → 强制放行。
- 严谨不是免费美德，是需要理性配置的预算。

### P5｜向更可执行处流动，并持续修剪（Crystallize & Prune）
> 信息沿"过程→结论→规则→默认"单向浓缩流动，过程原件蒸馏后归档冷存储；冗余规则/文档/留痕定期修剪。只积累不修剪=囤积，不是智能。

- 衍生：文档河流、证据卡三层折叠、规则退役、认知修剪、注意力保鲜期
- 河流：`References过程文档 → docs/kernel规范 → tools规则 → 提示词默认值 → 原件归档`
- 与"积累"对称的"遗忘"是v2.0缺失项，v3.0补齐

## 二、最小可运行认知闭环（MCC）——先跑这个，其余后置

不建九层。发现型生产只跑一条最短环，全部其他机制（理论/范式/L3-L4/元认知地图）作为MCC跑通后**按需调用的工具**：

```
① 1个异常        必须附工件/读数证据，排除工具假象
② ≥2个假设       至少1个反直觉；每个含因果机制
③ 冻结预言       实验前git写死 O1/O2（事后不可改）
④ 1个判别实验    唯一变量+活性对照+有界+断言候选已实测
⑤ 盲裁决         中性标签，结论锚读数，列≥3替代解释
⑥ 固化/证伪      存活假设→走v1.x完整质量门；被否假设→误解库
```

MCC本身可被一条脚本检查完整性（缺步骤→warn），但**步骤内部的认知质量（假设是否真的竞争、实验是否真判别）属于默会判断**，交红队，不假装能机械判定。

## 三、机制设计：用对抗均衡取代监督堆叠

不设"元认知超级裁判"，改用**对立KPI**让质量成为博弈的稳定均衡：

| 角色 | KPI（被奖励什么） | 对立约束 |
|---|---|---|
| 生产者 | 红队/CI/人审**之后**才发现的错误数越少越好 | 不能靠降低难度（DAL由规则初定、红队可升级） |
| 红队 | **强证伪数**（改变claim方向的阻断）+ 规则绕过数 | 阻断必须锚硬事实，凑数的形式问题不计强证伪 |
| 综合者 | 理论的**成功新预言数** | 伪压缩（无新预言）被红队打回 |
| 元认知 | 不是"挑错数"，而是"追溯链断裂数 + 真实失败未沉淀数" | 它只检查机械完整性，不做内容裁决 |

博弈均衡自动维持质量，无需一个更聪明的上层裁判——监督链在P1的硬事实处自然终止。

## 四、工具箱（v2.0机制的重新归类）

v2.0的九层机制全部保留，但明确为"按需调用"，并标注**当前规模（20原子/1域/单人）是否启用**：

| 工具 | 何时调用 | 当前启用？ |
|---|---|---|
| MCC最小认知闭环 | 每个发现型原子 | ✅ 立即 |
| 错误分类法+PAT模式库 | 每批后 | ✅ 立即（已有大量真实错误） |
| 四级状态+三分类replay+毒样例 | 已在运行 | ✅ 保持 |
| DAL分级验证强度 | 所有生产 | ✅ 立即（P4的落地） |
| L1直觉/类比 | 教学原子 | ✅ 渐进 |
| L2预测题 | 核心原子（先3-5颗试点） | 🟡 试点 |
| 跨域迁移检查 | 进入新域（CONC）时 | 🟡 CONC开工时 |
| 理论综合（命题→原理） | 单域verified≥10且出现共享机制 | 🟡 MEM可试1次，但叫"局部模型"不叫"理论" |
| L3/L4、范式健康度、研究纲领状态机、三环正式复盘 | 跨≥3域、出现真实不可调和冲突时 | ⏸ 后置（当前是YAGNI） |
| 混沌工程 | 流水线稳定后 | ⏸ 后置 |
| 异质多模型 | 多模型可用时 | ⏸ 条件触发；此前用上下文隔离+独立性评分 |

**原则：每个 ⏸→🟡→✅ 的晋升，都必须由一个真实发生的失败或明确的规模阈值触发，不凭想象提前建设。**

## 五、架构自身的演化协议（让架构可证伪）

架构是假设，不是真理。每个机制的启用都是一次可检验的变异：

1. **失败买单制**：新机制必须指明"它要解决的那个**已经发生**的失败"，附证据；说不出真实失败的机制=投机设计，拒绝。
2. **小批次对照**：新机制先在1-2颗原子上试点，与不使用它的批次对比（强证伪发现率/漏检率/单颗成本），数据支持才推广。
3. **回退条件前置**：启用时写明"出现什么数据就回退"。
4. **最小内核冻结**：五条P原理视为宪法，改动需人审A级；工具箱自由演化。
5. **架构变更日志**：每个机制记录"为何启用/由哪个失败买单/实测效果/是否保留"。

这让架构走变异-选择-保留的演化路径，而不是BDUF（big design up front）——**用演化论的方法建造演化论的系统，消除v2.0的方法论矛盾。**

## 六、默会知识的诚实位置

- 显式划分：**机械可判**（交给脚本）vs **暂不可判的专家直觉**（交给红队/人），后者不许用看似客观的分数伪装。
- 沉淀通道：红队产生"闻着不对"的直觉 → 被强制追问"你具体看到哪个工件特征" → 该特征能在≥3个案例稳定复现 → 才提炼为规则+毒样例；不能复现的，留在"评审经验提示"，不硬化。
- 一次性直觉不立规则（防误判和Goodhart）。

## 七、发现的野性与多源观察（创造力的真实位置）

- **受控漫游配额**：观察员定期"无明确问题地"翻工件/标准/跨域，允许低效，记录意外
- **远类比强制**：溯因时至少1个假设来自不相关域的结构借用
- **意外发现奖励**：查A得B的serendipity显式记录，若产出新原子计入L4
- **多源观察**：编译器行为 + 标准文本 + 真实语料频率 + 学习者提问 + 跨语言对比 + 编译器源码/标准论文
- 以上全部只产出**候选**，仍须过MCC和辩护关（狂野地想，严谨地证）

## 九、回到"阙疑"二字

《论语·为政》："多闻阙疑，慎言其余，则寡尤。"

这名字早已给出了比"无所不能的超强智能"更成熟的目标：
- **多闻**：广泛观察、保留漫游与意外（七）
- **阙疑**：诚实标注无知、悬置没把握的判断（P1悬置/边界地图），不假装全知
- **慎言**：只说有独立证据锚定的话（P1辩护严谨）
- **寡尤**：目标不是零错误（不可能），而是少犯错、且每个错都让人变强（P3反脆弱）

v3.0不追求"全知的强AI"幻觉，追求一个**在无知中诚实、在预算内求知、在错误中进化、知道何时该说"够了"的系统**。这更可实现，更值得信任，也更配得上"阙疑"这个名字。

## 十、v3.0相对v2.0的净变化

1. 九层八角色 → 五原理内核 + 按需工具箱（压缩，不扩充）
2. 监督递归 → 判断链终止于硬事实 + 对立KPI博弈
3. 发现/辩护混用组织 → 发现单脑融合、辩护多脑对抗
4. 无限严谨 → 认知预算 + 停止规则（满足即可）
5. 只积累 → 积累与修剪对称的文档河流
6. BDUF设计论 → MCC最小闭环 + 失败买单 + 对照演化
7. 范式/理论等重概念 → 推迟到真实规模阈值，当前用"局部模型"
8. 隐性的默会判断 → 显式承认 + 沉淀通道
9. 单一观察源 → 六源观察 + 受控漫游
10. 架构不可证伪 → 架构机制本身可对照、可回退

**落地的第一步不是写更多设计，而是让MCC在CONC-002/003或第五批上真实跑一次，用失败为后续机制买单。**
