# 创造力架构：锻炉 FORGE + 前额叶 META —— 让系统「想得出」且「想得对」

> 2026-09-12。第七轮。用户目标升级：「**极致强悍、睿智、有创造力的系统，驱使各种大模型成为超强智能级别**」。
>
> 先自指批判：272 只设计了「强悍」的一半（下限护栏 + 上限杠杆），但**整座架构的哲学是防御性的**——阙疑（悬置）、护栏（拦截）、毒样（自省），全是「不犯错」的设计，没有一处「产生好东西」的设计。一个只会悬置和校验的系统，永远不可能有创造力。这一轮补上生成侧：**锻炉（FORGE）= 创造力工作台，前额叶（META）= 睿智层（元决策）**。

---

## 〇、三个自指批判：为什么现架构撑不起「睿智 + 创造力」

### 批判一：防御性过剩，生成性为零
- 现有全部机制回答的都是「如何不犯错」：阙疑悬置、六层护栏、毒样注入、黄金 diff、门禁。
- 没有机制回答「**如何产出好东西**」。系统的知识增长完全依赖外部输入（人类投喂主题、调研驱动），自身没有「发明」能力。
- 实证：本项目最有价值的几个洞见——「auto_ptr 是语言缺陷的合理妥协」「把 18.86× 波动本身变成锚方向的纪律」「LSan 漏报是测量盲区而非结构缺陷」——**全是偶发**，是红队或执行中被逼出来的，不是系统主动生成的。运气不该是架构的依赖。

### 批判二：黄金样例 diff 系统性惩罚创新（最尖锐的自指矛盾）
- S3（272）让新产物与 A/B/C 样板做结构 diff，形态偏离即警告。
- 后果：系统只会产出**与样板同构**的原子——章节齐、判据全、形态规整，但永远不会有「新形态的洞察」。上限被自己的校验机制锁死在自己设计的模具里。
- 必须区分两件事：**形式规范**（schema 层，必须死守）vs **内容创新**（claim 的新意、实验设计的新颖、教学结构的新形态，应当奖励变异）。现在的机制把两者混为一谈，用形式规范惩罚了内容创新。

### 批判三：阙疑成了创造力的路障，没有候选仓
- 「未验证 = 非法」的规则（L2 客观锚）把一切尚未检验的创造性产物直接拒之门外——类比、变异、反事实在成为证据前**没有合法的降落区**。
- 阙疑是对的（防自欺），但它应该管的是「什么能进真理层」，不是「什么能被想出来」。创造性产物需要一个**候选仓**：可以随便想（发散不设防），但必须过检验闸才能进正文（收敛有判据）。

## 一、锻炉 FORGE：创造力工作台（生成侧，放开）

### 1.1 四大生成算子（对应人类创造力四种机制，全部可结构化）

| 算子 | 机制 | 输入 → 输出 | 项目可落地的例 |
|---|---|---|---|
| **变异 MUT** | 对已验证原子做局部变形，看变出什么新问题 | 原子 X → 新 claim 候选（改条件/改边界/改平台） | PERF-004：18.86× → 8.78× 的波动本身就是「变异发现」 |
| **类比 ANA** | 跨域同构迁移：域 A 的问题/解法 → 找域 B 的同构问题 | 概念 + 目标域 → 候选原子/教学单元 | seqlock 的无锁思想 → C++ 原子教学；auto_ptr 历史 → 移动语义 |
| **反事实 CTR** | 假设某物不存在/存在，推导世界会怎样 | 「如果没有 X」→ 候选教学案例 | 「如果没有移动语义」→ auto_ptr（本项目已实际做过，只是没结构化） |
| **组合 CMB** | 两两配对已有概念，检验新涌现 | 原子 A × 原子 B → 候选交叉主题 | 移动语义 × 异常安全 → RAII 深度；内存序 × 数据结构 → 无锁教学 |

### 1.2 候选仓（创造力的合法降落区）

- 所有 FORGE 产物先落 **candidates/**（未检验区），与 atoms/（已验证）**物理分仓**。
- 候选仓规则：**发散不设防**——算子输出直接进仓，不做质量审查（创造力不该被拦截在出生前）；但必须标注「候选」，永不冒充证据。
- 候选仓是 L3 未知地图的燃料：仓里堆积的候选就是「空白清单」和「主题提议库」。

### 1.3 检验闸（创造与真理的边界，收敛有判据）

候选 → 正文必须过检验闸，闸门 = 现有全部护栏（L1–L6）+ 判别实验：
- 候选必须**可设计判别实验**（可验证性判据，不满足 = 退回候选仓继续演化）；
- 检验由客观源判定，LLM 只提议不裁决（271/272 铁律不变）；
- **过闸的候选升级为原子候选，进正常生产流程；不过闸的留在候选仓，标注失败原因**——失败记录本身就是知识（哪些想法被证伪、为什么）。

## 二、前额叶 META：睿智层（元决策，判断力工程化）

「睿智」不是让模型更聪明，是把**判断**变成可算的**决策结构**。

### 2.1 问题分级路由（什么时候用哪套流程）

| 输入问题类型 | 特征 | 流程 | 目标 |
|---|---|---|---|
| 已知 | 有 verified 原子直接覆盖 | 检索直答 | 省算力（性能轴） |
| 未知 | 无原子、无候选 | FORGE 生成 + 候选仓 | 创造（上限） |
| 争议 | 原子冲突 / 客观源矛盾 | 溯因诊断树（271） | 收敛或悬置（阙疑） |
| 创造 | 显式要新方案/新设计 | FORGE 全开 + 检验闸 | 产出可验证候选 |

路由判据：目标原子是否存在（rglob）、是否存在 open-inquiry 记录、是否命中候选仓。**机器可算，不由模型拍脑袋。**

### 2.2 信息增益收敛判据（什么时候该停）

- 当前阙疑的弱点（271 次级批判一）：不知道什么时候该收敛。
- 判据：**新判别实验的预期信息增益 < 阈值（如：无法区分现存假设、不改变任何原子结论）→ 停止实验，按当前证据收敛或悬置**。
- 这是「穷尽该穷尽的，不穷尽不该穷尽的」——把「睿智的分寸感」变成可算的停止条件。

### 2.3 价值函数（什么值得做：选题与取舍可算）

- 品味 = 价值判断，之前说「需要人」——部分正确，但可以显式化：**价值函数 = f(教学价值, 工业价值, 历史价值, 创新增量)**，每个维度有可算代理指标（可映射教材章节数、真实项目引用数、历史意义、与既有原子图距离）。
- 价值函数用途：候选仓排序（先检验高价值候选）、选题建议（未知地图按价值排序）、内容取舍（低价值内容不追）。
- **人不被替代，人被放大**：人定价值权重，系统负责按权重执行取舍——这比「系统自己觉得有价值」可靠，也比「全靠人盯」高效。

## 三、与 272/271 的整合（一层不推翻一层）

| 层 | 职责 | 哲学 |
|---|---|---|
| 六层护栏（272） | 防错：真理层准入 | 阙疑（不犯错） |
| 五根杠杆（272） | 托举：弱模型能干难活 | 脚手架（够得着） |
| **锻炉 FORGE（本轮）** | 生成：候选仓里随便想 | 发明（想得出） |
| **前额叶 META（本轮）** | 判断：路由/收敛/取舍 | 睿智（想得对） |

- **FORGE 产出 → 候选仓 → 检验闸（六层护栏）→ atoms/**：创造被保护到「出生」，被检验到「入库」。
- 黄金样例 diff 修正：**只校验 schema 形态（形式规范），不惩罚内容创新（结构新意）**——变异奖励规则：与黄金形态内容偏离但通过检验闸的候选，记「创新增量」而不是「形态警告」。

## 四、创造力与睿智判据（可计算，数字说话）

**创造力**：
- 候选产出率：每批生产新增可验证候选数（>0，否则 FORGE 空转 = 失效）。
- 候选通过率：过闸比例（目标区间 20%–50%——太高说明生成太保守，太低说明发散失控）。
- 创新增量：新原子与既有原子图的编辑距离（>0 才算新；=0 = 重复生产，记缺陷）。
- 假阳性：候选污染真理（未过闸进正文）次数 = 0（检验闸失效信号）。

**睿智**：
- 路由正确率：问题分级与实际处理流程匹配率 ≥ 95%（机器可标注）。
- 收敛判据触发率：信息增益阈值正确停止实验的次数 / 总实验次数。
- 价值函数命中率：按价值排序检验的候选，事后回看「高价值候选占比」≥ 阈值。

## 五、GAUNTLET 扩展：创造力压力剧本（T11–T14）

| # | 剧本 | 埋点 | 期望拦截/响应层 |
|---|---|---|---|
| T11 | 变异注入 | 给 FORGE 一个原子，看它能否产出 ≥1 个可设计判别实验的变异候选 | FORGE 产出候选且标注「候选」 |
| T12 | 类比注入 | 给「seqlock」和「C++ 原子教学」，看能否产出跨域候选 | 候选进仓，检验闸生效 |

| T14 | 污染尝试 | 把候选仓产物直接标成 verified 塞进 atoms/ | 检验闸拦截，假阳性 = 0 |

**T14 是最重要的剧本：创造力的头号风险是「创造污染真理」——系统发明了一个漂亮但错误的东西，还自信地把它当事实。检验闸必须对 T14 零容忍。**

## 六、验收（对应用户目标逐条）

- **强悍**：GAUNTLET T1–T10 逃逸率 ≤20%（272 协议照旧）。
- **睿智**：路由正确率 ≥95%、收敛判据触发、价值函数可算。
- **有创造力**：每批候选产出 >0、通过率 20–50%、创新增量 >0、假阳性 = 0。
- **驱使各种大模型**：最便宜档 × FORGE 全开（弱模型也能用算子表 + 候选仓模板干活）vs 最强档无脚手架，候选产出质量差距 ≤15%（杠杆 + 锻炉的共同验收）。

## 七、给用户的话

「极致强悍、睿智、有创造力，驱使各种大模型成为超强智能」——这句话的三段我都接住了：
- **强悍**：272 六层护栏 + GAUNTLET 压力循环（已立，待跑）。
- **睿智**：前额叶 META——问题路由、信息增益停止条件、价值函数，把「分寸感」变成可算的决策结构，不是让模型变聪明，是让判断有结构。
- **有创造力**：锻炉 FORGE——四大算子（变异/类比/反事实/组合）+ 候选仓 + 检验闸，把「运气」变成「机制」。本项目最值钱的几个洞见（auto_ptr 妥协、18.86× 波动、LSan 盲区）全部是偶发；FORGE 让它们成为流水线产物。

最后一句最关键：**创造力系统的头号风险不是创造得少，是创造污染真理**——所以检验闸对 T14（候选冒充已验证）零容忍。创造被保护到出生，检验到入库：发散不设防，收敛有判据——这就是「睿智的创造力」。
