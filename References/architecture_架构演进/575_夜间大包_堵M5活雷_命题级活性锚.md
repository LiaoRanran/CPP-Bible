## 活雷与根因（已查明，别再从头猜）
- v3 基线 M5 = **0 blocked / 29 escaped / 56 n_a**：27 张原子卡的 29 条 inference 命题，被 `mut_m5` 把 `claim_type: inference→observation` 后，**OBSERVATION-LIVENESS 闸 29/29 全放行**（C-P [88%,100%]）。
- 根因（`gate_engine.py::check_observation_liveness` 约 2377–2420）：活性判据问的是「这条命题**引用的证据卡**有没有活性条件」（`_has_falsification_quantified / _has_fixture_specific_assert_symbol / _has_non_env_run_key` 作用在整卡 `cards` 上），**不问「这个对照证不证伪得了这条命题」**。inference 命题（如 prop-2「fence 不建立 happens-before」，evidence=[EV-CONC-002]）改标 observation 后，蹭了同主题证据卡上**为别的命题（prop-1）服务的**夹具符号 ⇒ 放行。
- 纯结构收口（不靠 LLM 猜语义，守 530 铁线）：**observation 命题必须在命题级显式指认自己的证伪锚点，不能只挂卡 id 蹭整卡工件**。inference 命题本就不该有单一工件读数证伪（它靠 `external_basis` 标准引用，这是对的），所以它一伪装成 observation 就指认不出锚 ⇒ 被新规则看见。

## 任务 1：命题级活性锚字段 + 机检（warn 起步）
- 在 `claim_structured` 命题项内为 observation 增加**可选**活性锚字段（建议名 `liveness`，最终形态以任务 0 读到的判据为准，最小可机检为准）：
  - 主形态 `kind: fixture_symbol` + `symbol: <夹具特有符号>`；机检：该符号必须真实出现在本命题 evidence 引用卡的 artifact_assert 中、且 `_is_universal_symbol` 为否、可定位（非散文）。锚了不存在/通用符号 ⇒ warn（锚了个假的也要被看见）。
  - 若三个 `_has_*` 已支持，可一并给 `kind: quantified`（指认的取值串在引用卡 falsification 中）/ `kind: run_key`（指认键在引用卡 actual.run_match_keys 且非环境量）；拿不准就只做 fixture_symbol，其余在 worklog 写明。
- 新规则（建议挂 OBSERVATION-LIVENESS，不新增会扩大覆盖债的规则 id；severity **warn**）：observation 命题缺 `liveness` ⇒ warn「命题 X 未在命题级指认证伪锚，仅靠引用卡工件（可能蹭同卡别的命题的证据）」。
- inference 命题不要求 liveness（沿用 external_basis 现状）。
- **存量零误伤铁线**：本规则只 warn 不 block；任务 0 量出的存量 warn 数就是预期暴露的债务，进人审清单，不得为压低数字放宽判据，也不得自动给存量命题填锚（填锚是知识活，见任务 3）。
