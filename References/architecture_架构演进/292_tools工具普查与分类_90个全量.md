## 四、冗余与重叠识别

### 高重叠组（功能相似，考虑合并）

1. **交叉引用三件套**：crossref_audit.py + xref_check.py + dangling_ref_linter.py
   - 三个都做引用检查，可能有重叠。建议：统一为一个工具加子命令，或明确分工。

2. **编译三件套**：compile_gate.py + compile_all.py + compile_run_sanitize_pipeline.py
   - compile_gate 是门禁、compile_all 是执行、compile_run_sanitize 是增强版。分工尚可，但 compile_classify.py + compile_triage.py 可能与 compile_gate 重叠。

3. **ASM 四件套**：asm_prepush_guard + asm_regen + asm_repro_spotcheck + verify_asm_evidence + book_asm_freshness
   - 5 个 ASM 相关工具，功能有重叠（生成/验证/新鲜度）。建议：统一为 asm_toolkit.py 加子命令。

4. **审计工具泛滥**：28 个审计工具，其中 6 个未被 CI 调用（deduplication_audit/expansion_audit/teaching_audit/template_audit/caption_truncation_audit/check_citations/hy3_check）。
   - 建议：未被 CI 调用的审计工具要么接入 CI，要么归档到 tools/legacy/。

5. **D5 五件套**：d5_appendix_audit + d5_compile_gate + d5_gap_scanner + d5_runtime_gate + d5_source_integrity
   - 5 个 D5 专用工具，全部被 CI 调用。如果 D5 阶段已完成，这些可能是阶段性工具，可归档。

### 疑似孤儿工具（CI 不调 + 无其他工具 import）

需进一步确认的候选：
- academic_chart.py（6KB）——学术图表，可能是一次性脚本

- chapter_lint.py（12KB）——章节 lint，可能被 chapter_compile_check 替代
- collect_reports.py（4KB）——收集报告，可能是一次性
- gen_d5_charts.py（17KB）——D5 图表，D5 完成后可能不需要
- m5_dashboard.py（7KB）——M5 仪表盘，阶段性工具

## 五、工具生命周期建议（参考 Bazel 四态）

| 状态 | 定义 | 候选工具 |
|---|---|---|
| **Active**（活跃） | CI 调用 + 日常维护 | T1 全部 9 个 + T2 CI 调用的 22 个 |
| **LTS**（长期稳定） | CI 调用但功能稳定，少改动 | gen_mkdocs_nav / rewrite_links / cppbible |
| **Maintenance**（维护） | 本地工具，不进 CI 但有用 | learning_path / l2_state / ci_local_precheck / prepush_check |
| **Deprecated**（待归档） | 阶段性任务完成 / 被替代 / CI 不调 | D5 五件套（D5 完成后）、gen_d5_charts、m5_dashboard、一次性修复脚本 |

**建议动作**：
1. 建 `tools/legacy/` 目录，将 Deprecated 工具移入（保留 git 历史）
2. 给 Active 工具加 `--version` 和 `--help` 标准接口
3. 统一 ASM 五件套为 `asm_toolkit.py` 加子命令
4. 统一交叉引用三件套为 `xref_toolkit.py` 加子命令
5. 给 Maintenance 工具加文档（README 或 docstring）说明使用场景
