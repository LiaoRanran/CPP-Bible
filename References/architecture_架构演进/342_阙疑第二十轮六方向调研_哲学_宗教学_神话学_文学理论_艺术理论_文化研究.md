## 一、哲学：形而上学、伦理学与认识论

**核心**：形而上学研究存在的本质（实在/因果/自由意志/同一性）；伦理学研究善与正当（后果论/义务论/美德伦理）；认识论研究知识的本质与边界（JTB=被证成的真信念/先验/后验）；分析哲学强调逻辑与语言分析，欧陆哲学强调历史与存在。

**对「阙疑」的映射**：
- 形而上学 = 「阙疑」的"形而上学"：原子的"存在"（什么是一颗原子？它的本质是什么？）是"形而上学"问题
- 伦理学 = 「阙疑」的"伦理学"：「阙疑」的"伦理"是"不编造/不掩盖/诚实报告"（铁律），DAL（决策影响等级）是"伦理分级"
- 认识论 = 「阙疑」的"认识论"：claim的"知识"定义=JTB（被证成的真信念）：claim=信念，证据卡=证成，replay=真（可验证）
- 分析哲学 = 「阙疑」的"分析哲学"：「阙疑」的方法是"分析哲学"（逻辑/语言/精确性/可验证性）
- 欧陆哲学 = 「阙疑」的"欧陆哲学"：红队的"批判"是"欧陆哲学"（解构/谱系学/意识形态批判）

## 二、宗教学：神学、比较宗教与仪式

**核心**：神学研究神/神圣/信仰的理性基础；比较宗教学研究不同宗教传统的异同；仪式（ritual）是宗教实践的核心（通过重复/象征/共同体建立神圣秩序）；神圣与世俗的区分（Durkheim）是宗教的基本结构。

**对「阙疑」的映射**：
- 神学 = 「阙疑」的"神学"：「阙疑」的"信条"是"极致自律/不编造/可验证"（类似宗教的"教义"）
- 比较宗教 = 「阙疑」的"比较宗教"：不同域（MEM/CONC/UB）是不同的"宗教传统"，有各自的"仪式"（生产流程）和"教义"（铁律）
- 仪式 = 「阙疑」的"仪式"：生产流程（夹具→证据卡→红队→门禁）是"仪式"（通过重复/规范/验证建立"神圣秩序"=verified状态）
- 神圣/世俗 = 「阙疑」的"神圣/世俗"：verified原子是"神圣"（经过仪式验证），draft原子是"世俗"（未验证）
- 朝圣 = 「阙疑」的"朝圣"：每批原子生产是一次"朝圣"（从draft到verified的"旅程"）

## 三、神话学：比较神话、原型与英雄之旅

**核心**：比较神话学研究不同文化神话的共同结构；原型（archetype，Jung）是跨文化的普遍心理模式（英雄/导师/阴影/骗子）；英雄之旅（monomyth，Campbell）是普遍叙事结构（出发→试炼→回归）；神话为人类提供意义框架。

**对「阙疑」的映射**：
- 比较神话 = 「阙疑」的"比较神话"：不同域的原子生产有共同的"神话结构"（误解→夹具→证据→验证→verified）
- 原型 = 「阙疑」的"原型"：原子类型（mechanism/pitfall/contrast/...）是"原型"（跨域的普遍模式）
- 英雄之旅 = 「阙疑」的"英雄之旅"：每颗原子的"旅程"是"英雄之旅"（draft=出发，红队=试炼，verified=回归/蜕变）
- 神话 = 「阙疑」的"神话"：「阙疑」的"叙事"（从G0到G5到G6的演进）是"神话"（为项目提供意义框架）
- 骗子（trickster） = 「阙疑」的"骗子"：红队是"骗子"（引入必要的混乱/挑战，打破自满）

## 四、文学理论：叙事学、诠释学与后结构主义

**核心**：叙事学（narratology）研究叙事的结构（fabula/syuzhet/视角/时间）；诠释学（hermeneutics）是解释的艺术（理解的循环/前理解/视域融合）；后结构主义挑战固定意义（作者已死/意义的延异/文本的不自足）；读者反应理论强调读者的主动建构。

**对「阙疑」的映射**：
- 叙事学 = 「阙疑」的"叙事学"：原子的"叙事结构"（claim→证据→误解→教学）是"叙事"，需要"叙事学"分析
- 诠释学 = 「阙疑」的"诠释学"：红队对claim/证据卡的"解释"是"诠释学"（理解的循环：从整体到部分再到整体）
- 后结构主义 = 「阙疑」的"后结构主义"：红队的"解构"是"后结构主义"（挑战claim的"固定意义"，揭示矛盾/不自足）
- 读者反应 = 「阙疑」的"读者反应"：读者（学习者）对原子的"理解"是主动建构的，原子设计需要考虑"读者反应"
- 作者已死 = 「阙疑」的"作者已死"：原子的"意义"不取决于Writer的意图，而取决于证据/验证/读者（这解释了为什么需要红队/门禁）

## 五、艺术理论：美学、当代艺术与批评

**核心**：美学研究美与审美经验（康德/黑格尔/阿多诺）；当代艺术挑战传统美学（观念艺术/装置/行为）；艺术批评在"点赞时代"面临危机；计算艺术学（computational aesthetics）用数据/算法研究审美。

**对「阙疑」的映射**：
- 美学 = 「阙疑」的"美学"：「阙疑」的"美"是"精确/可验证/诚实"（科学之美），原子的"优雅"是"美学"标准
- 当代艺术 = 「阙疑」的"当代艺术"：「阙疑」挑战传统"知识生产"（不是写教科书，而是生产可验证的原子），类似"当代艺术"挑战传统美学
- 艺术批评 = 「阙疑」的"艺术批评"：红队是"艺术批评"（对原子的"批评性分析"），人审是"策展人"（选择哪些进入verified）
- 计算美学 = 「阙疑」的"计算美学"：gate_engine/replay是"计算美学"（用算法/数据评估原子的"质量"）
- 灵韵（aura） = 「阙疑」的"灵韵"：verified原子的"灵韵"来自"验证过程"（夹具/证据/红队/门禁），而非原子本身

## 六、文化研究：霸权、表征与身份

**核心**：文化研究（Cultural Studies，伯明翰学派）研究文化与权力的关系；霸权（hegemony，Gramsci）是统治阶级通过文化/意识形态而非强制维持权力；表征（representation）是意义生产的过程；身份（identity）是社会建构的（种族/性别/阶级的交叉性）。

**对「阙疑」的映射**：
- 文化研究 = 「阙疑」的"文化研究"：「阙疑」是一种"知识文化"（有自己的规范/仪式/价值观），需要"文化研究"视角分析
- 霸权 = 「阙疑」的"霸权"：铁律/门禁是"霸权"（通过规范而非强制维持质量标准），但这是"良性霸权"（为了质量而非压迫）
- 表征 = 「阙疑」的"表征"：原子是知识的"表征"（通过claim/证据/误解表征概念），需要分析"表征"的政治（什么被表征/什么被遗漏）
- 身份 = 「阙疑」的"身份"：每颗原子有"身份"（域/类型/主题/编号），身份是"社会建构"的（通过relations/frontmatter建构）
- 交叉性 = 「阙疑」的"交叉性"：原子的"交叉性"（同时属于多个域/类型/主题），需要"交叉性"分析
