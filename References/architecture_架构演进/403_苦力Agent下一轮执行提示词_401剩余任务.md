## 任务 5：C2 四工具 --json 输出（2 小时）

### 目标
给 4 个工具加 `--json` 标志，输出结构化 JSON。不带 `--json` 时文本输出完全不变。

### 修改文件
- `tools/gate_engine.py`
- `tools/atom_evidence_replay.py`
- `tools/poison_drill.py`
- `tools/golden_lock.py`

### 统一 JSON schema（每个工具都按这个结构输出）
```json
{
  "tool": "工具名",
  "version": "v6.1",
  "timestamp": "ISO8601时间",
  "status": "pass|fail",
  "summary": { "具体指标": "值" },
  "findings": [
    {"rule": "规则名", "severity": "block|warn|advice",
     "file": "文件路径", "message": "描述"}
  ],
  "infra_errors": []
}
```
- `summary` 里的具体指标按工具填：gate 填 block/warn/advice；replay 填 confirm/refute/infra_error；poison 填 passed/total；golden 填 atoms/evidence/replay_confirm。
- `--json` 时 stdout 只输出 JSON，日志走 stderr。
- exit code 不变（block>0 → exit 1）。

### 操作顺序（一个工具一个工具改，改完一个跑一次测试）

**5.1 gate_engine.py**
- 加 `--json` 参数解析
- 收集 findings 时同时存结构化数据
- `--json` 时输出 JSON，否则走原有 print
- 测试：`python tools/gate_engine.py --check --json | python -m json.tool`（必须能解析）

**5.2 atom_evidence_replay.py**
- 同上
- 测试：`python tools/atom_evidence_replay.py --check --json | python -m json.tool`

**5.3 poison_drill.py**
- 同上
- 测试：`python tools/poison_drill.py --json | python -m json.tool`

**5.4 golden_lock.py**
- 同上
- 测试：`python tools/golden_lock.py check --json | python -m json.tool`

### 测试要求
在 `tests/` 下新增 `test_json_output.py`，每个工具 1 个测试：
```python
def test_gate_json_parseable():
    result = subprocess.run([...], capture_output=True, text=True)
    data = json.loads(result.stdout)
    assert "tool" in data
    assert "summary" in data
    assert "status" in data
```
4 个工具共 4 个测试。
