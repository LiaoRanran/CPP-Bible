## 一、语言学：claim 的语义角色与框架

### 1.1 核心理论

**语义角色标注（SRL）**：
- Agent（施事）、Patient（受事）、Instrument（工具）、Experiencer（经验者）
- PropBank：ARG0-ARG5 核心角色
- "Ali [Agent] kicked the ball [Patient] with his foot [Instrument]"

**框架语义学（Frame Semantics）**：
- 词义只有在结构化背景知识（框架）中才可理解
- FrameNet：1000+ 框架，每个框架有角色定义
- LLM 可以提取框架语义参数（JSON 表示显著提升）

### 1.2 对「阙疑」的映射

**claim 的语义角色形式化**：

```
claim: "unique_ptr 的删除器是类型的一部分"
  Agent: unique_ptr
  Patient: 删除器
  Instrument: 类型系统
  框架: 类型擦除 vs 类型参数化

claim: "屏障在循环体内阻止消除"
  Agent: 屏障
  Patient: 编译器消除
  Instrument: 循环体位置
  框架: 编译器优化 vs 同步原语
```

**自动检测 claim 的语义完整性**：
- claim 是否有明确的 Agent/Patient/Instrument？
- claim 是否唤起了正确的框架？
- 工具：`tools/claim_srl.py`，用 LLM 提取语义角色，检查完整性

**与本体论的互补**（324）：
- 本体论 = 类层级（ATOM-MEM-RAII ⊑ ATOM-MEM）
- SRL = 语义角色（谁对谁做了什么）
- 两者结合 = 完整的语义表示

## 二、行为经济学：LLM 也有损失厌恶

### 2.1 核心理论

**前景理论（Kahneman & Tversky, 1979）**：
- 参考点依赖：评估结果相对于参考点，不是绝对财富
- 损失厌恶：损失的痛苦约是收益快乐的 2 倍（λ ≈ 2-2.5）
- 概率加权：高估小概率事件，低估大概率事件

**LLM 也有损失厌恶**（2025 研究）：
- GPT-4 在 14 个经典范式中匹配前景理论的价值函数曲率
- 推理模式模型（Claude Opus 4.6/4.7, GPT-o1, DeepSeek-R2）损失厌恶降低但未消除
- 链思维（CoT）有"考虑反面"效应，类似人类的 Mussweiler 效应

### 2.2 对「阙疑」的映射

**Writer 的损失厌恶**：
- Writer 倾向于"保守写"（避免被红队打回的"损失"），而不是"冒险写"（提出新 claim 的"收益"）
- 这解释了为什么"颗粒度失控"（证据卡越来越长，因为 Writer 怕被打回所以加更多留痕）
- 防御：明确告知"红队打回是正常的，平均每颗 1.2 次"，降低损失感知

**红队的损失厌恶**：
- 红队倾向于"严格审"（避免"漏拦"的损失），而不是"高效审"
- 这解释了为什么红队有时"过度审查"（抓小问题而忽略大方向）
- 防御：红队必须区分"阻断级"和"建议级"，不要把建议级当阻断级

**参考点的调整**：
- Writer 的参考点是"上一批的质量"，如果上一批质量高，这一批会更保守
- 可以通过调整参考点来激励创新："这一批允许 1 个高风险 claim，即使被打回也不算失败"
- 概率加权：LLM 可能高估"被红队打回"的概率，需要用真实统计校准

**落地**：
- 提示词中加入"损失厌恶校准"段落：明确打回率、鼓励冒险
- 监控 Writer 的"冒险率"（新 claim 比例），如果持续下降，说明损失厌恶在起作用

## 三、混沌理论：提示词的蝴蝶效应

### 3.1 核心理论

**对初始条件敏感（SDIC）**：
- 微小初始差异指数级发散：|δx(t)| ≈ |δx(0)| · e^(λt)
- 李雅普诺夫指数 λ > 0 = 混沌
- Lorenz 把 0.506127 截断为 0.506，天气模拟完全发散

**奇怪吸引子**：
- 混沌系统有界但不可预测
- 长期行为被限制在某个区域（吸引子）
- 有限尺寸李雅普诺夫指数（FSLE）：统一框架

### 3.2 对「阙疑」的映射

**提示词的蝴蝶效应**：
- 提示词的微小变化（一个词、一个标点）可能导致输出完全不同
- 这就是为什么提示词需要版本控制和 A/B 测试（325 人机交互）
- 可以测量"提示词敏感度"：微小变化导致输出差异的速率

**系统的"混沌区域" vs "稳定区域"**：

| 操作 | 混沌度 | 说明 |
|---|---|---|
| 提示词措辞 | 高 | 微小变化导致输出差异大 |
| claim 表述 | 高 | 一个词的改变可能改变 claim 的可证伪性 |
| replay 验证 | 低 | 确定性输出，可复现 |
| gate 检查 | 低 | 规则匹配，确定性 |
| 红队审查 | 中 | 依赖 LLM 判断，有一定随机性 |

**李雅普诺夫指数的类比**：
- 高敏感度的提示词需要更严格的版本控制和测试
- 低敏感度的操作（replay/gate）可以信任自动化

**奇怪吸引子**：
- 「阙疑」的"吸引子"是"高质量原子"
- 即使路径不可预测（提示词混沌、红队随机），最终都会收敛到这个区域
- 因为门禁系统（replay/gate）提供了"有界性"

## 四、法学：原子体系作为判例法

### 4.1 核心理论

**三种法律推理**：
- 演绎推理：一般原则应用到具体案例
- 归纳推理：从具体案例合成一般原则
- 类比推理：比较当前案例与类似过去案例

**判例法（stare decisis）**：
- 遵循先例：类似案例类似裁决
- 区分先例（distinguishing）：指出当前案例与先例的差异
- 问题禁反言（issue estoppel）：已决事项不能再争议

**法律解释三原则**：
- 文本主义：按字面意思解释
- 目的论：按立法目的解释
- 语境论：按上下文解释

### 4.2 对「阙疑」的映射

**原子体系 = 判例法体系**：

| 法学概念 | 「阙疑」对应 |
|---|---|
| 判例 | 已验证原子 |
| 遵循先例 | 新原子不能与已验证原子矛盾 |
| 区分先例 | 新原子与旧原子的差异点必须明确说明 |
| 问题禁反言 | 已验证原子的 claim 不能被推翻（除非有新证据） |
| 法律解释 | claim 的解释（文本/目的/语境） |

**类比推理 = 红队的"类似案例比较"**：
- 红队应该问："这个 claim 与之前哪个已验证原子类似？有什么不同？"
- 这可以防止"重复造轮子"（与已有原子实质重复，LEAK-001 教训）
- 工具：`tools/precedent_check.py`，自动查找最相似的已验证原子

**法律解释三原则的应用**：
- 文本主义：gate 的模式匹配（按字面检查）
- 目的论：claim 的教学目标（为什么教这个？）
- 语境论：原子的 prereq/contrasts 关系
- 三者结合 = 完整的 claim 解释

## 五、医学诊断：红队的鉴别诊断

### 5.1 核心理论

**鉴别诊断（Differential Diagnosis）**：
- 3-5 个最可能诊断（按概率排序）
- 1-2 个"不能漏"诊断（can't-miss，即使概率低也必须排除）
- 下一步需要什么检查来区分前三个

**假设-检验（Select-and-Test）**：
- 先提出假设（溯因推理：从观察到最佳解释）
- 再用检验排除或确认
- 信息增益：选择最能区分假设的检查

**三推理整合**：
- 归纳（从案例到原则）+ 演绎（从原则到案例）+ 溯因（从观察到解释）

### 5.2 对「阙疑」的映射

**红队的"鉴别诊断"方法**（can't-miss 清单的理论基础）：

```
红队审查一颗原子时：
1. 列出 3-5 个最可能的问题（按概率排序）
   - 断言自证？口径不统一？活性对照缺失？
2. 列出 1-2 个"不能漏"的问题（即使概率低也必须检查）
   - claim 与证据矛盾？夹具被内联？断言恒真？
3. 说明需要什么证据来区分这些问题
   - 看工件？重跑夹具？查历史？
```

**这正是我们 can't-miss 清单的理论基础**！
- "不能漏"问题 = 即使概率低也必须检查，因为漏了是灾难性的
- 例子：断言自证（P4）、恒真观测（P6）、口径不统一（ALLOC-002）、夹具被内联（LEAK-001）

**信息增益 = 夹具设计原则**：
- 夹具应该最大化信息增益（一个实验区分多个假设）
- PERF-003 的"双平台对照"就是信息增益最大化
- 红队应该问："这个夹具能区分哪些假设？不能区分哪些？"

**溯因推理 = 红队的核心能力**：
- 从证据（工件/输出）到最佳解释（为什么 claim 对或错）
- 这比"找问题"更深层：不仅要找问题，还要解释问题的根因

## 六、建筑学：原子体系作为模式语言

### 6.1 核心理论

**Christopher Alexander 的模式语言**（1977）：
- 253 个模式，每个 = 问题陈述 + 讨论 + 解决方案
- 模式语言 = 可组合的设计词汇
- 目标：让没有专业知识的人也能设计高质量环境

**模块化分解原则**（Alexander, 1964）：
- 最小化子系统间的信息传递
- 内部密集连接，外部松散连接

**Alexander 的 15 个生命属性**：
- 强中心、尺度层级、交替重复、边界、局部对称、梯度、正空间、粗糙度等

### 6.2 对「阙疑」的映射

**原子体系 = 模式语言**：

| 建筑学概念 | 「阙疑」对应 |
|---|---|
| 模式 | 原子（问题+解决方案） |
| 模式语言 | 原子体系（可组合的知识词汇） |
| 让普通人能设计 | 让非 C++ 专家的 Agent 能生产高质量原子 |
| 模块化分解 | 域划分（MEM/CONC/UB） |
| 最小化信息传递 | 域之间的依赖关系最小化 |

**Alexander 的 15 个生命属性 → 原子的"健康属性"**：

| 生命属性 | 原子健康属性 |
|---|---|
| 强中心 | 核心 claim 明确 |
| 尺度层级 | 有不同粒度（概述/细节/示例） |
| 边界 | 适用范围明确（precondition/postcondition） |
| 局部对称 | 内部结构一致（frontmatter/正文/证据卡格式统一） |
| 粗糙度 | 有真实的限制和边界（limitations 字段） |
| 梯度 | 难度递进（beginner → advanced） |

**"形式追随功能"**：
- 原子的结构（frontmatter/正文/证据卡）应该服务于教学功能
- 如果某个字段不服务于教学，应该删除（证据卡瘦身，315）

**模块化分解的检查**：
- 域之间的"信息传递"是否最小化？
- MEM 域的原子是否依赖 CONC 域的细节？（不应该，只依赖 prereq）
- 工具：`tools/coupling_check.py`，检查域间依赖

## 九、一句话总结

326 把「阙疑」的理论支撑从二十四学科扩展到**三十学科**。最关键的三个新洞察：

1. **医学的鉴别诊断方法**——红队审查应该用"3-5 个最可能问题 + 1-2 个 can't-miss 问题"的结构，这正是我们 can't-miss 清单的理论基础。can't-miss 问题 = 即使概率低也必须检查，因为漏了是灾难性的（断言自证、口径不统一、夹具被内联）。

2. **法学的判例法类比**——原子体系 = 判例法体系：已验证原子是先例，新原子必须遵循先例（不能矛盾）和区分先例（说明差异点）。红队应该自动查找最相似的已验证原子，防止"重复造轮子"（LEAK-001 教训）。

3. **行为经济学的 LLM 损失厌恶**——GPT-4 在 14 个经典范式中表现出损失厌恶（损失痛苦 ≈ 2× 收益快乐）。这解释了为什么 Writer 倾向于"保守写"（怕被打回）、红队倾向于"严格审"（怕漏拦）。需要用真实统计校准（"平均打回率 1.2 次"），并鼓励冒险（"允许 1 个高风险 claim"）。
