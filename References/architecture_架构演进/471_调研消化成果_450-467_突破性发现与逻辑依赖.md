## 一、突破性发现（4 项，可能改变架构方向）

### 1. TDD 顺序反转（454 T1）——零成本，直击根因

**逻辑链**：ALLOC-002（口径反转）→ LEAK-002（LSan 零报告被推翻）→ EV-MEM-017（`_Znwm` vs `_Znwy`）——根因都是**先写夹具再补断言**，断言被夹具输出锚定成自证。

**改法**：先写断言（基于理论预期，不看夹具输出），再写夹具验证。和 TDD"红→绿→重构"同构。

**价值**：零成本，只改生产顺序。可能直接减少 30-50% 的"断言写死常量/与工件不符"类问题——这正是红队抓得最多的类型。

### 2. 差分测试形式化（462 DIFF1/2）——已有资源，零成本升级

**现状**：阙疑已有五编译器（MinGW 15.3 / WSL g++13.3 / 14.2 / riscv64 13.2 / clang++ 22.1.8），但只用来做 replay 的跨编译器验证，没有显式对比输出差异。

**改法**：同一夹具，多编译器，对比 `.out` 的确定性输出。任何不一致自动标记——**-O0 vs -O2 不一致 = UB 嫌疑**。

**价值**：比 sanitizer 更轻量的 UB 检测方法。CONC-001 的 inline 顺序依赖（-O0 顺序敏感 / -O2 顺序无关）就是差分测试的天然案例，但目前没有形式化为规则。

### 3. 符号执行（456）——验证维从 8 到 10 的关键

**现状**：夹具测试是手工的"n=1000/8000"两点测试，只覆盖两条路径。

**改法**：KLEE 在 LLVM bitcode 上做符号执行，自动覆盖所有路径。KLEE 在 GNU Coreutils 中发现 84 个 10+ 年未被发现的 bug。

**可行性**：教学夹具通常 <50 行，状态爆炸风险低。clang++ 22.1.8 已装好，KLEE 基于 LLVM。

### 4. 覆盖率量化（457 COV1/2）——断言判别力不足的根因

**硬证据**：AI 生成测试 93.1% 行覆盖率，但只有 58.6% 突变杀灭率——超过 1/3 的真实 bug 在 CI 全绿时溜过。

**现状**：阙疑的夹具没有覆盖率数据，不知道断言覆盖了多少路径。402 F03（断言判别力不足）的根因可能就是"断言只覆盖了部分路径"。

**改法**：gcov 是 GCC 内置，零新工具。每颗新原子的夹具跑 gcov，<80% 行覆盖率标 weak。

**和 P1-3 的关系**：覆盖率（执行了没有）+ 突变测试（执行了能不能检测错误）= 双维度闭环。

## 七、第三轮补充（461）

### handoff JSON schema（HAND1/2）——减少人工操作的关键

**现状**：用户每天都在做"写提示词→复制粘贴给 Agent→Agent 产出→复制粘贴回来"的人工 handoff。多模型协作（苦力/好模型/对抗）全靠人工复制粘贴。

**改法**：定义阙疑内部 handoff JSON schema——所有 agent 都在同一仓库、同一文件系统，不需要 A2A 的网络协议层。handoff 和 DAG checkpoint 结合，每个 DAG 节点的产出就是 handoff 的 input_files。

**价值**：大幅减少人工操作，让 DAG 调度器可以自动交接。这是从"人监工"到"系统自调度"的关键一步。

## 九、第四轮补充（374-449 底层架构思想）

### 突破性架构思想（4 项，定义系统长期方向）

#### 1. 级联路由（384）——成本优化的最直接杠杆

**核心命题**：50-70% 的任务不需要最强模型。级联路由（先便宜→验证→不通过升级）因为有确定性验证器，比预测路由更可靠。

**为什么适合阙疑**：预测路由只看输入就决定模型，预测不准时浪费或降级；级联路由能看到便宜模型的实际回答，再用 gate/replay 验证——验证不通过才升级到强模型。FrugalGPT/RouteNLP 实测 40-98% 成本降低，匹配 GPT-4 质量。

**当前状态**：用户已经在人工做路由（苦力干杂活+好模型干重活+对抗模型做对抗），但没有系统化的级联机制。

**落地路径**：定义任务难度分类（机械/语义/创造）→ 机械任务用苦力 → 语义任务用好模型 → 验证不通过自动升级。成本差 10-100×，ROI 极高。

#### 2. 数据飞轮四阶段（385）——系统越用越强的核心机制

**四阶段**：Produce（生产）→ Coach（评估+反馈）→ Distill（提炼）→ Improve（改进）。

**阙疑现状**：已有 Produce（Writer 生成原子）和 Coach（红队+门禁+人审），**缺 Distill 和 Improve**：
- Distill：从失败中自动提炼可复用知识（红队发现→规则候选→毒样例）
- Improve：提示词版本管理+回归测试（改了提示词后，用历史案例验证没退化）

**价值**：这是从"人监工"到"系统自学习"的关键。当前每次红队发现的问题都靠人记下来、写成规则，没有自动化管道。

#### 3. 反事实扰动验证（391）——claim 验证的升级

**核心命题**：claim 验证从"断言锚定"升到"反事实证伪"——如果改一个变量（编译器版本、优化档、平台），claim 还成立吗？

**当前状态**：阙疑已经是"执行接地"验证（夹具实测+双平台 replay），但缺"反事实扰动"——只验证了当前条件下 claim 成立，没验证条件变化后是否还成立。

**和差分测试的关系**：差分测试（462 DIFF1/2）就是反事实扰动的一种形式——同一夹具，多编译器，对比输出。-O0 vs -O2 不一致 = claim 的边界条件。

**实用路径**：完整形式化（Lean/Coq）成本过高，不适合教学夹具场景。实用路径是"反事实扰动+执行接地验证"——自动跑多编译器/多优化档，claim 的适用范围自动显式化。

#### 4. 元模式的元模式（444）——阙疑的核心哲学

**7 条元模式**：
1. 不变量约束优于存在性检查
2. 零 LLM 确定性检查是成本优势
3. 对抗驱动进化
4. 校准是自治的前提
5. 因果推断是实测的理论基础
6. 知识是网络，不是层级
7. 成本是隐形约束

**元模式的元模式**：**把不确定性转化为确定性**。这和系统名字「阙疑」（多闻阙疑，慎言其余）哲学一致——不确定的地方标记为"阙疑"，然后用确定性机制逐步压缩不确定性。

**四道墙的真实高度**（445 修正）：
- 100% 正确：可形式化语义 100% 正确，不可形式化语义高概率正确
- 零成本：零边际成本做得到（已知问题全变规则后），零总成本做不到（新问题永远需要红队）
- 完全自治：可验证部分完全自治做得到，教学效果自治做不到
- 零误报：低误报（5-15%）做得到，零误报做不到（No Free Lunch）

## 十一、第五轮补充（300-369 哲学底座与认知形式化）

### 系统"宪法"：五条生成性原理（367）

整个体系不可再分的内核只有五条。所有机制（replay、sha、红队、四级状态、认知环、毒样例）都是这五条的实例：

- **P1 独立可证伪**：任何主张必须能被独立于生产者的验证路径锚定到机械硬事实。判断链硬度梯度：机械硬事实（退出码/hash/汇编符号）> 确定性工具（gate/replay）> 结构化评审（红队）> 个人判断。追溯不到硬事实的标记为"悬置判断"。
- **P2 发现-辩护分离**：发现语境允许狂野（单脑流动+六顶帽），辩护语境必须对抗隔离（多脑对抗+物理隔离）。发现侧不设质量门，辩护侧不开后门。
- **P3 错误必沉淀且可遗传**：每个真实错误必须变异为可执行约束+毒样例，跨域遗传。新规则必须同时交阳性毒样例（抓得住）和阴性毒样例（不误伤）。只对真实失败立法，不对想象风险立法。
- **P4 认知预算下信息增益最大化**：下一个动作投给"预期信息增益÷成本"最高者。**停止规则**：连续两轮批判新增 P0=0 且工程线有待验证产物 → 强制放行，停止架构、回到生产。
- **P5 向更可执行处流动并持续修剪**：信息沿"过程→结论→规则→默认"单向浓缩。只积累不修剪=囤积，不是智能。

### 认知层形式化（359/360）

**科学发现状态机**（359）：S1 异常观测 → S2 溯因建模 → S3 假设竞争（≥2 假设，至少 1 个反直觉）→ S4 判别实验设计 → S5 执行 → S6 固化。
- 判别实验不是"验证 H1 的实验"，而是"**结果在 H1 和 H2 下必然不同**"的实验。
- 溯因推理（Abduction）：观测到异常 F → 找能解释 F 的最佳假设 H。溯因是或然的，不是证明。
- 这就是 MCC 最小闭环的理论基础。

**知识进化论**（360）：命题（原子）→ 理论（命题网络）→ 范式（世界观）。
- 拉卡托斯研究纲领：硬核（不轻易放弃的核心假设）+ 保护带（遇异常优先调整的辅助假设）。
- 范式健康度：progressive（预言成功>补丁）→ degenerating（补丁数>预言成功数）→ crisis（竞争理论出现）→ replaced（新理论解释全部旧知识+异常）。
- 范式转换规则：新范式必须解释旧范式下所有 verified 原子（不能丢知识）。

### 哲学底座（318）

- **反脆弱**（Taleb）：红队不是成本，是反脆弱的必要压力源。没有红队的系统会腐烂。系统从错误中获益、变强——阙疑已经是反脆弱的，但需要自觉化。
- **证伪强度分级**（Popper）：弱（"可能提高性能"，不可证伪）/ 中（"大对象时更快"，需定义边界）/ 强（"n>10000 时快 >2x"，冒险预测）。每次证伪产生新问题→新规则。
- **元认知监控**：系统不仅执行任务，还要监控自己的执行过程。

### 跨学科交叉洞察（349，7 个交叉中最有价值的 3 个）

1. **知识证据等级**（证据法×信息科学）：证据卡加等级字段（一/二/三/四级证据），解决"证据卡是留痕非证据"。小工作量，高价值。

3. **claim 指称语义**（解释学×程序语义）：提取 claim 的可观测推论集合，为 claim 形式化提供中间路径（不需要完全形式化，先提取推论）。

## 十五、第六轮补充（271-299 哲学批判与跨领域调研）

### 271 架构批判十问："概念过剩、判据稀缺"

对 v3 架构的自我审判，六大致命批判：

1. **oracle 问题回魂**——v3 引入 QuickCheck 式生成性探索，但 oracle 是 LLM 自己（"性质"由 LLM 写，"反例是否反驳"也由 LLM 判）。收敛：废除"性质探索覆盖未知的未知"，降级为"已知算子库的枚举"，LLM 只提议不裁决。
2. **迪昂-蒯因滑坡**——"怀疑一切"导致无限回归。收敛：定义信任基线协议（默认可信源+怀疑触发条件四条），假设链只保留一层。
3. **概念债务与接口未整合**——每轮加概念没有退役，状态机两套并存。收敛：架构收敛契约，每轮升级附概念保留/合并/退役表，概念总数设上限（状态≤6、机制≤6）。
4. **"共同体"是假独立**——Writer/RedTeam/Gatekeeper 是同一模型家族的三个角色，共享盲区。收敛：独立性定义改成工具链级（编译器/sanitizer/标准原文），LLM 只定位不裁决。
5. **认知转化后端工程落差**——无学习者数据，教学法有争议。收敛：降级为研究议程，需真实学习者实证（n≥20）。
6. **哲学自洽**——客观锚的地位含糊。收敛：客观锚是"实用基线"而非"认识论特权"，客观锚定真值下限，融贯管解释排序。

**最锋利的一句话**："缺判据=不算机制，算隐喻。"——每个机制必须配一个可计算判据，否则只是哲学名词。

### 277 架构宪法：五条公理 + 判定权矩阵

系统的"单一事实源"（single source of truth）：

**五条公理**（违反即 BLOCK）：
1. 模型是提议器，系统是判定者——LLM 永不裁决自己产物的对错
2. 无客观锚不断言——每个 claim 必须追溯到真机输出/标准原文/≥2 独立源
3. 验证必须独立于生成——红队用独立上下文
4. 知识必须可复算、可证伪、可回滚
5. verified 唯人签——无人时系统自纠错到"可签"状态并悬置

**判定权矩阵**（宪法核心）：
| 活动 | 提议权 | 判定权 | 签署权 |
|---|---|---|---|
| 写 claim/夹具/叙事 | Writer（模型） | — | — |
| schema/客观锚/复算/符号 | — | 机器门禁 | — |
| 语义自洽/隔离假设/恒真断言 | — | 独立红队 | — |
| 争议立场/价值终裁/verified | — | — | 人 |
| 判自己产物对错 | **无人有此权** | — | — |

一句话：**模型提议 → 机器判客观 → 独立红队判语义盲区 → 人签真理。**
