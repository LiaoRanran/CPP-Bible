# 377 认知智能与教学转化：从搜集到应用

> 日期：2026-09-13。监工完成，覆盖系统进化阶梯的两端：输入端（自主发现）和输出端（知识回流）。
> 与 374（语义自律）、375（证据智能）、376（鲁棒性+编排）合起来覆盖完整进化路径。
> 流程：搜集 → 整理 → 挖掘 → 联系 → 批判 → 结合 → 应用。

## 一、搜集（搜了什么）

两路并行检索：
1. 自主选题 / 假设生成 / 概念发现 / 新颖性检测 / AI科研选题
2. 知识库到教学内容自动生成 / 教材生成 / RAG教学助手 / 知识回流

核心来源（12 份高相关）：
- Chain of Ideas（arXiv 2410.13185）：文献链结构+Idea Arena评估
- AutoResearcher（arXiv 2510.20844）：五维度新颖性评估
- Deep-Ideation（OpenReview）：科学概念网络上的Explore-Expand-Evolve
- AScience/ASCollab（OpenReview）：假设狩猎+异构Agent自组织演化网络
- IDEAgent：质量-多样性搜索演化想法种群
- A Vision for Auto Research（arXiv 2504.18765）：文献→想法→方法三阶段
- Slide2Text（arXiv 2503.17710）：PPT→定制化教材
- 上海交大"交学伴"：知识图谱增强教学推理
- EduRAG（IJFMR）：多模态资源→统一知识库→带引用的解释

## 二、整理（分类）

| 类别 | 核心问题 | 代表工作 |
|---|---|---|
| A. 新颖性评估 | 怎么判断一个想法值不值得做 | AutoResearcher 五维度 |
| B. 想法链/概念网络 | 怎么从已有知识发现下一个问题 | Chain of Ideas、Deep-Ideation |
| C. 假设狩猎 | 持续探索假设空间而非批次制 | AScience/ASCollab |
| D. 质量-多样性搜索 | 既保质量又保方向多样性 | IDEAgent |
| E. 可验证引用教学 | 教学内容每个断言可追溯到证据 | Textbook-Embedded VTA、RUCAI |
| F. 知识图谱增强教学 | 用概念关系组织教学顺序 | 交学伴、多模态KG+RAG |
| G. 从知识库生成教材 | 原子→教材章节/练习/解释 | Slide2Text（反向用） |

## 三、挖掘（每个类别的核心洞察）

**A. 新颖性五维度**：技术新颖性（新算法/方法）、问题新颖性（未探索的问题/gap）、应用新颖性（已有方法到新域）、理论新颖性（新理论洞察/框架）、实证新颖性（新实验设计/评估方法）。每个维度给评分+理由，不是总分。这比"我觉得有意思"客观得多。

**B. 想法链**：把相关文献组织成渐进发展链（A→B→C的演进关系），而不是平铺。LLM在链结构上更容易捕捉"下一个自然的问题"。关键不是"有多少知识"，是"知识之间的演进关系"。

**C. 假设狩猎**：不是批次制（一批做3颗然后停），而是持续探索——异构Agent自组织成演化网络，在共享标准下持续产出和同行评审。核心隐喻：hunting（狩猎）不是 farming（耕作），是主动追踪有价值的线索。

**D. 质量-多样性搜索**：演化候选想法种群，同时保留高质量和多样性——避免所有想法都挤在同一个方向。这对我们"批次选题"有直接启发：每批应该有不同类型的原子（mechanism/pitfall/contrast/performance），而不是全是同一类。

**E. 可验证引用教学**：教学内容的每个断言带可验证的教材引用，学生能追溯到原文。实验显示这比"AI直接回答"可靠得多——因为回答被grounded在权威材料里。这正是我们Book↔原子同步的目标。

**F. 知识图谱增强教学**：概念之间的先修关系、依赖关系、对比关系，用来组织教学顺序和推理。我们的relations DAG（prereq/contrasts/serves）就是这个知识图谱——可以用来生成Book的教学逻辑。

**G. 从知识库生成教材**：Slide2Text是从PPT→教材，我们可以反向用：从原子（claim+证据+误解+夹具）→生成Book章节的解释/练习/常见错误。关键约束：必须从原子生成，不能让LLM自由发挥，否则破坏可核验性。

## 四、联系（和我们系统的映射）

| 外部发现 | 我们的现状 | 差距 |
|---|---|---|
| A. 五维度新颖性 | 凭直觉选下一批原子 | 没有结构化选题评估 |
| B. 想法链 | 27颗原子是平铺的，relations不完整 | 没有按演进关系组织 |
| C. 假设狩猎 | 批次制（一批3颗） | 没有持续探索循环 |
| D. 质量-多样性 | 批次内原子类型随机 | 没有刻意保持多样性 |
| E. 可验证引用 | Book 147章引用 ATOM id=0 | 完全没做引用同步 |
| F. KG增强教学 | relations DAG有雏形但不规范 | N1双写法没归一，无法用 |
| G. 原子→教材 | book_atom_sync.py 224行未收编 | 工具存在但没落地 |

**已有的雏形**：relations DAG就是知识图谱雏形；三权分立就是持续评审的雏形；book_atom_sync.py就是教学转化的雏形。但都没完成。

## 五、批判（哪些不适用、哪些有局限）

1. **新颖性评估需要大量已有知识做对比**——我们只有27颗原子，覆盖面太小，五维度评分不准。需要先扩大覆盖面（至少50+颗），新颖性评估才有意义。
2. **想法链需要relations结构化**——N1双写法归一还没修完，relations字段不规范，无法可靠地组织成链。这是前置依赖。
3. **假设狩猎的持续循环需要稳定的Agent编排**——我们当前还是批次制+人工裁决，离自组织演化网络很远。短期只能做"批次内持续迭代"，做不到全天候狩猎。
4. **教学内容自动生成容易引入错误**——必须严格从原子生成，每个断言绑定原子id，不能让LLM自由生成。这比通用的"AI生成教材"约束强得多，但也安全得多。
5. **多模态知识图谱对C++域可能过度**——C++知识主要是文本+代码+实测，不需要视频/音频/OCR处理。交学伴的多模态预处理不适用。
6. **质量-多样性搜索的"多样性"需要定义类型体系**——我们的原子type有10类（mechanism/pitfall/contrast/...），可以用type分布做多样性指标，但这需要先确认type体系本身合理。

## 六、结合（和已有架构的结合点）

**和 375 跨原子矛盾检测结合**：想法链和矛盾检测都需要relations DAG——两者共享基础设施，relations归一后可以同时做。

**和 374 语义自律结合**：新颖性评估需要claim结构化（才能判断"这个claim和已有claim是不是重复/矛盾/递进"），语义自律落地后才能做。

**和 376 多模型编排结合**：假设狩猎的持续循环需要小模型做初筛、大模型做深度评估——376的任务分级直接适用。

**和 book_atom_sync.py 结合**：教学转化就是这个工具的目标，收编后优先做"Book章节↔原子id引用同步"，再扩展为"从原子生成教学内容"。

**和 G6 状态体系结合**：自主选题的候选想法可以作为draft级原子进入流水线，经过machine-verified→human-verified的标准流程。

## 七、最终应用（分阶段落地）

### 立即落地（轻量，流程改进）

**应用 1：选题评估模板**
- 下一批选原子时，用五维度（技术/问题/应用/理论/实证新颖性）+ 教学覆盖度（Book里有没有对应章节）打分
- 每批至少包含2种不同type的原子（质量-多样性）
- 这不需要新工具，改选题提示词即可

**应用 2：Book↔原子引用清单**
- 扫描Book 147章，列出每章应该引用哪些原子（基于关键词/概念匹配）
- 产出引用清单，不自动改Book（人审后再改）
- 这是教学转化的第一步，零风险

### 中期落地（需要一些工程）

**应用 3：relations归一后做想法链分析**
- N1双写法归一后，把原子按prereq/contrasts/serves组织成演进链
- 识别链的末端（"下一个自然问题"），作为选题候选
- 这是B类的最小落地

**应用 4：book_atom_sync.py 收编+引用同步**
- 评估224行工具与W1/A3功能重叠，收编或重写
- 实现Book章节→原子id的自动引用插入
- 这是E类的落地，直接解决"Book引用id=0"

### 长期落地（需要更多基础设施）

**应用 5：从原子生成教学内容**
- 用原子的claim+证据+误解+夹具生成Book章节的解释/练习/常见错误
- 每个生成的断言绑定原子id，保持可核验
- 这是G类的落地

**应用 6：持续假设狩猎循环**
- 从批次制升级为"持续探索+定期评审"——建设者持续产出候选，红队持续评审，监工定期裁决入库
- 需要376的checkpoint/resume和多模型编排做支撑

## 九、局限与后续

- 本调研聚焦"认知智能+教学转化"，未覆盖"元认知/自我监控"（系统知道自己在做什么、进度如何）——那是更上一层，留待未来。
- 认知智能的落地高度依赖前置基础设施（语义自律+relations归一+覆盖面），不能跳过374直接做377。
- 教学转化的自动生成必须保持可核验性，这是和通用"AI生成教材"的本质区别——我们生成的每个断言必须能追溯到原子+证据。
- 假设狩猎的持续循环是终极形态，但当前批次制更适合额度有限的环境——持续循环会烧更多额度。
