## C1：声明-实现绑定（3 小时）

### 目标
堵住 373 绕过测试发现的"声明-实现脱钩"（N4 借工件、B7 command 复制别卡工件）。

### 修改文件
`tools/atom_evidence_replay.py`

### 具体改动

**C1.1 编译器版本比对**
重编译时，在执行 command 前先捕获实际编译器版本：
```python
# 伪代码——实际实现按现有代码风格
compiler_actual = run(f"{compiler_path} --version")
if card_compiler_version not in compiler_actual:
    return InfraError("compiler_mismatch",
                      expected=card_compiler_version,
                      actual=compiler_actual)
```
- 卡内字段 `artifact_compiler` 必须是实际 `--version` 输出的子串
- 不匹配 → `infra_error:compiler_mismatch`（不是 refute，是环境问题）

**C1.2 command 借用检查**
扫描 command 文本，发现以下模式直接 block（不执行）：
- `cp ` / `copy ` / `mv ` / `move ` 后跟 `.asm`
- Python `shutil.copy` / `shutil.move`
- 任何对 artifact 目标路径的写入（除了编译器自身的 `-o` 输出）

实现：简单正则/子串匹配即可，不做完整 shell 解析。
```python
FORBIDDEN_ARTifact_OPS = [
    r'\bcp\b.*\.asm', r'\bcopy\b.*\.asm',
    r'\bmv\b.*\.asm', r'\bmove\b.*\.asm',
    r'shutil\.(copy|move)',
]
```
命中 → `refute:artifact_command_borrowed`（这是内容问题，不是环境问题）。

**C1.3 重编译 sha 比对（--verify-artifact）**
- 新增 `--verify-artifact` 标志（默认关闭，CI 开启）
- 重编译产物写到**临时目录**（不覆盖盘上工件）
- 比对临时产物 sha vs 卡内 artifact_sha256
  - 一致 → confirm
  - 不一致 → `refute:artifact_stale`（工件与断言不同代）
- 比对完删除临时目录

### 测试要求
在 `tests/test_atom_evidence_replay.py` 新增：
1. `test_compiler_mismatch_detection`：卡内写 g++-99，实际是 g++-13 → infra_error
2. `test_command_borrow_cp_blocked`：command 含 `cp other.asm x.asm` → refute
3. `test_command_borrow_shutil_blocked`：command 含 shutil.copy → refute
4. `test_verify_artifact_sha_match`：同代工件 → confirm
5. `test_verify_artifact_sha_stale`：旧 sha → refute:artifact_stale
6. `test_verify_artifact_temp_cleanup`：跑完临时目录被清理

### 验收
```powershell
python -m pytest tests/test_atom_evidence_replay.py -v  # 新测试全过
python tools/atom_evidence_replay.py --check  # 存量 56 卡不新增 refute
python tools/gate_engine.py --check  # block=0
python tools/poison_drill.py  # 毒样例仍全拦
```

**重要**：如果存量卡因为新检查出现 refute，不要改卡——报告为"存量技术债"，由人决定。

## C2：工具 JSON 输出（2 小时）

### 目标
5 个核心工具支持 `--json` 标志，输出结构化结果，为未来 MCP 化做准备。

### 修改文件
- `tools/gate_engine.py`
- `tools/atom_evidence_replay.py`

### 统一 JSON schema
```json
{
  "tool": "gate_engine",
  "version": "v6.1",
  "timestamp": "2026-09-13T...",
  "status": "pass|fail",
  "summary": { "block": 0, "warn": 8, "advice": 0 },
```

- exit code 语义不变（block>0 → exit 1）

### 测试
每个工具加 1 个测试：`--json` 输出能被 `json.loads()` 解析，且 `summary` 字段齐全。

### 验收
