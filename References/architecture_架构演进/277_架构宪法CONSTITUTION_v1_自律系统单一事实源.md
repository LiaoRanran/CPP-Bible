## 一、五条公理（不可动摇，违反即 BLOCK）

1. **模型是提议器，系统是判定者。** LLM 永不裁决自己产物的对错；判定必须来自客观源或独立上下文。外部背书：Self-Correction Blind Spot、Circular Trust、correlated error（275 源④）。
2. **无客观锚不断言。** 每个 claim 必须能追溯到真机输出、标准原文、或 ≥2 个独立源；未采集标「未采集」，禁止编造。
3. **验证必须独立于生成。** 红队用独立上下文（不给 Writer 草稿全文，只给断言清单+夹具+工件），否则验证信号与生成错误相关、近乎无信息。
4. **知识必须可复算、可证伪、可回滚。** 断言锚常量+活性对照（不锚时序/倍数/地址）；每一步有检查点与回滚路径。
5. **verified 唯人签（human:liaoranran）。** 无人时系统自纠错到「可签」状态并**悬置**，绝不越权签署——这是诚实边界，不是缺陷。

## 二、当前生效架构（认识论 + 四层 + 横切纪律）

```
                    阙疑 EPOCHE（认识论：悬置判断，探究网络为唯一内核）
                                      │
        ┌──────────────┬──────────────┼──────────────┬──────────────┐
     护栏 L1–L6      杠杆 S1–S5     锻炉 FORGE      前额叶 META
   （防错·客观判定） （托举弱模型）  （生成·放开）    （元决策·判断）
        └──────────────┴──────────────┼──────────────┴──────────────┘
                                      │
              横切纪律（276）：blast radius · error budget · prereq 边 · 环节减法
                                      │
                         六态状态机 + 候选仓物理分仓
```

- **认识论——阙疑 EPOCHE**（270，经 271 修正）：悬置判断；所有活动 = 探究图上的算子；冲突不否决，先进溯因（open-inquiry）。
- **护栏 L1–L6**（272）：L1 Schema → L2 客观锚 → L3 双源 → L4 毒样 → L5 元审计 → L6 检查点。
- **杠杆 S1–S5**（272）：S1 降维 / S2 检索引用 / S3 黄金样例 diff（**只校 schema 形式，不罚内容创新**）/ S4 分档路由 / S5 增量上下文。
- **锻炉 FORGE**（274）：四算子（变异·类比·反事实·组合）→ 候选仓 `candidates/`（发散不设防）→ 检验闸（六层护栏+判别实验，收敛有判据）。
- **前额叶 META**（274）：问题分级路由（已知/未知/争议/创造）· 信息增益停止条件 · 价值函数 f(教学,工业,历史,创新增量)。
- **横切纪律**（276）：爆炸半径（单次破坏边界）· error budget（批次质量透支）· prereq 先决边（知识结构）· 环节减法（可靠性衰减）。

## 三、判定权矩阵（宪法核心：谁能判什么）

| 活动 | 提议权 | 判定权 | 签署权 |
|---|---|---|---|
| 写 claim / 夹具 / 叙事 | Writer（模型） | — | — |
| schema / 客观锚 / 复算 / 符号 / 预算 / 爆炸半径 | — | **机器门禁**（gate/replay/poison/lock） | — |
| 机器盲区：语义自洽、隔离假设、实质重复、自证/恒真断言 | — | **独立红队**（独立上下文） | — |
| 争议立场、价值/品味终裁、5 分授予、verified | — | — | **人（human:liaoranran）** |
| 判自己产物对错 | **无人有此权**（公理 1/3） | — | — |

一句话：**模型提议 → 机器判客观 → 独立红队判语义盲区 → 人签真理。** 生产方不能自判无逃逸（error budget 的消耗判定权归独立方）。

## 四、唯一状态机（六态 + 信任字段 + 候选分仓）

```
draft → anchored ─┬─→ cross-checked →(人在，可选)→ [human-signed 背书标记，非状态] → published
                  └─→ open-inquiry ⇄ contending ─┘
```

- 六态：`draft / anchored / open-inquiry / contending / cross-checked / published`（**状态 ≤6，硬上限**）。
- 信任度是**字段**不是状态：`anchored / cross-checked` 作信任标记；`disputed` 已并入 open-inquiry（冲突一律先进溯因，不直接否决）。
- `contending` 合法性：客观触发条件 + 有实验日程 + 复审期 ≤N 天，否则悬置沦为懒惰（BLOCK）。
- **候选仓物理分仓**：FORGE 产物在 `candidates/`（未检验，不进此状态机、永不冒充证据）；过检验闸才进入 draft。**T14（候选冒充 verified 塞进 atoms/）零容忍。**

## 五、8 环节流水线（P0-4 减法后）+ 分档路由

| # | 环节 | 性质 | 职责 |
|---|---|---|---|
| 1 | 任务分级路由 | 机械+模型 | META 路由已知/未知/争议/创造 |
| 2 | 取证 | 机械 | 夹具+真机+工件 sha |
| 3 | 落卡 | **模型** | Writer 只写机器判不了的叙事/类比/概念转变 |
| 4 | 机器门禁 | 机械 | gate/replay/poison/lock |
| 5 | 红队（独立上下文） | **模型+独立源** | 携带「机器盲区清单」入场，不重复机械化检查 |
| 6 | 修复循环 | **模型** | ≤2 轮，超限升级人审，不硬改 |
| 7 | 人审 | 人 | 只复核边界 + 授予 5 分/verified |
| 8 | 原子化+锁同步 | 机械 | git mv + frontmatter + golden_lock |

**环节数 ≤8、模型环节 ≤3（3/5/6），机械环节兜底。** 砍的是重叠（自评只留叙事、红队只查盲区），制衡不减。

**分档路由（S4）**：
- 弱模型 × 无人：只做可机械判定段，产物止于「可签悬置」，不越权；
- 强模型 × 有人：全流程，人审聚焦价值与争议；
- 任何档：客观锚、独立验证、检查点不允许关闭。

## 六、无人自纠错闭环（正面回答「离开人也能纠错」）

**无人时系统能做到**：① 所有可机械判定的错全部堵完（L1–L6）；② 独立红队查完机器盲区；③ 修复循环 ≤2 轮；④ 仍有争议/无法验证的，悬置进 open-inquiry 或 candidates/，并写明缺什么证据才能收敛。

**无人时不做（诚实边界）**：不越权置 verified、不终裁价值争议、不把候选当真理。

结论：**人不是系统正确性的必要条件（机器+独立红队已能自纠错到「可签」），但人是真理层（published/verified）的必要条件。** 人在，只是让签署更直观、让品味判断在场；人不在，系统把活干到「等人签」而不是「假装签完」。

## 七、两条价值轴的量化目标

- **自律轴（下限）**：GAUNTLET 逃逸率 ≤20%；全监督档逃逸 =0；中断后检查点续作 =100%；T14 污染假阳性 =0；error budget 耗尽即锁库。
- **性能轴（上限+效率）**：最便宜档 × FORGE 全开 vs 最强档无脚手架，候选质量差 ≤15%；环节 ≤8、模型环节 ≤3；单轮上下文消耗可测下降（S5/动态选择）；断言锚只锚常量+活性对照。
- **创造力轴**：候选产出 >0、检验闸通过率 20–50%、创新增量（原子图距离）>0、假阳性 =0。
- **睿智轴**：路由正确率 ≥95%、信息增益停止条件触发、价值函数可算。

## 九、修宪程序（amendment）—— 此后架构这样演进

277 之后**不再新增并列架构文档**。任何架构变更走修正案：

1. **触发**：外部论文/项目实证/GAUNTLET 逃逸/红队系统性盲区，四选一，须有证据。
2. **提案**：写明 机制 + 机械判据 + 落点 + 退役了谁（无判据 = 隐喻，拒收）。
3. **批判**：独立红队过一遍（含「这是不是又在加概念」）。
4. **生效**：宪法版本号 +0.1（机制级）或 +1.0（公理级），旧版进档案；概念超上限（状态/机制各 ≤6）必须先退役再新增。
5. **复测**：机制变更必须 GAUNTLET 复测逃逸率不升高，否则回滚。
