#### Step 2：创建攻击用例注册表

#### Step 3：实现回归测试运行器

`tools/attack_regression.py`：
```bash

python tools/attack_regression.py run --type A4  # 只跑 A4 类
python tools/attack_regression.py report       # 输出拦截率报告
```

**运行逻辑**：
1. 从注册表加载所有 status=fixed 的攻击用例
2. 对每个攻击用例，构造最小复现（卡+夹具+command）
3. 跑 gate_engine.py，检查是否触发预期的 rule
4. 统计拦截率 = 被拦住的攻击数 / 总攻击数

## 任务 2：426 时序约束框架（InvariantChecker 类）

### 架构设计文档

`References/architecture_架构演进/426_架构设计_时序约束通用框架_不变量约束优于存在性检查.md`

### 问题

414 P0-3（F02）已经手写了时序检查（编译后无覆写），但这是"单点修复"。426 的目标是把时序/代际/空间三类不变量抽象为通用框架，让所有新规则按不变量约束设计，而不是各自手写。

### 实现

#### Step 1：创建 InvariantChecker 类

在 `tools/gate_engine.py` 中新增（或独立模块 `tools/invariant_checker.py`）：

```python
class InvariantChecker:
    """
    不变量约束检查器：支持时序、代际、空间三类不变量。
    所有新 gate 规则应使用此框架，而非手写存在性检查。
    """

    def __init__(self, command=None, artifact_path=None,
                 artifact_content=None, fixture_source=None):
        ...

    # === 时序不变量 ===
    def after_line_no_write(self, marker_line, target_path):
        """marker_line 之后，没有对 target_path 的写操作。"""
        ...

    def after_line_no_command(self, marker_line, command_pattern):
        """marker_line 之后，没有匹配 command_pattern 的命令。"""
        ...

    # === 代际不变量 ===
    def same_generation(self, claimed_sha, regenerate_func):
        """claimed_sha == 重新生成的 sha。"""
        ...

    def same_command_as_out(self, card_command, out_command):
        """.out 的生成命令与卡的 command 一致。"""
        ...

    # === 空间不变量 ===
    def symbol_in_artifact_not_comment(self, symbol, artifact_content):
        """symbol 在 artifact_content 中存在，且不在注释中。"""
        ...

    def symbol_in_function(self, symbol, function_name, artifact_content):
        """symbol 在指定函数体内存在。"""
        ...

    # === 内部工具 ===
    def _detect_write_ops(self, command_text, target_path):
        """检测 command_text 中对 target_path 的写操作（7 种）。"""
        ...

    def _strip_comments(self, content):
        """剥离 C/C++/asm 注释。"""
        ...
```

#### Step 2：实现 _detect_write_ops（核心）

支持 7 种写操作：
1. `cp <src> <target>`
2. `mv <src> <target>`
3. `python -c "import shutil; shutil.copy(...)"`
4. `powershell Copy-Item <src> <target>`
5. `cmd copy <src> <target>`
6. `command > <target>`（重定向）
7. `command >> <target>`（追加）

**关键**：不是黑名单，是"target 路径出现在写位置"的语义检测。如果无法确定语义，给 warn（保守）。

#### Step 3：重构 EV-ARTIFACT-PRODUCER 使用 InvariantChecker

把 414 P0-3 的手写时序检查重构为 `after_line_no_write()` 调用。

**重构是纯代码整理，不改变行为**——用 P32/P33 毒样例验证不回归。

#### Step 4：重构 EV-ASSERT-SYMBOL-MAPPED 使用空间不变量

把通用符号检查重构为 `symbol_in_artifact_not_comment()` 调用。

#### Step 5：pytest

```python
class TestInvariantChecker:
    def test_after_line_no_write_python(self):
        # python 覆写 → 检测到写操作
        ...

    def test_after_line_no_write_powershell(self):
        # powershell 覆写 → 检测到写操作
        ...

    def test_after_line_no_write_redirect(self):
        # > 重定向 → 检测到写操作
        ...

    def test_after_line_no_write_clean(self):
        # 编译后无写操作 → 通过
        ...

    def test_symbol_in_artifact_not_comment(self):
        # 符号只在注释中 → 检测失败
        ...

    def test_same_generation(self):
        # sha 一致 → 通过；不一致 → 失败
        ...

    # ≥10 例
```
