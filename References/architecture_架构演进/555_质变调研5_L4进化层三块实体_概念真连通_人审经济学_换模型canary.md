# 555 · 质变调研（五）：L4 进化层的三块实体 —— 概念真连通 / 人审经济学 / 换模型不退化

> 前四轮（549-552）补的是"验证器怎么更强"。这轮回答一个更根本的问题：**L4 进化层到底长什么样？** 检索 2026-09-16。结论：L4 不是一个宏大模块，而是一台**自我校准引擎**，由三块组成——知识层校准（概念真连通）、人审预算校准（谁值得人看）、模型层校准（换了没退化）。现在这三块在系统里要么是零、要么是散的。

## A · 概念真连通：从标签袋到可推理概念图
**我们的病（实测）**：529 批判"概念层 157 节点跨原子连通 0"。根因不是没抽概念，是**没做实例层融合**——同一个"内存屏障"在 FENCE-001 叫 `内存屏障(fence)`、在 PERF-002 叫 `栅栏`、在 ATOM-MEM 叫 `barrier`，三者各成一个节点，自然全是孤立标签。

**业界正解（三篇收敛）**：
- Wikontic（arXiv:2512.00590）：抽三元组 → ontology 类型/关系约束 → **实体归一化去重**，得到 compact/well-connected 图（正确答案实体落在 96% 三元组）。
- CORE-KG（2510.26512）：**type-aware 共指消解 + domain-guided 结构化 prompt**，专治"重复节点、碎片图"——和我们的病一模一样。
- LLM-KG 综述（2510.20345）：instance-level fusion = entity alignment + 共指 + dedup + conflict resolution；从启发式聚类演进到 reasoning-based 判别。
- 顶向下/底向上混合（2608.07023）：**orphan 不丢弃**——孤立节点单独路由，给它生成"它该连谁"的细粒度边。

**批判吸收（守纪律：不用 embedding、不让 LLM 自动入库）**：
1. 我们已有 `concept_aliases.txt`（527，11 条整串别名）——这是**人工版实体归一**，方向对但命中率太低（整串匹配，"栅栏"匹配不上"内存屏障(fence)"）。
2. **L1 机械升级（现在做）**：把概念名做**核心词归一**——去括号注释、去修饰、小写、去同义后缀（fence/barrier/屏障 归一词族），用确定性词表而非 embedding。归一出的"同一概念候选"不自动连，列成**人审合并候选清单**（哪些概念节点疑似同一个），人拍板才合边。
3. **orphan 处理（现在做，正合 2608 的做法）**：跨原子连通=0 的 157 个概念不是垃圾，是孤儿。机械地给每个孤儿找"共享同一张原子/同一批命题/归一后核心词相同"的候选邻居，输出 `concept_candidates_for_review.md`——**系统主动说"这两个概念我怀疑是同一个，你看一眼"**，而不是干等。这就是 L4 进化的最小骨架：系统自己发现知识缺口，递人审。
4. 严守边界：概念合并永远要人签（551 已降级 Dung 求解器，同理，概念合并不自动）；机械只产候选。

## B · 人审经济学：136 条 warn 不该平铺，要排队
**我们的病**：warn 136 条四桶全 0、未分类，人要一条条看——而人是唯一瓶颈（你亲自说"人就一个苦力"）。

**业界正解（三篇高度收敛）**：
- 主动学习三采样（Maxim/QASkills/aldeiadaponte 一致）：**不确定性采样**（判定贴边界的优先）、**多样性采样**（每类至少覆盖一条，别让人审 136 条同一 rule）、**分歧升级**（多信号打架才升级人）。
- *When Should Humans Step In*（2603.13688）：人审派遣按**边际价值**——哪些人审对最终决策质量提升最大；AI 同行评审实测，按 acquisition rule 选择性问人，用一小撮人审逼近全人审质量。
- Galileo SME-agreement-gap：headline 80% 一致会藏住 edge case 分裂——aggregate 数字看不见人审真正该看的偏差。
- Nugget 人审（2606.29033）：人审不是打一次分，是**调 judge 的权重**——人审结果反哺规则/分类器本身。

**批判吸收（现在做，纯排序逻辑，零新依赖）**：
1. **人审队列优先级 = KIL × 不确定性 × 首次出现**（把 550 设计的 KIL 真正用起来）：
   - KIL（危害度 H=错了多严重 × 被多少原子引用）高 → 排前（这卡错了影响一大片）；
   - 不确定性高（新规则首触 / block 与 warn 边界 / 跨信号分歧）→ 排前；
   - 同一 rule_id 已人审过 N 条 → 同类降权（多样性，别重复劳动）；
   - 低 KIL + 已审过同类 → 排后或自动 accept 建议。
2. **人审不是"看 136 条"，是"校准系统"**：人审分类结果回写——某规则连续 N 次被人判"误伤"→ 系统主动建议降 severity；连续 N 次判"漏拦"→ 建议升。这把人审从成本变成进化信号。
3. 落地：golden_lock 加一个 `--review-order` 子命令，输出排序后的人审清单（不是平铺），标注每条为什么排这（KIL/不确定性/已审次数）。纯读 golden_state + 图谱，机械排序。

## C · 换模型不退化：model canary（呼应用户"随模型升级进化"）
**我们的病**：golden_lock 锁的是**知识卡内容**（.asm sha、verdict），但从不锁**模型产出行为**。你白天苦力、晚上好模型、混元、豆包来回换——新模型写卡/修毒样例/跑门禁，有没有偷偷变差？**零回归**。这正好是你愿景"随模型变强系统自己进化"的反面：升级前必须先能测"没退化"。

**业界正解（五篇完全一致，已成熟）**：
- golden/canary set：25-50 个**冻结真实任务样本**+ per-case 断言，每次换模型/改 prompt 都跑（automatescale/futureagi）。
- **关键：不比对逐字字符串，比对结构与不变量**（antigravity）——"frontmatter 七键齐、verdict 正确、门禁不红"，生成内容本来就 wobble，逐字比必 flaky。
- 确定性跑：temperature=0 / 固定 seed / 哈希输出（dreaming.press）；每日 replay 对比 day-one 基线向量，漂移即报警（futureagi）。
- canary + shadow + rollback：新模型先小流量/影子并行，稳了再全量（Cygnet/TheNeuralBase）。
- 血泪教训（掘金）：**换主模型必须连 fallback/备用模型一起测**——有人只换主模型，fallback 一触发全量 context_length_exceeded。

**批判吸收（现在做，轻量）**：
1. 建 `data/model_canary/`：冻结 20-30 个**代表性生产任务**（如"给一段 C++ 片段产出合规 frontmatter""构造一个毒样例""对一张卡跑 gate 并给 verdict"），每个带**结构断言**（JSON 合法/必需键齐/verdict 与预期一致/门禁不红/token 预算内），不带逐字期望。
2. 每次**换干活模型/换大提示词**，跑 canary：对比基线——结构通过率、规则触发分布、token 成本、耗时。任一关键项劣化超阈值即报警，提示"这次升级可能退化"。
3. 与 554 的 syrupy 是姊妹：**syrupy 锁工具（确定性代码）输出，canary 锁模型（随机生成）行为**——两者合成系统的回归金字塔。
4. 严守：canary 只报警不自动回滚（G-supervisor 纪律）；换模型时主+备/退路模型一起跑（掘金教训）。

## 一、统一洞察：这三块合起来就是 L4 进化层
之前说 L4=40% 却不知它具体是什么。现在清楚了：**L4 = 自我校准引擎**，三个传感器闭环：
- 知识层校准（A）：系统自己发现"这两个概念可能是同一个""这个概念没人连"，递人审 → 知识越用越连通；
- 人审预算校准（B）：把有限的人时按边际价值排序 → 人不被 136 条淹没；
- 模型层校准（C）：换模型/改提示词时能测"没退化" → 升级是安全的，不是赌博。
三者都遵循同一铁律：**机械只产候选/报警/排序，合并/接受/升级的决策权永远在人**（不自动 KG 入库、不自动 accept、不自动切模型）。这正是"冷静准确但拥有超强智能"——智能体现在系统**主动找缺口、递判断**，而非自动拍板。

## 二、落地批次建议（接在 554 之后，别插队）
- **批次 U（人审排序，最小最快，纯读数据零风险）**：golden_lock 加 `--review-order`，按 KIL×不确定性×已审次数排序 warn 136，输出带理由的清单。半天，立即缓解人瓶颈。
- **批次 V（概念孤儿候选，纯 L1）**：concept 核心词归一 + 孤儿候选邻居清单 → `concept_candidates_for_review.md`，只产候选不连边。
- **批次 W（model canary，轻量）**：冻结 20-30 任务样本 + 结构断言 + 换模型时跑；复用现有门禁做断言，不引新 LLM judge。
- 明确**现在不做**：embedding 自动合并概念、LLM 自动裁人审、自动切模型——等 L3 门（EIR 置信+异族+可回滚）开了再说。
- 与已有资产的关系：B 复用 550 的 KIL（设计已久未落地）；C 复用 554 的 syrupy 思路但对象是模型不是工具；A 复用 527 的 concept_aliases 但从整串升级到核心词归一。

## 三、给监工的一句话
前四轮我们一直在造"更强的验证器"，这轮发现真正的下一个坎是**系统会不会自己校准**：知识真连起来（A）、人时花在刀刃上（B）、换模型不退化（C）。三件事都不依赖模型变强、不引重库、机械可做，且都把决策权留给人。做完这三块，L4 才从"40% 设计图"变成"真能自我进化的骨架"——而不是一句口号。
