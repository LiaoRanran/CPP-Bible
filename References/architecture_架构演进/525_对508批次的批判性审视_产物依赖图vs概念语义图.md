> 日期：2026-09-14
> 结论先行：508基建扎实，但有一个**关键认知差**必须点破，否则会误以为"知识图谱建好了=智能层到位了"。

## 一、508建的知识图谱是什么

读 tools/knowledge_graph.py 的schema（line 49-68）：

```
nodes(id, type, path, title, status)   type ∈ ATOM/EVIDENCE/MISCONCEPTION/FIXTURE/ARTIFACT/RULE
edges(src, dst, type)                   type ∈ PREREQUISITE/SPECIALIZES/REALIZES/EVOLVED_FROM/CONTRADICTS/REFERENCES
```

**这是「产物依赖图」**：节点是文件，边是文件之间的引用关系。
能干：改夹具波及哪些原子、一颗原子的前置链、谁是孤儿节点。——这些是**工程影响面**查询，有价值。

## 二、它不是524说的那个突破

524层7要的是**「概念语义图」**：节点是 `subject/predicate/object`（内存屏障、编译器消除、原子性……），不是文件。
它要能回答：
- 两个原子的 claim 是否在概念层矛盾？
- "内存屏障"这个概念出现在哪些论断里？
- 哪个误解 refute 了哪一条具体命题？

**为什么现在建不出来**：schema里 nodes 没有 claim/subject/predicate/claim_type 字段。claim 还是≤50字自然语言，机器不把它拆成概念三元组，概念就进不了图。

**所以**：508的图是L0/L1工程图（文件关系），524的突破在L3智能（概念关系）。**两者不是二选一，是上下两层**——依赖图现在就能用，概念图要等claim结构化落地。

> 这不是返工。依赖图先铺，claim_structured 落地后给 nodes 加 concept 表即可在其上长概念层。架构没走偏，只是别误判完成度。

## 四、下一步钉在哪（按524终局对齐）

**不要急着加新基建。508已经把L0/L1的工具铺够了。现在真正卡智能层脖子的，是一件事：**

### ⭐ 批次E：claim结构化 v0.3（这是524的核心，一直没动）

它一落地，会同时解锁：
1. 知识图谱从「文件图」长出「概念图」层（nodes加concept表）
2. 验证强度连续谱可执行（observation机验/inference人审分流）
3. 自动矛盾检测成为可能（图查询，不再靠读文本）

**实现要点（对极致目标负责，接口终局化）**：
- frontmatter加 `claim_structured: {subject, predicate, object, claim_type, negates, extracted_by}`

- 新规则：observation类必须有artifact断言支撑；inference类禁止机器直推verified
- 先拿现有最完整的 CONC-FENCE-001 做样板回填，验证schema不破坏存量

## 五、一句话

508把**发动机的外壳和仪表盘装好了**（依赖图/度量/备份/并行），但**燃料喷射系统（claim结构化）还没装**。下一步不是再装外壳，是把燃料喷进去——让知识图谱从"知道哪个文件连哪个文件"升级到"知道哪个概念和哪个概念矛盾"。这一步才是L3智能的真正起点。
