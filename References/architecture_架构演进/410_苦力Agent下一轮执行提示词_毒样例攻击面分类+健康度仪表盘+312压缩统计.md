## 任务 1：毒样例按攻击面分类（409 P0，机械）

### 背景
409 定义了 10 类攻击面（A1-A10）。当前 36 个毒样例没有分类标签。需要给每个毒样例加攻击面标签，并计算覆盖率。

### 攻击面分类（409 定义）
- A1：声明-实现脱钩（漂亮声明+假工件）
- A2：断言恒真（写死的字面量/自比/三元两支相同）
- A3：工件借用/覆盖（cp/mv 其他工件）
- A4：注释伪造（夹具注释里写符号名/取值串）
- A5：通用符号滥用（main/call/ret 哪都命中）
- A6：未声明键（.out 有断言没声明的键）
- A7：符号映射缺失（断言符号不在工件里）
- A8：间接注入（知识库内容被污染）
- A9：规则逃逸（找到规则边界条件）
- A10：门禁假阳性（sha 路径覆盖不到 artifact_assert）

### 执行步骤
1. 列出所有毒样例文件：`Get-ChildItem tests/poison/ -Recurse -Filter *.md`（或实际存放路径，先找到）
2. 对每个毒样例，Read 后判断属于哪一类（可能多类，标主类+次类）
3. 在毒样例文件的 frontmatter 加 `attack_surface: A{n}`（主类），如果有次类加 `attack_surface_secondary: [A{m}, ...]`
4. 如果毒样例没有 frontmatter，加一个（不要改正文）
5. 生成覆盖率报告：`docs/kernel/poison_coverage.md`
   - 每个攻击面有几个毒样例
   - 覆盖率 = 有标签的攻击面数 / 10
   - 未覆盖的攻击面列出来（当前应该是 A8 间接注入没有毒样例）

### 验收
- 所有毒样例都有 `attack_surface` 标签
- 覆盖率报告存在，数字与实跑一致
- `grep -r "attack_surface:" tests/poison/` 的行数 == 毒样例数
- gate block=0（加标签不应该触发任何规则）

### 注意
- 判断不确定时，标最接近的一类，并在报告里注明"待人工复核"
- 不要改毒样例的正文，只加 frontmatter
- 如果毒样例存放路径不是 tests/poison/，先找到实际路径再做

## 任务 3：312 压缩后 token 计数（407 落地，简单）

### 背景
403 的 B1 完成了 312 压缩。407 要求压缩前后用 tokenizer 实算，不是估算字数。

### 执行步骤
1. 找到压缩前的备份：`References/architecture_架构演进/312_backup_pre_compress.md`
2. 找到压缩后的文件：`References/architecture_架构演进/312_*.md`（最新的那个）
3. 用 Python 的 `tiktoken`（如果没装，用 `transformers` 的 GPT2 tokenizer，或者简单按字符数×0.35 估算并标注"估算"）
4. 计算两个文件的 token 数
5. 在压缩后的文件末尾加一段（或单独写 `docs/kernel/312_compression_report.md`）：
   ```
   ## 压缩统计
   - 压缩前：{n} tokens（{m} 字符）
   - 压缩后：{x} tokens（{y} 字符）
   - 压缩率：{pct}%
   - 约束条目数：压缩前 {a} 条 → 压缩后 {b} 条（grep 核对）
   ```
6. 如果 tiktoken/transformers 都没装，用字符数估算并明确标注"字符估算，非精确 token"

### 验收
- 压缩率数字明确
- 约束条目数用 grep 实算（不是估算）
- 不修改 312 的正文内容，只加统计段或单独报告
