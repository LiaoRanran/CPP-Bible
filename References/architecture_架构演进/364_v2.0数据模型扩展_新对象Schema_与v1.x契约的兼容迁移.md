# 364_v2.0数据模型扩展_新对象Schema_与v1.x契约的兼容迁移

> 2026-09-12 · v2.0展开文档6/6 · 对应358全部新增层的数据落地
> 目标：定义认知记录/原理理论/模式/理解度/边界地图的机器可检查Schema，并保证v1.x零破坏迁移

---

## 一、数据模型设计原则（继承v1.1教训）

1. **所有新Schema必须是JSON Schema机器契约**，不是给人看的YAML示例（v1.1漏洞A8的教训）
2. **新增字段全部可选+渐进填充**，v1.x的20颗原子不迁移也能继续通过门禁
3. **未知字段容忍**：gate/replay对不认识的字段只warn不block（先验证这一点，避免"原子化那一刻才引爆"）
4. **每个新对象有明确生命周期和状态机**，不制造无主数据
5. **认知层产物与质量层产物分离存储**，发现语境的狂野不污染辩护语境的严谨
6. **新gate规则默认warn级**，积累毒样例和误报样本后再升block

## 二、新增数据对象总览

| 对象 | 文件位置 | 对应层 | 状态机 |
|---|---|---|---|
| 认知记录 cognition_record | cognition/CR-{DOMAIN}-{NNN}.md | ⑧认知层 | open→investigating→adjudicated→crystallized/abandoned |

## 三、认知记录 Schema（cognition_record）

```yaml
# cognition/CR-CONC-001.md
id: CR-CONC-001
schema_version: "2.0"
type: cognition_record
domain: conc
status: crystallized          # open/investigating/adjudicated/crystallized/abandoned
created_at: 2026-09-12
dri_roles: [observer, abducer, experimenter, analyst]

anomaly:                      # S0-S1
  fact: "令人惊讶的事实（含读数/工件行号）"
  default_expectation: "原本预期"
  evidence_refs: [工件/卡路径]
  is_tool_artifact: false    # 是否已排除工具假象

hypotheses:                   # S2 溯因，≥2
  - id: H1
    statement: ""
    mechanism: "因果链"
    explains: []
    fails_to_explain: []
    status: survived          # proposed/competing/survived/refuted/inconclusive
  - id: H2
    ...

discriminating_experiment:    # S4（冻结：实验执行后不得改预言）
  frozen_at: "git commit/path"
  prediction_matrix:
    - {if: "H1", then_observe: "O1具体读数"}
    - {if: "H2", then_observe: "O2具体读数"}
  single_variable: ""
  controls: {active: "", negative: "", counterexample: ""}
  discriminating_power: strong   # strong/weak/non-discriminating
  bounded: true

execution:                    # S5
  fixture: "Examples/atoms/xxx.cpp"
  artifacts: {windows_sha: "", wsl_sha: "", riscv_sha: ""}
  readings: "确定性读数集"

adjudication:                 # S6（盲法）
  blind_labels_used: true
  result: "哪个假设存活，引用具体读数"
  posterior_updates: []
  unresolved_alternatives: [] # S7 替代解释

alternative_sweep:            # S7
  alternatives_considered: 3  # ≥3
  each_resolved: [excluded|included, ...]

crystallization:              # S8
  survived_hypothesis: H1
  produced_atom: ATOM-CONC-FENCE-001
  refuted_hypotheses_as_misconceptions: [MIS-CONC-...]
  cognition_quality_checks:   # 状态机门禁记录
    competing_hypotheses_ge2: true
    predictions_differ: true
    experiment_discriminating: true
    alternatives_swept: true
```

**门禁规则（COGNITION-*，先warn后block）**：
- COG-HYPOTHESIS-COUNT：hypotheses < 2 → warn
- COG-PREDICTION-DIFFER：prediction_matrix的then_observe无实质差异 → warn
- COG-ALT-SWEEP：alternatives_considered < 3 → warn
- COG-FREEZE：execution后prediction_matrix被修改 → block（事后合理化）
- COG-BOUNDED：夹具无界循环 → block（复用现有检查）

## 四、原理/理论 Schema

### 4.1 原理 principle
```yaml
id: PRIN-CONC-001
schema_version: "2.0"
type: principle
domain: conc
status: draft               # draft/established/challenged/superseded
statement: "未被可观测的计算可能被编译器消除"
scope: "适用范围与边界条件"
derivation_rules: "如何从原理推出具体原子"
derived_atoms: [ATOM-CONC-FENCE-001, ...]
exceptions: []
compression:
  principle_count: 1
  atoms_explained: 4
  ratio: 0.25               # 必须<1
compression_tests:          # 四条判据
  coverage_complete: true   # 簇内原子全部可推出
  non_tautological: true    # 不是原子重述
  novel_prediction: "推出的新预言"
  novel_prediction_verified: false
  independent_evidence_lines: 2
redteam:
  counterexamples_found: []
  scope_narrowed: false
```

### 4.2 理论 theory
```yaml
id: THEORY-CONC-001
schema_version: "2.0"
type: theory
domain: conc
status: progressive         # progressive/degenerating/crisis/replaced
name: "可观测性契约理论"
hard_core: ["编译器可任意转换，只要不改变抽象机可观测行为"]
protective_belt: ["检测工具的可达性限制", ...]
positive_heuristic: "系统测试各语言构造的可观测性边界"
negative_heuristic: "不轻易推翻硬核，先怀疑测量"
principles: [PRIN-CONC-001, ...]
explains_atoms: []
predicted_atoms:            # 理论预言（研究backlog输入）
  - {prediction: "", status: unverified}
anomalies: []
health:                     # 范式健康度（360第四节）
  anomaly_rate: 0.0
  ad_hoc_patch_rate: 0.0
  novel_prediction_rate: 0.0
  batches_degenerating: 0
human_review: required      # 理论级一律人审
```

**门禁规则**：
- PRIN-COMPRESSION：ratio≥1 或 novel_prediction缺失 → block（伪压缩）
- PRIN-COVERAGE：derived_atoms存在无法从原理推出的 → block
- THEORY-HUMAN：理论status变更必须人签 → block级
- THEORY-CRISIS：ad_hoc_patch_rate连续3批>1且novel_prediction=0 → 标记crisis（warn+人审）

## 六、理解度 Schema（原子frontmatter内嵌扩展）

```yaml
# 在现有原子frontmatter中新增（全部可选）
understanding:
  level: 2                  # 0-4，不得超过已验证的最高级
  L1:
    mechanism_chain: []
    analogy: ""
    analogy_mapping: ""
    why_not_opposite: ""
  L2:
    prediction_problems:
      - id: PP-MEM-RAII-001-1
        scenario: ""
        ptype: typical|boundary|counterintuitive|distractor|composite|inverse
        predicted_outcome: ""
        verified_artifact: "实测工件路径"   # 必须实测
  L3:
    transfer_links:
      - target_domain: ""
        principle: ""
        evidence_in_target: ""
        boundary: ""
  L4:
    generated_questions:
      - question: ""
        research_path: ""
        produced_atom: ""
```

**门禁规则**：
- UNDER-LEVEL-MONOTONIC：声称L2但缺L1 → block
- UNDER-PREDICTION-VERIFIED：L2预测题缺verified_artifact → block（答案不能想当然）
- UNDER-TYPES：L2声称的三类题（典型/边界/反直觉）不全 → warn
- UNDER-TRANSFER-EVIDENCE：L3迁移缺目标域实证 → block

## 八、与v1.x的兼容迁移策略

### 8.1 零破坏原则

- v1.x的atom/evidence/misconception Schema**不变**，understanding是原子内的可选扩展块
- 新对象（cognition/principle/theory/pattern）存新目录，不影响现有gate扫描
- gate对未知顶层字段：先实测确认是warn/容忍，再依赖（不假设）

### 8.2 分阶段启用

| 阶段 | 启用内容 | 门禁级别 | 依赖 |
|---|---|---|---|
| M1 | 错误分类法+模式库（meta/、patterns/） | 纯文档，无门禁 | 无，可立即做 |
| M2 | cognition_record Schema+CR目录 | COG规则全warn | M1 |
| M3 | understanding可选扩展+L1补全 | UNDER规则warn | 无 |
| M4 | L2预测题（3-5颗试点） | UNDER-PREDICTION-VERIFIED升block | M3 |
| M5 | 原理/理论Schema+MEM首次综合 | PRIN/THEORY规则warn | 20颗原子（已满足） |
| M6 | 边界地图/backlog工具生成 | 只读聚合，无门禁 | M1-M3 |
| M7 | 全部规则积累毒样例后升block | block | 误报样本收集 |

### 8.3 迁移检查清单（每次启用新Schema）

1. 写JSON Schema文件到schemas/
2. 生成1个正例+1个反例毒样例
3. 实跑确认：v1.x旧文件不被新规则误报（阴性测试）
4. 实跑确认：故意写错的新文件被抓住（阳性测试）
5. gate/replay对未知字段的容忍性实测
6. 新目录加入golden_lock统计的方式明确（避免污染现有基线）
7. 文档+工具cmd_check元组同步（v1.1教训：新工具必须登记）

### 8.4 golden_lock基线扩展

现有基线：{atoms, verified_atoms, evidence, replay_confirm, replay_infra_error, ...}
v2.0新增计数（渐进）：
- cognition_records（总数/各状态数）
- principles / theories / patterns
- understanding L分布
- boundary_map覆盖率
- 错误分类法命中率/新型错误数
**关键：新指标只增不改，旧指标口径不变，防止基线历史数据失效。**

## 核心结论

364把v2.0的九层架构落到可机器检查的数据契约和零破坏迁移路径上：

> v1.x的数据模型回答"一个命题如何被验证和存储"；v2.0扩展的数据模型回答"一个认知过程如何被记录（cognition）、知识如何被压缩（principle/theory）、教训如何跨域复用（pattern）、理解如何被测量（understanding）、系统的无知如何被测绘（boundary_map）"。
>
> 所有新结构遵循同一纪律：**Schema是机器契约不是文档、新字段可选渐进、创造性判断不自动化、发现与辩护分离存储、规则先warn后block**。这保证v2.0的宏大认知架构不会以破坏v1.x已建立的严谨质量体系为代价——工厂（v1.x）继续保证出厂质量，科学家共同体（v2.0新增层）在它之上做发现、理解和进化。

**v2.0六份展开文档（359-364）至此完成。下一步是让Agent以对抗性视角批判v2.0整体（358-364），再修订为v2.1，然后才进入分阶段实现。**
