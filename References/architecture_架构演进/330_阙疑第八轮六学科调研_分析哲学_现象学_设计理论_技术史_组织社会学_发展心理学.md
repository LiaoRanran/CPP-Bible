## 一、分析哲学：语言游戏与意义即使用

### 1.1 核心理论

**维特根斯坦后期**：
- **语言游戏（Sprachspiele）**：语言不是世界的静态图像，而是一种活动
- **意义即使用**：一个词的意义不在于它指称什么对象，而在于它在语言中被使用的方式
- **家族相似性**：概念没有共同本质，只有交叉相似（如"游戏"没有共同定义）
- **生活形式（form of life）**：语言游戏嵌入在特定的文化和社会语境中

**逻辑实证主义（维也纳学派）**：
- **可证实性原则**：一个陈述的意义在于它的证实方法
- 分析命题（true by definition）vs 综合命题（可经验验证）
- 不可证实的陈述（形而上学/伦理学）= 无意义

### 1.2 对「阙疑」的映射

**claim 的意义 = 它在证据体系中的使用**：
- claim 的字面表述不重要，重要的是它在证据卡/夹具/红队中的"使用方式"
- 同一 claim 在不同"语言游戏"中有不同意义：
  - Writer 的游戏：claim = 待验证的假设
  - 红队的游戏：claim = 待攻击的目标
  - Gatekeeper 的游戏：claim = 待检查的格式
  - 读者的游戏：claim = 待学习的知识点

**家族相似性 = 原子之间的关系**：
- 原子没有共同本质（不是所有原子都有相同结构）
- 只有交叉相似（prereq/contrasts/related 关系）
- 这解释了为什么"原子类型"有 10 种（mechanism/pitfall/contrast/tool...），没有单一本质

**可证实性原则 = falsification 字段**：
- claim 必须可证伪（我们的 falsification 字段就是可证实性原则的实现）
- 不可证伪的 claim = 无意义（如"性能很重要"这种模糊表述）

## 二、现象学：意向性与悬置

### 2.1 核心理论

**胡塞尔**：
- **意向性**：意识总是关于某物的意识（every consciousness is consciousness of something）
- **noesis/noema**：意识行为（主观侧）与意识对象（客观侧）的共构
- **悬置（epoché）**：悬置对外部世界的假设，关注经验本身的结构
- **生活世界（Lifeworld）**：前理论的、被体验的世界

**海德格尔**：
- **此在（Dasein）**：人的存在方式，实践先于理论
- "上手状态"（Zuhandenheit）：工具在使用中透明，不被理论化

**梅洛-庞蒂**：
- **具身现象学**：认知植根于身体，身体图式是动态的预期结构
- **运动意向性**：运动不是由 detached 的意志命令，而是身体的前反思技能

### 2.2 对「阙疑」的映射

**悬置 = 红队两段式盲读**：
- 红队第一段：悬置对卡的信任（epoché），只看夹具/工件
- 这正是现象学方法：不预设结论，回到"事物本身"
- 红队第二段：再对照卡，看卡的自述是否与"事物本身"一致

**实践先于理论 = 夹具实测优先**：
- 先做夹具实测（实践），再写 claim（理论）
- 不是先写 claim 再找证据（理论先于实践）
- ALLOC-002 的教训：理论（"pool 最省"）被实践（实测 8056B）推翻

**意向性 = Agent 的注意力管理**：
- Agent 的"意识"总是指向某个任务（claim/夹具/证据卡）
- 注意力的指向决定了"看到什么"（noema）
- 上下文耗尽 = 意向性的"视野"受限，需要换页（MemGPT）

**具身认知 = Agent 通过工具与世界互动**：
- Agent 的"身体"是工具（replay/gate/poison）
- 认知不是在真空中发生，而是通过工具与代码库互动
- 工具的"上手状态"：replay 用熟了就透明了，不再被意识到

## 三、设计理论：格式塔与可供性

### 3.1 核心理论

**格式塔心理学**：
- 整体大于部分之和
- 组织原则：接近性、相似性、连续性、闭合、图形-背景

**吉布森的可供性（affordance）**：
- 环境提供给有机体的行动可能性
- 可供性存在于有机体-环境的关系中，不是物体的固有属性

**诺曼的设计原则**（《设计心理学》）：
- **感知可供性**：用户感知到的行动可能性
- **符号（signifier）**：指示可供性的可感知线索
- **映射（mapping）**：控制与效果之间的关系
- **反馈（feedback）**：行动结果的确认
- **概念模型**：用户对系统如何工作的理解
- **执行鸿沟**：意图与实现方式之间的差距
- **评估鸿沟**：系统状态与用户理解之间的差距

### 3.2 对「阙疑」的映射

**原子的教学可供性**：
- 一个原子"提供"什么学习体验？（概念解释/反例/实证/对比）
- 感知可供性 = 读者从原子结构中感知到的学习路径
- 符号 = 证据卡的断言标签（告诉读者"这里有证据"）

**执行鸿沟与评估鸿沟**：
- **执行鸿沟**：读者想理解一个概念，但原子的结构不支持（如缺少前置知识）
- **评估鸿沟**：读者学完后无法评估自己是否理解（如缺少自测题）
- 好的原子设计应该缩小这两个鸿沟

**格式塔 = 原子体系的整体**：
- 20 颗原子的整体大于单颗之和（关系网络产生涌现价值）
- 接近性 = 同域原子（MEM/CONC/UB）
- 相似性 = 同类型原子（mechanism/pitfall）
- 连续性 = prereq 链（A→B→C 的学习路径）
- 闭合 = 读者补全未明说的联系

## 四、技术史：创新扩散与路径依赖

### 4.1 核心理论

**罗杰斯的创新扩散**：
- S 曲线：创新者（2.5%）→ 早期采用者（13.5%）→ 早期大众（34%）→ 晚期大众（34%）→ 落后者（16%）
- 五个采纳属性：相对优势、兼容性、复杂性、可试用性、可观察性
- 临界点：早期采用者→早期大众之间的"鸿沟"（摩尔）

**路径依赖**：
- 技术选择一旦确定，后续选择受其约束（QWERTY 键盘、铁轨宽度）
- 锁定效应：次优技术可能因早期优势而主导
- 正反馈：采用越多，优势越大（网络效应）

**技术范式**（多西）：
- 技术发展的框架，类似于库恩的科学范式
- 范式内 = 渐进改进（常规工程）
- 范式转移 = 革命性突破

### 4.2 对「阙疑」的映射

**原子生产的 S 曲线**：
- 第一批（8 颗）= 创新者阶段（慢，探索方法）
- 第二至四批 = 早期采用者（加速，方法成熟）
- 第五批 = 跨越鸿沟（从"实验性"到"生产级"，但遇到质量瓶颈）
- 第六批（CONC）= 早期大众（新域，需要重新适应）

**路径依赖的风险**：
- 早期的工具设计（replay/gate）约束了后续的架构选择
- 证据卡格式一旦确定，迁移成本高（315 的三层分离就是在对抗路径依赖）
- 警惕：G6 范式可能成为新的路径依赖（范式内优化 vs 范式转移）

**技术范式转移**：
- G0→G6 = 范式转移（从"知识点+示例"到"claim+证据卡+红队+门禁"）
- G6 内 = 常规工程（生产更多原子，优化工具）
- G7 = 下一次范式转移（触发条件：G6 出现无法解决的异常）

## 五、组织社会学：科层制与网络组织

### 5.1 核心理论

**韦伯的科层制**：
- 理性-法律权威（非传统/魅力型）
- 层级制（清晰的指挥链）
- 规则与标准操作程序
- 非人格化（不因人而异）
- 专业能力（基于技术能力的任命）
- 书面记录

**后韦伯组织**：
- 项目制、矩阵制、adhocracy（临时组织）
- 网络组织（节点+连接，无中心）
- 平台组织（双边市场）

**集体智慧**（Surowiecki）：
- 群体智慧超过个体的四个条件：
  1. 多样性（不同视角）
  2. 独立性（不互相模仿）
  3. 分散化（局部知识）
  4. 聚合机制（汇总个体判断）

### 5.2 对「阙疑」的映射

**三权分立 = 科层制的理性化**：
- 规则明确（gate 33 条规则）
- 职责分离（Writer/红队/Gatekeeper）
- 非人格化（机器检查不因人而异）
- 专业能力（每个角色有专门的提示词）
- 书面记录（frontmatter/status_history）

**网络组织 = 多 Agent 协作**：
- Writer/红队/Gatekeeper 之间是网络关系，不是严格的层级
- 信息流动是双向的（红队的反馈修改 Writer 的输出）
- 人审是网络中的"超级节点"（高连接度）

**集体智慧的四个条件**：
- 多样性 = Writer + 红队 + Gatekeeper + 人审（不同视角）✅
- 独立性 = 红队两段式盲读（不被 Writer 的自述影响）✅
- 分散化 = 每个角色有局部知识（Writer 懂生产，红队懂攻击）✅
- 聚合机制 = golden_lock + 门禁汇总 ✅
- 「阙疑」已经满足集体智慧的四个条件！

**科层制的局限**：
- 规则僵化（P4-P7 可能过度约束创新）
- 反应慢（每批需要多轮红队+门禁）
- 需要平衡：规则保证下限，灵活性保证上限

## 六、发展心理学：最近发展区与脚手架

### 6.1 核心理论

**维果茨基的社会文化理论**：
- **最近发展区（ZPD）**：独立能做的 vs 有指导能做的之间的差距
- **脚手架（Scaffolding）**：逐步减少的支持，最终让学习者独立完成
- **更有知识的他者（MKO）**：教师/同伴/工具，提供指导
- 学习引导发展（不是发展引导学习）

**皮亚杰的认知发展阶段**：
- 感知运动阶段（0-2岁）
- 前运算阶段（2-7岁）
- 具体运算阶段（7-11岁）
- 形式运算阶段（11岁+）
- 每个阶段有不同的认知能力，不能跳过

### 6.2 对「阙疑」的映射

**Agent 的最近发展区**：
- Agent 独立能做的（基础生产）vs 有提示词指导能做的（高质量生产）
- 提示词 = 脚手架，逐步细化后可以减少支持
- 已验证原子 = MKO（"更有知识的他者"，指导新原子的生产）

**「阙疑」的认知发展阶段**：
- G0-G2 = 感知运动阶段（探索工具，建立基础）
- G3-G4 = 前运算阶段（开始结构化，但逻辑不完整）
- G5 = 具体运算阶段（原子化，逻辑完整但依赖具体案例）
- G6 = 形式运算阶段（四级状态，抽象规则，可迁移）
- G7 = ？（超越形式运算，元认知/自我进化）

**脚手架的逐步撤除**：
- 第一批：详细提示词 + 人审每步
- 第五批：提示词简化 + 人审只签关键节点
- 目标：Agent 能独立生产高质量原子（脚手架完全撤除）
- 但不能跳过阶段（皮亚杰：不能从具体运算直接跳到形式运算）
