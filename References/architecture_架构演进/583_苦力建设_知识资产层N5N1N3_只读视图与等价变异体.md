## 任务 1（N5，本批核心）：mutation 报告层 `equivalent` 字段 + M6 八条逃逸定性

**目标**：回答"M6 那 8 条逃逸里，哪些根本是**无效变异（等价变异体）**、哪些是**真洞**"，在不改一条 verdict 的前提下，把"变异体有没有改变判决可见面"变成可证伪的机器字段。

### 1.1 判据（严格按规格 05 §四）

设 `P1 = atom_evidence_replay.parse_frontmatter`（safe_load 路径）、`P2 = gate_engine` 硬化解析（`_UniqueKeyLoader` 那套）。对变体 `T'` 与原文 `T`：

```
equivalent(T, T')  ⟺  canon(P1(T)) == canon(P1(T'))  ∧  canon(P2(T)) == canon(P2(T'))  ∧  op ∉ {M1, M7}
```

- `canon(·)` = 解析结果的**规范化字符串**：键按字典序、去注释/去空白差异。
- **不做跨类型归一**：`1` 与 `true`、`"yes"` 与 `true`、`"00000000"` 与 `0` 的差异**必须保留**——它们是 556/557 `[type-diverge]` / YAML-1.1 硬化的信号，归一会洗掉真实走私面。canon 只排键、去空白注释，**不动值的类型**。
- **`op ∉ {M1, M7}` 是硬边界**：M1（删 negative_controls）/ M7（改数值/命令）的判决还走 replay 读工件与命令，frontmatter 相等**不足以**判等价（那需要 TCE 式产物比对，属冻结 W2，不做）。
- 语义：`equivalent=True` ⇒ "该变体在任何只读 frontmatter 的规则下都不可能与原文产生不同 finding"。

### 1.2 落点（只加不改）

- `_card_variants` 每条 per 记录加 `"equivalent": true|false`；`n_a` 细分类加 `equivalent` 计数（与 `out_of_scope`/`malformed` 同列，**不进拦截率分母**）。
- **`_variant_index()` 的 5 字段不含 equivalent** ⇒ 579/580 的确定性对账逐字不变。
- 报告（`_report`/JSON）只**新增** equivalent 相关计数与清单字段，不删不改既有字段。

### 1.3 机器验收（每一条都要有 pytest）

1. **不改判决**：同一输入，加字段前后 `_variant_index()` 逐变体字典完全相等；`blocked/escaped/n_a` 三总数与 v5 权威一致（1183 变体：989 严格 619 / 9 / 185；逐算子 M1 64/1/27｜M2 168/0/27｜M3 65/0/42｜M4 200/0/33｜M5 29/0/56｜M6 324/8/0｜M7 139/0/0，b/e/n_a）。
2. **保守性自证（最关键，防"把真逃逸洗成等价"）**：对每条 `equivalent=True` 的变体，在**同一沙箱内**跑"原文 vs 变体"的 finding 集合差；**差集必须为空**；若任一非空 ⇒ 判据假阳性 ⇒ 命令 exit 非 0 并打印该变体。把这条做成可重复的自检（可挂在 `--selfcheck-determinism` 同批或独立 `--selfcheck-equivalent`），并有一条**反例测试**：手工构造一个"canon 相等但某规则 finding 不同"的变体（若存在），断言它**不被**标 equivalent。
3. **双解析器缺一不可**：单解析器相等、另一解析器不等 ⇒ `equivalent=False`（写正例：一个只被硬化解析器判为走私的形态，如全角键名/重复键，safe_load 与硬化解析结果分叉）。
4. 对 v5 的 1183 变体出一张表：每算子 `equivalent / out_of_scope / malformed / 真可判` 四计数。
5. 两次跑一致（沿用确定性自检）。

### 1.4 M6 八条逃逸定性（只读，不跑 gate）

取 v5 里 M6 的逃逸变体，逐条：
- `equivalent=True` ⇒ **无效变异**（攻击集缺陷，不是门禁缺陷），登记"应修算子 M6（只变异解析后确实不同的形态）"；
- `equivalent=False` 且 escaped ⇒ **真逃逸候选**，逐条静态归因（对照 `EV-FM-*` 判据面）：`规则缺失`（无规则覆盖该形态）或 `规则漏检`（有规则但条件没覆盖），带证据行；
- 产出 M6 逃逸 `{equivalent / 规则缺失 / 规则漏检}` 三类计数 + 逐条清单（可落 `data/mutation/m6_triage_583.json`，大结果不入 git 或只入清单 .md）。
- M1 那 1 条逃逸同样登记现状（M1 不适用 canon，标"需 TCE/工件比对，冻结"）。

> 若 8 条全部 equivalent=True，也要如实报"尺子噪声、非门禁洞"，**不许为了显得有洞而改判**；若有真逃逸候选，**本批只登记不补规则**（补规则另开包、warn 起步、先量存量）。
