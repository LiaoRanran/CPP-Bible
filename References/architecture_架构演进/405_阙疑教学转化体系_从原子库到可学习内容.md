# 405 阙疑教学转化体系：从原子库到可学习内容

> 日期：2026-09-13。外部调研：学习科学（Karpicke & Roediger 检索练习 2.2 倍保留、Dunlosky 高效用方法仅两种）、学习路径生成（EDU-Graph RAG、前置依赖 DAG、1Cademy 自适应）、误解教学（ACM "When Wrong is Right" 错误示例、McMining 自动挖掘、antipattern cards）。
> 核心问题：**阙疑有 27 颗原子、56 张证据卡、~80 条误解，但没有一个学生能直接用这些东西学习。** 系统再强，不能转化为教学价值就是空中楼阁。

---

## 一、学习科学的两条铁律（必须遵守）

### 铁律 1：主动回忆 > 被动阅读
- Karpicke & Roediger (2008, *Science*)：检索练习一周后保留 **80%**，重读同样材料只有 **36%**——2.2 倍差距
- Dunlosky et al. (2013, *Psychological Science in the Public Interest*)：综述数百项研究，只有**练习测试**和**分散练习**被评为"高效用"
- 含义：教学内容不能是"让学生读原子卡"，必须是"让学生回答问题"

### 铁律 2：错误示例 > 正确示例
- ACM "When Wrong is Right"：故意包含错误步骤的示例（erroneous examples），学生必须自我解释为什么错——比正确示例更能促进概念知识和长期保留
- 概念转变（conceptual change）：不是"告诉学生正确答案"，而是"让学生看到自己的错误观念被反例否证"
- 含义：我们的红队发现的"坏卡"、误解库的反例，是**比正确原子更有价值的教学材料**

## 二、阙疑的独特教学资产（别人没有的）

| 资产 | 数量 | 教学转化 |
|---|---|---|
| 原子（可证伪 claim） | 27 颗 | → 主动回忆问题（"RAII 的核心保证是什么？"） |
| 证据卡（实测数据） | 56 张 | → 答案+实证支撑（比教科书"据说"硬） |
| 误解库（3 条反例） | ~80 条 | → 诊断 MCQ + 错误示例 |
| relations（prereq/contrasts） | 已有 schema | → 学习路径 DAG |
| 红队坏卡（真实逃逸） | 373 档案 | → "这张卡为什么错？"交互练习 |

**关键洞察**：阙疑的每个组件都天然对应一种教学形态，不需要从零造内容。

## 三、四层教学转化模型

### L1：闪卡层（Active Recall Cards）——最低成本，最高收益

**每颗原子 → 3-5 张闪卡**：
- 卡 1（概念）：正面=claim 的问题化，背面=claim 答案
  - 例：正面"RAII 的核心保证是什么？"，背面"资源获取即初始化，对象生命周期绑定资源生命周期"
- 卡 2（反例）：正面=误解的触发词，背面=为什么错
  - 例：正面"'各线程写各自的变量就没有竞争'对吗？"，背面="错，共享缓存行可导致 18× 慢化（PERF-004）"
- 卡 3（实证）：正面=证据卡的关键读数，背面=含义
  - 例：正面"LSan 对同一份真泄漏夹具，加一个 volatile 计数器后报告从 0 变为 64B/2 allocs，说明什么？"，背面="泄漏检测工具的报告与否高度依赖代码形态，没报≠没泄漏"

**格式**：Anki 兼容（制表符分隔 Q/A）或 Markdown Q&A。
**工具**：`tools/atom_to_flashcards.py`——读原子 frontmatter 的 claim + pedagogy.misconception，自动生成闪卡。
**间隔重复**：先用 Anki（学生自己导入），长期可做内置调度（SM-2 算法）。

### L2：诊断层（Misconception MCQ）——误解库的教学利用

**每条误解 → 1 道多选题**：
- 题干：一个场景或问题
- 4 个选项：1 个正确 + 3 个分别对应不同误解
- 解析：每个选项为什么对/错，引用对应原子

例（MIS-MEM-032"各线程写各自变量就没有竞争"）：
```
问：4 个线程各累加一个独立变量，以下说法正确的是？
A. 一定没有竞争，因为变量独立
B. 可能慢 10×+，因为变量可能共享缓存行 ← 正确
C. 一定有竞争，因为多线程就有竞争
D. 只有加锁才安全

解析：
A 是 MIS-MEM-032（忽略缓存行共享），PERF-004 实测相邻布局慢 18.86×
C 是过度概括（无共享数据时无数据竞争）
D 是混淆"数据竞争"与"性能竞争"
```

**工具**：`tools/misconception_to_mcq.py`——读误解的触发词+反例，生成 MCQ 草稿（人审后使用）。
**价值**：学生选错了就知道自己有哪个误解，比"读一遍误解库"有效得多。

### L3：路径层（Learning Path DAG）——学什么、先学什么

**基于 relations.prereq 的有向无环图（DAG）**：
- 节点=原子，边=prereq（A→B 表示学 B 前必须掌握 A）
- 拓扑排序=学习顺序
- 学生掌握某原子后，解锁其后续原子

**例（MEM 域）**：
```
RAII-001 → MOVE-001 → MOVE-002
  ↓
LEAK-001 → LEAK-002
  ↓
PERF-001 → PERF-003 → PERF-004
```

**工具**：`tools/learning_path.py`——读所有原子的 relations，构建 DAG，输出拓扑排序+每个原子的"已解锁前置"。
**自适应**：学生答对某原子的闪卡→标记"已掌握"→推荐下一个未掌握且前置已满足的原子（1Cademy 思路：正确→进阶，错误→复习前置）。

### L4：交互层（Erroneous Examples + Live Fixtures）——最高成本，最高价值

**错误示例练习**（"这张卡为什么错？"）：
- 从红队档案（373 逃逸、ALLOC-002 方向反转、LEAK-002 观测反转）中选真实坏卡
- 学生任务：找出卡中的错误，说明为什么错，给出修正
- 这是"When Wrong is Right"的直接应用——学生必须自我解释错误

**活代码实验**：
- 夹具（Examples/_atom_*.cpp）是可运行的，学生可以修改参数、改优化档、改编译器，观察结果变化
- 例：PERF-004 夹具，学生把 tight 改成 padded，观察 18×→1× 的变化
- 这比"读证据卡"主动得多

## 五、与现有体系的关系

- **不替代原子生产**：原子是"知识的真相源"，教学内容是"真相的消费形态"
- **原子生产时就要考虑教学转化**：新原子的 claim 必须能问题化（不能问题化的 claim 是坏 claim），pedagogy.misconception 必须引用误解（为闪卡和 MCQ 提供素材）
- **红队发现自动转化为教学材料**：每个红队阻断不仅是"修规则"，还是"一个错误示例"——373 的 14 个逃逸、ALLOC-002 的方向反转，都是天然的教学案例
- **是 399 教学转化体系（L7）的具体落地**：399 说"教学转化"，405 给出"转成什么、怎么转、优先级"

## 六、质量控制（教学内容也需要门禁）

教学内容不能"生成了就用"，需要验证：
1. **闪卡准确性**：闪卡答案必须和原子 claim 逐字一致（工具自动比对）
2. **MCQ 选项互斥**：每个错误选项必须对应一个真实误解（不能是"明显错"的凑数选项）
3. **学习路径无环**：DAG 必须无环（拓扑排序失败=relations 有矛盾，触发 404 的 L1 冲突检测）
4. **错误示例有明确答案**：每个"这张卡为什么错"必须有标准答案和修正方案

---

## 七、元结论

阙疑的教学转化有一个**其他学习库没有的优势**：我们的知识不是"写出来的"，是"实测出来的"。每颗原子都有可复现的夹具和工件，每条误解都有 3 条反例，每个红队发现都是真实的"坏例子"。

这意味着教学内容不是"二手转述"，而是"一手证据"——学生学的不是"书上说 RAII 是什么"，而是"这个夹具实测证明了 RAII 的什么"。

**先做 L1 闪卡**——27 颗原子立刻能变成 ~100 张闪卡，学生今天就能用。这是系统从"自嗨"到"有用户"的第一步。
