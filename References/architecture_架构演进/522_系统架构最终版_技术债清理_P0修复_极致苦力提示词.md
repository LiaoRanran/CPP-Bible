**问题**：contains_in 有 N≥2 次判别力检查，但 contains_any 完全没有。

**步骤**：
1. Read gate_engine.py 找到 contains_in 的判别力检查逻辑（搜 `discriminat` 或 `N≥2` 或 `k == N`）
2. 把同样的检查扩展到 contains_any：每个候选符号若在所有函数区间都出现（恒真），block
3. 毒样例 tests/poison/ 加 P63：contains_any 用 .file/.section 应被拦
4. pytest 加正例（合理符号通过）+ 反例（恒真符号block）
5. 跑全量确认存量56卡零误伤
6. 一个commit

### A2：S1 verified_by 与 git 作者对比（warn观察期，不block）

**步骤**：

### A3：P0-A重编译不变量对构建脚本卡的处理（fail-closed但给清晰路径）

**问题**：command用make/cmake时，_artifact_compile_lines找不到直接编译行 → infra_error:recompile_unavailable，多TU原子写不了。

**步骤**：
