# 执行层架构：脚手架 SCAFFOLD —— 干活的 Agent 上下限宪章

> 2026-09-12。第五轮架构，也是把方向从「知识怎么验证」转向「**干活的 Agent 怎么被托举和约束**」的一轮。
>
> 用户指令原文：「狠狠架构一轮，必须榨干每一丝力量去给后面干活的 Agent 执行提升上限、保证下限。」
>
> 核心主张先给：**把执行 Agent（Writer/RedTeamer/Gatekeeper/调研 Agent）当作「不可靠的执行部件」来设计——模型是提议器，系统是判定者。** 所有关键判定（真值、质量、通过与否）一律由非模型机制完成（工具输出、判据计算、schema 校验、双源交叉）。这正是编译器给程序员加安全带的逻辑：人类会犯错，所以有了类型系统和 UB 检测；LLM 会幻觉、会偷懒、会自欺，所以有了下面这套。

## 〇、先列失败模式：弱模型的下限威胁清单（每条都有项目实证）

设计护栏之前，先精确枚举「会被击穿」的点——没有威胁清单的护栏是装饰：

| # | 失败模式 | 形态 | 项目实证 |
|---|---|---|---|
| F1 | 幻觉/编造 | 未测说测了、没数据编数字、引文造假 | EV-MEM-002 零观测伪证据 |

| F3 | 偷懒走过场 | 红队 rubber-stamp、「存在性检查」冒充「语义检查」 | 多批红队若不被要求独立上下文即压成走过场 |
| F4 | 上下文溺水 | 长上下文里遗忘铁律、行为退化 | 本项目上下文耗尽反复发生 |

## 一、下限保证：六层护栏（从内到外，每层独立可拦）

### L1 结构护栏（Schema）——防格式漂移、字段缺失、状态非法
- 所有产物（原子/证据卡/误解/夹具）强制走 schema：frontmatter 字段白名单、状态机合法值、relations 目标**必须先 rglob 确认存在**（不然 git mv 瞬间才爆）。
- **模型自由发挥空间 = 0**；schema 违背由机器直接 block，不经模型判断。
- 实证：ATOM-ID-FORMAT 拦 type:tool；MIS-MEM-027 不存在在 git mv 瞬间才被拦——这层要提前到**写入时**。

### L2 客观锚护栏（判定）——防幻觉、编数字、零观测伪证据
- 任何事实断言必须有**可复算的客观锚**：编译 rc、运行输出逐字、工件 sha256、引文摘录字符串命中。
- 没有客观锚的断言 = **非法状态**，强制阙疑（留白），不许「感觉对」。
- 铁律升级：claim/actual 不编造，未采集标「未采集」——从纪律变 schema（写不进 schema 就写不进仓库）。
- 实证：EV-MEM-002、PERF-003 三实现数字「未实测不写」。

### L3 双源护栏（互证）——防平台相关结论冒充普适
- 跨编译器/跨平台/跨标准版本矩阵化：版本矩阵空格数 = 0 才放行（v2 已立）。
- 单源结论必须显式标「单源未交叉」，禁止沉默冒充。
- 实证：gcc-14 升版六卡 refute；PERF-003 两平台排序相反——单源结论必然翻车。

### L4 毒样护栏（自省）——防 Goodhart、自证、恒真、伪证伪
- P1–P7 毒样例（已上线）+ **held-out 注入事故集**（外部事故集，非本系统 LLM 生成）：每轮混沌演练强制跑，**逃逸率归零才允许 release**。
- 注入集与优化目标分离（防 Goodhart）：系统不知道哪些是注入。
- 实证：P4–P7 新规 4/4 在 PERF-003 上零命中（盲区登记在 docs/S6_tool_debt.md，收紧方案已写：豁免必须带可核对锚）。

### L5 元审计护栏（规则自反）——防「审计者无人审计」
- 门禁必须扫**所有**目录（goldens/ 不被扫描的教训：草稿在 goldens/ 不被扫，问题只在 mv 瞬间引爆）。
- 「规则本身是否被遵守、规则本身是否有盲区」设为最高级审计项。
- 每个动作留痕（自律声明：改了哪些范围、未测什么、凭什么认为自己没错）。
- 实证：goldens/ 漏扫、safe-delete shim 拦 Windows、WSL 真删。

### L6 检查点护栏（恢复）——防上下文耗尽、并发写冲突、进度丢失
- 每完成一步写检查点；产物按 sha 缓存，未变不重跑。
- Windows replay 与 WSL 预检**禁止并行**（同写 Examples/*.asm → 假 refute，实测 40/40→16/24）。
- git 状态是唯一权威来源；上下文恢复时先读轨迹再续作，不重跑夹具。
- 实证：多轮「上下文耗尽如实汇报不硬编」，第五批数据固化后续作零重跑。

## 二、上限提升：五根杠杆（让弱模型做到「看似不可能」的事）

护栏保证不砸，杠杆负责够高。弱模型的现实：推理弱、记忆不可靠、长上下文溺水——但**能执行确定性步骤、能填模板、能查、能模仿**。架构就顺着这四条能力设计。

### S1 降维脚手架：把复杂判断拆成局部填充
- 「写一颗 5 分原子」拆成 20 步 checklist，每步输出有 schema，每步判据可算。
- 模型只做「局部填充」，复杂判断被结构消化——IDE 补全隐喻：模型填函数体，架构保类型安全。
- 实测判据：同一步骤，弱模型与强模型的输出字段合格率差异 ≤ 阈值。

### S2 检索-引用生成：把「知道」变成「查到」
- 幻觉的根源是「凭记忆生成」；改成「检索-引用-生成」：标准原文、事故库、先例库先检索，摘录字符串必须命中才允许写入断言。
- 先例库是最强脚手架：B 样板的版本边界表、gcc-14 事件、P4–P7 事件，都是「下次直接抄的结构」。
- 判据：每颗原子的引文命中率（摘录字符串在源中存在的比例）≥ 100%，命中失败 = block。

### S3 黄金样例 diff：模仿比推理容易
- 新产物与黄金样板（A/B/C，已验证 5 分）做**结构 diff**：章节齐全性、判据表格式、断言锚形态、留痕节。
- 偏离黄金形态即警告；形态跑偏 = 大概率内容也跑偏。
- 判据：结构相似度（节覆盖率 × 形态锚点命中率）≥ 阈值，低于即退回重写。

### S4 能力分档路由：按档位给活，给足手脚
- 任务按认知强度分档：确定性校验/编译/跑测 → 最便宜档；证据卡起草/误解撰写 → 中档；溯因/判别实验设计/哲学裁决 → 最强档。
- 每档有 token 预算与产出标准；超预算自动降档或分片，不硬撑。
- 接住用户现实：多平台低价模型轮班（traeWork/CodeBuddy/豆包/DS flash），「榨干每一丝性能」的落点之一。

### S5 增量上下文：防溺水
- 红队/门禁只注入「diff + 相关先例 + 本步骤 schema」，不注入全文件。
- 弱模型在长上下文里行为退化（F4）；上下文越短，模型越可靠。短 = 上限高，不是降级。

## 三、上下限的交汇：可废止 + 未知地图

「上限高」和「下限稳」不是两个目标，是同一个设计的两个面：

- **对尝试宽容**（上限高）：可废止让试错变便宜——弱模型敢提议，错了被客观源杀死，成本只是重跑一次判别实验。
- **对错误零容忍**（下限稳）：护栏让错误在入库前被拦死——逃逸率归零、矩阵空格为零、无锚断言非法。

**可废止是上限的引擎，护栏是下限的刹车。** 没有护栏的可废止是灾难，没有可废止的护栏是死水。这正好是阙疑（EPOCHE）的执行形态：系统不要求自己「总是对」，只要求自己「错得起、错必现」。

## 四、角色目标函数（从「规则列表」升级为「可度量自律」）

| 角色 | 目标函数（最大化/最小化） | 度量 |
|---|---|---|
| Writer | 最小化未锚定断言；最小化与黄金形态的 diff | 无锚断言数、结构相似度 |
| RedTeamer | 最大化证伪尝试数；最大化对 P4–P7 盲区的命中 | 尝试数、盲区命中数 |
| Gatekeeper | 零逃逸率；零矩阵空格 | 毒样逃逸率、空格计数 |
| 调研 Agent | 最小化二手/无源条目；最小化「已查证 vs 一方称」混淆 | 原始源占比、标注率 |

目标函数可度量，模型被度量牵引——**比被命令约束更自律**（271 自律轴内化）。

## 五、验收判据（可证伪，数字说话）

**下限**：
- 最便宜档模型跑同一批毒样例 + held-out 注入事故集：逃逸率 = 0。
- 同一事故（LEAK-001 类）重演：≥ 80% 判别实验决策被系统自动复现。

**上限**：
- 最弱模型 + 完整脚手架 vs 最强模型无脚手架，产出质量差距量化：断言锚合格率、红队拦截率、结构相似度——**目标是把差距压缩到「脚手架能补齐的范围」**，即弱模型+脚手架 ≥ 强模型无脚手架。
- 吞吐率：每 token 产出的 verified 原子数，从「未度量」变为每轮必报（271 性能轴落地）。

## 六、给用户的话

这一轮回答的是「怎么给后面干活的 Agent 提升上限、保证下限」：**上限不是靠更强的模型，是靠更强的脚手架构**——把复杂判断拆成弱模型也能做的局部填充（S1）、把记忆换成检索（S2）、让模仿替代理推理（S3）、按档位给活（S4）、把上下文变短（S5）；下限不是靠更严的提示词，是靠六层不依赖模型自觉的机械护栏（Schema → 客观锚 → 双源 → 毒样 → 元审计 → 检查点）。每一条都对应一个你已经踩过的坑——F1–F10 没有一条是虚构的。

「榨干每一丝力量」在这份宪章里的意思：**每一分算力都花在让机制更硬上（护栏），而不是花在求模型更乖上（提示词）。** 提示词是意志力，护栏是制度——制度比意志力可靠，尤其当执行者是一群会轮班、会偷懒、会幻觉的模型时。
