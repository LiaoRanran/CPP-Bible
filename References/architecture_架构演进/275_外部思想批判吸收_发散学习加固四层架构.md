## 一、八个外部思想源：最强点 / 批判 / 吸收

### 1. 编译器差分测试（Csmith / EMI / MLIR-Smith）

- **最强点**：机器大规模生成随机程序，用「多编译器输出不一致 = 至少一个错」找编译器 bug——Csmith 已在 GCC/LLVM 上找到 400+ bug；EMI（等价模输入）用同一程序的语义等价变体做差分。
- **批判**：① 随机程序无语义意义，只找差异、不找教学点；② survey 明说 majority voting 无 ground truth——**多编译器一致也不等于正确**（这反而支持我们「多源一致 ≠ 真」的立场）；③ 生成组合空间爆炸，需要可解释性过滤。
- **吸收**：FORGE 变异算子机器化——基于已 verified 原子 + 夹具做 **Csmith 式随机/差分程序生成**，跨 gcc/clang 差分探测行为差异（自动发现「编译器之间不一致」这类 B 样板式教学点）；**落点：锻炉；P1**。

### 2. 混沌工程（blast radius / abort conditions / error budget）

- **最强点**：主动注入故障测韧性，但**实验开始前必须定义爆炸半径、中止条件、回滚路径**；先小后大（sandbox→canary→region）；SLO/error budget 驱动发布节奏——**预算耗尽强制停线修复**。
- **批判**：混沌工程治的是运行期韧性，我们治的是知识正确性——注入对象不同，但纪律结构完全同构。
- **吸收**：① GAUNTLET 协议补**爆炸半径声明**（每剧本必须声明影响范围/自动中止条件/回滚路径）；② 逃逸率从「报告指标」升级为 **error budget**——预算耗尽 = 强制停线修复，不是「记一笔」。**落点：GAUNTLET；P0**。

### 3. Agent 编排模式 + Lusser's law（orchestrator-worker / checkpoint）

- **最强点**：生产主导模式是 orchestrator-worker + DAG 规划；每节点持久化状态（checkpoint）；动态 agent 选择（语义缓存检索，别把全部 agent 塞进上下文）；human-in-the-loop 中断阈值。
- **批判**：**Lusser's law 是给我们最响的警钟**——单 agent 95% 可靠，链 5 个只剩 77%，链 10 个剩 60%。我们多角色流水线，环节数量是可靠性大敌；agent 越多上下文成本越高（性能轴直接冲突）。
- **吸收**：① 环节做减法：生产流水线**合并可合并的环节**，环节数上限写入架构约束；② checkpoint 每节点持久化已是我们 L6——升级为「状态快照 + diff 恢复」标准；③ 动态选择：红队/门禁按影响面动态选卡，不全量跑。**落点：前额叶/护栏；P0**。

### 4. LLM 自我修正失败研究（Self-Correction Blind Spot / Circular Trust）

- **最强点**：学术界已系统证实——LLM 无法可靠修正自己的输出（Self-Correction Blind Spot：能修正别人的错误、修不了自己的）；intrinsic self-correction 常**降低**准确率（Llama-3.1-8B 推翻 58.8% 最初正确回答）；信息论解释：**生成器与评估器错误相关时，自我评估近乎无信息，反复自我批判只增强信心不增加信息**（correlated error）；这就是「Verification Paradox / Circular Trust」。
- **批判**：无——这是对我们最彻底的学术背书。我们的「LLM 只提议、客观源只判定」「红队独立上下文」全部由此获得外部证据支持。
- **吸收**：① 红队隔离升级：**RedTeamer 必须使用与 Writer 不同上下文**（只给断言清单 + 夹具 + 原始工件，不给 Writer 草稿全文）——直接实现「独立检测信号」；② 新增铁律：任何「让模型审自己的输出」的流程 = 非法，除非有独立源介入。**落点：护栏 L4/L5；P1**。

### 5. 知识空间理论 KST（Doignon & Falmagne；ALEKS）

- **最强点**：知识不是线性量表，是**可行知识状态的集合**；先决关系（surmise relation）约束哪些组合可行（「会微积分必会代数」）；**outer fringe（外缘）= 学习者下一步该学什么**；ALEKS 用 KST 20–30 题定位知识状态（vs IRT 100+ 题），生产验证 15 年、50M 学生、4000 学校；知识状态准确性比参与度更预测学习成果。
- **批判**：KST 假设先决关系可枚举——我们的原子 relations 目前只是「相关」标签，没有形式化为先决结构，**这正是 L4 一直缺的数学地基**。
- **吸收**：① relations 升级：原子图增加**先决-衍生边类型**（surmise relation），定义「学会 B 必须以 A 为先决」的形式化约束；② outer fringe = 未来教学推荐引擎的数学基础（L4 数据管道就绪后直接用）；③ 诊断效率目标：未来学习者诊断用 ≤30 题定位知识状态（对标 ALEKS）。**落点：前额叶/知识图；P0（建模）+P2（应用）**。

### 6. AI 科学家批判（四坑清单 / 验证瓶颈）

- **最强点**：AI Scientist 类系统的系统性失败清单——① benchmark cherry-picking（挑有利数据集）；② data leakage（训练/评估重叠）；③ metric misuse（指标误用）；④ 相关性混淆因果；外加：38% 实验因编程错误失败、代码改动 <1%（无真适应）、**验证瓶颈**（AI 生成假设无法规模化验证，人审跟不上生成）。
- **批判**：无——这是「自动生成科学」路线的现实证伪，恰好证明我们走「生成候选 + 客观源验证」而非「自动写论文」是对的。
- **吸收**：候选仓/验收直接挂**四坑防则**：候选的判别实验必须声明「为什么这个基准不偏袒 / 数据无泄漏 / 指标用什么 / 结论是相关性还是因果」；验证瓶颈 → 客观锚不可规模化跳过（人类审阅只复核边界，不承担全量验证）。**落点：锻炉检验闸；P1**。

### 7. 自适应学习生产实践（ALEKS / DreamBox 数据）

- **最强点**：知识状态建模在 K-12 数学大规模生产验证（1M+ 学生），知识状态准确性 > 参与度指标；自适应路径 = 先决图 + 难度匹配。
- **批判**：数学是可枚举领域，C++ 工程知识更开放——KST 落地需要先做「原子先决图」的领域建模（P0 吸收项 5 就是第一步），不能直接照搬。
- **吸收**：L4 认知转化后端的落地路线图：先决图建模 → 诊断 → outer fringe 推荐 → 概念转变干预。**落点：前额叶；P2（依赖真实学习者数据）**。

### 8. EMI / mutation 变体思想（并入差分，单独列出因为它直接对应我们的 mutation testing）

- **最强点**：EMI 用同一程序的语义等价变体做差分——和我们的 mutation testing（变异体找「客观源能否杀死」）同构，但人家是机器大规模自动做。
- **批判**：EMI 的目标是编译器 bug，我们的目标是教学洞见——变体生成要有「教学判别力」过滤（变异后行为差异是否对应一个可讲的知识点）。
- **吸收**：FORGE 变异算子的目标函数：变异候选必须满足「跨编译器/平台行为差异 或 与已 verified 断言冲突」，否则不产生教学增量，退回。**落点：锻炉；P2**。

## 二、三个最重要的吸收（本轮的核心结论）

1. **Lusser's law → 环节做减法**：我们的多角色流水线正在对抗可靠性复合衰减（95%×5=77%）。P0：合并可合并环节、环节数设上限——**这是「上限提升、下限保证」之外我们漏掉的第三维：环节冗余本身就是下限威胁**。
2. **KST → relations 升级为先决结构**：L4 缺的数学地基找到了。P0：原子图增加先决-衍生边类型；这同时让 L3（未知地图）更精确——空白 = 先决图上的悬空节点。
3. **Self-correction 研究 → 独立检测信号的学术背书 + 红队上下文隔离升级**：外部证据证明我们 271/272 的架构决策是对的，并给出新动作（红队用独立上下文，实现真正的「独立检测信号」）。
