## 一、机器人学：运动规划与控制

**核心**：运动规划（RRT*/MPC）在高维空间中寻找无碰撞路径；控制（PID/LQR/强化学习）跟踪轨迹；SLAM同时定位与建图；操作（manipulation）处理物体。

**对「阙疑」的映射**：
- 运动规划 = Agent的"任务规划"：在"约束空间"（门禁规则/人审要求）中寻找从需求到交付的"路径"
- 控制 = Agent的"执行控制"：根据反馈（门禁结果）调整执行（PID式的微调）
- SLAM = 「阙疑」的"自我定位"：同时定位（当前进度）与建图（知识图谱）
- 操作 = 「阙疑」的"精细操作"：如修改单个原子的frontmatter（需要精确控制）

## 二、计算机图形学：光线追踪与全局光照

**核心**：光线追踪模拟光的传播路径；全局光照计算间接光照（反射/折射/散射）；路径追踪是蒙特卡洛方法的全局光照；3D高斯泼溅是新的场景表示。

**对「阙疑」的映射**：
- 光线追踪 = 「阙疑」的"影响追踪"：追踪一个claim的变更如何"反射"到相关原子/证据卡/误解
- 全局光照 = 「阙疑」的"全局影响"：不仅考虑直接影响（prereq），还考虑间接影响（contrasts/relations的传递）
- 路径追踪 = 红队的"随机采样"：随机选择"光线"（审查路径），发现全局问题
- 3D高斯泼溅 = 「阙疑」的"原子表示"：每个原子是一个"高斯"，有位置（主题）、协方差（关系范围）、颜色（类型）

## 三、计算机视觉：SAM与基础模型

**核心**：SAM（Segment Anything Model）实现零样本分割；基础视觉模型（Grounding DINO/Molmo）支持开放词汇检测；视觉-语言模型统一检测/分割/跟踪。

**对「阙疑」的映射**：
- SAM = 「阙疑」的"原子分割"：从"知识海洋"（Book/）中"分割"出独立的原子（可提示的分割：给一个主题，返回一个原子）
- 开放词汇检测 = 「阙疑」的"开放主题检测"：可以检测任意主题的原子（不限于预定义的域）
- 基础模型 = 「阙疑」的"基础提示词"：一个通用的提示词可以处理多种任务（MEM/CONC/UB域）
- 零样本 = 「阙疑」的"零样本生产"：在新域（如CONC）无需重新训练提示词，直接生产

## 四、自然语言处理：Transformer与RAG

**核心**：Transformer的自注意力机制处理长程依赖；RAG（检索增强生成）结合外部知识；RAFT结合RAG与微调；Self-RAG加入反思token。

**对「阙疑」的映射**：
- 自注意力 = 「阙疑」的"自注意力"：提示词中的每个部分都"关注"其他部分（如红队的can't-miss清单关注claim的写法）
- RAG = 「阙疑」的"RAG"：Agent在执行时检索相关原子/证据卡/历史教训（外部知识），而不是只依赖提示词
- RAFT = 「阙疑」的"RAFT"：结合RAG（检索历史教训）与微调（根据反馈调整提示词）
- Self-RAG = 「阙疑」的"Self-RAG"：Agent在执行时加入"反思token"（自检步骤），决定是否需要检索/验证

## 五、推荐系统：协同过滤与知识图谱

**核心**：协同过滤通过用户-物品交互预测偏好；知识图谱增强推荐的可解释性和冷启动；图神经网络建模高阶交互；冷启动是核心挑战。

**对「阙疑」的映射**：
- 协同过滤 = 「阙疑」的"原子推荐"：根据原子之间的"交互"（引用关系）推荐相关原子
- 知识图谱 = 「阙疑」的"知识图谱"：原子/误解/证据卡构成的知识图谱，增强推荐的可解释性
- 冷启动 = 「阙疑」的"新域冷启动"：在新域（如CONC）没有历史原子时，如何生产第一颗原子
- 图神经网络 = 「阙疑」的"关系传播"：通过关系网络传播"质量信号"（如一颗原子被验证，提升相关原子的可信度）

## 六、数据挖掘：关联规则与模式挖掘

**核心**：关联规则挖掘（Apriori/FP-Growth）发现"如果X则Y"的模式；序列模式挖掘发现时间顺序模式；质量度量包括支持度/置信度/提升度；神经符号方法结合神经网络与规则学习。

**对「阙疑」的映射**：
- 关联规则 = 「阙疑」的"教训关联"：发现"如果出现X（如口径不统一），则会出现Y（如方向反转）"的模式
- 序列模式 = 「阙疑」的"流程模式"：发现生产流程中的时间顺序模式（如"夹具→证据卡→红队→门禁"的最优序列）
- 支持度/置信度 = 「阙疑」的"教训度量"：每条教训的支持度（出现频率）和置信度（预测准确率）
- 神经符号 = 「阙疑」的"神经符号"：结合神经网络（LLM的直觉）与符号规则（gate的机械检查）

**最有价值的三个洞察**：
1. **SAM = 原子分割**——从"知识海洋"中"分割"出独立的原子，可提示的分割（给一个主题，返回一个原子）。这是「阙疑」的核心能力：从Book/中提取原子。
2. **RAG = 「阙疑」的RAG**——Agent在执行时检索相关原子/证据卡/历史教训，而不是只依赖提示词。Self-RAG的反思token对应「阙疑」的自检步骤。
3. **关联规则 = 教训关联**——发现"如果出现X，则会出现Y"的模式。这是「阙疑」的"元学习"：从历史批次中学习教训的关联模式，提前预防。
