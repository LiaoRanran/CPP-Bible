## 一、认识论：知识、证成与真理

**核心**：知识的经典定义是"被证成的真信念"（JTB，Justified True Belief）；Gettier问题质疑JTB的充分性；基础主义vs融贯论是证成结构的两大传统；内在主义vs外在主义是证成来源的争论。

**对「阙疑」的映射**：
- JTB = 「阙疑」的"JTB"：原子的"知识"=被证成（证据卡/replay）的真（实测正确）信念（claim）
- Gettier问题 = 「阙疑」的"Gettier问题"：有些原子满足JTB但仍不是"真知识"（如ALLOC-002的旧claim：被证成（旧数据）、真（旧数据正确）、信念（旧claim），但不是真知识（口径不统一））
- 基础主义 = 「阙疑」的"基础主义"：铁律是"基础信念"（不证自明），其他规则建立在其上
- 融贯论 = 「阙疑」的"融贯论"：原子的"证成"来自与其他原子/证据卡/误解的融贯（关系网络）
- 外在主义 = 「阙疑」的"外在主义"：原子的"证成"来自外部过程（replay/门禁/人审），不只是Agent的内在信念

## 二、形而上学：本体论、实体与存在

**核心**：本体论（ontology）研究"存在本身"；实体（substance）是独立存在的基元；Aristotle的十范畴（实体/数量/性质/关系...）；存在vs生成（being vs becoming）是根本分歧。

**对「阙疑」的映射**：
- 本体论 = 「阙疑」的"本体论"：研究"原子是什么"（claim+证据卡+误解+夹具的统一体）
- 实体 = 「阙疑」的"实体"：原子是"实体"（独立存在，属性依赖于它）
- 十范畴 = 「阙疑」的"范畴"：原子的"范畴"（type: mechanism/pitfall/contrast/...）
- 存在vs生成 = 「阙疑」的"存在vs生成"：原子的"存在"（verified状态）vs"生成"（生产过程）
- 本质vs偶性 = 「阙疑」的"本质vs偶性"：原子的"本质"（claim/证据）vs"偶性"（格式/措辞）

## 三、逻辑学：形式逻辑、模态逻辑与证明论

**核心**：命题逻辑/谓词逻辑是基础；模态逻辑研究可能性/必然性（□/◇）；证明论研究证明的结构；Kripke语义用可能世界解释模态算子；Curry-Howard同构将命题与类型、证明与程序对应。

**对「阙疑」的映射**：
- 形式逻辑 = 「阙疑」的"形式逻辑"：gate_engine的规则是"形式逻辑"（机械检查）
- 模态逻辑 = 「阙疑」的"模态逻辑"：原子的"可能性"（可能被证伪）vs"必然性"（必然通过门禁）
- 证明论 = 「阙疑」的"证明论"：证据卡是"证明"（claim的证明），replay是"证明验证"
- Kripke语义 = 「阙疑」的"可能世界"：每个编译器/平台是一个"可能世界"，原子在不同世界中的真值不同
- Curry-Howard同构 = 「阙疑」的"Curry-Howard"：命题=claim，证明=证据卡，程序=夹具（这是332的核心洞察，此处强化）

## 四、科学哲学：证伪主义、范式与科学革命

**核心**：Popper的证伪主义（科学理论必须可证伪）；Kuhn的范式（paradigm）与科学革命（normal science→anomaly→crisis→revolution）；Lakatos的研究纲领（research programme）；费耶阿本德的"怎么都行"（anything goes）。

**对「阙疑」的映射**：
- 证伪主义 = 「阙疑」的"证伪主义"：claim必须可证伪（falsification字段），不可证伪的claim不是"科学"
- 范式 = 「阙疑」的"范式"：G5（知识点+示例）是旧范式，G6（claim+证据卡+红队+门禁）是新范式
- 科学革命 = 「阙疑」的"科学革命"：G5→G6是一次"范式转移"（gestalt shift）
- 研究纲领 = 「阙疑」的"研究纲领"：每个域（MEM/CONC/UB）是一个"研究纲领"，有硬核（hard core）和保护带（protective belt）
- 怎么都行 = 「阙疑」的"怎么都行"：在方法论上，「阙疑」反对"怎么都行"，坚持严格的方法论

## 五、心灵哲学：意识、感受质与意向性

**核心**：意识的"难问题"（hard problem，Chalmers）解释为什么物理过程产生主观体验；感受质（qualia）是主观体验的质性；意向性（intentionality）是心理状态的"关于性"；全局工作空间理论（GNWT）vs整合信息理论（IIT）是两大意识理论。

**对「阙疑」的映射**：
- 难问题 = 「阙疑」的"难问题"：为什么"规则+证据+红队"产生"高质量知识"？这是「阙疑」的"难问题"
- 感受质 = 「阙疑」的"感受质"：好的原子有"质感"（教学价值/直觉共鸣），无法完全形式化
- 意向性 = 「阙疑」的"意向性"：原子的"关于性"（关于某个主题/误解/概念）
- 全局工作空间 = 「阙疑」的"全局工作空间"：提示词是"全局工作空间"（信息被广播给所有子Agent）
- IIT = 「阙疑」的"IIT"：原子库的"整合信息"（关系网络的整合度）决定"意识水平"（系统智能）

## 六、政治哲学：正义、自由与平等

**核心**：Rawls的"作为公平的正义"（justice as fairness）：原初状态（original position）+无知之幕（veil of ignorance）+两大原则（平等自由+差别原则）；自由至上主义（Nozick）vs平等主义（egalitarianism）；社群主义（communitarianism）批评自由主义的"原子化个人"。

**对「阙疑」的映射**：
- 原初状态+无知之幕 = 「阙疑」的"无知之幕"：设计提示词时，假设不知道具体的Agent/环境/域，设计"公平"的流程
- 差别原则 = 「阙疑」的"差别原则"：资源（计算/时间/注意力）分配应优先照顾"最不利者"（最难的原子/最弱的Agent）
- 平等自由 = 「阙疑」的"平等自由"：每个原子/域/Agent都有平等的"基本自由"（被审查/被验证/被改进的权利）
- 社群主义 = 「阙疑」的"社群主义"：原子不是"原子化个人"，而是存在于"社群"（关系网络/域/批次）中
- 正义 = 「阙疑」的"正义"：「阙疑」的"正义"是"程序正义"（公平的生产/审查/验证流程）而非"结果正义"（每颗原子都完美）

---

**最有价值的三个洞察**：
1. **JTB = 原子的知识定义**——原子的"知识"=被证成（证据卡/replay）的真（实测正确）信念（claim）。Gettier问题直接对应ALLOC-002的旧claim：满足JTB但不是真知识（口径不统一）。这解释了为什么「阙疑」需要红队：红队是"Gettier问题探测器"。
2. **科学哲学 = 「阙疑」的方法论基础**——证伪主义（claim必须可证伪）、范式转移（G5→G6）、研究纲领（每个域是一个研究纲领）。「阙疑」的方法论本质上是"科学方法"的工程化。
3. **无知之幕 = 提示词设计原则**——设计提示词时，假设不知道具体的Agent/环境/域，设计"公平"的流程。这是Rawls政治哲学对「阙疑」的直接应用：提示词应该是"在无知之幕后设计的"，不偏袒任何特定的Agent/域。
