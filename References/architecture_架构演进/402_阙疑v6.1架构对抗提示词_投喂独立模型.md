## §5 严重度定义（统一口径）

- **逃逸阻断**：构造的坏卡/坏工件通过了它本应被拦下的门禁（gate block=0 或 replay confirm）
- **高危**：没直接逃逸，但门禁给出误导性结果（假 infra_error、warn 淹没、计数失真）
- **中**：流程/文档层漏洞，需要多个条件叠加才可利用
- **低**：健壮性、可维护性、可读性问题
- **误报**：合法卡被错误拦截（同样重要——记录合法卡路径和误判规则）

## §6 环境与边界

- Windows PowerShell 跑 MinGW GCC（PATH 中）；WSL 跑 g++-13.3/14.2；TSan 需 `setarch -R`；**无 Clang、无 ccache**。
- 只读命令可随意跑（gate/replay/poison/pytest/grep/读文件）。
- **不要**：push、commit、改正式文件、改 CI、安装软件、跑无限循环、跑超过 60 秒的性能夹具。
- replay 会真实编译执行，构造探针时夹具必须**有界、无破坏性**（不删文件、不联网、不写正式目录）。
- Windows replay 与 WSL 预检**不要并行**（同写 .asm 会出假结果）。
- 工具真实行为以实跑为准（`python tools/gate_engine.py --list` 等），文档里的规则数/字段名可能已漂移——**文档与代码冲突时，以代码为准并记录文档失真**。
