# 内部红利审计：榨干现有系统的每一丝潜力（先内后外）

> 2026-09-12 · 第 278 份。方法论：用户要求「先内卷式思考、榨干内部每一丝潜力，再向外找灵感」。本轮**只做实证审计**——所有数字来自对仓库的实扫，不做理念演绎。
>
> 审计时间点：G5 第五批卡层（atoms 20 verified / evidence 49 / misconceptions 79 / Examples 1528 / tools 90 / docs 282）。

---

## 〇、核心发现：当前最大浪费是「设计 ↔ 实现互相看不见」

连续写了 266–277 共 12 份架构文档，但审计仓库后发现一个讽刺事实：**文档在重新发明工程里早已存在、甚至更成熟的机制**。这不是小问题——它正是本项目最防的「口径漂移」，只不过这次漂移发生在架构层。向外找灵感之前，必须先把这层落差填平，否则每学一个外部思想都会重复造一个已有轮子。

## 二、零代码 / 低成本内部红利清单（按收益排序）

- **I1 机制-工具绑定表（零代码，最高优先）**：把 277 宪法每条机制绑定到具体工具/规则 ID，已实现标「复用」、缺口标「待建」。一次绑定，永久消除重复发明。本轮表一即初稿。
- **I2 工具普查（tool census）**：tools/ 有 **90 个 .py，CI 只调用 36 个**，约 54 个不在 CI（本地/一次性/僵尸）。90 个工具是 Lusser 衰减的实体面——没人能完整记住 90 个工具的职责。普查分三类：CI 活 / 本地活 / 僵尸归档；僵尸移入 `tools/archive/`，维护面收敛。
- **I3 误解库 = 现成原子 backlog（零采集成本）**：misconceptions 79 条，域分布 **MEM=32 / UB=15 / STL=10 / CONC=10 / PERF=8 / HIST=3**，而 atoms 仅 20 颗。每条高频误解对应一颗「该锻造未锻造」的原子——FORGE 候选仓的内部供给已经堆在那里，不需要等外部灵感。用 coverage_map + 误解引用计数排序，直接产出下一阶段锻造队列。
- **I4 失败模式 → 毒样例/规则提炼（数据已在手）**：红队历史拦截模式中，P4–P7 只机械化了 4 类（自证断言/伪证伪/恒真观测/无留痕矩阵）。第五批又暴露至少 4 个新模式，**应提炼成 P8–P11 毒样例**：
  - **P8 编译期折叠常量冒充活性观测**（ALLOC H4：15 行输出 8 行是编译期常量，claim 引用的量全在其中，无运行时见证）；
  - **P9 一 bit 两计**（LEAK H1：cycle_is_leak 与 dtor_count 同源 sete dl，两个指标实为一个观测）；
  - **P10 统计口径不统一致方向反转**（ALLOC B1：三个分配器元数据各算各的，统一后排序反转——比「算错数」更危险，因为结论方向反了）；
  - **P11 消除 vs 失败不可区分**（LEAK H2：dtor=0 可能是泄漏，也可能是构造被编译器整体消除，缺活性对照）。
- **I5 .asm 工件 = 编译器行为数据库（横向未挖掘）**：Examples 1528 文件、evidence 49 卡的 .asm 目前只做「逐字复现」（纵向 replay），跨卡/跨编译器/跨 -O 档的横向差分从没挖过。这正是 Csmith 差分思想的内部版：同一夹具多平台 .asm 已有，写一个横向 diff 工具能自动发现「编译器间行为差异」教学点（B 样板式内容可半自动产出）。
- **I6 evidence(49) > atoms(20) 的服务关系审计**：近 2.5 倍的卡物比，部分卡服务草稿（第五批），但应机械核对有无「孤儿证据卡」（不 serves 任何现存/草稿原子）——孤儿卡要么是未锻造原子的证据（进 backlog），要么是冗余。

## 五、向外找灵感的前置闸门

在启动下一轮外部调研前，I1–I6 必须先做完（尤其 I1 绑定表、I3 误解 backlog、I4 新毒样例）。理由：**内部已采的数据还没榨干就向外学，等于守着矿没挖去借别人的矿**——外部思想（Csmith 差分、KST、error budget）在本仓库的对应物其实大多已具雏形，落差在「没接线」，不在「没学到」。外部调研的正确姿势因此变为：带着 I1 绑定表里明确标「缺口」的格子去外部找解法，而不是泛泛地扫。

## 六、给用户的话

这轮内卷审计最有价值的不是发现新机制，是发现**我们不缺机制、缺接线**：error budget、先决拓扑、状态机范式、覆盖地图、DAG 学习路径全都在工具里躺着，架构文档却在重新设计它们；79 条误解、1528 个夹具、49 张卡的横向价值从没被二次提炼。

向外找灵感我会继续，但先把这六笔内部红利兑现——它们零成本或低成本、且全部可机械验收。这也给宪法补了一条新的元规则：**先复用后新建，先榨干后外求。**
