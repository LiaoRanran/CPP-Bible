## 十、关键教训

1. **假逃逸比真逃逸更危险**：M2 的 207 条"逃逸"全是 actual 键漏读造成的假逃逸——尺子本身坏了，读数全错。修复后逃逸率从 23.7% 降到 6.3%。
2. **发现器完备性是持续过程**：每修一个尺子 bug 就 un-mask 出一批真实逃逸（M5 0→29、M2 141→168），发现器越完备，看到的洞越多。
3. **warn 起步是铁律**：所有新收紧一律 warn 不 block，观察期 N 轮 + 人审裁决后才升级——541 的两次存量翻车（block 0→38）就是因为没遵守。
4. **自检不能裸 except Exception**：569 的退出自检静默空转就是因为 NameError 被裸 except 吞掉——"没查成却像查过"是最危险的假绿。
5. **信任根是最终瓶颈**：34 项攻击面中 4 项未防御全部是信任根问题（自签/回溯/stale/采集造假），单用户模型下无法根本解决，需多人/带外身份/可信时间戳。
