## Part 1 · 统计原语库 `tools/stat_bounds.py`（N1）
把 `_arch_v6/probe_bounds.py` 正规化为正式工具（函数保留、补 docstring/类型/边界校验/CLI），至少含：
`cp_upper(k,n,conf)`、`cp_interval(k,n,conf)`（Clopper-Pearson 精确）、`wilson(k,n,conf)`、`n_for_upper_bound_zero(eps,conf)`（零失效样本量）、`n_for_proportion(...)`、底层 `beta_quantile`。
- **边界 fail-loud**：n=0、k>n、k<0、conf∉(0,1) 一律抛 ValueError，禁止静默返回。
- **scipy/numpy 不可用，也禁止为对拍把 scipy 加进核心依赖**（核心依赖保持 pyyaml）。正确性用四重锚点（写进 `tests/test_stat_bounds.py`）：
  1. k=0 解析解：C-P 上界 == `1 - conf**(1/n)`（与数值法误差 <1e-9）；k=n 用对称性 `1 - (1-conf)**(1/n)`；
  2. 独立第二实现交叉：另写一份用不完全 Beta 函数**数值积分求 CDF 再二分**的实现，与 probe 的 `beta_quantile`（牛顿/分位反解）相互独立，两法在随机 (k,n) 网格上偏差 <1e-7；
  3. 公开锚点回归：56 卡 0 误伤 95% 上界≈0.05209、rule-of-three 3/56≈0.05357、n=100,k=0 95% 上界≈0.0295；
  4. 样本量：eps=5%@95% 零失效 n=59、eps=2% n=149。
- CLI：`tools/stat_bounds.py cp --k 0 --n 56`、`wilson`、`n-needed --eps 0.05`，输出分子/分母/点估计/区间，机器可读 `--json`。
- 验收：新测试全绿；与 `_arch_v6/probe_bounds.py` 输出逐值一致；纯标准库可跑。独立 commit。
