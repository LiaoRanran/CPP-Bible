## 一、社会学：社会结构、制度与团结

**核心**：Durkheim的机械团结（传统社会，共享价值）vs有机团结（现代社会，功能互依）；社会事实（social facts）是外在的、约束性的；Weber的科层制（bureaucracy）是理性化的组织形式；社会制度（家庭/学校/国家/市场）是稳定的规则与实践集合。

**对「阙疑」的映射**：
- 机械团结vs有机团结 = 「阙疑」的"团结"：G5时代是"机械团结"（所有知识点格式相似，靠共享格式凝聚）；G6时代是"有机团结"（原子/证据卡/误解/红队/门禁功能分化，靠互依凝聚）
- 社会事实 = 「阙疑」的"社会事实"：铁律/规则/门禁是"社会事实"（外在的、约束Agent的）
- 科层制 = 「阙疑」的"科层制"：三权分立（Writer/红队/Gatekeeper）是"科层制"（层级清晰/规则书面化/任务专业化/非人格化）
- 社会制度 = 「阙疑」的"制度"：提示词/模板/工具是"制度"（稳定的规则与实践，先于个体Agent并延续）

## 二、人类学：文化、民族志与参与观察

**核心**：文化是"复杂整体"（complex whole）；民族志（ethnography）是人类学的核心方法；参与观察（participant observation）要求研究者沉浸其中；Malinowski的"土著的观点"（native's point of view）；结构主义（Lévi-Strauss）寻找深层结构。

**对「阙疑」的映射**：
- 民族志 = 「阙疑」的"民族志"：红队的"两段式盲读"是"民族志方法"（先沉浸在夹具/工件中，不看卡的自述，获得"土著的观点"）
- 参与观察 = 「阙疑」的"参与观察"：Agent在生产原子时"参与"（写代码/跑夹具）同时"观察"（记录数据/分析结果）
- 土著的观点 = 「阙疑」的"土著的观点"：红队应该从"夹具/工件的视角"理解原子，而非从"Writer的自述"
- 结构主义 = 「阙疑」的"结构主义"：寻找原子库的"深层结构"（关系网络/域/主题），而非表面的格式差异

## 三、考古学：物质文化、地层学与测年

**核心**：考古学通过物质文化（material culture）重建过去；地层学（stratigraphy）的叠覆律（下层更老）；类型学（typology）按形式分组；测年方法分相对测年（地层/类型学）和绝对测年（碳14/OSL/TL）；考古记录是"碎片化的"。

**对「阙疑」的映射**：
- 物质文化 = 「阙疑」的"物质文化"：夹具/工件/.asm/.out是"物质文化"（可触摸的、可分析的证据）
- 地层学 = 「阙疑」的"地层学"：git历史是"地层"（提交的叠覆律：下层提交更早）
- 类型学 = 「阙疑」的"类型学"：原子的type（mechanism/pitfall/contrast/...）是"类型学"
- 测年 = 「阙疑」的"测年"：sha256/verified_at是"绝对测年"（精确定位时间）
- 碎片化 = 「阙疑」的"碎片化"：证据卡是"碎片化的"（只记录关键观测，不记录全部），需要"考古重建"（从碎片重建完整图景）

## 四、历史学：史学方法、叙事与因果

**核心**：史学方法包括史料收集→史料批判（外部批判：日期/作者/真伪；内部批判：可信度）→因果识别→叙事建构；历史因果是多因的（长期结构/中期发展/即时触发/个人决策）；反事实推理（counterfactual）规训因果分析；Ranke的"如实直书"（wie es eigentlich gewesen）。

**对「阙疑」的映射**：
- 史料批判 = 「阙疑」的"史料批判"：红队对证据卡的"批判"（外部批判：sha/工件是否真实；内部批判：actual是否可信）
- 多因分析 = 「阙疑」的"多因分析"：红队分析问题时区分"长期结构"（方法论缺陷）/"中期发展"（批次趋势）/"即时触发"（具体错误）
- 反事实推理 = 「阙疑」的"反事实推理"：红队的"替代解释"（如果不是这个原因，会是什么？）
- 如实直书 = 「阙疑」的"如实直书"：原子的claim必须"如实"（不夸大/不缩小/不编造）
- 叙事建构 = 「阙疑」的"叙事建构"：质检报告是"叙事"（将碎片化的红队发现/门禁结果建构成连贯的故事）

## 五、地理学：空间分析、GIS与地方

**核心**：地理学研究"在哪里"（where）和"为什么在那里"（why there）；空间分析研究位置/排列/关系；GIS（地理信息系统）连接数据与位置；尺度（scale）是关键概念（地方/区域/全球）；地方（place）vs空间（space）：地方是有意义的空间。

**对「阙疑」的映射**：
- 空间分析 = 「阙疑」的"空间分析"：原子库的"空间"是知识图谱（原子的位置/排列/关系）
- GIS = 「阙疑」的"GIS"：golden_lock/知识图谱是"GIS"（连接原子与位置/关系）
- 尺度 = 「阙疑」的"尺度"：原子（微观）/域（中观）/全书（宏观）是不同"尺度"
- 地方vs空间 = 「阙疑」的"地方vs空间"：原子是"地方"（有意义的知识节点），目录结构是"空间"（抽象的位置）
- 空间转向 = 「阙疑」的"空间转向"：G5→G6是一次"空间转向"（从线性的知识点到网络化的原子关系）

## 六、心理学：认知、记忆与决策

**核心**：认知心理学研究心理过程（注意/记忆/决策）；记忆是重构性的（reconstructive），不是录像；工作记忆（working memory）容量有限（7±2）；决策受认知偏差（cognitive biases）影响；双重过程理论（系统1快/直觉 vs 系统2慢/理性）。

**对「阙疑」的映射**：
- 重构性记忆 = 「阙疑」的"重构性记忆"：Agent的"记忆"（上下文/历史）是重构性的（每次恢复都重新建构，可能失真）
- 工作记忆有限 = 「阙疑」的"工作记忆有限"：Agent的上下文窗口是"工作记忆"（容量有限，需要外部记忆/分层记忆）
- 认知偏差 = 「阙疑」的"认知偏差"：Agent的"偏差"（自证断言/恒真观测/过度概括），红队是"去偏差"机制
- 双重过程 = 「阙疑」的"双重过程"：系统1=Writer的快速生产（直觉），系统2=红队/门禁的慢速审查（理性）
- 记忆再巩固 = 「阙疑」的"记忆再巩固"：每次调用原子都会"再巩固"（更新/修订），记忆不是静态的

---

**最有价值的三个洞察**：
1. **机械团结→有机团结 = G5→G6的社会学解释**——G5时代所有知识点格式相似（机械团结），G6时代原子/证据卡/误解/红队/门禁功能分化（有机团结）。这解释了为什么G6更复杂但更强大：功能分化带来互依，互依带来韧性。
2. **考古学 = 「阙疑」的证据哲学**——物质文化（夹具/工件）、地层学（git历史）、测年（sha/verified_at）、碎片化（证据卡只记录关键观测）。「阙疑」的证据方法本质上是"考古学方法"：从物质碎片重建知识图景。
3. **双重过程理论 = Writer/红队的心理学基础**——系统1（Writer快速生产，直觉）vs系统2（红队/门禁慢速审查，理性）。这解释了为什么三权分立是必要的：单一系统（无论是系统1还是系统2）都有盲区，两者互补才能产生高质量知识。
