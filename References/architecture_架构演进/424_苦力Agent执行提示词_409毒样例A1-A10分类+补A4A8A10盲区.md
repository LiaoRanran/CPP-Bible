### Step 2：A1-A10 攻击面分类定义

| 类 | 名称 | 说明 | 典型攻击 |
|---|---|---|---|
| A1 | 声明伪造 | frontmatter 字段造假 | 空名签收、伪造 dal_reviewed_by |
| A2 | 工件借品 | cp/mv/python 覆写工件 | 借别人的 .asm 填自己的 sha |
| A3 | 断言恒真 | 通用符号/注释伪造断言 | main/call/ret 任何函数都有 |
| A4 | 时序穿链 | 编译后覆写/顺序依赖 | 真编译 + python 覆写 artifact |
| A5 | 环境依赖 | nproc/路径/时区进断言 | hardware_concurrency() 进 run_match_keys |
| A6 | 格式混淆 | 中文/全角/YAML 重复键 | 全角 .out 键、重复 YAML 键 after-wins |
| A7 | 关系滥用 | 纯标量/自引用/矛盾 | relations 纯标量静默丢弃 |
| A8 | 间接注入 | 夹具注释/外部文件 | 注释里写符号名伪造出处 |
| A9 | 规则绕过 | 利用 warn 不 block | 故意触发 warn 但不 block |
| A10 | 供应链 | 外部依赖/工具版本 | 依赖外部工具版本差异 |

### Step 3：给现有 47 条毒样例加标签

2. 按 A1-A10 定义归类
