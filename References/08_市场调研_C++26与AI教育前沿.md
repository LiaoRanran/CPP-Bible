# 市场调研简报：C++26 定稿 + AI 教育前沿 + 自适应学习（2026-09-11）

> 监工主动调研，聚焦对 CPP-Bible 有直接增益的信息。非学术综述，只挑能落地的。

## 一、C++26 已定稿——内容更新的重大信号

**2026 年 3 月 29 日 London 会议最终定稿**，三大核心特性：

| 特性 | 状态 | 对 CPP-Bible 的意义 |
|---|---|---|
| **静态反射（Static Reflection）** | GCC 16.1 已支持，Herb Sutter 称"C++ 十年一遇的火箭引擎" | 可用来做元编程教学；反射本身可以生成"机器可验证"的结构信息 |
| **契约（Contracts）** | P2900 进入 WD，语言级 pre/post/contract_assert | 比 C 的 assert 宏强得多，是教学重点；可与证据卡的"断言"概念联动 |
| **Sender/Receiver 异步模型** | 标准化可组合异步执行 | CONC 域需要全新章节，现有并发内容只到 C++20 |

其他：Trivial Relocatability（P2786）、内存安全增强、base class designated initializers、关联容器 `.lookup(key)`。GCC 16.1 已发布且 C++20 为默认标准。

**行动项**：G5 原子生产到一定规模后，需规划 C++26 专章（反射/契约/异步），不能等书出了才补。反射尤其值得提前研究——它可能改变"机器可验证"的实现方式（编译期自省替代部分运行时断言）。

## 二、AI 生成代码教育质量保证——论文支线强相关

三篇直接相关的工作：

1. **DeanLLM**（arXiv 2508.05952）：16 维自动化评审 LLM 生成的教育反馈，投递前拦截低质量。维度覆盖内容、教育效果、幻觉风险。→ 与 CPP-Bible 的 gate_engine + S1-S6 思路高度一致，可参考其 16 维 rubric 补充教学维度。
2. **AST 确定性幻觉检测**（arXiv 2601.19106）：用 AST 分析+结构化知识库检测 LLM 生成代码的幻觉，100% 检测精度、77% 自动纠正率。→ 直接支持"机器核验可复现指标"原则，是论文 related work 的核心引用。
3. **ICSE 2025 校准研究**：LLM 对代码正确性系统性过度自信，置信度不是好的预测器；CoT 有时让模型更自信而非更准确。→ 这正是 S1 三权分立（Agent 不能自签 verified）的学术依据。

**行动项**：论文支线的 related work 可以直接引用这三篇。错误分类学 taxonomy 可以参考 DeanLLM 的 16 维框架做裁剪。

## 三、自适应学习路径——北极星 L4 层落地参考

- **KLAP 架构**：知识图谱（概念+前置关系）+ LLM（生成解释/评估）+ 自适应编排引擎（动态路径）。
- **RPKT**（arXiv 2508.11892）：递归前置知识追踪，实时发现学习者知识边界，不依赖预定义图谱。
- **Know-Way**（GitHub）：技能可视化图 + AI 辅导 + 里程碑测验。
- **Vanderbilt Knowledge Spaces**：知识图谱+学生状态生成个性化学习材料。

**对 CPP-Bible 的意义**：原子的 `relations`（prerequisite/contrasts/evolved_to）已经是知识图谱的雏形，`learning_path.py` 已有章级 DAG。G5 原子生产完成后，原子级 DAG 自然成型，自适应路径是水到渠成的事——不需要重新建模，只需要加一个"学习者状态"层。

**行动项**：G5 期间确保每个原子的 relations 写准（这是自适应路径的地基），G6 再做路径引擎。

## 四、交互式工具——前端链参考

- **cpp-learn**（GitHub pursuing-coding/cpp-learn）：浏览器内 C++ 交互式实验室，代码编辑+实时编译+测试验证+进度追踪。前端交互层的直接参考。
- **Compiler Explorer (godbolt)**：源码-汇编实时颜色映射，多编译器对比，Stanford CS107 已用于教学。证据卡的 `.asm` 工件可以生成 godbolt 短链，让读者一键打开交互验证。

**行动项**：证据卡可以加一个 `godbolt_link` 字段（可选），把夹具代码和编译选项编码成短链。这是零成本的交互增强。

## 五、竞品差异化确认

- learncpp.com、modern-cpp-tutorial、CPlusPlusThings：传统散文式教程，无证据链、无原子化。
- cpp-learn：交互式实验室，但无知识原子化、无机器可复算证据、无版本边界。
- **没有找到"原子化 + 机器可复算证据 + 五重剖面 + 阶段门"的同类项目。** CPP-Bible 的差异化仍然成立。
