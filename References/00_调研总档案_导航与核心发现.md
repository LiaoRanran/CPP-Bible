## 二、核心发现总览

### 2.1 项目定位与差异化

**三条支柱**（01）：
1. 可验证的 Meyers——差异在"机器可复算"而非作者权威
2. 结构化误解库——字段 vs 散文，可聚合/可回归
3. 自适应学习路径——图遍历 vs 推荐系统，确定可测

**六层北极星架构**（04）：L0 内容原子 → L1 来源置信 → L2 实证验证 → L3 制衡门禁 → L4 学习路径 → L5 多端交付

**竞品差异化确认**（08/09/10）：
- learncpp.com / modern-cpp-tutorial / CPlusPlusThings：传统散文式，无证据链、无原子化
- cpp-learn：交互式实验室，无知识原子化、无机器可复算证据
- Cursor / GitHub Copilot：AI 辅助写代码（生成效率），不做知识教学+验证
- **没有找到"原子化 + 机器可复算证据 + 五重剖面 + 阶段门"的同类项目。差异化成立。**

### 2.2 C++ 标准动态（08）

**C++26 已于 2026-03-29 London 定稿**，三大特性：
- **静态反射**（GCC 16.1 已支持，Sutter 称"十年一遇的火箭引擎"）——可能改变验证方式（编译期自省替代部分运行时断言）
- **契约 Contracts**（P2900，语言级 pre/post/contract_assert）——教学重点，可与证据卡断言联动
- **Sender/Receiver 异步模型**——CONC 域需全新章节
- 其他：Trivial Relocatability、内存安全增强、base class designated initializers、`.lookup(key)`

**行动**：G5 后规划 C++26 专章；反射特性可提前做实验夹具。

**多Agent协作**（09）：
- MARS（arXiv 2509.20502）：author→reviewer→meta-reviewer，与 CPP-Bible 三权分立同构
- LLM Review（OpenReview）：**小模型+评审框架胜过大模型单agent**；创意任务需要发散而非收敛
- MAD conformity 问题：多Agent辩论中跟随多数意见即使错误——需异源/异构
- 跨平台异源策略（traeWork Writer / CodeBuddy RedTeamer）对应 A-HMAD 异构思想

### 2.4 教学范式（09/10）

**认知负荷理论 CLT**（10）——教学封装的学术依据：
| CLT 原则 | CPP-Bible 机制 | 状态 |
|---|---|---|
| 工作示例效应 | 证据卡完整可运行示例 | ✅ |
| 专长逆转效应 | audience + depth.layer | ✅ 需 G5 确保准确 |
| 自我解释效应 | socratic 提问链 + predict_first | ✅ |
| 渐隐示例 | 证据卡→Koans 填空测试 | ⏳ G6 |
| 内在负荷控制 | 原子粒度（一知识点一原子） | ✅ |
| "写出来≠理解了" | 证伪对照 + 汇编锚定 | ✅ |

**关键洞察**：CLT 研究证明"AI 提示越多学得越浅"（L@S 2025，平均每练习点3.7次提示）——这解释了为什么 CPP-Bible 不做"AI 直接给答案"，而是"先预测→再验证→误解纠正"的主动学习链。

**其他教学范式**（09）：

## 五、核心洞察（一句话版）

1. **CPP-Bible 的核心机制全部有学术同源**——证据卡=可复现研究+测试驱动学习，误解库=误解研究，三权分立=MARS多Agent评审，原子导出=间隔重复，教学封装=认知负荷理论。这不是拍脑袋的工程，是多范式整合。
2. **"垃圾大模型也能干活"有学术依据**——LLM Review 证明小模型+强评审框架胜过大模型单agent。前提是门禁/评审链足够强。
3. **AI 提示越多学得越浅**——CLT 和 L@S 2025 都证明了这一点。CPP-Bible 的"先预测再验证"主动学习链是正确的教学设计方向。
4. **C++26 反射可能改变验证方式**——编译期自省替代部分运行时断言，值得提前研究。
5. **不与 Cursor/Copilot 竞争**——它们做"帮你写代码"，CPP-Bible 做"帮你理解并证明"，互补关系。
