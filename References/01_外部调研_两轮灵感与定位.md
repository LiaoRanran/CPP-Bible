# 01 外部调研：两轮灵感与定位

> 归档：2026-09-10 · 关联规范 `docs/kernel/{M1_ontology,M2_empirical,M3_sources,M4_gate_engine,M5_metrics}.md`、`S1_S6_controls.md`
> 性质：**调研沉淀**（灵感 → 决策链留痕），不是规范。规范在 `docs/kernel/`，此处只解释"为什么这样定"。

## 0. 定位声明（护城河方向）

**可验证的 Meyers + 结构化误解库 + 自适应学习路径。**

三句话拆开——这是本书与"又一本 C++ 教程"的分界线：

| 支柱 | 含义 | 与既有教材的差别 |
|---|---|---|
| **可验证的 Meyers** | 条目式（item）写法：一条断言 + 边界 + 一个反例 | Meyers 的 item 靠作者权威；**我们的每条断言能被机器复算**（`atom_evidence_replay` 四校验：编译/输出/工件哈希/sanitizer） |
| **结构化误解库** | "常见误解"是字段不是段落：`pedagogy.misconception[]` | 散落段落无法聚合/检索/回归；字段可被规则查（`PED-MISCONCEPTION`）、可统计重灾区 |
| **自适应学习路径** | M1 的四种 DAG 边构成有向无环图，路径 = **图遍历** | 固定章节顺序 → 按读者当前掌握集合求拓扑序；确定性、可测试、可解释 |

## 1. 第一轮调研：6 个灵感

| # | 灵感 | 对本书的落点 | 落地状态 |
|---|---|---|---|

## 2. 第二轮调研：4 个发现

1. **Meyers item 模式与我们高度同构**：Effective Modern C++ 的 item = 一条可操作结论 + 为什么 + 怎么做。
   差别只在"证据要求"——我们要求**机器可复算**，这是可执行的护城河而不是口号。
2. **内存误解是重灾区**：移动语义 / 值类别 / 生命周期是误解最密集区。实证：全书 298 条 `[UNVERIFIED]`
   中 MEM / STL / CONC 三域占比最高（见 `tools/m5_dashboard.py` 与 `build/metrics.json`）。
   → **样板 A 选"移动语义"不是随手挑的**，它是误解密度的最大值点。
3. **Godbolt 颜色映射可作教学桥**：汇编视图把源码行与指令对应关系**可视化**——
   读者看到 `call malloc` 高亮对应到源码哪一行，比一大段文字解释有效得多。
   → 纵深证据（`depth.drill_note`）应当指向"可对照的行号"，而不只是"我跑过汇编"。
4. **学习路径 = 图遍历，不是推荐系统**：不做 ML 推荐——DAG 上按"已知集合"求拓扑序即可，
   结果确定、可测试、可对读者解释"为什么先学这个"。

## 3. G4 落地 5 件事（把调研变成样板）

1. 三样板各走四步：**3 分平庸版 → 红队攻击 → 升 5 分候选 → 人审**；
2. 每样板填满**五剖面**（`sources[]` / `evidence[]` / `superiority` / `depth` / `pedagogy`）——缺一即打回；
3. 误解写进 `pedagogy.misconception[]`，**至少 3 条且逐项标 `level: surface|deep`**；
   deep 类（结构性误解）必须配 **≥2 个独立反例**（指向证据卡 ID）——surface 一次纠正即可，
   deep 不给足反例纠不过来（这是调研的核心结论，已固化为门禁规则）；
4. 纵深至少钻到 **asm 层**（`depth.layer: asm` + `drill_note` 指向证据卡的汇编证据）；
5. `superiority` 逐来源写增量（M3 禁词表拦截"更详细/更全面"式空话）。

## 5. 决策记录（为什么这样定）

| 决策 | 取舍 | 理由 |
|---|---|---|
| 不做推荐系统 | 图遍历 vs ML | 确定性、可测试、可解释；教材必须能对读者讲清"为什么先学这个" |
| 误解做成结构化字段 | 字段 vs 散文 | 散文无法聚合/回归；字段可被门禁查、可统计重灾区、可导出题库 |
| 样板先写"平庸版" | 3 分 → 5 分 vs 直接写 5 分 | 没有平庸版对照就无法证明"升级补了什么"（0.4 rubric 要求写明升分依据） |
| 证据一切走机器复算 | 人工核验 vs 机器 refute | G2 教训：作者自述会产生假阳性（"旧工件 vs 旧记录"），机器比才可靠 |
