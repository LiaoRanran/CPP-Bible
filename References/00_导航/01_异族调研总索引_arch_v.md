## 调研纪律

所有 _arch_v* 调研均遵守以下纪律：
1. **全程只读**：不修改 tools/evidence/atoms/Examples/tests/data 任何正式文件
2. **零实跑**：不跑 pytest/poison_drill/mutation_fuzz/tool_integrity --check（避免"还原真实仓库"逻辑冲掉未提交编辑）
3. **零 git 写**：不 commit/checkout/reset/push
4. **zero_pollution.md**：每个目录均含 git 前后状态自证
5. **外部事实标注**：所有外部论断附链接+检索日期+【已查证】/【一方称】标注
6. **不编数字**：算不出的明说缺什么，不编造编号/数字
