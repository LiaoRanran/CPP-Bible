### observation 命题的活性锚缺口

- 50/50 observation 命题全缺活性锚（proposition_liveness_audit 实跑）

- 这是论证层最大的知识债——observation 命题没有"可证伪的活性对照"

### inference 命题的签署缺口

- 29/29 inference 命题的签署状态需逐卡核实
- P65 毒样例验证：inference 机器独自晋升 verified 须 block
- P66 毒样例验证：inference 命题级无签+卡级无人签+无基准 ⇒ block
- 人审权力：inference 命题的 verified 晋升必须人签（机器不能独自晋升）

## 三、W2 加权 AF 求解

### 3.1 求解结果

| 节点类型 | 数量 | 判决 | 说明 |
|---|---|---|---|
| 命题 | 79 | IN | 全部接受（可信度高） |
| 误解（MIS） | 42 | OUT | 全部拒绝（可信度低） |
| 不确定 | 0 | UNDEC | 无不确定节点 |

### 3.2 W2 模型定义

W2 = 可信度加权击败 + 命题反驳误解的对称边

- **可信度加权击败**：攻击边的权重 = 攻击者可信度 - 被攻击者可信度。只有当攻击者可信度 > 被攻击者可信度时，攻击才构成击败。
- **对称边**：MIS→命题边 + 命题→MIS 边（命题反驳误解）。
- **可信度分级**：命题 = medium（卡面有 verified_by/machine_verified），MIS = low（MIS 卡面 0 张有可信度字段）。

### 3.3 为什么 W2 能解除退化

| 模型 | IN | OUT | UNDEC | 结果 |
|---|---|---|---|---|
| S0 零攻击 | 79 | 0 | 0 | 全接受（平凡） |
| S1 MIS→命题（单向） | 43(MIS) | 0(命题) | 0 | 语义倒置：错误声称被当真 |
| S2 MIS↔命题（对称） | 0 | 0 | 122 | 全不确定（grounded=∅） |
| W1 阈值加权 | 语义倒置持续 | — | — | 低阈值误解被当真、高阈值全员接受 |
| **W2 可信度加权+对称** | **79** | **42** | **0** | **非退化且语义正确** |

**关键洞察**：最直觉的修法（阈值加权 W1）无效，必须"方向性可信度 + 命题反向反驳误解（对称边）"双条件。这是 594 异族调研的核心发现。

### 3.4 收敛过程

- 第 1 轮：命题 IN（无攻击者击败它们），MIS OUT（被命题击败）
- 第 2 轮：无变化（不动点）
- 第 3 轮：确认不动点 ⇒ 收敛

实际 3 轮收敛（含一轮确认），计算耗时 <0.5ms（P 类，朴素最小不动点已足够）。

## 六、论证层的三大瓶颈

### 6.1 人审 0/388（最大瓶颈）

388 条候选攻击边人审 0 条。这是论证层从"概念可用"到"令人信服"的最大瓶颈——没有经过人审确认的攻击边，W2 求解的结果只是"机器预测"，不是"经过验证的论证"。

**优化路径**：MIS 群组级人审（42 组，24.5 分钟），而非边级人审（388 边，1.89 小时）。

### 6.2 命题活性锚 0/50（知识债）

50 条 observation 命题全缺活性锚。活性锚 = 特有符号 + 量化证伪，是 observation 命题"可证伪"的硬保证。没有活性锚，observation 命题只是"声明"，不是"可验证的观察"。

**优化路径**：批量补活性锚（需人审裁决，因为活性锚的设计需要领域知识）。

### 6.3 verified_by_oracle 0/83（信任根缺口）

83 张证据卡 verified_by_oracle 填了 0 张。这是"独立验证"的缺口——没有 oracle 验证，证据卡的 verified 只是"自签"，不是"独立验证"。

**优化路径**：异族 oracle 验证（需外部独立验证者，单用户阶段结构性上限）。

## 七、设计意图分析

### 1. W2 求解是"论证层从概念到可用"的关键
W2 加权 AF 求解（IN79/OUT42/UNDEC0）证明了论证框架在本仓数据上是可用的——不是退化的全接受或全不确定，而是语义正确的"命题全 IN、误解全 OUT"。这是 593-594 异族调研的核心成果。

### 2. 候选攻击边自动生成是"零 Oracle 风险"的设计
388 条候选攻击边由 MIS related_atoms × 卡面命题自动生成，零 Oracle 风险——不依赖 LLM 标注，不依赖人审预标注，纯规则生成。这是"生成者不能兼任判断者"第一原则的体现——攻击边的生成是规则驱动的，不是 LLM 驱动的。

### 3. 人审从"边级"到"MIS 级"是"工作量降 4.6 倍"的优化
595 异族调研发现，388 边的"工作量"是假象。把人审从"边级确认"改为"MIS 级目标映射"，工作量从 1.89 小时降到 24.5 分钟。这是"人审效率工具链"的核心设计——不是减少人审，而是让人审更高效。

### 4. 命题闭包是"论证密度"的可计算度量
命题闭包（avg 6.076/max 8/min 4）是"论证密度"的可计算度量——闭包越大，命题的论证链越长。这是"度量诚实化"的体现——不满足于"论证很丰富"，而是量化"论证密度是多少"。

### 5. 三大瓶颈显式登记是"不掩盖问题"的纪律
人审 0/388、活性锚 0/50、verified_by_oracle 0/83 三大瓶颈显式登记，而不是"修个规则假装堵住"。这是"度量诚实化"的体现——承认存在已知缺口，并说明为什么暂时不修复（需人审/需外部验证者）。
