## 二、命题分类（79 命题）

| 类型 | 数量 | 占比 | 说明 |

| observation | 50 | 63.3% | 观察命题（需活性锚+工件断言） |

### observation 命题的活性锚缺口

- 50/50 observation 命题全缺活性锚（proposition_liveness_audit 实跑）
- 活性锚 = 特有符号 + 量化证伪（P68 毒样例验证：只挂 run_match 卡的 observation 须 warn）
- 这是论证层最大的知识债——observation 命题没有"可证伪的活性对照"

### inference 命题的签署缺口

- 29/29 inference 命题的签署状态需逐卡核实
- P65 毒样例验证：inference 机器独自晋升 verified 须 block
- P66 毒样例验证：inference 命题级无签+卡级无人签+无基准 ⇒ block
- 人审权力：inference 命题的 verified 晋升必须人签（机器不能独自晋升）

**OUT 的 7 个 MIS**：
1. MIS-LANG-001（语言特性误解）
2. MIS-MEM-001（内存管理误解）
3. MIS-MEM-003（内存管理误解）

这 7 个 MIS 的共同特征：人审时标记为 modify（需要修改攻击边的目标或权重），MIS 可信度保持 low，被命题（medium）明确击败。详见 data/out_mis_review_checklist_20260920.md。

### 3.2 W2 三阶段判决演进

| 阶段 | 人审状态 | IN | OUT | UNDEC | 击败边 | 语义 |
|---|---|---:|---:|---:|---:|---|
| 阶段 0（人审前） | 0/388 | 79 | 42 | 0 | 194 | 二元对立：命题全对，误解全错 |
| 阶段 1（半量人审） | 194/388（MIS→命题） | 121 | 0 | 0 | 0 | MIS 可信度升到 medium，同可信度不击败，全 IN |
| **阶段 2（全量人审）** | **388/388** | **114** | **7** | **0** | **17** | **分层判决：35 MIS IN（有技术含量），7 MIS OUT（被明确击败）** |

**关键洞察**：全量人审后，论证层从"二元对立"（命题全对/误解全错）变成"精细分层"（35 个 MIS 有足够技术含量需进一步裁决，7 个 MIS 被命题明确击败）。这是人审全量完成带来的质变——论证层不再是简单的"对错二分"，而是有了"灰度"。

### 3.3 W2 模型定义

W2 = 可信度加权击败 + 命题反驳误解的对称边

- **可信度加权击败**：攻击边的权重 = 攻击者可信度 - 被攻击者可信度。只有当攻击者可信度 > 被攻击者可信度时，攻击才构成击败。
- **对称边**：MIS→命题边 + 命题→MIS 边（命题反驳误解）。
- **可信度分级（人审全量后）**：
  - 命题 = medium（卡面有 verified_by/machine_verified）
  - MIS（人审 approve）= medium（35 个，人审确认攻击成立，提升可信度）
  - MIS（人审 modify/reject/unreviewed）= low（7 个 modify，人审认为攻击边需修改，保持低可信度）

### 3.4 为什么 W2 能解除退化

| 模型 | IN | OUT | UNDEC | 结果 |
|---|---|---|---|---|
| S0 零攻击 | 79 | 0 | 0 | 全接受（平凡） |
| S1 MIS→命题（单向） | 43(MIS) | 0(命题) | 0 | 语义倒置：错误声称被当真 |
| S2 MIS↔命题（对称） | 0 | 0 | 122 | 全不确定（grounded=∅） |
| W1 阈值加权 | 语义倒置持续 | — | — | 低阈值误解被当真、高阈值全员接受 |
| W2（人审前） | 79 | 42 | 0 | 非退化且语义正确（二元对立） |
| **W2（人审全量后）** | **114** | **7** | **0** | **非退化且精细分层** |

**关键洞察**：最直觉的修法（阈值加权 W1）无效，必须"方向性可信度 + 命题反向反驳误解（对称边）"双条件。这是 594 异族调研的核心发现。人审全量后，W2 从"二元对立"进化为"精细分层"。

### 3.5 收敛过程

- 第 1 轮：命题 IN（无攻击者击败它们），35 个 approve MIS IN（同可信度不击败），7 个 modify MIS OUT（被命题击败）
- 第 2 轮：无变化（不动点）
- 第 3 轮：确认不动点 ⇒ 收敛

实际 3 轮收敛（含一轮确认），计算耗时 <0.5ms（P 类，朴素最小不动点已足够）。

## 六、论证层的瓶颈与进展

### 6.1 人审全量完成（里程碑，2026-09-20）

388 条候选攻击边人审全量完成（354 approve + 34 modify + 0 reject），准确率抽样 100%。这是论证层从"概念可用"到"数据完整"的里程碑——W2 求解的结果不再是"机器预测"，而是"经过人审验证的论证"。

**新瓶颈：OUT 的 7 个 MIS 复核**。7 个 modify MIS 被判决为 OUT，需要人工复核是否改判 IN（详见 data/out_mis_review_checklist_20260920.md，预估 ~39 分钟）。

### 6.2 命题活性锚 0/50（知识债）

50 条 observation 命题全缺活性锚。活性锚 = 特有符号 + 量化证伪，是 observation 命题"可证伪"的硬保证。没有活性锚，observation 命题只是"声明"，不是"可验证的观察"。

**优化路径**：批量补活性锚（需人审裁决，因为活性锚的设计需要领域知识）。

### 6.3 verified_by_oracle 0/83（信任根缺口）

83 张证据卡 verified_by_oracle 填了 0 张。这是"独立验证"的缺口——没有 oracle 验证，证据卡的 verified 只是"自签"，不是"独立验证"。

**优化路径**：异族 oracle 验证（需外部独立验证者，单用户阶段结构性上限）。

### 6.4 无 high 可信度节点（结构性缺口）

当前所有节点可信度最高为 medium（命题 + approve 的 MIS），没有 high 可信度节点。这意味着：
- OUT 的 7 个 MIS 无法被任何节点辩护（需要 high 可信度节点攻击命题，才能让命题变成 OUT）
- 论证层缺少"最高可信度"的锚点

**优化路径**：引入 high 可信度（如经过异族独立验证的命题、经过编译可复现验证的 observation 命题），为论证层提供"最高可信度锚点"。

## 七、设计意图分析

### 1. W2 求解是"论证层从概念到可用"的关键
W2 加权 AF 求解（人审前 IN79/OUT42，人审后 IN114/OUT7）证明了论证框架在本仓数据上是可用的——不是退化的全接受或全不确定，而是语义正确的判决。人审全量后，W2 从"二元对立"进化为"精细分层"，这是论证层的质变。

### 2. 候选攻击边自动生成是"零 Oracle 风险"的设计
388 条候选攻击边由 MIS related_atoms × 卡面命题自动生成，零 Oracle 风险——不依赖 LLM 标注，不依赖人审预标注，纯规则生成。这是"生成者不能兼任判断者"第一原则的体现——攻击边的生成是规则驱动的，不是 LLM 驱动的。

### 3. 人审从"边级"到"MIS 级"是"工作量降 4.6 倍"的优化
595 异族调研发现，388 边的"工作量"是假象。把人审从"边级确认"改为"MIS 级目标映射"，工作量从 1.89 小时降到 24.5 分钟。这是"人审效率工具链"的核心设计——不是减少人审，而是让人审更高效。

### 4. 人审全量完成是"论证层数据完整"的里程碑
388 条边全部人审，W2 判决从"机器预测"变成"经过验证的论证"。人审全量后，论证层有了完整的数据支撑，为人审反馈闭环、辩护链推理、论证漏洞检测等智能功能奠定了基础。

### 5. 命题闭包是"论证密度"的可计算度量
命题闭包（avg 6.076/max 8/min 4）是"论证密度"的可计算度量——闭包越大，命题的论证链越长。这是"度量诚实化"的体现——不满足于"论证很丰富"，而是量化"论证密度是多少"。

### 6. 四大瓶颈显式登记是"不掩盖问题"的纪律
OUT 的 7 个 MIS 复核、活性锚 0/50、verified_by_oracle 0/83、无 high 可信度节点，四大瓶颈显式登记，而不是"修个规则假装堵住"。这是"度量诚实化"的体现——承认存在已知缺口，并说明为什么暂时不修复（需人审/需外部验证者/需架构决策）。
