## 八、设计意图分析

### 1. 硬阻断只由机器规则承担
40 条 block 全部在 programmatic 象限，人审/混合/LLM 规则只给 advice。这是"生成者不能兼任判断者"第一原则的体现——机器可以硬阻断客观事实，但不能替人做主观判断。

### 2. 3 条 machine-untriggerable 规则的结构性位置
HUMAN-GOLDEN-REVIEW（human）/ HYBRID-TEACHING-DEPTH（hybrid）/ LLM-SUPERIORITY-QUALITY（llm）各占一个非 programmatic 象限，且全部是 advice 级别。它们的 check is None，机器原理上无从触发——这是设计上的"显式留白"，不是遗漏。

### 3. warn 观察期规则的升级路径
16 条 warn 中，多条标注了"观察期"（OBSERVATION-LIVENESS / S1-GIT-AUTHOR-BINDING / CARD-PATH-NOT-CANONICAL）。这些规则从 warn 升级到 block 需要人审裁决，是"度量诚实化"的体现——不急于硬阻断，先观察误报率。

### 4. 证据卡层面规则最密集
23 条 evidence 规则（15 block + 7 warn + 1 advice），是整个 gate 最密集的层面。这反映了项目的核心信任假设——"证据卡是验证的基石"，所以对证据卡的约束最严格。

### 5. pedagogy 规则全部是 advice
5 条 pedagogy 规则（误解清单/动机先行/预测后揭示/苏格拉底/教学深度）全部是 advice 级别。这是设计上的克制——教学法是主观判断，机器只能建议，不能阻断。
