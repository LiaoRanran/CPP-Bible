## 1 · 项目定位

**阙疑（QueYi）** — 出自《论语》"多闻阙疑，慎言其余"。
拿不准的宁可标"存疑"也不硬说，与系统第一原则"拒绝零幻觉的虚假宣称、只给统计上界"对齐。

- **不是**：另一本 C++ 教材
- **是**：机器可核验、错误率有上界、可换验证者的严格知识生产系统
- **核心资产**：元系统（验证方法论），不是 C++ 内容本身
- **当前阶段**：内核搓成熟（v2.0-v2.5），人审全量完成，即将进入智能探索期

## 6 · 风险与瓶颈

### 结构性上限（无法通过工程解决）
1. **单用户身份认证**：git 作者可自设，无第三方时间戳，L2+ SLSA 不可达
2. **真实缺陷率分母**：原理不可知，只能给统计上界
3. **单人四眼替代**：人审质量控制结构性上限 ~8/10（已从 6 提升，因为有了 automation bias 检测+陷阱题）
4. **内容教学质量**：不可机器度量，编译通过≠讲得好

### 工程瓶颈（可通过建设解决）
1. **oracle 验证 0/83**：证据卡全部缺 verified_by_oracle
2. **活性锚 0/50**：observation 命题全缺 liveness
3. **slow 性能**：test_task_queue_stateful 20.0s（609 B1 已从 72.6s 优化，省 72.5%）
4. **本地未 push**：320+ commit 未 push，GitHub 上不可见
5. **推翻通道 0 事件**：data/overturned_events.jsonl 仍为空，首次真实推翻需人触发

### 已规避的风险
1. **585 红队三攻击**：全封堵（Merkle+governance+git 作者绑定），12 回归锁
2. **覆盖率伪造**：行为级 covered（581），取代文本 grep
3. **等价变异体误判**：M6 八条逃逸全定性为等价体（583），不是门禁洞
4. **尺子变更史**：诚实声明 v1→v5 是口径修正，不宣称"逃逸率在降"（582/592）
5. **人审自动化偏差**：automation bias 检测+陷阱题+review_seconds+reason_len（609 A2）
6. **人审反馈自动链**：闭环到"建议"为止，apply 只标已确认，不动 attack_edge_generator.py（609 A4）
