## 五、发布风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 外部评审发现判决错误 | 信任危机 | oracle 验证 + 人审全量 + 逃逸率 1/1406 |
| 单用户信任根无法闭环 | "令人信服"上限 | 异族独立验证 + OpenTimestamps + 诚实声明上限 |
| 书籍内容平庸 | 对外价值有限 | 知识资产层深化 + 定位"自用工具书" |
| ~320 commit 含敏感信息 | 安全风险 | push 前 git log 审查 + 密钥扫描 |
| pre-push 门禁阻止 push | 无法发布 | --no-verify（需人工确认）或修复门禁 |
| 外部贡献者不理解架构 | 贡献困难 | README + 架构文档 + 贡献指南 |

## 六、结论

阙疑项目对外发布需要完成 **P0（5 项）+ P1（5 项）+ P2（5 项）** 共 15 项准备工作。

**最关键的 3 项 P0**：
1. **测试套件全绿**（610-611）——fast/slow 全绿是发布前提
2. **~320 commit push**（人工决策）——外部可见性的前提
3. **README 重写**（615-620）——外部读者 30 秒理解项目

**最关键的 3 项 P1**：
1. **oracle 验证 0/83 → 50/83**（612-620）——"令人信服"的关键
2. **活性锚补全 0/50 → 50/50**（611-612）——论证层完整性
3. **书籍内容深化**（615-625）——知识资产层增长空间最大

**预计发布时间**：v3.5 对外发布准备（615-620），v4.0 对外发布（620-625）。
