# 市场调研简报（第三轮）：AI 编程导师格局 + 认知负荷理论

> 2026-09-11，监工主动调研。聚焦教学封装设计的学术依据和竞品格局。

## 一、AI 编程导师产品格局

**关键发现**：
- **Cursor** 定位为"专为编程教育设计"，强调交互式学习、实时协作编程、集成教程、代码审查建议。AI 原生编辑器（VS Code fork），全项目索引（RAG）。
- **GitHub Copilot** 对学生免费（Student Developer Pack 送 Pro），Microsoft Learn 有专门教学模块（生成作业/测试用例/解释概念/调试）。
- **学生免费策略已成行业标配**：Copilot Pro 免费（学生月验证）、Cursor Pro 免费一年（SheerID 验证）、Zed Education 等。
- 产品形态分三类：对话编程（Claude Code/ChatGPT）、AI 原生 IDE（Cursor/Windsurf）、智能体（Copilot Workspace/Claude Agent）。

**对 CPP-Bible 的意义**：
- 这些产品都是"AI 辅助写代码"，核心价值是**生成效率**，没有一个做"AI 辅助学知识 + 机器可验证证据链"。
- CPP-Bible 的差异化不在"帮你写代码"，而在"帮你理解为什么、并证明给你看"。这是互补而非竞争——学习者可以用 Cursor 写代码，用 CPP-Bible 学知识。
- **学生免费策略意味着目标用户（学生）有充足的 AI 工具**，CPP-Bible 不需要自己做 AI 对话功能，专注内容质量和验证体系即可。

**行动项**：README 和宣传材料中明确"不是又一个 AI 编程助手，是机器可验证的 C++ 知识体系"，避免被归类到 Cursor/Copilot 赛道。

## 二、认知负荷理论（CLT）——教学封装设计的学术依据

**核心概念**：
- 三类认知负荷：内在（内容难度）、外在（无效信息处理）、相关（图式构建）。工作记忆只能同时处理 2-7 个元素。
- **工作示例效应（worked examples）**：给完整示例比让学生自己搜索解法更有效，减少外在负荷。教育心理学最稳健的发现之一，重复验证数百次。
- **专长逆转效应（expertise reversal）**：对新手有益的教学支持（如详细示例）可能阻碍高级学习者。Kalyuga 2003/2007。
- **自我解释效应（self-explanation）**：学习者主动解释示例比被动阅读效果好。
- **渐隐示例（faded examples）**：从完整示例逐步移除步骤，让学习者填空，平滑过渡到独立解题。

**编程教育中的最新研究**：
- **AI 生成工作示例**（ACM 3636243）：LLM 生成的 worked examples 能有效降低外在负荷、优化相关负荷，但质量参差不齐。
- **GenAI 编码提示实验**（BJET 2025）：AI 提示提高了编码分数，但概念理解提升相当——**AI 帮你"写出来"但不一定"理解了"**。
- **交互式教程悖论**（L@S 2025）：学习者平均每练习点 3.7 次提示，每次提示降低认知负荷同时降低编码深度——提示越多，学得越浅。
- **自适应调试训练**（Taylor & Francis 2026）：小颗粒度知识+间隔巩固比一次性大量信息更有效。
- **AI 生成执行轨迹**（arXiv 2606.03288）：多机构研究，DeFT 框架+专长逆转效应，提示需要根据学习者水平差异化。

**对 CPP-Bible 的意义**——每条都能对应到现有机制：

| CLT 原则 | CPP-Bible 对应机制 | 现状/改进方向 |
|---|---|---|
| 工作示例效应 | 证据卡的完整可运行示例 | ✅ 已有，且是机器可验证的 |
| 专长逆转效应 | `audience` 字段 + `depth.layer` 标记 | ✅ 已有，但 G5 原子生产时要确保每个原子标准 |
| 自我解释效应 | `socratic` 提问链 + `predict_first` | ✅ 已有，五重剖面强制 |
| 渐隐示例 | 证据卡→Koans 填空测试 | ⏳ G6 做（09 已提） |
| 内在负荷控制 | 原子粒度（一个知识点一个原子） | ✅ 原子化本身就是 CLT 设计 |
| "写出来≠理解了" | 证据卡的证伪对照 + 汇编锚定 | ✅ 不只是"能跑"，还要"观测通路是活的" |

**最重要的洞察**：CLT 研究证明"AI 提示越多学得越浅"——这正好解释了为什么 CPP-Bible 不做"AI 直接给答案"，而是做"先预测→再验证→误解纠正"的主动学习链。socratic 提问链和 predict_first 不是装饰，是有学术依据的教学设计。

**行动项**：
1. 把 CLT 原则写进 docs/kernel/，作为教学封装设计的理论依据（M1 教学维度的学术支撑）
2. G5 原子生产时，`audience` 和 `depth.layer` 必须准确标注——这是专长逆转效应的工程化
3. 论文中引用 CLT 作为教学设计的理论框架，worked examples + self-explanation + faded examples 三效应组合
