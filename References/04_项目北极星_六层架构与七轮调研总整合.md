## 0. 一句话定位

**CPP-Bible 不是一本 C++ 书，是一个从 "事实正确" 到 "认知重构" 到 "远迁移能力" 的可验证学习系统。**

三支柱（护城河，与 "又一本 C++ 教程" 的分界线）：



| 支柱          | 含义                                      | 与既有教材的差别                                             |
| ----------- | --------------------------------------- | ---------------------------------------------------- |
| 可验证的 Meyers | 一条断言 + 边界 + 反例，且每条机制断言能被机器复算            | Meyers 靠作者权威；我们靠编译 / 运行 / 汇编 /sanitizer 四校验 + 工件哈希同代 |
| 结构化误解库      | 误解是字段不是散文，分层 surface/deep，可聚合 / 检索 / 回归 | 散文段落无法统计重灾区、无法做选择题 distractor                        |
| 自适应学习路径     | 原子 DAG + 掌握度门，路径 = 图遍历                  | 固定章节顺序 → 按读者掌握集合求拓扑序，确定 / 可测 / 可解释                   |

设计哲学（七轮调研收敛，贯穿六层）：



1. **内容与引擎分离**：原子是内容，DAG/BKT/ 路径是引擎；LLM 管教学表达，不管结构终判。

2. **机器管可复现，人管语义**：证据 / 格式 / 依赖机器卡死；洞见 / 叙事 / 5 分授予人终审。

3. **阈值概念重点投入**：知识点不平等，20-30 个阈值概念值得 80% 的交互设计投入。

4. **生产性失败先于教学**：先让读者撞墙再给答案，顺序比内容更重要。

5. **近迁移靠原子，远迁移靠 Pattern 与综合案例**。

6. **掌握才放行**：掌握概率 ≥0.95 才进下一个，不是 "看完了" 就算学过。

7. **规则治理而非投票治理**：质量靠规则体系 + 证据，不靠多数人同意（同 Wikipedia rule of law）。

### 2.3 三种已验证黄金模板（G4 成果，5 分人审授予）



* **A 移动语义**（MEM/mechanism）：红队抓到零观测伪证据（-O2 消除搬运，须 argc 派生 + volatile 读回证明观测通路是活的）。

* **B 灰区分界**（UB/contrast）：f (i++,i++) C++11/14=UB、C++17 起 = unspecified（P0145R3，indeterminately sequenced）；CI 实测 GCC 右→左、Clang 左→右，顺序相反。

* **C auto\_ptr 演化**（HIST/evolution）：is\_copy\_constructible\<auto\_ptr>=false；libstdc++ 用 backward/auto\_ptr.h 在 C++23 仍可编译 = "标准移除 ≠ 实现删除"。

## 3. L1 质量治理层

### 3.1 已建成机制（G1-G4）



| 机制               | 作用                                                     | 关键纪律                                  |
| ---------------- | ------------------------------------------------------ | ------------------------------------- |
| gate\_engine     | 25 条规则，四象限（fact/programmatic/advice/ 非程序化登记）三 severity | block 退出 1；advice 永不阻断；LLM 语义判项只登记不终判 |
| evidence\_replay | 干净环境重算：编译退出码 / 输出逐字 / 工件 sha256/sanitizer              | 工件必须与断言同代；裸 g++ 钉死完整工具链路径；异构环境快照还原    |
| S1 三权分立          | Agent 写不出合法 verified 签收                                | verified ⟹ verified\_by: human:\*     |
| S2 声明 - 证据绑定     | verified 只能绑 verdict=confirm 的卡                        | 每次门禁干净环境重跑                            |
| S3 伪证据检测         | 硬编码期望 = 作弊级；恒真 / 缩样本 / 工件不同代 block                     | "证明某事没发生" 必须同时证明观测通路活着                |
| S4 黄金非回归锁        | 六指标机器复算，恶化即红                                           | 改口径须 --accept "理由" 显式留痕               |
| S5 带息豁免          | 豁免票 owner 必须 human，90 天上限，负债率 > 15% 停线                 | 无永久豁免                                 |
| S6 毒样例 + 黑匣子     | poison\_drill 每次 quality 必跑（结构性自检，无静默全绿）               | 独立沙箱 finally 还原                       |

### 3.2 G5 要补的规则（来自调研）



* **对比案例强制**：任何原子缺 contrasting\_cases 即 block（依据 §6.2 Schwartz 2011）。

* **阈值概念三件套**：is\_threshold=true 必须同时有 productive\_failure + ≥2 contrasting\_cases + 突破前典型错误。

* **Writer/RedTeamer 异源**：写作与红队不得用同一模型（依据 §6.1，18 模型评分哲学存在系统偏差）。

* **题目三关**：出题 Agent → 学生 Agent 试做 → 人审，方可入题库（PyTaskSyn 模式）。

* **规则自生长流水线**：新缺陷 → 判断可否形式化 → 规则草案 + 毒样例（正例触发 / 反例不触发）→ 人审 → 注册。

### 3.3 永久边界（已写入 M2，不得违反）



* 编译器矩阵上限：**GCC + Clang 双编译器实测 + MSVC 以标准条文代替**，禁止写 "三编译器全实测"。

* UB 类证据卡必须在 Linux/WSL 侧过一遍 sanitizer（Windows MinGW 无 libasan 会 skip）。

* 计数 / 计时实验必须 -O0 与 -O2 双跑，计数器必须 volatile；汇编找不到调用点却 "证实" 论断 = 伪证据。

## 4. L2 知识结构层（G5 建）

### 4.1 节点与边

节点：Atom / Pattern / Misconception / Chapter / Threshold (特殊 Atom)。



| 边类型               | 含义      | 强度 / 来源                                           |
| ----------------- | ------- | ------------------------------------------------- |
| prerequisite      | 前置      | hard (必须)/soft (建议)/recommended (推荐)，Open Mastery |
| containment       | 大主题包含子点 | ACM KG                                            |
| association       | 弱相关，供推荐 | ACM KG                                            |
| contrasts         | 对比      | G4 样板                                             |
| evolved\_to       | 演化      | G4 样板                                             |
| misconceived\_as  | 误解关联    | 第三轮                                               |
| part\_of\_pattern | 原子属于某模式 | Soloway plans                                     |

规模估算：\~1300 原子 × 平均 2.5 边 ≈ 3250 边（参照 ACM 研究 127 节点 / 298 边密度）。

### 4.2 Pattern 模式层（Soloway 理论落地）

专家与新手工作记忆都只有 3-4 chunk，差别在专家 chunk 是模式级。Pattern = 刻板动作序列（plan）+ 识别信标（beacon）：



```
\# patterns/PATTERN-MEM-RAII.md

beacons:                          # 看到这些特征就应认出该模式

&#x20; - "构造函数获取资源、析构函数释放"

&#x20; - "局部对象管理堆/文件/锁，无手动 free"

composed\_of: \[ATOM-..., ATOM-...]

block\_model\_zones: \[执行×代码块, 功能×整体]   # Block Model 12 区域，标注训练了哪些
```

练习题从 "回忆单个原子" 升级到 "识别模式"（给一段代码问用了哪个 Pattern），训练 chunk 变大。

### 4.3 阈值概念（Threshold Concepts）

一旦理解即重构整个域认知，突破前经历 troublesome knowledge。C++ 候选清单：RAII、值类别 (lvalue/xvalue)、模板实例化模型、严格别名与对象模型、所有权语义、异常安全保证。

要求：标 is\_threshold，配更重的生产性失败 + 更多对比案例 + 可探索解释（L5 优先做这 20-30 个）。

## 5. L3 / L4 / L5（G5 后）

### 5.1 L3 学习路径：引擎只回答 "下一步学什么"

抄 Open Mastery 哲学：DAG + 引擎管结构，LLM 管教学，证明掌握否则不放行。



```
PKG 个人掌握态（每原子 BKT 概率/薄弱误解/认知负荷预算）

&#x20;       \+  EduKG（L2 全局图谱，三种强度前置边）

&#x20;       ▼

路径引擎：找 ZPD（hard 全过、soft ≥80%）→ 优先补薄弱误解关联原子

&#x20;       → 阈值概念前检查全部 hard → 认知负荷预算（每次新原子≤2 medium）

&#x20;       → RPKT 递归补"unknown unknowns"前置 → BKT ≥0.95 放行
```



* **BKT 四参数**：P (L0) 初始掌握 / P (T) 学习转移 / P (G) 猜对 / P (S) 粗心错；每次答题贝叶斯更新，≥0.95 放行。DKT (LSTM) 为远期升级。

* **RPKT**：学习者说 "教我移动语义" 但不知自己缺值类别，递归追溯前置闭包补漏。

* 算法参考实现：PyEdmine（知识追踪 + 认知诊断 + 习题 / 路径推荐合集），不从零写。

### 5.2 L4 练习评估：四套生产与编排规则

**(1) 每域一张概念清单（Domain Concept Inventory，Delphi 六步法）**



1. Delphi 多轮匿名专家共识，列 "既重要又难" 概念（G5 前可让：用户 + 三本书 + eel.is 标准 + 执行 Agent 独立列，取交集定优先级）；

2. 从作业 / 访谈提炼真实误解；

3. 出选择题，**每个错误选项 (distractor) 精确映射一个 MIS-ID**；

4. 学生 think-aloud 验证选项理由符合设计；

5. 信度 Cronbach's α ≥0.70；

6. 大样本 + IRT 校准难度 / 区分度。

   价值：做完不只知道对错，还知道中了哪些误解。

**(2) 每原子 3 题 Bloom 配比**：Understand (代码追踪 / 输出预测) + Analyze (找 bug / 识别 UB / 对比实现) + Evaluate (方案选择)。每 Pattern 加 1 道远迁移综合题（跨域真实问题，不指定用哪些原子 + 显式类比标注）。

**(3) 合意困难编排（Bjork）**：



* 交错 (interleaved)：不按原子分块连做，混合多原子，逼读者先判题型（数学 / 类别学习元分析证据最强）；

* 间歇反馈：先提交预测再揭示，不即时给答案；

* 变化 (variation)：同知识点换类型 / 优化级别 / 上下文，防虚假熟练；

* 测试即学习：每原子以测试结束而非 "读完" 结束。

**(4) 生产性失败（Kapur，仅阈值概念强制）**：先给超出当前能力的问题让读者尝试（大概率错），再正式教学 —— 概念理解与迁移显著优于先教后练；关键在 generation 而非失败本身，最有效条件是 contrasting cases。

### 5.3 L5 四种交付形态



| 形态           | 技术                                        | 受众    | 时机  |
| ------------ | ----------------------------------------- | ----- | --- |
| 静态书          | 现有 PDF/epub 流水线重构                         | 线性阅读者 | G7  |
| 在线自适应学习器     | L3+L4 引擎 + Web                            | 交互学习者 | G8  |
| 可探索解释        | 单文件 HTML，仅阈值概念 20-30 个，改参数看汇编 / 分配变化      | 深度理解者 | G7  |
| FSRS/Anki 导出 | 原子→卡，FSRS 三变量 (R/S/D)，比 SM-2 省 30-50% 复习量 | 复习巩固者 | G6+ |

原则（Bret Victor）：静态书传 what，交互层让读者自己发现 why；非阈值概念不做交互，投入产出比低。

### 5.4 反馈闭环（贯穿，依赖真实学习者数据）



* 记录**编辑 / 修改过程轨迹**而非只记最终答案（380 万轨迹研究：过程诊断价值显著更高，与本项目 "四步留痕 / 工件同代" 同源）。

* IRT 难度校准：专家会系统性低估 "自己认为基础" 的题，需每题数百条响应校准（LLM 判难度仅 37.75%，不可用，见 §6.1）。

* 错误聚类 → 新 MIS 候选（McMining 方法）；新缺陷 → 新 gate 规则；verified 率升高 → golden\_lock 阈值自适应收紧。

## 6. 七轮调研中 "定生死" 的硬证据

### 6.1 LLM 评估不可靠 —— 人审终审是被数据证明的必要设计（第七轮，最重要）



| 研究                         | 数据                                                            | 推论                                            |
| -------------------------- | ------------------------------------------------------------- | --------------------------------------------- |
| AutoCode, arXiv 2510.12803 | LLM vs 人类专家评题目质量相关系数 **0.07**、新颖性 **0.11**                    | LLM 不能终判质量 → Agent 最高自评 4、5 分仅人工              |
| arXiv 2511.18597           | GPT-4o 判 LeetCode 难度 **37.75%**（三选一近瞎猜）；显式特征 LightGBM **86%** | audience/cognitive\_load 不信 LLM，专家初标 + IRT 校准 |
| arXiv 2509.26483           | 18 个 LLM 分宽松 / 严格 / 平衡三型，同作业评分显著不同                            | Writer/RedTeamer 须异源                          |
| 第四轮 LLM 导师综述               | 65.5% 研究报过度依赖 / 表面学习；48% 响应含幻觉；GPT-4 迁移得分 22 vs 人类导师 74       | 教学叙事与语义必须人审                                   |

**结论：本项目 G3 就用 S1 三权分立 / Agent 上限 4 分把该问题制度化，早于 2025-2026 文献的实证共识。**

### 6.2 决定教学法的关键效应量



* **Testing Effect（检索练习）**：Tier S，d=0.50-0.80，500+ 研究；LLM 生成检索题实验 89% vs 73%。Forward Testing Effect：测试增强后续学习，应每 2-3 原子测一次。

* **生产性失败**（Kapur 2016）：先撞题再教学，概念理解 / 迁移显著更优；对比案例是最有效条件（Schwartz 2011, JEP）。

* **Worked-example + Expertise Reversal**：worked example 帮新手，却对专家有害；指导密度须随水平撤除（audience 字段的依据）。

* **交错练习**（Brunmair & Richter 2019 元分析）：数学 / 类别学习最强，训练 "选方法" 而非仅 "用方法"。

* **远迁移双条件**（Gick & Holyoak 1983）：多变练习上下文 + 显式类比训练；"形式训练说" 已证伪（学编程不自动提升一般思维，元分析非编码迁移 d=0.47 但区间 -0.02\~0.73，须显式教迁移）。

* **认知负荷**：工作记忆 3-4 chunk；专家优势在 chunk 更大（模式级、按深层结构分类），不在容量。

### 6.3 工程与治理参照



* **FSRS**：Retrievability/Stability/Difficulty 三变量，相同保留率比 SM-2 少 30-50% 复习，需 400-1000 条记录个性化。

* **GraphRAG 教育标准架构**：EduKG 全局图谱 + PKG 个人图谱双图谱；mastery-driven retrieval（掌握 < 0.4 补前置）；前置 agent + 相似度 agent。
