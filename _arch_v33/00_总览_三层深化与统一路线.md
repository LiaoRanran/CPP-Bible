## 1. 一句话结论

三层分别调研 2024–2026 前沿后，结论与 v31 同源但更具体：**阙疑的三层架构不需要换范式，需要的是把每层的"土法单点"升级为 2025–2026 已被工业界兑现的标准结构**——

- **头部层**：deep research 已产品化为"规划→问题展开→取证→带引用报告"四阶段固定管线；claim 核查已模块化到 4B 小模型可打 70B；标准源已全面 git/HTML 化（无官方 API 但不再需要）；编译器测试的 LLM 用法已收敛为"离线学习、在线零模型"；证据时效的全部信号源（WG14/WG21 issue log、编译器状态表、C2Y UB 移除清单）都在公开订阅面上。
- **中间层**：2025 下半年起"历史事故→自动检查器"在 SOSP/TSE/ISSTA 线上集中兑现（单个工作 92 个潜伏 4.3 年的内核 bug、30+ CVE）；自进化闭环的稳定形态固定为"挑战者–规划者–求解器–**外部验证器**–批评器"五环，无外部验证器的自进化必然漂移；保形弃权已从单答案推进到成对判决与多级级联；嵌入式域 LLM 实测能力腰斩，语言适配层必须刻意做薄。
- **尾部层**：判决工业界在加"条件/粒度"两正交轴而非第五态；agent 安全给出工具门/shadow/熔断/预算四类阙疑尚无的保护器；RATS（RFC 9334）给了信任根三角色标准词汇；透明账本 2025 起换 tile/checkpoint 后端（CT static API、IETF Key Transparency、Rekor v2）；SLSA L4 把可复现列为最高级准入（best-effort）；813 行纯核心的正确"轻形式化"是 stateful 性质测试而非证明助手；C2PA 2.2 + in-toto + RATS 已凑齐"知识验证"借壳所需的全部标准件，**行业空白在知识侧，阙疑有生态位窗口**。

### Phase W2 · 尾部加固（4–8 周，信任资产，外部可感知）

8. **T4 账本 checkpoint/双证明端点**（最小 static-CT 集：签名 checkpoint + inclusion/consistency 两证明），周目击先 cron 在本地机器跑；这是外部独立性 L2 的最低工程档。

10. **T5 reproduce manifest** 以 648 十卡为模板（版本串+命令+输入/期望哈希），`replay_probe.py <EV-ID>` 单命令验收。
11. **T6 核心 stateful PBT**：813 行核心先建性质清单与序列模型骨架（不追求一步到位覆盖率）。

### Phase W3 · 中间进化（6–10 周，依赖 W1 数据积累）

12. **M1 候选规则挖掘器**：原料用 452 改判事件 + poison_drill 记录 + M1–M7 结果；阴性回测集=已通过卡×变异集（复用 PCK）；产出只进 643 rule_drafts 同构队列，MDL 上岗。
13. **M2/B8 shadow 同步建设**：新变异器、新规则、新模型一律先 shadow 一批（只记账），这是 647"保护器触发≈0"的直接解药——没有分母就没有保护器。
14. **M3 校准升级**：SCOPE-BPE 接 swap 双跑产出、分层 α 预算落表；补证重校准机器强制（与 H3 联动）。
15. **M7 人审接口修复**：封 647 A2 默认值洞（缺字段 fail-closed + 白名单 reason 枚举），队列优先级排序与三率看板。

### Phase W4+ · 条件触发，不提前投入

- H5 探针积木化扩量 / H6 ESBMC 常态化：当且仅当 W1 人工评测证明 seeker 召回质量不足、且反例需求集中在可界算小函数（648 风格探针）。

- M5 语言适配包（嵌入式 C）：真实新读者/新受众出现再做；LLM 嵌入式 55.6% pass@1 是期望管理锚点，不承诺自动化跨域。
- T2 B7–B10 全量上岗：shadow 分母积累完 + T4/T1 上线后再切执行模式。
- T3 闭包 RATS 化/T7 知识 manifest 导出：随 queyi-core 拆分批次执行（v31 V0 已登记）。
- 训域内小模型（v31 A7）：jsonl 资产成熟是唯二前置，本篇无新增。
- CVM 外部锚（T3 高工程档）：真实对抗模型/外部用户出现再评估，公开日志周锚先行。

## 5. 风险与反模式清单

1. **把 deep research 输出当证据**：前沿系统自主度天花板 L4，L5 不存在；agent 报告必须过与其他证据同构的分级流程（默认 L4/L5、把握度不升级不判）[S3]。
2. **自进化闭环无外部验证器**：挑战者–求解器–LLM 批评器自循环会课程漂移（SAGE 显式以 critic 双过滤防此弊）；阙疑的外部验证器只能是 L0（真机/规则/SMT）。
3. **规则挖掘规模幻觉**：39,931 补丁→645 条可复用规则（≈1.6% 提纯率）意味着无阴性回测/MDL 的自动上线规则会淹没系统；KNighter 的 30 CVE 全部伴随补丁验证与 FP 精炼 [S26][S30]。
4. **bounded 证明当 pass**：ESBMC 自己用 unwinding assertion 防的就是这个；"K 界内成功"只能换 unknown(bounded) [S23]。
5. **账本后端迁移破坏客户端**：Rekor v2 GA 但公共实例保留 v1 的官方理由是客户端行为破坏 [S49]——阙疑自建账本 API 形状首版即终版，存储后端可换。
6. **把可复现承诺成位级一致**：SLSA 自身只在 L4 best-effort 列位级可复现 [S50]；知识证据的目标是"任何人一条命令重放得同判"，manifest 忠实记录环境比 bit-identical 更诚实也更可达。
7. **嵌入式/跨语言外推**：前沿模型在嵌入式有原理图时仅 55.6% pass@1，跨语言效率系统性差异显著 [S37][S39]；语言无关核心必须先行，否则适配成本指数级。
8. **保护器只加不演练**：shadow 模式与毒化演练（v31 ImpossibleBench）必须配套——B1–B5 真实触发≈0 的根因大概率是从未有过 shadow 分母，不是保护器设计错。
9. **叙事贪天功**（延续 v31）：效率提升来自检索与起草，可信全部来自 L0 与尾部；三层深化不改变这一归属。
