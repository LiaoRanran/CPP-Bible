## 一、一页结论

**分布式验证是 v10/v11 反复判定的"单用户结构性缺口"的理论正解，也是本轮探针数据显示多样性最差的一层：仓内名义上的验证者不少，真实独立票极少——编译器几乎只有 GCC 家族（GCC 79 / Clang 1 / MSVC 0）、证据 kind 实际只用 schema 九种里的两种（run 41 / asm 15）、388 条人审全部出自同一个人。** PBFT 的数学结论是 `n ≥ 3f+1` 且节点失效要**独立**；本探针用实测的共因失败参数演示：当共因概率 c=0.3、单验证者被骗率 q=0.01 时，3 票多数接受坏命题的概率从理想独立的 0.03% 飙到 **30.0%**——多数表决在相关失败面前几乎不提供增益。

**范式跃迁潜力评级：理论最高、单用户可兑现性最低。** 真正值得做的不是"搭一个假 BFT"，而是为未来的多主体/多 agent 验证**预埋可交换的验证产物格式**（attestation 化的证据卡），即 v16 in-toto 路线的延续。

## 二、理论基础

- 拜占庭将军问题：口头消息下少于 `3m+1` 个将军无法容忍 m 个叛徒【已查证，Lamport, Shostak, Pease, ACM TOPLAS 4(3):382–401, 1982】。
- PBFT：异步网络中 3f+1 副本、三阶段（pre-prepare/prepare/commit）、视图切换，BFT 复制仅比非复制慢约 3%，把 BFT 从理论变实用【已查证，Castro & Liskov, OSDI 1999】。但 O(n²) 通信使其在 ~20 节点外不经济，且**安全性建立在失效独立 + 消息认证（签名/MAC）之上**——单用户无密钥环境第二条不成立（v10 已论）。
- 供应链侧的"分布式信任"替代形态：in-toto 用签名 attestation 记录每一步 inputs→outputs，SLSA 给成熟度分级，验证可由任意第三方独立重做【一方称：v15/v16 已检索 in-toto.io / slsa.dev 官方，本轮未重开，URL 附后】。

## 四、实现路径（现实分档）

1. **现在（单用户）：不做共识协议，做"可被第三方验证的产物"**（0.5–1 人月）。把每张证据卡的验证过程导出为**自描述 attestation**：输入夹具哈希、编译器版本与命令、退出码、stdout/stderr 哈希、判决规则集哈希。任何人/任何 agent 拿到 attestation + 源码能独立重跑。这是 in-toto link 的教育内容版，也是"未来多主体"的唯一前置条件——没有可交换的验证包，分布式协议没有消息可传。
2. **中期（多学习者/开源协作出现时）：引入第二、三独立票而非直接 BFT**。最便宜的真异质票是**跨编译器**（当前 Clang 1 / MSVC 0，扩展空间大）和**跨人**（第二个审阅者，哪怕偶发）。2 个真独立票 + 分歧人裁，比 3 个同源假票强（Knight-Leveson）。
3. **远期（有社区/有密钥）：才谈 BFT/签名/合谋抵抗**。PBFT 需要身份（密钥）与独立运维节点，二者在单用户离线仓均不存在，提前实现是纯仪式。

## 五、成本-收益

- 成本：档1 中等（数据已在卡里，主要是格式固化与导出器）；档2 边际成本在编译时间/他人时间；档3 在单用户期不可达。
- 收益：档1 把"可信"从"作者声称可复现"升级为"陌生人可一键复核"，这是"令人信服"的核心语义（v15 判断）；档2/3 才触及真正的独立性增益。
- 对用户实际需求（考研+嵌入式 Linux 单人）：分布式协议零直接价值；attestation 对求职/开源展示有间接价值（可携带的可信证据）。

## 七、反例与风险（≥2）

1. **假分布式比单验证更危险**：同机、同 Python、同作者、同 LLM 预标注漏斗下跑 3 个"验证者"，给出的是 c≈1 的 3 票（p04 表），却在外观上获得"多数同意"的权威感——这是用冗余购买虚假的信任，比诚实承认单票更糟。
2. **合谋与 Sybil**：无身份体系时，一个行为者可伪造任意数量验证者（多 agent 都由同一模型驱动时偏好相关，2024–26 LLM-judge 文献大量记录位置/自偏好/宽容偏差，见维度1/5）；PBFT 的安全证明依赖抗 Sybil 的认证通道。
3. **协议复杂度本身是攻击面**：三阶段、视图切换、超时/重传在异步网络引入新的分歧与活性问题（PBFT 后续 Aardvark 等文献指出"优化常见情形会让拜占庭情形极其脆弱"）；为不需要的共识付安全税。
4. **教育内容的"判决"不像双花那样可客观仲裁**：BFT 解决的是对同一可验证值达成一致；"这个教学结论对不对/讲得好不好"含价值判断，即使 3f+1 节点也可能一致地认可一个平庸结论（garbage in, consensus out）。

## 八、模型上限态（自判）

单用户结构上限**在 v10 已被正确判定，本轮不翻案**：无密钥、单机、单人不可能长出真分布式信任。本轮新增的判断是——**通往分布式的正确第一块多米诺骨牌不是协议，是证据的 attestation 化（让验证可被陌生人重跑）**；在那之前谈 BFT/合谋/TEE 都是悬空的。该方向的"质变"严格依赖外部条件（第二个人/第二个编译器家族/密钥基础设施）出现，无法靠本仓工程量变触发。
