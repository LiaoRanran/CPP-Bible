## 一、一页结论

**用真实规则/证据结构回答"LLM 能力提升 10 倍后阙疑的哪些能力增值、哪些贬值"：63 条规则中 15–16 条（约 24%）依赖真实执行，47–48 条（约 76%）是纯文本/结构判断；56 张证据卡中 41 张 run 类必须程序真跑出读数。模型越强，47 条文本规则趋近"生成即满足"、内容产能趋零成本，但"真跑过且工件这次产生"的 24% 执行底座相对增值。阙疑把资本压在验证层（执行+统计+信任根），方向上抗模型迭代。**

**但有一个现状比未来更重要：388 条人审 100% 已经过 LLM 预标注/镜像漏斗（p08 实测）——"LLM 接管初审"不是未来情景，是现在完成时。** 真正该问的不是"LLM 能不能做审查"，而是"在 LLM 已经做了初审的现实下，人的剩余不可替代判断是什么、台账是否如实记载了这一点"（答案见维度5：没有）。

另外，关于"涌现"本身，2023 NeurIPS 杰出论文证明多数所谓涌现能力是**非连续度量制造的视错觉**（29 个指标中 25 个换成连续指标后涌现消失）——这对阙疑的直接教益是：**不要为"模型突然会了"做架构赌博，连续可核验的能力刻度比拐点叙事可靠**。

**范式跃迁潜力评级：这不是"方向"，是"环境变量"。它改变所有方向的相对价值，但自身不构成阙疑要做的事。**

## 二、理论基础

- 涌现能力主张：Wei et al. 称大模型在某些任务上出现不可预测的sharp跃迁【一方称：arXiv:2206.07682，2022，本轮以反方一手为主，原文未重开】。
- 反方（更重要）：Schaeffer/Miranda/Koyejo 证明涌现是**度量选择**的产物——多选题全对/全错、exact string match 这类非连续指标对小模型严苛；换成连续/线性指标后性能平滑可预测，29 指标 25 个无涌现，并在视觉模型上用"错误指标"反向造出了视错觉【已查证，NeurIPS 2023 Outstanding Paper, arXiv:2304.15004】。
- Scaling laws：能力随计算/数据/参数呈幂律平滑变化【一方称：Kaplan et al. arXiv:2001.08361, 2020，未重开】。
- 奖励模型过优化（Goodhart 的 RL 定量版）：对 reward model 优化过度后真实质量先升后降，KL 惩罚控制背离【已查证，Gao, Schulman, Hilton, ICML 2023（arXiv:2210.10760），本轮经多篇 2025/2026 一手综述交叉确认标题/年份，正文未重开 → 标【一方称】对其数值细节】。

## 三、本仓探针证据（p08）

- 规则依赖真实执行（LLM 无法靠"更会说"满足）= 15（24%，p02 关键词表为 16，差异为 EV-MSCV-NO-VERIFY 的"MSVC"未被 p08 词表命中；**取区间 15–16/63**）；纯文本可判 = 47–48（76%）。
- quadrant 已显式交给 llm/hybrid 的规则 = 2（LLM-SUPERIORITY-QUALITY、HYBRID-TEACHING-DEPTH），纯 human = 1（HUMAN-GOLDEN-REVIEW）——系统早已不排斥 LLM 裁判，但把它关在特定象限。
- 56 证据卡 run 类 41：LLM 再强也改不了程序的实际 stdout。
- 388 人审 100% 经 LLM 预标注/镜像（与 p05 互证）。

**10 项核心能力 × LLM-10× 的方向（每项附本仓数字，详见 p08 输出）：**
- ↑增值：真编译 replay（41 run 卡）、poison 毒样例（124 载荷，防强模型伪造）、人审的价值/意图残余、claim 结构化（79 命题成为强制 schema）、C-P 诚实分母（1/1406）、信任根（9–12 锚文件）。
- →迁移/重定义：mutation 从文本层到语义层（7 算子）；BKT 学习者镜像从"模型"变"校准基准"（27 init/0 事件）。
- ↓贬值：gate 文本规则（47/63 趋近默认满足）、内容产能（写卡/写章）。

## 四、对三个核心问题的输入

1. **质变方向选择**：环境变化奖励"锚在现实而非文本"的能力。维度3（元验证，护执行底座）、维度5（重立真人测量）、D5（真人学习结果）全部属于"外部现实锚"类；维度2 的 VDD 只在文本层有红利（76%），且红利随模型变更强而变薄——这解释了为什么 VDD 不是质变。
2. **现在就该做的防御性动作**：把规则体系里"必须执行"的 24% 显式标记为不可委托给 LLM 的硬核心（architecture invariant），未来引入生成 agent 时这部分永远走独立 replay；把 76% 文本规则规划为可被约束解码吸收（与维度2路径一致）。
3. **学习者镜像的重新定位**：当 LLM 可直接当 tutor，BKT 不是用来"教"，而是用来**检测真人相对 AI 教学的实际掌握增益**——评估对象从人变成"人+AI 系统"，这与 NEJM 社论的信任校准分区一致。

## 五、成本-收益

- 本节几乎全为"不做什么"的判断，直接成本≈0；收益是防止在错误方向（文本规则再加码、赌涌现、为全自动人裁做架构）上投入。
- 唯一正投入是 24% 硬核心的显式保护与语义变异算子（与03/07 合并）。

## 六、反例与风险（≥2）

1. **Mirage 结论也可能被过度外推**：Schaeffer 证明的是"声称的涌现很多是度量伪影"，不是"能力没有非线性跃迁"；若因"涌现是幻觉"而完全不为强模型能力预留接口（如未来可靠的形式化级代码审查），是对称的错误。阙疑应保持规则可插拔（quadrant 字段已是这种预留）。
2. **执行底座自身依赖的工具链也在被 AI 改变**：编译器/sanitizer 未来可能内嵌 AI 诊断，"真执行"的解释层可能被污染（AI 生成的编译器警告/修复建议），届时"程序真跑过"与"结果被 AI 解读"之间还要再加一道边界。
3. **24/76 是当前规则文本的静态切分，语义边界会移动**：今天需要编译才能判的规则，未来可能由"带验证器的代码生成"在生成时保证（如经过形式验证的代码模板）；把 24% 教条化永久化会错失这部分迁移。
4. **能力评估的基准污染**：前沿模型可能在训练中见过阙疑同类模式（benchmark contamination 是 2025–26 公认问题），用当代 LLM 跑本仓内容得到的"高分"可能是记忆而非能力，需要时间戳隔离/新颖夹具（与 poison 思想一致）。

## 七、模型上限态（自判）

LLM 演进对阙疑不是风险也不是救世主，是**持续的相对价格变化**：文本侧验证越来越便宜、现实侧验证相对稀缺。最优策略是把投入不可逆地挪向现实锚（真执行、真人、真统计、真工件溯源），并拒绝两种对称错误：赌涌现（为模型突然全对而拆掉人/执行闸）和无视涌现（把 76% 文本规则继续当核心资产手工加码）。
