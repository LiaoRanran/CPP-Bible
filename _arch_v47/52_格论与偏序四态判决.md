# 方向 52：格论与偏序——把"四态判决"建构成一个格，而不是四分类

## 核心结论

1. **四态判决的合并运算必须是上确界（join, ⊔），而"⊔ 是 join-semilattice 运算"这件事直接给出阙疑最核心的卖点：判决可复算是定理，不是测试观察。** 因为 `⊔` 满足结合律、交换律、幂等律，67 条规则以**任意顺序、任意分批、任意重复**地 fold 到同一张卡上，结果唯一。这正是"不依赖内核的独立对账器"成立的数学前提——第三方可以并行地、分片地复算 452 条判决而不需要复现 `gate_engine.py`（3826 行）的任何执行顺序。**没有格结构，这句话只能靠"我们测过 N 次都一样"来支撑；有了格结构，它是 `sup_comm` + `sup_assoc` + `sup_idem` 三条公理的推论。**

2. **判决格必须显式包含一个幺元 ⊥，而"pass"在格上不是 bottom——这是当前设计里一个真实的结构性歧义。** 实测：67 条规则中 block 44 / warn 16 / advice 7（44+16+7 = 67 ✓），**没有任何规则输出 `pass`**。也就是说 `pass` 是"没有任何规则触发"的产物，它在代数上就是 fold 的起点 ⊥。只有当系统引入"证据不足、拒绝判决"（对应方向 51 的 Chow 拒判）这个第五态时，才需要一个真正的 ⊥，此时格从 4 元素链 C₄ 扩张为 5 元素链 C₅（高度 4）。**论文必须写清楚 `pass` 到底是"最轻微的判决"还是"没有判决"**——两者在格上是不同位置，混淆会让单调性定理失效。

3. **一个可检验的设计约束：判决格应保持为分配格（最好是一条链或链的乘积），否则会撞上 M₃/N₅ 定理并失去可分解性。** 最简单的两个非分配格是"钻石格" M₃（5 元素，三个两两不可比的中间元）与"五边形格" N₅；一个格是分配的当且仅当它不含 M₃ 或 N₅ 作为子格（M₃–N₅ 定理；Mizar 有形式化 `yellow11`，arXiv:2402.14931 给出证明捷径）。若阙疑为"判决"引入三个互不可比的中态（例如 advice / abstain / needs-human），判决格立刻变成 M₃，**Birkhoff 表示定理失效**（Isabelle AFP 中 Matthew Doty 2026-02-06 的形式化条目证明的是"任一有限**分配**格同构于其并不可约元的下集格"），损失矩阵也无法再分解为各维度贡献之和。**这是一条能写进论文的 theorem-driven design rule。**

## 精确数字与案例

### 一、判决格的构造与 Hasse 图

**基本定义（Stanford CS353 讲义的措辞）**："A semilattice is a partial order (X, ≤) in which every doubleton {x, y} has a least upper bound, denoted x ∨ y and called the join of x and y. Even though the relation is partial (i.e. not linear as an order), the operation ∨ is total (x ∨ y is well-defined for all x, y)。" ——**注意这句的要点**：序可以是偏的，但 join 运算必须是全函数。这正是"判决合并"所需要的。

**方案 A（当前四态，链 C₄）**：

```
序关系（自下而上，严重度递增）：
        block          ⊤   rank 3
          |
        warn               rank 2
          |
       advice              rank 1
          |
        pass           ⊥   rank 0        ← 同时也是 fold 幺元
```

Hasse 图就是一条竖线（4 个节点、3 条边）。代数性质：

- **链 ⇒ 全序 ⇒ 分配格 ⇒ 模格 ⇒ 完备格**（有限格自动完备）。
- 高度 h = 3（最长链含 3 条边）。
- `x ⊔ y = max(x, y)`（严重度取大），`x ⊓ y = min(x, y)`。
- 元素数 4，join-不可约元数 = 3（除 ⊥ 外每个元素都不可约）。
- **Birkhoff 检验**：C₄ 的并不可约元构成一个 3 元素链，其下集格恰有 4 个元素 → `C₄ ≅ O(J(C₄))`，表示定理在此处是"紧的"。

**方案 B（加入 abstain，链 C₅）**：

```
        block          ⊤   rank 4
          |
        warn               rank 3
          |
       advice              rank 2
          |
        pass               rank 1
          |
       ⊥ (未判决/证据不足)  rank 0        ← 真幺元
```

高度 4。此时 `pass` 从"幺元"变成"一个真实的正向判决"，语义清晰化，代价是多一层。

**方案 C（二维：严重度 × 置信度，链的乘积）**：

若判决 = (严重度 ∈ C₄) × (置信度 ∈ C₃)，得 `C₄ × C₃`，12 个元素，**高度 = 3 + 2 = 5**，元素数 = 4×3 = 12，仍是**分配格**（链的有限乘积是分配格）。这是"既想保留四态严重度、又想表达置信度"的标准解法，且不破坏分配性。

### 二、为什么合并必须是 ⊔：三条律给出"顺序无关"定理

设规则集 `R`，每条规则 `r` 输出 `v(r) ∈ V`（V = 判决格）。整体判决定义为

```
verdict(card) = ⊔_{r ∈ R, r 触发} v(r)          （空集时 = ⊥）
```

**定理（顺序无关性 / 可复算性）**：若 `⊔` 是 V 上的 join（即 (V, ⊑, ⊔, ⊥) 构成 join-semilattice with bottom），则对任意两个规则序列 `σ, τ`（同一规则集的任意排列），`foldl(⊔, ⊥, σ) = foldl(⊔, ⊥, τ)`。

证明只需三条公理：

| 公理 | 形式 | 提供的保证 |
|---|---|---|
| 交换律 `sup_comm` | `a ⊔ b = b ⊔ a` | 相邻两规则可交换 ⇒ 任意排列等价（冒泡论证） |
| 结合律 `sup_assoc` | `(a ⊔ b) ⊔ c = a ⊔ (b ⊔ c)` | 可以任意分批、任意加括号 ⇒ 对账器可并行分片 |
| 幂等律 `sup_idem` | `a ⊔ a = a` | 规则重复触发、账本重放、Merkle checkpoint 重算都不改变结果 |

**这就是"判决可复算 + 证据可追"的代数内核**：幂等律让重放安全，结合律让分片安全，交换律让顺序安全。**论文应把这三条写成 Proposition 1，并指出它是 452 条账本可被第三方复算的充分条件。**

**为什么 ⊔ 而非 ⊓ 或多数投票？** 三条理由：

1. **语义（存在量词）**：产品语义是"只要存在一条 block 规则触发就 block"，这正是 `⊔`（`∃` 的最小上界）。取 `⊓`（`∀`）会变成"所有规则都同意才 block"，与 block 44 条的设计意图相反。
2. **单调性**：只有 ⊔ 保证"证据增加 ⇒ 判决不下降"。若 `E ⊆ E'` 则 `⊔E ⊑ ⊔E'`。这条性质是可被对账器独立抽检的（见行动 3）。
3. **与损失矩阵相容**：方向 51 推出的门限规则关于 `p_sound` 单调下降时严重度单调上升，与 ⊔ 的单调性方向一致。

### 三、上确界/下确界的语义，以及"上下确界"给出的两个新问题

| 运算 | 符号 | 语义 | 在阙疑中的用途 |
|---|---|---|---|
| 上确界 `⊔`（join / sup / lub） | `a ∨ b` | 最严重的判决胜出 | **规则合并**（当前引擎应做的事） |
| 下确界 `⊓`（meet / inf / glb） | `a ∧ b` | 最宽松的判决胜出 | **多份证据的下界**：若两个独立证据源分别给出 warn 与 advice，则**保守下界**是 advice |
| 顶部 `⊤` | `block` | 最强判决 | 上界哨兵 |
| 底部 `⊥` | `pass`（方案 A） | 最弱判决 / 幺元 | fold 起点 |

**两个由格结构"免费"给出的新能力（都是论文素材）**：

- **多证据源的下界判决**：阙疑有 9 个保护器（protector）。若把每个保护器的输出视为判决格元素，则 `⊓` 给出"所有保护器都同意的最强结论"，`⊔` 给出"任一保护器主张的最强结论"。**同时报告 `⊓` 与 `⊔` 就得到一个区间 `[⊓, ⊔]`，它是对"判决不确定性"的一个无需概率假设的刻画**。这比报一个标量可信度更诚实，且与方向 59 的测度论互补（这里不需要概率空间）。
- **区间宽度作为可审计的量**：`⊓ ≠ ⊔` 的记录数可以从 452 条账本里直接数出来，作为"规则间分歧率"指标。这是一个目前没人报、但一查就有的数字。

### 四、单调性与不动点：规则之间有依赖时怎么办

Cousot & Cousot (POPL 1977) 的原文表述（逐字引自作者主页的 Summary）：

> "Abstract program properties are modeled by a **complete semilattice**, Birkhoff[61]. Elementary program constructs are locally interpreted by **order-preserving functions** which are used to associate a system of equations with a program. The program global properties are then defined as one of the **extreme fixpoints** of that system, Tarski[55]."
>
> "**consistent abstract interpretations form a lattice** (section 7)"
>
> "various classical algorithms such as Kildall[73], Wegbreit[75], compute program properties as **limits of finite Kleene[52]'s sequences**"

（题目：*Abstract interpretation: a unified lattice model for static analysis of programs by construction or approximation of fixpoints*，POPL 1977, Los Angeles, pp. 238–252。）

**Knaster–Tarski 定理**：设 L 是完备格、`f : L → L` 保序，则 f 的不动点集合本身也是完备格（因此存在最小与最大不动点）。其逆命题由 Anne C. Davis 证明：若每个保序 `f : L → L` 都有不动点，则 L 必为完备格。**这条逆定理对阙疑是一个诊断工具**：如果你设计的判决聚合在某个输入上"不收敛/无一致判决"，那说明判决集根本不是完备格（缺 ⊤ 或缺 ⊥ 或缺某些子集的 sup）。

**具体迭代上界（可写进论文的实现细节）**：

- 若 67 条规则各自输出 C₄ 元素、且规则之间**无依赖** → 只需一次 fold，67 次 `⊔`，无迭代。
- 若规则之间**有依赖**（规则 A 的结论作为规则 B 的输入）→ 状态空间是乘积格 `C₄^67`，元素数 `4^67`（约 1.4 × 10⁴⁰），**高度 = 67 × 3 = 201**。
- 在有限高度 h 的格上，从 ⊥ 出发的 Kleene 序列 `fⁿ(⊥)` 至多 `h + 1` 步到达最小不动点 → **C₄^67 上最多 202 步收敛**。这是"迭代式规则闭包"的硬上界，也是一个**有限的、可预算的代价**。

（若采用方案 C 的 `C₄ × C₃`，高度 5 → 最多 6 步。维度选择的代价差异一目了然。）

### 五、为什么格比"四分类"强：四个具体方面

**1. 分类丢失距离信息。** 四分类的混淆矩阵把"把 block 判成 advice"与"把 block 判成 pass"视为同等的两个错误。在链 C₄ 上定义秩距离 `Δ(d, d*) = |rank(d) − rank(d*)|`：

| 预测 \ 真值 | pass | advice | warn | block |
|---|---|---|---|---|
| **pass** | 0 | 1 | 2 | 3 |
| **advice** | 1 | 0 | 1 | 2 |
| **warn** | 2 | 1 | 0 | 1 |
| **block** | 3 | 2 | 1 | 0 |

加权误差 `Σ w(Δ)`（如 `w(Δ) = Δ` 或 `w(Δ) = Δ²`）是**序数分类（ordinal classification）**的标准做法（CRAN 的 `ordinal` 包提供累积链接模型 CLM）。**注意方向性不对称**：漏 block（真值 block、判 advice，Δ=1）与误 block（真值 advice、判 block，Δ=2）在对称距离下不同，但若业务上"误杀"更贵，应改用**非对称**的矩阵——这与方向 51 的损失矩阵是同一件事，只是这里用秩距离而非代价数表达。

**2. 分类没有代数结构，因此无法定义"合并"。** 这是最硬的一点：one-hot 的四个类别之间没有 ⊔，你只能诉诸"多数投票"（不满足幂等律，重放会改变结果！）或"取 argmax"（不满足交换律的确定性版本，浮点并列时不确定）。**只有格结构能给幂等律，而幂等律正是 append-only 账本可安全重放的前提。**

**3. 单调性可被第三方独立验证。** 性质 `E ⊆ E' ⇒ f(E) ⊑ f(E')` 是一个**一阶性质**，可以在 452 条账本上做抽检：随机采样若干 (卡, 证据子集) 对，检查加证据后判决是否只升不降。若发现反例，说明聚合函数不是 ⊔、或规则之间存在非单调的"否决/例外"逻辑。**这是一个免费的内部一致性审计，且不需要 ground truth。**

**4. 有现成的类比可引用。** Dorothy E. Denning, *A Lattice Model of Secure Information Flow*, CACM 19(5), May 1976, pp. 236–243（Purdue University）。原文摘要逐字：

> "The central component of the model is a **lattice structure derived from the security classes and justified by the semantics of information flow**. … It also leads to the construction of **automatic program certification mechanisms** for verifying the secure flow of information through a program."

**这个类比对阙疑几乎完美**：Denning 面对的是"如何判定一个程序是否会泄漏信息"，阙疑面对的是"如何判定一条知识断言是否成立"；两者都用**格**来组织判决等级，并把判定变成格上的单调计算。而且 Denning 自己在引言里引用了不可判定性结果：

> "Harrison et al. [12] have recently demonstrated that **in general it may be undecidable whether an access right to an object will 'leak'** to a process in a system whose access control mechanism is modeled by an access matrix"

——**这是方向 55 的完美引线**：格提供了可判定的子问题，但包围它的是不可判定性。阙疑的论文可以同时引用这两点，且它们来自同一篇文献。

### 六、能形式化什么、不能形式化什么、代价多大（本方向的工程评估）

| 项目 | 能否形式化 | 用什么系统 | 代价估计 |
|---|---|---|---|

| Birkhoff 表示定理在 C₄ 上的实例 | ✅ 已有现成形式化 | **Isabelle AFP: "Birkhoff's Representation Theorem For Finite Distributive Lattices"，Matthew Doty，2026-02-06** | **0**（直接引用） |
| M₃–N₅（非分配性判据） | ✅ 已有现成形式化 | **Mizar: "On the Characterization of Modular and Distributive Lattices"（JFM yellow11）**；另有 arXiv:2402.14931 的证明捷径 | **0**（直接引用） |

| 门限规则关于 `p` 的单调性（方向 51） | ⚠️ 半能 | 需要实数的线性算术；Lean 有 `linarith`，但需把损失矩阵常量化 | 中（100–300 行） |
| **损失矩阵的具体数值（100/60/30/50）** | ❌ **不能** | —— | **这些是经验量，不是数学命题**。可形式化的是"给定矩阵 ⇒ 门限"这一**映射**，不是矩阵本身 |
| **"证据"本身的语义**（什么算一条证据） | ❌ **不能** | —— | 这是模型论/可计算性问题，见方向 54、55 |
| **"知识断言成立"的真值** | ❌ **不能**（且不可判定） | —— | 见方向 55 |

**结论（可直接写进论文的判断）**：格论能给阙疑的是**"判决合并层的三个定理"（幂等/交换/单调）加上一条"分配性设计约束"**，总实现代价在 **1 人日以内**，且有两处可直接引用的现成形式化（Isabelle AFP 的 Birkhoff、Mizar 的 M₃–N₅）。格论**不能**给的是判决的正确性——它只保证"无论你怎么算都算到同一个东西"，不保证"那个东西是对的"。**把这两件事分开说清楚，恰恰是阙疑相对"又一个 LLM 代码评测"的差异点。**

## 盲区（诚实标注）

- **mathlib 的 `Finset.sup` 具体 API 名与既有定理名我没有核实。** 我确认了 `Mathlib.Order.Lattice` 中存在 `SemilatticeSup`（"A SemilatticeSup is a join-semilattice, that is, a partial order with a join (a.k.a. lub / least upper bound, sup / …)"）以及 `Mathlib.Order.CompleteLattice`（"A complete lattice is a bounded lattice which has suprema and infima for every subset"），但"顺序无关性由库直接给出"这一说法需要在真正写 Lean 时确认。**论文里不要写"`Finset.sup` 自动给出置换不变性"除非亲跑通。**
- **Denning 1976 的页码 236–243 是我从文件名 `p236-denning.pdf` 与 PDF 页数 8 推出的，未从 ACM 官方页面逐字核实。** DOI 是 10.1145/360051.360056，卷期 CACM 19(5), May 1976 可信度较高。
- **Cousot & Cousot 1977 的届次在来源内部自相矛盾**：页面正文标题写 "Sixth Annual ACM SIGPLAN-SIGACT Symposium"，而同一页面底部 BibTeX 写 "Fourth Annual"。我采用了 POPL 1977, Los Angeles, pp. 238–252（两处一致）。**引用时请核对 POPL'77 的正式届次。**
- **"67 条规则中没有任何规则输出 pass"是我的推断**，依据是 44(block) + 16(warn) + 7(advice) = 67 恰好穷尽。若存在第 68 条或存在显式 `pass` 规则，本方向第二节的论证需要修改。请核对 `gate_engine.py` 的实际规则表。
- **Kleene 迭代"最多 202 步"的上界假设了规则之间存在依赖且状态空间为 C₄^67。** 若实际是方案 C 或其它结构，数字不同。且该上界是**最坏情况的**（每次迭代只上升一级），实际通常远小——**不要在论文里把它当成典型代价**。
- **Isabelle AFP 的 Birkhoff 条目日期（2026-02-06）来自 PDF 首页署名块**，这是 AFP 的"最近更新/当前版本"日期，**不等于首次提交年份**。引用时应写成"Isabelle Archive of Formal Proofs, entry `Birkhoff_Finite_Distributive_Lattices`, author Matthew Doty"。
- **Mizar `yellow11` 我只看到了 PDF 首页摘要**（"pentagon lattice N5 and the diamond lattice M3 … characterization of modular and distributive"），未验证其内部定理编号与形式化完整度。
- **本方向完全未处理"证据"本身的偏序结构。** 判决格是清晰的，但"证据集 E"是否也构成格（例如证据的合取/析取对应 ⊓/⊔）我没有展开。若要做，需要方向 54（模型论）来定义证据的满足关系。
- **链的选择（pass ⊏ advice ⊏ warn ⊏ block）是业务假设，不是数学事实。** 若实际存在"warn 比 block 更不受欢迎"的场景（如误报疲劳），序关系就要改，全部门限与距离矩阵随之改变。
