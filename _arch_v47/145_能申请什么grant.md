# 方向145：能申请什么grant——学生身份下的资助地图、资格门槛与申请日历

## 一、先建立资助地图的阅读方法

学生谈grant最容易犯两个错误：要么以为资助只有奖学金一类，要么把面向机构/企业的大额基金当成自己可以申请的对象。判断一个grant是否值得投入申请时间，只需先回答四个问题：**谁能申请（个人还是组织、是否要求学生身份）、要求什么（开源协议、项目成熟度、是否需要机构背书）、给多少、窗口在哪**。本文按「国内—国际开源—会议—其他」四层梳理可核实的金额与门槛，最后给出阙疑的适配清单和2026—2027申请日历。

需要先说明一个现实约束：绝大多数国际开源资助不要求申请者有显赫背景，但默认两个前提——项目以OSI认可的协议完整开源，且有可核查的前期成果。阙疑的37实卡/67规则/9保护器/452账本/3826行内核恰好构成「可核查的前期成果」，这是一个零影响力双非本科生最有分量的申请筹码。

## 二、国内通道：大创与国家奖学金

**大学生创新创业训练计划（大创/国创计划）：与阙疑匹配度最高的第一选项。** 依据教育部2019年《国家级大学生创新创业训练计划管理办法》（教高函〔2019〕13号）：项目分创新训练、创业训练、创业实践三类，面向本科生个人或团队；经费标准明确为「创新训练项目和创业训练项目获得经费支持平均不低于2万元/项，创业实践项目平均不低于10万元/项」，高校按学科特点确定具体额度[1]。其经费机制为财政拨款加学校配套：早期文件确定中央财政按平均1万元/项拨款、高校按不低于1:1配套，合计约2万元[2]。选拔结构是校—省—国家三级，省级从校级项目中遴选不超过1/3的优秀项目推荐国家级[2]。阙疑作为创新训练项目完全对口：有明确研究问题（C++知识验证）、有系统成果、有可公开的中期检查证据。关键动作是找到愿意挂名的指导教师并在校内通知窗口（通常春季）前完成申报书。省级与校级项目门槛更低，即使国家级未中也应逐级申报。

**国家奖学金：金额已调整，注意时效。** 2007年办法确定的本专科生国奖标准为每人每年8000元[3]；但据财政部、教育部、人社部2024年《关于调整高等教育阶段和高中阶段国家奖助学金政策的通知》（财教〔2024〕181号），**自2024年起本专科生国家奖学金标准由8000元提高到10000元，名额由每年6万增加到12万**；国家励志奖学金由5000元提高到6000元[4]。因此严谨表述是「现行标准10000元，8000元为2024年前标准」。国奖评审以绩点为主、科研竞赛为辅，阙疑的论文/大创立项可作为科研加分项，但它本身不是研究经费，定位应是「品牌与科研副产品带来的奖励」而非资助来源。

## 三、国际开源资助：五个真实可申的项目

**GSoC（Google Summer of Code）：学生专属、金额按地区购买力分档。** 2026年官方标准：小项目750—1650美元、中项目1500—3300美元、大项目3000—6600美元；以中项目基准3000美元、大项目6000美元按PPP购买力调整；津贴分两期（中期评估45%、结项55%）[5]。**中国地区对应小/中/大约900/1800/3600美元**[6]。注意GSoC不是投自己的项目：学生要向入选的导师组织申请，为其项目完成一个夏天的开发。阙疑作者有两条路：以学生身份申请相关测试/工具链组织的席位（履历用阙疑成果，增强录取概率）；或反过来让阙疑未来作为导师组织参选（要求项目成熟度与两名以上导师，短期不现实）。申请窗口：组织3月公布、学生3—4月申请、夏季编码。

**NLnet/NGI Zero：对个人开放、与阙疑匹配度最高的国际资助。** 荷兰NLnet基金会运营的NGI Zero系列（欧盟委员会资金）是少数**明确对个人和任何类型组织开放**的grant：NGI Zero Core及Commons Fund的项目额度为5000—50000欧元，成果须以自由开源协议公开[7]。Commons Fund总盘子约2160万欧元，约每两个月开一轮新call；2026年4月公布的第九轮有57个项目入选，历史已资助超过1000个项目[7]。需要诚实标注的不确定性：官方文本表明个人可申请、面向全球，但实际评审高度偏好与「互联网基础设施、隐私、开放技术」直接相关的项目，且申请者需具备英文合同与发票/收款能力——中国大陆个人申请者的合同与税务实操案例较少，申请前应去信确认收款可行性，不能假设流程顺畅。阙疑的切口应是「可审计AI基础设施：知识判决账本作为开放的验证组件」。

**NumFOCUS Small Development Grants：小额但流程规范。** 面向其sponsored/affiliated项目，单笔上限约5000美元（2019年平均单笔3816美元）；2024年资助33项、合计约29万美元，项目累计已超100万美元；通常每年两轮[8][9]。门槛在于阙疑不是NumFOCUS旗下项目——直接申请不合资格，但可先申请affiliation，或作为思路参照。

**GitHub Accelerator：曝光价值大于金额。** 2023年首届为10周项目、每人2万美元资助、20个项目，全球超1000份申请；2024年改为每项目4万美元、只选10个、主题锁定开源AI，要求申请人在GitHub Sponsors支持地区、有真实用户增长[10]。中国大陆的Sponsors收款支持情况需要逐项核实，短期定位为「了解规则、积累条件」，不宜作为2027年前的现实指望。

**Sovereign Tech Fund（STF）：大额、门槛同样高。** 德国联邦经济部出资，公开案例研究确认每项目最低5万欧元、无固定上限、实际投资最高到100万欧元，按里程碑分期；面向全球申请者，但聚焦「被广泛使用却资金不足的开放数字底座技术」，六条评审标准中「普及度」与「跨行业重要性」排在最前[11]。阙疑当前体量达不到「关键基础设施」标准，属于三年以上的长期目标，而非本轮申请对象。

其他可登记在地图上的选项：PSF（Python软件基金会）小额grant典型500—5000美元、滚动受理但要求与Python生态相关；德国Prototype Fund约47500欧元/6个月但主要面向德国居民；Linux Foundation旗下资助多面向项目组织；GitHub Sponsors是日常赞助通道而非一次性grant。

## 四、会议travel grant：前提是论文被接收

**会议学生资助的共同前提是论文/作品被接收**，不能脱离投稿独立规划。以NeurIPS为例：其Financial Assistance面向学生及毕业两年内博士后作者，优先资助有论文在会者，形式历史上为注册费减免、酒店住宿或现金旅行补贴（2019年有作者记录获得注册豁免加1400美元旅行资助）[12]；申请窗口通常9—10月，与志愿者申请联动。各workshop也常自设注册报销（如NeurIPS 2025某workshop提供175/230美元注册费报销、10—15个名额）。对阙疑的含义很直接：travel grant是论文路线图（方向144）的下游动作——2027年若论文A获NeurIPS相关接收，立即在结果公布后数周内提交资助申请；未获接收则此通道不存在。各SE会议（ICSE/ASE/ISSTA）也多有student travel/volunteer计划，金额与形式逐年不同，需在论文投出时即把会议官网的资助页加入跟踪。

## 五、阙疑的适配清单与2026—2027申请日历

**适配结论分三档：**
- **高匹配、立即行动**：大创（校级秋季预热、国家级春季窗口，创新训练约2万元，需指导教师）；国奖（2024年起10000元，靠绩点＋成果）。
- **高匹配、需前期沟通**：NLnet Commons Fund（5000—50000欧元，个人可申请，先去信确认中国大陆个人收款与合同可行性，约双月一轮）；GSoC（以学生身份申请相关组织，中国区中项目约1800美元，3—4月窗口）。
- **条件性/长期**：会议travel grant（论文被接收后申请）；NumFOCUS（需先affiliate）；GitHub Accelerator（2024年4万美元、AI主题、地区支持待核实）；STF（最低5万欧元，体量未到，长期观察）。

**申请本身的工时与命中率必须计入决策。** 一份严肃的国际grant申请（技术叙述、里程碑拆解、预算表、成果公开承诺）通常需要三到五个完整工作日，且NLnet这类项目首轮未中可据反馈在下一轮再投，但每一轮都是完整重写而非原样复投；GSoC申请看似只有一份表格，真正的门槛是此前两三个月在目标组织社区留下的可见贡献。因此同时推进的grant不宜超过两个：大创与一个国际通道并行是合理上限，再多就会与论文双盲窗口和课程绩点正面冲突。对独立学生而言，「申请到什么」之外，「申请过程中形成的可公开项目文档」本身也是一份可复用资产。

**2026—2027申请日历：**
- **2026年10—11月**：联系指导教师，按校内通知准备大创申报书（以四态判决＋账本为研究内容、66.7%/43.8%为预实验证据）；完成GSoC目标组织清单并开始社区参与（GSoC评审极度看重申请前的贡献记录）。
- **2026年12月—2027年1月**：提交大创校级/省级材料（具体日期以学校教务处通知为准）；起草NLnet一页proposal并发信询问个人申请的收款路径。
- **2027年2—4月**：大创立项结果跟进；NLnet选择一轮call正式提交（双月窗口，注意投稿双盲纪律——若与论文评审期冲突，提交时点须让位于双盲，避免身份暴露）；3—4月提交GSoC申请。
- **2027年5—9月**：国奖按学校秋季评审节奏申报；若论文获接收，立即提交NeurIPS/对应会议financial assistance申请；GitHub Accelerator仅在规则与地区条件确认后考虑。
- **全年纪律**：所有申请材料数字口径与论文/README一致；任何grant都不改变「双盲优先」的排序；被拒则记录评审意见，下一轮带实质改进再申，不一稿多投grant。

对一个合肥、双非本科、嵌入式方向、零影响力起点的研究者，这份日历的现实目标是：2027年内拿到大创立项＋力争一次国际开源资助，并为会议travel做好触发准备——钱的数额在其次，「竞争性评审通过」本身就是申研与NeurIPS叙事中可验证的信用记录。

### 对阙疑的三条具体行动

1. **2026年11月底前**：确定指导教师并完成大创申报书初稿，以37实卡/452账本为已有基础、66.7%/43.8%为预实验数据，按校内窗口逐级申报校级、省级、国家级。
2. **2027年1月前**：向NLnet发信确认个人申请的合同与收款可行性，并在2027年4月或6月一轮call（与双盲评审不冲突的窗口）提交5000—50000欧元的正式申请。
3. **2027年论文结果公布后两周内**：若获接收立即提交NeurIPS/相关会议travel grant；同时在3—4月窗口以学生身份完成一次GSoC申请，用阙疑成果作为能力证明。

### 盲区

1. 大创与各国际grant的具体细则高度依赖学校和当年通知，文中金额为全国性文件标准，地方院校实际执行额度与报销科目可能缩水。
2. NLnet对中国大陆个人申请者的合同、税务与跨境收款实操缺乏公开成功案例，可行性信中若得不到明确答复，申请可能白做工。
3. GSoC近年竞争激烈且导师组织偏好有长期社区关系的申请人，零贡献记录临时申请的实际成功率很低。
4. GitHub Accelerator/Sponsors在中国大陆地区的支持状态本文未取得官方确认页，不能作为可依赖路径。
5. 多个grant与双盲投稿期可能重叠，grant申请材料一旦公开项目细节存在破盲风险，时序协调在实际执行中可能被迫放弃某一轮。
6. NumFOCUS affiliation与STF等通道的真实门槛仅由公开文档推断，独立小项目进入其评审视野的概率缺少历史数据。
