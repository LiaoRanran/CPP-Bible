# 方向 59：测度论与概率验证

## 核心结论

1. **测度论对阙疑的贡献只有一条，但这一条恰好击中了项目当前最严重的算术问题：43.8% 这个聚合检出率在测度论上是不定义的，因为它没有指定分层上的测度**。阙疑的外部 corpus 是 40 条、分三层，报告 A 54.2% / B 12.5% / C 0%。同一个"检出"事件在两个不同测度下给出两个完全不同的概率：按条目均匀测度（每层按其规模加权）与按层均匀测度（(54.2+12.5+0)/3 = **22.2%**）。**"43.8%"这个数字只在"层规模已知且条目加权"这一个前提下才有意义——而阙疑的三层规模没有随数字一起报出。** 这不是"待修的算术错误"，这是**测度未指定**。修法不是重算，而是在论文里显式写出 `P(检出) = Σ_i w_i · p_i` 并给出 `w_i` 与 `n_i`。

2. **Hoeffding 不等式给出"要多少样本才够"的硬答案，而阙疑现有样本量远远不够**：`N = ln(2/δ) / (2ε²)`（PRISM 手册逐字给出该式）。代入：ε=0.10、δ=0.05 → **N = 184.4 ≈ 185**；ε=0.05、δ=0.05 → **N = 737.8 ≈ 738**；ε=0.02、δ=0.01 → **N = 6,623**。阙疑的盲 holdout 是 **n=30**。用 Clopper-Pearson 精确区间（我手写实现并交叉验证过 6/6 的下界 = 0.025^(1/6) = 0.5407）算，**20/30 的 95% 置信区间是 [0.4719, 0.8271]，宽度 35.5 个百分点**；17/30 是 [0.3743, 0.7454]，宽度 37.1 个百分点。**结论：以 n=30 报告"66.7% 检出率"作为主结论在统计上是不可辩护的——审稿人只要算一次区间就会要求你降级为"探索性结果"。** 正确的做法是把 30 当作 pilot，用区间报告，并把"要达到 ±5% 精度需要 738 条"写进 limitations 与 future work。

3. **PRISM/Storm 对阙疑的正确用法不是"验证内核"，而是"验证评估协议"，而且这个转向是被测度论逼出来的**。阙疑的内核是**确定性**的（同一条知识卡、同一份证据 → 同一个判决），所以内核本身没有概率转移，写成 DTMC/MDP 是强行的。真正随机的对象是**评估流程**：抽样哪些缺陷、每个缺陷是否被检出、分层如何加权。PRISM 手册给出了四种统计模型检测方法（CI / ACI / APMC / SPRT），其中 APMC 逐字：*"offers a probabilistic guarantee on the accuracy of the approximate value generated for a P=? property, based on the Chernoff-Hoeffding bound... Prob(|Y-X| > epsilon) < delta"*。**把阙疑的"检出率"建模成一个 Bernoulli 参数并给出区间，用不着 PRISM——用 Python 十行就能算；PRISM 的价值在于当评估协议本身含多阶段随机（例如先随机选层、再随机选条目、再随机决定重注入）时，它能把"协议的期望检出率"形式化。** 这是一个"要不要上重工具"的判断：**在 n=30/40/452 这个量级，不要上 PRISM；把它写进 related work 作为"更严格的替代路径"即可。**

## 精确数字与案例

### 一、测度论的最小充分工具，以及它在阙疑规模上如何退化

概率空间的定义（Kolmogorov 1933 年专著 *Grundbegriffe der Wahrscheinlichkeitsrechnung*，中文译名《概率论基础》）：三元组 (Ω, F, P)，其中 Ω 是样本空间，F 是 Ω 上的 **σ-代数**（对补集与可列并封闭），P: F → [0,1] 满足三条公理：

1. **非负性**：P(A) ≥ 0，∀A ∈ F
2. **归一化**：P(Ω) = 1
3. **σ-可加性**：对任意两两不交的可列事件列 A₁, A₂, …，`P(∪ᵢ Aᵢ) = Σᵢ P(Aᵢ)`

（以上三条来自多个来源一致转述，包括百度百科"概率空间"词条、Grokipedia "Probability space" 页面、以及德语维基镜像的 "Probability axioms" 页面。三者表述一致。）

**关键退化（这是阙疑唯一需要理解的测度论事实）**：当 Ω 有限时，**任何** F 都可以取为幂集 2^Ω，σ-代数的全部技术困难（不可测集、Carathéodory 扩张定理、Lebesgue 测度的构造）**全部消失**。P 就是 Ω 上一个和为 1 的非负权重向量。**σ-可加性退化为有限可加性**（德语维基镜像页逐字：*"This in turn shows that σ-additivity implies finite additivity. Some authors consider merely finitely additive probability spaces, in which case one just needs an algebra of sets, rather than a σ-algebra."*）。

**对阙疑的判定**：阙疑的所有样本空间都是有限的（30 / 40 / 452 / 67×37），所以：
- **不需要**测度论的重型机器（Radon–Nikodym 导数、条件期望的严格构造、Fubini 定理）；
- **需要**的是**在有限集合上正确选择测度（即权重）**——这正是 43.8% 出问题的地方；
- **不需要**可测函数、随机变量、积分理论——因为阙疑不涉及连续分布，不需要对密度函数积分。

**这是一条负面结论，但它比正面结论更有价值**：测度论对阙疑的适用面极窄，唯一真实的落点是"分层聚合时测度怎么选"。**不要在论文里写"我们用测度论形式化了验证器"，会被一眼看穿。**

### 二、43.8% 的算术不自洽：从测度角度看是"测度未指定"

阙疑现状：外部 corpus 40 条，三层，A 检出 54.2%、B 检出 12.5%、C 检出 0%，聚合报告 43.8%。

**测度论的读法**：设第 i 层有 nᵢ 条，该层检出率为 pᵢ，则条目加权的聚合检出率为

```
P_item(检出) = ( Σ_i n_i · p_i ) / ( Σ_i n_i ) = ( Σ_i n_i · p_i ) / 40
```

而层加权的聚合检出率为

```
P_layer(检出) = (1/3) · Σ_i p_i = (54.2% + 12.5% + 0%) / 3 = 22.23%
```

**两个数字（43.8% 与 22.2%）都是"正确的"，它们只是在不同测度下的同一个事件**。43.8% 要成立，必须满足：

```
Σ_i n_i · p_i = 0.438 × 40 = 17.52
```

**17.52 不是整数**——**这就是"算术不自洽"的真正来源**。由于每条 corpus 条目的检出结果是 0 或 1，Σ nᵢ·pᵢ 必须是一个非负整数。所以 43.8% 与 (54.2%, 12.5%, 0%) 这一组数字**在任何分层规模下都无法同时成立**。

**反推可行的整数组合**（我列出来供阙疑对照）：
- 若 A=24, B=8, C=8：13/24 = 54.17% ✓、1/8 = 12.5% ✓、0/8 = 0% ✓ → 总计 14/40 = **35.0%**
- 若 A=24, B=16, C=0（无 C 层）：13/24 = 54.17%、2/16 = 12.5% → 总计 15/40 = **37.5%**
- 若 A=48, B=16, C=16（总 80）：26/48 = 54.17%、2/16 = 12.5%、0 → 28/80 = **35.0%**

**没有任何组合能给出 43.8%**。因为 43.8% = 7/16，而 54.2% ≈ 13/24，两者的分母不一致。**结论：43.8% 这个数字与三个分层率来自不同的统计口径（可能 43.8% 是另一批数据，或者是某个更细粒度的平均），必须回到原始数据重算，而不是"修一下"**。

**这是本方向给阙疑最有价值的一条**：43.8% 的问题不是算错，而是**没有声明测度**。修法：

1. 在论文里写清楚 `P(检出) = Σ_i w_i · p_i`，并给出 `w_i = n_i / 40`；
2. 同时报告 `P_layer = (1/3)Σp_i` 作为敏感性分析（审稿人会问"层加权会怎样"）；
3. 报告每层的 `n_i`（这本身是数据集描述的必要部分）。

### 三、Clopper-Pearson 与 Wilson：阙疑各数字的精确区间（我算的）

Clopper-Pearson（"精确"区间）基于二项分布与 Beta 分布的等价性：对 k 次成功 / n 次试验，下界是 Beta(α/2; k, n−k+1) 的分位数，上界是 Beta(1−α/2; k+1, n−k) 的分位数。我用纯 Python（`math.lgamma` + Lentz 连分式实现不完全 Beta 函数 + 二分求根）计算，并用已知闭式解交叉验证：n=k=6 时下界应为 0.025^(1/6) = **0.5407**，实算得 **0.5407** ✓。

| 阙疑的指标 | k/n | 点估计 | 95% Clopper-Pearson 区间 | 区间宽度 |
|---|---|---|---|---|
| 盲 holdout（按 30 条中 20 条被标出） | 20/30 | 0.6667 | **[0.4719, 0.8271]** | 35.5 pp |
| 盲 holdout（按真错 17 条中 17 条） | 17/30 | 0.5667 | **[0.3743, 0.7454]** | 37.1 pp |
| 外部 corpus 聚合（43.8% 的整数近似 18/40） | 18/40 | 0.4500 | [0.2926, 0.6151] | 32.3 pp |
| 真实缺陷夹具重注入（6/6） | 6/6 | 1.0000 | [0.5407, 1.0000] | 45.9 pp |

**读法**：所有区间的宽度都在 32–46 个百分点。这意味着**阙疑目前所有检出率数字的置信区间都互相重叠**——"盲 holdout 66.7%"、"corpus 43.8%"、"夹具 100%"这三个数字在统计上**无法区分**。这不是坏消息，而是**必须诚实报告的事实**：E&D Track 的 CFP 明确欢迎 negative results 与批判性分析，**"我们的区间重叠，因此不能声称哪个配置更好"是完全可以发表的结论**，而且比虚假的排序更符合 E&D 的定位。

**Wilson vs Clopper-Pearson 的选择**：多项比较研究（《Confidence Intervals for the Binomial Proportion: A Comparison of Four Methods》，SCIRP *Open Journal of Statistics*，2021-10-21；ResearchGate 同文，2021-01-01）的推荐是 *"we recommend the Wilson interval or the equal-tailed Jeffreys prior"*——即**Wilson 区间或等尾 Jeffreys 先验区间优于 Clopper-Pearson**，因为 Clopper-Pearson 的**实际覆盖率偏高（过于保守）**，导致区间比必要的更宽。**对 n=30 这种小样本，Wilson 区间会比 Clopper-Pearson 窄，从而给出更有信息量的结论。** 阙疑目录里已有 `32_Clopper-Pearson精确计算.md`（另一调研员产出），**建议补充 Wilson 作为主报告区间、Clopper-Pearson 作为保守上界**，并在方法节说明选择理由。

### 四、Hoeffding：样本量的硬公式与阙疑的差距

PRISM 手册（prismmodelchecker.org/manual/RunningPRISM/StatisticalModelChecking）逐字给出 APMC 方法：

> "The APMC (Approximate Probabilistic Model Checking) Method ... offers a probabilistic guarantee on the accuracy of the approximate value generated for a P=? property, based on the Chernoff-Hoeffding bound. The parameters of the method are: 'Approximation' (epsilon), 'Confidence' (delta), 'Number of samples' (N). Letting X denote the true result of the query P=?[...] and Y the approximation generated, we have: Prob(|Y-X| > epsilon) < delta where the parameters are related as follows: **N = ln(2/delta) / 2epsilon²**. This imposes certain restrictions on the parameters, namely that N(epsilon²) ≥ ln(2)/2."

**我代入计算的完整表**：

| ε（精度半宽） | δ（置信水平 1−δ） | 所需样本 N = ln(2/δ)/(2ε²) |
|---|---|---|
| 0.10 | 0.05（95%） | **184.4 → 185** |
| 0.10 | 0.01（99%） | 264.9 → 265 |
| 0.05 | 0.05（95%） | **737.8 → 738** |
| 0.05 | 0.01（99%） | 1,059.7 → 1,060 |
| 0.02 | 0.05（95%） | 4,611.1 → 4,612 |
| 0.02 | 0.01（99%） | 6,622.9 → 6,623 |
| 0.01 | 0.05（95%） | 18,444.4 → 18,445 |
| 0.01 | 0.01（99%） | 26,491.6 → 26,492 |

**阙疑现状对照**：n=30。要达到 ε=0.10（±10 个百分点）需要 185 条——**差 6.2 倍**；要达到 ε=0.05 需要 738 条——**差 24.6 倍**。

**必须说明的重要限定（诚实性）**：**Hoeffding 是"无分布假设"的界，因此是保守的**。当真实分布接近正态（大 n 时的二项分布），Hoeffding 会高估所需样本。对比：用 Wald 正态近似，`N ≈ z²·p(1−p)/ε²`，取 p=0.667、ε=0.05、z=1.96 得 `N ≈ 3.8416 × 0.2222 / 0.0025 ≈ 341`——比 Hoeffding 的 738 少一半以上。**所以引用 738 时必须说明"这是 Hoeffding 保守界；正态近似给出 341"。** 我的建议是**两个数字都报**，并说明阙疑选择哪一个以及为什么。

**注意 PRISM 手册的另一条限制**（同一页逐字）：*"there are also a few restrictions on the modelling language features that can be used"*，且 *"Currently, statistical model checking can only be applied to P or R operators and does not support LTL-style path properties or filters."* 这些限制进一步说明：**统计模型检测是为"随机系统 + 时序性质"设计的，不是为"评估协议 + 比率估计"设计的**。

### 五、PRISM / Storm：工具现状与"该不该用"的判断

**版本事实**（核验过）：
- **PRISM 当前版本 4.8.1，首次发布于 2024-01-13**（prismmodelchecker.org/download.php 逐字：*"The current version of PRISM is 4.8.1 (first released 13 January 2024)."*）。相对 4.7 的主要新增：*"1. Support for uncertain models: 1.1. interval DTMCs (IDTMCs) 1.2. interval MDPs (IMDPs) 2. Improved strategy (policy) generation"*。
- **Storm**：现代概率模型检测器（stormchecker.org，页面标注 2026-08-30 抓取），提供 Python 接口 `stormpy`。支持的模型类型按"时间离散/连续"与"是否部分可观测"两个维度分类（stormchecker.org/documentation/background/models.html）。
- 一个第三方中文对比页（echo.cool，2026-06-24）称：*"PRISM: 强调易用性和教学友好性，提供图形界面和脚本支持，适合理论研究和小规模模型"*——**这是中文二手来源，我未核验其准确性，不作为引用依据**。

**PRISM 手册给出的四种统计模型检测方法**（逐字摘要，来源同上）：

| 方法 | 适用性质 | 参数 | 数学依据 |
|---|---|---|---|
| **CI**（Confidence Interval） | 定量 P=? | Width w、Confidence α、样本数 N | Student-t 分位数：`w = q · sqrt(v/N)` |
| **ACI**（Asymptotic CI） | 定量 | 同上 | 用正态分布近似 Student-t（大样本时适用） |
| **APMC** | 定量 | Approximation ε、Confidence δ、N | **Chernoff–Hoeffding**：`N = ln(2/δ)/(2ε²)` |
| **SPRT**（Sequential Probability Ratio Test） | 仅限有界性质 P~p | Indifference δ、Type I/II 误差 α/β | Wald 序贯概率比检验，基于 [YS02] |

关于 SPRT 的机制，手册逐字：*"The parameter delta is used as the half-width of an indifference region [p-delta,p+delta]. PRISM will attempt to determine whether either the hypothesis P≥(p+delta)[...] or P≤(p-delta)[...] is true, based on which it will return either true or false, respectively. The parameters alpha and beta represent the probability of the occurrence of a type I error... and a type II error..."*

关于"阈值落在区间内则不给答案"这一重要行为，CI 方法逐字：*"For a bounded property P~p[...], the (Boolean) result is determined according to the generated approximation for the probability. This is not the case, however, if the threshold p falls within the confidence interval [Y-w,Y+w], in which case no value is returned."*

**这最后一条对阙疑的判决有直接启发**：PRISM 的做法是"证据不足时拒绝给布尔答案"。阙疑是**四态判决**——如果阙疑的四态里有一态是"证据不足/无法判定"，那么阙疑的判决代数与 PRISM 的这个行为在结构上是同源的。**这是一个值得在论文里点出的设计先例**（并且是一个有正式工具背书的设计选择，不是阙疑自创的怪癖）。

**该不该用 PRISM 的判断**（这是本方向的核心工程结论）：

| 任务 | 用 PRISM 吗 | 理由 |
|---|---|---|
| 验证内核判决的正确性 | **不用** | 内核是确定性函数，无概率转移；写 DTMC 是强行的 |
| 计算检出率的置信区间 | **不用** | 十行 Python 就够；PRISM 的 CI 方法本质是同一个公式 |
| 计算"要达到某精度需要多少样本" | **不用** | 直接用 `N = ln(2/δ)/(2ε²)` 闭式 |
| 形式化"含多阶段随机的评估协议" | **可以考虑** | 例如"先按层抽样、再随机选条目、再按概率重注入"的复合协议，其期望检出率用 PRISM 可以给出可验证的上界 |
| 验证"盲态协议不可回盲" | **不用** | 这是**协议设计**问题（状态机 + 单调性），不是概率问题；方向 52（格论）与方向 64（append-only）更对口 |

**结论：在 n=30/40/452 这个量级，上 PRISM 是负收益**——它增加了一个外部依赖、一个建模语言、一个版本锁定（4.8.1），换来的信息量用一个公式就能得到。**正确做法：在 related work 里用一段话说明"更严格的替代路径是概率模型检测（PRISM 4.8.1 / Storm），但本系统的评估规模（n≤452）使统计区间方法已充分，无需引入状态空间模型"。** 这段话会让审稿人看到你**知道**更重的工具存在但**有理由**不用——这正是 E&D Track 想看的"评估方法论自觉"。

### 六、概率程序验证的现状（对阙疑的间接参考）

这一块与阙疑的技术栈距离很远，但有两个可引用的方法论要点。

**（1）概率程序的语义基础。** 概率程序的形式语义通常归功于 Kozen 1981 年的工作（**我未核验该论文的确切标题与出处，标注为未核实**）。近年的一手工作是 *Symbolic Semantics for Probabilistic Programs*（arXiv:2307.09951，2023-07-19；Springer LNCS 章节 10.1007/978-3-031-43835-6_23，2023-09-15），逐字：*"We present a new symbolic execution semantics of probabilistic programs that include observe statements..."*、*"As a main contribution we provide a full correctness proof of symbolic execution of probabilistic programs"*。

**（2）连续概率程序的演绎验证。** *Foundations for Deductive Verification of Continuous Probabilistic Programs*（arXiv:2502.19388，2025-02-27；ACM DL 10.1145/3720429，2025-04-09），逐字：*"On the practical side, we show that our approach enables to use existing automated verifiers targeting..."*、*"We show that this approach enables the SMT-based invariant verification for programs with a fairly general control..."*。**这里的关键词是 "invariant"（不变量）**——概率程序的验证最终仍归结为"找到一个在转移下保持的不变量"，这与阙疑的哈希链不变量、以及方向 58 的 sheaf 全局截面，是同一个方法论母题。

**（3）近似/可靠验证的边界。** *Tools and Algorithms for Sound Multi-Objective Probabilistic Model Checking*（ACM DL 10.1007/978-3-032-26204-2_10，2026-05-18；Springer PDF 2026-07-02），逐字：*"In this paper, we present the first implementations of recently-developed sound MO-PMC algorithms that bound the..."*（句子在抓取处截断）。**"sound"（可靠）在这里的含义是"给出的是真实的上下界，而不是点估计"**——这是与统计方法（给区间、有误报概率）的根本区别。**阙疑若要声称"判决可复算"，其数学性质更接近 soundness（结果可被独立重算验证），而不是 statistical soundness（有概率保证）。这个区分应当写清楚。**

### 七、对"验证器输出可信度"的形式化：该写什么、不该写什么

阙疑需要一个"验证器输出可信度"的形式化。基于本方向的调研，**正确的形式化是这样三层，而不是测度论重机器**：

**第 1 层（必须）——四态判决的代数结构**。阙疑的四态（例如 verified / red-team / draft / 加上一个"不可判定"态）是**偏序**上的元素，不是概率。这一层的正确数学工具是**格论**（Lattice），方向 52 已覆盖。**不要在这里引入概率**——把"verified"说成"95% 可信"会同时破坏可复算性（95% 从哪来？）与四态的清晰性。

**第 2 层（必须）——评估指标的不确定性**。检出率、精确率、召回率都是**二项比例的估计**，用 Clopper-Pearson / Wilson 给区间。这一层是纯统计，不需要测度论。

**第 3 层（可选）——聚合测度的显式声明**。当指标跨层聚合时，必须显式写出权重与测度（见本文第二节）。**这一层才是测度论真正的落点**。

**明确不要做的三件事**：
- ❌ 不要写"我们构造了样本空间 Ω 与 σ-代数 F，证明验证器输出是 F-可测的"——阙疑的 Ω 有限，F = 2^Ω，这个陈述**恒真、无信息量**（与方向 58 里"紧致性恒真"是同一类错误）。
- ❌ 不要写"我们用 Radon–Nikodym 导数定义了证据的密度"——阙疑的证据是离散的哈希指纹，没有密度。
- ❌ 不要声称 PRISM 验证了内核——内核是确定性的，这句话会被立刻反驳。
