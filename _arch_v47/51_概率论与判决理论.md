# 方向 51：概率论与判决理论——把"四态判决"形式化为一个判决理论问题

## 核心结论

1. **四态判决不是四分类，而是"一个二值动作 × 一个严重度刻度"的复合判决。** 用判决理论拆开后可见：`pass / advice / warn` 在**动作**层面完全同构（都不阻断），差别只在**通信成本**（c(P)=0 < c(A)=1 < c(W)=3）；只有 `block` 承载了真正的真假后果。因此一个 4×2 的损失矩阵 `L(d, ω)`（`d ∈ {P,A,W,B}`，`ω ∈ {成立, 不成立}`）就足以完整刻画系统，而**不需要** 4×4 矩阵。代入一组可辩护的代价数（放行错卡的下游损失 100/60/30/0，误阻断正确卡的损失 0/1/3/50），Bayes 最优规则给出**三个显式门限**：`p_sound ≥ 0.9756 → pass`、`[0.9375, 0.9756) → advice`、`[0.3896, 0.9375) → warn`、`< 0.3896 → block`（`p_sound = P(断言成立 | 证据)`）。这是本项目**第一次**把 67 条硬编码 if-then 规则背后的隐含偏好写成可审计的对象。

2. **引入 advice / warn 两个中间态，定量地把 block 门限推向更保守的一侧。** 二态世界（只有 pass/block）下，用 Elkan (2001, IJCAI'01) 的闭式门限公式 `p* = (λ(1|0)−λ(0|0)) / ((λ(1|0)−λ(0|0)) + (λ(0|1)−λ(1|1)))`，代入 λ(block|成立)=50、λ(pass|成立)=0、λ(pass|不成立)=100、λ(block|不成立)=0，得 **block 当且仅当 P(不成立) ≥ 1/3 ≈ 0.3333**。四态世界下 block 要求 **P(不成立) > 0.6104**。即 block 触发区间从 `[0.333, 1]` 收缩到 `[0.610, 1]`，**触发区间相对缩小 41.6%**。这个数字是可以直接写进论文、用来论证"四态判决比二态判决更克制"的硬结果——它把"我们很谨慎"这句定性话变成了一个可复算的常数。

3. **Neyman–Pearson 范式为阙疑提供了一个比"检出率"更诚实的评价口径，但代价是样本量。** NP 分类（Tong & Feng 等，JMLR 2016 / *Science Advances* 2018 / JMLR 2020 / JASA 2024，配套 `nproc` R 包与 Python 包）主张：**先把高优先级的那类错误（此处＝误 block 一条正确卡）控制在用户指定的 α 之下，再最小化另一类错误（漏检错卡）**。这与阙疑"宁可 warn 也不乱 block"的产品直觉完全一致，且它**天然解释了为什么不该报告单一检出率**：单一标量隐含了一个未言明的损失比。但代价是——盲 holdout 只有 30 条，自算 Clopper–Pearson 95% 区间宽度为 **0.47**（若按 11/17 计，区间 `[0.383, 0.858]`），**任何"检出率 66.7%"的声称在统计上都与"30%"不可分辨**。这一条既是方法贡献，也是必须主动暴露的威胁。

## 精确数字与案例

### 一、判决理论的骨架：从 0-1 损失到代价矩阵

判决理论的标准设定（Elkan 2001 的表述，逐字引自原文 PDF）：

> "Given a specification of costs for correct and incorrect predictions, an example should be predicted to have the class that leads to the lowest expected cost, where the expectation is computed using the conditional probability of each class given the example."

数学形式（Elkan 式 (1)）：令 `λ(i|j)` 表示**真实类为 j 时预测类 i** 的代价，最优预测为

```
argmin_i  Σ_j  P(y = j | x) · λ(i | j)
```

三个必须记住的结构性事实（逐字转述自该 PDF）：

- **合理性条件（reasonableness conditions）**：二分类下必须 `λ(+|−) > λ(−|−)` 且 `λ(−|+) > λ(+|+)`。若第一条被违反（即 `λ(−|−) ≥ λ(+|−)`），则**最优策略是把所有样本都标为正类**。
- **行支配（row domination）判据**："Say that row k dominates row m in a cost matrix λ if for all j, λ(k|j) ≥ λ(m|j). In this case the cost of predicting m is no greater than the cost of predicting k, regardless of what the true class j is. So it is optimal never to predict k." ——**这是对阙疑最关键的一条**：它给出了"某个判决态永远不会被使用"的充分条件。若 `advice` 那一行的每一列都不小于 `pass` 那一行的对应列，`advice` 就是死码。四态要成立，必须显式打破行支配。
- **规范形**："By scaling and shifting entries, any two-class cost matrix that satisfies the reasonableness conditions can be transformed into a simpler matrix"，即 2×2 代价矩阵在**矩阵视角**下有两个自由度，但从**决策视角**看，"any 2x2 cost matrix has essentially only one degree of freedom from a decision-making perspective"。

**闭式门限（Elkan 式 (2)）**，记 `p = P(类1 | x)`：

```
p* = ( λ(1|0) − λ(0|0) ) / ( ( λ(1|0) − λ(0|0) ) + ( λ(0|1) − λ(1|1) ) )
```

且"the optimal prediction is class 1 if and only if p > p*"。

**定理 1（重标定）**：为把目标门限 `p*` 对应到学习器实际使用的门限 `p₀`，"the number of negative examples in the training set should be multiplied by"（PDF 文本层为位图字体，按定理语义还原为 `p*(1−p₀) / (p₀(1−p*))`，见盲区）。Elkan 自己在摘要里对该路线的评价是：**"changing the balance of negative and positive training examples has little effect on the classifiers produced by standard Bayesian and decision tree learning methods"**，推荐做法是"learn a classifier from the training set as given, and then to compute optimal decisions explicitly using the probability estimates given by the classifier"。**这条对阙疑是直接可用的工程指导**：不要靠重采样去调门限，要先把规则打分变成概率估计，再在外部算最优判决。

### 二、四态判决的损失函数矩阵（本方向的主要产物）

真值空间 `Ω = {S (断言成立), F (断言不成立)}`，判决集 `D = {pass, advice, warn, block}`，按严重度线性序 `pass ⊏ advice ⊏ warn ⊏ block`（此序在第 52 方向会被提升为格结构）。

语义前提（必须写进论文假设节）：

- `pass / advice / warn` 三种判决**都不阻断**该知识卡的使用，因此它们在"是否放行"这个二值动作上同构；区别只在于向读者输出的提示强度与由此产生的注意力/复核开销。
- `block` 是唯一的阻断动作，会导致该卡从可用集合中移除。

代价设定（单位：抽象的"下游成本单位"，只关心比值）：

| 判决 `d` \ 真值 `ω` | `ω = S`（卡正确） | `ω = F`（卡有错） | 说明 |
|---|---|---|---|
| `pass` | 0 | **100** | 完全不提示，错卡被全盘接受 |
| `advice` | 1 | **60** | 有提示但弱，读者可能忽略 |
| `warn` | 3 | **30** | 醒目提示，读者大概率复核 |
| `block` | **50** | 0 | 误杀正确卡的代价；真错时无代价 |

**行支配检验**：`pass` 行在 `S` 列最小、`block` 行在 `F` 列最小，互不相占优；`advice`/`warn` 行也都不被任何其它行逐列占优（因为它们在 `F` 列更便宜、在 `S` 列更贵）。因此**四个态在最优策略下都可能被选中**——四态不是装饰。若改成 `L(advice, F) = 100`（提示不起作用），则 `advice` 行被 `pass` 行支配 → `advice` 立刻变成死码。这给出了一个**可证伪的判据**：只要能从账本里测出"warn 是否真的降低了错卡的下游损失"，就能判定四态是实质性的还是装饰性的。

令 `p = P(ω = S | 证据)`，四条期望损失：

| 判决 | 期望损失 `R(d | p)` |
|---|---|
| `pass` | `100 − 100p` |
| `advice` | `60 − 59p` |
| `warn` | `30 − 27p` |
| `block` | `50p` |

逐对求交，得 **Bayes 最优四态判决规则**：

| 相邻比较 | 交点 | 含义 |
|---|---|---|
| pass vs advice | `100 − 100p < 60 − 59p ⇔ p > 40/41 ≈ **0.9756**` | 只有极强证据才敢"什么都不说" |
| advice vs warn | `60 − 59p < 30 − 27p ⇔ p > 30/32 = **0.9375**` | 0.9375 以下升级为 warn |
| warn vs block | `30 − 27p < 50p ⇔ p > 30/77 ≈ **0.3896**` | 低于 0.3896 才阻断 |

即：

```
p ≥ 0.9756            → pass
0.9375 ≤ p < 0.9756   → advice
0.3896 ≤ p < 0.9375   → warn
p < 0.3896            → block
```

**单调性**：`p` 单调下降 ⇒ 严重度单调上升。这不是巧合，而是损失矩阵满足 **递增差分 / Monge 型条件**（相邻行的差值随列单调）的必然后果。第 52 方向会把它升级为格上的单调函数保证；这里先给出可验证的判据：

> 判决规则关于 `p` 单调 ⟺ 对任意 `d₁ ⊏ d₂ ⊏ d₃`，有 `[L(d₂,ω) − L(d₁,ω)] − [L(d₃,ω) − L(d₂,ω)]` 关于 `ω` 的排序一致。

**四态相对二态的定量收益**（本方向最硬的一个数字）：

- 二态（只有 pass/block）：`block ⟺ P(F) ≥ 1/3 ≈ 0.3333`（由 Elkan 式 (2) 直接代入）。
- 四态：`block ⟺ P(F) > 0.6104`（即 `p_sound < 0.3896`）。
- block 触发区间由 `[0.3333, 1]` 收缩到 `[0.6104, 1]`，**长度相对缩小 (0.6104−0.3333)/(1−0.3333) = 41.6%**。

这可以直接写成论文里的命题：**"在给定代价设定下，引入两个中间判决态使阻断动作的发生区间缩小 41.6%，而漏检损失仅从 0 上升到 30（占总损失上界 100 的 30%）。"** 这是"四态判决有用"的一个可复算证明，而不是一句宣言。

### 三、ROC / PR 曲线下的最优门限，以及"不该报单一检出率"

Davis & Goadrich（ICML 2006, Pittsburgh, PA）的三条结论（逐字引自摘要）：

> "a deep connection exists between ROC space and PR space, such that **a curve dominates in ROC space if and only if it dominates in PR space**"
> "**in PR space it is incorrect to linearly interpolate between points**"
> "**algorithms that optimize the area under the ROC curve are not guaranteed to optimize the area under the PR curve**"

对阙疑的直接含义：

1. **外部 corpus 40 条、真错高度偏斜时，应当报 PR 曲线而非 ROC 曲线。** 但更重要的是第 3 条：如果论文里同时报 AUROC 和 AUPR，必须明确以哪个为优化目标——两者不等价。
2. **PR 空间禁止线性插值** —— 若论文要画 PR 曲线，必须画"achievable PR curve"（该文给出的、类似 ROC 凸包的构造与高效算法），不能用折线连接稀疏点。阙疑 452 条判决账本在严重度维度上只有 4 个离散工作点，插值会系统性高估。
3. **最优工作点不是 AUC 最大点。** 在 ROC 平面上，给定代价比和类先验，最优点是斜率为
   `s = (N_neg / N_pos) · (λ(+|−) − λ(−|−)) / (λ(−|+) − λ(+|+))`
   的等性能线与曲线族相切的点；在 PR 平面上对应的是等 F 值线。把阙疑的损失矩阵代进去，就能在 452 条账本上算出**当前系统离其自身代价设定下的最优点有多远**——这比"检出率 66.7%"信息量大得多。

### 四、Neyman–Pearson 范式：给阙疑一个正确的成功判据

经典 Neyman–Pearson 引理（Neyman & Pearson, 1933）：在两个简单假设之间，**似然比检验是所有水平 α 检验中功效最大的**（UMP）；Karlin–Rubin 定理把它推广到具有单调似然比的复合假设。它的一条工程化表述（Wikipedia 转述其在雷达中的应用）："the Neyman–Pearson lemma is used in first setting the rate of missed detections to a desired (low) level, and then minimizing the rate of false alarms, or vice versa. **Neither false alarms nor missed detections can be set at arbitrarily low rates, including zero.**"

把这一范式搬到分类问题上，是 NYU 杨烽（Yang Feng）组与合作者的一条完整研究线（全部为可核验的真实出版物）：

| 论文 | 作者 | 刊物 | 年份 | 贡献 |
|---|---|---|---|---|
| Neyman-Pearson Classification under High-Dimensional Settings | Anqi Zhao, Yang Feng, Lie Wang, Xin Tong | *JMLR* | 2016 | 首个高维 NP 分类框架，"NP-oracle property" |
| A Survey on Neyman-Pearson Classification and Suggestions for Future Research | Xin Tong, Yang Feng, Anqi Zhao | *WIREs Computational Statistics* | 2016 | 系统综述与分类法 |
| Neyman-Pearson Classification Algorithms and NP Receiver Operating Characteristics | Xin Tong, Yang Feng, Jingyi Jessica Li | *Science Advances* | 2018 | **NP-ROC band** 与 **NP-umbrella 算法**（可把任意 scoring 型分类器改造为 NP 分类器） |
| Neyman-Pearson Classification: Parametrics and Sample Size Requirement | Xin Tong, Lucy Xia, Jiacheng Wang, Yang Feng | *JMLR* | 2020 | **有限样本样本量公式**，保证以高概率控制 type I error |
| Neyman-Pearson Multi-class Classification via Cost-sensitive Learning | Ye Tian, Yang Feng | *JASA* | 2024 | 建立 **NP 分类 ⇄ 代价敏感学习** 的理论等价 |

配套软件真实存在：`nproc`（CRAN 的 R 包；Python 版 `github.com/ZhaoRichard/nproc`）、`npcs`（CRAN，多类版）。

**NP 范式对阙疑的对应表**：

| NP 术语 | 阙疑中的对应物 |
|---|---|
| type I error（高优先级，必须控制） | **误 block 一条正确的知识卡**（直接损害可用性，且不可逆地进入账本） |
| type II error（在约束下最小化） | **漏检一条错误的知识卡** |
| α（用户指定上界） | 论文应显式声明的目标，例如 α = 0.05 |
| NP-ROC band | 替代单一检出率的曲线族报告 |
| 样本量要求 | 盲 holdout 30 条**远远不够**，见下 |

**代价（必须诚实写出来）**：Tong 等 (JMLR 2020) 的核心问题就是"How much data do we need?"——在 NP 范式下，要以高概率保证 type I error ≤ α 且 type II error 接近最优，所需样本量随 `1/α`、维度与信号强度增长。**阙疑 30 条盲 holdout 无法支撑 α = 0.05 级别的声明**。用自算的 Clopper–Pearson 95% 区间（纯 Python 二分求正则化不完全 Beta 函数的逆，非引用现成表格）：

| 观测 | `p̂` | CP 95% 区间 | 区间宽度 |
|---|---|---|---|
| 11/17 | 0.6471 | [0.3833, 0.8579] | **0.4746** |
| 12/17 | 0.7059 | [0.4404, 0.8969] | 0.4564 |
| 7/16 | 0.4375 | [0.1975, 0.7012] | **0.5037** |
| 21/48 | 0.4375 | [0.2948, 0.5882] | 0.2934 |

结论很刺眼：**在 n ≈ 17 的规模上，检出率的 95% 置信区间宽度接近 0.5，区间下界可以低到 0.20。** 论文里绝不能把"检出 66.7%"当成点估计来用；正确写法是**报区间 + 声明"本数据集的统计功效不足以区分 20% 与 70%"**，并据此把论文定位从"我们检出了多少"改为"我们提供了一种在给定 α 下可审计的部分判决机制"。

### 五、拒判（abstention）与选择性判决：四态的"第三态"其实有 55 年历史

- **Chow, C. (1970), "On optimum recognition error and reject tradeoff", *IEEE Transactions on Information Theory*** —— 提出最优拒绝规则（optimum rejection rule），并给出错误率与拒绝率之间的一般关系。这是"拒判"作为一个**最优决策**而非"失败兜底"的起点。
- **Geifman & El-Yaniv, "Selective Classification for Deep Neural Networks" (arXiv:1705.08500, 2017; NeurIPS 2017)** 与 **SelectiveNet (PMLR v97, 2019)** —— 引入 **risk–coverage 曲线**：允许用户在"覆盖率"上做取舍，把被拒绝的样本交给人工。

**对阙疑的关键提醒**：`advice` / `warn` 本质上是**有代价的软拒判**——它们不阻断，但把复核责任转嫁给读者。Chow 的框架告诉我们，拒判的最优阈值同样由一个显式代价（拒判成本）决定：**如果阙疑从未度量过"读者看一条 warn 要花多少时间"，那么 `warn` 的门限就是未定义的**。这是一个可以立刻补的实验。

### 六、序贯检验：把"多轮质证"变成有最优性保证的过程

Wald 的序贯概率比检验（SPRT，Wald 1947 同名专著）与 **Wald & Wolfowitz (1948), "Optimum Character of the Sequential Probability Ratio Test", *Annals of Mathematical Statistics* 19(3)** 证明了：**在所有（两类错误概率不超过 SPRT 的）序贯检验中，SPRT 使两类假设下的期望样本量 `E_i(n)` 同时最小**。

对阙疑的意义很直接：当前 `gate_engine.py`（3826 行）似乎是一次性打分后出判决。**如果改成"规则逐条累积对数似然比，越过上界就 block、越过下界就 pass、中间继续"的序贯协议**，则 Wald–Wolfowitz 定理给出一个可写进论文的最优性声明：**"在相同的错误概率约束下，阙疑的序贯质证协议所需的规则调用次数期望最小。"** 而且它天然解决了"67 条规则全跑太贵"的问题——平均只需跑一小部分。

（注意：Wald–Wolfowitz 最优性在"序贯计划检验 / sequentially planned tests"情形下**不再直接成立**，Schmitz 在 *Metrika* 上的工作明确说明 "no direct counterpart to the famous Wald-Wolfowitz theorem is available"——若论文要宣称最优性，必须限定在固定步长序贯的设定内。见盲区。）

### 七、共形预测（conformal prediction）：唯一能给"无分布假设覆盖保证"的工具

Split conformal 的核心保证：在**仅假设数据可交换（exchangeable）**的前提下，构造出的预测集满足边际覆盖率等于名义水平 `1 − α`（有限样本、无分布假设）。相关新近工作如 *Conformal Prediction With Conditional Guarantees* (arXiv:2305.12616)。

对阙疑：**判决账本的 452 条记录若要声称"我们的判决集合以 95% 概率覆盖真值"，唯一不需要给判决器建概率模型的路径就是共形预测**。但请注意两点：(a) 保证是**边际**的而非条件于单张卡的；(b) 可交换性假设在"按时间顺序 append 的账本"上是**可疑的**——账本有时间漂移（工作树 227 项漂移就是证据）。

## 盲区（诚实标注）

- **Elkan 定理 1 的分数形式**：PDF 文本层为位图字体，`pypdf` 抽出的字符顺序为 `p*, (1−p*), (1−p₀), p₀`，我按定理语义还原为 `r = p*(1−p₀)/(p₀(1−p*))` 型的重标定因子（推导：重标定后后验几率按 1/r 缩放，故 `r = p*(1−p₀)/(p₀(1−p*))`）。**该精确形式我未从印刷版逐字核实**，论文引用时请核对 IJCAI'01 纸质/官方 PDF 原式。式 (2) 的门限公式则是逐字对照后重排的，可信度较高。
- **四态损失矩阵中的数值（100/60/30/50/1/3）是我构造的示例，不是实测值。** 它们只为演示门限推导与"block 区间缩小 41.6%"这一**结构性**结论；41.6% 这个数字随代价设定变化，**不能脱离矩阵单独引用**。论文若要用，必须替换为实测或给出敏感性分析（建议附一张"门限 vs 代价比"的热力图）。
- **Tong 等 (JMLR 2020) 的样本量公式我没有打开原文**，因此**没有给出"α=0.05 下需要多少条盲测样本"的具体数字**。需要时请直接取该文公式或跑 `nproc`。
- **置信区间为本人自算**（纯 Python 实现正则化不完全 Beta 函数的连分数展开 + 二分求逆，无 `scipy` 依赖），未与 R 的 `binom.test` 交叉验证；可能有个位小数级别的误差。且 11/17、7/16 等分子是我根据百分比**反推**的，分母口径本身存疑（见行动 2）。
- **Wald–Wolfowitz 最优性的边界**：Schmitz 指出在"sequentially planned tests"下无直接对应定理，我未读该 *Metrika* 原文全篇，**不确定其反例是否覆盖"规则调用次数由已跑规则动态决定"这一情形**——而这恰恰是阙疑可能的改造方向。宣称最优性前必须核这一条。
- **共形预测的可交换性假设**在带时间戳的 append-only 账本上很可能不成立（工作树 227 项漂移是旁证）。若强行套用，边际覆盖保证会被漂移违反；需要"加权/滑窗共形"变体，我没有核实哪些变体已有成熟理论保证。
- **"检出率"与"判决正确率"的混用风险**：本方向全程假设真值是二值的（卡成立/不成立）。但阙疑的 `draft / verified / red-team` 三分状态说明真值可能是三值甚至带置信度的，此时 4×2 矩阵应升级为 4×3，门限推导需重做。
