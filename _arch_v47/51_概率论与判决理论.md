# 方向 51：概率论与判决理论——把"四态判决"形式化为一个判决理论问题

## 核心结论

1. **四态判决不是"四分类"，而是"一个连续的后验概率 $p$ 被切成了四段"；切点由损失矩阵唯一决定。** 用判决理论拆开后可见：`block / warn / advice / verified` 对应的是 $p=P(\text{断言成立}\mid\text{证据})$ 的四个区间。给定一个具体的损失矩阵（见第三节），我**手算**出的切点是 **0.200 / 0.6667 / 0.9231**。也就是说：**四态判决的全部内容就是"在 $p$ 上放三个阈值"**——这三个数字比"四种颜色"更容易被审稿人接受，也更容易被第三方复算。**这是本方向对阙疑最直接的产出。**

2. **最优阈值的公式是闭式的，任何 2×2 损失矩阵只有"一个自由度"。** Elkan（*The Foundations of Cost-Sensitive Learning*，IJCAI 2001，6 页）在原文中证明：*"This formula for $p^*$ shows that any 2x2 cost matrix has essentially only one degree of freedom from a decision-making perspective, although it has two degrees of freedom from a matrix perspective."* 我自己推导（见第二节）得到标准形式 $p^*=\dfrac{c_{10}-c_{00}}{(c_{10}-c_{00})+(c_{01}-c_{11})}$，其中 $c_{ij}$ 是"预测为 $i$、实际为 $j$"的代价。**对阙疑的含义**：67 条规则无论多么复杂，最终**只需要确定一个代价比**（"漏检一条真错"相对"误杀一条正确知识"贵多少倍），阈值就自动确定。这极大地简化了"规则权重的调参"问题——**不需要调 67 个权重，只需要调 1 个代价比**。

3. **在阙疑的场景（真错 17 / 检出 66.7%）下，ROC 与 AUC 是错误的汇报工具，应改用 PR 曲线与原始计数。** Saito & Rehmsmeier（*The Precision-Recall Plot Is More Informative than the ROC Plot When Evaluating Binary Classifiers on Imbalanced Datasets*，*PLoS ONE* 2015，DOI 10.1371/journal.pone.0118432）逐字：*"We show here that the visual interpretability of ROC plots in the context of imbalanced datasets can be deceptive with respect to conclusions about the reliability of classification performance."* 阙疑的"真错"比例在盲 holdout 是 17/30 = 56.7%（不算极度不平衡），但在外部 corpus C 层是 **0 检出**——**这种层内极端不平衡正是 ROC 最会骗人的场景**。**结论：阙疑应报告 PR 曲线 + 原始计数，并在论文里引用 Saito & Rehmsmeier 说明理由。**

## 精确数字与案例

### 一、Neyman–Pearson 引理：精确陈述与"最优"的确切含义

**Stanford STATS 200 Lecture 6（Autumn 2016，5 页）逐字给出的框架**：

> *"Let's focus on the problem of testing a simple null hypothesis $H_0$ against a simple alternative hypothesis $H_1$. We denote by $\beta=P_{H_1}[\text{accept }H_0]$ the probability of type II error… Equivalently, $1-\beta=P_{H_1}[\text{reject }H_0]$ is the probability of correctly rejecting $H_0$ when $H_1$ is true, which is called the power of the test against $H_1$."*
> *"When designing a hypothesis test for testing $H_0$ versus $H_1$, we have the following goal: maximize: the power of the test against $H_1$ subject to: the significance level of the test under $H_0$ is at most $\alpha$. This is an example of a constrained optimization problem."*

**Neyman–Pearson 的内容**：在**简单零假设 vs 简单备择**的情形下，似然比检验是**一致最优（UMP）**的——即"在固定第一类错误率 $\alpha$ 下，功效最大"。

**⚠️ 三个必须写清楚的限制（否则会被统计审稿人抓住）**：

| 限制 | 具体含义 | 对阙疑的影响 |
|---|---|---|
| **只对"简单 vs 简单"成立** | NP 引理不直接适用于复合零假设/复合备择 | 阙疑的"断言不成立"是一个复合假设（有很多种不成立方式），**不能直接套 NP** |
| **NP 是"固定 $\alpha$ 最大化功效"** | 它**不涉及代价**，只涉及两类错误率的约束 | 阙疑真正关心的是代价（漏检 vs 误杀），**NP 框架不回答"该选哪个 $\alpha$"** |
| **NP 不给出"最优点"** | NP 给出的是**一族**最优检验（对应不同的 $\alpha$），即 ROC 曲线上的**每一个点** | 选哪个点必须由**判决理论（代价）**决定，不是 NP 决定的 |

**对阙疑最有用的一句话**：**NP 引理告诉你"在 ROC 曲线上，每个 $\alpha$ 下的最优操作点在哪里"；判决理论告诉你"该选 ROC 曲线上的哪一个点"。** 这两件事必须分开写，混在一起是常见错误。

**理论源头**：Wald, *Statistical Decision Functions*, New York: Wiley, **1950**（Springer 的 Minimax 条目逐字：*"Minimax (Wald, Statistical decision functions. New York: Wiley, 1950) is the principle in statistical decision theory of…"*）。Wald 的框架把"检验"推广为"决策函数"，引入**风险函数（risk function）**、**容许性（admissibility）**与**极小极大（minimax）**准则。Wald 原文对容许性的定义（Gwern 存档 PDF 逐字）：*"A decision function $\delta$ will be said to be admissible if there exists no other decision function $\delta^*$ which is uniformly [better]"*。

### 二、Bayes 判决规则与最优阈值：闭式推导

**期望损失原则（Georgia Tech ISyE handout 4 逐字）**：*"Bayesian expected loss is the expectation of the loss function with respect to posterior measure… In comparing two actions $a_1=\delta_1(X)$ and $a_2=\delta_2(X)$; after data $X$ had been observed, preferred action is the one for which the posterior expected loss is smaller."*

**我给出的完整推导（可逐行复核）**：

设 $p=P(\text{成立}\mid x)$。代价矩阵记 $c_{ij}$ = "预测为 $i$、实际为 $j$"的代价（行 = 预测，列 = 实际，与 Elkan 的约定一致）。两个动作的期望代价：

$$E[\text{cost}\mid\text{预测正}] = p\,c_{11}+(1-p)\,c_{10},\qquad E[\text{cost}\mid\text{预测负}] = p\,c_{01}+(1-p)\,c_{00}$$

预测正更优 ⟺ $E[\text{cost}\mid\text{正}]\le E[\text{cost}\mid\text{负}]$，整理得：

$$\boxed{\;p \ge p^* = \frac{c_{10}-c_{00}}{(c_{10}-c_{00})+(c_{01}-c_{11})}\;}$$

**这正是 Elkan Eq. (2) 的形式。** ⚠️ **诚实标注**：我下载了 Elkan 的 PDF（`cseweb.ucsd.edu/~elkan/rescale.pdf`，6 页，IJCAI'01），但**该 PDF 的数学符号在 `pypdf` 提取后严重乱码**（例如阈值公式被提取为 `R V ( 02*WF ( *+* (30* F (!*+*MLN(!*10 F (30+0`）。因此上式的推导是**我自己独立完成的**，它**在结构上与 Elkan 的记号一致**（分母含 $c_{01}$ 与 $c_{10}$，对角项 $c_{00},c_{11}$ 可设为零），但我**没有逐字符核对 Eq. (2)**。**"reasonableness 条件"我逐字读到了**：原文 *"the cost of labeling an example incorrectly should always be greater than the cost of labeling it correctly. Mathematically, it should always be the case that $c_{01}>c_{00}$ and $c_{10}>c_{11}$. We call these conditions the 'reasonableness' conditions."*

**Elkan 的另一条关键洞察（逐字）**：*"The essence of cost-sensitive decision-making is that it can be optimal to act as if one class is true even when some other class is more probable. For example, it can be rational not to approve a large credit card transaction even if the transaction is most likely legitimate."* —— **这句话就是四态判决存在的理由**：如果最优动作可以在 $p<0.5$ 时仍然选择"报警"，那么"二值判决 + 0.5 阈值"在理论上就是错的。

### 三、把四态判决写成判决理论问题（含手算阈值）

**形式化**：
- **真值状态**：$T$（断言成立）与 $F$（断言不成立），$p=P(T\mid\text{证据})$。
- **动作集合**（= 四态判决）：$V=\{\texttt{block},\ \texttt{warn},\ \texttt{advice},\ \texttt{verified}\}$。
- **损失矩阵**（行 = 动作，列 = 真值；单位：一次误导性判决的代价）：

| 动作 $v$ | $T$（成立） | $F$（不成立） |
|---|---|---|
| `verified` | 0 | **10** |
| `advice` | 0.5 | 4 |
| `warn` | 2 | 1 |
| `block` | **6** | 0 |

**这个矩阵满足的两条单调性（必须满足，否则判决逻辑不自洽）**：
- $T$ 列随判决变严厉而**递增**：0 → 0.5 → 2 → 6
- $F$ 列随判决变严厉而**递减**：10 → 4 → 1 → 0

**期望损失**（$p$ 为"成立"的后验概率）：
$$E_v(p)=L(v,T)\,p+L(v,F)\,(1-p)$$

逐项展开：
- $E_{\text{verified}}=0p+10(1-p)=10-10p$
- $E_{\text{advice}}=0.5p+4(1-p)=4-3.5p$
- $E_{\text{warn}}=2p+1(1-p)=1+p$
- $E_{\text{block}}=6p+0(1-p)=6p$

**相邻比较求切点**（我手算，可复核）：

| 比较 | 不等式 | 解 |
|---|---|---|
| `verified` vs `advice` | $10-10p\le 4-3.5p$ | $p\ge \frac{6}{6.5}=0.923077$ |
| `advice` vs `warn` | $4-3.5p\le 1+p$ | $p\ge \frac{3}{4.5}=0.666667$ |
| `warn` vs `block` | $1+p\le 6p$ | $p\ge \frac{1}{5}=0.200000$ |

**最优决策规则（四态判决的判决理论刻画）**：

| 后验概率区间 | 最优动作 |
|---|---|
| $p<0.200$ | `block` |
| $0.200\le p<0.6667$ | `warn` |
| $0.6667\le p<0.9231$ | `advice` |
| $p\ge 0.9231$ | `verified` |

**数值自检（我逐个代入验证）**：

| $p$ | $E_{\text{verified}}$ | $E_{\text{advice}}$ | $E_{\text{warn}}$ | $E_{\text{block}}$ | 最小者 |
|---|---|---|---|---|---|
| 0.10 | 9.0 | 3.65 | 1.10 | **0.60** | `block` ✓ |
| 0.50 | 5.0 | 2.25 | **1.50** | 3.00 | `warn` ✓ |
| 0.80 | 2.0 | **1.20** | 1.80 | 4.80 | `advice` ✓ |
| 0.95 | **0.50** | 0.675 | 1.95 | 5.70 | `verified` ✓ |

**这张表的三个直接用途**：
1. **`verified` 需要 $p\ge 0.923$** —— 这个门槛极高，说明**"verified"这个标签在理论上应该很难拿到**。阙疑当前有 23 张 verified 卡，如果按这个矩阵，需要逐卡检查是否真的有 92.3% 的后验把握。
2. **中间两个状态覆盖了 $[0.200, 0.9231]$，宽度 0.723** —— 即**72% 的后验概率区间被两个中间态吸收**。这正是"四态比二态强"的定量表达：**二值方案会把这 72% 的区间强行二分，而其中每一侧的判决在某些 $p$ 值上都是次优的。**
3. **`advice` 与 `warn` 的分界在 0.6667，不是 0.5** —— 因为"不成立"的代价（10）远大于"成立"的代价（6），所以分界点被推高。**这是代价敏感的直接后果，也是四态设计的理论依据。**

**敏感性分析（阙疑应该做的）**：把 $L(\texttt{block},T)$ 从 6 调到 20（"误杀正确知识的代价提高 3.3 倍"），切点如何变化？`warn` vs `block` 变成 $1+p\le 20p$ ⟹ $p\ge 1/19=0.0526$。即**`block` 的区域从 $p<0.2$ 缩小到 $p<0.053$**。**这个敏感性曲线（切点 vs 代价比）是一张可以放进论文的图。**

### 四、代价敏感学习的工程实现与真实数字

**scikit-learn 1.9 官方示例 `plot_cost_sensitive_learning`（我逐字提取）**：
- 核心 API：**`TunedThresholdClassifierCV`**（自动搜索阈值）、**`FixedThresholdClassifier`**（固定阈值）、`sklearn.frozen.FrozenEstimator`。
- 官方对理论依据的表述（逐字）：*"theoretically, given that our model is calibrated, our dataset is representative and large enough, we do not need to tune the threshold, but can safely set it to 1/5 of the cost ratio, as stated by Eq. (2) in Elkan's paper"*。

**德国信用数据集（OpenML `data_id=31`）实例**：
- 样本 **1000** 条，**20** 个特征；good = **700**，bad = **300**。
- 代价设定：把 bad 判成 good 的代价是反向的 **5 倍**（FP 增益 −1，FN 增益 −5）。
- 结果：默认阈值 0.5 时业务指标 **−209**；调优后阈值 **0.03** 时 **−143**（"增益提升近 2 倍"）。

⚠️ **我发现的矛盾（必须放进盲区）**：按我在第二节推导的公式，$c_{10}=1,\ c_{01}=5$（对角为 0）应得 $p^*=1/(1+5)=0.1667$。但 sklearn 实测最优阈值是 **0.03**，相差 5.6 倍。官方文字 "1/5 of the cost ratio" 我也无法解释成 0.1667。**最可能的原因是模型概率未校准**（官方表述的前提是 *"given that our model is calibrated"*）。**阙疑若要引用这个例子，必须同时说明"理论阈值与实测最优阈值可以差一个数量级，原因是校准"。**

**信用卡欺诈数据集（OpenML `data_id=1597`）实例**：
- 样本 **284,807** 条，**30** 列；欺诈 **492** 条，占 **0.17%**。
- 业务收益对比：全部接受基线 **221,445.07€**；全部拒绝基线 **−698,490.00€**；逻辑回归默认阈值 **244,919.87€**；调优阈值 **0.03** 时 **249,433.39€**。
- **注意**：调优阈值（0.03）在**两个完全不同的数据集**上都出现了——这提示"最优阈值远低于 0.5"在不平衡数据上是常态。

### 五、ROC vs PR：为什么阙疑应该用 PR

**Saito & Rehmsmeier 2015（*PLoS ONE* 10(3): e0118432，DOI 10.1371/journal.pone.0118432）逐字**：*"We show here that the visual interpretability of ROC plots in the context of imbalanced datasets can be deceptive with respect to conclusions about the reliability of classification performance."*

**具体机制（可直接写进论文）**：
- ROC 的横轴是 **FPR = FP/(FP+TN)**，分母是**负类总数**。当负类极多时，**即使 FP 的绝对数量很大，FPR 仍然很小**，ROC 曲线看起来很好。
- PR 的横轴是 **Recall = TP/(TP+FN)**，纵轴是 **Precision = TP/(TP+FP)**，**分母含 FP 的绝对数量**，因此对假阳性更敏感。

**对阙疑的三层含义**：
1. **外部 corpus C 层检出 0%** → 此时 $TP=0$，$TP+FP=0$（若系统在该层零命中）⇒ **Precision 未定义**（见方向 45）。ROC 上这个点会被画成 (0,0) 或 (0,1)，**看起来像是"保守"，实际上是"无信息"**。**PR 曲线上无定义的点无法被误读。**
2. **A 层 54.2% / B 层 12.5% / C 层 0%** 这种层间差异极大的情形，**合并成一条 ROC 会掩盖层间差异**，而分层 PR 曲线能直接显示。
3. **阙疑的样本量太小**（每层 10–40 条），**ROC 的经验曲线在这么小的样本下由少数几个点决定**，AUC 的置信区间会非常宽（用 bootstrap 或 Hanley–McNeil 方法算）。**此时报告"原始计数 + PR"比报告"AUC = 0.xx"诚实得多。**
