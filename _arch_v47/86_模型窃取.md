# 方向 86：模型窃取/提取攻击（Model Stealing / Extraction）

> 子主题：攻击者通过 API 查询重建受害模型的参数或功能（query-based extraction、path-finding / recovery attacks）；若阙疑的某些判据以模型 API 形式暴露，如何被窃取复刻；防御（查询节流、水印、API 限制、输出加噪）；对"验证系统知识产权"的启示。
> 说明：本文件中"path-finding attack"按学界通行理解映射为**恢复/方程求解类攻击（recovery / equation-solving attacks）**——即以最小查询量精确重建模型内部结构（决策路径、权重、边界），而非仅做近似克隆。该命名在盲区内说明。

---

## 核心结论

1. **基于查询的提取攻击在真实商业 API 上已被实证可行且极廉价。** Tramèr 等人在 USENIX Security 2016 对 Amazon 与 BigML 的预测 API 发起攻击，仅用 **650–4,013 次查询**即提取出与受害者**100% 等效（100% equivalent）**的模型；对逻辑回归甚至只需 **d+1 次查询**（d 为特征维），在 Google 平台成本 **低于 $0.10**。这意味着"只要把判决逻辑挂在 API 后面就安全"是一个已被证伪的假设。

2. **即便大规模生产级模型（GPT-3.5、PaLM-2、商业 MLaaS）也可被部分或功能性窃取。** Carlini 等（ICML 2024）仅凭公开 API 查询就恢复了 GPT-3 Ada/Babbage 的**整个最后一层**、反推出隐藏维度，成本仅**数百到数千美元**；CloudLeak（NDSS 2020）对 Microsoft、Face++、IBM、Google、Clarifai 五个商业平台的大规模 DNN 实现近完美功能克隆；Model Leeching（2023）以 **$50、48 小时、10 万次查询**从 ChatGPT-3.5-Turbo 提取出 **73% Exact-Match 相似度**的模型。API 设计上的微小疏漏（如暴露 `logit_bias`）即可成为致命入口。

3. **对阙疑而言，确定性的规则系统比神经网络"更"易提取，且单一防御层必然失效，必须分层。** 阙疑的核心是 **67 条规则（block 44 / warn 16 / advice 7）+ 9 个保护器 + 四态判决**，本质是离散分段（piecewise）确定性逻辑。Tramèr 对决策树做过**精确路径提取（exact paths）**，仅 1,150 次查询即 100% 等效——而神经网络尚需数万至数百万查询。若阙疑把判决以 API 形式暴露，理论上可在数千查询内被逐路径重建。防御须叠加**查询侧检测（PRADA，0 误报）+ 输出加噪（校准扰动降低 48% 提取精度）+ 水印溯源（Jia 2021 以 <100 次查询 95% 置信确权）+ 访问控制**，任何单层都无法独立抵御。这直接支撑阙疑"验证系统知识产权"的论文卖点：用 Merkle checkpoint / 哈希链给判决注入**可确权水印**，使被复刻输出可被溯源。

## 精确数字与案例

### 一、奠基性证据：Tramèr 等《Stealing Machine Learning Models via Prediction APIs》（USENIX Security 2016）

这是模型提取攻击的奠基文献，明确把"预测 API 既是访问控制又是信息泄漏面"这一张力形式化。论文 Table 1 报告了对真实 ML 服务的提取攻击精确查询数：

| 服务商 | 模型类型 | 数据集 | 提取所需查询数 | 攻击耗时(s) | 等效度 |
|---|---|---|---|---|---|
| Amazon | Logistic Regression | Digits | **650** | 70 | 100% |
| Amazon | Logistic Regression | Adult | **1,485** | 149 | 100% |
| BigML | Decision Tree | German Credit | **1,150** | 631 | 100% |
| BigML | Decision Tree | Steak Survey | **4,013** | 2,088 | 100% |

逐字引文（来自论文 Table 1 标题与正文）：
> "For each target model, we report the number of prediction queries made to the ML API in an attack that extracts a 100% equivalent model. The attack time is primarily influenced by the service's prediction latency (≈100ms/query for Amazon and ≈500ms/query for BigML)."

> "For both services, we show computationally fast attacks that use a small number of queries to extract models matching the targets on **100% of tested inputs**."

> "In some cases, our attacks extract the exact parameters of the target (e.g., the coefficients of a linear classifier or the **paths of a decision tree**)."

对阙疑最关键的引文（决策树路径提取，即"path-finding"的本源）：
> "Our attacks (Algorithm 1 and the top-down variant) extract an exact description of the tree's paths, using respectively 1,722 and 1,150 queries. ... a user who wishes to make more than 1,150 predictions has economic incentives to run an extraction attack."

> "For these models [logistic regression], the attack requires only 41 queries on average, and 113 at most. On Google's platform for example, an extraction attack would cost less than $0.10."

**对阙疑的映射**：阙疑的 9 个保护器与大量 block/warn 规则可视为一组"决策路径"。Tramèr 证明离散分段模型可被**精确**重建（不仅是近似），而阙疑的确定性（同输入必同输出）使攻击者无需处理概率噪声，提取难度低于神经网络。

### 二、高保真/精确恢复：Jagielski 等《High Accuracy and High Fidelity Extraction of Neural Networks》（USENIX Security 2020）与方程求解

这类攻击（recovery / equation-solving）旨在恢复**权重级**保真度，而非仅功能近似。论文在双层 ReLU 全连接网络上实现：

| 参数量 | 测试集保真度（与受害模型一致率） | 查询次数 |
|---|---|---|
| 12,500 | **100%** | 2^17.2 ≈ 140,000 |
| 25,000 | **100%** | 2^18.2 |
| 50,000 | **100%** | 2^19.2 |
| 100,000 | **99.98%** | 2^20.2 |

逐字引文：
> "For smaller networks, we achieve 100% fidelity on the test set: every single one of the 10,000 test examples is predicted the same."

> "we achieve 100% test set agreement on models with fewer than 200,000 parameters and greater than 99% test set agreement on larger models."

权重精度（与侧信道攻击对比）：
> "we are able to achieve an average error in the first weight matrix for a similarly sized neural network of just 0.0000009—over two thousand times more precise."

论文同时指出**纯学习法（替代模型训练）无法达到高保真**：即便固定初始化与 SGD 随机性，Fashion-MNIST 上保真度峰值仅 **93.7%**。这区分了两类攻击目标——**accuracy（好用）** vs **fidelity（逐位一致）**，对"知识产权"论证很重要：攻击者即便只求功能克隆（accuracy），也已足以无偿复用受害者的能力。

**对阙疑的映射**：阙疑若未来引入任何基于梯度的判决器（如用 NN 给"边界情形"打分），则面临权重级恢复风险；即便只暴露四态判决标签（hard-label），最新研究已证明**硬标签条件下**也能以极少查询做高效提取（见盲区）。

### 三、规模化与产品化：CloudLeak、Knockoff Nets、Model Leeching、Carlini 2024

**（1）CloudLeak（Yu 等，NDSS 2020）**——首个针对大规模商业 DNN 的黑盒提取。论文在 **Microsoft、Face++、IBM、Google、Clarifai** 五个商业 MLaaS 平台上验证，结合主动学习（active learning）、迁移学习（transfer learning）与对抗样本（FeatureFool）显著降低查询量。逐字引文（来自论文摘要与引言）：
> "Our results demonstrate that the proposed method can easily reveal/steal large-scale DNN models from these cloud platforms."

> "an adversary can use our attack framework to construct a free version of the victim model which bypasses the monetary costs involved in collecting data and training models."

**（2）Knockoff Nets（Orekondy 等，CVPR 2019）**——功能窃取（functionality stealing）。攻击者不知训练数据、不知模型内部、不知输出语义，仅凭"图进、预测出"黑盒交互即可克隆。论文明确给出成本下限：
> "We validate model functionality stealing on a range of datasets and tasks, as well as on a popular image analysis API where we **create a reasonable knockoff for as little as $30**."

**（3）Model Leeching（Birch 等，2023，arXiv:2309.10544）**——针对 LLM 的提取。用 SQuAD 数据自动向 ChatGPT-3.5-Turbo 打标签，再以小约 100 倍的 Roberta-Large 训练替代模型：
- 总样例 **100,000**，成功收集 **83,335**（错误率 16.66%）；
- 查询耗时 **48 小时**，成本 **$50**；
- 达到 **73% Exact-Match 相似度**，SQuAD EM/F1 = **75% / 87%**；
- 对抗攻击可迁移性提升 **11%**。

逐字引文（摘要）：
> "achieving 73% Exact Match (EM) similarity, and SQuAD EM and F1 accuracy scores of 75% and 87%, respectively for only $50 in API cost."

**（4）Carlini 等《Stealing Part of a Production Language Model》（ICML 2024）**——生产级语言模型的部分精确窃取。作者（含 OpenAI、Google DeepMind 成员）凭公开 API 恢复了 GPT-3 Ada/Babbage 的**整个最后一层**并反推出隐藏维度（如 ChatGPT 规模）：
> "Our attack recovers one layer of the model (the final layer) for a few hundred or a few thousand US dollars (depending on the layer's size...). Our attack also allows us to reverse-engineer the hidden dimension of these models, e.g., we learn the size of ChatGPT."

> "Our attack worked because (and only because!) a few model providers made the logit bias parameter available. Model providers (like Anthropic) who did not provide such an API were not vulnerable to this attack."

该案例给出对阙疑最尖锐的启示：**API 设计的一个微小决定（是否暴露某个字段/精度）就决定系统可被攻破与否**。防御手段是"限制同时发送 logprobs 与 logit_bias 的查询能力"。

### 四、防御与知识产权：检测、输出扰动、水印

**（1）查询侧检测：PRADA（Juuti 等，IEEE EuroS&P 2019，arXiv:1805.02628）**——首个通用提取攻击检测器。它分析连续 API 查询的分布，偏离良性行为即告警。论文原话：
> "We show that PRADA can detect all prior model extraction attacks with no false positives."

论文的新攻击本身相比 SOTA 在对抗样本可迁移性上提升 **+29–44 个百分点**、预测精度提升 **+46 个百分点**。PRADA 的核心统计量是"查询向量到训练分布的距离"——真实用户查询呈自然分布，提取者会密集采样低置信度/决策边界区域。

**（2）输出加噪 / 校准扰动（Guo 等，2023，arXiv:2308.00958）**——对输出分布加校准噪声。业界综述（securetom 指南，二次来源）报告其"实现 **48% 的提取精度下降**而维持合法可用性"，但强调"激进扰动会损害合法用途"。这对应阙疑可做的"对边界判决加 ±ε 扰动 / 截断为粗粒度四态"。

**（3）水印与所有权验证（知识产权核心）**——这是阙疑"验证系统知识产权"最直接的对标技术：
- **Uchida 等（2017，arXiv:1701.04082）《Embedding Watermarks into Deep Neural Networks》**：首次提出 DNN 所有权授权水印。
- **Adi 等（2018，USENIX Security 2018）《Turning Your Weakness Into a Strength: Watermarking Deep Neural Networks by Backdooring》**：通过后门注入水印，使被窃模型仍可被确权。
- **Jia 等（2021，USENIX Security，arXiv:2002.12200）纠缠水印**：以**少于 100 次查询**对疑似被窃副本达到 **95% 置信度**的所有权确认，性能代价低于 **0.81 个百分点**。

**（4）系统级防御分类（Survey 2508.15031，2025/2026）**将防御归为四大类：①攻击检测（含查询监控/节流）；②所有权验证（水印/指纹）；③攻击预防（数据扰动/模型修改/访问控制/对抗训练）；④组合防御。并给出成本量化：线性模型精确参数恢复仅需 **1–4 次查询/参数**，含 2^10 参数的模型恢复通常需 **3^12 次查询/参数**，元模型训练攻击约需 **40 GPU days**。

| 防御层 | 代表工作 | 量化效果 | 阙疑可落地形式 |
|---|---|---|---|
| 查询检测 | PRADA (2019) | 0 误报，检测全部已知攻击 | 监控判决 API 查询分布（马氏距离偏离 4σ 告警） |
| 输出扰动 | Guo (2023) | 提取精度 −48% | 边界判决加 ±ε / 截断四态 |
| 水印确权 | Jia (2021) | <100 查询、95% 置信 | 每条判决附 Merkle 根 HMAC canary |
| 访问控制 | Carlini 缓解 (2024) | 提高攻击成本 | 不暴露中间置信/日志字段 |

## 对阙疑的 3 条具体行动

1. **为判决 API 注入"裁决水印"字段（所有权验证层）。** 在 `gate_engine.py`（当前 3,826 行）的判决输出结构中新增可逆字段 `verdict_canary`：对每条四态判决附带基于 Merkle checkpoint 根的 HMAC 签名（复用现有 452 条判决账本 + 哈希链机制）。这样任何被复刻的 API 输出在溯源时都能被确权，直接服务论文"验证系统知识产权"卖点。时间点：**2027-05 之前**完成字段定义与 9 个保护器的最小覆盖；写入 `_arch_v47/` 下的威胁模型小节 `T-extract.md`。

2. **为任何拟对外暴露的判决 API 配置"查询节流 + 输出加噪"双层（访问控制 + 输出扰动层）。** 新建 `api_config.yaml`（置于 `_arch_v47/` 或项目根配置目录），明确：单账号每日查询上限 **≤10,000 次**、单接口每秒 **≤50 请求**；对边界/低置信判决**截断为粗粒度四态**并加 **±ε 扰动**（参考 PRADA 与 Guo 2023 的"校准扰动"思路，避免激进扰动损害合法对账用途）；**不暴露**中间置信度或日志字段（对标 Carlini 2024 中 `logit_bias` 教训）。时间点：**在第一次公开 demo/API 之前**必须上线。

3. **在 NeurIPS 2027 E&D 投稿的 threat-model 章节新增"确定性规则系统的可提取性"小节。** 引用 Tramèr 2016 决策树精确路径提取（**1,150 次查询、100% 等效**）与 Jagielski 2020（ReLU 网络 **100% 保真**），论证：阙疑的 67 条规则 + 9 个保护器因确定性、离散分段，若以 API 暴露，理论上**可在数千查询内被逐路径重建**，风险高于神经网络；并据此把"盲态协议不可回盲 + 哈希链溯源 + 判决水印"定位为**针对提取攻击的知识产权防护贡献**，而非仅复算正确性贡献。提交节点：**2027-09 投稿前**完成该小节与可复现实验（构造一个合成"规则 API"演示 1,150 查询级提取，作为 negative-result / 压力测试证据，契合 E&D Track 定位）。

## 盲区（诚实标注）

- **"path-finding attack"命名无单一权威文献对应**：英文检索未命中以《Path Finding Attacks on ML Models》为 exact-title 的奠基论文。本文件将其映射为 **recovery / equation-solving 攻击族**（精确重建决策路径/权重），并以 Tramèr 的决策树路径提取 + Jagielski 的权重恢复作为实证依据。若审稿人特指某一具体论文（如基于决策边界轨迹逼近的 ADBA，arXiv:2406.04998），需补查——**该具体论文的提取查询数未核实**。

- **CloudLeak 的精确查询缩减倍数未核实**：论文摘要宣称用主动学习"显著减少查询数"，但本文件未打开全文取得"较基线减少百分之多少"的精确数字，仅确认其攻击了 5 个商业平台。该量化值标为**未核实**。

- **Carlini 2024 隐藏维度具体数值未公开**：论文因负责任披露协议**未公布** GPT-3.5-turbo-chat 的真实隐藏维度，仅确认"恢复值经 OpenAI 确认正确"。故阙疑不可引用具体维度数字。

- **Survey 2508.15031 的汇总统计截断**：所抓取的 HTML 文本未包含"调研论文总数"与"各防御胜率百分比"的汇总表，仅给出分类法与个别技术查询复杂度（1–4 queries/param、40 GPU days）。整体计量数字标为**未核实**。

- **Model Leeching 的 73% 是功能近似而非全模型克隆**：该数字基于 SQuAD QA 任务、用比 ChatGPT-3.5 小约 100 倍的 Roberta-Large 作替代模型，仅说明"能力可被廉价近似复用"，不代表权重级窃取。引用时须避免夸大为"完整复制"。

- **阙疑当前并无真实公开判决 API**：本方向威胁是**前瞻性（prospective）**的——项目现有 37 实卡 / 452 条账本均为本地资产。因此"被窃取"是假设场景，行动 2/3 应在 API 真正暴露前落地，而非事后补救。

- **部分防御数字来自二次/行业来源**：输出扰动"−48%"与 Jia 2021"95%/<100 查询"取自 securetom 行业指南（非同行评审原文），虽其引用了 arXiv 原始编号（2308.00958、2002.12200），但精确数字建议投稿前回查原论文核实。

- **样本与方法偏差**：绝大多数提取攻击实证集中在图像分类（CIFAR/ImageNet）、QA 与逻辑回归/决策树；针对**规则引擎 / 形式化验证系统**的提取攻击研究稀少（本文件据"离散分段模型更易精确恢复"做外推，属推理而非已实证结论）。
