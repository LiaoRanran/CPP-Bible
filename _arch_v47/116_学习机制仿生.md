# 方向116：学习机制仿生——规则如何从452条案例中学习而不被自家变异体欺骗

## 一、问题定位：阙疑需要"学习"，但什么才算真学习

阙疑verifier的演进叙事是一条学习曲线：从37张实卡、67条规则、9个保护器、452条 append-only 账本记录出发，在30条盲测 holdout（含17条真错）上检出率66.7%，在40条外部 corpus 上检出率43.8%；变异测试 core 97.3%/all 81.5%；反事实测试 P=R=F1=0。最后一个数字是本篇的起点：一个"学习成绩"看起来很高、但在干预性问题上精确率、召回率、F1 全部为零的系统，到底学到了什么？答案是：它可能只学到了相关性，没有学到因果；可能只记住了自家变异体的模式，没有形成对真实错误的泛化识别。

学习科学为区分"真学习"和"伪学习"提供了丰富的参照系：Hebb 的共同放电假说给出了最朴素的联想学习规则；多巴胺奖赏预测误差给出了"惊奇度驱动更新"的定量理论；稀疏编码与预测编码刻画了无监督地从输入统计中建立内部模型的方式；反馈对齐与三因子学习法则则试图解释大脑在只有局部信息和全局广播调制信号的条件下如何完成信用分配。本篇梳理这些机制，并用至少三分之一的篇幅回答阙疑最实际的问题：规则更新如何设计误差信号、如何设计奖赏、如何避免刷分。方向115讨论记忆架构，本篇讨论"导致突触（规则）改变的算法"。

## 二、学习机制的九条核心事实

**1. Hebb 共同放电（1949）。** Hebb 在 1949 年《The Organization of Behavior》中提出著名公设：当一个神经元反复参与激活另一个神经元，二者之间的连接效率增强——通俗表述即"一起放电的细胞连在一起"（cells that fire together wire together）[1]。这是纯局部、无监督的规则：只依赖突触前与突触后同时可观测的活动，不需要外部标签。现代 STDP（Markram 等1997、Bi 与 Poo 1998）为其加入精确时序：突触前领先突触后数毫秒则增强，反序则减弱。Hebbian 学习的固有风险是正反馈失控，故生物系统还配有 Oja 归一化、突触缩放等稳态机制。

**2. 多巴胺奖赏预测误差（Schultz 等1997）。** Schultz、Dayan 与 Montague 1997 年在 *Science*（275卷5306期，1593–1599页）提出灵长类中脑多巴胺神经元的活动可以用时序差分（TD）学习中的奖赏预测误差解释：意外奖赏引发簇状放电；奖赏完全被线索预测时神经元在奖赏时刻静默、而在线索时刻放电；预期奖赏被取消则在预期时刻放电率显著下抑[2]。学习由"实际−预期"的误差 δ 驱动，完全可预测的事件不再产生学习——这同时解释了 Kamin 1960 年代发现的 blocking 现象：已能预测结果的线索会阻止新线索建立联想。Steinberg 等2013年用光遗传学在 blocking 范式中直接施加多巴胺脉冲，成功"解锁"学习，为该理论提供了因果证据[11]。

**3. 稀疏编码（Olshausen & Field 1996）。** Olshausen 与 Field 1996 年在 *Nature*（381卷，607–609页）证明：在自然图像上仅以"稀疏性"为约束学习线性编码，得到的基函数自发呈现类似初级视皮层 V1 简单细胞的局部化、朝向选择性感受野[3]。1997年他们在 *Vision Research* 把模型扩展到过完备字典。Vinje 与 Gallant 2000 年在 *Science* 用清醒猕猴 V1 单细胞记录证实自然视觉下的稀疏编码与去相关。稀疏性的功能含义是：任何时刻只有少数单元活跃，表征能量高效、特征间干扰低。

**4. 预测编码（Rao & Ballard 1999）。** Rao 与 Ballard 1999 年在 *Nature Neuroscience*（2卷1期，79–87页）提出层级预测编码模型：高层向低层传送预测，低层只把预测与实际活动的误差（prediction error）向上回送，系统以最小化层级误差为目标[4]。该框架为视觉中的 end-stopping 等非经典感受野效应提供了功能解释，并后来与自由能原理、主动推理相贯通。其架构要害是"预测"与"误差"双通道分离。

**5. 反馈对齐（Lillicrap 等2016）。** Lillicrap、Cownden、Tweed 与 Akerman 2016 年在 *Nature Communications*（7:13276）证明：反向传播不要求误差通路严格使用前馈权重的转置——用固定的随机反馈矩阵传递误差，网络仍能学习；学习过程中前馈权重会自发与随机反馈对齐，使近似梯度与真实梯度方向相关[5]。这回应了 Grossberg 1987 年提出的权重传输问题（weight transport problem）：真实神经元没有任何机制让一条反向突触精确镜像前馈权重，故经典 BP 长期被质疑生物学不可信。Nøkland 2016 年提出直接反馈对齐（DFA），把误差直接送到各层。

**6. 三因子学习法则。** Frémaux 与 Gerstner 2016 年在 *Frontiers in Neural Circuits*（9:85）系统化了新 Hebbian 三因子框架：突触改变 = 突触前活动 × 突触后变量 × 神经调制第三因子[6]。前两个因子是局部 Hebbian 项，只设置"资格痕迹"（eligibility trace，一个短时有效的标记）；第三因子（多巴胺表奖赏、乙酰胆碱表新颖、去甲肾上腺素表意外）在痕迹有效期内到达才真正改写权重。Gerstner 等2018年综述了资格痕迹在纹状体、皮层、海马突触上的实验证据[7]。三因子结构解释了全局广播的低维调制信号如何驱动海量局部突触的选择性更新。

**7. 关键期（Hubel 与 Wiesel）。** Hubel 与 Wiesel 1960–70年代在猫和猴上发现视觉系统存在发育关键期：眼优势柱的可塑性只在出生后一段窗口内最高，关键期内剥夺单眼视觉会造成不可逆的皮层重塑；他们因此获1981年诺贝尔奖[9]。工程含义是：系统早期的结构选择决定后期可塑性空间。

**8. 睡眠中学习。** Wilson 与 McNaughton 1994 年在 *Science* 报告海马位置细胞在睡眠中重放白天活动序列[10]；离线重放被认为服务于巩固与泛化（另见方向115）。

**9. BP 的生物学合理性争议。** 除权重传输外，经典 BP 还被质疑：神经元如何在生物学上实现连续可微、误差信号在真实皮层回路中以什么载体传播。Marblestone、Wayne 与 Kording 2016 年在 *Frontiers in Computational Neuroscience* 提出折中框架：大脑可能在多样化的成本函数和预制结构中做优化，多种信用分配机制（预测编码、反馈对齐、树突误差编码）可以与神经回路相容[8]。

## 三、对阙疑的具体映射（本篇核心）

**映射1：规则从账本案例"学习"= Hebbian 共现 + 巩固门，而非逐条记忆。** 反复在同类案例上触发的模式才沉淀为规则，正是 Hebbian 思想：案例特征与错误后果在多次判决中共同出现，候选规则的置信度上升。但必须为正反馈装上稳态机制——规则不能因为命中自己生成的变异体就不断自我增强。工程上对应两道门：一是方向115的巩固期（静置、多源复现）；二是规则置信度的更新只接受带外标签（人工标注的真错、编译器/sanitizer 实证）驱动，拒绝"系统输出再当标签"的回路，那等价于没有外部钳制的 Hebbian 网络，必然漂移或锁死。

**映射2：变异测试 core 97.3% 是"自家训练场成绩"，要警惕只学会识别自家变异体。** 变异体由项目自己的生成器按已知规则反向构造，它们与规则共享同一组模式先验；在它们上得高分，类似学生刷自己出的卷子——考的是"生成器与检测器的一致性"，不是真实错误识别能力。外部 corpus 43.8% 与反事实 P=R=F1=0 已经给出反证：一旦材料偏离生成器分布，成绩骤降。对应行动是把变异体定位为"回归测试"（保证规则不退化）而非"能力评测"；能力分必须锚定在17条人工真错和持续扩容的外部真实缺陷上，并在论文中分层报告这两类数字，禁止合并平均。

**映射3：预测误差 → 判决与证据不一致信号。** 预测编码双通道可以直接实现：规则对代码给出预期（如"此处应触发 UB 告警/应当编译失败"），独立通道采集实测（编译器矩阵、ASan/UBSan、运行结果），二者的不一致即预测误差，向上汇聚而不是被多数票掩盖。这比让规则直接输出结论更可靠，因为它把"可错的预期"和"独立的实测"分轨记录（与方向64的 append-only 事件互锁：预期事件与实测事件分别落盘，差异事件追加而非覆盖）。长期高误差的规则自动进入复审队列——预测误差既驱动单次告警，也驱动规则修订。

**映射4：奖赏信号设计——检出真错给奖，刷变异分不给奖。** 多巴胺 RPE 的精髓是奖励"超出预期"，而对完全可预测事件零响应。阙疑的奖赏函数必须据此设计：在盲 holdout/外部真实缺陷上每检出一条新的真错（尤其是规则此前预期不到的错误类型）给高权重奖赏；在自家变异体上的命中只给低权重回归分（建议占综合指标不超过约30%）；而对"把正确代码误报为错"设置强负奖赏（见方向117的自身免疫成本）。RPE 还要求显式维护规则的预期基线：一条总在报警的规则即使命中率高也不再获奖赏增量——这抑制"什么都报"的策略。blocking 的警示同样适用：若旧规则已能解释某案例，新增一条几乎重复的规则不应得到信用。

**映射5：反事实 P=R=F1=0 = 系统没有因果学习能力。** 反事实测试问的是干预下的问题（"若改这一处，错误是否消失"），它要求的不是模式匹配而是因果模型；全零成绩说明67条规则学到的是输入特征与判决标签的关联（association），而非干预—结果的因果结构。这一结论必须诚实写进论文，同时给出修复路线：构造最小对照对（语义保持变换 vs 植入真实错的版本）让规则在配对差异上学习，用"do(x) 前后判决是否翻转"作为新评测——从相关性学习迈向因果性学习的第一块跳板。

**映射6：稀疏编码 → 规则应稀疏、分层触发。** 健康的规则库应像 V1 一样：任一代码片段只激活少数高相关规则。应统计67条规则的触发率分布：对"什么都触发"的低信息量规则合并或降级，对触发率极高但从无实证支持的规则标记为冗余；把报告预算集中给稀疏但高精度的告警，误报疲劳正是嵌入式工程现场用户关闭告警的首要原因。

**映射7：反馈对齐与三因子 → 规则更新可以局部，误差与奖赏可以全局广播。** 阙疑不需要一条贯穿全部规则的精确微分链：单条规则可按本地证据（该案例的输入与实测）做 Hebbian 式调整，而全局误差信号（holdout 检出变化、对账差异）与全局奖赏（真错检出）像神经调制信号一样广播，由各规则的资格窗口决定是否采纳。这与单人可维护的代码规模匹配：简单、局部、可审计，优于模仿深度网络的复杂更新管道。

**映射8：关键期 → 2026–2027 正是规则库结构定型窗口。** 早期写入的规则组织方式（四态判决、事件 schema、规则—证据关系）会像眼优势柱一样固化；趁现在只有67条规则、3826行内核时把接口改对，成本远低于规则过百后的回炉。

## 四、失败模式与边界

第一，所有生物学习机制都服务于有机体适应性而非事实正确性，联想记忆天然接受迷信学习（偶发共现被当成因果）——这恰是反事实零分的生物对应。第二，Hebbian/STDP 无监督规则不能直接提供"什么是真错"的标签，第三因子（外部奖赏）不可或缺。第三，反馈对齐在现代深度/卷积/注意力结构上的扩展性仍有争议，不能因其在小网络成功就外推。第四，SM/奖赏权重（如变异分30%）是工程设定而非实证最优，需用消融实验校准。第五，关键期与睡眠学习是发育/系统级现象，对软件组织只有隐喻级指导。

## 五、对阙疑的三条具体行动、盲区与来源

**对阙疑的三条具体行动：**

1. **2026-12 前**，上线"预测—实测"双通道：每次判决先落盘规则预期事件、再落盘编译器/sanitizer 实测事件，自动汇总不一致信号；同时重订指标权重——holdout/外部真错检出占≥70%、变异体回归分≤30%，误报计入负分。
2. **2027-02 前**，构建"反事实2.0"对照集（不少于60对：同一段代码的语义保持变换版与真实错植入版配对），先登记规则预测再揭盲，目标反事实 P/R/F1 从 0 提升至 0.3 以上，并按配对差异驱动规则修订。
3. **2027-04 前**，完成规则稀疏化审计：统计67条规则触发率与单位告警信息量，合并/下线高触发低实证规则，使任一样例平均触发规则数下降而 holdout 检出率不低于66.7%基线。

**盲区：**

1. 三因子、反馈对齐在生物神经元上的证据仍在快速更新，本文映射为架构启发，不代表阙疑实现了等价机制。
2. 70/30 的奖赏权重无文献直接支撑，属先验设定，需2027年消融数据修正。
3. 反事实对照集若仍由自家生成器构造，可能重蹈变异体过拟合覆辙；真实 CVE 配对样本的获取能力未知。
4. 稀疏化阈值在小样本上选择敏感，过度稀疏可能压低本就不高的外部召回。
5. 多巴胺 RPE 的单胺神经元模型本身尚有争议（如多巴胺是否同时编码显著性），类比精度有限。
