# 方向 45：缺失数据处理方法——MCAR/MAR/MNAR、删除 vs 插补，以及"全无命中"的正确处置

## 核心结论

1. **"缺失率多少算危险"这个问题在方法学上已被明确否定，官方答案是"缺失率不是判据，FMI 才是"。** Madley-Dowd, Hughes, Tilling, Heron 在 *Journal of Clinical Epidemiology* **110: 63–73**（2019-06）的模拟研究结论逐字为：*"Provided sufficient auxiliary information was available; MI was beneficial in terms of bias and never detrimental in terms of efficiency… In the absence of bias, the FMI was a better guide to the efficiency gains using MI than the proportion of missing data."* 更直白的：*"for MAR data, valid MI reduces bias even when the proportion of missingness is large."* 丹麦统计局研究指南（2026-09-26 更新）也写死：*"There is no real percentage threshold (5% / 10% / 40% are rules of thumb with no foundation). What matters is the mechanism and how well the missing values can be predicted from the rest."* 因此阙疑论文里**绝不能**写"缺失率低于 X% 所以安全"这种句子——那是会被方法学审稿人直接抓住的。

2. **MAR 假设在数据里不可检验，Little's MCAR 检验只能"拒绝 MCAR"、不能"证明 MCAR"。** 缺失机制三分类来自 Rubin 1976（*Biometrika* **63(3): 581–592**，DOI 10.1093/biomet/63.3.581）。Little（1988，*JASA* **83: 1198–1202**，DOI 10.2307/2290157）提出的 MCAR 检验统计量服从自由度 $\sum_j k_j - k$ 的卡方分布，但 R 包 `misty::na.test` 文档逐条列出**六个缺陷**，其中最要命的三条：(a) *"the test can only reject, but cannot prove the MCAR assumption"*；(b) *"simulation studies suggest that Little's MCAR test suffers from low statistical power, particularly when the number of variables that violate MCAR is small"*（Thoemmes & Enders 2007）；(c) *"MNAR cannot be ruled out regardless of the result of the test"*。**对阙疑的含义：任何"我们检验了 MCAR，p > 0.05，所以缺失可忽略"的写法都是错的。**

3. **"反事实算子 P = R = F1 = 0"不是缺失数据问题，是分母为零的退化问题，必须显式标记为"未定义"，不能插补、不能填 0。** scikit-learn 官方文档（1.9.1，`precision_score`）逐字：*"When `true positive + false positive == 0`, precision returns 0 and raises `UndefinedMetricWarning`. This behavior can be modified with `zero_division`."* 而 `zero_division` 的取值集合是 **{“warn”, 0.0, 1.0, np.nan}**，默认 `“warn”`（*"If set to 'warn', this acts like 0, but a warning is also raised"*），`np.nan` 选项在 **1.3 版本**才加入。也就是说：**sklearn 的默认行为是把"无预测正例"报告成 P = 0，这在语义上是错的**——"没有命中"不等于"命中率为零的完美错误"，它意味着该指标**无信息**。阙疑的反事实算子 P = R = F1 = 0 极可能就是踩了这个默认值，而不是模型真的差。

## 精确数字与案例

### 一、机制判定的精确定义与不可检验性

| 机制 | 形式化条件 | 能否从观测数据检验 |
|---|---|---|
| MCAR | $P(M \mid X_{obs}, X_{mis}) = P(M)$，缺失与任何变量（含自身）无关 | 只能**拒绝**，不能证明。Little's test 是唯一标准工具。 |
| MAR | $P(M \mid X_{obs}, X_{mis}) = P(M \mid X_{obs})$，缺失的原因**全部落在已观测变量里** | **不可检验**。丹麦统计局指南逐字：*"The assumption cannot be tested in the data, only judged on substantive grounds."* |
| MNAR | 缺失概率依赖 $X_{mis}$ 本身 | **不可检验**，只能做敏感性分析（见第四节）。 |

**Little's MCAR 检验的六个已知缺陷（`misty::na.test` 文档逐字，据 Enders 2010）**：

1. 不指明**哪些变量**违反 MCAR，也不识别缺失的相关变量（即无法给出辅助变量）。
2. 依赖多元正态；偏离正态时不可靠，且**不适用于分类变量**。
3. 只查均值差异、假设各缺失模式共享协方差阵，因此**检测不到基于协方差的 MAR/MNAR 偏离**（因为 MAR 和 MNAR 也能产生均值相等的子群）。
4. 功效低，尤其当违反 MCAR 的变量少、缺失与数据关系弱、或数据是 MNAR 时（Thoemmes & Enders 2007）。
5. **只能拒绝、不能证明**；不显著 ≠ MCAR。
6. 零假设下数据"实际是 MCAR 或 MNAR"，显著则说明是 MAR 或 MNAR，**无论结果如何都不能排除 MNAR**。

**工程实现注意**：`naniar::mcar_test` 与 `misty::na.test` 都基于 `norm::prelim.norm`，该函数**约 30 个变量**就会出数值问题；超过 30 个变量时文档建议改用 `LittleMCAR`（`BaylorEdPsych`，可到 50 变量），但**该包已被 CRAN 移除**，需从 archive 获取。这是一个真实的工程坑：**变量多的数据集上 Little's test 会静默给出不可信结果**。

### 二、"缺失率多少算危险"——三个可引用的具体口径

| 来源 | 口径 | 逐字 |
|---|---|---|
| Madley-Dowd et al., *J Clin Epidemiol* 110: 63–73, 2019 | 用 **FMI** 而非缺失比例作判据 | *"the FMI was a better guide to the efficiency gains using MI than the proportion of missing data"*；*"valid MI reduces bias even when the proportion of missingness is large"* |
| 丹麦统计局研究指南（2026-09-26） | **没有**百分比阈值；>40–50% 作敏感性/假设生成 | *"There is no real percentage threshold (5% / 10% / 40% are rules of thumb with no foundation)."*；*"treat results with high missingness (roughly >40-50% on a key variable) as sensitivity / hypothesis-generating, and run complete-case and mice side by side"* |
| Li, Raghunathan & Rubin 1991（经 van Buuren 教材转述） | **FMI 解读刻度** | FMI 到 **0.2** 为 "modest"（适度），**0.3** 为 "moderately large"（中等偏大），**0.5** 为 "high"（高） |

**对阙疑最直接可用的结论**：报告缺失情况时，写"缺失率 12%"没用；写"FMI = 0.31，属 moderately large；同时给出 complete-case 与 MI 两套结果，方向一致"才有说服力。

### 三、插补：MICE 的精确算法与必须报告的四个数字

**MICE = Multivariate Imputation by Chained Equations**（van Buuren & Groothuis-Oudshoorn, *Journal of Statistical Software* 45(3), 2011；R 包 `mice`，仓库 `github.com/amices/mice`，站点 `amices.org/mice`）。核心是 **FCS（Fully Conditional Specification）**：对每个含缺失的变量建一个回归模型，用其余变量预测它；缺失值不是填"最佳猜测"，而是**从预测分布里随机抽一个**——这就是 m 份数据集彼此不同的原因。"Chained"指逐变量轮转、每轮用上一轮刚填好的值。

**Rubin 规则（必须逐字写进论文）**：

- 合并估计：$\bar Q = \frac{1}{m}\sum_{\ell=1}^{m}\hat Q_\ell$
- 总方差：$T = \bar U + B + B/m = \bar U + (1 + 1/m)B$，其中 $\bar U$ 是组内方差均值，$B$ 是 m 个完全数据估计之间的方差。
- 三来源分解：$\bar U$（抽样）、$B$（缺失带来的额外方差）、$B/m$（**模拟误差**）。van Buuren 教材逐字警告：*"不包含该项将导致 p 值过低，或置信区间过短。"*

**FMI / RIV / RE 的精确公式（Book_MI 第 10 章，含数值示例）**：

| 量 | 公式 | 书中数值示例 |
|---|---|---|
| $\lambda$（FMI 的 lambda 版） | $\lambda = \dfrac{V_B + V_B/m}{V_T}$ | $= \dfrac{0.040027 + 0.040027/3}{0.849084} = 0.06283485$ |
| RIV（方差相对增量） | $\mathrm{RIV} = \dfrac{V_B + V_B/m}{V_W} = \dfrac{\lambda}{1-\lambda}$ | $= \dfrac{0.040027+0.040027/3}{0.7957147} = 0.06704779$ |
| FMI（自由度校正版） | $\mathrm{FMI} = \dfrac{\mathrm{RIV} + \frac{2}{df+3}}{1+\mathrm{RIV}}$ | SPSS 用 dfOld：**0.0665132**；R `mice` 用 dfAdjusted：**0.0797587** |
| RE（相对效率） | $\mathrm{RE} = \dfrac{1}{1 + \mathrm{FMI}/m}$ | $= \dfrac{1}{1+0.0665132/3} = 0.9783098$ |

**⚠️ 一个常见的命名陷阱（书中明确点名）**：*"文献中经常混淆 γ 与 λ，并错误地将 λ 标注为缺失信息比例。当 ν 较大时 λ 与 γ 几乎相同，但当 ν 较低时它们可能显著不同。"* 写论文时必须说清用的是哪一个。

**m 取多少**：van Buuren 教材第 2.3.2 节逐字：*"传统上 m 的选择为 m=3、m=5 和 m=10。目前的建议是将 m 设得更高，例如 m=50"*；*"m 越大，模拟误差对总方差的影响就越小。"* 丹麦统计局指南给的是操作性规则：*"at least as many as the percentage of rows with at least one gap (if e.g. 30% of rows are incomplete => set m around 30). Today 20-50 is typical"*。

### 四、MNAR 的敏感性分析：delta 调整 / pattern-mixture / tipping point

MNAR 不可检验，唯一诚实的做法是**敏感性分析**。标准工具是 **delta-adjustment**（pattern-mixture 框架）：先按 MAR 做 MI，再对缺失单元按"缺失者比观测者差 $\delta$"施加偏移，看 $\delta$ 多大时结论翻转（**tipping point analysis**）。检索到的方法学材料：delta 调整综述（PMC5860630，*"We review the delta-adjustment procedure and demonstrate how it can be used to assess sensitivity to departures from MAR"*）、SAS 实现的 tipping point 指南（`psiaims.github.io/CAMIS/SAS/tipping_point.html`）。**对阙疑**：如果某些知识卡是"因为太难所以没人标注"（即缺失依赖未观测的值），那就是 MNAR，必须做 $\delta$ 扫描并报告 tipping point，而不是假装 MAR。

### 五、"全无命中"（P = R = F1 = 0）的正确处置

这是本方向对阙疑**最可操作**的一节。

**问题的形式**：设混淆矩阵为 TP, FP, FN, TN。则
$$P = \frac{TP}{TP+FP},\quad R = \frac{TP}{TP+FN},\quad F_1 = \frac{2P R}{P+R}$$

- $TP + FN = 0$（**没有真错样本**，例如外部 corpus 某一层本来就没有缺陷）⇒ R 的分子分母都是 0 ⇒ R **未定义**（不是 0）。
- $TP + FP = 0$（**系统一个都没报**）⇒ P **未定义**。
- 两者同时为 0 ⇒ F1 **未定义**。

**sklearn 的实际行为（1.9.1 官方文档逐字）**：

> *"When `true positive + false positive == 0`, precision returns 0 and raises `UndefinedMetricWarning`. This behavior can be modified with `zero_division`."*
> `zero_division` **{“warn”, 0.0, 1.0, np.nan}, default=“warn”**；*"If set to 'warn', this acts like 0, but a warning is also raised."*；*"Added in version 1.3: `np.nan` option was added."*

官方示例直接展示了三档差异：

```python
y_true = [0, 1, 2, 0, 1, 2]; y_pred = [0, 0, 0, 0, 0, 0]
precision_score(y_true, y_pred, average=None)                      # array([0.33, 0.  , 0.  ])
precision_score(y_true, y_pred, average=None, zero_division=1)     # array([0.33, 1.  , 1.  ])
precision_score(y_true, y_pred, average=None, zero_division=np.nan)# array([0.33, nan, nan])
```

**同一个"什么都没预测"的分类器，P 可以是 0、可以是 1、可以是 NaN——完全取决于一个默认参数。** 这就是为什么阙疑的"P = R = F1 = 0"必须当成 bug 处理，而不是当成结果报告。

**建议的正确处置（按优先级）**：

1. **首选：报告原始计数 (TP, FP, FN, TN)，不用比率。** 比率在分母为零时无定义，计数永远有定义。论文表格里同时给计数与比率。
2. **次选：显式写"未定义 / undefined"，并注明原因**（"该层无真错样本" vs "系统该层零命中"）。这两者含义完全相反，绝不能都写 0。
3. **不要用 `zero_division=1` 把 P 刷成 1**——那是自欺。
4. **不要用 `zero_division=0`（默认）**——它把"无信息"伪装成"最差"。
5. **若必须给单个数**：报告**保守下界**，例如用 Clopper–Pearson 单侧下界（阙疑已有 `32_Clopper-Pearson精确计算.md`），并同时报告样本量 n；n 小时区间会很宽，这本身就是诚实的信息。
6. **报告"未定义率"**：例如"三层 corpus 中 1 层的指标未定义"，这比报告一个假数字更有信息量。

## 盲区（诚实标注）

- **Madley-Dowd et al. 2019 的具体模拟数字（各种缺失比例下的偏差量级）我没有拿到**。我读到的是 ScienceDirect 页面的摘要（Objectives / Results / Conclusion 三段），**正文的表格与数值一律未核实**。论文中若要引用具体偏差数字，必须重新取全文。
- **FMI 的解读刻度（0.2 / 0.3 / 0.5）是二手转述**：来自 van Buuren 教材经 WebFetch 模型摘要转述，原始出处标注为 "Li、Raghunathan 和 Rubin 1991"，但我**未核实该 1991 年文献的准确题名与页码**。
- **`misty::na.test` 的六个缺陷是 R 包文档的表述**，其原始依据是 Enders (2010) *Applied Missing Data Analysis* 与 Thoemmes & Enders (2007, AERA 会议论文)。**我未读到这两份原始文献**，因此"六条缺陷"应表述为"R 包文档归纳"，不要写成 Enders 的原话。
- **"van Buuren 第 2.8 节（How many imputations?）中基于 FMI 推导 m 的公式我没拿到**。WebFetch 只取到第 2.3 节，该节反复指向 2.8 节但未包含其内容。因此"m 与 FMI 的定量关系"**标为未核实**。
- **Danish 统计局指南是工程教程而非同行评审文献**，其 ">40–50%" 阈值是操作建议，不应作为论文中的方法学权威引用。
- **样本偏差**：本方向检索到的中文材料（CSDN、知乎、腾讯云）绝大多数是二手科普，**没有一篇可作为学术引用**；我仅用它们确认术语译名，未采信任何数字。
- **"反事实算子 P=R=F1=0 的成因"是我的推断**（推测踩了 sklearn 的 `zero_division` 默认值），**我没有看到阙疑的实际代码**，因此这只是最可能的解释，不是已确认的诊断。若实际原因是"该层确实无正样本"，则处置方式（应报未定义）相同，但修复位置不同。
