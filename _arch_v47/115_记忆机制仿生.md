# 方向115：记忆机制仿生——把452条账本作情景记忆、把67条规则作语义记忆

## 一、问题定位：验证系统首先是一个记忆系统

阙疑verifier面对的每一个 C++ 知识判决问题，本质上都是记忆问题：哪些具体案例被记住了（452条 append-only 账本记录），哪些抽象结论沉淀下来了（67条规则），记忆在陌生材料上能否被唤起（30条盲测 holdout 含17真错、检出率66.7%；40条外部 corpus、检出率43.8%），以及记忆是否会被污染（变异测试 core 97.3%/all 81.5%，反事实测试 P=R=F1=0）。系统的37张实卡、9个保护器、约3826行内核要在标准演进、编译器版本变化和对抗性输入下维持判断，等价于一个经典的记忆架构问题：感觉输入、短时工作区、长时存储应当如何分工，信息如何巩固，旧记忆何时失效，以及——最危险的——虚假记忆如何形成。

人脑用约1.3–1.4千克、功耗约20瓦的器官解决了同类问题，且其机制已被一百多年的实验反复刻画。本方向梳理记忆科学中被引用最坚实的八个结果，并将它们逐条映射到阙疑的账本、规则与评测设计；方向106（神经网络仿生）与113（脑科学与类脑计算）提供更广的神经计算背景，本篇专注"记忆"这一功能切面。

## 二、记忆科学的八个核心事实

**1. Atkinson–Shiffrin 三级记忆模型（1968）。** Atkinson 与 Shiffrin 1968 年在 *The Psychology of Learning and Motivation* 第2卷提出"模态模型"：环境信息先进入感觉记忆（sensory register，毫秒到约2秒，容量大、按感官通道分别保持），经注意选择进入短时存储（容量约 7±2 个组块，无复述时约保持15–30秒，以声学编码为主），经复述加工进入长时存储（容量与时长近乎无限，以语义编码为主）[1]。Miller 1956 年给出短时容量"7±2"的经典估计；Glanzer 与 Cunitz 1966 年用系列位置曲线（首因效应对应长时、近因效应对应短时）为双存储分离提供了行为证据。

**2. Baddeley 工作记忆模型（1974/2000）。** Baddeley 与 Hitch 1974 年把被动的"短时存储"改造成主动的多组件工作记忆：中央执行器（central executive，负责注意分配与调度）加两个从属系统——语音环（phonological loop，保持言语声音信息）和视空画板（visuo-spatial sketchpad，保持视觉与空间信息）[2]。Baddeley 2000 年在 *Trends in Cognitive Sciences*（4卷11期）补充第四个组件情景缓冲器（episodic buffer）：一个容量有限、临时整合多源信息、把工作记忆与长时情景记忆接通的接口[3]。

**3. 病人 HM：情景记忆与长时存储的脑基础。** Scoville 与 Milner 1957 年在 *Journal of Neurology, Neurosurgery & Psychiatry*（20卷1期）报告了 Henry Molaison（HM）：为治疗癫痫切除双侧内侧颞叶（含海马大部）后，他无法形成新的长时情景记忆（顺行性遗忘），但短时记忆保持正常，且程序性学习能力保留——术后仍能学会镜像描图等动作技能，尽管他不记得自己练过[4]。HM 于2008年去世，终生配合研究。这个案例确立了：短时与长时记忆、情景记忆与程序性记忆是可分离的不同系统，海马对情景记忆的巩固至关重要。

**4. LTP：记忆的突触候选机制。** Bliss 与 Lømo 1973 年在 *Journal of Physiology*（232卷2期，331–356页）报告：对麻醉兔海马齿状回传入纤维施加强直刺激后，突触传递效率显著增强并可持续数小时至数天——即长时程增强（LTP）[5]。Lømo 本人在1966年首先偶然观察到该现象。LTP 具备 Hebb 性质（突触前与突触后协同活动导致增强）、协同性与饱和性，被视为学习记忆在突触层面最主要的候选机制；晚近研究也强调其与记忆行为之间的对应仍非完全闭合。

**5. Ebbinghaus 遗忘曲线（1885）。** Ebbinghaus 1885 年出版《论记忆》（Über das Gedächtnis），以自己为唯一被试、记忆无意义音节（每列13个三字母组合），用"节省法"（重学比初学少花的时间比例）测量保持：20分钟约保持58.2%、1小时约44.2%、约9小时35.8%、1天33.7%、2天27.8%、6天25.4%、31天约21.1%[6][7]。曲线形态是先陡后缓的长尾；Murre 与 Dros 2015 年在 PLOS ONE 用现代条件复现了该结果。Ebbinghaus 更重要的发现是：每次及时复习都会把曲线斜率压平——这是间隔重复的科学源头。

**6. SM-2 与 Anki：间隔重复的工程化。** 波兰研究者 Piotr Woźniak 1987年12月写出第一个 SuperMemo 程序；其 SM-2 算法为每个项目设易度因子 EF（初始2.5，下限1.3），复习间隔 I(1)=1天、I(2)=6天、之后 I(n)=I(n−1)×EF；复习后按0–5分自评质量 q 更新 EF，公式 EF′=EF+(0.1−(5−q)(0.08+(5−q)×0.02))，q<3 则从头开始[8]。SM-2 被 Anki、Mnemosyne 等直接继承，是部署最广的复习调度算法。Cepeda 等2006年对184篇文献、317个实验的元分析显示，分散学习在几乎所有条件下优于集中学习约10%–30%[11]。

**7. 记忆巩固与睡眠重放。** Diekelmann 与 Born 2010 年在 *Nature Reviews Neuroscience*（11卷，114–126页）综述睡眠的记忆功能：慢波睡眠中海马与新皮层协同重放白天经验，使情景记忆逐步脱离海马、向新皮层做系统巩固；睡眠剥夺显著损害次日保持[9]。Wilson 与 McNaughton 1994 年在 *Science* 首次直接记录到睡眠中海马位置细胞的序列重放。

**8. Ramirez 等2013：植入虚假记忆。** Ramirez、Liu 等与 Tonegawa 2013 年在 *Science*（341卷6144期，387–391页）发表实验：用光遗传学标记小鼠海马齿状回中编码某一环境 A 的 engram（记忆痕迹）细胞并表达光敏感通道；随后在完全不同的环境 B 中施加足部电击、同时用光束重新激活 A 环境的 engram；此后小鼠被放回 A 环境时表现出显著僵住——电击从未在 A 发生，却形成了对 A 的恐惧虚假记忆[10]。关键警示是：虚假记忆与真实记忆在被回忆时调用的下游神经机制相同，主观确信无法区分二者。Josselyn 与 Tonegawa 2020 年在 *Science* 的综述将 engram 研究系统化。

## 三、对阙疑的具体映射（占本篇核心）

**映射1：452条账本 = 情景记忆，67条规则 = 语义记忆，二者必须分离存储。** 账本记录的是带时间、上下文（编译器版本、编译选项、规则版本、证据来源）的具体事件，正对应海马—内侧颞叶系统所保持的情景记忆；规则是从多次案例中抽象出去上下文的一般结论，对应新皮层中按意义组织的语义记忆。HM 的启示在此是架构性的：两类记忆物理上分离、更新路径分离——案例的大量增删不应直接改写规则；即使规则库全部回滚，账本仍应完整可读，反之亦然。若把规则直接写在案例上、或用案例表充当规则表，就等于让同一脑组织同时承担两种功能，一处损伤即全盘受损。

**映射2：holdout 与 corpus 评测 = 再认测试，66.7%与43.8%的差距是"迁移保持"差距。** 记忆研究区分自由回忆、线索回忆与再认，陌生材料上的表现才反映真实保持。30条盲 holdout 与系统训练材料同源、分布相近，对应"熟悉教室的考试"；40条外部 corpus 分布更远，43.8%的检出率说明系统记忆在跨语境提取时显著衰减。这一差距应在论文中按"近迁移/远迁移"如实报告，而不能用 66.7% 代表整体能力。更要警惕算术不自洽污染记忆成绩——先修方向31所指的数字一致性，再谈保持率。

**映射3：遗忘曲线 → 证据时效与复核调度。** 知识卡引用的来源 URL 会失效、编译器行为会随版本改变、C++ 标准每三年发布新版（C++17/20/23/26），证据的"保持率"随时间衰减，与 Ebbinghaus 曲线同构。应把 SM-2 调度思想用于证据复核：每条证据入库时记录获取时间与依赖的标准/编译器版本，初查1周后、再1个月、再3个月，之后间隔乘以易度因子；凡依赖单一旧版编译器或非稳定来源的证据，EF 取低值（约1.3–1.5），复核更密；多独立来源、跨编译器矩阵复现的证据 EF 可取高值。这比"每年人工重看一遍"的均一策略高效得多，且把有限的人工复核预算投在最可能"被遗忘"（过时）的证据上。

**映射4：巩固与睡眠重放 → 规则更新必须有离线巩固期。** 情景记忆向语义记忆的转化不是即时的：单条案例刚进账本时是未巩固的"海马态"信息，若立刻据此改规则，系统会被个别事件（甚至单条投毒）牵着走。工程上应设置巩固门：一条候选规则变更需要案例在账本中"静置"一段时间、由多个独立来源/夹具复现、并经过下一节所述的独立对账，才允许进入规则库。每次发布前的批量重放（方向64的 replay）可类比为"睡眠重放"——离线、按序、无新输入地把事件流过一遍，巩固产出规则差量与警报。

**映射5：虚假记忆研究 → 证据污染的直接警示。** Ramirez 实验对阙疑有三条具体教训。第一，engram 一旦形成，再激活时与真实记忆不可主观区分：被错误规则判决过的卡即使后来纠正，若不留下显式反转事件与冲突记录，系统（和读者）无法从"确信感"识别它曾是错的——纠错必须追加事件而非覆盖（与方向64互锁）。第二，虚假记忆是在"重新激活旧痕迹时嫁接新内容"形成的，对应攻击面是：在账本重放、迁移或合并过程中插入篡改，因此迁移脚本必须先固定原始哈希、再按序重放、逐批校验。第三，生物脑无法自证记忆真伪，阙疑同样不能以系统内部一致性作为真值来源；holdout 的17条人工标注真错、外部独立 oracle 才是区分"真实记忆"与"虚假记忆"的外部锚点。

**映射6：工作记忆模型 → 内核运行时的带宽管理。** 一次判决涉及的代码片段、规则条件、证据表与上下文，是在容量有限的"工作区"中整合的——对应中央执行器加语音环（符号序列）、视空画板（结构/图信息）与情景缓冲器（接通账本历史）。工程含义是显式限制单次判决同时持有的上下文规模（7±2 个有效组块的量级），把大块历史检索交给账本索引而非全量载入；情景缓冲器的接口应只取"与当前卡相关的历史事件流"，避免无关历史干扰判决。

## 四、类比边界与失败模式

第一，人脑与验证系统的目标函数不同：脑为生存优化，容忍大量遗忘与失真；审计系统要求精确可重放，遗忘是被显式调度的，不是自然衰减。第二，SM-2 的 EF 是启发式手工参数，源自单一用户的词汇学习，迁移到证据时效只借其调度形态，不能声称有同等实证支撑。第三，睡眠巩固机制是系统级过程，"发布前重放"只是功能类比，不共享生物机制。第四，虚假记忆实验基于小鼠、单一海马回路、恐惧条件反射这一狭窄范式，外推到软件证据污染需谨慎。第五，记忆再认的"熟悉感"在人类中本身就是高假阳性信号，对应教训是：与历史案例相似不能作为新卡正确的证据。

## 五、对阙疑的三条具体行动、盲区与来源

**对阙疑的三条具体行动：**

1. **2026-12 前**，为37张卡的全部证据加时效字段（获取时间、依赖标准版本、编译器版本、来源类型），并实现 SM-2 式复核调度器：初间隔7天，之后按证据易度因子（单来源/旧编译器取1.3–1.5，多源跨版本取2.0–2.5）递增，输出首张复核到期清单。
2. **2027-01 前**，建立规则"巩固期"制度：案例进入账本后须静置不少于14天、获至少3个独立证据（来源或可执行夹具）支持并通过独立 replay 对账，才允许触发规则变更；变更生效前在 holdout 上预登记预测。
3. **2027-03 前**，执行一轮季度"证据再认"盲测：评审者在不看原判决标签的条件下对452条案例相关抽样重新判决，计算前后一致率与翻转分布，作为记忆稳定性指标写入论文，并据翻转案例反向修订规则。

**盲区：**

1. SM-2 参数迁移到证据复核无直接论文实证，最优复核间隔需在2027年用自身到期复核数据回拟。
2. Ebbinghaus 的具体百分比来自单人被试与19世纪实验条件，本文引用以"约"字限定，不能作为定量保证。
3. 情景/语义记忆分离在认知神经科学中仍有边界争议（如语义记忆是否也部分依赖海马），映射为架构启发而非定论。
4. 虚假记忆实验物种与范式狭窄，软件系统中的"污染后行为是否同样不可逆"未经实测。
5. 评审者再认盲测的样本量受限于单人项目人力，一致率估计会有较宽置信区间。
