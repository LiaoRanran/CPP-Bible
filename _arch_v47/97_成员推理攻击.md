# 方向 87：成员推理攻击（Membership Inference Attack）

> 调研日期：2026-09-29。服务对象：阙疑/queyi（C++ 知识验证系统，目标 NeurIPS 2027 E&D Track）。本文件回答一个具体问题：**如果阙疑的任何环节使用 ML 组件、且其"训练集/知识库"包含敏感或专有知识卡，成员推理攻击（MIA）会造成什么数据隐私泄露，防御的真实代价是什么**，并结合 corpus 40 / 盲 holdout 30 的数据隐私考量。

## 核心结论

1. **MIA 的定义与威胁已七年实证**：Shokri、Stronati、Song、Shmatikov（IEEE S&P 2017）首次系统化"给定一条数据 + 黑盒访问模型，判断它是否在训练集中"的攻击，用影子模型（shadow model）训练攻击分类器，对 Google 商业 ML 服务训练的 Purchase(100) 零售模型攻击精度达 **0.935**（论文摘要表述为 median accuracy **94%**），对 Texas 医院出院数据集攻击精度**超 70%**——证明"某条医疗记录是否被用于训练"本身就是隐私敏感事实。任何"模型/系统在训练中见过某卡"的信号都可能被逆向。
2. **评估口径已从平均精度转向低误报率**：LiRA（Carlini、Chien、Nasr、Song、Terzis、Tramèr 等，IEEE S&P 2022，arXiv 2112.03570）指出传统"平均 accuracy"掩盖真实风险，改用 TPR@低 FPR：其攻击在 **FPR=0.001% 时 TPR 达 0.1%–10%**（CIFAR-100 上 11.2%），比先前攻击**强 10 倍**；在 CIFAR-10/CIFAR-100 上**首次误报前**可正确识别 **682 / 3079** 个成员。含义：即使攻击"平均看很弱"，对单条记录的法律级隐私推断（GDPR 语境）依然可能成立——这正是"宁可标注未核实、逐条可追"的阙疑式审计同样适用的口径。
3. **LLM/检索式场景的攻防真相是"双面"的**：一方面 Duan 等（COLM 2024，arXiv 2402.07841）大规模评估 Pythia 160M–12B 发现 MIA "**barely outperform random guessing for most settings**"，表面成功多可归因于分布偏移；另一方面 Carlini 等（ICLR 2023，arXiv 2202.07646）证实语言模型记忆化随模型容量、样本重复次数、上下文长度呈**对数线性增长**，且 RAG 场景的 S2MIA（ICASSP 2025，arXiv 2406.19234）证明 RAG **外部数据库**的成员隐私可被语义相似度攻击击穿、并能**绕过三种代表性防御**。阙疑的知识卡库本质上是"判例式外部知识库"，其隐私暴露面更接近 RAG 而非纯权重内化——账本/Merkle 结构保护的是完整性，不是成员隐私。

## 精确数字与案例

### 一、开山之作：Shokri 2017（IEEE S&P）的攻击精度与防御初测

论文：*Membership Inference Attacks Against Machine Learning Models*，Reza Shokri、Marco Stronati、Congzheng Song、Vitaly Shmatikov（Cornell Tech / UT Austin / Ephv / ETH 背景，arXiv 1610.05820，v2 2017-03-31），发表于 IEEE Symposium on Security and Privacy 2017。

**攻击设定**：黑盒访问目标模型，训练影子模型集合模拟目标行为，再用二分类攻击模型区分"目标模型对该样本的预测分布"与"对非成员的预测分布"。

Google 训练模型上的攻击精度（论文 Table II 逐字数字）：

| 数据集 | 训练精度 | 测试精度 | 攻击精度（precision） |
|---|---|---|---|
| Adult | 0.848 | 0.842 | 0.503 |
| MNIST | 0.984 | 0.928 | 0.517 |
| Location | 1.000 | 0.673 | 0.678 |
| Purchase(2) | 0.999 | 0.984 | 0.505 |
| Purchase(50) | 1.000 | 0.693 | 0.860 |
| Purchase(100) | 0.999 | 0.659 | 0.935 |
| TX hospital stays | 0.668 | 0.517 | 0.657 |

关键逐字引文：

- "For multi-class classification models trained on 10,000-record retail transaction datasets using Google's and Amazon's services in default configurations, our membership inference achieves median accuracy of 94% and 74%, respectively."
- "Our results for the Texas hospital discharge dataset (over 70% accuracy) indicate that membership inference can present a risk to health-care datasets..."
- 规律：**训练/测试精度 gap 越大（过拟合越重），攻击越准**——Purchase(100) gap 达 0.34，攻击精度 0.935；Adult gap 仅 0.006，攻击精度 0.503（≈随机）。
- 影子模型数量：CIFAR 100 个、Purchase 20 个、TX hospital 10 个、Location 60 个、MNIST 50 个；"Increasing the number of shadow models would increase the accuracy of the attack but also its cost."（逐字）
- 即使完全用合成数据训练影子模型，攻击 Google 模型精度仍有 90%（"Even if we make no prior assumptions about the distribution of the target model's training data and use fully synthetic data..., the accuracy of membership inference against Google-trained models is 90%"，逐字）。

防御初测（Table III，Purchase(100)）：L2 正则 λ=1e-2 时攻击总精度从 **0.92 降到 0.53**，代价是测试精度 0.66→0.63；TX hospital 上 λ=5e-3 时攻击精度降到 0.52 但测试精度**崩到 0.35**。输出抑制类手段几乎无效：仅输出 top-1 标签时攻击精度仍 0.60（Purchase）/0.67（TX）。逐字结论："Even restricting the prediction vector to a single label (most likely class), which is the absolute minimum a model must output to remain useful, is not enough to fully prevent membership inference."

### 二、评估范式转变：LiRA 与低 FPR 口径（IEEE S&P 2022）

论文：*Membership Inference Attacks From First Principles*，Carlini、Chien、Nasr、Song、Terzis、Tramèr 等（Google Research / UMass Amherst，arXiv 2112.03570，2021-12-07 提交，IEEE S&P 2022 发表）。核心主张：隐私审计关心的是"在极低误报率下能否坐实某条记录是成员"（对应法律举证），而非平均准确率。

LiRA 与先前攻击对比（论文 Table I 逐字数字，TPR@FPR）：

| 方法 | TPR@0.001% FPR (C-10 / C-100) | TPR@0.1% FPR (C-10 / C-100) |
|---|---|---|
| Yeom et al. | 0.0% / 0.0% | 0.0% / 0.0% |
| Shokri et al. | 0.0% / 0.0% | 0.3% / 1.6% |
| Song and Mittal | 0.0% / 0.0% | 0.1% / 1.4% |
| Watson et al. | 0.1% / 0.9% | 1.3% / 5.4% |
| **LiRA** | **2.2% / 11.2%** | **8.4% / 27.6%** |

其他关键数字（均逐字核出于 arXiv HTML 版）：

- "Our attack is 10× more powerful at low false-positive rates, and also strictly dominates prior attacks on existing metrics."
- 首次误报前正确推断成员数：CIFAR-10 **682**、CIFAR-100 **3079**（先前攻击 <2 / <20）。
- 影子模型规模：ImageNet 64 个、其余数据集 256 个；"Training more than 64 shadow models provides diminishing benefits, but the attack deteriorates quickly with fewer models."
- 基线 LOSS 攻击的反直觉失败：对损失最低、看起来"最有信心是成员"的 1% 样本，"the attack is only correct 48% of the time (worse than random guessing)"——说明朴素置信度启发式不可靠。
- 与差分隐私的理论衔接：LOSS 攻击的 "TPR/FPR ≤ 3/2"，"consistent with a strong DP level of ε=0.4"——低 FPR 口径可直接反推 DP 预算是否真的挡住了攻击。
- 评估设置警示：目标模型全部 100% 训练精度，测试精度 CIFAR-10 90% / ImageNet 65% / CIFAR-100 60%——过拟合是攻击成立的前提之一。

配合 Yeom、Fontana、Kagal、Finucane 的 *Privacy Risk in Machine Learning: Analyzing the Connection to Overfitting*（ICML 2018 / FLoC，arXiv 1709.01604）从理论上把成员推理隐私风险与**过拟合**和**样本影响（influence）**绑定：攻击成功率随过拟合程度上升，这是"正则化是一种防御"的理论来源。

### 三、LLM 与 RAG 场景：MIA 何时失效、何时真实成立

**失效面**：Duan、Suri、Mireshghallah、Min、Shi、Zettlemoyer、Tsvetkov、Choi、Evans、Hajishirzi，*Do Membership Inference Attacks Work on Large Language Models?*（COLM 2024，arXiv 2402.07841）。逐字引文：

- "We perform a large-scale evaluation of MIAs over a suite of language models (LMs) trained on the Pile, ranging from 160M to 12B parameters. We find that MIAs barely outperform random guessing for most settings across varying LLM sizes and domains."
- 归因："(1) the combination of a large dataset and few training iterations, and (2) an inherently fuzzy boundary between members and non-members."
- 警示：表面成功常见于分布偏移——"the apparent success in such settings can be attributed to a distribution shift, such as when members and non-members are drawn from the seemingly identical domain but with different temporal ranges."

这直接解释了 WikiMIA（Min 等，*Detecting Pretraining Data from Large Language Models*，ICLR 2024，arXiv 2310.16789）动态基准的设计动机：用模型发布前/后的数据划成员边界，规避时间分布偏移造成的假阳性。

**成立面（与阙疑更相关）**：

1. 记忆化前提：Carlini、Ippolito、Jagielski、Lee、Tramèr、Zhang，*Quantifying Memorization Across Neural Language Models*（ICLR 2023，arXiv 2202.07646）：三个对数线性关系——记忆化随 (1) 模型容量、(2) 样本重复次数、(3) 提示上下文长度增长；结论逐字："memorization in LMs is more prevalent than previously believed and will likely get worse as models continues to scale, at least without active mitigations."
2. RAG 外部库攻击：Li、Liu、Wang、Yang，*Generating Is Believing: Membership Inference Attacks against Retrieval-Augmented Generation*（ICASSP 2025，arXiv 2406.19234）：S2MIA 利用"样本与 RAG 生成文本的语义相似度"判定该样本是否在 RAG 外部数据库中，摘要逐字："Extensive experiment results demonstrate that S2MIA can achieve a strong inference performance compared with five existing MIAs, and is able to escape from the protection of three representative defenses."（具体 recall/AUC 数字未核实，见盲区。）另有同期工作 *Mask-based Membership Inference Attacks for Retrieval-Augmented Generation*（WWW 2025，DOI 10.1145/3696410.3714771）与 RAGLeak（Springer 2025 会议章节，DOI 10.1007/978-981-96-9101-2_8），三者共同确认：**RAG 知识库的成员隐私是真实攻击面**。
3. 中文侧佐证：信息安全学报《机器学习中成员推理攻击和防御研究综述》（2022）系统梳理国内视角的攻击分类与防御谱系；中文技术社区（知乎 2022、博客园 2024、CSDN 2026 多篇）对 Shokri/LiRA/防御实现的复现文章较多，但多为二手转述，不作为数字依据。
4. 基准化信号：NeurIPS 2024 已出现面向视觉-语言大模型（VLLM）的 MIA 专用基准（论文 *Membership Inference Attacks against Large Vision-Language Models*，NeurIPS 2024 正式论文集，proceedings.neurips.cc 可查），自称是"first membership inference attack (MIA) benchmark tailored for various VLLMs"（逐字，来自论文集页面摘要）——说明顶会已把 MIA 从"单篇攻击论文"推进为"可复用的评测对象"，这与 NeurIPS E&D Track 把 evaluation 本身当作研究对象（"evaluation itself becomes an object of scientific study"）的定位完全同向。

### 三点综合判读（供阙疑决策直接引用）

第一，**MIA 的可用性梯度非常清晰**：过拟合重（训练/测试精度 gap 大）的模型最脆弱（Shokri Table II 的规律），数据量大、训练迭代少的现代预训练几乎不受平均口径 MIA 影响（Duan 2024），但"低 FPR 口径下单条记录被坐实"的风险从未归零（LiRA）。第二，**攻击不需要白盒**：ML-Leaks（NDSS 2019）证明即使攻击者没有与目标同分布的数据、也没有与目标同架构的模型，仍可用 8 个多样数据集上的实验证明攻击广泛适用——因此"我们的知识卡来源很冷门所以安全"不是有效论据。第三，**检索式架构的隐私面比训练式更直接**：S2MIA 等三篇 2024–2025 工作说明，只要系统把知识条目取回并展现在输出里（阙疑的判决书恰恰要展示证据），攻击者就能用输出与候选条目的相似度做成员判定。这三点合起来意味着：阙疑即便不训练任何神经网络，只要"某卡是否在库/是否被审计过"这件事本身有价值（例如某卡来自某企业的内部规范），成员推理仍是必须写进威胁模型的攻击。

### 四、防御谱系与真实代价：DP、正则化、蒸馏、输出抑制

| 防御路线 | 代表工作 | 实测效果 | 代价 |
|---|---|---|---|
| 差分隐私训练（DP-SGD） | Abadi、Chu、McMahan、Goodfellow、Talwar，*Deep Learning with Differential Privacy*，CCS 2016（arXiv 1607.00133） | 据课程笔记（GitHub cs858-wiki）与 EmergentMind 转述：MNIST **97%**、CIFAR-10 **73%** 测试精度，隐私预算为个位数 ε（**此两数未直接核读原文正文，二手转述**）；摘要原文仅表述为 "at a minor cost of accuracy compared to non-private models"（逐字，已核） | 逐样本梯度裁剪+加噪，训练慢、小数据场景精度损失显著 |
| 正则化/早停 | Shokri 2017 Table III | L2 λ=1e-2 攻击精度 0.92→0.53（Purchase）；TX 上 λ=5e-3 攻击 0.52 但测试精度崩至 0.35 | 过强正则直接牺牲效用；"Note that more regularization... would potentially result in a significant reduction of the target model's test accuracy"（逐字） |
| 模型蒸馏/知识聚合 | Papernot、Abadi、Erlingsson、Goodfellow、Talwar，PATE（ICLR 2017 最佳论文，arXiv 1610.05755）：敏感数据分成多个教师模型，学生只从**加噪聚合投票**中学习 | 教师互相隔离使任一记录只影响少数教师，聚合加噪提供 DP 保证；"state-of-the-art privacy/utility trade-offs on MNIST and SVHN"（摘要逐字） | 需训练多教师，推理需保持聚合噪声 |
| 输出抑制（top-k、rounding、temperature） | Shokri 2017 Table III | top-1 标签仍留 0.60–0.67 攻击精度；temperature t=20 也只降到 0.84/0.76 | **对 MIA 基本无效**（攻击利用误标记行为差异） |
| 对抗式置信度扰动 | Jia 等，*MemGuard*，CCS 2019（arXiv 1909.10594） | "the first defense with formal utility-loss guarantees against black-box membership inference attacks"（摘要逐字）；具体攻击精度降幅未核实 | 有 utility-loss 上界保证，但需在推理时加噪 |
| "删离群点"式缓解 | *The Privacy Onion Effect: Memorization is Relative*（arXiv 2206.10469，2022）：移除最外层最易被记忆的离群点后，内层点成为新的外层、重新变得脆弱 | 摘要逐字："removing the 'layer' of outlier points that are most..."——**逐层剥洋葱**，防御不可一次性完成 | 说明任何"移除高记忆样本"的一次性防御都会失效（作者顺序未逐字核实，见盲区） |

**真实世界部署的 DP 代价参照**：美国 2020 年人口普查是 DP 规模化部署的标志性案例（Abowd，*A Chronicle of the Application of Differential Privacy to the 2020 Census*，Harvard Data Science Review），学界围绕 ε 预算与精度损失的争论持续多年；PNAS 2025 年论文《The 2020 US Decennial Census is more private than you (might) think》甚至论证其实际隐私保证**强于官方声明**（具体 ε 数字未核实）。含义：DP 的"可证明性"本身是可审计、可争论的对象——这与阙疑"判决可复算"的立场同构，但 DP 的实用性代价（精度/延迟/审计复杂度）必须实测而非引用。

### 五、真实世界影响：从医疗数据到"审计即泄露"

Shokri 2017 之所以选择 Texas 医院出院数据集，正是因为"某人的医疗记录被用于训练"这一成员事实本身敏感（该数据集用于医院再入院类预测任务）。此后 MIA 逐渐成为 GDPR/隐私法语境下评估"个人数据保护"的事实性工具：LiRA 明确把攻击评估对准"法律级举证"场景——在 FPR=0.001% 这一极低误报率下仍能以 0.1%–10% 的 TPR 坐实成员身份，意味着"训练集中确有此条数据"可以在审计中作为可复核的证据链陈述。对 2020 美国人口普查的 DP 部署争议（Abowd 的 HDSR 编年史；PNAS 2025 复核论文）则展示了另一面：隐私保证的强度本身会成为公共辩论对象，官方声明与学界复核可能相左（该案例中 PNAS 复核认为实际隐私保证**强于**官方声明）。对阙疑的直接类比是：**"知识卡 X 是否进入过 452 条判决账本"也可能成为有价值的成员事实**——例如它间接暴露"某企业曾向阙疑提交过某内部缺陷卡"。阙疑的哈希链保证的是"账本不可改"，而"账本可被查询什么"才是成员隐私的决定点。

## 对阙疑的 3 条具体行动

1. **把"知识卡库成员隐私"写成正式威胁模型条目（时间点：2026-12-31 前）**。在 `research/12_threats_to_validity.md` 新增小节 **T7：成员推理 / 库成员泄漏**：明确列出 37 实卡 + 10 草稿中哪些卡含专有/敏感来源（企业内部 C++ 编码规范、付费标准文本、私有缺陷报告），标注其是否允许进入外部 corpus 40；同时论证 append-only 哈希链账本与 Merkle checkpoint 只保证**完整性**（不可篡改、可复算），**不提供成员隐私**——如果对账器/审计 API 允许"给定知识卡文本或其哈希，查询该卡是否产生过判决"，这就是一个成员推理 oracle（类比 S2MIA 对 RAG 库的攻击）。产出：T7 小节 + 一张"卡来源敏感级 × 可访问面"矩阵表。
2. **在审计接口上做"输出最小化 + 接口降权"实验，而不是迷信输出抑制（时间点：2027-05 前，与论文投稿对齐）**。依据 Shokri 2017 的结论（top-1 标签仍挡不住攻击），在 `gate_engine.py`（3826 行）对外暴露的判决/审计 API 上做 A/B：基线返回四态判决 + 置信度分数 + 中间证据，实验组仅返回四态判决 + Merkle proof；用 corpus 40（三层，检出 43.8%）与盲 holdout 30（真错 17，检出 66.7%）作为成员/非成员集，测"能否仅凭接口响应推断某卡是否在 holdout 中"（AUC + TPR@FPR=1% 口径，口径照抄 LiRA）。注意 holdout 30 的"盲态协议不可回盲"承诺必须写进实验前提：回盲即等于对攻击者泄露 holdout 成员名单。
3. **在 NeurIPS 2027 E&D 投稿的 dataset card 中预注册一条 MIA 相关实验，负结果也写（时间点：2027-03 前定稿）**。具体写法：声明"知识卡不在公开网络、第三方审计只经盲态协议访问"这一边界条件；预注册实验——用 15 个真实缺陷夹具的历史重注入数据（重注入 6/6=100%、历史覆盖 12/15=80%）反向演示"攻击者能否从 452 条判决账本的时序/哈希结构反推某夹具是否曾被审计"；若结果接近随机（预期如此，因为账本不含明文），作为 negative result 写入，呼应 E&D 官方定位 *"evaluation itself becomes an object of scientific study"* 与 *"Submissions need not introduce a new model or outperform prior work"*；同时引用 LiRA 低 FPR 口径说明为何用 TPR@FPR 而非平均 accuracy 汇报。

## 盲区（诚实标注）

1. **DP-SGD 的 97%（MNIST）/ 73%（CIFAR-10）两个数字是二手转述**：来自 GitHub 课程笔记（ssg-research/cs858-wiki）与 EmergentMind 的转述，两次独立来源一致，但未直接核读 arXiv 1607.00133 正文表格；论文摘要本身只有"minor cost of accuracy"的定性表述。
2. **S2MIA / RAGLeak / Mask-based MIA 的具体攻击指标（recall、AUC、F1）未核实**：只拿到 arXiv 摘要（S2MIA）与论文标题/DOI（另两篇），正文数字未读。三条来源中 S2MIA 的"绕过三种代表性防御"为摘要逐字，但"三种防御"具体是哪三种未核实。
3. **Privacy Onion Effect 的作者顺序未逐字核实**：确信为 Steinke/Nasr 参与的 Google 工作（arXiv 2206.10469，2022），作者全名单与发表会议（通常称 NeurIPS 2022）未逐一核对。
4. **MemGuard 的具体攻击精度降幅未核实**：只确认其"第一个带 utility-loss 形式保证的防御"这一摘要表述与 CCS 2019 出处（GitHub jinyuan-jia/MemGuard、arXiv 1909.10594）。
5. **"LLM 上 MIA 基本失效"的结论有外推风险**：Duan 2024 的设定是 Pythia/Pile 预训练（大数据、少迭代）；在数据重复、微调、领域集中（如纯 C++ 语料）场景，LiRA 式攻击与记忆化（Carlini 2022）仍然成立，不能拿它当"阙疑无风险"的证据。
6. **US Census 相关的两个来源（HDSR 编年史、PNAS 2025）只读到摘要级信息**，未核实具体 ε 值；网络上流传的"ε=8 时成员推理攻防平衡点"之类说法（CSDN 2026 博客）为二手内容，本文件**未采用**。
7. **Shokri 数字取自 ar5iv 的 arXiv v2 版**，与 IEEE S&P 正式版可能存在表格编号差异；且原文自身存在 0.895/0.896 的正文-图注不一致，已在正文如实标注。
