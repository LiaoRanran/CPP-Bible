# 07 · 数据结构与文件格式设计（JSON schema）

> 所有 schema 纯 JSON；签名在单用户阶段为"模拟签名"（见 01.6），W 档升级 Ed25519。

## 7.1 link（in-toto 风格步骤记录）
```json
{
  "schema": "queyi.link/v1",
  "step": "gate_validate",
  "command": ["python","tools/gate_engine.py","--check"],
  "materials": { "gate_engine.py": "<sha256>", "rule_defs": {"H-fence.py":"<sha>"} },
  "products":  { "data/overturned_events.jsonl": "<sha256>" },
  "environment": { "git_head": "2af99a31…", "author": "LiaoRanran", "ts": "2026-09-19T12:00:00+00:00" },
  "functionary": "git:<head>",
  "sig": "<sha(functionary+payload)>"
}
```
- `materials/products` 值为 sha256 字符串或 `{相对路径: sha256}` 映射。
- 校验：重算 `sha(functionary+剔除sig的payload)` == `sig`；`materials` 含上一步 `products` 哈希。

```json
  "steps": [
    {"name":"write_cards","functionaries":["git:HEAD"],"materials":[],"products":["atoms/**","misconceptions/**"]},
    {"name":"gate_validate","functionaries":["git:HEAD"],"materials":["write_cards.products"],"products":["gate_engine.py"]},
    {"name":"replay_verify","functionaries":["git:HEAD"],"materials":["gate_validate.products"],"products":["atom_evidence_replay.py"]},
    {"name":"poison_test","functionaries":["git:HEAD"],"materials":["replay_verify.products","poison_drill.py"],"products":["poison_drill.py"]},
    {"name":"mutation_test","functionaries":["git:HEAD"],"materials":["poison_test.products"],"products":["data/mutation/**"]},
    {"name":"metrics_collect","functionaries":["git:HEAD"],"materials":["mutation_test.products"],"products":["data/metrics.jsonl"]},
    {"name":"human_review","functionaries":["git:HEAD"],"materials":["metrics_collect.products"],"products":["data/overturned_events.jsonl"]}
  ],

  "keys": {"git:HEAD":"<head指纹>"},
  "signed": "<sha(keys+steps+inspections)>"
}
```

## 7.3 provenance（SLSA v1 适配，= link 超集）
```json
{
  "schema": "queyi.provenance/v1",   // 兼容 SLSA provenance v1 字段
  "buildDefinition": {
    "buildType": "queyi.local.step",
    "invocation": {"entryPoint":"gate_validate","parameters":["--check"],"environment":{"git_head":"2af99a31…"}},
    "materials": [{"uri":"tools/gate_engine.py","digest":{"sha256":"<h>"}}]
  },
  "runDetails": {
    "builder": {"id":"local:git:<head>"},
    "metadata": {"invocationId":"<uuid>","startedOn":"ISO8601","finishedOn":"ISO8601",
                 "completeness":{"parameters":true,"environment":true,"materials":true}},
    "products": [{"uri":"data/overturned_events.jsonl","digest":{"sha256":"<h>"}}]
  }
}
```
注：provic 与 link 同源；验证器可互读（见 02.8）。

## 7.7 exemption link（封堵攻击2 台账）
```
{"schema":"queyi.exemption/v1","id":"EX-001","by":"git:<author>","reason":"…",
 "rule":"ATOM-CLAIM-CONCEPT-NORMALIZED","link":"data/supply_chain/links/exemption-EX-001.json",
 "sig":"<sha(gitHEAD+payload)>"}
```
poison 运行前校验：每条豁免台账项须有对应 exemption link，否则拒绝。

## 7.8 诚实边界
- 所有 `_sig`/`signed` 在单用户阶段为**模拟签名**（git HEAD 身份），只防事后篡改，不防当时伪造（见 01.6、05.4）。
- `merkle_roots.json` 自身不进自身根（递归无解），其可信度依赖 OpenTimestamps + git 历史（与 `.tool_checksums` 同源，须上链补强）。
