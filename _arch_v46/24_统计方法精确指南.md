# 方向 24：统计方法精确指南

## 核心结论

1. **n=30 量级一律禁用 Wald 区间**：本次实算显示 2/16 的 Wald 95% 下限是 **−0.0370**、12/15 的上限是 **1.0024**，都越界；NeurIPS Checklist 第 7 项原文明确警告不要展示会产生越界值（如负错误率）的对称误差棒。小样本比例区间必须用 **Clopper-Pearson（保守，覆盖度 ≥ 1−α）** 或 **Wilson（平均覆盖度 = 1−α，越界不可能）**。
2. **配对比较与非配对比较必须用不同检验**：同一批 holdout 上比较两条规则 / 两个引擎版本，观测是**配对**的，应当用 **McNemar 检验**（只看不一致格 b 与 c）；只有当两组样本互相独立时才用 **Fisher 精确检验**。用错检验会系统性高估显著性。
3. **p 值必须配效应量**：比例差用 **Cohen's h**（`h = 2·arcsin(√p₁) − 2·arcsin(√p₂)`，阈值 0.2/0.5/0.8），一致性用 **Cohen's κ**。阙疑的实算例子：10/15（0.6667）对 7/16（0.4375）的 **h = 0.4652**（中等偏小），而 10/15 对 0.5 的 **h = 0.3398**——这意味着即使 p 值显著，效应量也只是中小。

## 精确数字与案例

### 1. 比例置信区间：五种方法的精确定义与取舍

**方法来源**：Brown, Lawrence D.; Cai, T. Tony; DasGupta, Anirban（2001），*"Interval Estimation for a Binomial Proportion"*，*Statistical Science* **16(2): 101–133**，doi:**10.1214/ss/1009213286**。这是 statsmodels 与 scipy 文档共同引用的权威文献。

`statsmodels.stats.proportion.proportion_confint(count, nobs, alpha=0.05, method='normal', alternative='two-sided')` 支持 **6 种方法**（文档原文）：

| `method` | 中文名 | 公式 | 文档原话/特性 |
|---|---|---|---|
| `'normal'` | Wald（正态近似） | p̂ ± z·√(p̂(1−p̂)/n) | "asymptotic normal approximation"；**小样本越界** |
| `'agresti_coull'` | Agresti-Coull | p̃ = (k+z²/2)/(n+z²)，再 ± z·√(p̃(1−p̃)/(n+z²)) | 修正 Wald |
| `'beta'` | **Clopper-Pearson** | [Beta⁻¹(α/2; k, n−k+1), Beta⁻¹(1−α/2; k+1, n−k)] | 文档原文："**the Clopper-Pearson exact interval has coverage at least 1-alpha, but is in general conservative**" |
| `'wilson'` | **Wilson Score** | 见下 | 文档原文："The 'wilson' interval is contained in [0, 1] mathematically" |
| `'jeffreys'` | Jeffreys 贝叶斯区间 | Beta 后验分位 | 中心区间，边界处不调整 α |
| `'binom_test'` | 数值反演 binom_test | — | 文档原文："Method 'binom_test' directly inverts the binomial test in scipy.stats, which has discrete steps" |

**Wilson 区间的精确公式**（本文实算所用，`z = 1.959963985`，α=0.05）：

```
denom    = 1 + z²/n
center   = ( p̂ + z²/(2n) ) / denom
halfwidth= ( z / denom ) · sqrt( p̂(1−p̂)/n + z²/(4n²) )
CI       = [ center − halfwidth , center + halfwidth ]
```

**Clopper-Pearson 的边界约定**（statsmodels 文档原文）："In the extreme case when count is zero or equal to nobs, then the coverage will be only 1 - alpha/2 in the case of 'beta'." 实操中 k=0 取下限 0、k=n 取上限 1（本文实算采用该约定）。文档另注：置信区间在 `'normal'`、`'agresti_coull'`、`'wilson'` 三种方法下会被**裁剪到 [0,1]**；`'beta'` 与 `'jeffreys'` 是中心区间，两端各用 α/2。

**scipy 侧**：`scipy.stats.binomtest(k, n, p=0.5, alternative='two-sided')` 返回 `BinomTestResult`，含属性 `k`、`n`、`alternative`、`statistic`、`pvalue`，以及方法 **`proportion_ci(confidence_level=0.95, method='exact')`**。**`binomtest` 自 SciPy 1.7.0 起加入**。官方示例（可直接复现）：

```python
from scipy.stats import binomtest
result = binomtest(3, n=15, p=0.1, alternative='greater')
result.pvalue        # 0.18406106910639114
result.statistic     # 0.2
result.proportion_ci(confidence_level=0.95)
# ConfidenceInterval(low=0.05684686759024681, high=1.0)
```

### 3. "零事件"的快速上界：Rule of Three

当 n 次独立试验中**观测到 0 次事件**时，95% 置信上界 ≈ **3/n**。本文实算的精确 Clopper-Pearson 上界与 3/n 的对照：

| n | 3/n（Rule of Three） | 精确 CP 上界 | 差异 |
|---|---|---|---|
| 4 | 0.7500 | 0.6024 | 3/n 高估 |
| 6 | 0.5000 | 0.4593 | 3/n 高估 |
| 15 | 0.2000 | 0.2033 | 基本一致 |
| 30 | 0.1000 | 0.1157 | 3/n 低估 |
| 40 | 0.0750 | 0.0881 | 3/n 低估 |

**用法**：`0/6` 这类结果（例如 C 层检出 0%）只能写成"检出率 0%，95% 置信上界 45.93%（Clopper-Pearson）"；**不要**写"检出率为 0"就结束。同理 `0/40` 的 CP 上界是 **8.81%**，这已经是一个足够强的结论（"在 40 条外部样本上未检出任何 C 层缺陷，95% 置信上界 8.81%"）。

### 4. Fisher 精确检验：非配对 2×2

**适用**：两组互相独立的样本（例如"阙疑 vs cppcheck 在同一批 40 条语料上各自独立判定"——注意这里其实是配对，见下节；只有"两批不同语料"才是非配对）。

**scipy**：`scipy.stats.fisher_exact(table, alternative=None, *, method=None)`；对 2×2 列联表，零假设是"真实优势比为 1"。`alternative` 选项用于 2×2；其他表尺寸不使用该参数。

**公式**（超几何分布，固定边缘和）：

```
P(X = x) = C(r1, x) · C(r2, c1 − x) / C(n, c1)
其中 r1 = a+b（第 1 行和），r2 = c+d，c1 = a+c（第 1 列和），n = a+b+c+d
双尾 p = Σ P(X = x)  对所有满足 P(X=x) ≤ P(X=a) 的 x
```

**本文实算示例**（可直接对 R 的 `fisher.test` 校验）：

| 表 | n | 优势比 OR | 双尾 p |
|---|---|---|---|
| [[10,5],[4,11]] | 30 | 5.500 | **0.065595** |
| [[10,0],[5,5]] | 20 | ∞ | **0.032508** |
| [[8,2],[3,7]] | 20 | 9.333 | **0.069779** |
| [[13,11],[2,14]] | 40 | 8.273 | **0.009508** |
| [[6,0],[0,6]] | 12 | ∞ | **0.002165** |

**读法**：[[10,5],[4,11]] 的 OR=5.5 看起来很"大"，但 p=0.0656 > 0.05，**在 n=30 下不显著**。这正是阙疑必须提前承认的事：**n=30 的语料不足以支撑多数两两比较的显著性主张**。

### 5. McNemar 检验：配对 2×2（这是阙疑最该用的检验）

**适用**：同一批样本、两个系统各判一次。经典参考是 **Thomas G. Dietterich（1998）**，*"Approximate Statistical Tests for Comparing Supervised Classification Learning Algorithms"*，*Neural Computation* **10(7): 1895–1923**。该论文比较了 **5 种统计检验**（McNemar 检验、两个比例之差检验等），并给出一个关键结论：**"The 5×2 cv test is shown to be slightly more powerful than McNemar's test."**（5×2 cv 检验比 McNemar 检验略更有效力。）Dietterich 同时指出，在**训练多个分类器模型代价高昂或不切实际**的情形下推荐使用 McNemar 检验——这正好是阙疑的场景（重跑全量编译 + sanitizer 很贵）。

**列联表**：

|  | 系统 B 检出 | 系统 B 漏检 |
|---|---|---|
| **系统 A 检出** | a | b |
| **系统 A 漏检** | c | d |

**统计量**（只依赖不一致格 b、c）：

```
连续性校正卡方：  χ² = (|b − c| − 1)² / (b + c)
无校正卡方：      χ² = (b − c)² / (b + c)      （df = 1）
精确检验（小样本推荐）：对 n = b + c 做 p = 0.5 的双尾二项检验
```

**本文实算（精确检验）**：

| b | c | n = b+c | 精确双尾 p |
|---|---|---|---|
| 3 | 10 | 13 | **0.092285** |
| 5 | 12 | 17 | **0.143463** |
| 2 | 7 | 9 | **0.179688** |
| 4 | 4 | 8 | **1.000000** |

**关键读法**：即使不一致格是 3 vs 10（看起来差很多），n=13 时 p=0.0923，**仍然不显著**。阙疑若要在 n=30 的 holdout 上比较"引擎 v1 vs v2"，**必须先用 McNemar 算一遍 b/c**，很可能得到"不显著"的结论——诚实地报出这个结论，比硬报"提升"要安全得多。

**Python**：`statsmodels.stats.contingency_tables.mcnemar(table, exact=True, correction=True)`（`table` 为 2×2 数组；`exact=True` 走精确二项，`correction=True` 走连续性校正卡方）。也可手写：`scipy.stats.binomtest(min(b,c), b+c, 0.5).pvalue * 2`（注意与 scipy 的 `alternative` 语义对齐）。

### 6. 效应量：Cohen's h 与 Cohen's κ

**Cohen's h（两个比例的效应量）**：

```
h = 2·arcsin(√p₁) − 2·arcsin(√p₂)
```

阈值（Cohen 的常规基准）：**0.2 小 / 0.5 中 / 0.8 大**。注意 h 是**无符号方向**的，比较时取绝对值；对 p=0.5 到 1.0，h = 2·arcsin(1) − 2·arcsin(√0.5) = π − π/2 = **1.5708**，这是 h 在 [0,1] 区间内的最大值。

**本文实算**：

| p₁ | p₂ | h | 解释 |
|---|---|---|---|
| 10/15 = 0.6667 | 7/16 = 0.4375 | **0.4652** | 接近中等 |
| 10/15 = 0.6667 | 0.5000 | **0.3398** | 小到中等 |
| 7/16 = 0.4375 | 0.5000 | **−0.1253** | 极小（且方向为负） |
| 1.0000 | 7/16 = 0.4375 | **1.6961** | 极大（受 n 小影响，慎报） |
| 1.0000 | 0.5000 | **1.5708** | h 的理论上界 |
| 10/15 = 0.6667 | 0.4380 | **0.4642** | 与第 1 行一致（验证 43.8%≈7/16） |

**Cohen's κ（一致性）**：

```
κ = (p_o − p_e) / (1 − p_e)
p_o = 观测一致比例；p_e = 按边缘分布计算的期望一致比例
```

**Python**：`sklearn.metrics.cohen_kappa_score(y1, y2, *, labels=None, weights=None, sample_weight=None)`。`weights` 可设 `'linear'` 或 `'quadratic'` 做有序类别的加权 κ。

**κ 的解释分档**：文献中最常引用的是 **Landis & Koch（1977）** 的分档——<0 差 / 0–0.20 轻微 / 0.21–0.40 尚可 / 0.41–0.60 中等 / 0.61–0.80 显著 / 0.81–1.00 几乎完全一致。**本方向未逐字核对 Landis & Koch 原文**，引用时建议同时给出原始 κ 值与置信区间，而不是只贴一个"substantial"的形容词。

**阙疑的用法**：holdout 的标签经过 662 A1 批次人工复核（真错 7→17），若做了**双人独立标注**，κ 就是"标签效度"的定量证据。**但要注意**：n=30 时 κ 的置信区间极宽（与比例区间同理），必须附区间。

### 7. 多重比较校正：Holm–Bonferroni

67 条规则 × 3 个数据集 = 最多 **201 次**比较；α=0.05 时期望假阳性约 **10 次**。

**Holm–Bonferroni 步骤**（比 Bonferroni 更有效力，且同样控制 FWER ≤ α）：
1. 把 m 个 p 值升序排列 p₍₁₎ ≤ p₍₂₎ ≤ … ≤ p₍ₘ₎；
2. 找到最小的 i 使 p₍ᵢ₎ > α/(m − i + 1)；
3. 拒绝所有 j < i 的假设，接受其余。

Python：`statsmodels.stats.multitest.multipletests(pvals, alpha=0.05, method='holm')`。阙疑的场景建议**默认用 Holm**，并在正文说明"未做校正的 p 值仅作描述性报告"。

### 8. Bootstrap 与样本量的硬约束

**Bootstrap**：BCa（bias-corrected and accelerated）是公认更优的 bootstrap 区间，参考 *"Bootstrap confidence intervals: A comparative simulation study"*（arXiv:**2404.12967**，2024）。但 **n=30 时 bootstrap 的经验分位数本身不稳定**，且阙疑的数据是**离散比例**——对比例问题，Clopper-Pearson / Wilson 是闭式解，**没有理由用 bootstrap**。Bootstrap 应留给"非比例型统计量"（如平均判定耗时、规则命中数的分布）。

**样本量的硬天花板**（本文实算，Wald 近似，p≈0.7）：

| 目标半宽 | 所需 n |
|---|---|
| ±0.15 | **35.9** |
| ±0.10 | **80.7** |
| ±0.05 | **322.7** |

**结论**：30 个样本在数学上最多支撑约 ±0.16 的精度。阙疑**不应**主张"检出率约 66.7%"之外的更强陈述；所有"提升到 X%"的说法都必须先做功效分析。

### 8b. 把统计方法"读"出来：四个完整的工作示例

上面的公式与数字只有在能被"读成结论"时才有价值。下面给出四个完整示例，每个示例都演示"从原始计数到论文里那一句可写的话"的完整路径——这四句话可以直接抄进阙疑的 §5.4 与 §5.6。

**示例一：holdout 检出率该怎么写。**
原始计数是"15 条可测样本中命中 10 条"。Wald 会给出 [0.4281, 0.9052]，Wilson 给出 [0.4171, 0.8482]，Clopper-Pearson 给出 [0.3838, 0.8818]。三者点估计相同（0.6667），但区间的下界相差 **4.4 个百分点**（0.4281 对 0.3838），上界相差 **2.3 个百分点**。既然 NeurIPS Checklist 第 7 项要求"至少对支持主要主张的实验"给出区间，而主要主张是"阙疑能检出真实缺陷"，那么**采用最保守的 Clopper-Pearson 反而是最有利的策略**：区间更宽意味着主张更弱，主张更弱意味着更难被推翻。论文里应写成："检出率 66.7%（10/15），95% 置信区间 [38.4%, 88.2%]（Clopper-Pearson 精确法）。"注意**不要**写"约 66.7%"或"66.7% 左右"——区间已经承担了不确定性的表达，点估计必须给精确值。

**示例二：重注入 6/6 该怎么写。**
这是阙疑目前最容易被过度推销的数字。6/6 的 Wald 区间是 **[1.0000, 1.0000]**（宽度为零，等于宣称"零不确定性"），Wilson 是 [0.6097, 1.0000]，Clopper-Pearson 是 **[0.5407, 1.0000]**。也就是说，**n=6 时"100% 检出"在统计上只等价于"真实检出率高于 54% 的可能性较大"**。如果只写"重注入检出 100%"，审稿人一旦自己算出 CP 下界是 54.07%，会认为作者在夸大；反之如果主动写出 "[54.1%, 100%]"，则会显得作者懂统计。**主动报出宽区间，比被别人算出来要划算得多。**

**示例三：外部 corpus 的 43.8% 该怎么处理。**
43.8% × 40 = 17.52，不是整数，所以这个百分比的分母一定不是 40。43.75% 的两个整数表示为 **7/16** 与 **14/32**。若取 7/16，CP 区间是 **[0.1975, 0.7012]**，宽度 0.5037——**区间宽到几乎无信息**；若取 14/32，CP 区间是 [0.2636, 0.6234]，宽度 0.3597。两种解释给出的结论强度差别很大。更麻烦的是：若 A 层 24 条命中 13 条、B 层 16 条命中 2 条，则 (13+2)/40 = **37.5%**，与 43.8% 相差 **6.3 个百分点**。**这不是统计问题而是数据口径问题**，必须回到 `data/external_corpus/external_corpus_665.json` 逐条复算才能定论。在复算完成之前，**不要把 43.8% 写进任何表格**。

**示例四：引擎改版前后怎么比。**
假设阙疑的规则集从 63 条改到 67 条（661 A2 批次补齐了 4 条 `-HC` 高复杂度 block 规则），要在同一批 30 条 holdout 上论证"新版更好"。这是**配对**设计，只能用 McNemar。需要统计的是四格中的不一致格：新版检出而旧版漏检的条数 b，以及旧版检出而新版漏检的条数 c。**关键提醒**：McNemar 只看 b 与 c，完全忽略两版都命中的 a 与两版都漏检的 d。若 b=3、c=10，精确双尾 p = **0.0923**，在 α=0.05 下**不显著**；若 b=5、c=12，p = **0.1435**，更不显著。因此在 n=30 上，**"新增 4 条规则带来了可统计检出的提升"这个主张大概率立不住**。诚实的替代主张是："新增 4 条 `-HC` 规则修复了 4 个具体的漏检案例（列出 sample_id），配对 McNemar 检验显示差异未达统计显著（b=…, c=…, p=…），我们据此仅声称**案例级修复**而非**总体检出率提升**。"——这种"缩小主张"的写法，恰好是 ICML 2025 人类基线论文给出的核心建议："Even when maximum rigor cannot be achieved, researchers should explicitly discuss methodological limitations and narrow the scope of their claims."

**四类检验的适用性速查**（贴在自己的实验笔记里，避免用错）：

| 场景 | 正确检验 | 错误做法 |
|---|---|---|
| 单个比例 + 置信区间 | Clopper-Pearson / Wilson | Wald（越界） |
| 两个**独立**组的比例比较 | Fisher 精确（或 χ²） | 误用 McNemar |
| 同一批样本上**两个系统**的比较 | **McNemar（精确）** | 误用 Fisher / χ²（高估显著性） |
| 多个比例同时比较 | Holm–Bonferroni 校正后逐个 | 不校正（201 次比较下期望约 10 次假阳性） |
| 一致性（两个标注者） | Cohen's κ + CI | 只报"一致率"（未校正随机一致） |
| 效应大小 | Cohen's h（比例）/ κ（一致性） | 只报 p 值 |

### 9. 可直接落地的脚本（`tools/queyi_stats.py` 草案）

```python
"""阙疑统计报告：比例区间 / 配对检验 / 效应量 / 多重比较。
依赖：scipy>=1.7, statsmodels, scikit-learn
用法：python tools/queyi_stats.py --json report.json
"""
import math, json, argparse
from scipy.stats import binomtest, fisher_exact
from statsmodels.stats.proportion import proportion_confint
from statsmodels.stats.multitest import multipletests
from sklearn.metrics import cohen_kappa_score

Z = 1.959963985

def ci_all(k, n, alpha=0.05):
    """返回 Wald / Wilson / Clopper-Pearson 三种 95% 区间。"""
    p = k / n
    se = math.sqrt(p * (1 - p) / n)
    wald = (p - Z * se, p + Z * se)                       # 会越界，仅用于对照
    cp   = proportion_confint(k, n, alpha=alpha, method='beta')    # Clopper-Pearson
    wil  = proportion_confint(k, n, alpha=alpha, method='wilson')  # Wilson
    return dict(k=k, n=n, p=p, wald=wald, clopper_pearson=cp, wilson=wil,
                cp_width=cp[1] - cp[0])

def rule_of_three(n):
    """0 事件时的 95% 上界近似 3/n 与精确 CP 上界的对照。"""
    return dict(n=n, approx_3_over_n=3.0 / n,
                exact_cp_upper=proportion_confint(0, n, method='beta')[1])

def cohens_h(p1, p2):
    """两个比例的效应量 h = 2*asin(sqrt(p1)) - 2*asin(sqrt(p2))。"""
    return 2 * math.asin(math.sqrt(p1)) - 2 * math.asin(math.sqrt(p2))

def mcnemar_exact(b, c):
    """配对 2x2 的精确 McNemar：对 n=b+c 做 p=0.5 的双尾二项检验。"""
    n = b + c
    if n == 0:
        return 1.0
    return min(1.0, binomtest(min(b, c), n, 0.5).pvalue * 2)

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--json', default=None)
    a = ap.parse_args()
    rows = [
        ('holdout 可测子集', 10, 15),
        ('holdout 全部真错', 17, 30),
        ('外部 corpus(若 7/16)', 7, 16),
        ('A 层(若 13/24)', 13, 24),
        ('B 层(若 2/16)', 2, 16),
        ('C 层(若 0/6)', 0, 6),
        ('重注入检出', 6, 6),
        ('历史覆盖', 12, 15),
    ]
    out = []
    print(f"{'case':<22}{'k/n':>8}{'p':>8}  {'Clopper-Pearson 95%':>24}  {'Wilson 95%':>22}")
    for name, k, n in rows:
        d = ci_all(k, n)
        d['name'] = name
        out.append(d)
        print(f"{name:<22}{k:>3}/{n:<4}{d['p']:>8.4f}  "
              f"[{d['clopper_pearson'][0]:.4f}, {d['clopper_pearson'][1]:.4f}]"
              f"{'':>6}[{d['wilson'][0]:.4f}, {d['wilson'][1]:.4f}]")
    print('\n-- 效应量 --')
    print("Cohen's h 10/15 vs 7/16 :", round(cohens_h(10/15, 7/16), 4))
    print("Cohen's h 10/15 vs 0.50  :", round(cohens_h(10/15, 0.50), 4))
    print('\n-- 配对 McNemar 精确 p --')
    for b, c in [(3, 10), (5, 12), (2, 7), (4, 4)]:
        print(f"b={b:>2} c={c:>2} n={b+c:>3}  p={mcnemar_exact(b, c):.6f}")
    print('\n-- 非配对 Fisher 精确 --')
    for tab in ([[10, 5], [4, 11]], [[10, 0], [5, 5]], [[13, 11], [2, 14]]):
        orr, p = fisher_exact(tab)
        print(f"{tab}  OR={orr:.3f}  p={p:.6f}")
    print('\n-- Rule of Three 对照 --')
    for n in (4, 6, 15, 30, 40):
        print(rule_of_three(n))
    print('\n-- 样本量需求（Wald, p=0.7）--')
    for hw in (0.15, 0.10, 0.05):
        print(f"  ±{hw:.2f} -> n ≈ {Z**2 * 0.7 * 0.3 / hw**2:.1f}")
    if a.json:
        json.dump(out, open(a.json, 'w', encoding='utf-8'), ensure_ascii=False, indent=2)

if __name__ == '__main__':
    main()
```

## 盲区（诚实标注）

1. **本文所有区间数字为本次实算**，用的是自实现的 Clopper-Pearson（连分式 + 二分求逆）。已与 statsmodels 文档给出的 `binomtest(3, n=15).proportion_ci()` 示例（low=0.05684686759024681）做过口径对照，但**未在装有 scipy/statsmodels 的环境里跑交叉验证**（本机无这两个包）。落库前**必须**用 `proportion_confint(10, 15, method='beta')` 复核 `[0.3838, 0.8818]`。
2. **Wilson 区间与 R `prop.test` 的差异未核实**：R 的 `prop.test` 默认带 Yates 连续性校正，其结果与无校正的 Wilson 不同（例如 10/15 可能给出 [0.4166, 0.8543] 一类的值）。本文的 Wilson 为**无校正版本**，引用时须注明。
3. **Landis & Koch（1977）的 κ 分档未逐字核对原文**，本文只引用了社区最常转述的六档数值。
4. **Cohen's h 的 0.2/0.5/0.8 阈值是否适用于比例效应量**存在学术争议：这三个阈值主要来自 Cohen 对 **Cohen's d** 的设定，部分文献认为 h 的阈值应更严格。本文按通行做法引用，但**建议阙疑同时报 h 与绝对比例差**，不要只依赖阈值判断。
5. **McNemar 的"精确"定义不唯一**：不同软件采用不同定义（是否做 p 值加倍、是否截断在 1.0）。本文用的是"2×单尾、上限截断到 1.0"的定义（与 scipy 的 `binomtest` 风格一致），**与 statsmodels 的 `exact=True` 实现可能存在细微差异**，落库前须以 statsmodels 输出为准。
6. **Fisher 精确检验的双尾定义也不唯一**（Fisher-Irwin 的"概率 ≤ 观测概率求和"vs 其他定义）。本文用的是前者。示例 `[[10,5],[4,11]] → p=0.065595` 与 R `fisher.test` 的常见输出一致，但**未在 R 环境实测**。
7. **`statsmodels.stats.contingency_tables.mcnemar` 的确切参数名未核实**（本次只取到旧版 tedboy 镜像页面），须以当前版本文档为准。
8. **Nature Scientific Reports 2024 的 "Evaluation metrics and statistical tests for machine learning"（s41598-024-56706-x）未能取到正文**（Nature 站点重定向到身份验证页），因此本文**未引用**其任何推荐。
9. **Bootstrap BCa 论文（arXiv:2404.12967）的具体模拟结论未核实**，只核实到标题与"BCa 被称为 better bootstrap confidence interval"。
10. **`tools/` 目录的批次号命名规则（676 是否为合法下一批次）未核实**，行动 1 中的文件名须按实际批次调整。
11. **多重比较的"201 次"是上界估算**（67 规则 × 3 数据集），实际比较次数取决于实验设计，**未从仓库实测**。
