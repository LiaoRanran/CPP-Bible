# 方向 68：怎么准备复试（用阙疑这个项目展示）

> 作者画像：合肥双非本科，嵌入式方向，初试约 2027-12；项目阙疑（queyi）——67 规则 / 四态判决 / 哈希链 / Merkle checkpoint / 盲 holdout 30（真错 17，检出 66.7%）。
> 本篇凡未查到者写"未查到/未核实"，列入盲区。**复试细则每年、每校不同，2027 年必须按目标院校当年《复试录取办法》逐字复核。**

---

## 核心结论

1. **2026 年教育部首次明确"初试成绩占综合成绩权重一般不低于 50%，面试是必要环节"**，并推行"三随机"（随机次序 / 随机考核组 / 随机抽题）。这意味着**复试仍是真实的翻盘/被翻盘场**（多数院校初试:复试为 7:3 / 6:4 / 5:5），但**初试仍是主战场**，复试不可本末倒置。
2. **复试的技术趋势是"去笔试、上机试"**：华南理工大学计算机科学与工程学院、软件学院已"陆续取消传统笔试环节，改为上机能力测试"；兰州大学工程硕博专项要求"企业方专家数量超过面试组半数"。**对阙疑画像，这意味着"能现场跑通、能现场改代码"比"能背八股"更值钱**。
3. **阙疑在复试中的正确用法是"一页纸 + 3 分钟 Demo + 5 个可追问点"，而不是"我投了 NeurIPS"**。导师最反感的是"空谈虚吹、把挂名论文拿出来显摆"（知乎高赞原文），最喜欢的是"讲清问题—方法—结果—局限"的闭环。**阙疑恰好天然具备"主动承认失败"（反事实算子 P=R=F1=0）这一稀缺的诚实性证据。**

## 精确数字与案例

### 一、复试的规则底盘（2026 年政策，最权威）

据中国研究生招生信息网（`yz.chsi.com.cn/kyzx/kydt/202603/20260316/2293451739.html`，2026-03-16，来源央视新闻）：
- **"初试成绩占综合成绩的权重，一般不得低于 50%"**（教育部首次明确，2026 年）；
- **"面试是必要环节"**，侧重考查"科研潜力、实践能力、沟通逻辑"；
- **"三随机"**：随机选定考生次序、随机确定考核组人员、随机抽取复试试题；鼓励引入外单位专家；
- 2026 年调剂："调剂意向采集系统 3 月 27 日开通，调剂服务系统 4 月 8 日开通"；**志愿锁定时间最长不超过 36 小时**（此前部分院校 48 小时甚至更长），每次开放调剂系统持续时间不低于 12 小时。

**权重参考**：搜狐（`sohu.com/a/1002800173_105067`，2026-03-30）统计"2025 年各高校常见的初试、复试成绩比例为 **7:3、6:4、5:5** 三种"。掌上考研（`kaoyan.cn/article/213893`，2025-01-24）则写"复试分数占总成绩的 **30%～50%**"。

**流程与时长（掌上考研，同上）**：
- 复试时间一般 **3 月底或 4 月初**，各校复试**约两天**；
- 面试流程：**面试组织 → 抽签入场 → 面试答题 → 随机提问 → 考生退场 → 评分考核**；
- 现场通常 **5–8 位老师**（主考官 + 副考官 + 记录员），**面试约 20 分钟**；
- 结构：**专业课笔试**（多数学校先笔试，通常在面试前一天）+ **综合面试**（英语测试 / 自我介绍 / 导师提问）。

### 二、2026 年的两个新变化（对本画像极关键）

1. **"去笔试、上机试"**。华南理工大学副校长许勇（同 chsi 报道）明确："计算机科学与工程学院、软件学院**陆续取消了传统的笔试环节，改为上机能力测试**，重点考查学生编程与解决实际问题的能力。"CSDN《408 计算机考研复试上机考试备考指南（2026 版）》（2026-09-12）给出的考查配比是：**数据结构与算法占 60–70%、计算机系统基础占 30–40%，C/C++ 是首选语言**。
2. **企业专家进面试组**。兰州大学工程硕博专项"明确要求各专业领域面试组企业方专家数量应超过面试组专家人数的一半"；华南理工"部分专业邀请联合培养基地的企业专家担任评委"。**对嵌入式方向，这意味着面试官可能直接问工程问题（如"功耗测过吗""量产 bug 怎么修"），而非纯理论。**

### 三、导师到底在问什么：11 个高频问题（知乎 `p/451070499`，2021-12-29）

该文列出导师最爱问的 11 问，并给出应答要点：
1. **为什么选择我们学校？**（从"硬实力 + 软实力"回答；**不要贬低本科院校**，调剂生不要显得委屈）
2. **你读研之后的规划？**（重点在"如何做、如何执行"，不要高谈阔论）
3. **近期读了哪些书/期刊？**
4. **考研过程中遇到过什么问题？**（重点在"你如何处理"）
5. **你为什么会想跨专业？**（考验情商，强调跨专业优势）
6. **你的缺点是什么？**（不要答"脾气大/爱偷懒/效率低"，也不要说"追求完美"；说完缺点要补"如何克服"）
7. **你的兴趣爱好？**
8. **你的毕业论文做什么？**（"必须提前做足功课""能回答导师随时提出的问题"）
9. **未来几年有什么规划？**（文中标注【重点】）
10. **如果你没通过考试怎么办？**（测抗压，诚实回答）
11. **怎样证明你能比别人做得好？**（**原文警告："很多同学明明只是在本科去实验室打打杂，结果就开始空谈虚吹，甚至将挂名的论文拿出来显摆"**）

另一组"综合素质 20 问"（知乎 `p/611217733`、`p/512025199`）与"六类高频问题"（今日头条 `7598202343246578202`，2026-01-22）内容高度重叠：自我介绍、报考动机、读研规划、专业选择、优势与缺点、抗压。

### 四、自我介绍的长度共识

CSDN《保研面试/考研复试中文自我介绍模板（30 秒、1 分钟、2 分钟…）》（`weixin_43595277/article/details/120520026`）给出多档模板；掌上考研建议"中英文自我介绍，**1 分钟左右**即可"；知乎《2025 考研复试全流程解析》（`p/18509367782`）建议"自我介绍一般控制在 **1–2 分钟**"；另有 3 分钟版本模板（知乎 `p/26375895003`，2025-02-25）。**结论：准备 1 分钟 / 2 分钟 / 3 分钟三版，按现场要求切换。**

### 五、联系导师：时机与禁忌

- **时机**：今日头条《2026 考研复试联系导师的邮件怎么写？时机、格式与内容避坑》（`7592104146166235688`，2026-01-06）与知乎《复试攻略丨考研最好什么时候联系导师？》（`p/351522682`）均提示：**考本校可在初试前联系**；**外校一般在初试成绩公布后、复试前**联系。
- **内容**：知乎《考研复试联系导师邮件模板》（`p/349422372`）强调先"搜集导师研究方向、团队情况"，邮件要体现"对研究方向的了解"。
- **禁忌**：不要群发、不要只发"求收留"、不要夸大成果。**对阙疑：邮件里可以写"我独立完成了一个 C++ 静态规则验证器（67 条规则 / 3826 行引擎 / 盲 holdout 检出率 66.7%），代码与复现脚本在 GitHub，可现场演示"——这比"我对科研充满热情"强 100 倍。**

## 对阙疑的 3 条具体行动

### 行动 1：写死"3 分钟 Demo 脚本"（现场上机可用）

**落盘位置**：`_arch_v46/68_复试Demo脚本.md`（新建）。脚本严格 3 分钟，含台词与命令：

| 时间 | 动作 | 台词（口播） |
|---|---|---|
| 0:00–0:20 | 打开终端，`cd C:/CodeLearnling/note/note/C++/CPP-Bible/` | "老师好，我演示一个可被独立验收的 C++ 知识验证器：阙疑。" |
| 0:20–0:50 | 展示规则数：读取 `data/_gate_rules.json`，口播 **67 条（block 44 / warn 16 / advice 7）** | "它把 C++ 常见错误编码成 67 条可判定规则，其中 44 条是硬拦截。" |
| 0:50–1:40 | 现场跑 `python tools/gate_engine.py --check`（**先离线录屏兜底**） | "这是 3826 行的判定引擎，四态判决：pass / block / warn / advice。" |
| 1:40–2:20 | 展示哈希链 + Merkle checkpoint | "每条判决都进哈希链，Merkle checkpoint 保证结果不可篡改、可被第三方独立复算。" |
| 2:20–2:50 | 展示盲 holdout 结果 | "盲 holdout 30 个样本，真错 17，检出率 66.7%（10/15 可测）。" |
| 2:50–3:00 | 主动说局限 | "反事实算子目前 P=R=F1=0，我把它作为已知失败写进论文，没有藏。" |

**硬性要求**：① 全程**离线可跑**（考场断网）；② 提前录 1 段 3 分钟 MP4 兜底；③ **绝不现场 clone/安装依赖**（失败即灾难）；④ 结尾必须留 10 秒"我准备了 5 个可能被追问的点，老师想听哪个"——把被动答辩变成主动引导。

### 行动 2：准备"10 个必答 Q&A"（每个 60–90 秒，中英双版）

**落盘位置**：`_arch_v46/68_复试Q&A.md`（新建）。10 问如下（前 6 问来自导师高频问题，后 4 问是阙疑专属技术追问）：

| # | 问题 | 应答骨架（要点） |
|---|---|---|
| 1 | 自我介绍（1 分钟） | 双非 / 嵌入式 / 独立完成阙疑 / 数字（67 规则、3826 行、66.7%） |
| 2 | 为什么选这个学校/方向？ | 结合导师方向 + 阙疑的可迁移性（编译/内存/UB） |
| 3 | 读研规划？ | 具体到"第一年补齐形式化验证、第二年做 X 方向" |
| 4 | 你的缺点？ | "急于求成" + 已在阙疑里用"冻结协议/周计划"纠正 |
| 5 | 毕业论文做什么？ | 阙疑的扩展或嵌入式相关，**必须能答细节** |
| 6 | 没通过怎么办？ | 诚实：二战/就业两条线都已准备（呼应方向 69） |
| 7 | **盲 holdout 30 的标签怎么来的？** | 真错 17 / 对照 9 / unknown 4；人工逐个按 atom 头部注释核标签；662 A1 复核记录在案 |
| 8 | **检出率为什么是 66.7% 而不是 17/17？** | 分母是 15 个"可测"样本（10/15），不是全部 17；**口径必须自洽** |
| 9 | **外部 corpus 检出率只有 43.8%？** | 分三层：A 54.2% / B 12.5% / C 0%；C 层是"检测器不可用"，**主动登记为盲区** |
| 10 | **反事实算子 P=R=F1=0 怎么解释？** | 主动承认校准失败（662 B3），并说明这恰是"不 overclaim"的证据 |

**英文版**：至少准备 Q1（自我介绍）、Q2、Q3 的英文稿；复试英语难度"一般不超过六级"（掌上考研原文）。

### 行动 3：把"项目展示"压缩成"一页 A4 追问应答卡"

**落盘位置**：`_arch_v46/68_追问应答卡.md`（新建，单页）。内容 = 3 个数字（67 规则 / 3826 行 / 66.7%）+ 3 个文件路径（`tools/gate_engine.py`、`data/_gate_rules.json`、`data/holdout/holdout.json`）+ 1 个"我主动承认的失败"（P=R=F1=0）+ 1 个 GitHub 链接。**打印 3 份**：一份自留、一份给主考官、一份备用。**目的**：让面试官"随手一翻就能追问"，把面试变成"技术讨论"而不是"背题考试"——这正是华南理工"上机能力测试"、兰大"企业专家面试"想要的考生画像。

## 盲区（诚实标注）

- **2026 年政策（初试权重≥50%、三随机、调剂 36 小时锁定）为 2026 年考研的规定，2027 年是否延续未核实**；且各校《复试录取办法》在 3 月才发布，**必须以目标院校当年原文为准**。
- **"7:3 / 6:4 / 5:5"为 2025 年多校统计（搜狐转述），未逐校核对**；个别院校复试权重可 >50%（掌上考研原文即写"甚至大于 50%"），与教育部"初试不低于 50%"**存在口径张力**，需按校复核。
- **未查到**：2027 年"2028 考研"的官方复试时间表（须等 2027-09 教育部通知）。
- **"3 分钟 Demo"脚本中的 `--check` 命令、规则数、holdout 数字均以 `_arch_v46/00_仓库扫描.md` 实测为准**；**"67 条规则 / 3826 行 / 检出 66.7%"已在本仓库扫描中交叉验证，但 452 条判决账本、变异率等数字未独立复算**。
- **未核实**：阙疑是否能在考场机器上"离线一键跑通"（依赖 Python 版本、`tools/` 下 595 个 `.py` 的耦合度）；**必须提前做一次"干净环境"演练**，否则 Demo 有失败风险。
- **知乎多篇（`p/18509367782`、`p/26375895003`、`question/393169460`）为自媒体/问答，非官方**；"1–2 分钟自我介绍"是经验共识，非规定。
- **"上机试替代笔试"目前是华南理工等部分院校的做法，未核实覆盖范围**；多数院校 2026 年仍保留专业课笔试。
- **未查到**：双非考生在复试中被问"本科出身"时的**官方评分规则**（是否存在隐性扣分），CSDN《双非逆袭北理自动化》（2026-05-03）仅提供个案叙事。
