## 二、模型上限态（真实判断）

1. **grounded 计算——模型能独立实现，79 节点规模无任何能力疑问**：
   - 算法（Caminada 不动点，_arch_v6:24-30 已给正确形态）：UNDEC 起步，
     无 IN 攻击者→IN，有 IN 攻击者→OUT，迭代≤V 轮。纯 Python 100 行内。
   - 复杂度依据【一方称 563 调研：ARGUS UAI 2026，grounded 修复 P 类，
     preferred/stable NP 完全】——本轮未检索 ARGUS 原文复核，标注：选型结论
     （不碰 NP 语义）即使在不考虑该出处时也成立：本仓要的是"唯一机器答案"，
     NP 语义给不出唯一答案，选 grounded 是需求决定。
   - **真正的卡点不是算法是边**：攻击边从哪来？当前命题三元组
     （subject/predicate/object）没有"反驳"类型化边，KG contradicts 也只有
     7 旧类。构图必须先做：① relations 中 contradicts 的类型化（582 真语义边
     同族工作）；② 运行期 refute 事件回挂——overturned 通道 0 事件
     （数据卡点）。⇒ grounded 引擎 1 批可建，但**空转**：输入边集为空时
     所有命题必然全 IN，输出没有判别力（与 selfcheck 选卡闸同理）。
2. **AGM 最小改变——模型可设计，定义选择是关键**：
   _arch_v6:46-49 给的口径（论证状态最小改变，非图最小改变；等小多解全部
   UNDEC 交人）可直接落地为"加攻击边前后三值标注 diff"。工程上零新依赖；
   卡点同上（边），以及"最小"的语义口径需人先拍板一次。
3. **第三方环节——单用户下的真实分级（我的判断）**：
   - **可做到**（模型内）：① 异族模型作评审第二意见（独立性按有效票打折，
     2026 一手证据：9 模型≈2 票，arXiv:2605.29800【已查证正文】）；
     ② git 历史作第三方时间线（不可本地伪造而不留痕——但 rebase 可重写，
     需配合推送后的远端，属带外）；③ 带外清单（如公开时间锚，见维度10）。
   - **做不到**（结构性）：真正的多主体（第二个利益相关人）、机构型第三方
     托管。单用户下"第三方"只能是**机制**（链/异族/远端），不是**人**。
4. **grounded 与 gate 三分类对接——可设计**：
   grounded 的 IN/OUT/UNDEC 映射到"当前可接受/拒绝/争议"；gate 的 block/warn/
   advice 是**规则级**处置，grounded 是**命题级**接受——两层正交：OUT 命题
   引用方应 warn（与维度2 stale 联动是同一个工程钩子）。不存在语义冲突，
   但当前无任何代码桥接。
5. **分权的理论极限——我的核心判断：单用户只能做到"角色化"，做不到"分权"**：
   立法/行政/司法最终都是同一人按键；异族模型是该人**雇佣**的角色，可被
   换岗/忽略。能构造的最大保证：
   ① 角色留痕强制化（drafted_by/reviewed_by family 元数据，同族 ⇒ 规则
     不生效）——把"自写自测"从默认变成需显式 override；
   ② 机械 Oracle 否决权不可配置移除（铁序，代码常量而非开关）；
   ③ 人必须在"看过分歧清单"后才能签字（清单机器生成，签字动作机器记录）。
   ⇒ 这是"伪分权"的天花板：**保证程序被遵守，不保证权力被制衡**。563 设计
     B 节方向正确，但把它写成"分权"会过度承诺，诚实名称应是"角色留痕与
     强制审查顺序"。

## 四、卡点与解冻信号

1. **论证引擎——工程卡点，但输入边是前置**。信号：① 真语义边落地（依赖维度6）；

   主体（人）；异族/公开链只能补"机制第三方"，不应被描述为分权。
