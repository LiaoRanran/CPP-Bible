# 562-04 · 现在借什么、等什么（从六个范式里挑，必须小而确定）

> 检索日期 2026-09-17。纪律：不给"等 AGI"式万能解；每条"现在借"必须能落成一句可执行动作 + 机器验收；"空想"必须给出为什么现在想也是空想。

## A. 现在就能借的（两块半，均 <1 天工作量量级）

### A1【可借·实证依据最强】把"共享状态放到 agent 外部"（来自 Lean/FLT 的 Prove2Me 教训）

- **来源事实**：Anthropic 2026-09-04 形式化 FLT 时，第一次多 agent 尝试失败（互相忘记进度、停止协作）；转机是 Prove2Me——**定理语句 DAG + 自然语言描述 + 语句/证明分文件**放在 agent 外部，agent 从图中拉任务（[Anthropic](https://www.anthropic.com/news/formalizing-fermats-last-theorem)；[流程报道](https://clauding.de/en/posts/claude-beweist-fermat-lean-11-tage/)）。失败尝试的残留行仍占最终证明 ~7%。
- **阙疑的现状**【事实】：534 已把 handoff/checkpoint/task_queue 建到"任务级共享状态外部化"；**命题级**（claim_structured 命题的证明状态 DAG）还没有——79 条命题的"哪条被证到哪一步"仍散在卡与报告里。
- **现在借什么**：给 `data/` 增一张**命题状态图**（`data/propositions/state.jsonl` 或复用 task_queue 的 events）：每条命题 `{prop_id, status: unproved|drafted|machine_verified|human_signed|refuted|suspended, evidence_refs[], updated_at, by}`；生成器就是一个从卡 frontmatter 聚合的小脚本，零新依赖。**让"下一条该证什么"可查询**（= 他们 Prove2Me 的"从 DAG 拉任务"，本仓以文本查询形态等价）。
- **机器验收**：79 条命题 100% 可查状态；"被 refute 的命题→卡→suspect 列表"一条命令得出（和 534 yield/handoff 的接口对齐）；新增/修改卡后重生成幂等（两次跑 diff 为空）。

### A2【可借·理论根据最硬】把"不信自报"从铁律升格为**带证明边界的公开立场**（来自对齐不可判定性）

- **来源事实**：内对齐验证不可判定（Rice/Gödel/Trakhnenbrot 三堵墙，[arXiv:2606.28639v1](https://arxiv.org/html/2606.28639v1)；Nature Sci Rep 2025 同结论）；可解释性只可做到"faithfulness gap 的上界"而非 faithful 本身（[arXiv:2609.15533, 2026-09-14](https://arxiv.org/abs/2609.15533)）。
- **现在借什么**：不为技术，为**叙述与流程**：①在投喂词/治理文档里把"不信模型自报"的根据从"经验教训（E12 等）"补上"数学根据"（引用上面两条），使规则不可被"模型变强了能不能放松"的讨论漂移——**放松只可能发生在'行为证据更强'的方向（蜜罐/毒样例/阴面），不可能发生在'心理状态验证'方向**；②把"解释性主张"挡在门外的现行做法（禁 LLM-as-judge 终审等）写成一条显式原则：**任何要求'证明模型内心没有欺骗意图'的提案，引用不可判定性直接否决**；只接受"证明某具体欺骗行为在给定输入下发生/未发生"（control 路线）。
- **机器验收**：治理文档里该原则可被 grep 到并带引用；下一次"要不要让模型自审"类讨论有单点否决依据（本轮已把此原则写入 03 §5）。

### A3【半块·接口预留】Oracle 身份进判决记录（来自可验证计算与透明日志的"信任迁移"）

- **来源事实**：zkVM 的 TCB 没消失只是迁移（STARK 去掉 setup、却暴露 trace 生成为新瓶颈，[ZK-Tracer](https://arxiv.org/html/2605.25493v2)）；透明日志把信任迁移到 OIDC/CA/监控者（[Sigstore](https://docs.sigstore.dev/)、[Rekor evolution 2026-06](https://blog.sigstore.dev/rekor-evolution/)）。
- **现在借什么**：判决记录加 `verified_by_oracle` 字段（工具链 id+方法+策略版本），**只写不读**（03 §3.1 已列）。以及一条纪律：任何"信任基础设施也会漂移"的现实（PQC 迁移、Rekor v1→v2）提示我们，**证明/日志方案本身要有版本号和迁移预案**——本仓对应物就是 toolchain_id 已进 sha 归属，补"策略版本"即可。
- **不借**：仓内上 Sigstore/Rekor 实物（本轮确认：单人本地仓库，引入外部透明日志 = 造运维负担；等 principal_ok 多主体化再评估）。

## B. 现在想也是空想的（各自理由）

| 方向 | 为什么现在想是空想（不是"等 AGI"万能解，是具体理由） |
|---|---|
| **zkVM 证明编译过程** | 【事实】把 g++ 放进 zkVM：10M cycles ≈ 2.3s 证明成本；而本仓单卡真编译 1.6–1.8s（560 实测）——证明开销 ≥ 计算开销的量级，且证明的是"某二进制跑了"不证明"编译器对"。在本仓规模是纯负担。触发条件：证明成本降到同类计算的 10% 以下 **且** 本仓出现"需向第三方证明验证过程"的真实需求。 |
| **形式化整库（Lean 化 C++ 知识）** | 【事实】FLT 单证明 13M 行、5× Mathlib 体量、~$30 万 API 成本、96 核编译 20× Mathlib——一次"验证搬移"的现价。本仓知识域是"编译产物的经验事实"（asm 里有没有 `lock`），**不是待证明的定理**；把它 Lean 化是无对象的形式化。（Lean 化适用于"有命题体系"的知识，本仓 future work 是命题体系本身先在 03 §3.4 过程中长出来。） |
| **证明走廊/全链 zk 归约** | 与 §1 冲突：找终点的路线。 |
| **AI 自动科研闭环（L4 进化层对标 AI-Scientist）** | 【事实】四尝试三失败的六大失败模式（[arXiv:2601.03315](https://arxiv.org/html/2601.03315)）+ 38.9% gradient hallucination + Refutability Gap——行业自己在 2026 年的诚实水位。**阙疑的 L4 现在该做的不是"进化层"而是 A1 的命题状态图**（先有可查询的"我错在哪"，再谈自动化发现）。触发条件：命题状态图 + 逃逸率曲线跑满两个季度（03 §3.3）。 |
| **人签升级为 proof-of-humanity / 链上身份** | 【事实】本轮未取得 2025–26 一手来源，不展开——**没有可信来源就是"现在想是空想"的诚实理由**；等 principal_ok 出现"多主体互不信任"的真实场景再说（当前单用户，问题不存在）。 |
| **用 active inference / free energy 当架构理论** | 【事实】该框架"难严格证伪、难扩展"（[综述](https://research.mental-momentum.ai/r/free-energy-principle-active-inference-rc1whn)）；且能动性理论仍在"四条件、无单一阈值"阶段（[arXiv:2606.23122v2](https://arxiv.org/html/2606.23122v2)）。若阙疑拿它当锚，等于让自己犯 Refutability Gap 指责别人的错。 |
| **给"智能是什么"下定义** | 【事实】Legg-Hutter 有 UTM 相对性（换机器可以让任意 agent 最优，[arXiv:2503.23923](https://arxiv.org/pdf/2503.23923.pdf)）；领域前范式。**现在可做的替代**：不定义智能，只维护"在给定 Oracle 下知识边界推进的记录"（A1+A2 已覆盖）。 |
