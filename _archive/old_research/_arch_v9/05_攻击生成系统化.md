**唱反调（先找不适用）**：
1. **TCE 不是万灵**：它依赖"产物可比"，而 2024 那篇实证说明自动等价判据在**人工等价变异体**上仍有漏（作者构造的等价变异体常常产物不同）。⇒ 本仓若用 TCE 式判据，**只能用于"剔除已确认等价"（缩小分母的噪声），不能用于"证明不等价"**。
2. **覆盖引导 fuzzing 的收益取决于输入空间**：本仓的变异对象是**卡面 YAML（有 schema）**，不是任意字节；对结构化输入，**文法/Schema 引导**比字节级 fuzz 更合适，而"文法"本仓**已经有**（`parse_frontmatter` + 规则读取面 `_gate_read_spans`）。
3. **LLM 红队今天进不来**：需要模型 + 没有错误率上界 + 属冻结项。它在**攻击生成**上确实强（生成"语义上真的弱化断言"的变异），但那正是 §四 W1 的门槛。

**只读可见的关键事实（为 §四 N 铺垫）**：M6 的变异点是**格式层**的（YAML 写法/键名形态/缩进），而**本仓的判决读取的是解析后的 frontmatter** ⇒ **若某变体经解析后与原文等价，则任何只读 frontmatter 的规则都不可能产生新 finding** —— 这类变体的"逃逸"是**等价变异体**，不是门禁漏洞。**今天没有这道判据，所以它们被算进了 escaped。**

## 三、差距与风险

1. **缺口 1（核心）**：**没有"变异体是否真的改变了判决可见面"的独立判据**。现在只有 `vtext == text`（字面）与 `out_of_scope`（M2 专用）。
2. **缺口 2**：**没有攻击集质量指标**（多样性/覆盖/等价占比）⇒ "攻击在进化"无法被机器证伪。
3. **缺口 3**：**M6 逃逸未定性** ⇒ 逃逸率口径里混着两类东西（真洞 + 等价变异体），这正是 v1→v3 三次口径修正的同类病根。
4. **风险 A**：等价判据**假阳性**（把真逃逸标成等价）会让"逃逸率"变好看——**这是最危险的攻击面**。⇒ 判据必须满足：① **不改 verdict**（只加字段）；② 判据**独立于判决**（不调 gate）；③ 报告里单列，且**分子分母双向可见**（既报"剔除了几条"，也报"剔除后分母还剩多少"）。
5. **风险 B**：等价判据**过度通用**（比如"只要解析器容忍就等价"）会把**真实的解析器走私漏洞**洗掉（例：全角键名 `ｉｄ` 若被 PyYAML 容忍但被门禁的硬化规则判为走私，则**不等价**！）⇒ 判据必须用**两个独立解析器**（见 N 的实现），单解析器相等**不算数**。

## 四、N / D / W

**N（现在借，1 件）——规范化等价变异体剔除（报告层字段，`equivalent`）**

**判据（形式化）**：设 `P₁` = 仓内 `atom_evidence_replay.parse_frontmatter`（PyYAML `safe_load` 路径）、`P₂` = 硬化路径使用的 `_UniqueKeyLoader`（`gate_engine` 里那套四信号解析，`_fm_hardening_uncached`）。对变体 `T'` 与原文 `T`：
```
equivalent(T, T')  ⟺  canon(P₁(T)) == canon(P₁(T'))  ∧  canon(P₂(T)) == canon(P₂(T'))  ∧  op ∉ {M1, M7}
```
- `canon(·)` = 解析结果的**规范化字符串**：键按字典序、去注释/去空白差异、数值/布尔等价化（`1` vs `true` 的差异**要保留**——它们对硬化规则是信号）。
- **`op ∉ {M1, M7}` 这条条件是硬边界**：M1/M7 的判决还会走 replay（读**工件与命令**），frontmatter 相等**不足以**判等价（那需要 TCE 式的产物比对，见 W2）。
- **语义**：`equivalent=True` ⇒ "该变体**在任何只读 frontmatter 的规则下**都不可能与原文有不同 finding"。这是**保守且可证伪**的：任何反例（用同一对 `P₁/P₂` 找到一条规则给出不同 finding）都能推翻它。

**字段落点（只加不改）**：`_card_variants` 的每条 per 记录加 `"equivalent": true|false`；`n_a` 细分类里加 `equivalent` 计数；`_variant_index()` 的 5 字段（`verdict/kind/why/new_block/new_warn`）**不含** `equivalent` ⇒ 579/580 的确定性对账**逐字不变**。

**机器验收**：
1. **不改判决**：对同一输入，加字段前后的 `_variant_index()` 完全相等（字典相等，逐变体）；`blocked/escaped/n_a` 三总数不变。
2. **保守性自证**：对每条 `equivalent=True` 的变体，跑一次"原文 vs 变体"的 finding 集合差（**在同一沙箱内**）⇒ 差集必须为空；**若非空 ⇒ 判据假阳性 ⇒ exit 非 0**（这条把"判据不能洗真洞"变成机器锁）。
3. 对 v5 的 1183 变体给出一张表：每算子 `equivalent / out_of_scope / malformed / 真可判`。
4. 两次跑一致（沿用 `--selfcheck-determinism`）。

**零误伤证据**：`classify()` 一行不动；`_findings_key`/`_snapshot` 不动；分母定义不动（`equivalent` 与 `out_of_scope` 一样进 `n_a` 细类）；`--jobs` 并行路径共用 `_card_variants` ⇒ 自动一致。

**M6 那 8 条的定性方法学（本 N 的直接应用，不需改任何判决）**：
1. 取 M6 的 332 个变体（v5 里 M6 全量），对每条算 `equivalent`；
2. `equivalent=True` 的 ⇒ 记"**无效变异**"（攻击集缺陷，不是门禁缺陷）⇒ 修的是**算子**（让 M6 只变异"解析后确实不同"的形态）；
3. `equivalent=False` 但 `verdict=escaped` 的 ⇒ **真逃逸候选** ⇒ 逐条做静态归因：该变异点**语义上弱化了哪条规则的判据**（对照 `EV-FM-*` 的判据面清单），输出"规则缺失"（没有规则覆盖该形态）或"规则漏检"（有规则但条件没覆盖）；
4. 产出：M6 逃逸的 `{equivalent / 规则缺失 / 规则漏检}` 三类计数 + 逐条清单。**这一步只读、不跑 gate**（用的是已有的 v5 报告 + 卡文本 + 解析器）。

**D（攒数据，2 件）**

- D1：**攻击集质量面板**（进 mutation 报告，只加字段）：① `equivalent_rate`（按算子）；② **攻击面覆盖**：`|被任一变异体产生新 finding 的规则| / |规则总数|`（本仓今天可算：v5 报告里有 `new_block/new_warn` 的规则 id）；③ 变异点多样性（不同 `point` 形态数 / 变体数）。
- D2：**每条逃逸的定性登记**（人/强模型，机器只列缺）：逃逸 → `{equivalent | 规则缺失 | 规则漏检}` + 证据行；落 `data/mutation/escaped_triage.jsonl`（新文件，不碰判决）。门槛：连续 2 批把新逃逸当场定性（否则"M6 8 条"会像 564 的挂账一样长期悬空）。

**W（等条件，3 件）**

- W1：**LLM 红队生成变异体**（PyRIT/Garak 那一族）。解冻信号：① 模型裁判误判上界 ≤1%（与本仓既有放行门同口径）；② 生成物**必须**过 W 门槛的确定性判据（`equivalent=False` + 产物比对）才允许进攻击集；③ 属"线索通道"，**不许**直接改 verdict。
- W2：**TCE 式产物等价（编译后比对）**。解冻信号：① 需要给 M1/M7（工件/命令类）算等价；② 已有"编译产物规范化"的稳定表示（`artifact_sha256` 是字节级，跨编译器不可用；需要**规范化 asm** 或**行为级**比对）；③ 2024 那篇的经验评估读通并承认其不完备性。**现在不做**：收益只覆盖 M1/M7（v5 里 escaped 只有 1 条来自 M1），成本是把编译引入报告路径。
- W3：**覆盖引导/文法引导的变异生成**（用本仓 schema 作为文法）。解冻信号：① 手写算子**连续 3 轮**无新发现（`new_findings_per_round → 0`）；② 已有"变异点必须落在读取面"的机器判据（M2 的 `_gate_read_spans` 已是一半）；③ 语言/工具在 Windows + 纯标准库可跑（本仓无第三方依赖偏好）。**现在不做**：7 个算子的产出还在变化（v5 仍有 9 条 escaped），先定性再扩产。

## 五、一句话给监工

> **本批唯一"零风险、可立刻上"的，是把"变异体到底有没有改变判决可见面"变成一个**可证伪的机器字段**（N）：它*不改*任何 verdict，却能立刻回答"M6 那 8 条里哪些根本是无效变异"——而这正是逃逸率口径第四次修正前必须先分清的事。
