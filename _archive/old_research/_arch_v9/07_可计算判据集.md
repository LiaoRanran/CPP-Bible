## C1 · 规范化等价变异体（本批头号判据）

```
equivalent(T, T') ⟺ canon(P₁(T)) == canon(P₁(T')) ∧ canon(P₂(T)) == canon(P₂(T')) ∧ op ∉ {M1,M7}
```
- **P₁** = `atom_evidence_replay.parse_frontmatter`（PyYAML `safe_load`）；**P₂** = `gate_engine` 的硬化解析路径（`_UniqueKeyLoader`，四信号用）。
- **canon(·)**：解析结果 → 键排序的稳定序列化；**保留**类型差异（`1` vs `true` 是硬化规则的真实信号，不许归一）。
- **输入**：卡原文 + 变体文本（mutation 报告里已有 `card/op/point`，变体文本需重算或落盘）。
- **样本量**：无（逐变体判定）。
- **假设**：该 op 的判决只读 frontmatter。—— **对 M1/M7 不成立**（它们还会走 replay 读工件/命令）。
- **不成立时**：M1/M7 的等价判定需要**产物级**比对（TCE 式，见 `05` 的 W2）；**在那之前，M1/M7 一律 `equivalent=False`**（保守）。
- **能算**：能。已给机器验收（假阳性自证：`equivalent=True` 的变体在沙箱内与原卡的 finding 差集必须为空）。
- **为什么必须两个解析器**：单解析器相等会把"**解析器走私**"洗成等价（例：全角键名 `ｉｄ` 若被 P₁ 容忍而 P₂ 判为走私 ⇒ 两者结论不同 ⇒ 不等价）。**这条是防"自己洗自己"的关键。**

## C4 · α 花费版置信区间

```
cp_interval_spent(k, n, looks, conf) = cp_interval(k, n, 1 - (1-conf)/looks)
```
- **语义**：只要总"看"的次数 ≤ `looks`，则这 `looks` 个区间**同时**覆盖真值的概率 ≥ `conf`（Bonferroni；保守但**自证**，不依赖任何外部论文细节）。
- **自检（可证伪）**：① `looks=1` 时**逐值等于** `cp_interval(k,n,conf)`；② 宽度对 `looks` **单调不减**。
- **输入**：k/n（任意批次）+ 声明的 `looks`。
- **样本量**：无（但解释力受 n 限制，见 C6）。
- **假设**：各次"看"用的是同一把尺子（否则被检验的就不是同一个量 —— 见 C5 前置 1）。
- **能算**：能（纯新增函数，零依赖）。

## C5 · "逃逸率在降"的判定（**今天不能算**）

**判据（四条全满足才允许宣称）**：
1. `ruler_fingerprint` 相同（定义：`sha256(排序后的 gate 规则 id 集 ‖ mutation 算子集 ‖ 口径版本 ‖ oracle 三元组)`）；
2. 参与比较的每批 `judged ≥ n_for_upper_bound_zero(0.05, conf_t)`（`conf_t` 为花费后的置信度，**具体数值须由函数算出，不在此写死**）；
3. **区间分离**：`U_latest < L_baseline`（同一 `conf_t` 下）；
4. **批数 ≥ 6**（纪律门槛，非统计定理）。

- **输入**：`data/metrics.jsonl` 的批次元数据（**今天缺** `ruler_fingerprint` 与 `judged/k` 的完整序列）。
- **今天能否算**：**不能**。缺：① 尺子指纹字段；② 连续 6 批同尺子数据（现 4 条记录、1 条含曲线，且 v1→v5 是尺子变更史）；③ 每批 n 达标。
- **不成立时**：报告只能写 `insufficient evidence for trend`（**不许**写"在降"）。
