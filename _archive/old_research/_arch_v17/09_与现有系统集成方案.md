# 09 与现有系统集成方案（replay / metrics / gate / in-toto(601)）

> 所有集成均保持 fail-closed 与"校验工具只读"契约（见 `atom_evidence_replay.py` 1456-1470）。

## 9.1 与 replay（`atom_evidence_replay.py`）的集成

### 9.1.1 升级 `_recompile_invariant`（阶段 1/3）
- **现状**（代码行 1409-1449）：独立重编译 + `CCACHE_DISABLE=1` + 临时目录 + 比 sha → tampered/ok/unavailable/infra。
- **集成点**：在返回 `ok` 前，追加 **符号表一致性**（`nm` 导出后逐条比对）与 **关键段一致性**（`readelf -S` 取 `.text`/`.data` 段 sha）。失败归入 `infra`（编译环境问题，非内容证伪，对齐 1458-1463）。
- **跨时间窗口**：间隔 >1s 重编译，验证 `__TIME__` 不漂移（05 §5.4）。

### 9.1.2 verdict 分流新增 TV 维度
- 当前 verdict 维度：run_match / artifact_sha / recompile_inv / extra_arts / negative_controls / sanitizer。
- 新增：TV 维度失败时 → `infra_error:tv_unreproducible`（不误判 refute）。

### 9.1.3 保持"只读契约"
- 现有 `restore_artifact` 默认 True（1724-1735）确保校验不改写被校验对象；TV 集成不得破坏此契约（只在临时目录重编译，见 1409 设计）。

## 9.2 与 metrics 的集成

- **新增指标**：
  - `build_reproducibility_rate` = 可复现卡数 / 总卡数（阶段 1）。
  - `translation_validation_pass_rate` = TV 通过卡数 / 总卡数（阶段 3）。
- **待修复清单**：不可复现 / TV 失败的卡写入 `data/`（如 `build/repro_issues.json`），供 gate 引用。
- **实现**：在 replay 的 `--json` 输出（1980-1998）中追加 `translation_validation` 字段，metrics 流水线消费。

---

## 9.3 与 gate（`gate_engine.py`）的集成

- **现状**：gate 已有 63 条规则（见本次 `--check` 输出），命中 191（block=0 warn=186 advice=5）。
- **新增规则建议**：
  - `REPLAY-BUILD-REPRO`：编译可复现率 < 阈值 → warn（不 block，因环境相关）。
  - `REPLAY-TV-PASS`：TV 通过率 < 阈值 → warn。
- **保持 fail-closed**：gate 自身规则不得降低 replay 的 block 判定。

---

## 9.4 与 in-toto / SLSA（601 供应链溯源层）的集成

- **replay_verify step 的 inspection**：将 TV 结果登记为 in-toto link 的 inspection（参考 600 的 in-toto layout 设计）。
- **Merkle 溯源**：编译可复现率 / TV 通过率作为 build definition 的**确定性证明**写入 SLSA provenance（600 已深挖 Merkle/OpenTimestamps 锚定）。
- **闭环**：replay（本调研）→ in-toto link（601）→ Merkle 根（600）→ OpenTimestamps 锚定，形成"编译可证 → 溯源可证"的完整链。

## 9.5 集成风险与对策

| 集成点 | 风险 | 对策 |
|---|---|---|
| replay `_recompile_invariant` 升级 | 改动核心判定逻辑，可能误伤 confirm=56 | 增量模式（1805）先 skip 未变卡；CI 守门 `--check` |
| gate 新规则 | 误 block | 先 warn 观察一轮再升级 |
| metrics 新字段 | 破坏现有 JSON schema | 向后兼容追加字段（1980-1998 已用 dict） |
| in-toto link 扩展 | 与 601 格式冲突 | 对齐 601 的 inspection 约定 |
