## 二、模型上限态（真实判断）

1. **命题闭包——P 类，模型能实现，规模到 1000+ 无压力**：
   prop_evidence 是现有表（prop_graph.py:110-114），WITH RECURSIVE 闭包是标准
   SQL；79 节点闭包成本可忽略，1000 节点仍为 O(V+E)。卡点纯工程。注意闭包语义
   只是"证据可达"，不是"论证成立"（后者见维度9 grounded）。
2. **KG 三种真语义边——模型能写判别规则，但规则质量无独立验证手段**：
   582 调研所称三种边【一方称，本轮未读到原文逐条】。基于 claim_structured 的
   subject/predicate/object 三元组（prop_graph.py:99-101），规则可从命题文本
   模式归纳；卡点是**边的正确性等于命题标注质量**——误标一条 proposition 就
   产生一条错边，而命题内容机器不判真伪（只判结构）。⇒ 边的可信度上限 =
   命题标注可信度，后者当前无度量。
3. **MIS 弱 Oracle 判官——这是本维度差距最大处，我的诚实判断：模型能做
  "一致性/相关性"机检，不能做"真伪"判定**：
   - 可机检（模型可设计）：① 反驳内容的**逻辑结构**（refutations≥2 已查，
     可扩到反驳论据与命题的关键词相关性）；② 引用 ID 与被反驳命题的
     主题一致性（NLI 类相关性打分——但 LLM 打分自身误判率未知，且 2026
     实证显示多判官在 NLI 上错误相关，见维度8）；③ 来源分级（URL 域/出版
     类型的机械规则）。
   - 不可做：判定"MIS 命题是否真是常见误解、反驳是否真成立"——这是领域
     事实判断，需要外部 ground truth（实证研究/真缺陷），本仓 0 此类数据。
   ⇒ 所谓弱 Oracle 只能弱在"结构更严"，不能弱在"内容更真"；把 LLM 相关性
     打分当真伪判据，等于让模型自证（582/585 已警告，本轮同意）。
4. **memory_query.py——模型可设计，查询语义=对既有只读视图的统一检索**：
   可查命题/卡/MIS/as-of，结果可验证（每结果带卡路径+行）。卡点不是模型
   能力；知识层真正缺口是**外置知识双通道**（582 物理隔离设计【一方称】），
   当前 0 落地。
5. **50 条 liveness 锚——模型可半自动生成候选，不可自动入卡**：
   data/prop_liveness_todo.md 已给"建议可锚符号"（如 `_Z10spin_plainv`），
   其来源是机器从工件断言反查。自动补锚的伪造风险：模型可生成"看起来特有"
   的符号但实际不在工件中——**防法已存在**：符号必须在该卡 artifact_assert
   真编译结果中命中（check_artifact_assert，atom_evidence_replay.py:663），
   对不上即 refute。故"机器提议 + 工件机器核验 + 人审写入"模型内能闭环，
   但当前纪律是"机器绝不写入卡面"（prop_liveness_todo.md:3）——这是人审
   依赖的政策选择，不是能力缺口。
6. **规模化边界**：79→1000 命题，SQLite 查询/闭包无压力；可视化（kg dot 图
   已 871 行 learning_path.dot）在 200+ 节点后不可读，需切视图——纯工程。

## 四、卡点与解冻信号

1. **MIS 真伪——ground truth 结构性缺失**。信号：外部实证语料接入（认知科学
   研究/真实学习者错误数据），或异族+人审逐条背书；在此之前"弱 Oracle"
   不得宣称判真伪。
2. **知识边可信度——标注质量无度量**。信号：命题抽样人审一致性 + 误标→错边
   的连锁率有数字（当前 0 数据）。
3. **liveness 写入——人审政策**。信号：人确认"机器核验通过即可写入"的政策
   变更；当前纪律明确禁止。
4. **外置记忆——纯工程大项**。信号：582 规格分批实施；最小可用入口
   memory_query 可先做。

## 五、本维度自由探索

1. **命题网络的"真值"与"接受度"应分层**：当前只有签署/机验状态，没有"论证
   状态"（维度9）。在 grounded 计算落地前，命题层给不出"当前可接受集"，
   图谱再密也回答不了全局问题——这是比补边更根本的缺口。
2. **MIS 是唯一面向"学习者会怎么错"的资产**，但与证据卡无双向引用闭环
   （ATOM-MISCONCEPTION-REF 只单向查存在）。若 MIS 被推翻，引用它的原子卡
   无联动——与维度2 的引用 stale 缺口同族。
3. **命题数增长的真实约束不在计算在人**：79 条已对应 27 卡，1000 条需要
   约 300+ 张经人/多轮核验的卡，单用户产能是硬限制。
