# MIS-MEM-012（misconception）

## 正面

【误解】MIS-MEM-012 移动一定比拷贝快，所以到处加 std::move 准没错
触发说法：move 肯定比拷贝便宜，无脑加就行

## 背面

为什么错：移动的收益来自**避免深拷贝**（掏空源对象）；对纯值类型（int、小 POD、无堆资源的聚合）移动与拷贝生成的代码完全相同——实测纯值组必搬 32 字节 SIMD，指针组只搬 8 字节，前者 move 无收益
反例 1：无收益却加了 move 会额外引入'源对象处于有效但未指定状态'的语义负担，且用在返回值上会阻断 NRVO（见 MIS-MEM-003）
关联原子：ATOM-MEM-MOVE-002
