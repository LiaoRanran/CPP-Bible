# 527 批次F 概念别名表（概念层归一：Book/ 口语写法 → 原子层规范名）
#
# 语义（knowledge_graph.load_concept_aliases / _canon_concept）：
#   命题的 subject/object 若是本表某个**别名**，入 concept_edges 前归一到左侧规范名。
#   这样"同一概念的两种写法"在图谱里是一个节点，矛盾检测/覆盖度统计才成立。
#
# 匹配口径：**整串精确匹配**（去首尾空白 + ASCII 大小写不敏感），**不做子串替换**。
#   为什么不做子串：`锁` 是 `自旋锁`/`死锁`/`加锁` 的子串，子串改写会把
#   `自旋锁` 变成 `自旋互斥量(mutex)` 这种胡说；`fence` 也嵌在 `atomic_signal_fence`
#   等标识符里。概念名是**命题级短语**，只该整串认。
#
# 格式（一行一条）：`规范名 <- 别名1, 别名2`
#   * 左侧 = 规范名（须与原子层命题里用的写法一致）
#   * `#` 起始为注释，可写行尾注（用于附词频证据）
#   * 空行忽略
#
