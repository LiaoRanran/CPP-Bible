# MIS-PERF-003 · Debug / -O0 下测出来的性能能代表发布版

**层级**：deep —— 结构性误解，须 ≥2 条独立反例才可能纠偏（认知科学依据：一次纠正不够）

## 触发模式（学习者常这么说 / 这么写）
- 我本地跑了一下，性能就是这样
- -O0 和优化后差不多

## 为什么它不成立
1. -O0 不做内联/向量化/常量传播，瓶颈分布与发布版完全不同；结论不可迁移
2. 此外短函数计时需考虑时钟自身开销（~25ns）与冷启动页错误，须预热 + 多次采样
