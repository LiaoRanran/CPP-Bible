## 1. 先把三个统计概念钉死（苦力照此实现，约 60 行）

- **二项模型**：n 次独立伯努利试验，k 次"坏事件"（误伤/逃逸），坏事件率 p。
- **Clopper-Pearson 精确区间**（最保守，推荐用于放权门判据）：
  - 下界：k=0 时 0；否则 B(α/2; k, n−k+1)
  - 上界：k=n 时 1；否则 B(1−α/2; k+1, n−k)
  - k=0 上界有解析解：**U = 1 − α^(1/n)**
  - B(q;a,b)=Beta(a,b) 的 q 分位（脚本里用 Numerical Recipes 风格连分式 + 二分）。
- **Wilson 区间**（近似，报告用，样本小时比 Wald 稳）：脚本已实现，与 C-P 对照。
- **rule of three**：α=0.05、k=0 时 U≈3/n，是 C-P 解析解的近似（1−0.05^(1/n)≈2.996/n）。
- **样本量（0 失效声明）**：要让 0 失效时上界 ≤ ε @置信 1−α：**n ≥ ln(α)/ln(1−ε)**。
- **样本量（已知率 p 的 ±ε 半宽，Wald）**：n ≥ z²p(1−p)/ε²（z=1.96）；p 未知取最保守 p=0.5。

## 2. 数字一：56 卡 0 误伤 ⇒ 误伤率上界 = 5.21%

| 输入 | 值 | 来源 |
|---|---|---|
| n | 56 张证据卡 | replay confirm=56；61 规则存量 block=0（ledger §4 / 投喂词口径，2026-09-17 复算一致） |
| k（误伤/block 命中） | 0 | 同上 |

**结果（C-P 精确单侧上界）**：
- 95%：**0.0521（5.21%）**
- 90%：0.0403（4.03%）
- 99%：0.0789（7.89%）
- rule-of-three 近似：3/56 = 5.36%（与精确解 5.21% 差 0.15p，n=56 已足够接近）

**这个数字怎么读（重要，别读错）**：
- 正确读法【事实+统计定义】：**若**每张卡上"规则误伤"是独立同分布伯努利事件，则"该规则集对同类卡的单卡误伤概率"在 95% 置信下不超过 5.21%。
- **它不证明"零误伤"**；56 个样本区分不了"p=0"和"p=5%"。
- **假设何时不成立（必须诚实）**：
  1. **独立性不成立**：56 卡共享同一套规则函数与解析器——若规则有系统性盲区（如恒真符号类），56 张卡是 56 次相关观测，有效样本量远小于 56；此时 5.21% 是**乐观上界**。
  2. **代表性不成立**：56 卡是当前手写库（mem 类为主、模板/并发覆盖薄），不是"未来所有卡"的随机样本；上界只对"与现库同分布的卡"成立。
  3. 因此 G-iso 开门若写"56 卡 0 误伤 ⇒ EIR≤5%"，在严格统计口径下**勉强卡线但前提脆弱**；正确用法是把 5.21% 当**基线观察值**，用 §4 扩样 + 独立来源（异族红队造卡）补独立性。

## 3. 数字二：mutation 拦截率的置信区间（1188 变体真实数据）

> JSON 里记录的 strict_rate=0.6433 与当前文件重算 0.6136 不一致（差约 3p），说明该文件是中间版本快照或当时分母口径不同（strict_blocked 字段=615≠729）。【事实】**基线文件自身口径不自洽**——这是第一个可执行修复：报告生成器必须同时写分子分母，禁止只写比率。Wilson 区间 61.4%=[58.6%,64.1%]，与 C-P 几乎重合（n 大，两法趋同）。

**能外推到"未见过的变异"吗？不能直接外推，理由**：
1. 1188 变体由 7 个**固定算子**机械生成，是封闭算子空间的采样，不是"所有可能逃逸"的随机样本；区间只描述"这 7 个算子按当前生成分布"的拦截率。
2. 232 个 N/A（M3 占 75、M5 占 83）说明算子在大量卡上不适用——可判子集有选择偏差。
3. equivalent mutants（变异后语义等价、本不该拦）混在 escaped/n_a 里未甄别，逃逸率被高估或低估方向不明。

**算子级分解（这一层最有决策价值，C-P 95% 逃逸率区间）**：

## 4. 数字三：要宣称"逃逸率 ≤5% @95%"，样本量门槛

n ≥ ln(0.05)/ln(0.95) = **59**（0 逃逸精确解；脚本 ceil）。完整反查表：

| 目标上界 ε | 置信 | 所需最小 n（0 逃逸） |
|---|---|---|
| 10% | 95% | **29** |
| 5% | 95% | **59** |
| 2% | 95% | **149** |
| 5% | 99% | **90** |

**已知率时的连续监测量（Wald，z=1.96）**：
- 按当前 treated 逃逸率 23.7%，要 ±5p 半宽：n≈279（z²·.237·.763/.05²）；
- 最保守 p=0.5：±5p 需 **385**；±2p 需 **2401**。
- 用途：G-llm-screen 的 EIR 盲测集规模设计——若盲测 0 误判，59 条独立命题即可声称"误判率≤5%@95%"；要 2% 精度则需 149 条。**独立性前提：盲测题必须来自异族/人独立构造，不能是建设方自己的卡（否则回到 §2 的相关性问题）。**
