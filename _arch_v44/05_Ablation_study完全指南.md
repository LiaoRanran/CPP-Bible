# _arch_v44 · 05 Ablation study 完全指南（方向 5）

> 核心问题：最小 ablation 集、每 ablation 回答什么、样本量（功效）、单人低成本跑、水的 ablation 特征、3 个好 table 范例、不好看怎么办。
> 诚实标注：【论文】；【共识】；【推断】；【盲区】。

---

## 一、最小 ablation 集（三件套）

1. **Full** 完整系统。2. **-X** 去一核心组件。3. **random-budget** 随机预算对照。每 ablation 先写「回答什么」否则即水。

## 二、映射到阙疑（每 ablation 回答什么）

| Ablation | 回答 |
|---|---|
| -变异基线 | 边界错是否靠变异或编译已覆盖 |
| -Merkle 审计 | 账本不可篡改是否影响可信度 |
| -B1 冲突仲裁 | 该保护器是否真起作用（因果） |
| random-budget | 检出率是否来自「更多尝试」非「更对方法」 |

## 三、样本量与统计功效

- 经验：每条件 ≥ 20–30 独立样本给误差棒；阙疑盲 holdout 20 在边缘，须扩或标「探索性」【推断】。功效公式：n ≈ (z_{α/2}+z_β)²·p(1-p)/δ²（比例检验）。例：p=0.8, δ=0.2, α=0.05, power=0.8 → n≈ 约 15–20 例（边界），印证需扩。

## 四、单人低成本 & 水的特征 & 不好看

- 阙疑单卡 0.59ms，ablation 成本极低，瓶颈在夹具。复用 48 卡+15 夹具做 -X。
- 水的特征： ablation 不设对照问题 / 只删无关紧要模块 / 无 CI / 用 -X 掩饰主实验弱。
- 不好看：报告为「组件 X 贡献有限」反成诚实贡献；或降级为 ablation 负结果（E&D 接受负结果）。

## 五、好 table 范例（3 个范式）

- 范例 A：Full / -X1 / -X2 / random 四行 + 每指标 95% CI。
- 范例 B：组件重要性排序（边际贡献±SE）。
- 范例 C：ablation × 难度分层（易/中/难）矩阵。【范式，非具名】

## 六、对阙疑的 3 条具体行动

1. **本周实现 4 个 ablation 脚本**：-变异 / -Merkle / -B1 / random-budget，输出带 95% CI 的检出率表。
2. **把盲 holdout 扩到 ≥ 30**：重注入夹具从 15 扩到 ≥ 25，使每条件样本达功效下限，否则全文标「探索性」。
3. **写 ablation 问题卡**：每个 ablation 文件头写明「本 ablation 要回答的科学问题」，杜绝水消融。
