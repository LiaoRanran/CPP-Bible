> 诚实标注：【论文】；【实证】；【共识】；【推断】；【盲区】。

## 一、辩论交叉验证实证

- 多 agent 辩论（如 CAMEL/生成-批判循环）在部分任务提升，但 2025–2026 实证显示：**边际增益随 agent 数递减，且自 favouring/一致偏差仍存**【实证/共识】。交叉验证有用当且仅当 agent 用**异源**证据（非同一模型不同 role）。

## 二、几个 & 分工 & 成本

- 最优：2–3 agent（生成/批判/仲裁）。>3 边际收益骤降且成本高。
- 分工：生成者（给答案）+ 独立验证者（机器判/规则/外部源）+ 仲裁（四态判决）。阙疑「人审判语义」即天然仲裁层。
- 成本：每加一 agent ≈ 线性 token 增；对单卡 0.59ms 的机器判层几乎免费，贵在 LLM 调用。

## 三、何时不该用

- 不该：任务可被单点机器判覆盖（阙疑多数可执行断言无需多 agent）；预算紧；无独立证据源（否则 circular 加重）。

## 四、对阙疑的 3 条具体行动

1. **只在「非可执行事实断言」层用 ≤3 agent**：生成+机器核查+仲裁，避免对可执行部分画蛇添足。
2. **强制异源证据**：多 agent 验证必须引用外部标准条款/编译器输出，禁止 agent 互证（破 circular）。
3. **算多 agent 成本上限**：在论文 methods 报 token 成本，证明「仅在弱项层用」以控总预算，回应审稿人对成本的质疑。
