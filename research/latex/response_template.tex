\section*{Reviewer 1}

\rev{The paper claims a new evaluation paradigm, but the empirical support is thin.}
\resp We agree the first submission was thin on baselines. The revised version reports a
\textbf{same-sample three-arm contrast}: failure-driven (FD) vs a static caliber arm vs a
\textbf{random-proxy arm}, recomputed by a single script from landed artifacts. Separately, the
\textbf{budget-matched control (A5) has run at full scale}: FD \textbf{54.6\%} vs Random
\textbf{30.6\%} ($\Delta$ \textbf{+24.0pp}, exact McNemar $p{=}2.3\times10^{-41}$, $b{=}136$/$c{=}0$)
and vs Static \textbf{24.7\%} (+29.9pp) --- but the pre-registered parallel analysis collapses to
$\Delta$ \textbf{0.0pp}, so we register it as \textbf{direction-only}, not a superiority claim.
\begin{itemize}[leftmargin=1.4em]
  \item FD holdout \textbf{82.9\%} (34/41) vs Static \textbf{2.4\%} (1/41) vs Random \textbf{9.8\%} (4/41);
        FD corpus \textbf{62.5\%} (40/64) vs Static \textbf{17.2\%} (11/64) vs Random \textbf{21.9\%} (14/64).
  \item Exact McNemar $p\le3.0\times10^{-8}$; Cohen's $h\ge0.85$; all four paired $\Delta$ CIs strictly
        positive (lower bound $\ge$\,\textbf{28.6pp}).
  \item \S9 (Claim Boundary) states explicitly which claims remain unsupported.
\end{itemize}
\chg{\S Experiments (Tables E1, E5); \S Claim Boundary.}

\rev{Why is mutation score not treated as defect detection?}
\resp Because they measure different things. Internal mutation core is \textbf{96.5\%} (110/114;
all-scope 81.8\%, 130/159), while external corpus measurable recall is \textbf{62.5\%} (40/64;
52.6\% all-sample). We cite Just et al.\ (FSE 2014): mutants are correlated with, but not equivalent
to, real faults; mutation is kept as an \textbf{internal self-justification metric only}.
\chg{\S Analysis item 4; \S Threats (Construct).}

\rev{The static arm is weak; is this a straw man?}
\resp We agree the static arm is \emph{not} a real static detector, and we say so. It is a
\textbf{caliber re-binning} (same raw catches, runtime evidence removed), and the two detection
sets' true errors are overwhelmingly visible only through sanitizer evidence. So the low static
number reflects the \textbf{detection sets' dependence on instrumentation}, not the weakness of
static analysis. We explicitly refuse to claim ``we beat a static detector''; the real
\texttt{detect\_static} interface lives in a split repository and remains missing.
\chg{\S Experiments (E1); \S Threats (Construct).}

\section*{Reviewer 2}

\rev{Reproducibility is unclear; the numbers depend on an undeclared environment.}
\resp We now declare the \textbf{WSL + g++ + \texttt{setarch}} dependency in the abstract, \S Claim
Boundary and the reproduction appendix, and require a verdict of \texttt{UNVERIFIED} (not a
misleading low score) when a dependency is missing. We also report the observed silent-drop failure
mode (35.0\% $\to$ 10.0\% without WSL) as a \emph{real} threat rather than a residual one.
\chg{Abstract; \S Claim Boundary; Appendix (Reproduction Commands).}

\rev{How does this differ from benchmark-evolution work?}
\resp Benchmark evolution changes the \textbf{items}; mutation-guided testing changes the
\textbf{tests}; formal verification produces \textbf{proofs}; MiniCheck changes the \textbf{judge's
weights}. We change the \textbf{verifier's evidence-acquisition capability} itself, and require each
step of that change to be \textbf{externally measurable and third-party recomputable} --- and,
uniquely, \textbf{self-falsifiable} (ablation A0 $-$ A5).
\chg{\S Related Work (positioning table); \S Experiments (ablation protocol).}

\rev{The paper says the random baseline is blocked --- then how do you claim an advantage over random?}
\resp The random arm in the \textbf{headline two-rate contrast} is an \textbf{instrument-level
proxy} (holdout 9.8\% (4/41), corpus 21.9\% (14/64); $p{=}1.9\times10^{-9}$ / $3.0\times10^{-8}$;
$h{=}1.65$ / $0.85$). The blocker is resolved: the budget-matched random control (\textbf{A5}) has
run at full scale --- FD \textbf{54.6\%} vs Random \textbf{30.6\%}, $\Delta$ \textbf{+24.0pp}
($p{=}2.3\times10^{-41}$). We still report a \textbf{directional} conclusion rather than a
controlled magnitude, but the reason has changed: it is no longer ``the arm is missing'' but that
the effect is \textbf{pool composition} --- the pre-registered parallel analysis collapses to
$\Delta$ \textbf{0.0pp} ($p{=}1.0$), triggering the \texttt{uninterpretable} clause.
\chg{\S Experiments (Tables E1/E5); \S Analysis; \S Threats (External).}

\section*{Reviewer 3}

\rev{Small sample sizes undermine the statistical claims.}
\resp We agree, and we now say so in the abstract and \S Claim Boundary rather than in a footnote.
Measurable sizes are holdout $n{=}41$ and corpus $n{=}64$; $\pm$5pp of CI half-width needs
$n{=}236/378$ ($\pm$10pp needs 61/97); a $\Delta{=}15$pp paired contrast needs $n\approx103$--173.
We therefore report \textbf{direction, intervals and effect sizes}, and explicitly refuse to report
magnitude \textbf{for the two headline rates}. For the budget-matched A5 contrast the nominal power
gap is now \textbf{closed}: A5 ran at $n{=}566$ ($\gg$ the $n\approx138$ paired requirement) --- but
a family-level cluster bootstrap (677b) puts the \textbf{effective} $n$ at $\approx$133--140
(design effect $\approx$4.2), i.e. at the lower end of the pre-registered window, so all A5
intervals are reported $1.78$--$2.10\times$ wider; what remains is running A0--A4 and multi-round
(modal) verdicts, not more samples. The \textbf{non-degenerate pool has now run} (677c).
\chg{Abstract; \S Statistical; Appendix (sample-size table).}

\rev{McNemar significance rests on an extreme structure ($c{=}0$).}
\resp Correct, and we state it. All four contrasts have $c{=}0$ (the opponent's catches are a subset
of FD's), so the significance is carried by the extreme discordant structure; a few reverse pairs
would inflate $p$ quickly. This is flagged as a residual statistical threat.
\chg{\S Statistical (Table E5 note); \S Threats (Statistical).}

\rev{Minor: terminology is inconsistent.}
\resp Fixed (677a). We use ``detector'' for assets and reserve ``verifier'' for the
\textbf{evidence-acquisition apparatus} as a whole; \texttt{unknown} and \texttt{miss} stay strictly
separate; \texttt{Random}$^\dagger$ keeps its dagger as an \textbf{instrument-level proxy} (the
dagger marks that the reported headline arm is the proxy, not that the arm is missing).
\chg{Whole manuscript.}

\section*{Standard reusable replies}

\paragraph{On ``sample size is too small''.}
We agree and say so up front. Measurable $n{=}41$ (holdout) / $n{=}64$ (corpus); $\pm$5pp half-width
needs $n{=}236/378$; $\Delta{=}15$pp paired needs $n\approx103$--173. We report \textbf{direction}
($\Delta$ lower bound $\ge$\,\textbf{28.6pp}; exact McNemar $p\le3.0\times10^{-8}$) and
\textbf{refuse to report magnitude} for the two headline rates. For the budget-matched A5 contrast
the expansion has already happened ($n{=}566 \gg 138$), so the remaining limitation there is pool
geometry, not power.

\paragraph{On ``the baseline is not strong enough''.}
Partly correct, and we label precisely. The \textbf{static arm is a caliber re-binning}, not a re-run
of a real static detector (split-repo \texttt{detect\_static} still missing) --- marked and excluded
from conclusions. The \textbf{random arm in the headline contrast is an instrument-level proxy}; the
true budget-matched control (\textbf{A5}) has run at full scale (1137 samples; $\Delta$ +24.0pp,
$p{=}2.3\times10^{-41}$) and is reported \textbf{direction-only} because its effect is pool
composition. The missing \texttt{detect\_static} remains an \textbf{open item} rather than being
substituted by an approximation.

\paragraph{On ``why not evaluate on SWE-bench''.}
Because our object of study is not code repair but \textbf{verification of knowledge claims}.
SWE-bench measures whether a model can patch an issue; we measure whether a claim is supported by
recomputable evidence under an explicit boundary triple. Adapting SWE-bench would change the
construct. We cite the SWE-bench contamination line as \textbf{motivation} for
external-sample-first design.

\paragraph{On ``reproducibility''.}
Every headline number is recomputed from landed artifacts by a single command; the environment
dependency (WSL + g++ + \texttt{setarch}) is declared, and a missing dependency yields
\texttt{UNVERIFIED} rather than a misleading low score. Statistical plans were pre-registered before
the reveals and recomputed through two independent paths (differences $<0.1$pp). Code is Apache-2.0
with DCO sign-off. Croissant and Responsible-AI metadata are \textbf{generated and self-checked}
(the 2027 specification is not yet released, so the shipped form is 2026-conformant; the generated
JSON-LD and its 13 self-checks are part of the artifact).

\paragraph{On ``how do you handle untrusted LLM input / prompt injection''.}
Registered as an explicit threat (T15). Architectural mitigation: \textbf{LLM output never becomes a
verdict directly} --- every LLM-produced candidate passes a deterministic schema check before
entering the ledger, and ML-based detection only \textbf{warns, never blocks}. Prompt injection can
pollute \emph{evidence processing} but not \emph{verdict recomputation}, because verdicts are fully
programmatic and checked by a kernel-independent reconciler. We cite a live CVE (CVE-2025-59145,
CVSS 9.6) as evidence the threat is real.

\paragraph{On ``data provenance / ethics of the external corpus''.}
The 74 \texttt{planted=false} samples are \textbf{single-file reconstructions} of public CVEs and
GitHub issues, not original production code; 74/74 sources were verified reachable (HTTP 200) and
the reduction applied to each is recorded per sample. \textbf{No original external artifacts are
included in the corpus} (provenance class \texttt{original-external-artifact} has count 0). Labels
were authored by a single annotator; the 676m blinded double annotation ($\kappa{=}0.77$ / 0.69 /
0.71) is \textbf{AI self-consistency, not human IAA}, and a two-annotator re-label protocol with
escalation is pre-registered in \S Threats. Until it runs, every rate reads as ``recall under
self-produced labels''.

\paragraph{On ``9-page limit''.}
The main text ends on page 8 (references start on page 9). If the camera-ready overflows, we move
the sample-size table and the related-work table into the supplement and merge the two ablation
tables (protocol + experiment).

\paragraph{On ``A5 / the core-mechanism falsification experiment''.}
A5 has run at full scale (1137 samples; derivation 571 / evaluation \textbf{566}): at $k{=}4$ over
the full 8-asset pool, FD \textbf{54.6\%} (309/566) vs Random \textbf{30.6\%} (173/566) vs Static
\textbf{24.7\%} (140/566); $\Delta$(FD$-$Random) \textbf{+24.0pp} (CI [+20.5, +27.5],
$p{=}2.3\times10^{-41}$, $b{=}136$/$c{=}0$), $\Delta$(FD$-$Static) \textbf{+29.9pp}
($p{=}1.9\times10^{-31}$); FD is strictly better than the single-seed draw in \textbf{97.6\%} of
2000 resamples. \textbf{But it still does not license ``FD beats Random''}: the effect is
\textbf{pool composition} --- 2 of 8 assets are constant-\texttt{unknown} over all 1137 samples and
the pre-registered 5\% rule adds a third (\texttt{linker}, 0.88\% catch rate), so in the
pre-registered parallel analysis (5 candidates) the $\Delta$ \textbf{collapses to 0.0pp}
($p{=}1.0$) while the \textbf{Static gap grows to +30.6pp} ($p{=}8.1\times10^{-34}$). The parallel
analysis is significant at $k{=}1$--3 (+11.31/+7.42/+7.42pp), pinning the \emph{selection} effect at
$\approx$\,+7--12pp; that sweep is exploratory. We therefore write no ``FD $>$ Random'' sentence.
\textbf{Two follow-up analyses are now in the paper (677b/677c).} \emph{Template leakage (677b):}
the samples are not independent (1137 samples $\to$ \textbf{474 template families}; 420 connected
components), and under the original split \textbf{64.5\%} of evaluation samples had a family sibling
in the derivation split; re-splitting at the family level (three strategies, the strict one with
\emph{zero} clone pairs crossing) leaves the endpoint unchanged (+23.0 to +26.7pp,
$p\le4.1\times10^{-29}$) and the parallel analysis at $\approx$0, but a family-level cluster
bootstrap gives a design effect $\approx$4.1--4.3, i.e. an \textbf{effective $n\approx133$--$140$} and
$\Delta$ cluster CIs of $[+16.6,+30.4]$ and $[+18.3,+33.4]$pp ($1.78$--$2.10\times$ wider, still
excluding 0); with the random arm re-drawn too, the lower bound reaches 0 ($\Delta\le0$ in
2.2--3.0\% of replicates) --- which is why the claim stays directional. \emph{Degenerate assets
(677c):} on the strict non-degenerate pool (5 assets) the effect \emph{survives} at $k{=}1$--3 (best
$k{=}1$: 33.04\% vs 21.73\%, \textbf{+11.31pp}, $p{=}6.0\times10^{-8}$); the $k{=}4$ zero is a
\textbf{set collision} (both arms must draw the same four of five, probability $0.2$), and the
degenerate assets account for \textbf{+24.03pp} of the single-point $k{=}4$ $\Delta$
(\textbf{+12.81pp} against the mean), leaving an isolated selection effect of
$\approx$\,\textbf{+7--12pp}. We now report $+24.0$pp (full pool) and $+7$--$12$pp (degenerate-free)
side by side.
Roadmap: the power gap is closed and the \textbf{non-degenerate pool has run}; what remains is
running A0--A4, multi-round (modal) verdicts, and reporting A5 intervals at the cluster width
(effective $n\approx133$--$140$). Separately we publish the capability-boundary map (38.4\% blind
spot, 13/34 types $>$50\% blind) and a measured $\sim$5\% run-to-run flip rate as first-class
limitations.

\section*{High-frequency questions}

\paragraph{Q1. Sample size is still small (41/64).}
See ``On sample size'' above; A5's power gap is closed at $n{=}566$, the two headline rates are not.

\paragraph{Q2. The LLM arm result contradicts your expectation.}
Correct, and registered as a \textbf{negative result}. GLM-4 caught 12/12 errors (vs FD's 6/12 on
the same subset) but produced 4/8 false positives on controls: more sensitive, far less specific.
All four pre-registered hypotheses failed. Caveats stated: some samples carry
\texttt{answer\_leak\_risk}; single model, single prompt. This is exactly why our architecture keeps
``LLM output never becomes a verdict''.

\paragraph{Q3. The external anchor's H2 did not pass.}
Yes --- \textbf{H2 misses by 0.8pp} and is registered as \emph{not} passed. The two subsets are
reported separately because their targets differ: verbatim guideline snippets 28.6\% (most guideline
text is stylistic advice, so ``no detection'' is expected) and reconstructed UB fragments 80.0\%
(our own reconstruction, hence an upper bound). The 50-snippet total rate of 44.0\% belongs to H3,
which passed at $\ge$30\%.

\paragraph{Q4. How does this differ from related work?}
Benchmark evolution changes the items; mutation-guided testing changes the tests; formal
verification produces proofs; MiniCheck changes the judge's weights; CELEUS uses e-processes to
save samples. We change the verifier's \textbf{evidence-acquisition capability} and require each
step to be externally measurable and \textbf{self-falsifiable} (A0 $-$ A5). The four-state verdict
is the information-structure projection of Belnap's four-valued logic; auditability rests on Merkle
roots plus a kernel-independent reconciler.

\paragraph{Q5. Reproducibility.}
See ``On reproducibility'' above.
