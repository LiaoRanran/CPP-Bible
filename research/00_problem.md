# 00 · 研究问题（Problem）

## 一句话
一个 C++ 知识验证系统（queyi）声称"能抓书里的错误"，但**它可能在原地测自己**——
用自己设计的变异分布证明自己 97% 有效，外部世界未必认。

## 具体 gap
1. **内部效度够、外部效度未知**：mutation score 97.3% 是对**自造变异分布**的漏检率，
   真实编译器 bug / UB / 教材错 / 跨编译器差异不在该分布里。
2. **仪表盘可能是假的**：元状态（HEAD/质量/边界覆盖）由同一工具链自报，存在自证风险。
3. **系统驱动 vs Protocol 驱动**：实验设计跟着系统能力走，而非先定 Protocol 再验证。

## 研究目标
把验证器从"自我诊断"升级为"可被独立验收"：
- 四层外部效度（真实缺陷 / 盲化 holdout / 独立生成 / 外部 corpus）；
- 三层元状态可验证（Observed / Authority / Intent）；
- Protocol 驱动的评估流程（本仓库 research/）。
