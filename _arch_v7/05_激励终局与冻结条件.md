# 564-05 · 开放系统激励与治理终局（看清即可，默认冻结）

> 篇幅刻意最小：单用户阶段这些机制全是空想；只登记"解决什么"与"解冻的可判定信号"。

## 各机制一句话（解决什么）
- **proof-of-useful-work**：让"贡献"必须附带可独立验证的工作量（本仓等价物已是 replay/poison——带证据的贡献天然抗刷）；开放系统里要防的是"刷卡量"，解法是只计通过机验+人签的卡，不计提交数。
- **预测市场式裁决 / 众包仲裁**：用押注聚合分散判断，解决"单审疲劳/单审偏见"；本仓对应未来 inference 命题的多主体分歧裁决。
- **staking/slashing**：裁决者质押声誉/权益，错判被更强者推翻时罚没——把 562 的"被推翻"从口头成本变成资产成本。
- **标注质量市场/声望排行**：多主体给卡/规则/毒样例打分，声望按历史命中与漏报率（563 二项上界）排序而非票数。
- **防刷/女巫身份**：proof-of-humanity/身份注册层，防止一人多号伪造共识（562 已记录无 2025-26 一手来源，不展开）。

## 为什么单用户阶段全是空想（诚实）
1. **没有第二个主体**：市场、押注、slashing 需要至少两个利益不相关方；当前 principal_ok 名册只有 1 人，分权（563-03）已经是"角色分离"而非"主体分离"。
2. **错误代价无处兑现**：slashing 罚的是没有价值的东西=零激励；单人给自己发声望没有信息量。
3. **共识是伪造的**：多账号/多模型同族在单用户控制下共享偏置（563 已实证同族一致不算独立佐证）。
4. 提前实现这些 = 为零参与者维护一套治理系统，纯负担（与 560 否决 Bazel、562 否决 Rekor 实物同理）。

## 解冻的可判定信号（满足才立项，不写"等 AGI"）
| 机制 | 解冻触发（可判定） |
|---|---|
| 多主体裁决 | `HUMAN_PRINCIPALS` 名册 ≥2 个**不受同一工作树写权限控制**的真实主体，且过去 90 天产生过 ≥3 次真实分歧记录 |
| proof-of-useful-work 计分 | 外部贡献者出现（非本仓维护者的 PR ≥5 个） |
| staking/slashing | 多主体裁决已运行 ≥2 季度且出现过"人签事后被推翻"的真实事件（562 overturned 事件 ≥3） |
| 声望市场 | 贡献主体 ≥5 且每主体有 ≥10 个带 563 上界的历史判定记录 |
| 密码学身份/透明日志 | 任一外部主体首次请求不可抵赖签署（sigstore/rekor 接入条件，561 已给物） |

**在任何解冻发生之前**，E 块唯一该做的是保证数据层就绪：sign_events、overturned 事件、模型族/主体 id、判定历史 JSONL 全部按 02/03/562 的格式先记着——**没有历史数据，解冻那天市场没有定价依据；有数据则机制可以迟到**。
