## 1. 一句话方案

用**三套 schema 驱动、零业务知识的开源渲染组件**（知识星图 / 内存剧场 / 证书展厅），把阙疑已有的台账与工件（100 节点 304 边、PCK 证书与 M1–M7 负测试、真机 trace、判决账本）变成一个**暗色、克制、可交互、可亲手验证**的静态产品站：首屏星图生长、步阶内存演出、证书现场重算哈希——炫酷全部由真实数据驱动，不演一个假数字。

## 3. 三份中立数据契约（通用化的骨架）

```
graph-bundle v1      nodes{state,severity,confidence_bound…} + links{type,caliber} + epochs(轮次) + clusters
trace-events v1      frame_enter/alloc/write/ptr_set/read/free/violation/output（步阶时间轴）
verifiable-claim v1  claim + boundary + fingerprint + chain[stage,actor,evidence] + mutation_tests + bound + provenance
```

- 同一套渲染器可服务：论证网络（PyArg/Argdown 产出可直接映 graph-bundle S10 S11）、SBOM/供应链 attestation、任何带验证链的知识项目；
- 适配器是纯 Python、跑在构建期、产物可复算——可视化数据自己也过阙疑门禁，视觉炫酷与"零编造"宪法不冲突。

## 4. 性能承诺与验收线（对 brief"秒开/60fps/大图谱"的硬回答）

- 首屏 LCP <2s（hero 页 <2.5s），首屏 JS <80KB gz；wasm 工具链（百 MB 级）点"运行"后才加载；
- 稳定 60fps：全 GPU 图谱 + 物理冻结后纯镜头、InstancedMesh 一次绘制、dpr≤2、按需渲染、链接关 alpha 混合；
- 规模：当前 100 节点零压力，引擎在数十万节点已被生产验证（S1 S4），万级未来不换架构；
- 三级降级：WebGL2 失败 → Canvas 预算力导向 → 静态 SVG，保证任何设备"打开就有"；
- Lighthouse 性能/可访问性 ≥90 进 CI；reduced-motion 全审。

## 6. 风险登记

1. **炫酷与可信打架**：最大风险是为视觉效果引入未验证元素。所有上屏数字必须来自锁哈希构建产物（导出器是唯一数据源），与 v31 video_fact_gate 同一纪律。
2. **许可踩雷**：Cosmograph 应用层 CC-BY-NC、GSAP 部分插件商业授权、Remotion 4 人以上付费——选型已避开（cosmos.gl MIT/CSS+GSAP 免费能力/不用 Remotion）。
3. **iOS 触觉/wasm 线程/多编译器**是平台硬边界，全部走"能力检测+无感降级+诚实标注"，不承诺不支持的东西。
4. **美术投入**：整套方案只需 1 个 Rive 角标资产，其余全代码驱动——单人可承载，不依赖设计师。
5. 浏览器合成音/触觉是增强通道，信息必须在视觉层完整成立（声音从不是唯一信号）。
