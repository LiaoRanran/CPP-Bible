## 0. 定位：这是全项目"最容易哇、也最容易破功"的一层

Python Tutor 用十年、**超 1000 万用户、2 亿段代码可视化**证明了"逐行看栈堆"是 CS 教育的第一刚需 S14；它在 C/C++ 上能精确呈现指针、未初始化内存、越界、嵌套 struct/union、type punning、位操作 S15。阙疑要做的不是复刻 Python Tutor（它已存在且免费嵌入），而是做它做不到的三件事：

1. **真机证据联动**——玩具步阶 ↔ GCC 15.3 锁版本真机工件/汇编/sanitizer 两档分明（沿用 v31 铁律）；
2. **UB 现场还原**——use-after-free/double-free/越界/数据竞争不是"报错弹窗"，而是内存单元变红、悬挂指针变成指向墓碑（ghost node）的叙事动画；
3. **炫酷的空间演出**——指针是飞行的光弧、malloc 是从堆区生长出的方块、free 是碎裂+墓碑，而不是静态表格。

## 2. 推荐架构：Trace 事件流（Python Tutor/C-Pulse 已验证的范式）

不要在浏览器里"边跑边画"。正确架构是**执行与渲染彻底分离**，且这正是阙疑可通用化的数据契约：

```
源码
 │  [档A：教学玩具] 浏览器内 clang-wasm(browsercc) + 轻量插桩
 │                  或 emcc -g 走 DWARF 取变量/内存（Chrome 已支持，免自研调试器 S21）
 │  [档B：真机证据] 服务端锁版本 GCC15/Clang22 + Valgrind/ASan/UBSan
 ▼
Trace 事件流（JSON，与 C-Pulse 原子事件同构 S19）
  {type:"frame_enter", fn, vars[]} {type:"alloc", addr,size,tag}
  {type:"write", addr, bytes, type} {type:"ptr_set", from,to}
  {type:"read", addr}  {type:"free", addr}
  {type:"violation", kind:"UAF|OOB|double-free|race|uninit", addr, step, sanitizer_msg}
  {type:"output", text}
 ▼
内存剧场（前端纯渲染器，只读 trace）—— 可任意 scrub/回放/重放，不重复编译
```

关键收益【推断】：

- trace 可缓存、可分享（URL/文件）、可由 CI 预算先生成（书中每个示例一份 trace，随工件锁哈希）；
- **同一份 trace 喂两个皮肤**：教学皮肤（炫酷动画）与审计皮肤（字节/地址/原始 sanitizer 文本）；
- 通用化：任何能产出该 trace 协议的后端（C/Python/Rust/教学解释器）都能接同一剧场——这是方向一 graph-bundle 的姊妹契约。

两档的视觉纪律（沿用 v31，在剧场里更要强制）：

- 档A（wasm 玩具）：左上角永远显示"**教学模拟 · 非验证证据 · WASM 后端，无 x86/sanitizer/多编译器**"，主色调与档B区分；
- 档B（真机）：每个数字旁挂编译器版本+命令+sha，trace 本身随工件入证；sanitizer 违例可一键跳到对应 PCK 证书。

## 3. 内存剧场的视觉设计（炫酷感从哪来）

**舞台三区**（深色底，等宽字体，与书站暗色系统统一）：

- 左：代码窗，当前行高亮（trace 的 step 驱动），播放头 + 时间轴 scrub（C-Pulse 已验证是核心交互 S19）；
- 中：**内存舞台**——栈（上，固定区，帧像卡片叠层）、堆（下，地址向上增长的网格/方块区）、全局与只读段（侧栏）；地址按 16 进制小标签，可切"语义视图/字节视图"（Python Tutor 的 byte-level toggle S15）；
- 右：输出终端 + 违例事件流。

**动效词典（每类事件一个物理化微动画，GSAP/Motion 弹簧，transform/opacity 走 GPU 合成）**：

| 事件 | 动画 | 声音（见方向四，可选默认关） |
|---|---|---|
| alloc | 堆方块从地址轴"生长"弹出（scale 0.6→1 + 轻微回弹，200ms） | 极轻"啵" |
| ptr 赋值 | 指针槽发出一道弧形光弧落到目标（sigmoid 贝塞尔，300ms），落定后留细线 | 无（高频不发声） |
| write | 目标字节格闪一下高光，值翻滚（数字 odometer） | 无 |
| frame_enter/exit | 栈帧卡片滑入/抬起消散 | 无 |
| free（正常） | 方块碎裂为粒子后淡出，**留下半透明墓碑（Ghost Node，标 freed@step）**——C-Pulse 已证明这是讲悬挂指针的最佳手法 S19 | 低沉短促"咔" |
| violation（UAF/OOB…） | 违例单元红色脉冲三连、肇事指针变红颤动、画面边缘 1px 红色警示框（不闪屏）；时间轴自动暂停在 `step`（Bug Replay：一键回到最初出错的写操作 S19） | 柔和警示音（非惩罚性，方向四 §2 规则） |
| uninit 读 | `?` 格子冒问号噪点，读到的值用斜体虚色 | 无 |
| race（多线程章） | 两个线程色光带同时写同一格，最后写入者用"碰撞迸溅"标记 | 短促双音 |

性能：方块/光弧全部对象池化（trace 最大几百步、对象几十个），一次合成层；不逐帧建 DOM；Canvas2D 或单个 SVG 组即可 60fps，无需 WebGL（规模太小，别过度工程）。

## 4. UB 现场还原：阙疑独有的杀手锏内容

现成工具讲"这段代码 UB"是弹窗；阙疑能讲"**在 GCC 15.3 -O2 下它实际发生了什么**"——因为证据都在仓库里：

- **ch40 悬挂/UAF、Appendix UB 15 例、ch107/108 数据竞争、ch77 扩容、ch95 UB 字符串**：每个示例预录 trace（档A 教学 + 档B 真机），剧场提供"错误直觉 → UB 触发 → 真机结果（或 sanitizer 输出）→ 为什么"四幕脚本；
- **汇编联动**（ch26/41/107 等 57 个 ASM 实证）：内存剧场侧边可开"汇编轨道"，真机 objdump 行与源码/内存 step 三轨同步滚动高亮——这是 Python Tutor 完全没有的维度，也是"我们不是教学玩具厂"的身份声明；
- **换档位实验**（ch08 编译器矩阵）：同一 trace 槽位，切换 GCC/Clang/-O0/-O2，对比真实输出差异（档B 沙箱），让"UB = 未定义≠某编译器行为"从口号变成可操作体验。

## 6. 不做清单

- 不做通用在线编译器/不接受任意大代码（Python Tutor 300 步、教学小片段是正确边界 S14）；
- 不在档A 伪造 sanitizer/汇编——wasm 后端拿不到的就不显示，宁可缺不可演；
- 不做 3D 内存（Pointer Realms 式 3D 隐喻 S20 对严肃内容是干扰；2D 三区+光弧已足够炫酷且可读）；
- 不自研 DWARF 调试器——Chrome 已给源码级能力 S21，嵌其工作流或只取 trace，重造无收益。
