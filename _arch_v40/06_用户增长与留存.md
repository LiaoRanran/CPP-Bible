# _arch_v40 · 06 用户增长与留存（方向 5）

> 核心问题：AARRR、留存曲线、病毒传播、社区增长、教育产品规律（Duolingo/Anki/Memrise）；教学产品 0→100 活跃用户路径。
> 诚实标注：【数据支撑】/【成功案例】/【个人观点】。

---

## 一、AARRR（在 0 用户时哪些有意义）

| 阶段 | 阙疑现状 | 优先级 |
|---|---|---|
| 获客 | 论文+知乎+本地 meetup | 中（先有内容） |
| 激活 | 跑通"一张卡七日闭环" | 高 |
| 留存 | 7 日/30 日返回率 | 高 |
| 变现 | 暂不 | 无 |
| 推荐 | 用户向同学推荐 | 中（口碑） |

**结论**：0 用户时只看"激活+留存"，增长（获客）和变现后置。

## 二、留存曲线

- 健康信号：次日/7日/30日留存阶梯下降但 30 日仍有 >20%（教育产品基准，【数据支撑/个人观点】）。
- 失败信号：次日即掉到 <10% → 产品价值不成立，先回炉 MVP（方向 4）。

## 三、病毒传播

- 教育产品的自然传播靠"学习成果可晒"（如"我用阙疑验证了 10 张卡"截图）。阙疑可设计"验证证书/GitHub 徽章"激励分享。
- Duolingo：游戏化+连胜机制驱动日活【成功案例】；Anki：间隔重复留存强但增长慢（靠口碑）【成功案例】；Memrise：社区课程驱动。

## 四、社区驱动增长

- Discord/GitHub Discussions/Reddit：阙疑在"有 1-2 贡献者"后再建（方向 7），空群反噬。

## 五、对阙疑的可执行建议

1. **0→100 活跃用户路径**：5 人深访(MVP)→ 合肥高校 1 场 workshop（获 20-30 人）→ 知乎长文引流（30-50）→ meetup 复购 → 100。用"七日闭环完成率"当北极星。
2. **设计分享激励**：验证徽章 + "我的验证报告"可晒图，触发自然推荐。
3. **留存靠"连胜/进度"**：教学产品加轻量进度条（不重，单人可做）。

## 六、能学/不能学（3 条）

- 能学：AARRR 在 0 用户时聚焦激活+留存、Duolingo 游戏化、Anki 间隔重复。
- 能学：分享徽章触发病毒系数。
- 不能学（不依赖）：烧钱买量/裂变黑客——0 预算只能靠内容+口碑【个人观点】。
