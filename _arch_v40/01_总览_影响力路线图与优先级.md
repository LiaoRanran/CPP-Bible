## 二、影响力杠杆排序（单位时间产出）

1. **第一篇论文**（学术信号，可被引用、可被评审背书，且直接喂给博客/演讲内容）
2. **公开 + 单脚本重放 artifact**（开源诚信是差异点，比 README 修辞更值钱）
3. **5 人深度用户访谈**（教学 MVP 验证，成本极低、信息极高）
4. **博客/演讲**（依赖前三者有料，顺序不能反）
5. **社区/商业化**（最后，且商业化最末）

## 三、关键反直觉结论（数据支撑）

- **Show HN 不灵**：138 次发布研究 [v40-S3] 显示 Show HN 标签统计上无优势（48h 甚至略负）→ 阙疑冷启动应靠"内容质量 + 学术背书"而非刷 HN。
- **绝大多数 OSS 收入极低**：Sponsors/OC 支持 >5 万开发者但中位收入微薄 [v40-S1] → 商业化排最后，且优先考虑 grants（NLnet/Mozilla/OTF）而非赞助。
- **弃坑是头号死因**：15% 广泛包被弃 [v40-S2] → 不公开/烂尾 > 技术错误，是最大风险。
