## 二、三大风险 Plan B

**风险 A：论文被拒**
- Plan B：rebuttal 迭代→ 改投下一档 venue（v37 已排）→ 仍拒则转 arXiv 长文+博客系列（影响力不依赖录用）。

**风险 B：开源没人用（最现实）**
- Plan B：不刷量；回到"内容+论文"引流（v40-S3 证明发帖平台无效）；用教学 MVP 的 5 人深访挖真实需求；接受"慢增长"——SQLite 式长期主义。

**风险 C：产品没人要**
- Plan B：教学 MVP 回炉（方向 4/5 行为指标）；若验证"伪需求"，缩回纯开源+论文路线，教学暂不独立成产品（v38 红线：核心优先）。

## 三、成功分水岭（每月自检）

- 绿：持续小步 + 单一价值 + 听用户 + 已公开。
- 红：不发布 / 范围蔓延 / 自嗨 / 0 反馈（方向 11 失败共性）。

## 四、对阙疑的一句话路线

**先公开（清债）→ 论文发声（最高杠杆）→ 内容+访谈验证教学 → 慢增长+grant，绝不因 0 用户而烂尾。**
