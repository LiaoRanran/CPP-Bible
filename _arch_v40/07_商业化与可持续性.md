# _arch_v40 · 07 商业化与可持续性（方向 6）

> 核心问题：OSS 怎么赚钱、Sponsors/OC/Patreon 真实收入、企业版划分、咨询利弊、grants；阙疑 3 年内收入来源、何时考虑。
> 诚实标注：【数据】= v40-S1；【成功案例】/【失败案例】/【个人观点】。

---

## 一、OSS 收入真相

- GitHub Sponsors + Open Collective 累计支持 >5 万开发者，但**绝大多数维护者月收入极低**（中位远低于 $100）[v40-S1，数据支撑]。Rust 等例外靠基金会/企业赞助（Mozilla/Amazon/Google）【成功案例】。
- 失败案例：指望 Sponsors 养活自己 → 99% 失望【失败案例】。

## 二、收入模式对比（对阙疑适用性）

| 模式 | 阙疑适配 | 说明 |
|---|---|---|
| GitHub Sponsors | 低优先级 | 0 用户时近乎 0，先有影响力 |
| Open Collective | 中 | 透明账本气质契合，未来可接 |
| 双许可/企业版 | 远 | 需企业需求，现在无 |
| 培训/课程 | 中-高 | 教学 MVP 成熟后可卖"验证方法论课" |
| 咨询 | 中 | 单人时间贵，接单易反噬核心（方向 11 风险） |
| **Grants** | **高** | NLnet/MOSS/Mozilla/OTF 等资助"公共价值基础设施"，阙疑"可验证知识"契合 |

## 三、grants（最该优先考虑）

- NLnet（NGI 零知识/隐私）、Mozilla 基金、Open Technology Fund、Sloan——资助去中心化/可验证/公共品基础设施【成功案例】。
- 阙疑的"知识断言可验证 + 透明账本"正是公共品叙事，比赞助更匹配。

## 四、对阙疑的可执行建议

1. **3 年内不依赖赞助养活**，以 grants + 教学课程为两条主收入探索线。
2. **Y1-Y2 先申请 1 个 grant**（NLnet/MOSS），用论文+开源 artifact 作材料——比 Sponsors 现实。
3. **教学课程变现最早可行**：MVP 验证后做"可验证性方法论"小课（知识付费，单人可交付）。
4. **咨询接单设上限**（如每月 ≤20% 时间），防反噬核心（方向 11）。

## 五、能学/不能学（3 条）

- 能学：优先 grants 而非赞助、教学课程变现、咨询设时上限。
- 能学：透明账本气质契合 Open Collective 叙事。
- 不能学（不依赖）：企业版/Sponsors 养活——数据证明不现实 [v40-S1]【数据支撑】。
