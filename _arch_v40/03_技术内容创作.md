# _arch_v40 · 03 技术内容创作（方向 2）

> 核心问题：技术博客/演讲/视频/社媒怎么写、发哪、与项目互相导流；阙疑写什么、发哪。
> 诚实标注：【成功案例】/【失败案例】/【个人观点】/【数据支撑】。

---

## 一、技术博客

- **结构**：倒金字塔（结论先行）+ 一个具体故事（阙疑有 G12 假开关被抓的现成故事）+ 可运行代码片段 + 一段"为什么难"。标题用"具体结果"而非"浅谈 X"（如"我们怎么用 813 行内核 + Merkle 账本让知识断言篡改必留痕"）。
- **渠道**：中文首选知乎/掘金/个人站（双非无海外 audience，中文技术圈对"可验证性/开源"友好）；英文可 dev.to/arXiv 摘要。
- **成功案例**：写"过程+失败"比写"教程"传播久（如 Postmortem 文体）【成功案例】。

## 二、演讲

- 从 lightning talk（5-10min）起步：本地高校开源社团/嵌入式 meetup（合肥有中科大/合工大，可蹭）。
- 选题：**"单人如何构建一个 fail-closed 验证系统"**——单人 + 强工程叙事，对 meetup 受众有反差吸引力。
- 失败案例：一上来投 KubeCon 级大会必拒；先本地再 regional【个人观点】。

## 三、视频（B 站/YouTube）

- 技术频道增长慢但长尾强；阙疑可做的低成本视频："账本重放 3 分钟看懂""假开关 G12 是怎么被差分验证抓出的"。
- 不推荐一上来全职做视频（单人时间不够，方向 10 约束）【个人观点】。

## 四、社媒渠道有效性（针对开源项目）

| 渠道 | 对阙疑有效性 | 说明 |
|---|---|---|
| 知乎 | 高 | 中文深度技术受众、可长文 |
| 掘金/CSDN | 中 | 流量大但浅 |
| GitHub | 最高 | 项目本身即内容 |
| Twitter/X | 低（无海外受众） | 除非论文被引后 |
| V2EX | 中 | 极客向，适合冷启动帖 |
| 即刻 | 中 | 国内开发者 |

## 五、对阙疑的可执行建议

1. **论文预印本出来后，同步发 1 篇知乎长文**（结论+故事+重放 GIF），把论文流量导到仓库。
2. **先写 3 篇"过程文"**（G12 抓包、账本设计、UVK 纲领数学基础），不写教程。
3. **本地 meetup lightning talk 1 次**（合肥高校），练表达、攒人脉（未来合作者来源，方向 3）。
4. **视频暂缓**，等论文+博客有反馈再做 2 条低成本 demo 视频。

## 六、能学/不能学（3 条）

- 能学：倒金字塔+故事化写作、知乎长文导流、本地 meetup 起步。
- 能学：把 v31–v39 调研笔记转成对外内容（已有素材不重写）。
- 不能学（不依赖）：爆款视频/海外社媒爆红——单人无此产能，且非杠杆点。
