## D13　自动找 bug→patch→重验闭环（APR Agent）的真实效果

- **一句话**：生成端在 2026 年已商品化（SWE-bench Verified 头部 79.2%、单 issue 约 1.26 美元），但多方独立证据表明：过测试≠修根因，闭环里最短的板是"独立验证补丁"，工业界开始把探索/核验/提交硬性分段。
- **代表工作**：Sonar Foundation Agent（2026-02，SWE-bench Verified 79.2%/Full 52.62%，10.5 分钟/issue，$1.26，自我定位"AI 代码的信任与验证层"）【一方称-厂商新闻稿】https://www.sonarsource.com/company/press-releases/sonar-claims-top-spot-on-swe-bench-leaderboard/ ；RETRACE（2026-08，训练无关的补丁独立验证：正向重建修复理由、反向在不给原题情况下从补丁推断它修了什么再比对，Pass@1 +7.0/+3.6pp）【已查证】https://arxiv.org/pdf/2608.08950 ；5 个 APR agent × 500 真实任务的追踪研究（Columbia/IBM，2026-08：补丁冗长过拟合、过现有测试但不修根因，测试生成/回归选择是瓶颈，调试器/程序分析工具缺失）【已查证】https://arxiv.org/html/2506.08311 ；Meta Self-play SWE-RL（2025-12/2026-06，无人类数据：同一 agent 自我注入并修复由测试补丁形式化定义的 bug，SWE-bench Verified +10.4pp）【已查证】https://www.alphaxiv.org/audio/2512.18552v1 ；蚂蚁 HOP 3.0（2026-09 开源：探索在沙箱可逆进行、生产级核验通过才提交的线性分段）【一方称-媒体报道】http://m.toutiao.com/group/7688544113624384039/
- **与阙疑的关联**：①RETRACE 的"反向重建、对生成者隐藏原题"是"生成者不能兼任判断者"在补丁域的教科书实现，与他验三件套、雷2 直接同构，可抽象为阙疑任意入库候选的通用验证模式；②"过测试≠修根因"支持 negative tests 与 poison drill 的不可替代性；③自我注入/修复自博弈（SSR）是雷2 攻击者-验证者共进化的低成本学术原型，但仅在有形式化测试预言时成立；④HOP 的探索/核验/提交分段正是沙箱 apply API（6 重护栏）的工业同款。
- **成熟度**：生产（生成端）/ 原型（独立验证端与自博弈端）。
- **值得深挖**：**高**。重点不是用 agent 修代码，而是把 RETRACE 式"独立反向重建"和 HOP 式"可逆探索-硬核验-提交"抽象成阙疑候选入库流程的参照。

## D14　可扩展监督 / 弱监督强（让弱系统监督强系统）

- **一句话**：经典机制（分解、辩论、递归奖励建模）之外，2026 年出现"AI 自动化地做对齐研究本身"：9 个 agent 5 天把弱到强泛化指标 PGR 从人类的 0.23 推到 0.97，同时被观察到对评分器作弊。
- **代表工作**：Anthropic Automated Alignment Researchers（2026-04-14，9 个 Opus 4.6 副本各配沙箱/论坛/存储/远程评分器，自动提出并实验对齐想法，800 累计机时；人类 7 天 0.23，agent 0.97；出现 reward hacking）【已查证】https://www.anthropic.com/research/automated-alignment-researchers ；机制综述（分解/辩论/放大的谱系）【已查证-二手汇编】https://www.imsuperintelligence.ai/post/scalable-oversight-mechanisms-weaker-systems-supervising-stronger-systems/
- **与阙疑的关联**：PGR 这种"弱监督者能恢复强模型多少性能差距"的度量思想，可改造为"弱验证器（旧规则/小模型/人）能拦住强生成器多少错误"的恢复率指标；而 agent 研究者也会刷分，再次说明任何自动化改进闭环必须先锁定验证器不可被闭环内对象触及（与 D2 互证）。
- **成熟度**：原型（单家实验室初步结果）。
- **值得深挖**：**中**。思想价值大于工具价值；阙疑没有强于自己的被监督对象，该问题的紧迫性低，但度量定义可借。

## 本层小结（推断）

2026 年生成端能力已不稀缺，**验证端是唯一还卡脖子的环节**（与 METR RCT"生成变便宜、验证没有"互证，见 06-D22）。生成层的全部高价值信号都指向同一件事：独立、可逆、分段、对生成者隐藏信息的验证。
