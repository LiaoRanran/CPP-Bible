# 11 · 外部对标：标注工具与人审平台

> 外部工具【一方称：行业常识，本次未逐一核验一手文档】。

## 11.1 论证/关系标注工具

| 工具 | 特点 | 本仓借鉴 |
|---|---|---|
| **LabelStudio** | 通用标注平台，支持关系/连线标注，可自托管 | 任务队列/理由字段/质检范式可借鉴；但重、需服务 |
| **Prodigy** | 主动学习标注，不确定性采样驱动人审 | "先审最不确定"正是本仓维度 5 主张 |
| **Brat** | 论证标注专用（claim/premise/attack） | 攻击关系标注的黄金参照；本仓 attack 边同构 |
| **OVA / Rationale** | 论证可视化+标注 | 辩护链展示范式 |

## 11.2 人审平台

- **MTurk / Prolific / Qualtrics**：众包/学术标注，多人一致性可用 kappa——**本仓单用户不适用**，但"陷阱题/资格测试"范式可借鉴（维度 2）。
- **Zooniverse / Fold.it**：citizen science 微任务——"把 194 边拆成微任务"思路同构。

## 11.3 知识图谱标注

- **Gephi / Cytoscape / Neo4j Browser**：图可视化+标注。本仓 121 节点规模用纯标准库生成 SVG 已够（维度 4），无需引入；若未来要交互再考虑。

## 11.4 本仓单用户+CLI 场景的适配结论

- **最可借鉴的是 Prodigy 的主动学习范式 + Brat 的攻击关系模型**，但都过重。
- 本仓 MVP（CLI 队列 + 静态 HTML + jsonl）已覆盖 LabelStudio/Prodigy 80% 的"人审效率"价值，且无部署成本。
- Web 界面（LabelStudio 式）是 W 段增强，非必需。

## 11.5 本仓落地评估

- 不自建平台，复用 `prop_graph` CLI + 本探针生成的 HTML 原型即可满足单用户人审。
- 若未来多人协作，再评估 LabelStudio 自托管（需服务器，超出单用户纪律）。
