### C1 政策研究（来源：jmlr.org/tmlr 主页 + author-guide.html，2026-01 抓取）
| 项 | 政策 |
|----|------|
| 双盲 | **是**，强制匿名；补充材料也匿名；投稿不得链具名版本 |
| 页数 | **无硬限制**（any length），但正文异常长拖慢审稿；鼓励会议式短篇 |
| 模板 | 必须用 **TMLR LaTeX 样式文件**（PDF 由其生成） |
| 周期 | 缩短/快速周转、滚动投稿（未给具体月数） |
| 代码/数据 | 补充材料 ≤100MB（PDF/ZIP），匿名，鼓励非强制 |
| 复现清单 | 指南页无强制 checklist，鼓励上传代码/数据 |
| 预印本 | 允许 arXiv（匿名/具名），但 TMLR 投稿本身须双盲且不指名 |

**scope 契合**：Queyi = 评估方法学 + 可复现性 + 数据集/基准，与 TMLR 高度契合。
