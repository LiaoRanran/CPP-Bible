## 1 · 当前 I2 覆盖（实跑口径）

| 维度 | 当前状态 |
|------|----------|
| 抽样 | `n_cards=5`（默认），非全量；全仓确认卡 `command+artifact_sha256` 齐全的有 **56** 张 |
| 时间窗口 | **短窗口**：同一进程内对每张卡调两次 `_recompile_invariant`，比两次 `status == "ok"`（= 重编译 sha == 卡值） |
| 比对内容 | 只比对**最终二进制 sha**（一次重编译的结果 vs 卡登记值） |
| 实现 | 复用 `aer._recompile_invariant`（不自己编译；CCACHE_DISABLE + 临时目录隔离） |
| 局限性 | 两次编译在**同一秒内**完成，`__TIME__`（秒级）无机会变化；未比符号表/段；未换 cwd/环境变量 |

## 2 · 缺口识别（5 项）

1. **跨时间窗口**：间隔 ≥1s 重编译，`__DATE__`/`__TIME__`/`__TIMESTAMP__` 会漂移。当前 I2 完全未覆盖
   （602 探针明确标注「跨天/跨秒漂移未被覆盖」）。若漂移仅落在时间宏区域 ⇒ 可接受（非真不可复现）；
   若落在其他区域 ⇒ 真不可复现（fail）。
2. **符号表一致性**：未用 `nm`/`objdump` 提取符号表比对两次编译的符号是否一致。
3. **段一致性**：未用 `size` 比对 `.text`/`.data`/`.bss` 段大小。
4. **不同 cwd / 环境变量**：卡的 `command` 若含相对路径或受 `PATH`/`TZ` 影响，换工作目录可能变结果；当前未测。
5. **多 TU 链接顺序**：`Examples/_ch12_tu_*.cpp`（25+ 个 TU）链接顺序依赖 `readdir` 顺序 → 潜在非确定；未覆盖。

## 5 · 关键结论（交人项前置）

- 编译可复现**在本仓已是事实**（短窗口 56 卡全通过 + 602 探针），B1 的价值是把这个事实变成
  **可声明、可证**的属性（跨时间 + 符号表 + 段级），而非发现新结论。
- 真不可复现的硬下限：**g++ 自身 bug / UB 合法非确定 / 跨机器绝对路径** 三类 602 §5.7 反例，纯标准库内无法根除；
  B1 的「时间宏漂移」判定是**容忍性**结论（可接受），其余差异一律判 fail。
