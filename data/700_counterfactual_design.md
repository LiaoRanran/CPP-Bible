## 3. 模拟比较（**同一冻结矩阵 1147 条**）

| 指标 | **A 现状** | **B 理论最优** | **C 极简** |
|---|---:|---:|---:|
| 池大小 | 8 | 6 | 3 |

| **检出率** | **59.55%** | **59.55%** | **54.84%** |
| 随机臂均值 | 40.94% | 49.50% | 0%（池=4，唯一组合） |
| 表观增益 $g_{\text{app}}$ | **18.61 pp** | **10.04 pp** | 54.84 pp |
| **构成膨胀份额** | **0.4602** | **0.0000** | **1.0000** |
| 聚合可操纵性 | 0.3333 | 0.3333 | 0.3333 |
| **审计成本**（配对样本数） | 18 | 18 | 18 |
| 四型风险 I/II/III/IV | 46.02 / 46.95 / 12.53 / 33.33 | 0 / 0 / 0 / 33.33 | 100 / 46.95 / 12.53 / 33.33 |
| **抗漂移能力** | 53.05 / 100 | **66.67 / 100** | 0.00 / 100 |
| **综合分** | **0.6230** | **0.7721** ⭐ | **0.3389** |

**综合分公式**：$0.35\cdot\text{检出率} + 0.25\cdot\text{稳定性} + 0.25\cdot\text{抗漂移} + 0.15\cdot\text{成本效益}$

### 3.1 三个结论

> ### 结论 F1：**设计 B 最优（0.7721），且其优势几乎全部来自"稳定性"与"抗漂移"。**
> B 与 A 的**检出率完全相同（59.55%）** —— 因为被移除的两个零产资产
> （`wunsequenced`/`compile-time`）**本来就不捕获任何样本**。
> ⇒ **B 的收益是"零成本"的**：去掉两个从不工作的组件，报告值不变，但
> **构成膨胀从 0.4602 降到 0.0000**（表观增益 18.61 → 10.04 pp）。

> ### 结论 F2：**设计 C（极简）是反面教材。**
> 砍到 3 个资产后：
> - 检出率从 59.55% 降到 **54.84%**（−4.71 pp）；
> - **构成膨胀份额 = 1.0000**（因为池=4=预算 $k$，贪心与随机**取同一个集合** ⇒ 表观增益全部来自"随机臂没有选择余地"这一假象）；
> - **抗漂移能力 = 0**（Type I 风险 100）。
> ⇒ **"少资产更简洁"是错的**：它把"预算约束下的选择问题"退化成"没有选择"，
> 从而让"选择效应"这一概念本身失去意义。

> ### 结论 F3：**审计成本在三设计上相同（18）—— 因为成本由 $\psi$ 决定，而 $\psi$ 由"最低产资产"决定。**
> 三个设计的最低产资产都是 `linker`（10 个捕获，10 个独有）⇒ $\psi$ 相同 ⇒ 成本相同。
> ⇒ **改进设计的"审计成本"维度，需要改变的是"最低产资产是谁"，不是"资产有几个"。**

## 5. 诚实边界

1. **三个设计都在同一冻结矩阵上模拟** ⇒ 只反映「资产池 / 记账 / 聚合 / 标签」四轴，
   **不含真实环境变化**（那需要新实测）。
2. **综合分的四个权重（0.35/0.25/0.25/0.15）与成本标定（900 样本 = 0 分）都是本批自定的**，无外部标定。
3. **设计 B 的「理论最优」是相对本批的四轴而言，不是全局最优** ——
   资产池只有 8 个可选（$2^8 = 256$ 个子集），搜索空间极小；
   **不声称全局最优**。
4. **设计 C 的检出率下降幅度取决于贪心序**；换序会变。
5. **设计 C 的"构成膨胀 = 1.0"是定义后果**（池大小 = 预算 ⇒ 无选择余地），
   不表示 C 的机制效应为零。
6. **所有数字来自 1147 条（92.9% 人工植入）的冻结矩阵** ⇒ 不代表真实缺陷分布。
7. **本批未模拟"aware 记账对检出率的副作用"**：aware 会把负例变成 unknown，
   使 `conditional_recall` 的分母变小甚至归零（692-A §4）⇒
   **设计 B 的检出率 59.55% 是 unaware 口径下的数字**，改用 aware 后需重新定义"检出率"。
