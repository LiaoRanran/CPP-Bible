# EV-MATRIX-UNBACKED 规则定义 v2（补全隐性预处理）

> **本文档是规则定义的权威补充**；`evidence/` 下（及任何其它）规则说明如与本文档不一致，**以本文档为准**
> （本批**未修改** `evidence/` 下任何文件；合并进 `evidence/` 需人审）。

## 一、规则目的
「多编译器矩阵声明」的证据卡，必须有**可核对留痕**撑起该声明；单一留痕不足以证明"多平台"。

## 二、适用条件
- 仅对 `compiler: [c1, c2, …]` **且编译器数 > 1** 的证据卡（`EV-*.md`）生效。
- 无 `compiler` 键，或编译器数 ≤ 1 ⇒ **不适用**（规则不产出 Finding）。

## 三、判定语义（完整）
在**预处理后的文本**（见第四节）中统计「可核对留痕锚」：
1. `.out` 路径：正则 `(?:Examples|build)/[^\s\])]+\.out`；
2. CI run 号：`run\s*#(\d+)` **或** 裸 10+ 位数字 `\d{10,}`；
3. `::notice::` 注释；
4. 标准条文声明：`标准条文` 或 `M2.*永久边界`。

**backed（PASS）** 当且仅当：
```
(len(outs) + len(runs) >= 2)                # 双平台 .out / 双 run / 各一处
或  (has_notice and (outs or runs))          # ::notice:: + 任一留痕
或  has_law                                   # 无编译器可用时的声明形态
```
否则 ⇒ **warn `EV-MATRIX-UNBACKED`**（消息含编译器数与留痕数）。

## 四、显式预处理清单（**v2 的核心补全**）
| # | 预处理 | 目的 | 来源 |
|---|---|---|---|
| P1 | **剥去 `actual:` 段**（至下一顶层键或文末） | `actual` 里的 `run_match_file: …x.out` 是**声明**不是**留痕**；不剥则规则对 `run_match_file` 形态**恒命中**（永久失效） | 原始定义（已知） |
| P2 | **剥去 `artifact_sha256:` 行** | **615 新发现的隐性预处理**：`artifact_sha256` 是 64 位十六进制，含 ≥10 位**纯数字片段**，会被 P3-锚②「裸 10+ 位数字」**误收为 CI run 号** ⇒ 多编译器**毒卡被结构性放行** | 2026-09-12 **P12 毒样例**首跑暴露（官方代码注释） |
| P3 | （无其它） | — | — |

- **预处理后的文本 = 原文 − `actual:` 段 − `artifact_sha256:` 行**。

## 五、边界条件与特殊情况
1. **64 位 sha 的数字片段**：`artifact_sha256` 形如 `0724805925216…`（64 hex）含长数字串；
   若只做 P1 不做 P2，该数字串进 `runs` ⇒ 锚数虚高 ⇒ **UNBACKED 被误判为 BACKED**。
2. **`actual` 之外的同名键**：仅剥**行首** `artifact_sha256:`；正文其它引用不受影响。
3. **`x/n` 与 MLE**：本规则不含统计；P2 只影响锚计数。
4. **历史 6 张分歧卡**（615 B1 实测，natural=P1-only 相对 official=P1+P2 误放行）：
   `EV-CONC-001`、`EV-CONC-002`、`EV-MEM-001`、`EV-MEM-039`、`EV-MEM-042`、`EV-MEM-043`。
   ⇒ 六张**全部由 P2 解释**（P2 缺失 ⇒ 被误判 BACKED）。
