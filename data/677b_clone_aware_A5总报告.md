## 1. Clone-family 分组结果（任务A）

**关系定义**（pair 级，任一满足即判克隆）：
- **C1** 归一化精确同构（676k L2 口径：去注释/字面量 → 标识符→`ID` → 数字→`NUM` → 去空白）；
- **C2** 归一化 token-set **Jaccard ≥ 0.85**（对换常量/变量名/注释免疫）；
- **C3** 676k L3b **结构层 TF-IDF 余弦 ≥ 0.90**（标识符保留、常量归一，专捕"常量微调 + 强制转换"型近克隆）。

**家族 = 满足全对约束的极大簇（complete-linkage）**——家族内任意两成员都必须判克隆（避免单链接链式合并把互不相似的样本拉进一族）；**分裂单位另取连通分量（single-linkage）**，见 §3。

**与 676k 对照**：676k 的 L2 重复组在 A5 内 160 组/668 条；676k 的 **103 对跨批近克隆，98 对落进同一家族**（余 5 对 = `B092 ~ F106..F110`，`(int)` 强制转换差异，因全对约束未合并但同分量）。

**质量验证（Agent 逐源码复核，非人类第三方，T17 一致）**：
- **C1 家族（精确同构）**：抽查 5 个家族（`F0014` A060/A061 仅变量名 `x`/`y` 不同；`F0002` A005/A006 仅数组下标常量 1/2 不同；`F0021` A088/A089 原文逐字节相同；`F0019` A080/A081 移位量 33/40；`F0106`/`F0131` 纯精确组）⇒ 全部是真模板克隆 ✓
- **C3 覆盖的对**：`F106`（`x << -1`）~ `F111`（`x << 32`）——同一缺陷模板、字面量不同 ✓（这类对只被 C3 判到，故 C2-only 会漏）
- **C2 的过度合并（已知代价）**：`F0288` 内 `F102`（`volatile const` 假写保护）~ `F171`（`register` 弃用）——**同代码骨架、不同缺陷类型**（归一化后逐字同构）。这与 676k 的 62.2% 克隆率是同一个"克隆"概念（结构性），**对泄漏控制是保守的（宁可多并）**，但不是"语义模板相同"的主张；已在报告与局限中显式标注。
- **残余跨家族克隆对 575 对**（同分量）：如 `d3-22`（double free）~ `d3e-09`（use-after-free）——骨架同构、缺陷不同 ⇒ 归入同一分量，被 strict split 保证不跨侧。

## 3. Clone-aware split 设计（任务B）

| split | 分裂单位 | 种子 | 派生/评估 | 家族跨 split | 单位跨 split | 克隆对跨 split | batch 最大偏差 |
|---|---|---|---:|---:|---:|---:|---:|
| family_random | 全对凝聚家族（474） | 6771 | 568/569 | 0 | 14 | 294 | 7.01pp |
| family_stratified | 全对凝聚家族（474），按 (batch, defect_type) 分层 | 6771 | 568/569 | 0 | 20 | 401 | 3.14pp |
| **strict_stratified** | **连通分量（420）**，分层 | 6771 | 569/568 | 0 | **0** | **0** | 5.12pp |
| （对照）original | 层内 sha256 奇偶（676f） | 20261003 | 571/566 | 147 | 123 | 1553 | 0.27pp |

- 三种 clone-aware split 的评估侧样本数 568–569（与原 566 偏差 <0.4%，验收 ±5% 内）；
- **strict 变体**保证"任意一对判克隆的样本都不跨 split"（克隆对跨越 = 0）⇒ **本批推荐的"不泄漏"口径**；
- 均衡性代价（batch 最大偏差升至 3.1–7.0pp）是"家族整体不动"的必然结果，已如实记录；
- family 级变体的残余跨越（294/401 对）来自"同分量内跨家族"的对，strict 变体消除。

## 6. 核心结论

1. **主端点成立**：clone-aware 后 Δ(FD−Random) = **+23.0～+26.7pp**（原 +24.0pp），p ≤ 4.1×10⁻²⁹ ⇒ **template-family leakage 不是主端点的驱动因素**（去泄漏后不降反略升，变化在抽样噪声内）。
2. **并列分析归零同样成立**：−0.53～+0.00pp（四种切分一致）⇒ `uninterpretable` 条款与"只给条件结论"的定位**不是泄漏的产物**。
3. **读法要改**：cluster bootstrap 把 Δ 的 CI 从 7.2–7.8pp 放宽到 13.8–15.1pp，**有效样本量 ≈133–140**（名义 566）⇒ 论文"区间应据此读宽"的定性判断**已量化**。
4. **不得升级**：若把随机臂的随机性也纳入，Δ 区间下界贴 0（full_refit 2.2–3.0%）⇒ A5 保持**方向证据/条件结论**。
5. **判定**：**成立（主端点）+ 成立（并列归零）+ 读法收紧（有效 n / 2× CI）**；论文现有主张**不需要改结论，只需要补稳健性与有效样本量**。

## 8. 未解决项与局限

1. **家族定义是工程决策**：C2 会把"同骨架不同缺陷类型"并族（`F102`~`F171` 例）；阈值敏感性只做了家族数层面（0.80/0.85/0.90），**未逐档重算 A5**。
2. **complete-linkage 残余** 575 对跨家族克隆对（同分量）⇒ family 级 split 有 294/401 对跨越；strict 变体为 0。
3. **bootstrap 单位大小不等** ⇒ 评估集规模波动（424–923）；deff 含规模变动成分；未做固定 n 的 rescale 变体；**family_random 未做 bootstrap**（计算量取舍）。
4. **未重跑 `detect()`**：矩阵复用 676f；`unknown` 处理口径与 676f 相同（绝不当 miss）；676f 已披露的 ~5% 逐格跑间不稳定本批不重新度量。
5. **质量验证是 Agent 源码复核**（10 家族 + 12 边界对 + 4 例跨族对），**非人类第三方**（T17 一致）；抽取证据留存在 `677b_clone_family_report.md` §4。
6. **均衡性代价**（batch 最大偏差最高 7.0pp）未做二次交换优化。
