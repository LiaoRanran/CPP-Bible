# 胸腺正确代码库（D3）

本目录只放**人工确认无缺陷**的 C++ 样本（阴性选择用）。每条新增带 `.cpp` 检查器的规则发布前，
必须在这些正确代码上测误报率：`tools/false_positive_thymus_671g.py --check`。

准入要求：
1. 样本经人工复核**确定无 UB/内存/并发缺陷**；
2. 无 sanitizer 告警（-O0/-O2 双档 + setarch -R）；
3. 每条样本登记来源与确认人；
4. 达到 `config.min_samples`（10）前，注册的检查器判 **inconclusive**（不许带过）。

当前为框架初始状态（2 条种子，671g 登记：历史 67 条规则无 C++ 检查器，胸腺对它们 unarmed）。
