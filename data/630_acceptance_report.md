## 二、关键结果

### 2.1 自身免疫率：从数字到可裁决方案（A 线）

| 指标 | 值 |
|---|---|
| 仅口径卡 / 诊断出的 warn 条数 | 22 张 / **132 条** |
| 分类 | 字段缺失型 **67** · 字段值不符型 **2** · 格式型 **63** |
| 可自动修 / 需人填 | **auto 42** / **human 90**（>5 ⇒ 触发 §十.3「需人审批量处理」） |
| 干跑·严格（只填 auto） | 剩余 warn 90 条、**0 张卡变干净 ⇒ 软警报率仍 100%** |
| 干跑·乐观（全填对） | **0 warn ⇒ 0%**（达 v23 软目标 ≤20%） |
| 干跑·悲观（signed_by 填错） | **warn 升 block** ⇒ 硬开火率 >10% 上限（**比不修更糟**） |
| v23 阈值对照 | 硬开火率 **0% 达标**（≤5%）；软警报率 **100%**（目标 20% / 疲劳线 40%） |

**最重要的两条结论**：
1. **病在软层不在硬层**（C3）：block = 0/23 ⇒ 硬指标健康；超标的是 warn 层 ⇒ v23 建议的
   「批量调参该层规则」正对应 A2 方案甲；
2. **修复瓶颈是人**（A3）：机器只能自动补 42/132 条（`liveness`），其余 90 条要么是
   语义判断（`object`）、要么**只能由在册人签**（`signed_by`）；
   **批量机器代签会把 warn 升格成 block**。
