## 7. 诚实边界

1. **内容匹配是"关键词/概念"级，不是语义级。** 英文词袋 Jaccard 因跨语言失效（§4.1），
   最终采用的是概念术语表匹配。`match`/`partial` 的边界由我定义的术语表决定；
   14 条 `partial` 是我**人工逐条读官方描述**后判为一致的，这部分是主观判断。
2. **`simplification` 与官方描述的"吻合"不等于"最小复现真的等价于原漏洞"。** 本核查只验证
   来源真实、缺陷类别对应，**不验证**样本代码是否忠实复现了 CVE 的语义。后者需要逐样本人工审阅
   源码与补丁，超出本批范围。
3. **URL 可达性只是当时的快照**（2026-10-04）。NVD/GitHub 链接未来可能变化；
   NVD 也做过旧 ID 的迁移与重编号。
4. **本次网络完全可达，没有"未核查"条目**。这与任务书预设的"网络可能不通"不同 ——
   如实记录，未编造任何结果。
5. **NVD 限流已被触发并记录**（1.5s 间隔 → 38 条 429；7s 间隔 → 全部补齐）。
   后续批次复用本脚本时请保留 ≥7 秒间隔，或申请 NVD API key。
6. 本批**未修改任何样本的 `source` 字段**（红线）。
