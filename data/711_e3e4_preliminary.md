## 2. 精确三态转移矩阵（本批新增物）

记账 = unaware（与 676g/692 主表一致；三态直接取判定字符串）。行 = g++ 13.3，列 = clang 18.1.3。

### 2.1 asan（n=200）

| $T^{(\text{E1}\to\text{E3})}_{\text{asan}}$ | → catch | → miss | → unknown | 行和 |
|---|---:|---:|---:|---:|
| **catch →** | **61** | **4** | 0 | 65 |
| **miss →** | **6** | **122** | **3** | 131 |
| **unknown →** | 0 | 0 | **4** | 4 |
| **列和** | 67 | 126 | 7 | 200 |

### 2.2 ubsan（n=200）

| $T^{(\text{E1}\to\text{E3})}_{\text{ubsan}}$ | → catch | → miss | → unknown | 行和 |
|---|---:|---:|---:|---:|
| **catch →** | **45** | **3** | 0 | 48 |
| **miss →** | **7** | **138** | **3** | 148 |
| **unknown →** | 0 | 0 | **4** | 4 |
| **列和** | 52 | 141 | 7 | 200 |

**对账（与 683 发布数字逐位一致，脚本内置断言）**：
一致率 187/200 = **93.5%**（两个资产），$\kappa$（三分类口径）= **0.864 / 0.8434**、
g++ catch 32.5%/24.0%、clang catch 33.5%/26.0%、$\Delta$ = **+1.0/+2.0pp**、$n_{\text{diff}}$ = 13/13。
⇒ 本批的矩阵与 683 报告**没有口径分歧**（重算值 = 发布值，逐位）。

**从矩阵新读出的四条**：

1. **$\Delta_{\text{unknown}} = +1.5$pp（两个资产都是）**：clang 侧多出 7 个 unknown，
   其中 3 个来自 miss（122/138 里的 3）、4 个是"双方都 unknown"的原生 $u\to u$。
   $\Delta_U$ 的具体值 683 报告未单列（710-B2 只写了"$\Delta\le2.0$pp"），本批把它钉死为 **+1.5pp**。
2. **反向对 $m\to c$ = 6（asan）/ 7（ubsan），且 $c>0$** ⇒ 按 **697-T4 的单向性判据**，
   **E1→E3 不是纯撤除型漂移**（E1→E2 的 $c=0$，是纯撤除）。E3 的本质是**换装置**：
   clang 会抓 g++ 抓不到的（LeakSanitizer、heap-buffer-overflow 类），也会漏掉 g++ 抓到的
   （`atomic_ub` 的灵敏度差异）。这与 697 §3 对 E9 的处理同类（cross-regime，不是能力撤退）。
3. **方向性不显著**：McNemar 精确检验 $p=0.754$（asan）、$p=0.344$（ubsan）——
   13 条差异在 200 帧上**读不出方向**（正向 4/3 vs 反向 6/7）。683 的"一致性高"结论保留，
   但**"clang 略强"（$\Delta=+1.0/+2.0$pp）不能写成趋势**（$p$ 远大于 0.05）。
4. **全部 6 个新增 unknown 都是"clang 不可用"（编译失败）**，类型集中在
   `register_ub`(2/资产)、`linker_odr`(1/资产)、以及 asan 侧另 1 条 —— 这些是
   **c-header 处理差异**导致的编译失败（683 已逐条登记 note）。

### 2.3 与 692 的 E1→E2 矩阵对比（同一张表的两种漂移）

| 量（口径统一为"unaware + 三态"） | E1→E2（692，n=566） | **E1→E3（本批，n=200，asan）** | E1→E3（ubsan） |
|---|---:|---:|---:|
| $c\to c$（保留的 catch） | 140 | 61 | 45 |
| $c\to m$（**静默丢失**） | **200（58.82%）** | 4（**6.15%**） | 3（**6.25%**） |
| $c\to u$ | 0 | 0 | 0 |
| $m\to c$（**反向，T4 判据**） | **0** | **6** | **7** |
| $m\to m$ | 226 | 122 | 138 |
| $m\to u$ | 0 | 3 | 3 |
| $\Delta_{\text{catch}}$ | −35.34pp | +1.0pp | +2.0pp |
| $\Delta_{\text{unknown}}$（unaware） | **0.00pp**（静默指纹） | **+1.5pp** | **+1.5pp** |
| McNemar $p$ | $1.2\times10^{-60}$ | 0.754 | 0.344 |
| 漂移类型（T4 判据） | **纯撤除**（$c=0$） | **换装置**（$c>0$） | **换装置**（$c>0$） |

**三条读数**：

1. **E2 与 E3 在代数上是两种不同的漂移**：E2 是 $\tau_G$（撤除，满足 A2 单调、T4 单向）；
   E3 **没有**"能力闭包包含"关系（有反向对）⇒ **E3 ≠ 撤除型 ⇒ 不能套用 692 的"能力撤退"叙事，
   也不能用 A2 的单调性保护**。680/710 的公式（如 $\Delta_{\text{env}}$ 的可加性）**不自动适用**于 E3。
2. **E3 的丢失量级小两个数量级**（6.15% vs 58.82%），且 **$c\to u = 0$**：clang 不会把 catch 变成 unknown，
   只会"抓不到"或"编译失败"。
3. **两个环境对的 $\Delta_U$ 指纹不同**：E2 的 $\Delta_U=0$（静默）；E3 的 $\Delta_U=+1.5$pp（响亮但小）。
   ⇒ 710-B2 设想的"E3 也 $\Delta_U=0$"**不成立**——不是环境门控，而是**工具可用性**（见 §3 P1）。

## 4. 对 710-B2 预测矩阵的修订（供 E3 正式实验预注册用）

"$c\to c\approx96\%$、$m\to c\approx3\%$"。先导实测（asan/ubsan 平均）：

| $T_{13}$ 修订版（先导读数，%） | → catch | → miss | → unknown |

## 5. 诚实边界

1. **先导 ≠ 实验**：200 帧（不是 566）、2 资产（不是 6）、E3 方向（不含 E4）、无 tsan、
   无 `compiler-warn`/`cross-compile`/`linker` 的任何 clang 读数 ⇒ **只够做定性修订，不够下结论**。
2. **P5 与 P1 的部分内容在同义反复**（§3 已逐条标注）；本批**不给预测记分**，只给"结构性判定 + 修订项"。
3. **无 aware/unaware 两套记账的实测对照**：E3 的记账不变性是**结构性论证**（$G_{\text{env}}=\varnothing$），
   本批没有重跑 aware 记账（红线禁新 detect）。
4. **$\kappa$ 是三分类口径**（`catch/miss/unknown`，逐位复算 = 683 发布值）；
   二分类口径（catch vs 非 catch）未发布、本批未新增（避免口径繁殖）。
5. **200 帧的抽样不含挂起样本**（stratified_sample 跳过 `hung_flag`）⇒ 与 676g 全池的
   "挂起样本全部 miss"结论不冲突（那是全池口径）。
6. **类型级差异的分布**（diff_composition_by_type）只列计数，不做族级统计检验（$n$ 太小）。
7. 本批**没有**修改 683/692/710 的任何已发布数字；§4 的修订矩阵是**新增物**，明确标"先导读数"。
