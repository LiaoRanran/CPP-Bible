# 616 A1 · 置信序列/e-process 实现报告

> 纯标准库实现（无 scipy/numpy）｜ 对齐历史参考 `_arch_v20/probes/output/p02_output.txt`（**不重跑 gate**）。

## 一、原理（为什么需要）
- **病**：逃逸率历史上用**固定样本 Clopper-Pearson 上界**，但项目**批次累积、每批复算**（v1→v7 + 报告≈9 次）
  ⇒ 序贯分析中的**连续偷看（peeking）**，固定样本 CI 在任意停止下**失效**。
- **药**：**e-process**（非负上鞅）+ **Ville 不等式** ⇒ 任意停止时刻联合有效；配 **Beta 混合先验** 得
  **置信序列（CS）**。连续监控看 CS，里程碑终点看 CP，**二者均 95%、不可混用**。

## 二、实现细节
| 组件 | 说明 |
|---|---|
| `betai(a,b,x)` | 正则化不完全 Beta（Numerical Recipes 连分式，`math.lgamma`） |
| `beta_quantile(p,a,b)` | Beta 分位数（70 次二分）——用于 CP 对照 |
| `log_eprocess(p0,x,n,a,b)` | `log[ B(x+a,n-x+b)/B(a,b) − x·log p0 − (n−x)·log(1−p0) ]`（H0: p=p0 的 e-process） |
| `cs_interval(n,x,a,b)` | `{p0 : E_n(p0) < 1/α}`（Ville）；上界=右根、下界=左根，二分求解 |
| `ConfidenceSequence` | 类：`update(successes, failures)`（failure=逃逸）/`get_ci()`/`get_upper_bound()`/`get_e_process(p0)` |

- **简化声明**：**无简化**——实现为精确闭式+数值根（`lgamma` + 连分式 + 二分），与参考实现数值一致（见三）。
- 类接口说明：`get_e_process` 需给定零假设率 `p0`（或初始化时 `null_rate`）——e-process **是 p0 的函数**；
  任务书原签名无参，此处补充 `p0` 参数并保留 `null_rate` 缺省（诚实标注）。

## 三、验证结果（与历史参考对照）
| 量 | 本实现 | 历史参考（p02） | 一致 |
|---|---|---|---|
| n=1406,x=1 CS anytime 上界 | **0.9062%** | 0.9062% | ✅ |
| n=1406,x=1 CP 单侧 95% 上界 | **0.3370%** | 0.3370% | ✅ |
| 放宽倍数 | 2.69× | 2.69× | ✅ |
| 轨迹 n=50/100/200/500/1000（0 逃逸） | 12.94/7.33/4.06/1.83/0.99 % | 同 | ✅ |

- 连续偷看 MC（`--demo`，小规模 reps=300/nmax=400）：CP 虚报 **4.67%**、CS **0.00%**；
  参考大样本（reps=3000/nmax=1406）：CP **13.80%** vs CS **0.00%**（理论 ≤5%）。

## 四、与固定样本 CP 的差异量化
- **同点对比**（n=1406,x=1）：CS 0.9062% vs CP 0.3370% ⇒ **宽松 2.69×**（anytime 的诚实代价）。
- **样本代价**（0 逃逸达 0.5% 上界）：CP 需 n=598，CS 需 n=2127（**3.56×**）。
- **虚报修正**：连续偷看下 CP 名义 5% → 实测 **13.80%**；CS 实测 **0.00%**（≤5% 理论）。

## 五、边界
- 未改任何现有工具/基线；未跑监工门禁；参考数字取自历史记录 p02（**未重跑 gate**）。
- `0.00%` 的经验虚报率**不代表零风险**（保守混合先验 + 定向计数的下界观测；理论保证是 ≤5%）。
