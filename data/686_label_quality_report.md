# 686 · B3 标注质量反事实报告

- **批次**：686 ｜ **实验**：`686_analysis.py::b3_label_quality` ｜ **数据**：`686_label_quality_counterfactual.json`
- **设定**：目标集 = `expected_verdict=='catch'` 的样本（668 条）；以概率 r∈{0.01,0.03,0.05,0.10,0.15} 翻转 expected_verdict（catch↔miss），每 r 50 次，重算（噪声目标集上）FD 贪心 vs 随机均值 Δ 与盲区率。
- **红线**：未跑真实 detect()；模型翻转目标集成员资格以模拟标注错误。

## 2. 解读

- **结论方向对标注噪声稳健**：即使在 r=15% 的高错误率下，FD-vs-Random 的 Δ 始终为正（24-27pp），**从未反转**（frac_reps_delta_below_0 = 0.00）。这直接缓解 T17（单标注者）的攻击：即使标签有显著噪声，核心结论不崩。
- **绝对盲区率对标注噪声敏感**：盲区率从 6.6%（r=0）升到 14.3%（r=0.15）——因为翻转把更多"难样本"纳入目标集。这说明**绝对覆盖率数字受标签质量影响，但相对优势不受影响**。

## 3. 当前标签错误率估算（诚实）

- 682 的 κ=0.727 是 **AI 重标 defect_type（35 类，n=287）**，**不是人类 IRR**；二元"是否为缺陷"标签的错误率应低于 35 类，但**未知**。
- 保守上界取 r=0.05-0.10；本反事实显示在该范围内结论稳定（Δ 仍 26-27pp）。
- **T17 仍开放**：AI 重标不等于人类双标注；预注册人类双标注（κ<0.6 全复核）仍需落地。

## 4. 模型局限（诚实边界）

- 本模型翻转 `expected_verdict`（目标集成员资格），是标注错误的**粗代理**；真实标注错误可能发生在 defect_type 或 verdict 细节层，而非整体成员资格。结论"方向稳健"稳健，但具体数值（尤其盲区率）需以真实双标注复核为准。
