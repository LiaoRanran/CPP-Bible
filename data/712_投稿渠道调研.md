## 0. 一句话结论（先看这个）

**当前所有"正规同行评审"渠道的真正阻塞点不是邮箱，而是三样东西：(1) 一个可被 reviewer 一键复现的代码包（Zenodo DOI）；(2) 至少一组人类标注数据；(3) 一个在 cs.SE / cs.LO 或相近领域有发表记录的人愿意背书。**
在这三样补齐之前，所有渠道都是"能注册但过不了初审"。短期（0–3 个月）最该做的不是再找新平台，而是先把论文以"可引用预印本 + 可复现代码包"的形式钉死在公共记录上（TechRxiv / 国家预印本平台 / Zenodo 三选二），同时把 OpenReview 账号提前养熟。

## 1. 渠道逐项调研

### 1.1 TechRxiv（IEEE 官方预印本）—— 【优先级最高，立刻重测】

| 项目 | 核实结果 |
|---|---|
| 网址 | https://www.techrxiv.org/ |
| 是否需要学校邮箱 | **不需要**。IEEE 运营，注册即用， moderation 为内容审核。 |
| 审稿模式 | 预印本（moderated，非同行评审），审核后即发布 |
| 投稿门槛 | PDF 上传 + 元数据；moderation 拒绝低质/无关内容 |
| 费用 | 免费 |
| 适合论文 | 论文 1（36 页那篇，实证+框架） |
| 预计周期 | 上传后数天内审核 |

**⚠️ 重要事实校正（必须诚实告知）**：项目背景称"TechRxiv 平台迁移关闭"。本次检索核实 **TechRxiv 仍在正常运营**——2025 年 7 月仍有新稿上线（如 techrxiv.175203708，2025-07-09），IEEE Author Center（2026-08 更新）仍在引导作者向 TechRxiv 投稿，IEEE 预印本政策（2025-09 更新）仍明确允许作者在 arXiv/TechRxiv 发布预印本。
**结论：所谓"迁移关闭"极可能是账号/实例迁移过程中的临时状态，而非平台死亡。下一步第一动作就是重新登录 techrxiv.org 确认账号状态；若确为账号问题，按 IEEE 支持流程找回，不要直接放弃这个渠道。**

**优点**：免费、IEEE 背书、DOI（10.36227/techrxiv.*）、被 IEEE Xplore 生态感知、对工程/计算机类预印本友好。
**缺点**：非同行评审、影响力低于 arXiv、不能解决"需要 endorsement"的问题。
**操作步骤**：① 用原账号登录 techrxiv.org 查状态；② 若账号丢失，走 IEEE Author Gateway 支持；③ 论文 1 的匿名化版 + 代码仓库链接作为补充材料一并上传。

### 1.2 arXiv（cs.SE / cs.LG / cs.CY）—— 【中期目标，短期不要硬磕】

| 项目 | 核实结果 |
|---|---|
| 网址 | https://arxiv.org/ |
| 是否需要学校邮箱 | **2026-01-21 起，光有学校邮箱已不够**（见下） |
| 审稿模式 | moderated preprint |
| 费用 | 免费 |
| 适合论文 | 两篇都适合（cs.SE 偏论文 1，cs.LO/cs.CY 偏论文 2） |

**⚠️ 2026-01-21 政策大改（必须知道）**：arXiv 官方博客（blog.arxiv.org, 2026-01-21, "Attention Authors: updated endorsement policy"）宣布：**自即日起，机构邮箱不再是自动 endorsement 的唯一凭证**。新作者走两条路：
- **路径一（自动）**：① 绑定学术/研究机构邮箱 **且** ② 已在该 endorsement domain 下有过被 arXiv 接收的论文（claim 所有权）。两条同时满足才自动通过。
- **路径二（个人 endorsement）**：必须找一位**同 domain、已有 endorsement 权限的 arXiv 老作者**亲自 endorse 你。arXiv 工作人员**不能**替你 endorse，也不能豁免。

**对本案的含义（冷酷事实）**：
- 你是独立本科生、从未在 arXiv 发过论文 → 路径一**永远走不通**（第②条不满足）。
- 路径二是唯一活路，而它本质上就是"找一个 cs.SE/cs.LO 领域的 arXiv 老作者给你签名"。这和"找导师背书"是同一道社交题，只是换成了线上签名。
- **endorsement 突破路径（按可行性排序）**：
  1. **被动吸引型**（契合你性格）：先在 TechRxiv / 国家预印本 / GitHub 把论文+代码完整公开，然后给 cs.SE 领域近 1 年发过 arXiv 的作者写**极简、附预印本链接**的 cold email，请求 endorse。关键不是"求认识"，而是"我的工作你 5 分钟能看完，值得签"。预期回复率 <5%，发 30–50 封有 1–2 个回应就算成功。
  2. **机构绑定型**：合肥学院若有计算机系老师在 arXiv 发过 cs.SE/cs.SE 相关论文，通过学校正式渠道（哪怕只是邮件）请他 endorse。这是最快但最不"被动"的一条。
  3. **先借船**：把论文写成"合作者主导"的共同投稿——即找一位已在 arXiv 的作者作为 co-submitter，他 submit 你挂名。这需要实质合作，不适合短期。
- **结论**：arXiv 不要作为短期出路，它是"等你有了预印本和代码之后顺手解决的事"，不是现在的阻塞点。

### 1.3 ChinaXiv（中国科学院预发布平台）—— 【国内首选，若有 edu.cn 邮箱】

| 项目 | 核实结果 |
|---|---|
| 网址 | https://chinaxiv.org/ |
| 是否需要学校邮箱 | **默认需要** .edu.cn / .ac.cn 机构邮箱；个人邮箱可注册但必须**管理员人工认证**后才能投稿 |
| 审稿模式 | 预印本（系统格式/重复/剽窃/研究性四检 + 管理员形式审查），非同行评审 |
| 费用 | 免费 |
| 适合论文 | 两篇均可（中英文都收） |
| 预计周期 | 形式审查通过后约 1–2 个工作日发布 |

**关键机制**：
- .edu.cn 邮箱：跳转"中国科技云通行证"注册 → 登录后需管理员认证才能投稿。
- 个人邮箱（如 QQ/163）：同样可注册，但必须**主动联系管理员**（eprint@mail.las.ac.cn）进行身份认证，提交实名、学历、研究经历、已发表论文列表、ORCID、ResearchGate 等材料。
- 支持 arXiv 一键导入（若日后上了 arXiv）。
- 提供 CSTR 与 DOI（10.12074/...），可被引用。

**操作步骤（个人邮箱版）**：① 注册中国科技云通行证；② 准备身份认证材料（你的 GitHub LiaoRanran、两篇论文 PDF、ORCID）；③ 发邮件到 eprint@mail.las.ac.cn 说明独立研究者身份 + 申请认证；④ 通过后按 6 步流程提交（个人信息→诚信承诺→上传论文+身份证明→格式校验→元数据→预览）。
**优点**：免费、有 DOI/首发权证明、国内可被知网/百度学术索引、对独立研究者开放（只是慢）。
**缺点**：形式审查可能对"无机构"作者更严；影响力主要在国内；不能替代同行评审。
**注意**：若你能拿到合肥学院的学生 edu.cn 邮箱，这条路径会快一个数量级。**本周内先确认合肥学院学生邮箱是否可注册/已分配。**

### 1.5 Zenodo（CERN 运营）—— 【不是发表渠道，但是所有渠道的前置依赖】

| 项目 | 核实结果 |
|---|---|
| 网址 | https://zenodo.org/ |
| 是否需要学校邮箱 | **不需要**。ORCID / GitHub / 本地账号均可注册 |
| 审稿模式 | 无审稿（自动+反 spam 检测），发布即得 DataCite DOI |
| 费用 | 免费（单条 ≤50GB） |
| 适合论文 | **论文 1 配套的代码 + 40 CVE 案例库 + 实验脚本**，论文 PDF 也可作为 publication/preprint 类型存档 |

**关键事实（2026-01-30 更新）**：Zenodo 反 spam 系统对 gmail/outlook 等通用邮箱用户标记更严；**强烈建议用 ORCID 或 GitHub 登录**，并填写完整的姓名、机构、ORCID、详细元数据以避免被误判为 spam。

**为什么这是前置依赖**：PeerJ（要求代码必须有 Zenodo DOI）、NeurIPS（代码 reproducibility）、几乎所有期刊都要求"代码仓库 + 持久 DOI"。**你现在没有 Zenodo DOI，等于所有需要 code availability 的渠道都过不了初审。** 这是性价比最高的一步，半天就能搞定。

### 1.7 PeerJ Computer Science —— 【正规同行评审，但有硬成本】

| 项目 | 核实结果 |
|---|---|
| 网址 | https://peerj.com/computer-science/ |
| 是否需要学校邮箱 | 不需要（免费账号即可），但 co-author 需邮件确认 |
| 审稿模式 | 单盲同行评审，30–35 天首次决定，录用后 30 天出版；**评审报告与 rebuttal 公开发表** |
| 费用 | APC **$2,155**（约 ¥1.5 万）；或个人终身会员 $755–970/人 |
| 录用率 | 约 28–33%（官方页面两处分歧：28% 与 33%，取保守值） |
| 适合论文 | 论文 1（软件/可复现性方向，期刊明确重视纯软件贡献） |

**关键政策（2026-09 核实）**：
- **代码必须在提交时公开**：GitHub/GitLab 仓库 **必须配 Zenodo DOI**（GitLab 需 release 后手动传 Zenodo）；否则可能被拒。
- **本科生 waiver 政策**：只有当研究时为本科生、且有至少一位资深 co-author 持有付费终身会员时，本科生的会员费才可豁免。**你是唯一作者 → 此 waivers 不适用。**
- 中国非世界银行低收入经济体 → 无 APC waiver。
- 接受已在 arXiv/TechRxiv/会议发表过预印本的投稿。

**冷酷评估**：$2,155 对无经费本科生是硬门槛；录用率 28% 意味着 70% 概率白交钱（注意：PeerJ 是 accept 后才付款，拒稿不花钱——这是它相对友好的一点）。**结论：可作为"代码+人类 IAA 补齐后"的冲奖目标，但不是现在的出路。**

### 1.10 OpenReview —— 【不是投稿渠道，是所有 ML 会议的地基】

| 项目 | 核实结果 |
|---|---|
| 网址 | https://openreview.net/ |
| 注册机制 | 用机构邮箱注册 → 自动激活；**无机构邮箱 → 进入人工 moderation，最长可达 2 周**（OpenReview 官方文档 + NeurIPS 2026 公告均明确） |
| 独立研究者 | 可选 "Independent Researcher" 身份（自动填 independent-researcher.org），但仍走 moderation |
| 投稿 | OpenReview 本身不收自由投稿，它是 NeurIPS/ICLR/ICML/COLM 等会议的投稿平台 |

**关键事实（NeurIPS 2026 官方公告，2026-04）**：所有投稿必须在 OpenReview 有有效 profile；**新账号若在截止前不足 2 周才注册，不设例外。**

**对你的含义**：你之前被拒，大概率不是"学校邮箱"本身，而是 profile 处于 pending moderation 状态。**解决方案**：
1. **本周就注册 OpenReview 账号**（哪怕用个人邮箱），填完所有字段（career/education/homepage 写满），让它进 moderation 排队。到 2027 年 5 月截止前有 7 个月，足够激活。
2. 若能绑定合肥学院 edu.cn 邮箱 → 自动激活，立刻可用。
3. preferred email 可设回个人邮箱，不影响投稿通知。

**这是 0 成本、必须立刻做的一步。**

### 1.12 被动展示平台（ResearchGate / Academia.edu / 知乎 / CSDN / 掘金）

| 平台 | 性质 | 关键事实 | 用法 |
|---|---|---|---|
