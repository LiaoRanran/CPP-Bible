---

## 1. 校准度（Calibration）

- **定义**：装置声称的"检出率 X%"与其在独立真值上的实际检出率之差。
- **计算方法**：在独立靶场（683）上，比较装置声明口径的覆盖率与该靶场实测覆盖率；单回合声明值的校准误差 ≈ 逐格不稳定率（676f ~5% → 单回合率 ±~2pp 噪声）。
- **当前值**：**待 683 真实靶场**给出权威校准；目前仅有代理——676f 实测逐格翻转 4.9% ⇒ 单回合覆盖率声明有 ~±2pp 未校正噪声（已登记为 Limitation）。
- **解读**：校准是元评估最核心的指标；在声明环境内"声称≈实测"需 683 验证，目前**不可断言已校准**。

## 2. 区分度（Discrimination）

- **定义**：装置能否区分"好资产组合"与"差资产组合"——即 FD 选择相对随机选择的覆盖优势，及其 AUC 式排序能力。
- **计算方法**：FD 选集覆盖率 vs 随机选集覆盖率的分布；**AUC = FD 覆盖率超过随机选集的比例**。
- **当前值**：A5 中 FD 严格优于单次随机种子在 **97.6%** 的 2000 次重采样中 ⇒ **AUC ≈ 0.976**；相对随机*均值*的增益 ≈ **+16pp**（全池）/ **+7-12pp**（机制）。
- **解读**：区分度**高**——装置确实能选出优于随机的资产集；但 AUC 高部分源于随机种子抽到退化资产，故相对*均值*的 +16pp 是更保守的区分度估计。

## 3. 稳定性（Stability）

- **定义**：评估结果在扰动（检测器噪声、跑间不稳定）下是否稳定。
- **计算方法**：注入 ε 噪声后重算选择集 Jaccard 与干净真值掉点（B4）；或实测跑间翻转率（676f）。
- **当前值**：**B4**：ε=5% Jaccard 0.97/掉点 0.1pp；ε=15% Jaccard 0.89/掉点 0.37pp；ε=20% 起失稳；ε=50% 崩溃。实测跑间翻转 4.9%（676f）。
- **解读**：稳定性**好**——在实测 ~5% 噪声与 ≤20% 扰动内，选择与覆盖高度稳定；远超实测范围的扰动才致崩。

## 4. 公平性（Fairness）

- **定义**：装置对不同缺陷类型的覆盖是否公平——是否存在系统性盲区（某类几乎必盲）。
- **计算方法**：各 defect_type 的盲区率分布；指标 = 盲区率极差 / Gini / "盲区>50% 类型占比"。
- **当前值**（676g）：**18/70 类型盲区 >50%**（死锁 94.3%、volatile 误用 92.9%、端序 89.3%、优先级反转 73.3%）；家族金字塔 memory 15.2% → link/ODR 67.7%；盲区率极差 ≈ 0%–94.3%。
- **解读**：公平性**差**——装置对语义/设计层缺陷（死锁、端序、活性）系统性盲区；这正是论文主动登记的"检测器能力边界"。公平性低**不是缺陷**而是被测对象的真实属性，但元评估必须显式报告。

## 5. 效率（Efficiency）

- **定义**：评估的成本效益比——每单位成本（运行时间/算力）换来的覆盖贡献。
- **计算方法**：资产覆盖率贡献 ÷ 运行成本；无 runtime 字段时暂用 **Shapley 边际覆盖贡献**（682）作代理。
- **当前值**（682 Shapley，255 子集精确）：asan 19.53 > ubsan > tsan > cross-compile > compiler-warn > linker 0.71 > 退化资产 ≈0。即 asan 贡献约 1/3 总增益，退化资产零贡献。
- **解读**：效率**高度集中**——少数资产（asan/ubsan/tsan）承载大部分覆盖；退化资产零效率。需 677c 的 runtime 数据才能算真实 cost-weighted 效率（矩阵无 cost 字段，本批无法做 cost-aware，见 685 A2 已列为 future work）。

## 诚实边界

- 五个指标中**仅有区分度/稳定性/公平性/效率代理**可基于现有数据计算；**校准度必须等 683 真实靶场**才有意义——这正是元评估的"自反性"问题（C3 专论）。
- 效率的"成本加权"因矩阵无 runtime/cost 字段而**无法完成**，本批延续 685 的结论：cost-aware 升級需 677c runtime 数据或 683 实测，列为 future work。
