## 2. 本基准的独特性（可被审稿人核验的四点）

1. **出处可追溯且在线验证**：109 个唯一 CVE 全部经 NVD API v2.0 查询确认，
   应答原文（描述/CVSS/发布时间/references）冻结落盘；此外提取 51 条 fix-commit、
   18 条 issue、16 条 PR 链接。**这是"数据可追溯性"的直接证据，不是声明**。
2. **检测口径与主实验完全同构**：同一 8 资产、同一判定字符串（与
   `holdout_reveal_661.detect` SAN 分支逐字一致）、同双档 -O0/-O2 口径 —— 因此
   "真实 vs 自造"的对比是**同尺子测量**，不是跨工具拼数字。
3. **PoC 全部可编译**：110 条最小重构通过 g++ 语法门（本地批量 `-fsyntax-only` 全绿），
   其中绝大多数可被 asan/ubsan/tsan 等真实触发（判定矩阵 880 格可复算）。
4. **诚实边界显式声明**：source-derived 重构（非原始项目上下文）、
   两资产恒 unknown（工具链事实）、挂起样本的超时观测口径 —— 全部写进数据卡与论文附录。

## 3. 与现有基准的互补关系（不是"取代"）

- 与 **Juliet/SAMATE** 互补：它们提供大规模合成覆盖（用于工具回归），
  本基准提供**小而真**的外部效度检查（110 条真实缺陷）；
- 与 **Magma/ARVO** 互补：它们保留真实项目上下文（构建/复现复杂），
  本基准做**最小重构**（单文件、可直接喂任意检测器，代价是上下文简化）；
- 与 **Big-Vul/Devign** 互补：它们是函数级 ML 语料（不可编译验证），
  本基准每条都能**编译并实测检测器行为**（880 格真实判定）。
