## 4. 安装命令

### 4.1 Windows 本机

```bash
# venv（仓库已带 .venv，缺则重建）
python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"

# 可选 extras
.venv/Scripts/pip install -e ".[pdf]"      # pypandoc（PDF/EPUB 发布）
```

系统依赖（winget / 手动）：

```powershell
winget install Qt.QtCreator            # 或手动装 MinGW g++ 到 C:/Qt/Tools/mingw1530_64
winget install MSYS2.MSYS2             # 再 pacman -S mingw-w64-x86_64-clang
winget install Git.Git
winget install OpenJS.NodeJS.LTS
wsl --install -d Ubuntu                 # sanitizer 真跑必需
```

- **tectonic**：解压到 **`C:\tools\tectonic\`**（`toolchain` 与发布脚本按此路径找）。
- **WSL 内**：`sudo apt update && sudo apt install -y g++ setarch`
  （g++ 13.3.0 + setarch，用于 `-fsanitize=` 双档 × 3 回合）。

### 4.2 CI（ubuntu-latest）

ci.yml 里各 job 自行安装（`pyyaml` / `hypothesis` / `pytest` / `pytest-xdist` / `ruff==0.6.9` /
`mypy==2.3.1` / `node`）。**无需 WSL、无需 tectonic、无需 Qt**——依赖 MinGW/WSL 的用例已用
`CI=="true"` 或 `skipif` 守卫。
