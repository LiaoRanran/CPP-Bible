## 4. B3 defect_type 词表一致性

- 规范词表：`676m_sample_manifest_corrected.json` 的 `vocabulary`，**34 项闭集**。
- **权威层（1042 逐样本 JSON）**：**0 条越界**，实际用到 32 个值（未出现的 2 个值不影响口径）。

## 5. B3b 跨源标签一致性（本轮核心缺陷）

以**权威逐样本 JSON**为基准，对 1042 扩样逐条比对：

| 对比轴 | 不一致数 | 分布 |
|---|---|---|
| **matrix `defect_type` ≠ 权威 JSON** | **308 / 1042（29.6%）** | 见下 |
| **manifest `defect_type` ≠ 权威 JSON** | **100 / 1042（9.6%）** | **全部集中在 expA** |
| **manifest `expected_verdict` ≠ 权威 JSON** | **38 / 1042（3.7%）** | **全部集中在 expA** |
| planted / severity | **0** | — |

### 5.1 expA 三方对照（源码可验证）

| 样本 | INDEX.json | **权威 JSON** | matrix | **源码实际** |
|---|---|---|---|---|
| `sample_001` | move_semantics | **use_after_free** | memory_safety | `// <<PLANTED-DEFECT>> use-after-free: read freed heap slot` |
| `sample_021` | move_semantics | **out_of_bounds** | memory_safety | `// <<PLANTED-DEFECT>> heap buffer overflow: read 6 past size 4` |
| `sample_050` | raii_violation | **null_pointer_deref** | null_pointer_deref | `// <<PLANTED-DEFECT>> null pointer dereference` |

- **权威 JSON 与源码逐条吻合**（含行号）；INDEX 的 per-entry 类型是**批量填充的陈旧值**（expA 100 条 = move_semantics 30 / raii_violation 30 / virtual_function 30 / linker_odr 10），manifest 直接继承之，matrix 则继承 INDEX 的 `by_type` 粗标签（memory_safety 24 / undefined_behavior 21 / out_of_bounds 20 / uninitialized_read 20 / null_pointer_deref 15）。
- expA 权威 JSON 的真实分布：out_of_bounds 28、uninitialized_read 20、null_pointer_deref 15、use_after_free 10、bit_operation 10、integer_overflow 8、double_free 6、other_ub 3。
- `expected_verdict` 同理：manifest 的 expA 有 38 条标 `miss`，而权威 JSON（并与 matrix 实际判定一致）为 `catch`。

### 5.2 影响判定（三态）

- **已确认**：manifest 的 expA 类型列 + expected 列**陈旧**，应以权威 JSON 重派生。
- **已确认**：matrix 的类型列在 308/1042（29.6%）上与权威 JSON 不一致，其中 38 个标签非规范。
- **已确认**：**"70 defect types" 是未归一化标签集的计数**；按 34 项规范词表归一后类型数会显著少于 70。
- **未见证据**：无证据显示样本源文件或判定结果本身被污染（不一致仅发生在**标签列**，`or_verdict_all8` 与源码证据未见矛盾）。

## 7. B5 检测器复现一致性（matrix 内部：expected vs actual）

| 结果 | 数 | 占比 |
|---|---|---|
| 一致 | 1036 | 90.32% |
| 不一致 | 111 | 9.68% |
| ├ `miss→catch`（实际比预期强） | 72 | 6.28% |

- **剩余 5 条非 hung**（真正值得复核）：`expA:sample_011`、`expA:sample_012`（matrix 标 memory_safety，源码为 double-free，ubsan 报 `free(): double free detected` → 实为**误报为 miss 的环境/归并问题**）、`expC:sample_032`（raii 泄漏，asan 一档 rc=126 未产出报告）、`expE:sample_E054`（JSON 备注已按"真实不一致即更新标注"把预期改为 catch，而 matrix 仍记 miss → **matrix 未回灌**）、`expG:sample_G051`（asan 出现 "WARNING" 但未计入 catch → 疑似**判定器解析边界**）。

## 11. 对论文与投稿的影响（重要，建议在 rebuttal/正文登记）

- **不受影响**：样本级盲区率 **38.4%**（440/1147）与检出率 **61.6%**（707/1147）是**样本级计数**，与类型标签无关 → **论文核心数字不动**。
- **受影响（需登记或复核）**：
  1. **"1147 samples over 70 defect types"** —— 70 是未归一化标签数；按 34 项规范词表，类型数会明显更低。建议改为"70 个标签值（含原始批次的 legacy 标签），其中扩样 1042 条使用 34 项规范词表"或直接重算。
  2. **"18 of 70 types exceed 50% blind"** —— 该统计建立在同一标签集上；用规范词表 re-derive 后 18/70 的分子分母都会变。**建议重算后再引用**。
  3. **家族/类型的梯度归纳（memory 15.2% → link/ODR 67.7%）** —— 同上，建议在规范化标签上复核（家族粒度结论大概率稳健，类型粒度需重算）。
  4. expA 100 条的 `expected_verdict` 在 manifest 层陈旧（38 条）—— 若任何分析引用了 manifest 的期望值，需以 JSON 为准重跑。
- **建议动作（最小代价路径）**：① 用权威 JSON 覆盖 manifest/matrix 的类型列（机械修复）；② 按 SCHEMA §3.3 归一化 38 个 legacy 标签；③ 重算类型级盲区统计；④ 在论文的 Limitations/Data statement 增加一句口径说明。
