# 686 · B4 检测器噪声反事实报告

- **批次**：686 ｜ **实验**：`686_analysis.py::b4_noise`（复用 685 方向2 鲁棒函数，扩展 ε）｜ **数据**：`686_noise_counterfactual.json`
- **设定**：全 1137 样本；种子 20260930；注入 ε∈{0.05,0.10,0.15,0.20,0.30,0.50} 的 catch↔miss 翻转（unknown 结构量保持）；每 ε 100 次；度量选择稳定性(Jaccard) 与干净真值掉点。
- **红线**：未跑真实 detect()；噪声为对 676f 矩阵的受控注入，扩展 685（685 仅到 0.10）。

## 1. 结果

| ε | 选择 Jaccard(均) | 干净真值覆盖掉点(pp) |
|---:|---:|---:|
| 0.05 | 0.968 | 0.10 |
| 0.10 | 0.932 | 0.22 |
| 0.15 | 0.892 | 0.37 |
| 0.20 | 0.832 | 0.73 |
| 0.30 | 0.764 | 1.65 |
| 0.50 | 0.555 | 8.72 |

## 2. 解读（鲁棒性边界）

- **低噪声区（ε≤0.15）：FD 选择高度稳定**——Jaccard ≥0.89，干净掉点 ≤0.37pp。与 685 的 1-Lipschitz 理论一致：掉点≈线性（0.10pp@5% → 0.22@10% → 0.37@15%），斜率≈每 5% 噪声 ~0.1pp。
- **中噪声区（ε=0.20-0.30）：开始失稳**——Jaccard 降到 0.83/0.76，掉点升到 0.73/1.65pp；选择集开始被噪声改变（非线性区）。
- **高噪声区（ε=0.50）：选择崩溃**——Jaccard 0.55（近随机），掉点 8.72pp。

## 3. 与 685 的衔接

- 685 证明 5% 噪声下 FD 鲁棒（Jaccard 0.964、掉点 0.11pp）；本批扩展证明**鲁棒边界在 ~15-20%**——超过 30% 选择开始失稳，50% 崩溃。
- 结论：FD 选择对**检测器级**噪声（676m 实测 ~5%）**远在稳健区内**；只有在极端（>30%）噪声下才需担忧，而那是远超实测的场景。

## 4. 诚实边界

- 本实验的"噪声"是逐格均匀翻转的**随机**噪声；真实检测器不稳定是**结构化**（特定样本/资产），最坏情况可能不同。但作为"鲁棒性边界探测"已足够。
- 与 685 一致：噪声自洽率（在被翻转标签上度量）是测量假象，已忽略，只看干净真值掉点。

## 5. 对论文建议

- 可作为 Limitations/robustness 的**鲁棒性边界证据**："FD 选择对 ≤20% 检测器噪声稳定；实测 ~5% 远在稳健区内。"
