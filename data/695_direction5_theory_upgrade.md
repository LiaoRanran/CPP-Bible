## 2. P1 详证：测量漂移代数

### 2.1 定义（把 684 与 692 收进同一个对象）

沿用论文已有的测量元组（`\S\ref{sec:threat}`，`eq:tuple`）：一条测量是
$$\mathrm{measurement} = (x,\, a,\, e,\, \theta,\, p,\, v),\qquad v \in \{\texttt{catch},\texttt{miss},\texttt{unknown},\texttt{contradict}\}.$$

**定义 P1.1（装置与报告率）**。装置 $M = (D, A, E, \Theta, P)$（数据集/资产池/环境/配置/协议）。
对样本 $x$，$V(x,a,e,\theta)$ 为观测；预算 $k$ 下 $V_k(x) = \bigvee_{a \in S_k} V(x,a,e,\theta)$。
报告率按论文既有口径（**分母 $=$ catch $+$ miss，`unknown` 单列**）：
$$\hat R(M) \;=\; \frac{|\{x: V_k(x)=\texttt{catch}\}|}{|\{x: V_k(x)\in\{\texttt{catch},\texttt{miss}\}\}|}.$$

> **这一步就是漂移理论的入口**：因为 `unknown` 被**排除在分母之外**，装置"少测了"这件事**在 $\hat R$ 上不可见**。静默失效不是一个工程 bug，它是**这个口径的数学后果**。692 已经用自然语言说了这件事（"丢失的测量被直接写成 `miss`，于是'没测'与'测了没中'在报表上同形"），**但从未把它写成一条关于分母的命题**。

**定义 P1.2（漂移生成元与漂移量）**。称口径扰动 $\tau: M \to M'$ 为一个**漂移生成元**，定义
$$D_\tau(M) \;=\; \hat R(\tau M) - \hat R(M).$$
论文的五个已知现象都是 $D_\tau$ 的实例：

| 现象（论文） | $\tau$ 的类别 | 内部证据 |
|---|---|---|
| F1（$+24$pp 选择增益坍缩，$k{=}4$ $\Delta{=}0$） | **构成漂移**（资产池构成） | 677c 退化资产发现 + 684-A4 推论 A4.1/A4.2 |
| F3（WSL 60.07% → native 24.74%） | **环境漂移**（$e_1 \to e_2$） | 692 配对实验，$n{=}566$ |
| F4（"率相似"掩盖构成偏移，标准化后 $-17.92$pp） | **总体/标签构成漂移** | 论文 F4 |
| 分母口径（含/不含退化资产） | **分母漂移** | 684-A4 的 $d$（全池 $d{=}3$） |
| 资产版本/运行时版本变化 | **仪器漂移** | 692 的 `asset@version` 字段 |

**这是 P1 的第一个增量**：现有产物把这几类漂移**分别**处理（684 管构成、692 管环境、论文正文管分母），**从未把它们识别为同一个算子族**。一旦统一，就能问出以前问不出的问题（见 2.3–2.5）。

### 2.2 核心对象：三态转移矩阵（可直接从现有产物算出）

**定义 P1.3（三态转移矩阵）**。对一对装置 $M, M'$（同一批样本，配对设计），
$$T^{(M \to M')}_{ij} \;=\; \bigl|\{x : V(x;M)=i,\ V(x;M')=j\}\bigr|,\qquad i,j \in \{\texttt{catch},\texttt{miss},\texttt{unknown}\}.$$

**关键：这个矩阵在本仓库里已经可以算出，且已有一半被算过。**
692 的配对实验（`data/692_environment_paired_experiment.json`）给出 $n{=}566$、E1：340/226/0、E2(unaware)：140/426/0、McNemar $b{=}200$（E1 独 catch）、$c{=}0$（E2 独 catch）。
由这些计数**唯一确定**转移矩阵：

| $T^{(E_1 \to E_2)}$ | → catch | → miss | → unknown |
|---|---:|---:|---:|
| **catch →** | **140** | **200** | **0** |
| **miss →** | **0** | **226** | **0** |
| **unknown →** | 0 | 0 | 0 |

> 复算路径（只读，不新增 `detect` 调用）：$T_{\text{catch,catch}} = \text{E2.catch} - c = 140$；$T_{\text{catch,miss}} = b = 200$；
> $T_{\text{miss,miss}} = \text{E1.miss} - c = 226$。三个数都取自 692 JSON，可一行命令复核。

**定义 P1.4（静默 vs 响亮退化）**。称 $M \to M'$ 是**静默退化**，若
$$T_{\texttt{catch},\texttt{miss}} > 0 \quad\text{且}\quad T_{\texttt{catch},\texttt{unknown}} = 0 \quad\text{且}\quad T_{\texttt{miss},\texttt{unknown}} = 0;$$
称其为**响亮退化**，若 $T_{\texttt{catch},\texttt{unknown}} > 0$。

- **静默**：能力丢失被写成 `miss` ⇒ 报表上"率降了"但"没测"看不见 ⇒ 692 实测的 $E_1 \to E_2$ 是**纯静默**（200/0/0）。
- **响亮**：能力丢失被写成 `unknown` ⇒ 报表上 `unknown` 率暴涨 ⇒ 692 的 **aware 记账**正是人为把静默转成响亮（`unknown` 0 → 426，`conditional_recall` 分母归 0 ⇒ 唯一诚实答案是"不可计算"）。

**这给出 P1 第二个增量**：692 把 aware/unaware 当作**两种记账口径**（工程选择）；P1 把它升级为**同一个转移矩阵的两种投影**，于是"哪种记账更诚实"变成一个**可判定问题**：响亮退化**必然**触发 `unresolved`（因为分母归 0），静默退化**不会**触发任何报警。**这直接解释了论文为什么必须有第四态。**

### 2.3 增益分解与可识别性（P1 的理论核心）

论文 F1 的实测事实是：控制退化资产后 $k{=}4$ 的增益 $\Delta = 0$。把它写成代数：

**命题 P1.5（增益分解，待证）**。在预算 $k$ 下，选择算子 $\pi$ 相对基线 $b$ 的表观增益
$$g_{\text{app}} \;=\; \hat R(S_k) - \hat R(B) \;=\; \underbrace{g_{\text{comp}}}_{\text{构成}} \;+\; \underbrace{g_{\text{mech}}}_{\text{机制}} \;+\; \underbrace{g_{\text{env}}}_{\text{环境}} \;+\; \underbrace{g_{\text{denom}}}_{\text{分母}},$$
其中 $g_{\text{comp}}$ 由资产池的退化/低产成分与覆盖重叠结构决定（684-A4 已给 $d$ 个退化资产时的期望形式），
$g_{\text{mech}}$ 为真正的选择算子效应。**F1 的"坍缩"即 $|g_{\text{comp}}| \gg |g_{\text{mech}}|$ 且 $g_{\text{mech}} \in [7,12]$pp 的区间估计。**

**命题 P1.6（可识别性条件，待证）**。$g_{\text{comp}}$ 与 $g_{\text{mech}}$ 可分离，当且仅当存在一个**退化资产的替代设计**（把退化槽位替换为等边际的非退化资产），使得替换前后 $\hat R$ 不变而 $g_{\text{comp}}$ 归零。
- 677c 的严格池 / Pool A/B/C 就是**部分实现**：Pool A 剔除全部退化资产（$d{=}0$）。
- **缺口**：现有池设计**没有做"等边际替换"**，因此 $g_{\text{comp}}$ 与 $g_{\text{mech}}$ **目前只在 $k{=}4$ 上被识别到"机制效应是小量"这一档**，尚未给出**逐 $k$ 的分解曲线**。这就是 P1 要补的第一件实验工作（见 §5）。

> **诚实边界（必须写进论文）**：如果拿不出等边际替换设计，那么"$+24$pp 是构成效应"这个说法就**只能**表述为"在 Pool A 上增益消失"，而**不能**表述为"构成效应 $=+24$pp、机制效应 $=0$"。**这两句话的强度差别很大**，是目前最容易被审稿人攻击的地方，也是 P1 第一个能实际提升论文强度的动作。

### 2.4 静默窗口的宽度理论（P1 最"新"的部分）

692 已经**经验性**画出了静默窗口：63 个能力撤退子集里，按 `retention ≥ 阈值` 且 `unsound_negatives > 0` 判，
窗口大小随阈值为 100%→0、99%→0、**95%→1**、90%→7、80%→18、50%→49。
最宽的窗口配置是"只缺 `linker`"：`unaware_catch_rate` 59.364%、retention 98.82%、`unsound_negatives` 22、类型相关可靠性 90.43%。

**692 画出了窗口，但没有解释窗口的形状。** P1 要做的是给出：

**命题 P1.7（静默窗口宽度，待证）**。设装置丢弃资产集 $\mathcal{G}$（环境门控丢失集），静默窗口
$$W(\rho) \;=\; \Bigl\{\mathcal{G} : \ \text{retention}(\mathcal{G}) \ge \rho \ \wedge\ \text{unsound\_negatives}(\mathcal{G}) > 0\Bigr\}.$$
则 $|W(\rho)|$ 由**覆盖重叠结构**决定：若被丢弃资产的独有 catch 集 $\bigcup_{a\in\mathcal{G}} C_a^{\text{sole}}$ 与其类型分布高度集中在少数类型上，
则即使 $\text{retention}$ 很高（率几乎不变），`unsound_negatives` 也**不会为 0**（因为这些类型上的负例是"假阴性"）。
**即：静默窗口的宽度 $\approx$ "被丢弃能力的类型集中度"的函数，而非"丢失量"的函数。**

- **可检验性**：692 的 `lost_e1_catches_by_group` 已给出被丢失 catch 的类型分布（`stl` 38 / `concurrency` 37 / `memory_safety` 29 / `legacy` 25 / `undefined_behavior` 24 / `real_world` 18 / …共 11 组）。
  ⇒ 用**类型集中度**（如归一化熵）预测窗口宽度，**现有数据即可做**（只读）。
- **反证条件**：若窗口宽度与"丢失量"（retention 缺口）的相关性**不弱于**与"类型集中度"的相关性，则 P1.7 的"集中度决定论"被证伪。

### 2.5 新子类："结构性 / 被动 Goodhart"

方向 1 找到的形式化文献（`#12` Majka & El-Mhamdi 2025 去独立性 Goodhart；`#13` Karwowski et al. 2023 Goodhart in RL 的几何刻画）**全部以"优化压力"为前提**：代理指标被当作目标去优化，于是过优化。

Queyi 的现象**不需要任何优化压力**：没有 agent 在追指标，$g_{\text{comp}}$ 依然把表观增益放大到 $+24$pp。这是一个**可命名的新子类**：

**定义 P1.8（结构性 Goodhart）**。称装置 $M$ 上发生**结构性（被动）Goodhart**，若存在漂移生成元 $\tau$（**非对抗、无优化压力**）使
$$\bigl|\hat R(\tau M) - \hat R(M)\bigr| > 0 \quad\text{而}\quad R^*(\tau M) = R^*(M),$$
其中 $R^*$ 为机制级目标量。即**报告值变了，被测量的东西没变**。

**与文献的区别（这是论文可以写死的一句话）**：
- 经典 Goodhart / reward hacking / Skalse 2022：需要**优化者**；
- 方向 1 `#12`/`#13`：需要**优化压力**（过优化速率、早停临界点）；
- **Queyi 的 P1.8：不需要任何优化者，漂移由仪器自身的口径与构成退化产生**。
  ⇒ 这意味着 **"防止 Goodhart"的经典处方（早停、正则、鲁棒优化）在本子类上无效**——因为不存在"优化轨迹"可以早停。这条推论本身就是可证伪的理论主张。

## 3. P2 详证：审计微积分（Audit Calculus）

### 3.1 为什么需要

方向 4 的对比表给出一个清晰结论：现有框架可归为**报告模板 / 评分系统 / 制度流程**三类，**没有一类给出"判定代数"**。
Queyi 的四态（survives / weakened / collapses / unresolved）**已经在用**，但**没有公理化**——目前它是协议的一部分，不是理论的一部分。
方向 1 `#1`（Auditing the Audit，五类管线失效）与方向 4 `B5`（Uncertainty-Aware Rejection ↔ unresolved 同构）表明：**"何时可以下结论"正在成为独立问题**，但无人给出代数。

### 3.2 最小公理（草案，5 条）

设 $\mathcal{C}$ 为 claim 集，$\mathcal{E}$ 为证据集，$\mathcal{T}$ 为漂移生成元族（P1 定义）。

- **A1（口径完备性）**：每个 $c \in \mathcal{C}$ 必须声明 $Q(c) = (D,A,E,\Theta,P)$；未声明的 claim **无判定**（不是 `unresolved`，是**非法**）。
- **A2（证据可复算性）**：$c$ 的每个数字 $v$ 必须存在一行命令 $\text{recompute}(v)$，且第三方可执行。
- **A3（单调性）**：若 $c$ 在口径 $Q$ 下 `survives`，则在同一 $Q$ 下加入**冗余证据**不得使其降级。（防"证据越多越可疑"的反直觉）
- **A4（漂移敏感性）**：`survives` 必须对 $\mathcal{T}$ 的某个子类**显式承诺不变性**；未承诺的漂移类别只能给 `weakened`。
- **A5（不可判定归因）**：`unresolved` 必须携带**归因**——是"仪器不可用"（分母归 0 / 资产缺失）还是"证据不足"（CI 跨 0）。**两者不得合并**（这是四态相对二态的全部价值）。

### 3.3 可判定性问题（P2 的理论产出）

一旦有公理，就能问**判定问题**，并期待**可计算性结论**：

1. **可判定**：给定 $Q$ 与证据集，判定 $c$ 是否 `survives`——在有限样本 + 冻结统计口径下，这是有限计算（论文已可执行）。
2. **部分可判定（P2 的核心猜想）**：判定 $c$ 是否对**所有** $\tau \in \mathcal{T}$ 不变，在 $\mathcal{T}$ 无结构时不可判定；但**若 $\mathcal{T}$ 由有限个已知生成元生成**（构成/环境/分母/版本），则不变性检验是**有限**的。
   ⇒ **这解释了论文为什么必须把漂移"枚举"而不是"泛泛担心"**：枚举是使不变性可判定的前提。
3. **不可判定（诚实负结果）**：$g_{\text{comp}}$ 与 $g_{\text{mech}}$ 的**无混淆**分离，在只有一个池设计时不可识别（呼应 P1.6）。
   ⇒ **论文应把这条写成正式的 Limitation，而不是措辞上的让步。**

### 3.4 P2 需要什么

- **理论**：把 5 条公理写成论文的 Definition，给出命题 1–3 的证明或反例。
- **数据**：用**已有 452 事件账本**做**实例化验证**（每个 claim → 一个判定轨迹）；**不需要新实验**。
- **风险**：公理化容易变成"给已有做法起名字"。**避免方式**：公理必须能**排除**某个具体做法（例如 A4 能排除"只报点估计、不承诺漂移不变性"的做法），否则是空转。

## 4. P3–P5 简证与排后理由

### P3 · 能力边界的可计算性（理论价值 4 / 数据 3 / 契合 4 / 创新 3）

- **是什么**：给定装置 $M$ 与样本总体，问"缺陷类型 $t$ 的**可检测性上界**是否**可计算**"，以及边界集 $\mathcal{B} = \{t : \Pr[\text{detect}\mid t] < 1/2\}$ 的**结构**（论文 F2：38.4% 盲区、13/34 类型 >50% 盲）。
- **必须与 693-E3 严格切分**：693-E3 是**实证预测器**（CART/LR，group-5fold AUC 0.781，泄漏感知），回答"能不能预测某个样本是否被捕获"。P3 回答的是**理论问题**：$\mathcal{B}$ 是**统计可估的**还是**只能被枚举的**？上界由什么决定（类型 × 资产覆盖矩阵的秩/重叠结构）？
- **排后理由**：**创新性被 693-E3 部分占位**，且若切分不清会被审稿人视为"给预测器套壳"。**可做的形态**：只做一条**负结果命题**——"在 $d$ 个退化资产与 62.2% 模板克隆率下，$\mathcal{B}$ 的**样本外估计**不可信"，把 693-E3 的泄漏高估（accuracy +0.0287 / AUC +0.0273）升格为**一般性主张**。

### P4 · 环境感知评估框架（理论价值 3 / 数据 5 / 契合 5 / 创新 2）

- **是什么**：把 692 的 `EnvironmentProfile` + `measurement_context_id` 从**一个项目的协议**升级为**可迁移的评估框架**（对照方向 1 `#10` NIST AI 800-3 的"必须显式声明分析模型"、方向 2 `D1` 的"Environment & Tooling 是独立 smell 类别"）。
- **排后理由**：**创新性被 692 占位**。692 已经完成形式化与实测，P4 只是"换个说法讲同一件事"。**唯一值得做的增量**：把 692 的**两条 profile** 扩到**第三条**（容器化 profile），因为 692 自己诚实登记了 `container_image = null` ⇒ 可复现强度上限只是**指纹级**而非**镜像级**。**补齐第三条 profile 是"框架"能否成立的关键实验，否则 P4 仍是一个点。**

### P5 · 跨域迁移（理论价值 3 / 数据 1 / 契合 3 / 创新 5）

- **是什么**：主张"审计协议"可迁移到其它**证据获取装置**（fuzzing 装置、形式化验证器、静态分析器）。
- **排后理由**：**数据可行性 1 —— 仓库内没有第二个领域的装置数据**。方向 1 与方向 4 的检索**均未找到同类先例**，这既是机会也是**风险**：没有先例意味着无法用外部证据支撑"可迁移"。
  ⇒ **只能写成 Future Work 的路线图**，且**必须标注为"主张，未验证"**。若写成贡献，属于**过度声明**（与论文 §Positioning "what we do *not* claim" 的自我约束冲突）。
