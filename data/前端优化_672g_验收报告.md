## 二、A · 星图交互修复（web/starmap.js / web/starmap.html / web/css/669c.css）

### 2.1 病：两套互相打架的拖拽语义

用户原话「操作起来好奇怪」。定位到 672e 的 `wire()`：

| 输入 | 672e 行为 | 用户直觉 |
| --- | --- | --- |
| 鼠标左键拖拽 | **旋转视角** | 平移画布（图谱 / 地图类应用的共识） |
| 键盘方向键 | 平移（`60 / view.k` 走世界偏移） | 与鼠标同义 |
| 右键拖拽 | 无（浏览器右键菜单弹出） | 旋转 |
| 画布上的提示 | 无（只在页脚 kbd 行提了一句） | 需要 |

### 2.2 改后的映射（用户直觉优先）

| 输入 | 672g 行为 | 实现 |
| --- | --- | --- |
| 左键拖拽 | **平移** | `panBy(view, dx, dy)` → `view.panX/panY`（屏幕像素） |
| 右键拖拽 / `Shift`+左键 | **旋转** | `rotateBy(view, dx, dy)` → `view.rotY`（绕竖轴）/ `view.rotX`（俯仰，clamp ±1.3） |
| 滚轮 | 缩放，**以光标为不动点** | `zoomAt(view, f, anchor, viewport)` |
| 双击画布 / `0` / 「复位视图」按钮 | 复位（旋转 + 平移归零 + 自适应） | `resetViewTransform(view)` + `fitView()` |
| 方向键 | 平移，**与左键同一套语义、同一量纲** | `panStepForKey(key)` → `panBy`（60px 屏幕像素，不随 k 变） |
| `+` / `-` / `Esc` | 缩放 / 取消固定（保留） | 原样 |
| hover 节点 | 高亮邻接 + 压暗非邻居（保留） | 原样 |

- 旋转灵敏度 **0.006 → 0.003**（`ROTATE_SENSITIVITY`，减半；672e 实测"一拖就转过头"）。
- 右键菜单：`canvas` 上挂 `contextmenu` + `preventDefault()`，否则一按右键就弹系统菜单、拖拽中断。
- 操作提示：`starmap.html` 画布容器内新增 `<p class="canvas-hint" id="map-hint">`，
  文案由常量 `INTERACTION_HINTS = '左键平移 / 右键旋转 / 滚轮缩放 / 双击复位'` 写入
  —— **常量是唯一真源**，HTML 里的静态文案由 JS 覆写，杜绝"两处文案漂移"。
- `aria-label` 与页脚 kbd 提示同步改写（不再说"拖拽旋转模型"）。

### 2.3 顺带修掉的投影量纲 bug（**真缺陷，非重构**）

672e 的 `projectPoint` 把 `view.x/y` 当成"缩放之后的屏幕平移"用
（`sx = cx + x1·persp·k + view.x`），但 `fitTransform` / `screenTransform` 给的
`view.x/y` 是**世界坐标量纲**的居中偏移。两者量纲不同 ⇒ 居中只在 `k·persp ≈ 1` 时碰巧成立。

实测（真实 `web/data/graph.json`，178 节点 / 1093 边，k = 0.3035）：

| | 包围盒中心应落在 | 实际落在 | 偏差 |
| --- | --- | --- | --- |
| 672e（修复前） | 视口中心 (450, 310) | (533.9, 299.4) | **x 偏 84px** |
| 672g（修复后） | 视口中心 (450, 310) | (450.0, 310.0) | 0 |

同一 bug 在 `centerOnIndex` 上更严重：搜索命中后"自动居中"对 x≈1184 的节点会算出
屏幕 x ≈ −379 ⇒ **目标被送出视口**。

修法：拆成两个量纲 —— 世界偏移（`view.x/y`）在**旋转前**加（⇒ 旋转绕"已居中的模型"转，
转完不会被甩出视口），屏幕平移（`view.panX/panY`）在**缩放后**加。
`zoomAt` 直接按锚点方程解 `pan' = pan + (anchor − c − pan)·(1 − k'/k)`，比原来绕
`toWorld`（2D 口径）折一次更准；`toScreen` / `toWorld` 两个别名因此成死代码，已删。

### 2.4 导出给测试的纯函数

`panBy` / `rotateBy` / `zoomAt` / `resetViewTransform` / `panStepForKey` /
`interactionMode` / `defaultView`，常量 `ROTATE_SENSITIVITY` / `ROT_X_LIMIT` /
`PAN_STEP_PX` / `ZOOM_RANGE` / `INTERACTION_HINTS`。全部无 DOM 依赖，Node 直测。
