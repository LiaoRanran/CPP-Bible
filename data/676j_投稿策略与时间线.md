## 1. 三轨并行策略

### 轨 1 · arXiv 预印本（现在就可以占坑）

| 项 | 内容 |
|---|---|
| **目的** | 确立首发权、获取反馈、增加可见度；给 TMLR 审稿人一个稳定引用锚 |
| **时间** | 论文最终版确认后**立即**（前置 = 676h 落地 A5/盲区数字；见 `data/676j_arXiv投稿准备清单.md`） |
| **优点** | arXiv 允许**随时更新版本**（v2/v3…），**不影响**后续期刊/会议投稿 |
| **注意** | 双盲 review 期挂**署名** arXiv 可能破盲 ⇒ 用匿名预印本或 review 后再挂（`cover_letter.md` §3） |
| **分类** | 主类 **cs.SE**，副类 **cs.PL**，可 cross-list cs.AI |
| **风险** | 新账号可能需 **endorser**（提前 1–2 周确认） |

### 轨 2 · TMLR 主投（**推荐主投**）

| 项 | 内容 |
|---|---|
| **理由** | ① **滚动投稿、无 deadline**；② 判据是「**证据是否支撑 claim** + **不因"不够新颖"拒稿**」——与本稿"窄而可信 + 主动登记局限"的资产结构**最匹配**；③ 要求**开源代码与数据**，本项目**已满足**（Apache-2.0 + DCO + `REPRODUCE.md` + Docker）；④ 本稿有**大规模数据**（1147 样本）与**可复现 pipeline**，正是 TMLR 偏好的形态 |
| **把握** | 作者自评 **8–9 成**（本稿优势：预注册 + 自否证 + 负结果 + 能力边界；劣势：头条率 n=41/64 小、单标注者、A5 仍 direction-only） |
| **时间** | arXiv 占坑后 **1–2 周**（等一点反馈） |
| **审稿周期** | **较长（约 3–6 个月，须复核现行政策）**；期间可同时挂 arXiv |
| **注意** | TMLR 对"局限是否诚实登记"敏感——本稿的 `uninterpretable`、38.4% 盲区、~5% 不稳定、T17 单标注者**都要保持显式**，不要为了好看而淡化 |

### 轨 3 · NeurIPS 2027 E&D（备选）

| 项 | 内容 |
|---|---|
| **理由** | E&D 赛道对**实证类**工作友好；本稿有**大规模数据**（1147 样本）与**可复现性**，契合赛道定位 |
| **时间** | 等 **2027 CFP 发布**（通常 **5–6 月**） |
| **注意 ①** | NeurIPS D&B 自 2024 起要求 **Croissant 元数据**；须确认 2027 是否为**投稿时强制**（非 camera-ready）——**须复核 CFP** |
| **注意 ②** | 当前用 `neurips_2025.sty`；**须替换为 2027 官方 sty**（发布后） |
| **注意 ③** | E&D 有**页数限制（9 页正文）**；本稿已达标，但 A5/盲区地图新增内容可能挤压版面 ⇒ 把细节放附录 |
| **注意 ④** | 若已投 TMLR 且审稿中，**须确认 NeurIPS 的双投政策**（通常不允许同一时间投两处"正式投稿"；arXiv 不算） |

> **三轨关系**：arXiv（占坑，随时可更）→ TMLR（主投，rolling）→ NeurIPS 2027 E&D（备选，若 TMLR 被拒或想同时走会议）。**arXiv 与期刊/会议不冲突**；TMLR 与 NeurIPS **可能冲突**（同时间正式投稿），须按官方政策协调。

## 3. 第二作者

- **现状**：用户计划给老师发邮件邀请；**有就有，没有就单作者**。
- **单作者完全可以**：TMLR 与 NeurIPS 都接受单作者投稿（无最低作者数要求）。
- **若加第二作者**：须确认**实质性贡献**（不能挂名）——建议明确其在"方法设计 / 实验监督 / 论文修订"中的具体贡献，并写进 AI-use / contribution 声明（论文已有 contribution split 约定）。
- **时间**：作者名单须在**投稿前**确定（arXiv 署名 / TMLR 作者块 / NeurIPS 作者块都需一致）。

## 4. 风险与应对

| 风险 | 概率 | 应对 |
|---|---|---|
| **TMLR 被拒** | 中 | 转投 **NeurIPS E&D**，或 **EMNLP / ACL Findings**（若强调 LLM 知识验证），或其他 SE 期刊；本稿资产结构（数据 + 复现 + 负结果）适配面广 |
| **NeurIPS CFP 变化**（页数 / Croissant / 双投政策） | 中 | 关注官方更新；**提前**准备 Croissant 元数据与 2027 sty |
| **审稿人质疑可复现性** | 中高 | 已备：`REPRODUCE.md` + `docker/paper/run_all.sh`（**fail-loud**）+ 完整数据（1147 样本）；再补 Docker 镜像 tag 与种子审计（676h `seed_audit`：实验类未固定种子 **0**） |
| **审稿人质疑 novelty** | 高 | 强调**两条独立贡献**：① **盲区地图**（方法论——把"资产池能力边界"量化成 38.4% / 18-of-70，且证明是**组合天花板**而非选择失败）；② **A5 的选择效应量化**（首次把 selection effect 钉在 ≈+7–11pp，且诚实登记 `uninterpretable`）。用"更窄但更清晰"换"更大但更脆" |
| **审稿人质疑"FD 没赢随机"** | 高 | 正面承认：**主端点 +24.03pp / p=2.3e-41 显著，但并列分析 k=4 归零 ⇒ direction-only**；**不**声称 superiority；把价值锚在"机制可审计 + 组合价值（35.6%→61.6%）+ 能力边界" |
| **审稿人质疑头条率 n=41/64 小** | 高 | 主动报功效表；指出 **A5 已达 n=566**；坚持"方向优先、幅度后置"；`cover_letter.md` 已把该局限写进正文级材料 |
| **审稿人质疑单标注者** | 中 | 主动登记 T17（对召回数最大威胁）+ 预注册 25% 双标注 + κ<0.6 全复核 |
| **审稿人质疑 WSL 环境依赖** | 中 | 已升级 fail-loud（`REPRODUCE.md` + Docker），旧的 35.0%→10.0% 静默掉分已封堵 |
| **双盲 / arXiv 破盲** | 中 | 用匿名预印本或 review 后再挂 |
