## 任务 2.1：仓库可用性（README / CONTRIBUTING / CoC / CI）

### 2.1.1 README 的"30 秒看懂"审计

**审计前的第一屏**：标题 → 一段"匿名声明"（5 行）→ "What this is" → "Core findings"（5 条 bullet）。
问题：**陌生人 30 秒内看不到"我该敲什么命令"**；匿名声明占据了首屏最贵的注意力位。

**已做的最小改动**（不动结论、不加新主张）：在标题下方加了 `30-second version` 代码块——

```
git clone <this-repo> queyi-audit && cd queyi-audit
python tools/verify_paper_numbers.py \
    --tex paper/paper1/queyi_neurips2027_v1.1.tex \
    --tex-extra paper/paper1/supplementary/paper_appendix_extras.tex
# -> "检察 124 条；missing 0；consistent 112"   and exit code 0
```

并指向 `REPRODUCTION_LOG.md`（**实测**退出码表），以及一句
"if you only want to find a defect in this package, start there: it has already found ten"。
这条改动的用意正是评审那句话：**让陌生人第一分钟就在做"可独立验证的动作"，而不是读作者的自述**。
