## 1. 问题

`pyproject.toml` 是从**源仓库原样拷来**的，于是把本包描述成了上游书稿的生产工具链：

| 字段 | 修复前 | 为什么错 |
|---|---|---|
| `name` | `queyi-audit-toolchain` | 名字里带 `toolchain`，与实际（复现包）不符 |
| `description` | 《现代 C++ 终极圣经》生产级工具链：门禁、构建、发布、本地开发一体化 CLI | **①实体错误**（本包不产出那本书）**②身份泄露**（书名是可搜索标识符，L7/L8） |
| `license` | `MIT` | **与 `LICENSE` 文件（Apache-2.0）和 README（Apache-2.0）矛盾** |
| `authors` | `The Authors <anonymous@example.com>` | 域名 `example.com` 是占位，非中立地址 |
| `keywords` | `mkdocs` / `pandoc` / `documentation` | 上游站点依赖，与本包无关 |
| `dependencies` | `pyyaml` + `mkdocs-material` + `mkdocs-mermaid2-plugin` | 本包复现路径**只用标准库**，多装两个站点依赖是误导 |
| `[project.scripts]` | `cppbible = "tools.cppbible:main"` | **入口指向包内并不存在的模块**（坏声明 + 上游标识符 L6/L8） |
| `[project.urls]` | `https://anonymous.github.io/queyi-audit` | 非合法 URL |
| `[tool.cppbible]` | 整段上游工具链配置（含 30 余条 `quality_gates`） | 与本包无关，且反复出现上游标识符 |

## 2. 修复后

```toml
[project]
name = "queyi-audit"
version = "1.0.0"
description = "Reproducibility package for auditing software-verification evaluation: a measurement-drift
               algebra, a frozen 1,147 x 8 detection matrix, and paper-number recomputation from frozen artifacts."
license = {text = "Apache-2.0"}
authors = [{name = "Anonymous", email = "anonymous@example.org"}]
dependencies = []                       # 复现路径纯标准库
[project.optional-dependencies]
test  = ["pytest>=7.0"]                 # 唯一必需第三方依赖（跑 shipped tests）
gates = ["pyyaml>=6.0"]                 # 仅 gate/lint 工具需要，不在复现路径上
dev   = ["pytest>=7.0", "ruff>=0.5.0", "mypy>=1.10.0"]
[project.urls]
Homepage   = "https://example.org/anonymous/queyi-audit"
Repository = "https://example.org/anonymous/queyi-audit"
[tool.setuptools]
packages = []                           # 元数据型包，不打包 tools/ 与冻结数据
py-modules = []
```

**变更要点**

1. **名称/描述**改为审计复现包；描述中**不含**任何上游标识符。
2. **许可证 `MIT → Apache-2.0`**，与 `LICENSE`、`README.md`、`CITATION.cff` 一致。
3. **删除** `[project.scripts] cppbible`、`[tool.cppbible]` 整段、`py-modules = ["tools.cppbible"]`
   —— 同时修掉"入口指向不存在模块"的坏声明与 L6/L8 标识符。
4. **依赖收敛**：`dependencies = []`（依据见 §3）；`pyyaml` 降为可选 extra `gates`。
5. **URL 中立**：不指向任何作者账号（双盲期间发布物不得含 `github.com/LiaoRanran/*` 链接）。
6. 保留 `[tool.ruff]` / `[tool.mypy]` / `[tool.pytest.ini_options]`（`testpaths` + `pythonpath = ["tools"]`
   是 `tests/` 能跑的前提），但**删掉了源仓库特有的长注释与 numpy/requests/opentimestamps 等
   本包不存在的 overrides**。

## 3. 依赖审计（"为什么 `dependencies` 可以是空的"）

对 CI 可达面（`tests/` + `tools/verify_paper_numbers.py`）逐个 import 审计：

```bash
grep -rhoE "^(import|from) [a-z_]+" tools/ tests/ | sort -u
```

命中的全部是标准库（`argparse` / `json` / `math` / `re` / `pathlib` / `hashlib` / `statistics` /
`bisect` / `logging` / `subprocess` / `collections` …）；第三方只有 **pytest**。

全仓仅 2 个工具 `import yaml`：`tools/gate_engine.py`、`tools/counts_659.py` —— **都不在复现路径上**
（`gate_engine` 只在 `docker/paper/run_all.sh` 里被调用，而该阶段已登记跳过）。
`numpy` / `requests` / `matplotlib` / `mkdocs` / `pypandoc` / `hypothesis` / `syrupy`：**0 命中**。

⇒ 因此 `requirements.txt` 只列 `pytest>=7.0`，`dependencies` 置空，`pyyaml` 归入可选 `gates` extra。
