## 二、A · 星图 2.5D 伪3D 重制（web/starmap.js + web/starmap.html）

### 目标达成
| 要求 | 落地 |
| --- | --- |
| 不引入 Three.js / 零外部依赖 | 纯手算透视投影（`projectPoint`），整文件无 `three` 引用 |
| z 轴坐标 | 新增 `depthFor()`：每个节点一个确定性 z ∈ [-220, 220]（种子按下标，布局可复现） |
| 透视投影：近大远小 | `projectPoint` 返回 `scale = focal/(cam+z)`，近节点 scale 大、远节点小 |
| 透视投影：远节点变暗 | 同函数返回 `alpha`，随深度递减并夹取 [0.45, 1] |
| 鼠标拖拽旋转 | `mousemove` 拖拽改为旋转模型（水平→绕 Y，垂直→绕 X 俯仰，clamp ±1.3） |
| 滚轮缩放 | 保留 `zoomBy`（view.k） |
| 双击复位 | 新增 `resetView()`，绑定 `dblclick` 与右上角"复位视图"按钮（旋转归零 + 自适应） |
| hover 高亮邻居 | 保留 `neighborSet()` 压暗非邻居；改为纯函数 `nodeAlpha(i, {hovered, neighbors, searchHits})` 承载 dim 规则 |
| 节点大小按 degree 分级 | 新增 `nodeRadiusFor(degree)`：对数归一，hub(51)→最大 13px，孤立点(0)→最小 2.4px |
| 聚类区域改渐变光晕 | `drawClusterHalo` 由实心 `globalAlpha=0.055` 圆改为 `createRadialGradient`（token 色 0.20→透明） |
| 颜色来自 design-tokens | 节点色 `STATE_COLORS`、聚类 `clusterPalette`、连线 `LINK_STYLE` 全部为令牌镜像；**移除**写死的 `rgba(224,122,114,…)` hover 边高亮 → 改用 `C.accent`（令牌） |
| 60fps rAF | 新增 `scheduleDraw()`：rAF 去重（≈60fps），无每帧物理循环（布局仍加载时一次求解） |

### 关键纯函数（可被 Node 单测，见第五节）
- `projectPoint(world, view)` — 透视投影，返回 `{sx, sy, scale, depth, alpha}`
- `depthFor(nodes, positions, params)` — 确定性深度分配
- `nodeRadiusFor(degree, params)` — degree → 半径
- `nodeAlpha(i, ctx)` — hover / 搜索压暗（邻居高亮）

### 不变量（未破坏既有测试）
- 2D 平面变换 `applyTransform` / `invertTransform` 仍导出且可逆（回归锁在 `starmap_672e.test.mjs`）。
- 力导向布局（`seedPositions` / `stepForces` / `runLayout`）完全未动；2.5D 深度只是渲染层叠加，不影响 178/1093 节点的布局真值。
- 代码区（去注释后）不出现 `178` / `1093`（既有纪律锁保持）。

## 三、B · stale-aria-busy 修复（web/home.js + 测试翻转）

### 根因（672d-C 发现）
`#metrics`、`#timeline` 在 `index.html` 初始带 `aria-busy="true"`（加载占位），
但 `home.js` 渲染完成后只调 `setState()`（切状态机 + class），**从不清理 `aria-busy`** ⇒
屏幕阅读器在内容已就绪后仍被告知"繁忙"。

### 修复
- `web/home.js` 新增 `clearBusy(el)`：`el.setAttribute('aria-busy', 'false')`。
- 在 `renderMetrics` 的 `ready` / `empty` / `error` 三分支与 `renderTimeline` 的
  `success` / `empty` / `error` 三分支渲染完成后调用 ⇒ 渲染完成即清 `aria-busy`。
- 翻转 `web/tests/home_dom_672d.test.mjs` 的"已知问题锁"断言：
  由 `eq(aria-busy, 'true')` → `eq(aria-busy, 'false')`。

### 验证
`home_dom_672d.test.mjs`：**43 断言全绿**（含 aria-busy 现 = 'false'）。
jsdom a11y 审计 `index.html` 的 `moderate` 由 **2 → 0**（见第四节）。
