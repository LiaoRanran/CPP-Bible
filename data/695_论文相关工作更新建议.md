## 2. 需要**调整措辞**的现有 claim（3 处）

### 2.1 ⚠️ 把"$\Delta_{\text{unknown}}=0$ 是静默退化的指纹"降级

| 项 | 内容 |
|---|---|
| **位置** | F3 段（L458–470）与 §Observation function（L205–206 一带）；论文正文措辞为"silent-degradation fingerprint"。 |
| **问题** | **指纹（fingerprint）在科学写作中意味着"充要特征"**。但本仓库只有**一个环境对**（692 的 E1 `wsl-gcc-13.3` / E2 `windows-native-mingw`，$n{=}566$）。方向 1 的 `eve2026validationcrisis`（#15）与 `cerqueira2026conceptdrift`（#17）都指出：**单个漂移实例不足以定义一个判定特征**。 |
| **建议改法** | 把"fingerprint"改为 **"a signature observed in one environment pair"** 或 **"a candidate signature"**，并在 T3 或 Future work 明确：*"Whether $\Delta_{\text{unknown}}=0$ is a sufficient signature of silent degradation requires more than one environment pair; we report it as a characteristic of the single pair we could measure."* |
| **为什么值得改** | 这是**低成本、高收益**的诚实化：不改，审稿人可以用"$n_{\text{env}}=1$"一句话打掉 F3 的普适性；改了，F3 变成"我们诚实报告了一个可推广假设的单一实例"，**反而更稳**。 |

### 2.2 ⚠️ 把"+24pp 是构成效应"改成"在 Pool A 上增益消失"

| 项 | 内容 |
|---|---|
| **位置** | F1 段（L419–440）。 |
| **问题** | "$+24$pp 是构成效应"隐含 **$g_{\text{comp}}$ 与 $g_{\text{mech}}$ 可无混淆分离**。但现有池设计（严格池 / Pool A/B/C）**只做了"剔除退化资产"，没做"等边际替换"**（方向 5 命题 P1.6）。缺等边际替换时，两句强度不同的陈述会被混为一谈：<br>（强）"构成效应 $=+24$pp，机制效应 $=0$"；<br>（弱）"在 Pool A（$d{=}0$）上，$k{=}4$ 的增益消失"。 |
| **建议改法** | 主句用**弱表述**（可复算、可复现），把强表述降为**受条件限制的推论**：*"With degenerate assets controlled (Pool A, $d{=}0$), the $k{=}4$ gain vanishes; we therefore report the headline gain as composition-dominated **within the pools we measured**, and note that a no-confounding separation would require an equal-margin substitution design (Future work)."* |
| **收益** | 同时得到两样东西：**保住 F1 的冲击力**（增益确实消失）+ **封住"不可识别"的攻击面**（主动承认分离条件）。 |
