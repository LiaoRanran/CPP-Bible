## 一、现状诊断：投稿为什么全受阻（冷酷根因拆解）

不要把受阻归因于"学校差"或"运气不好"。拆开看，你被卡在 **4 个独立的、可修的结构性问题**上，它们和你的研究质量其实关系不大：

### 根因 1：你缺的不是邮箱，是"身份凭证链"
- OpenReview 被拒 → 表面是"缺学校邮箱"，实质是**新账号无机构邮箱 = 进入人工 moderation，最长 2 周**，你又在临近截止时注册。
- arXiv 被卡 → **2026-01-21 起政策又收紧了**：光有学校邮箱不够，还得"同 domain 有过 arXiv 论文"。你两条都不满足。
- TechRxiv"迁移关闭" → 实际平台没死（2025–2026 仍在运营），是你**账号/实例迁移**出了问题，没走 IEEE 支持流程。
- **结论**：邮箱问题的本质是"平台无法证明你是个活人学者"。解法不是去办一个 edu.cn（当然有更快），而是**用 ORCID + GitHub + 预印本 DOI 组成一套可验证的身份链**，让任何平台都能自动判你为真人。

### 根因 2：你的"可复现性"为 0，而 2026 年所有正规渠道都要代码 DOI
- PeerJ 明确要求 GitHub **必须配 Zenodo DOI**；NeurIPS 有 reproducibility checklist；连国内 CCF 会议都在问代码。
- 你现在**没有 Zenodo DOI、没有 Docker、没有一键复现脚本**。
- **结论**：哪怕邮箱问题全解决，你投任何正规渠道，reviewer 第一句就是"代码呢"。这不是邮箱问题，是工程交付物缺失。

### 根因 3：你的核心数据里，人类标注 = 0
- 你所有 κ 都是 **AI 自洽**，不是人类一致。
- 这在 2026 年是**双重雷**：① 统计上没有 inter-annotator 效度；② NeurIPS 2026 刚 desk-reject 了 18.4% 疑似 AI 生成稿，你的"AI 自洽"会被误判。
- **结论**：这是你被"同学没时间"卡住的真正代价——缺一个人类 ground truth，整篇实证的效度就站不住。

### 根因 4：你用的是"主动社交"模式，而你的性格是"被动吸引"
- 你找同学做 IAA、找 arXiv 老作者 endorse、找导师背书——这些都要求你**主动开口求人**，而你内向，每求一次都内耗一次，最后全部烂尾。
- **结论**：不是你能力不够，是**策略和性格错配**。后面所有建议都改成"把成果做成可被搜到的资产，让人来找你"。

**一句话诊断**：你的研究本身（E1→E2 退化 60.07%→24.74%、McNemar p=1.24e-60、g_app R²=0.9997、Type I=849 样本下界）**有真东西**。挡住你的是 4 件交付物层面的事，不是研究层面的事。这是好消息——因为交付物能在 3 个月内补齐，而研究质量补不了。

## 二、短期出路（0–3 个月，2026-10 至 2027-01）：按 ROI 排序

ROI = （解决的阻塞数）÷（投入时间/钱）。下面从高到低。

### S1【本周做，0 成本，解决全部 4 个根因的地基】注册并养熟 3 个账号
- **做什么**：① OpenReview 注册（用个人邮箱，profile 写满 career/homepage，进 moderation 排队）；② ORCID 注册；③ Zenodo 用 **GitHub 登录**（避免被当 spam）。
- **怎么做**：每个都在 30 分钟内完成；OpenReview 不要重复注册（会撞号）。
- **什么时候**：2026-10 月第 1 周。
- **预期效果**：OpenReview 到 2027-05 有 7 个月激活期；ORCID/Zenodo 成为你跨平台统一身份链。**这是所有后续动作的前置，不做后面全废。**

### S2【本周做，0 成本，2 天搞定】Zenodo 代码包 + 第一个 DOI
- **做什么**：把现有代码、40 CVE 案例库、实验脚本打包，关联 GitHub，打第一个 Zenodo DOI。
- **怎么做**：GitHub 仓库 → Zenodo 关联 → release → 自动出 DOI（10.5281/zenodo.xxxx）。先不追求完美复现，先有 DOI。
- **什么时候**：2026-10 月内。
- **预期效果**：立刻解决"无代码 DOI"这个硬门槛；这个 DOI 之后能贴在所有投稿、所有平台、所有文章文末。**半天工作量，收益覆盖未来 2 年所有投稿。**

### S3【本周做，0 成本，1 天】TechRxiv 账号重测
- **做什么**：登录 techrxiv.org 确认你账号状态；若丢失，走 IEEE Author Gateway 支持找回。
- **怎么做**：别再假设它"关了"——2025-07 还有新稿，IEEE 2026-08 还在推。用事实说话。
- **什么时候**：2026-10 月第 1 周。
- **预期效果**：若账号可用，论文 1 的 PDF（匿名化版）+ S2 的 Zenodo DOI 链接直接传，几天内得 10.36227/techrxiv.* DOI，**首发权当天钉死**。

### S4【2 周内，0 成本】国家预印本平台(napstic) 发论文
- **做什么**：在 sinoxiv.napstic.cn 实名注册，把两篇论文各发一条预印本。
- **怎么做**：这是唯一明确"实名即可、不卡机构邮箱"的国家级平台。**注意只用 .napstic.cn 官方域名，别碰 sinoxiv.com。**
- **什么时候**：2026-10 月底前。
- **预期效果**：再得一个 DOI + 国内可被检索。与 TechRxiv 形成"国外 + 国内"双首发保险。

### S5【2–4 周，0 成本】路径 A 人类盲标注（人-AI κ 从 0 到 1）
- **做什么**：你本人间隔 ≥2 周、盲（先藏 AI 结果）独立标 100 样本，算人-AI κ。
- **怎么做**：分两个周末，每次 50 个；标完再和 AI 结果对。
- **什么时候**：2026-11 月启动，12 月底出数。
- **预期效果**：把"人类 IAA=0"这个最致命的雷先排掉一半。不完美，但从 0 到 1。

### S6【持续，0 成本】被动吸引内容资产（3 篇硬核技术文）
- **做什么**：把三个最有传播力的点写成知乎/CSDN 长文：① "我在 WSL 里跑出 60%，到 native 只剩 24.74%——环境静默退化实录"；② "Goodhart 四型分类 + g_app(d)=5.47+5.28d−0.26d² 拟合 R²=0.9997"；③ "F1 因果分解：+24.03 怎么被拆成 −9.55/−8.27/−4.65/+10.74"。
- **怎么做**：每篇 2000–4000 字，硬核、带数据、带代码链接，文末挂 TechRxiv/Zenodo DOI。**不社交、不求转发，靠搜索流量。**
- **什么时候**：2026-11 月起，每月 1 篇。
- **预期效果**：这是你"被动吸引"的弹药库——审稿人、潜在合作者、未来的 endorse 人，都是搜这些文章找到你的。

> **短期不做的事**：不要现在就投 PeerJ（$2155 + 无人类 IAA 纯白交）、不要现在硬磕 arXiv endorsement（没预印本没人理你）、不要现在投 CCF 中文会议（2026 周期已过，2027 春再说）。

## 三、中期出路（3–9 个月，2027-01 至 2027-05）：NeurIPS 2027 路径

详细周历见《712_NeurIPS2027准备清单.md》，这里只讲战略取舍。

### M1【2027-01，主攻】路径 B：引入外部人类基准
- **做什么**：找 1–2 个**已有社区人类 ground-truth** 的公开 CVE/commit 基准，把你的框架跑上去，用别人标好的人类数据算 E1→E2 退化。
- **为什么是主攻**：它一次性解决"人类 IAA=0"和"真实基准是重建"两个硬伤，是 reviewer 唯一会认的人类效度形式。
- **预期效果**：论文从"AI 自洽"升级为"在外部人类共识基准上，60.07%→24.74% 退化仍成立"。

### M2【2027-02】第三环境 E3 = Clang 工具链
- **做什么**：在 native Clang 下重跑 40 CVE，验证 F1 分解里那个 −4.65 linker 项是否反转。
- **预期效果**：一张三环境对照表（WSL/GCC/Clang），把"环境退化"从单点观测变成可复现机制。

### M3【2027-03】重新定位 contribution type
- **做什么**：按 **Negative Results / Use-Inspired** 重写 intro——把"静默退化 + 下界（Type I=849 / Type II=17）"作为核心卖点，而不是藏着掖着。
- **为什么**：NeurIPS 2026 已正式细分 contribution type，Negative Results 是被鼓励的赛道。你的工作本质就是"能力边界"，硬当 General 投是错位。
- **预期效果**：匹配对的 track，被 desk reject 的概率显著下降。

### M4【2027-04】匿名化 + 投稿
- **做什么**：代码仓库匿名化、PDF 去名、Zenodo embargo；~5/14 交 abstract，~5/21 交全文（**提前 3 天**）。
- **预期效果**：投出去。中不中是概率，投不投是你能控制的。

### M5【2027-06~09】Rebuttal + 决策
- 用提前备好的 3 套 rebuttal 弹药（见清单第 4 节）；若拒，**立刻转 TMLR（rolling，无截止）或 ICML 2028**，不要停。

## 四、长期出路（9 个月以上，2027-07 起）：学术身份建立

长期目标不是"中一篇 NeurIPS"，而是**让"Queyi 框架的作者"成为一个被人记住的学术身份**。

### L1 【2027 春保底】一篇正规可检索论文
- **做什么**：若 NeurIPS 拒，把论文 1 中文化，投 CCF 中文会议/期刊（WISA/数智服务大会节奏，每年 3–5 月截稿；或直投《计算机科学》《计算机应用》）。
- **成本**：CCF 学生会员 50 元/年 + 注册约 ¥2000 + 到会。
- **预期效果**：用最低成本换一篇正规、EI/中文核心可检索论文。**这是你考研复试/申请硕士时简历上第一行实打实的东西。**

### L2 【持续】把"被动吸引"做成系统
- 每出一个新结果，就同步：① Zenodo 新版本 DOI；② 一篇技术文章；③ 预印本平台更新。
- **逻辑**：让你的 GitHub（LiaoRanran）、ORCID、知乎主页、TechRxiv 主页**四个入口指向同一套成果**。任何搜到其中一个的人，都能顺藤摸瓜找到全部。
- **预期效果**：6–12 个月内，潜在合作者/导师/endorser 会主动通过这些渠道找到你——这正是你"内向但要学术身份"的最优解。

### L3 【2027 下半年】用第一篇成果换"正式合作者"
- **做什么**：带着已发表/已预印的论文，去联系 cs.SE / 软件验证方向的年轻老师（AP、博后），**不是求背书，而是"我有一个做完的框架和数据，缺一个合作点"**。
- **预期效果**：一旦有了第一个有 arXiv 记录的合作者，你 arXiv endorsement 路径、reciprocal reviewer 名额、导师背书三件事**一次性解决**。

## 五、被动吸引策略（核心：如何让别人主动来找你）

你内向，不要主动社交。那怎么让人来？**把你的学术存在做成 6 个可被搜索、可被信任的静态资产**，然后什么都不用做：

| 资产 | 作用 | 维护动作 |
|---|---|---|
| **GitHub（LiaoRanran）** | 证明你是真做工程的人 | README 写清框架，代码可跑，CI 绿 |
| **ORCID** | 跨平台统一身份 | 关联所有 DOI/预印本 |
| **Zenodo 记录** | 可引用、可复现 | 每次更新打新版本 DOI |
| **TechRxiv/国家预印本** | 首发权 + 可被 Google Scholar 索引 | 论文更新时同步新版本 |
| **知乎/CSDN 技术长文** | 中文世界的曝光入口 | 每月 1 篇，带数据带代码 |
| **OpenReview profile** | 投 ML 会议的地基 | 保持激活，别pending |

**关键原则**：
1. **所有资产互相链接**（文章挂 DOI、DOI 链 GitHub、GitHub 链预印本）——形成闭环，搜索引擎和人都能顺藤摸瓜。
2. **内容硬核，不卖惨不求人**。你越"把东西做好放在那"，越显得可信；你越主动求人，越像学生。
3. **cold email 只在有了预印本+代码之后发**，且只发"我的工作你 5 分钟能看完"的极简邮件，预期回复率 <5%，发 30–50 封有 1–2 个回应就成功。**这是被动吸引里唯一需要"主动"的一步，但它建立在你已有资产之上。**

## 六、风险与诚实局限

我必须对你诚实，不打包票：

1. **NeurIPS 2027 录用概率客观很低**。无机构、无导师、曾是 AI 自洽 IAA、单人作者——这在 NeurIPS 历史上是小概率事件。这份计划的价值是"让投稿无硬伤"，不是"保证中"。请不要把 7 个月的全部希望压在这一篇上。
2. **人类 IAA 即使补齐，也只是"从 0 到可辩护"，不是"从可辩护到优秀"**。路径 A（自己盲标）reviewer 会质疑；路径 B（外部基准）才是主力，但能否找到合适公开基准，有不确定性。
3. **E3 环境有可能推翻主结论**。如果 Clang 下退化不成立，你的核心叙事会受冲击——但这恰恰是 Negative Results 论文该有的诚实，不是世界末日。
4. **经济成本**：PeerJ $2155、F1000 $1758、中文会议约 ¥2500——这些都不该现在花。**短期所有出路都是 0 成本**；唯一值得花钱的节点是"论文已被录用后"。
5. **身心风险**：你自述有失眠、内耗、濒死体验。7 个月赶 NeurIPS 是高压日程。**如果中途崩盘，优先级永远是：人 > 论文**。里程碑按周拆小就是为了让你不至于一天扛一座山。投不出去，天不会塌；身体垮了，一切都没了。
