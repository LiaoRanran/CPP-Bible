### 选题 1 · Measurement Drift Algebra: A Formal Framework for Evaluator Auditing

**一句话**：把评估器审计从"报告模板 / 评分系统 / 制度流程"升级为**带可识别性条件的代数对象**。

**核心内容**（697-A/B 已完成的在括号里标 ✅）：

| 组件 | 内容 | 状态 |
|---|---|:--:|
| 公理系统 | 7 条公理（可枚举性 / 单调性 / 幂等性 / 交换闭包 / 超可加性 / 不可逆性 / 可观测分层） | ✅ 697-B §1 |
| 定理 T1 | 撤除型漂移的超可加性 + **闭式残差** $-\lvert C_A\cap C_L\setminus C_B\rvert/n$，三种划分实测吻合 | ✅ 697-B §3 |
| 定理 T2 | 不可逆性 ⇒ **漂移不可事后校正** | ✅ 697-B §3 |
| 定理 T3 | 静默性是 $(\tau, \text{口径})$ 二元组的性质 ⇒ 修正"$\Delta_{\text{unknown}}=0$ 是静默指纹" | ✅ 697-B §3 |
| 定理 T4 | 单向性判据 $c_g = 0$，11 层实测 | ✅ 697-B §3 |
| 结构性 Goodhart | 定义 + 四型分类 + 可判定性二分 | ✅ 697-A |
| 检测协议 | 5 步协议 | ✅ 697-B §6 |
| **缺口** | **等边际替换设计**（分离 $g_{\text{comp}}$ 与 $g_{\text{mech}}$） | ⏸ **需要新设计** |
| **缺口** | **第二个领域 / 第三个环境对**（跨域验证） | ⏸ **需要新数据** |

**目标 venue**：ICML / NeurIPS 主会（方法论方向）；备选：AISTATS / UAI；
**不建议**投 ICSE/FSE（那是选题 3 的地盘）。
