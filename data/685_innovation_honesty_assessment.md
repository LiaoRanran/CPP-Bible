## 逐点诚实评估

### 创新点 1 · AGEA（反古德哈特评估装置框架）

| 问题 | 诚实回答 |
|---|---|
| 这是全新的吗？ | **否**（数学上）。四态判定、Merkle 账本、能力边界声明各自都不新（Merkle 1979；Datasheets/Model Cards 2021）。 |
| 增量贡献是什么？ | **框架合成（synthesis）**：首次把上述构件**组装**为「反评估者自欺」的**可证伪形式性质**（定义 2），并抽象为通用评估装置理论。这点是新的。 |
| 实验支持吗？ | 靠**既有工程事实**支持（452 条账本 + Merkle 根 + 676g/682 审计 + 677d 方向性 claim），无需新跑；定理靠 Merkle 密码学性质论证。 |
| 值得写进论文吗？ | **是，但定位为「框架/治理贡献」**，不是「算法/定理贡献」。这正是 684 C2 诊断的结论——论文最强资产是治理框架，而非算法新颖。 |
| 风险 | 若审稿人质疑「这只是把已有实践包装」，回应是：我们提供了**可证伪的反古德哈特性质**（定义 2），这是 HELM/Model Cards 未做的。 |

**结论**：诚实定性为 **框架合成创新（非数学新定理）**；可辩护，但不宜拔高。

---

### 创新点 2 · 子模「无免费午餐」天花板

| 问题 | 诚实回答 |
|---|---|
| 这是全新的吗？ | **否**（定理是 max-of-sum ≥ sum-of-max 不等式在覆盖目标上的实例化，根 Golovin-Krause 2011）。 |
| 增量贡献是什么？ | **定量封口**：把 684 的「自适应≈FD」升级为「自适应增益上限 = 条件多样性 = +2.3pp」的可计算结论。 |
| 实验支持吗？ | **是**（`685_direction1_experiment.json`，可复现）。 |
| 值得写进论文吗？ | 作为**定理式附录/正文 1 段**值得；作为「novel contribution」则过度。 |
| 风险 | 低；属标准理论的干净应用，审稿人难以反驳。 |

**结论**：**应用/扩展级创新**；真实增量（定量天花板），但非新定理。

### 创新点 3 · 能力边界量化器

| 问题 | 诚实回答 |
|---|---|
| 这是全新的吗？ | **否**（覆盖天花板的互补重述）。 |
| 增量贡献是什么？ | 把「能力边界」从口号变为**一行可计算、随演化单调非增的可声明量**，与 append-only 账本契合。 |
| 实验支持吗？ | 是（684 A3 的 8-资产天花板 63.0% → CB=37.0%）。 |
| 值得写进论文吗？ | 作为 capability boundary 的形式化脚注/附录值得；不独立成贡献。 |
| 风险 | 低。 |

**结论**：**应用级**，价值在「使能力边界可声明、可审计」，非新定理。

## 总诚实结论（对用户）

- **三个创新点都不是数学新定理**。最诚实的定位：本批（含 684）的理论贡献是 **「把验证器资产选择形式化为子模最大化 + 给出自适应天花板与鲁棒稳定性」**——这是**形式化与定量封口**，不是新算法。
- **真正的、可辩护的「新」在于合成层**：把 Queyi 的治理构造抽象为 **AGEA 反古德哈特评估装置框架**（定义 2 的反自欺可证伪性质）。这是 framing/synthesis 级的创新，与 684 C2「治理框架是论文最强资产」一致。
- **论文 claim 必须保持克制**：继续 684 C2 的「形式化 + 治理」定位，**绝不**声称「novel algorithm / novel selection mechanism」。任何「新」的表述都限定为「to our knowledge, the first to formalize verifier-asset selection as submodular maximization / the first to frame evaluation apparatus as anti-Goodhart」。
- **未达「真新定理」不丢人**：在 NeurIPS E&D 赛道，一个**可审计的评估治理框架 + 严谨的形式化**本身就是稀缺且可发表的增量；强行编造新定理才是高风险。
