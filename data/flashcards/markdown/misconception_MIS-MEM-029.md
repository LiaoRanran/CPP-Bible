# MIS-MEM-029（misconception）

## 正面

【误解】MIS-MEM-029 性能结论不标平台/编译器/标准库版本，或基准不控制变量（三变量同变）
触发说法：\"XX 比 YY 快 3 倍\"——不说是哪台机器、哪个编译器、哪个标准库版本

## 背面

为什么错：**平台翻转是实测的**：同一夹具、同一工作量，MinGW 15.3.0/libstdc++ 上 `monotonic < pool < global`（两资源快 4.4× 与 2.0×），Linux/glibc 上 `global < pool < monotonic`（两资源反而慢 1.9× 与 1.37×）——同一句\"池更快\"在两平台上一直一假（EV-MEM-039 双平台对照）
反例 1：**变量不唯一会被红队当场拆掉**：本卡初版的 `controlled_vars` 声称\"唯一变量 = 标准库\"，但 libstdc++ 列取自 MinGW、libc++ 列取自 WSL + `g++-14` ⇒ 标准库/驱动/平台三者同变，因果无法归因；补\"同一条 `g++-14` 驱动分别跑两标准库\"的对照后，唯一变量才真正只剩标准库（EV-MEM-038 同驱动对照表）
反例 2：**顺序效应会伪装成策略优势**：策略测量顺序固定（global→monotonic→pool）时，冷启动与频率爬坡被算进第一个策略——实测 global 首轮 771200 ns、后续落到 47–49 万，若只取首轮就会把\"谁先跑\"读成\"谁更慢\"（EV-MEM-039 逐轮样本）
