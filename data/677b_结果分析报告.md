### 1.3 三种 clone-aware split

- `family_random` / `family_stratified`：分裂单位 = **全对凝聚家族**（同族整体进同一侧，家族跨 split = 0）；
- `strict_stratified`：分裂单位 = **克隆关系连通分量**（最强口径，**任意一对判克隆的样本**都不跨 split，克隆对跨越 = 0）；
- 种子 6771；评估侧样本数 568–569（与原 566 偏差 <0.4%，验收要求 ±5%）。
- 均衡性代价：原 split 的分层均衡最好（batch 最大偏差 0.27pp）；family-aware split 因跨批家族整体迁移，最大偏差 7.0pp（family_random 的 source_batch）～3.1pp（family_stratified）。详见 `677b_split_comparison.md`。

## 2. A5 重算结果（任务C）

判定矩阵与检测器：**复用 676f 的 1137×8 逐格真实 `detect` 结果**；统计原语与 676f/673p 完全一致（exact McNemar、McNemar 口径 Δ CI、Clopper–Pearson、2000 次 Random 分布）。
**管线正确性核对**：在原 split 上重算 ⇒ FD 54.5936% / Random 30.5654% / Δ+24.0283pp / p=2.296×10⁻⁴¹ / 并列 Δ=0.00，与 676f 登记值**逐位一致**（5 项 match 全为 True，见结果 JSON 的 `control_reproduction_original_split`）。

## 3. Cluster Bootstrap（任务D）

重采样单位 = 分裂单位（家族/连通分量），2000 次，种子与 split 同源（6771）。**两种模式**：

- **frozen_arms**（推荐读法）：冻结两臂资产集（= 论文报告的 Δ 对应的固定对照），只重采样数据 ⇒ **报告量 Δ 的 cluster CI**；
- **full_refit**：每 replicate 重排 FD + 重抽 Random ⇒ 含选臂方差，回答"换个随机臂会不会翻盘"。

| split | 指标 | 普通 CI（676f 口径） | **cluster CI（frozen）** | 宽度比 | 设计效应 / 有效 n |
|---|---|---|---:|---:|---:|
| family_stratified | FD 率 | [51.35, 59.67]（8.32pp） | **[47.53, 63.96]**（16.43pp） | 1.97× | deff≈4.05 → **≈140**（名义 569） |
| family_stratified | Δ | [+19.14, +26.90]（7.76pp） | **[+16.57, +30.38]**（13.80pp） | **1.78×** | Δ≤0 比例 **0.0** |
| strict_stratified | FD 率 | [53.39, 61.67]（8.29pp） | **[48.53, 65.78]**（17.24pp） | 2.08× | deff≈4.26 → **≈133**（名义 568） |
| strict_stratified | Δ | [+22.11, +29.30]（7.19pp） | **[+18.28, +33.39]**（15.12pp） | **2.10×** | Δ≤0 比例 **0.0** |

- 并列（5 候选）：family_stratified Δ 的 cluster CI [−2.84, +1.59]pp（含 0）⇒ 归零结论同样稳健。
- **full_refit 的警告（诚实边界）**：若把"随机臂也是随机的"纳入不确定性，Δ 的 95% 区间为 [+0.43, +39.02]pp（Δ≤0 比例 2.2%）与 [+0.00, +40.03]pp（3.0%）——**下界贴 0**。这支持论文现有的保守定位：A5 只能给**方向证据 / 条件结论**，不得升级为"FD 优于随机"的确认性主张。区间宽的主因是 Random 臂自身的不确定性（其 cluster CI 宽 15.7–16.0pp）。
- 重采样后评估集样本数在 424–737（family_stratified）/ 345–923（strict）之间波动（单位大小不等所致，已如实记录）——deff 中含这一规模变动成分。
- FD 排序的稳定性：full_refit 下 2000 次中 `asan` 2000/2000 次入选、`tsan` 1992–2000、`ubsan` 1990–1992（前三位在**全部**重采样中稳定），第 4 位在 `cross-compile`/`compiler-warn` 间摆动 ⇒ 选择效应集中在前 3 个资产。

## 4. 核心结论判定

| 问题 | 判定 | 依据 |
|---|---|---|
| clone-aware 后 Δ(FD−Random) 是否还在？ | **成立（稳健）** | +23.02 ～ +26.71pp，p ≤ 4.1×10⁻²⁹；三 split + strict 一致；96.3–97.6% 随机抽样更劣 |
| 原结果是否主要来自 leakage？ | **否** | 去除泄漏后 Δ 不降（略升），变化在噪声内；泄漏贡献量级 ≈ 0 |
| 并列分析 k=4 归零是否泄漏产物？ | **否（同样稳健）** | −0.53 ～ +0.00pp，四种切分一致 |
| 「FD 优于同预算随机」可否升级为确认性主张？ | **仍不可** | ①退化资产机制（5 候选中 k=4 两臂选集必重合）；②有效样本量 ≈133–140，full_refit 下区间下界贴 0 |
| 区间该怎么读？ | **普通 CI 需按 ~2× 放宽** | deff≈4.1–4.3；论文"区间应据此读宽"的定性判断得到量化 |

## 5. 未解决项与局限（诚实边界）

1. **家族定义是工程决策**：双指标 + 全对约束（C1∪C2∪C3，threshold 0.85/0.90）。C2（标识符归一后的 token Jaccard）会把"**同代码骨架、不同缺陷类型**"的样本并族（例：`F102` `volatile const` 假写保护 ↔ `F171` `register` 弃用，归一化后逐字同构）——这与 676k 的 62.2% 克隆率同源，是数据构造方式的固有属性；本批沿用该口径并在报告中标出。阈值敏感性只做了**家族数**层面（0.80/0.90 见任务A报告），**未**逐档重算 A5。
2. **complete-linkage 的残余**：575 对判克隆的对跨家族（但同分量）⇒ family 级 split 有 294/401 对克隆对跨越；strict 变体为 0。故 **strict 变体是本批推荐的"不泄漏"口径**，family 级变体是卡片指定的构造。
3. **cluster bootstrap 的单位大小不等** ⇒ 每 replicate 评估集规模波动（424–737/345–923），deff 同时含组内相关与规模变动；未做"固定 n 的 rescale"变体。
4. **只对 family_stratified 与 strict 做了 bootstrap**（family_random 未做，出于计算量考虑）。
5. **未重跑 detect()**：判定矩阵复用 676f；`unknown` 处理口径与 676f 相同（绝不当 miss）。逐格判定存在 ~5% 跑间不稳定（676f 已披露），本批不重新度量。
6. **两种 split 的均衡性代价**（batch 最大偏差最高 7.0pp）是「家族整体不动」的必然结果，未做二次交换优化。
7. 本批**不改论文**：更新建议见 `data/677b_论文更新建议.md`，由论文批次执行。
