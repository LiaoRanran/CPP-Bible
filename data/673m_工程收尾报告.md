## 1. 任务 A · push 与 CI

### 1.1 push 失败（如实记录，未强推）

```
$ git push origin master
Enumerating objects: 213 → Writing objects: 42% (59/140)
send-pack: unexpected disconnect while reading sideband packet
error: failed to push some refs to 'https://github.com/LiaoRanran/CPP-Bible.git'
```

4 次尝试（全量推 / 分片推单个 commit / 调大 `http.postBuffer` / 改 `http.version=HTTP/1.1`）**全部在同一环节失败**。

定位证据：

| 检查 | 结果 | 说明 |
|---|---|---|
| `git fetch` / `git ls-remote` | ✅ 正常 | 读通路没坏 |
| 服务端 auth | ✅ 401 → 200 | **凭据有效，不是权限问题** |
| 远端 HEAD | `5a9da94e`（= 本地基线） | **不是冲突**（ahead=11/12、behind=0） |
| 待传数据量 | 75 文件 / 3983 插入，最大 blob 123KB | **不是体积问题** |
| `curl -X POST .../git-receive-pack` | ✅ 401 in 1.1s | POST 通路本身是通的 |
| `GIT_CURL_VERBOSE` | `Established connection to github.com (**fd00::1a** port 443)` | **git 连的是本地拦截代理**，不是真实 GitHub |
| `ssh -T git@github.com` | 被解析到 **198.18.0.26** | DNS 被拦截（198.18/15 是保留网段，非 GitHub） |

**结论**：本机网络出口（fd00::1a / 198.18.0.26 拦截层）对 git 的 **receive-pack 分块上传流**不返回响应，上传写完后即被挂断。属**环境限制**，非仓库/权限/冲突问题。已按要求**不强制 push**。
