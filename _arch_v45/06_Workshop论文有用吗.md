# 方向 06：Workshop 论文有用吗

## 核心结论
1. Workshop 论文**不是正式同行评审（普遍仅有轻量评审/仅 chairs 过目）**，CV 权重远低于主会/DB track，但它是**双非单人作者最低成本获得会议曝光、建立人脉、试讲 idea** 的入口。
2. 对 QueYi：先投一个"程序分析/LLM 评测/可信 AI"相关的 NeurIPS/ICSE workshop（如 Mechanistic Interpretability、AI Evaluation、SEAI），用 workshop 当"预演 + 找合作者"舞台，再冲主会。
3. Workshop 论文可以（且应该）后续扩展成正式会议/期刊稿；arXiv 预印本 + workshop 短文是"先占坑、再深耕"的标准打法。

## 精确数字与案例
- **评审强度**：NeurIPS workshop 多无严格双盲，部分仅 chairs 审或 poster-only；例：NeurIPS 2025 Workshop on Mechanistic Interpretability 收录短文（如 Vigna 组的 Ethereum approve 攻击分析文，列于其 publications）。
- **价值实证**：Faster R-CNN 等里程碑工作最初也经 workshop/tech report 演化；workshop 的核心价值是**反馈 + 网络**，不是引用数。
- **成本**：workshop 投稿通常 4–8 页、周期短（截稿常在主会后 1–2 月），几乎零版面费。
- **风险**：部分 workshop 论文不被 Google Scholar 当作 peer-reviewed 计数；投前确认该 workshop 是否被 proceedings 收录（如 some NeurIPS workshops 有 Proceedings of Machine Learning Research, PMLR）。

## 对阙疑的 3 条具体行动
1. **锁定 2–3 个对口 workshop**：NeurIPS 2027 的 AI Evaluation / Trustworthy ML / Code LLM workshop + ICSE 的 SEAI workshop；把 QueYi 缩成 4 页短文，主打"可审计知识验证基准"。
2. **用 workshop 找合作者**：在 poster 环节主动找做 PBT/程序验证的研究者交换邮箱（为方向 31–33 的导师/合作铺路）。
3. **workshop → arXiv → 主会**：workshop 短文发 arXiv，附"full version to NeurIPS E&D 2027"字样，占时间窗且不被算双投（workshop 非正式稿 + arXiv 预印本均允许）。

## 盲区（诚实标注）
- 未逐个核对 2027 各 workshop 的截稿日与是否进 PMLR；需临近 2027 截稿时查 NeurIPS workshop 列表。
- workshop 的"网络价值"对 introvert 单人作者转化率低，需主动出击（见方向 33）。
