# 方向 08：论文被拒后转投哪里

## 核心结论
1. 被拒≠结束：顶会均接受"被拒稿扩展后重投下一会"，关键是**用 reviewer 意见补实验**，而非换皮重投。QueYi 被 NeurIPS 拒后，最顺的降级链是 NeurIPS E&D → ICSE/ASE *Tool/Dataset* → JSS、EMSE、TSE 等期刊。
2. 选择下家的核心判据：**受众是否匹配 + 拒稿意见能否被补齐**。QueYi 是"系统+基准"，SE 期刊（EMSE/TSE）比泛 ML 会议更懂，且对单人作者更友好（期刊无"接收率硬控"压力）。
3. 不要沉没成本式死磕：若连续 2 次被拒且意见集中在"创新性不足"，应转向"更垂直的会场"（如 程序分析专会 PLDI/ISSTA 的 tool 类，或 软件测试会议 ICST）。

## 精确数字与案例
- **降级链示例（ML 向）**：NeurIPS E&D → ICML / ICLR（若偏方法）→ 二区期刊（如 JMLR、TPAMI 视主题）。
- **降级链示例（SE 向，更匹配 QueYi）**：NeurIPS E&D → ASE/ICSE *Tool* → **EMSE**（Empirical Software Engineering）或 **TSE**（IEEE Transactions on Software Engineering）。TSE/EMSE 是 SE 顶刊，接收系统性工具/基准工作，且期刊评审更看重"可用性 + 复现"而非新鲜度。
- **拒稿再利用**：NeurIPS rebuttal 意见（见方向 04）直接变成"下一稿的 related work/局限/额外实验"清单；平均被拒 1.5 次是顶会常态。
- **时间窗口**：NeurIPS 2027 拒稿（约 2027-09）→ 可赶 ICSE 2028（截稿约 2027-09/10，需快改）或 ASE 2028（约 2028-05）；或投 EMSE 长周期。

## 对阙疑的 3 条具体行动
1. **建"拒稿→行动"模板**：每次被拒，立刻把 reviewer 意见归类（样本小/对比少/创新弱/写作糊），每条配一个补实验；QueYi 优先补"外部 corpus 检出率"（从 33.3% 提升）与"更多编译器差异案例"。
2. **预设降级会场清单**：在主稿里就预留 ICSE/ASE *Tool* 与 EMSE 两版框架，被拒时一键改 framing（基准→工具/经验研究）。
3. **别拖**：被拒后 2 周内出修订稿投下一会，保持 momentum；冻结超 3 个月则重启成本高（见方向 59）。

## 盲区（诚实标注）
- TSE/EMSE 精确录取周期与接收率来自行业记忆，未核对 2026/2027 官方；应查各刊 website。
- "平均被拒 1.5 次"为泛化经验值，无 QueYi 专属数据。
- 若触发方向 54 的制裁风险，转投国内/中立会场（如 软工顶会 国内主办、或 APSEC）需另评估。
