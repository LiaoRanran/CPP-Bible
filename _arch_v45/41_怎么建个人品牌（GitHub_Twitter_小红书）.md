# 方向 41：怎么建个人品牌（GitHub / Twitter / 小红书）

## 核心结论
1. 单人研究者的"个人品牌"= **一个能被搜到的主页（GitHub profile README）+ 一个持续产出渠道（博客/arXiv）+ 一个社交分发（X/小红书）**。对双非作者，这是"用作品证明能力"替代"学历标签"的关键。
2. 三平台分工：**GitHub = 作品与可信度（pinned QueYi）**；**X = 国际研究者触达**；**小红书/知乎 = 国内人脉与求职曝光**。不要三处都水，选 1 主 2 辅。
3. 品牌一致性：统一 handle（如 `LiaoRanran`）+ 统一一句话定位（"Building QueYi: auditable C++ verification"），所有平台一致，让搜你名字第一屏就是 QueYi。

## 精确数字与案例
- **GitHub profile README**：包含一句话定位 + pinned 3 repo（QueYi 置顶）+ 联系方式 + 博客/arXiv 链接；这是最被低估的"简历"。
- **发布节奏**：GitHub 每周有 commit（CI badge 绿色示活）；X/小红书每周 1–2 条要点（数字/图）。
- **案例**：许多独立研究者靠 GitHub + X 被大组注意到并获邀合作/录取（如 Karpathy 生态的独立开发者）；起点都是"一个能跑的好 repo"。
- **度量**：不看粉丝数，看"repo star 数 / arXiv 下载 / 被引"三个硬指标（方向 10）。
- **反模式**：买粉、蹭热点、标题党——一次翻车伤信誉（方向 58）。

## 对阙疑的 3 条具体行动
1. **写 GitHub profile README**：一句话 + QueYi 置顶 + badge（CI/arXiv/license），今天就能做。
2. **统一 handle + 定位语**：GitHub/X/小红书/知乎全用同一名 + "auditable C++ verification"，确保搜索一致。
3. **每周 1 条 build log**：在 X + 小红书同步发 QueYi 进展（配数字/截图），既练表达又建存在感（方向 33/39）。

## 盲区（诚实标注）
- X 在国内访问受限，小红书受众偏求职学习——效果需实测，勿全押一个平台。
- 品牌对**录取/求职**的实际增益难量化，主要是"被搜到时不至于空白"。
- 考研冻结期（方向 44）品牌维护应降到最低（月 1 条）。
