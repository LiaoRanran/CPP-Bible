# 方向 34：时间管理精确到小时

## 核心结论
1. 单人作者 + 考研并行的死穴是**没有外部 deadline 逼你**，时间会漏给"刷手机/纠结方向"。必须用"周计划 + 日小时块 + 公开进度"三件套把时间外化。
2. 基于方向 44 的真实时间线：**大三（2026-09~2027-07）＝科研期**，用"科研小时表"；**考研冲刺（2027-09~2027-12）才冻结 QueYi**，用"备考小时表"。二者分年，不混。（作者 2026-09 上大三，初试约 2027-12。）
3. 番茄钟 + 周复盘是底线：每天 3 个深工块（每块 2–3h），其余处理琐事；单人项目最忌"全天碎片化"。

## 精确数字与案例

**备考小时表（仅 2027-09~2027-12 考研冲刺期使用；大三不适用）**
| 时段 | 内容 |
|---|---|
| 07:30–08:00 | 晨间复习（背单词/政治） |
| 08:00–11:30 | 数学（深工块 1） |
| 11:30–14:00 | 午休 + 英语阅读 |
| 14:00–17:30 | 408 专业课（深工块 2） |
| 17:30–19:30 | 运动 + 晚饭 + 政治 |
| 19:30–22:30 | 数学/408 错题（深工块 3） |
| 22:30–23:00 | 日复盘 + 明日计划 |
> QueYi 此期零接触（方向 44 串行方案）。

**冲刺期（考后，科研为主）小时表**
| 时段 | 内容 |
|---|---|
| 09:00–12:00 | 实验/写代码（深工块 1） |
| 14:00–17:00 | 论文写作（深工块 2） |
| 19:30–21:30 | 读论文/冷邮件（深工块 3） |
| 周末 | 半天 GitHub 维护 + 半天休息 |

- **工具**：Todoist/Notion 周计划 + GitHub Projects（方向 13）+ 番茄钟 App；周日晚做下周 7 天块。
- **案例**：考研党常见失败 = 每天"学了一点但没块"；用 3 深工块后效率翻倍。QueYi 冻结期若手痒，设"每月 1 天解冻检查"而非每天看。
- **防 burnout**：每周留半天完全离线；单人项目无同事替你，健康是单点故障。

## 对阙疑的 3 条具体行动
1. **立刻写周计划**：今晚列未来 4 周考研块（备考期）或科研块（冲刺期），贴 GitHub Projects 公开。
2. **冻结期设"每月 1 天"**：2027-09~2028-03 每月选 1 天（如每月 1 号）花 2h 看 QueYi issue/CI 状态，其余零接触。
3. **日复盘 15 分钟**：每晚记"今天完成 3 块？没完成哪块？明天调"，避免假性努力。

## 盲区（诚实标注）
- 小时表是模板，需按你精力曲线调整（夜猫子可推迟）；关键是"块"不是"钟点"。
- 若你决定不考研（方向 44 另一选项），则全程科研块，表不同。
- "冻结期零接触"对 momentum 有损（方向 44 已讨论），靠考后 12 周冲刺补。
