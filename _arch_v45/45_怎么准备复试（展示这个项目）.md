# 方向 45：怎么准备复试（展示 QueYi）

## 核心结论
1. 复试对双非是**翻盘场**：初试看分数（你的短板可能是本科背景），复试看"你到底会不会做事"——QueYi 让你从"双非考生"变成"已做出可运行系统的研究者"，这是差异化的核武器。
2. 复试三块：**专业课面试（考基础）、英语面试（考表达）、综合面试（考项目与潜力）**。QueYi 主要在综合面试发力，但也可在英语面试用英文讲 1 分钟项目（方向 37 练过）。
3. 关键心态：**主动、具体、诚实**。别吹"我做了 AI 大项目"，而是"我做了 QueYi：813 行 C++ 内核，盲 holdout 检出 80%，可复现"，并主动说局限（小样本 CI 宽）。

## 精确数字与案例

**3 分钟项目陈述脚本（综合面试）**
- 0:00–0:30 问题：LLM 生成 C++ 有 UB/知识错，人难查；
- 0:30–1:30 方案：QueYi 四态判决 + append-only 哈希链 + Merkle checkpoint（1 张图）；
- 1:30–2:30 结果：盲 holdout 20 样本（7 真错）检出 **80%**；重注入 15 夹具 **100%**；变异 core **97.3%**；单卡 **0.59ms**；
- 2:30–3:00 局限 + 规划：样本小（CI 28.4–99.5%）、外部 corpus 33.3%，计划扩 corpus 投 NeurIPS E&D。

**高频追问与答法**
- "你一个人做的？"→ "是，代码/CI/论文独立完成（GitHub 可查 commit 历史），我还能现场讲每个模块。"
- "33.3% 外部检出太低？"→ "对，我们诚实报告并分析了原因（分布偏移），下一步扩外部样本——这正是研究空间。"
- "为什么不用 Coq/Rust？"→ "类型系统/形式化管内存安全，QueYi 管知识语义正确性，互补（方向 24）。"
- "有什么创新？"→ "首个把验证做成**可审计基准**（哈希链 + 三编译器）的 C++ 知识系统。"

**材料准备**：1 页项目简介（PDF）+ GitHub 链接 + 电脑里预装好的可跑 demo（离线兜底）。

## 对阙疑的 3 条具体行动
1. **背熟 3 分钟脚本 + 10 个 QA**：照上面，录一版自我演练（方向 40），确保超时不过 3:30。
2. **准备"可跑 demo"兜底**：Docker 镜像 + 录屏双保险，评委电脑没编译器也能展示。
3. **把局限变加分**：主动说"样本小、外部 33.3%"，对齐 E&D 指南"坦诚被奖励"，导师会觉得你懂科研。

## 盲区（诚实标注）
- 各校复试形式（是否笔试/机试/英语听力）差异大，需按目标校 2027 复试办法准备（未确认）。
- "双非 + QueYi"能否翻盘取决于导师/评委，无保证；但差异化明显提升概率。
- 数字需与 repo 一致，现场被追问细节不能对不上（否则信誉崩）。
