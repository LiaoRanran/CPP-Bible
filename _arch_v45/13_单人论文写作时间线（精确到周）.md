# 方向 13：单人论文写作时间线（精确到周）

## 核心结论
1. 单人写顶会稿的隐形杀手是**没有 deadline 纪律**：没有 coauthor 催你，容易无限拖延。必须用"假 deadline + 周计划"外部化压力。
2. 对 QueYi（目标 NeurIPS 2027，投稿约 2027-05），倒排：2026-10 起 30 周写作期，前 10 周堆实验、中 10 周写、后 10 周改 + arXiv。比"最后 3 周狂写"质量高 3 倍。
3. 单人写作要**先写 methods + experiments（你最熟的），最后写 intro/abstract（需全局视角）**；反过来会卡死。

## 精确数字与案例
- **30 周倒排（以 2027-05 投稿为 T）**：
  - W-30~-21（10 周）：补实验。QueYi 优先补"外部 corpus 检出率（从 33.3% 提升）""更多编译器差异 case（17 方向）""变异算子扩展（20 方向）"。
  - W-20~-11（10 周）：写 methods + experiments + related work 草稿（不与 intro 纠缠）。
  - W-10~-6（5 周）：写 intro/abstract/contribution，做图表。
  - W-5~-3（3 周）：全文润色 + 找 2 个朋友/导师外部审（方向 31）。
  - W-2~-1（2 周）：arXiv v0.4 锁版 + OpenReview 提交 + checklist 核对（方向 03）。
  - W0：投稿。
- **案例**：许多单人作者用"每周一向自己发进度邮件"或 GitHub Projects 看板强制节奏；QueYi 可在 GitHub 建 `paper-2027` 看板，每卡一章节。
- **rebuttal 预留**：投稿后 ~3 个月出分（2027-09），留 2 周 rebuttal（方向 04）；不要以为投完就结束。

## 对阙疑的 3 条具体行动
1. **建 GitHub 看板**：`paper-2027` 项目，列 13 个章节卡 + 截止周；每周日勾掉，没勾的周一补——用公开进度逼自己。
2. **锚定假 deadline**：把 NeurIPS 2027 真实截稿前移 2 周当"个人 DDL"，buffer 应对突发（考研并行时尤其重要，见方向 44）。
3. **实验优先于写作**：W-30~-21 只做实验不动笔；等"核心数字齐全"再写，避免边写边改导致结构崩。

## 盲区（诚实标注）
- 上述周数基于 NeurIPS 2027 约 2027-05 截稿的假设，实际日期需等 2027 CFP（通常前一年底发布）。
- "30 周"假设你同时备考（方向 44）会冲突；若并行考研，需压缩为"实验在考研前冻结、考后 12 周冲刺"（见方向 44 串行方案）。
- 单人无 coauthor 互审，外部审需主动求人（方向 31–33），易拖延。
