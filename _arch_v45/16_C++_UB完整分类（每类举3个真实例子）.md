# 方向 16：C++ UB 完整分类（每类举 3 个真实例子）

## 核心结论
1. 未定义行为（UB）是 QueYi 验证的**核心敌对方**：LLM 生成的 C++ 常踩 UB 而编译器/人类都难察觉。系统掌握 UB 分类是构建"知识验证卡片"的前提。
2. C++ UB 可归为 ~15 大类；每类都要能举出"看起来合理但 UB"的真实例子——这正是 QueYi 48 卡应覆盖的内容骨架（当前 48 卡需映射到这些类）。
3. 对审稿人，QueYi 的价值在于"把 UB 知识点变成可自动判定的四态卡片"；所以方向 16 的清单应直接成为 corpus 的 taxonomy（taxonomy 越全，benchmark 越硬）。

## 精确数字与案例（15 类 × 3 例）

**① 数据竞争（data race）**
- 两线程无锁同时写同一 `int x;` → UB。
- `std::shared_ptr` 跨线程拷贝非原子操作 → UB。
- `std::cout <<` 多线程并发无同步 → UB（输出交错属未指定，但数据竞争本身 UB）。

**② 空/野指针解引用**
- `int* p=nullptr; *p=5;` → UB。
- `delete p; *p=1;`（use-after-free）→ UB。
- 返回局部变量地址 `int* f(){int x; return &x;}` → UB。

**③ 有符号整数溢出**
- `int x=INT_MAX; x+1;` → UB（无符号是 well-defined 回绕）。
- `int a=-1, b=1; a/b` 在极少数实现 UB（仅当结果不可表示）。
- `int m=INT_MIN; -m;` → UB（补码取负溢出）。

**④ 未初始化读取**
- `int x; if(x>0)` → UB（ indeterminate value）。
- 栈数组未初始化当字符串 → UB。
- `std::string s; s[0]` 未初始化读 → UB。

**⑤ 数组越界 / 缓冲区溢出**
- `int a[3]; a[5]=1;` → UB。
- `std::vector<int> v(1); v[10]=0;` → UB（未定义，非异常）。
- `char buf[4]; strcpy(buf,"abcdef");` → UB。

**⑥ 迭代器失效**
- `for(auto it=v.begin(); it!=v.end();) v.erase(it++)` 错误写法 → UB。
- 范围 for 中 `v.push_back` 使迭代器失效 → UB。
- `erase` 后未更新迭代器继续使用 → UB。

**⑦ 未排序多重修改（unsequenced）**
- `i=i++;` → UB。
- `f(i++, i++)` 参数求值顺序未定 → 若改同对象 UB。
- `a[++i]=i;` → UB（读写同一标量无顺序）。

**⑧ 严格别名（strict aliasing）**
- `int x=5; float f=*(float*)&x;` → UB（类型双关走错路）。
- 用 `char*` 读 `int` 合法，但用 `float*` 读 `int` 不合法。
- 通过 union 类型双关在 C++ 是 UB（C 允许）→ 经典坑。

**⑨ 生命周期结束后使用**
- `std::string& r=std::string("x"); r.size();` → UB。
- 临时对象绑定到局部引用延长生命周期，但返回后 → UB。
- `std::string_view` 指向已销毁 string → UB。

**⑩ 移位越界**
- `1<<32` 对 32 位 int → UB。
- `x>>-1`（负移位量）→ UB。
- `int x; x<<=33;` → UB。

**⑪ 无效动态转换 / 虚调用**
- `dynamic_cast` 到无关类型返回 null 后解引用 → UB。
- 构造/析构期间调用纯虚函数 → UB。
- 通过已 delete 对象调用虚函数 → UB。

**⑫ 宏与求值顺序**
- `#define SQUARE(x) x*x` 中 `SQUARE(i++)` → UB（i++ 两次）。
- 宏参数带副作用重复求值 → UB/未指定。
- `a = f() + g()` 中 f/g 谁先未定（非 UB，但易错）。

**⑬ 函数参数求值顺序**
- C++17 前 `f(i, i++)` 未指定；C++17 后规定左到右但仍需避免。
- `std::cout << i << i++` → 未指定顺序。
- 同一标量在实参中多次修改 → UB。

**⑭ 浮点异常 / 窄化**
- `double d=1e300; float f=d;` 溢出 → UB（可选陷阱）。
- 列表初始化窄化 `{int x=3.5;}` → 编译错误（非 UB 但常混淆）。
- `reinterpret_cast` 浮点→整型陷阱表示 → 实现定义。

**⑮ 宽字符 / locale / 其他**
- 在 `char` 为负平台上把 `char` 当数组下标 → 可能越界 UB。
- `setlocale` 后字符串比较行为改变 → 未指定。
- `std::signal` 处理函数内调用非 async-signal-safe 函数 → UB。

## 对阙疑的 3 条具体行动
1. **UB taxonomy 入 corpus**：把上述 15 类做成 QueYi 的"UB 知识树"，48 卡每卡标注属于哪类（如"卡#12：宏双关 UB"），让 benchmark 覆盖度可量化。
2. **每类造 3 夹具**：按上面例子写 45 个最小可编译/不可编译夹具，作为"金标准"验证 QueYi 四态判决是否正确（真错 vs 误报）。
3. **对齐编译器差异（方向 17）**：标注哪些 UB 在 GCC/Clang/MSVC 表现不同（如严格别名优化开关 `-fno-strict-aliasing`），这是 QueYi 的差异化卖点。

## 盲区（诚实标注）
- "15 类"是我的归纳，非 C++ 标准官方计数；标准以"undefined behavior"条款列出的条目更多（数百条），但按主题可归为这些类。
- 部分例子在不同标准版本（C++11/17/20）行为不同（如参数求值顺序 C++17 改了），已尽量标注。
- 例子未经编译器逐一实测，以你仓库 813 行内核的实测为准（方向 19 工具可验证）。
