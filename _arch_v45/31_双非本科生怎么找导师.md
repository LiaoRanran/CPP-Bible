# 方向 31：双非本科生怎么找导师

## 核心结论
1. 双非找导师的**唯一杠杆是"已有可验证的成果"**——你正好有 QueYi（813 行内核 + 可复现 benchmark + 在投 NeurIPS），这比 99% 双非生的"成绩单"强得多；把它当敲门砖，而不是递简历。
2. 路径优先级：**(a) 通过 GitHub/论文直接联系做程序验证/SE 的导师 > (b) 本科院校老师推荐 > (c) 会议/workshop 面聊 > (d) 盲投招生办**。冷邮件必须附带 QueYi 链接 + 一句你读过他哪篇论文。
3. 目标匹配比排名重要：与其冲清北名校的"大模型"组（竞争激烈、你不对口），不如找**做程序分析/软件测试/形式化验证**的组（SE 顶校如 中科大/南大/上交 SE 方向，或海外做 verification 的组），你的 C++ 验证系统正对口。

## 精确数字与案例
- **导师匹配库**：用 Semantic Scholar / Google Scholar 搜 "C++ verification benchmark"、"program analysis LLM"、"software testing mutation"，列出 20 位做相关方向的导师（国内外）。
- **国内对口**：中科大（软件学院/查宏侠等程序分析）、南大（软件所）、北大（程序语言）、清华（系统/验证）；以及合肥本地（中科大就在合肥！地理优势，方向 43 长鑫同城）。
- **案例**：有 QueYi 这种"能跑的系统 + 在投顶会"的双非生，导师回复率远高于空简历——因为导师要的是"能立刻干活的人"，不是"分数高的人"。
- **避坑**：不要群发同模板邮件（一眼假）；不要找明显不做你方向的导师（浪费彼此时间）。

## 对阙疑的 3 条具体行动
1. **建导师短名单（20 人）**：用 Scholar 搜 "mutation testing / C++ verification / LLM code" 方向，分"冲刺/匹配/保底"三档，合肥中科大优先（同城可面聊）。
2. **准备一页"项目简介"**：把 QueYi 压成 1 页 PDF（问题/方法/数字/链接），邮件附上，降低导师了解成本。
3. **用论文当破冰**：每封邮件引用该导师 1 篇相关论文 + 一句"我的 QueYi 与该文的 X 相关"，证明你真读过、真匹配。

## 盲区（诚实标注）
- 具体导师姓名/方向我未逐一核实，需你用 Scholar 实时搜（列出的是方向示例，非推荐名单）。
- "双非 + 在投顶会"是否足以敲开名校组未知，取决于导师当年名额；应多投广撒网。
- 若目标海外，需语言成绩/推荐信，时间线更长（见方向 44 考研并行）。
