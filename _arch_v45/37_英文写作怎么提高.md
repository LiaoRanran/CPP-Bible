# 方向 37：英文写作怎么提高

## 核心结论
1. 双非单人写英文顶会稿的最大障碍不是词汇，而是**中式语序 + 过度修饰**；解法是"模仿顶会句式"而非"背单词"。QueYi 稿应逐句对照 3 篇同领域录取论文的写法。
2. 高效路径：**精读→仿写→工具校对→母语者/LLM 润色（但披露）**。其中"仿写"最被低估：把好论文的句子结构套到你的内容上，立即从"能懂"升到"专业"。
3. 对审稿人，语言差会直接拉低 Clarity 分（方向 03）；但**过度用 LLM 润色若不披露，2026 后风险陡增**（方向 08 v42 AI 披露）。平衡：用工具改语法，但核心表述自己写 + 披露使用。

## 精确数字与案例
- **中式英语典型**：`We very much hope...` / `In order to...`（删）/ 长定语从句堆叠 / 被动滥用。改写为主动短句。
- **顶会句式模板**：
  - 缺口：`However, existing approaches fail to ... because ...`
  - 贡献：`We introduce QueYi, which ... and achieves ...`
  - 结果：`On 20 blind holdout samples, QueYi detects 80% of errors.`
- **工具**：Grammarly（语法）、Writefull（学术措辞，基于语料）、LaTeX 拼写检查；**Overleaf** 协作润色。
- **案例**：许多非母语作者靠"逐段仿写 + 导师改"达到可发表；纯 LLM 翻译的稿在 2025–2026 被 Pangram 类检测标红（方向 02）。
- **量化**：每天写 200 词英文（哪怕记笔记），3 个月可显著改善；读 20 篇同领域论文的 intro 可建立句式库。

## 对阙疑的 3 条具体行动
1. **建句式库 + 仿写**：从 3 篇同领域录取论文摘 30 个句式，存 `_arch_v45/cache/sentence_bank.md`；写 QueYi 每段先套句式再填内容。
2. **工具链 + 披露**：Grammarly/Writefull 改语法，核心 claim 自己写；投稿时按会议政策披露 AI 辅助（方向 08 v42）。
3. **每日 200 词**：用英文写 QueYi build log（方向 33），既练写作又产出内容，一举两得。

## 盲区（诚实标注）
- "Pangram 检测标红"针对 AI 生成**全文**，语法润色通常不触发；但政策趋严，披露最安全。
- 母语者润色需花钱/找人（方向 31/32），单人可能缺资源。
- 我未评估你当前英文水平，建议先写一段给外部读者测 Clarity。
