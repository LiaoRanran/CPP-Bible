## 1. 一句话结论

**"谁来验证验证者"没有一个单点答案，只有一个结构：信任向上递归到"最小 TCB + 透明账本 + 显式声明的终止层"就必须停下——这不是妥协而是数学与工程史的共识（Tarski/Thompson/de Bruijn/Milawa 全部指向同构解）；而 2025–2026 文献已开始审计裁判与基准（REFINE/BabelJudge/BenchMarker/CodeJudgeBench），却没有任何工作把"验证系统本身"当被攻击对象、用真实改判账本做回归、带 fail-closed 语义——这个三元组合的空白就是 v34 判断的 12–24 月窗口，且窗口在文献侧被本次调研精确确认。阙疑手里已有全部零件（challenger/poison_drill/独立重实现/33 条目闭包/Merkle 账本/813 行内核），v35 的全部结论是：把它们从散件组装成协议。**

| # | 洞察 | 出处 | 改变什么决策 |
|---|---|---|---|

| 3 | **"信某物"必须换成"篡改必留痕"**：社会终止（CT/Rekor/Trusted Publishing 模型）是单人项目唯一负担得起的信任放大器；硬件信任根把递归转移给厂商（TrustZone 沦陷已被 NDSS'25 实锤），不适配阙疑成本结构 | [06]§2.2/2.3 | 651 Merkle 账本的战略地位再确认；不引入硬件依赖 |
| 4 | **阙疑的信任递归已终止在正确的层，但最底层是"作者本人"且未声明**：技术选型全对（最小内核+透明账本），风险不在单点而在单点未声明——论文/开源若称"不信任任何单点"即虚假陈述 | [06]§3 | 必须发《信任终止声明》（07-M5），消除单点的触发条件=外部 maintainer [v34-P16] |
| 5 | ** Thompson 威胁的现代答案是"独立重实现"——阙疑已经在做但没命名**：independent_verifier_628+纯标准库 RSA 正是 DDC 微缩版，652 假开关被差分验证抓出即其有效性证明；应升格为协议组件 | [04]§2.2/4 | L3 层正式化（07 决策 A）；论文方法贡献点 (c) |
| 6 | **验证器变异测试是文献空白+内部现成**：变异测试成熟但默认靶机是代码；把变异算子施加在验证器逻辑上（阈值/谓词/fail-closed 分支）并度量"元监控检出率"无人做过，而 652 的人工差分已经示范了一次 | [05]§3.1 | M2 验证器变异集（≤20 算子+账本自动回归）成为元验证度量方法的核心 |
| 7 | **abstain 路径从未被对抗测试**：poison_drill 测"毒卡必须 fail"，ImpossibleBench 测"测试-规范矛盾必须被发现"——但"矛盾卡必须 abstain"在内部与文献中都是空白；LLM 永不给 pass 使 abstain 成阙疑安全的关键路径 | [05]§3.2 | M3 不可能卡（≥10 张，被骗放行率=0 验收） |
| 8 | **裁判可靠性文献反向印证"权力最小化"正确**：26 裁判模型顺序敏感、斯瓦希里语顺序一致性 0.480≈抛硬币——与其审计裁判不如让裁判权力小到不值得攻击；但 B1 改判通道是残余暴露面 | [01]§L1/L4 [03]§2.2/2.4 | B1 改判附可重放证据哈希；pairwise 类内部工具强制双序一致 |

### 3.1 排序

```

  M3 不可能卡（abstain 对抗测试）           [05]       被骗放行率从无到有
  M6 challenger 扩九种轨迹扰动+双序一致     [01][03]   吸收 2026 文献
  M8 元验证攻击集定稿 → arXiv 占位          [07]       v34-P3 时间锚不变（2026Q4）

第三梯队（12–24 月，触发/并轨）
  M7 VSA 去同源（独立性 L2→L3）             [06]       M5 之后
  M9 形式规格 v1（账本三性质+合成表四性质） [04]       与 v34-P2 并轨
  P16 联动：外部 maintainer/独立安全评估     [v34]      消除单点的唯一真解
```

### 3.2 依赖图（不可反向）

- **M1 → M2/M3/M6/M8**：假开关不修，一切攻击集结果被污染（652 gaps 已证实该污染真实发生过一次）。
- **M5 → M7/M8**：先声明信任终止层，再去同源、再写论文威胁模型——顺序不能倒。
- **M2+M3+M5 = "最小元验证协议"**：第一篇论文实验章的地板；三者齐 → M8。
- **M9 与 v34-P2 并轨**，不新增独立排期。
- **M4 无硬依赖**，可随时插入。

### 3.3 七方向在图中的位置

方向 1（攻击面）提供靶标清单 → 方向 2（数学）证明结构合法性 → 方向 3（元审计）划清 novelty 边界 → 方向 4（形式化）给 L1/L3 的方法 → 方向 5（红队）给 L2 的方法与度量 → 方向 6（信任根）给 L4/L5 的终止结构 → 方向 7（设计）组装成 07 篇的五层塔。
