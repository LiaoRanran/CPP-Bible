怎么用

卡库

按状态 / 四态 / 域 / 类型筛选，按证据强度排序，搜全部知识卡； 每张可展开看断言、边界与证据，点「详情」看四态判决理由；机器卡单独标注、不进教学台账。

学习台

把 42 张知识卡与机器卡反例变成可复习的牌组：间隔重复（SM-2）+ 主动回忆 + 错例驱动。 进度存本机，可导出/导入。

现场验哈希

用浏览器 Web Crypto 对工件重算 sha256，与台账逐字节比对：可一次拖入多个文件批量验证， 结果可导出 CSV。离线可用，文件不出本机。

实验结果

检出率（holdout / external / counterfactual）、变异杀死率、结果分布与系统演化 —— 现算自真实台账，分母与口径一并给出。

星图

178 节点 / 1093 边的知识接地网络（真实数据渲染），可缩放、可点选看详情。

复现清单
