# 伦理声明（Ethics Statement）

**论文：** Queyi: 零成本静态感知的 C++ 缺陷检测资产选择
**日期：** 2026-10-09

## 1. 研究对象与受试者

- 本研究**不涉及人类受试者**，未收集任何个人身份信息（PII），未进行用户研究、调查或行为实验。
- 研究客体为**程序缺陷检测技术**（静态/动态分析资产选择），属于软件工程方法论研究，无需机构审查委员会（IRB / 伦理委员会）审批。

## 2. 数据来源与隐私

- **构造性缺陷夹具**：由本仓库脚本自动生成，不含真实系统的专有代码。
- **真实 CVE 重构集（110 例）**：全部源自**公开漏洞数据库**（NVD、GitHub Advisory），按最小复现夹具重构，保留原始 CVE 编号与上游链接；已做去标识化处理，**不含任何非公开或个人信息**。
- 无爬虫抓取受保护内容；重构过程遵循各上游项目的开源许可。

## 3. 人工智能使用的披露

- 本研究的**缺陷标注**由"AI 第二遍标注器"（source-evidence annotator）完成，**非人类专家标注**。这一事实已在论文正文与方法论章节如实披露。
- 因此，**人类间标注一致性（human IAA）在全仓库为 0**；论文报告的一致性指标（如 Cohen's κ）明确标注其标注者为 AI，未将其误导为人类专家一致性。
- 除标注外，论文撰写、实验设计、统计分析均由作者完成；生成式 AI 未替代任何需署名的学术贡献。

## 4. 双重用途与潜在危害

- 本研究产出为**防御性**软件缺陷检测方法论（帮助开发者在零运行时成本下发现 C++ 缺陷）。属于典型良性安全研究。
- 所提方法不提供任何攻击能力、漏洞利用或规避技术；不针对任何特定厂商或产品。
- 真实 CVE 仅用于方法验证，且已重构为最小无害复现夹具，不构成可利用的漏洞信息。

## 5. 公平性与偏差

- 实验设计已做环境感知校正（见论文 §环境感知），区分"确定性 miss"与"环境相关 silent degradation"，避免对环境敏感缺陷的不公平归因。
- 跨工具比较（clang-tidy / cppcheck vs Queyi）已声明**非容器化同环境**的局限，结论仅作能力分歧参考，不夸大。

## 6. 结论

本研究在伦理上属于低风险、防御性、无人类受试者的软件工程研究，数据来源合法公开，AI 使用已充分披露，无利益冲突或潜在危害需特别警示。
