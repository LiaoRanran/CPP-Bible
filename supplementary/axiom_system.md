# 测量漂移代数：公理系统说明（707-A 工程落地）

> 科研依据：700-A 元理论发现（权威源 `data/700_axiom_independence.json`，生成者
> `tools/compute_700_axiom_independence.py`）。本文件把「哪些公理是实质性的、哪些是恒真的、为什么」
> 写成可直接引用的说明；工程侧同步见 `tools/test_axiom_independence.py` 与
> `tools/compute_700_axiom_independence.py --substantive-only`。

## 1. 框架

- 漂移算子 **τ_G = 资产列删去**（保留 `A\G`）。
- 报告函数 **R_ρ(S)** 由**聚合族 ρ** 给定（OR 并集 / at-least-2 / max / min / mean / sum / exactly-one）。
- 损害 `h(G) := R(A) − R(A\G)`。
- 穷举模型域：`|X| = 4` 样本 × `|A| = 3` 资产 ⇒ `2^{12} = **4096**` 个覆盖结构 × **7** 个聚合族。

## 2. 七条公理的分类（700-A 结论）

| 编号 | 内容 | 分类 | 理由 |
|:--:|---|---|---|
| **A1** | 口径可枚举性 | **元公理** | 约束语言/分类法，不是结构性质 ⇒ 不参与结构检查 |
| **A2** | 撤除单调性 `G⊆H ⟹ R(A\H) ≤ R(A\G) ≤ R(A)` | **真公理（实质性）** | 存在反例聚合（`min_single` / `mean_single` / `exactly_one_nonmonotone`） |
| A3 | 幂等性 `τ_G∘τ_G = τ_G` | **定理（恒真）** | 由 τ = 列删去直接推出 |
| A4 | 交换闭包 `τ_G∘τ_H = τ_{G∪H}` | **定理（恒真）** | 同上 |
| **A5** | 超可加性 `G∩H=∅ ⟹ h(G∪H) ≥ h(G)+h(H)` | **真公理（实质性）** | 存在反例聚合（`at_least_2` / `min_single` / `mean_single` / `exactly_one_nonmonotone`） |
| A6 | 不可逆性（`M↦M\|_{A\G}` 非单射） | **定理（恒真）** | 列删去在全结构域上非单射 |
| A7 | 可观测性分层（静默性是 (τ, 记账口径) 二元组的性质） | **定理** | 把 unaware/aware 记账写进结构后可证（698-B 定理 T3） |
| **(A8)** | 标签轴闭包 | **缺失（TODO）** | 见 §4 |

**结论**：把 A3/A4/A6/A7 写成公理是**冗余**；真正起约束作用的结构公理只有 **A2（单调）与 A5（超可加）**，外加元公理 A1。

> 由 A5 可得：多口径变化同时发生时**不能线性相加**（报告必须逐口径分别声明）。

## 3. 工程落地（707-A）

1. **检查简化**：`compute_700_axiom_independence.py --substantive-only` 只跑 A2/A5，跳过恒真的 A3/A4/A6（省算力），并附 A8 占位。
2. **回归护栏**：`tools/test_axiom_independence.py` 用 4096 结构独立重算，断言「只有 A2/A5 有反例、A3/A4/A6/A7 恒真、A8 缺失」；未来若有人改动聚合族/检查逻辑致分类漂移，测试变红。
3. **输出**：`data/707_axiom_independence_test.json`（测试）与 `data/707_axiom_substantive_check.json`（简化检查）。

## 4. 不完备性与 A8（标签轴闭包）

存在漂移 **τ_λ（标签词表变化）** 使**逐样本裁决与全部七条公理关心的量都不变**，但**分组统计改变** ⇒ 现有七公理系统**无法表达 Type III（标签）漂移**。

- **A8 候选形式化**：口径签名由 `(A, E, Θ, P)` 扩为 `(D, A, E, Θ, P, λ)`，且任何报告统计量都必须显式声明其**分组轴 λ**；未声明 λ 的统计量**不可比较**。
- **为何不能自动验证（TODO）**：λ 属**报告规范层**，非覆盖结构性质 ⇒ 本穷举域（覆盖 + 聚合）无结构反例可检，只能以规范约束落地。故 A8 以占位 + 文档形式登记，**不伪造自动检查**。

## 5. 诚实边界（700-A）

- 「恒真」结论只对 **|X|=4、|A|=3、7 种聚合** 的有限域成立，**不是对任意域的证明**。
- 「有反例」是充分证据；「恒真」是**域内**证据。
- A7 的检验只覆盖 `|G|=1` 的情形。
- 复杂性结论（口径套利 NP-hard、结构性不可判定）为**归约论证**，未做形式化归约证明。
