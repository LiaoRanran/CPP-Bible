## 1. 一句话结论

1. **大架构**：2024–2026 三条独立技术线（RLVR、LLM 事实核查、LLM 形式化证明）与阙疑土法收敛到同一范式——可执行 oracle 为底座、LLM 仅在缝隙里当候选器、弃权用分布无关数学保证、验证器持续被攻击。阙疑不缺架构，缺的是把已有机制（cs_upper_bound、盲审、负测试）升级到文献中的数学口径；最大闲置资产是 **PCK 负测试数据集**。
2. **前端**：浏览器里能跑 C++（WASM Clang 已成熟）但**永远产不出 x86 汇编/sanitizer/多编译器证据**，站点必须分"试一下"与"证据"两档；**MkDocs Material 已于 2025-11 进入维护模式（安全支持到 2026-11）**，书站暂不迁、交互层另起 Astro/Starlight 纯静态新站；零后端、零账号、本地复算优先。
3. **视频**：Manim CE（0.20.1）为主力，与团队 Python 栈同构；2026 年最强生成式视频屏内文字可读率仅约 5%，技术内容禁用；开源中文 TTS（IndexTTS2，Apache-2.0）已过可用线；成败关键是"**证据驱动动画**"——画面数字只能从锁哈希工件解析，视频发布过事实闸门。

## 3. 三方向统一的判决层级原则（全系统宪法候选）

三个方向独立推出同一个结构，应合并成一条贯穿规则：

```
L0  可执行 oracle     编译器/运行/sanitizer/哈希/规则（确定、可复算）     ← 唯一可出 pass
L1  域内小模型裁判     原子断言级（MiniCheck 式，未来由 PCK 数据训练）     ← 仅原子散文
L2  前沿 LLM          起草规则/脚本/分幕、给意见与候选                    ← 永不放行
L3  人审权威          盲审、二审、最终授权                                ← 数学必需
                    （任何一层置信不足 → abstain/挂起，带保形上界）
```

- 对**卡片**：L0 编译运行 + 67 规则；L2 只起草。
- 对**前端交互**：浏览器/沙箱结果一律 L0'（非证据展示），只有锁版本工件 + 现场哈希可入证。
- 对**视频**：L2 写旁白初稿；video_fact_gate（L0 同构物）放行；人定稿。

## 4. 统一路线图（串行、单人可承载、按依赖排序）

### Phase V0 · 开源地基（1–2 月，无新学问，纯还债 + 高性价比动作）

1. queyi-core 开公开远端、定版本/CHANGELOG、PyPI/uv 可安装（`uvx quyi verify`）；了结 647 登记的"两份并列"债。
2. PCK provenance 扩四字段（模型 id/版本、prompt 哈希、rubric 版本）；判决层级 L0–L3 写入治理文档。
3. **PCK M1–M7 负测试导出标准 jsonl**（数据资产动作，先于一切训练）。
4. 前端零后端首屏：证书查看器（Web Crypto 现场重算 sha256）+ 证书角标挂书站 + Cytoscape 知识图谱单页。
5. MkBooks 书站维持现状的正式决定记录在案（2026-11 前安全窗口）。

### Phase V1 · 裁判机制数学化（2–3 月，接 636/647 保护器）

6. B6 保护器候选：Sage 双轴自审（swap 稳定性 + 三卡传递环），按模型版本出漂移报告，零人工标注。
7. FP/FN 双率口径替换单一 error_rate；FN 用轻量复查估计（B4 区分度问题的一半解）。
8. 来源/品牌/年份线索脱敏并入盲审协议（防新近性/来源偏差）。
9. pass 判决 split-conformal 上界试点；"取证后强制重校准"机器化（不重算不许 pass）。
10. 毒化演练加入 ImpossibleBench 式"不可能卡"，指标=被骗放行率。

### Phase V2 · 开源给人用（与 V1 可并行，偏产品）

11. Astro/Starlight 起 `quyi-lab` 纯静态应用站；浏览器 wasm playground（先单线程章节：语言/STL/模板），全页"非验证证据"标记。
12. giscus 反馈、Pagefind 搜索、FSRS 复习模式（本地进度，导入导出 JSON，无账号）；anki.csv 继续作为通用导出。
13. 规则验证器 Pyodide 化（纯 stdlib 优势），证书页可在浏览器现场跑 67 规则。

### Phase V3 · 视频管线 pilot（1 集，验收物是第二集成本曲线）

14. ch77（或 ch107）4–6 分钟 pilot：scene_spec 模板、numbers.lock、2–3 个复用 mobject、manim-voiceover + IndexTTS2、video_fact_gate 原型。
15. pilot 过闸门后月更 1–2 集，一卡一视频，无证书卡不做视频；CI 可选渲染 job。

### Phase V4+ · 条件触发，不提前投入

- 真实外部用户出现 → Judge0 自托管（多编译器/汇编/sanitizer 复现按钮）；滥用规模化 → Firecracker microVM。
- jsonl 数据量与标签成熟 → 训 0.5–7B 域内原子核查模型（L1 层实体化）。
- 2026-11 安全窗口或交互需求 → 书站向 Zensical/Starlight 迁移决策。
- queyi-core 若 Rust 重写 → Kani/Verus 进 TCB（重写验收条件，非现工程）。
- 账号/云同步被真实需求证明 → Logto/Keycloak；桌面离线箱 → Tauri 2 + Python sidecar；均缓建。

## 5. 风险与反模式清单（三方向合计）

1. **把 LLM 意见当判决**——2026 年最强模型在难例上也有近 1/4 偏好不自洽 [S30]，随和偏差 TNR<25% [S2]。
2. **多模型辩论幻觉**——辩论第一轮后放大四类偏差 [S14]；"看起来更民主"不等于更可靠。
3. **playground 输出混入证据链**——wasm 无 x86/sanitizer/多编译器 [S37][S52]，一旦混用，全书信任锚点崩。
4. **视频成为第一个允许编造数字的介质**——生成式视频文字 80% 不可读 [S64]；无 fact_gate 不发布。
5. **在 C++ 断言上追形式化证明 / 在单人项目上过早装后端与账号**——工具链与维护成本双不支持。
6. **押注发布停滞的工具链**（Motion Canvas 最后 release 2024-12 [S59]）与**忽视 MkDocs 维护模式**（2026-11 窗口 [S45]）。
7. **RLVR 式自欺**：效率提升被叙述成能力提升——搜索压缩≠能力扩张 [S5]；阙疑的全部可信度来自尾部验证，叙述上不许贪天功。
