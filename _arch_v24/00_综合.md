**跨方向共通概念（≥3 个方向独立出现）**：

1. **误差必须是被建模的信号，而不是被记录的结果**（A 后验更新 / B 击败器 / C ERN / D RPE）。四域独立收敛：学习对象是"预期与实际的差"及其归因，而非"发生了什么"。
2. **一切强度必须归一化/有界/可滑动**（A Cromwell / C BARR 再平衡 / D BCM-Oja / E MMAS）。四域独立收敛：无界累积必然自锁或停滞。
3. **退役/衰减/修剪是一等功能**（B 未证伪到期 / C 重读风险与再平衡 / D 主动遗忘 / E 蒸发-修剪-凋亡）。四域独立收敛：只进不出的系统是历史负债。
4. **元层与对象层必须分离，信任必须塌缩到小内核**（A 哥德尔第二+de Bruijn / B 验证主义"元规则不必满足对象级标准" / C 元认知两层 / E 法定人数非中央）。四域独立收敛：自证不可能，权威来自程序与小可审内核。
5. **确认不对称与证据方向性**（B Hempel 白鞋 / D 缺省负信号 / E 舞蹈自我熄灭）：能失败的测试 > 大量通过；预期落空本身即证据。
6. **异构（退化）而非同源复制**（E 精确化 / 与 v21/v22/v23 的"他验独立"合流）。

## 二、对阙疑的顶层重构建议

如果从第一性原理重新设计阙疑，**核心抽象不应是"验证流水线（gate→replay→人审）"，而应是"误差信号系统 + 生命周期管理"**。具体地，四个中心对象与两类附加声明：

1. **判决规则（不变量）**——现有 gate/replay/双实现。补：**规则只是三种信号源的消费者，不是中心**；每条规则带"被推翻阈值"（D-1），且新增/修改须以"新预测"形式准入（B-2）。
2. **证明对象（证书）**——现有 PCK 证书/replay 重放/append-only 台账。补：**信任塌缩声明**（A-2）——终审只落在"可独立重查的小内核+台账"上；一切引擎（AI 判官/规则/统计）只以证书形式提交，自陈不入链。
3. **误差流（三类错误 + 一种信号）**——现有逃逸率/自身免疫率。补：①**运气正确**（Gettier 类：结论真而推理链断）与**击败器台账**（B-1）；②**缺省负信号**（预期通过却被击中=最强学习事件）与**信用分配**（归因到最早可预测点）（D-2）；③**独立冲突信号**（互斥判定/欠定并列→升级处理，不直接改判）（C-1）。
4. **生命周期（状态机）**——新增：证据/毒样例/规则的**衰减（半衰期）+ 封顶（上下界）+ 自动退场（自我熄灭）+ 主动退役（多通路）**（E-1/D-2）；卡片语义统一为"未证伪至 D 日 + 击败器清单"（B-1）。
5. **报告义务一：三难声明**（A-1）——每个组件必须声明它牺牲了 soundness/completeness/可判定性中的哪一角，以及其外部依赖（人裁/更强元系统）。
6. **报告义务二：校准度**（C-2）——组件自报置信 vs 实际正确率的周期测量，与 v23 的监控器代际报告并列。

一句话版本：**阙疑当前是"判决结果系统"，第一性原理要求它成为"误差流+生命周期系统"；判决是误差流的输出，不是系统的中心。**

与 v23 四指标的关系：coverage / recall(逃逸) / 自身免疫 / Horizon 四量报告**全部保留**；v24 在此之上叠加"三难声明 + 校准度 + 击败器台账 + 生命周期"四件，属于增强而非返工（与 v23 §五的自我评价一致）。

## 三、v21-v23 的更新汇总

**加强（不需要改）**：
- v21"验证器攻击面"：本方向从 de Bruijn 判据（A4）与"理由=叙事"（C6）两侧加固——攻击面不止内容侧，也包括"校验逻辑本身"与"自陈理由"。
- v22"不追求零误报"：A1（Rice）给出证明层根因，C2（焦虑-ERN）给出机制层同构。
- v23"四指标+分层分流"：E4（法定人数/速度-精度）与 C1（冲突通道）为其提供生物层对应物。

**修正/补充**：
1. **v23"双侧语料"需加方向性**（B7）：毒样例是"能失败"的强证据，正确语料主要服务自身免疫（防误伤）；报告应给"能失败的测试数/killed 率"，不能以通过率冒充有效性。
2. **v23 三阈值（硬开火≤5%/软警报≤20%/疲劳线40%）升级为"参数"**（E4/M2）：它们是法定人数类参数，应各自声明所取的速度-精度位置并实测回填；另加 D-1"被推翻阈值"作为第四个参数（滑动）。
3. **v23"0% 检出的三归因"扩为四**（D6）：除"真无威胁/未送审"外，新增"**处理伪影**"（证据处理/缓存/时点导致信号消失——神经发生之争的直接教训）；处置顺序：先排伪影，再谈不存在。
4. **v22 D11 免疫类比升级为三层**（E1/E3）：补 CRISPR；v22 D12 DNA 的"凋亡"与 D5 主动退役合流为"退役是纠错一等公民"。
5. **v22 D1 科学哲学部分判据化**（B4/B6）：波普尔口径保留但不得用作划界（已被判败）；拉卡托斯"进步=产生新预测"成为规则改动的准入标准与重构触发器。
6. **v21 Top5 之"多智能体辩论=死路"再加一证**（E5）：退化与冗余的区分从术语层面判决"同源多角色=冗余不是退化"。

**明确不动**：
- v22 D13 预测编码/自由能：维持"概念更新、不作底座"（C 方向补充了其神经落点，结论不变）。
- v21 供应链信任（SLSA/Sigstore）、v22 拜占庭 n≥3f+1、v23 攻击面 L1-L8 主体结构——均无冲突。

## 四、最值得深挖的 3 个概念（排序）

1. **击败器台账 + "运气正确"错误类（Gettier 结构）**（B1/M1）。
   理由：这是本轮唯一**全新错误类**——现有三指标（逃逸/自身免疫/coverage）都不覆盖"结论对而过程错"，而它在分布漂移时会翻转为逃逸；机制轻（登记"若成立则应推翻"的未查事实即可），且与漏洞模式（defeasibility）有成熟哲学文献。深挖方向：击败器的形式化（什么算一条击败器）、与豁免四元组的合并、邻近可能性扰动测试（B2 安全条件）。
2. **误差流化：缺省负信号 + 信用分配 + 强度耦合**（D2/C2/M2）。
   理由：这是最大的**架构性升级**——把系统从"结果记录"转为"误差信号系统"；四域独立收敛（A/B/C/D），且 D2 给出了"预期落空即最强信号""归因到最早预测者"两条可直接操作的原则；与 v23"共同进化"线（629/630/631）直接接口。深挖方向：阙疑场景中"最早可预测点"的定义、负信号强度与更新幅度的映射、正/负学习者偏置的历史测量。
3. **有界学习三件套 + 证据生命周期**（D1/E-1/E3/M2）。
   理由：规则膨胀（v22 已识别为自身免疫主要来源）在 v24 获得了三套可组合的刹车：归一化/Oja 竞争、BCM 滑动阈值、衰减-封顶-自动退场-修剪；且有现成工业对应（MMAS、ACO 蒸发）与生物实现（CRISPR 修剪、信息素半衰期）。深挖方向：阙疑现有 67 规则的"涌现交互"是否可用中间量（证据充分度）替代直接叠加（D3 的线性失败警告）。

（并列提名：C1 独立冲突检测器——组件级成本低、边界清晰，可作为第 4 项先落地。）
