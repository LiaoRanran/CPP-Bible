# 方向 G：信息论与热力学

> 核心问题：**信息是什么？智能/验证的代价下限是什么？**
> 检索：15 次（Shannon 熵、Kolmogorov 复杂度、算法信息论、麦克斯韦妖/Szilard、Landauer、贝叶斯/Solomonoff、MDL 奥卡姆、压缩-泛化、互信息、率失真、Fisher/Cramér-Rao、信息几何、计算热力学代价、非平衡熵产、算法信息动力学）。

## 核心概念清单

1. **香农熵（Shannon 1948）**：信息是**不确定性的减少量**，单位比特。信道容量给出可靠传输的理论上限——任何通信都有不可突破的边界。
2. **Kolmogorov 复杂度（1965）**：一个对象的最短程序长度；衡量"不可压缩的信息量"。**不可计算**——没有算法能求最短程序。
3. **算法信息论（Solomonoff/Chaitin/Kolmogorov）**：把复杂度与贝叶斯先验桥接（Solomonoff 先验）；Chaitin Ω 常数揭示算法随机性与不完备性。
4. **麦克斯韦妖 → Szilard 引擎 → Landauer 原理**：妖看似无偿降低熵，实则自身需擦除信息，**擦除 1 bit 至少耗 kT·ln2**——信息与热力学熵本质等价。
5. **Landauer 原理**：计算不是零能耗的；**擦除/重置信息有物理下限**。这是摩尔定律撞墙的根本原因之一。
6. **贝叶斯 / Solomonoff 归纳（1964）**：最优预测=对所有可计算理论按复杂度加权求平均（通用先验）。**理论最优但不可计算**。
7. **最小描述长度 MDL（Rissanen 1978）**：奥卡姆剃刀的形式化——最优模型使"模型描述长度 + 数据编码长度"之和最小。**简单=可压缩**。
8. **压缩 ≈ 泛化 ≈ 理解**：好的压缩隐含学到了结构（LLM 的 next-token 训练目标被论证等价于压缩）。
9. **互信息**：特征 X 能多大程度减少目标 Y 的不确定性——特征选择的核心度量。
10. **率失真理论**：允许一定失真 D 时，压缩所需最小速率 R(D) 的下界。**零失真代价极高**。

## 反直觉发现

- **信息有物理代价**：擦除 1 bit 至少耗 kT·ln2，计算不可零能耗。"免费判定"不存在。
- **最简洁判据不可计算**：Kolmogorov 复杂度不可算，我们只能近似（压缩比、MDL），别妄想精确"找最短"。
- **压缩即理解**：能高度压缩一个领域，往往意味着抓住了结构——泛化来自压缩。
- **妖的百年悖论被"付费"解开**：麦克斯韦妖不违反热力学第二定律，因为它自己擦除信息要付费。任何"降不确定性"的系统都在付费。
- **奥卡姆被形式化为数学**：简单不是"假设少"，而是"可压缩"。
- **理想最优推断不可达**：Solomonoff 归纳最优但不可计算，只能逼近。

## 对阙疑的发散联想（【类比推断】）

- **【类比推断】** Landauer / 计算代价 → 阙疑的"验证/智能"有物理下限：每条验证都耗能（算力、人时），**不能无限验证**。呼应 F 脑成本、636 性价比预算——把"验证成本"显式纳入决策。
- **【类比推断】** Kolmogorov 不可计算 → 没有"终极简洁判据"；阙疑只能用近似（压缩比、MDL）衡量规则复杂度，别追求精确"最简单"。
- **【类比推断】** 压缩 = 泛化 = 理解 → 阙疑的"知识"若能被**压缩/抽象**（高路迁移 C）才算真理解；堆砌原始声明不算。呼应 v27 知识本质的"分布式"。
- **【类比推断】** 麦克斯韦妖 → 阙疑像个"信息妖"：靠降低不确定性（判定）获利，但自身维护（复核、擦除旧判定）要付费。系统必须为判定付费，不能假装免费。
- **【类比推断】** 奥卡姆 / MDL → 阙疑的规则在解释力相同时**优先选更可压缩（更短描述）**的验证策略；这是形式化的"少即是多"。
- **【类比推断】** 互信息 → 阙疑的"该查什么"：选与目标（判定正确性）**互信息最大**的检查项，而非全量检查（降低外部认知负荷 C）。
- **【类比推断】** 率失真 → 阙疑不必追求零失真：允许一定误报率以**大幅降低验证成本**，在率失真前沿选工作点（呼应 637 阈值未校准、容忍小错）。
- **【类比推断】** Fisher 信息 / Cramér-Rao → 阙疑对"某类错误率"等参数的估计有**精度下限**；知道"我最多能多确定"比假装精确更重要——诚实登记不确定性。
- **【类比推断】** 信息几何（Amari）→ 阙疑的判定空间是概率流形；不同验证策略在流形上移动，**自然梯度（沿流形测度）比欧氏更优**——设计指标要考虑几何结构。
- **【类比推断】** Solomonoff 不可计算 → 阙疑的"理想推断"不可达，只能逼近（贝叶斯 + 启发式）；别追理论最优，追可操作近似（呼应 B 机制设计的务实态度）。

## 死路确认

- **"可无限验证直到确定"**：Landauer/成本下限，确定性有代价。
- **"存在最简单判据"**：Kolmogorov 不可计算，只能近似。
- **"零误报可达成"**：率失真——零失真代价极高。
- **"精确估计一切"**：Fisher / Cramér-Rao 下有界。
- **"理想最优推断可实现"**：Solomonoff 不可计算。

## 对自我进化系统的含义

把阙疑当成一个**有热力学下限的信息处理器**：承认验证有成本、用压缩衡量理解深度、在率失真前沿（而非零失真）工作、诚实标出估计的精度下限、用可计算的近似替代不可达的最优。系统的"聪明"不在于更用力验证，而在于更聪明地分配有限的验证预算。

## 最值得搬的一个概念

**Landauer 原理 + 率失真理论的组合**：**"验证有物理/算力下限，必须在率失真前沿工作"**。

为什么是它：它把前面所有方向对"成本"的直觉（A 保留余量、B 激励成本、C 认知预算、F 脑成本、636 性价比预算）统一成一个可计算的信息论表述——阙疑不能无限验证或追求零误报，而应为每类判定**明确允许的失真（误报/漏报率）**，并在"成本—失真"前沿选工作点。这恰好给 637 的"阈值未校准、诚实登记不确定性"一个理论支点：不是"校准到完美"，而是"在可承受代价下选一个诚实的失真点"。
