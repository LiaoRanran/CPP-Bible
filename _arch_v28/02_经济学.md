# 方向 B：经济学与博弈论

> 核心问题：**激励怎么设计？多主体怎么合作？怎么防止搭便车？**
> 检索：15 次（机制设计、公地悲剧/Ostrom、声誉系统、Axelrod、信息不对称、信号理论、激励相容、搭便车、VCG 拍卖、契约理论、行为经济学、公共品实验、Ostrom 八原则、委托代理、Clarke pivot）。

## 核心概念清单

1. **机制设计（Hurwicz / Maskin / Myerson，2007 诺奖）**：反推问题——给定想要的社会目标，倒着设计规则，使分散、自私的参与者在追求自身利益时恰好达成目标。核心是"不要改人，改规则"。
2. **公地悲剧（Hardin 1968）vs Ostrom 自主治理（1990）**：Hardin 认为公共资源必被过度消耗；Ostrom 用大量实证反驳——**社群自主治理可永续**，并提炼出 8 条设计原则。
3. **声誉系统（eBay / Stack Overflow / Uber）**：把成员历史行为聚合成可见信号（评分、徽章、karma），解决陌生人间的信任问题。但存在刷分（sock puppet、vote brigading）的系统性漏洞。
4. **重复博弈与 tit-for-tat（Axelrod, *The Evolution of Cooperation* 1984）**：计算机锦标赛中，最朴素策略（首轮合作、之后模仿对方上一步）胜出。**合作无需利他或强制，只需 reciprocity（礼尚往来）+ 宽容 + 可预期报复**。
5. **信息不对称（Akerlof 1970 "柠檬市场" / Stiglitz 1981 信贷配给）**：当一方知道得更多，市场可被完全摧毁（劣币驱逐良币）。这是 2001 诺奖主题。
6. **信号理论（Spence 1973）**：教育等"昂贵信号"的价值，常不在于它本身提升能力，而在于**它是高能力者才付得起的代价**——信号价值来自"贵"。
7. **激励相容与显示原理（Revelation Principle）**：存在一种直接机制，使**说真话成为每个参与者的占优策略**。把"诚实"从道德要求变成理性最优。
8. **搭便车（Olson, *集体行动的逻辑* 1965）**：大群体里个体理性地不贡献，导致公共品供给不足。规模越大越严重。
9. **VCG / Vickrey 拍卖（Vickrey 1961, Clarke 1971, Groves 1973）**：第二价格/VCG 机制下，如实报价是占优策略，且结果社会最优。机制设计的经典成功。
10. **契约理论（Hart 不完全契约 2016 / Holmström 道德风险）**：很多事不可观测、不可写全（不完全契约），剩余控制权（residual control rights）比试图写尽条款更关键。

## 反直觉发现

- **最朴素策略赢了**：在残酷的重复博弈锦标赛里，tit-for-tat（不是最聪明的算法）夺冠——简单、宽容、可预期比精明更重要。
- **公地悲剧不是宿命**：Ostrom 推翻了"公共资源必然崩溃"，自主治理的社群能长期可持续。强制集中管理反而常失败。
- **信号贵才有用**：教育的很多"价值"是信号价值（证明你是高能力者），而非人力资本的真实提升。便宜的信号没用。
- **激励 >> 道德呼吁**：实验室与现实中，人会对激励做理性反应；靠"请你守规矩"的效果远弱于让守规矩成为其自身利益。
- **说真话可以是占优策略**：VCG 证明，好的机制设计能让"诚实"不是美德而是最优反应——这比劝人诚实可靠得多。
- **利他惩罚维持合作**：公共品实验里，人愿意花自己的钱去惩罚背叛者（altruistic punishment），正是它维持了长期合作——纯粹自利模型预测不出。

## 对阙疑的发散联想（【类比推断】）

- **【类比推断】** 机制设计 → 阙疑的本质：不要试图"让参与者变好"，而是**设计规则让"正确/诚实"成为每个参与者的占优策略**。把人审批、溯源、复现设成激励相容的环节，而不是道德呼吁。
- **【类比推断】** 公地悲剧 + Ostrom 八原则 → 阙疑的知识库是一个 commons：需明确边界（哪些算已验证知识）、本地规则、集体选择、分级制裁（graduated sanctions）、冲突解决机制、对外部权威的自主权。**八原则几乎可直接套用**。
- **【类比推断】** 声誉系统 → 阙疑的信任信号：把每个判定、每个知识源的历史表现聚合成可见信号（类似 SO 的 reputation）。但要**主动防御刷分**——sock puppet / vote brigading 是已知漏洞。
- **【类比推断】** tit-for-tat → 阙疑与知识源/工具的关系应是**重复博弈而非一次性判定**：对背叛（误判、污染）要有可预期、宽容、快速的回应，而不是一刀切封杀或放任。
- **【类比推断】** 柠檬市场 → 阙疑的"劣币驱逐良币"风险：未验证的廉价声明会像柠檬市场一样，把高质量验证挤出去。**必须降低信息不对称**（接地、可溯源、可复现）才能保住高质量端。
- **【类比推断】** 信号理论 → 阙疑的"昂贵信号"：要求高成本动作（人审批、独立复现、公开失败记录）作为可信信号；**廉价声明不计数**，否则人人声称自己正确。
- **【类比推断】** VCG / 激励相容 → 阙疑的诚实激励（比 #1 更具体）：让"说真话、报实情"是占优策略。例如把"承认不确定/未知"设计成有回报而非有代价。
- **【类比推断】** 搭便车 → 阙疑的验证劳动：若验证无偿，长期供给不足（Olson）。需给验证者**激励或声誉回报**，否则系统靠少数人在撑。
- **【类比推断】** 利他惩罚 → 阙疑的社区 enforcement：必须有人愿意付出成本去惩罚错误声明，否则搭便车横行、commons 退化。
- **【类比推断】** 不完全契约 → 阙疑的"无法写全规则"：像 Hart 的不完全契约，不可能预判所有情形；要保留**剩余控制权**（人审批、仲裁、回溯）而非妄想规则全覆盖。

## 死路确认

- **"加强道德教育让守规矩"**：实验表明激励 >> 道德呼吁，道德呼吁对理性博弈者几乎无效。
- **"一次性完美判定"**：真实是重复博弈，单次必错；应设计可迭代、可纠错的交互。
- **"规则写全所有情况"**：不完全契约理论证明不可能；留剩余控制权比写尽条款可靠。
- **"靠集中权威统一管控"**：公地悲剧常由强制失败，分散自治（Ostrom）反而更稳。
- **"声誉可自动可信"**：声誉系统天然可被刷分操纵，需额外防作弊设计，否则信号失真。

## 对自我进化系统的含义

把阙疑当成**制度设计问题而非算法问题**：目标不是训练出一个"永远正确"的判定器，而是搭一套**让正确成为各参与主体（人、工具、验证器）占优策略**的机制。具体包括——保留人审批作为剩余控制权、用昂贵信号过滤廉价声明、用重复博弈式交互容忍并纠正错误、用分级制裁而非一刀切。系统自己进化时，进化的是"机制"而非"更聪明的判定规则"。

## 最值得搬的一个概念

**激励相容（Incentive Compatibility）+ 显示原理**。

为什么是它：它是机制设计的核心定理，也是把"诚实/正确"从**道德要求**变成**理性占优策略**的钥匙。对阙疑而言，这比任何"再加一条校验规则"都根本——规则再多变会被博弈绕过，而让说真话是每个人自己的最优反应，规则才真正落地。落地形式：设计每一步（人审批、溯源、复现、承认未知）使参与者的自利动机与系统目标一致；对无法激励相容的部分，保留人作为剩余控制权的兜底。
