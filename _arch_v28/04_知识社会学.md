# 方向 D：知识社会学与科学学

> 核心问题：**知识是怎么在人类社群里累积的？科学是怎么进步的？**
> 检索：15 次（Kuhn 范式、Feyerabend、Merton CUDOS、同行评议现实、Popper/Kuhn/Lakatos、复制危机、预注册/开放科学、马太效应、科研不端、同行评议偏误、科学计量、后常规科学、共识形成、科研基础设施、Lakatos 纲领）。

## 核心概念清单

1. **范式与科学革命（Kuhn 1962）**：成熟科学不是平滑累积，而是"常规科学（在范式内解谜）→ 异常积累 → 危机 → 革命（范式转换）"。**共识会崩溃，且崩溃是进步的一部分**。
2. **反对方法（Feyerabend 1975）**：没有普适的科学方法，"怎么都行（anything goes）"。方法论无政府主义——多元策略竞争比锁定一种更有效。
3. **默顿规范 CUDOS（Merton 1942/1973）**：科学共同体的制度性规范——**公有性、普遍主义、无私利性、有条理的怀疑主义**。是理想而非现实。
4. **同行评议的现实（Smith："若是药早被禁"）**：理想中的质量门，现实中充满偏误、低效、声誉同质性。并非金标准。
5. **证伪 vs 范式 vs 研究纲领（Popper / Kuhn / Lakatos）**：Popper 主张可证伪是划界标准；Lakatos 折中，用"进步/退化"的研究纲领来衡量——**进步纲领预测新事实，退化纲领只会事后解释**。
6. **复制危机（Open Science Collaboration 2015）**：对 100 项心理学研究的复现中，**仅约 36% 可复现**。【一方称】这是现代科学最刺眼的事实之一——大量"已发表知识"可能不真。
7. **预注册与开放科学**：在收集数据前公开研究设计以对抗 p-hacking；开放数据/代码/流程以增透明。
8. **马太效应（Merton 1968）**：名气大的科学家获得超出其贡献的信用与引用——**累积优势与质量脱节**。
9. **科研不端（Stapel 2011 等）**：系统性数据捏造案例说明，连"专家背书"都可能来自造假。
10. **后常规科学（Funtowicz & Ravetz 1993）**：当决策的** stakes 高 + 不确定性高**时，事实与价值无法分离，需把"同行共同体"扩展到包括利益相关者、非专家。

## 反直觉发现

- **科学不是累积的**：Kuhn 证明进步常靠范式革命而非平滑叠加；旧范式下的"知识"会被整体替换。
- **仅约 1/3 可复现**：复制危机揭示大量已发表结论站不住——"已发表"≠"已验证"。
- **同行评议远不如想象可靠**：被讽"若是一种药早被禁"，偏误（性别/国籍/声誉同质性）与低效并存。
- **名气不等于质量**：马太效应使高声望者获得超额信用，与真实贡献脱钩。
- **CUDOS 是理想规范**：现实中常被私利违背（不端、偏误、封闭），规范≠实际行为。
- **没有唯一正确方法**：Feyerabend 表明方法论无政府状态在历史上反而催生突破。

## 对阙疑的发散联想（【类比推断】）

- **【类比推断】** 复制危机 → 阙疑的核心警示：已"验证"的知识未必真。每条知识都须**可独立复现**，复现失败应触发降级而非忽略。直接对接 637 的"诚实登记"。
- **【类比推断】** Kuhn 范式 → 阙疑也有"判定范式"（例如确定性判定 vs 概率+人审批）。当异常（反复误判）积累成危机，应**允许范式革命**而非硬修补旧规则。
- **【类比推断】** 同行评议现实 → 阙疑不能把"人审批"当金标准：人审批同样有偏误、低效、声誉同质性。需**多源交叉 + 透明留痕**对冲。
- **【类比推断】** CUDOS → 可作阙疑的四条元规范：公有（知识共享）、普遍（标准不因人而异）、无私（不为私利改判定）、有条理怀疑（对所有主张质疑）。立为系统级纪律。
- **【类比推断】** Feyerabend 怎么都行 → 警告：不存在"唯一正确的验证方法"。阙疑应**允许多种验证策略并存竞争**，而非锁定一种方法论。
- **【类比推断】** 马太效应 → 阙疑的权威偏置：知名度高的知识源/工具会被过度信任。需**显式对抗**（权重不与名气挂钩，或挂钩反确认偏误预算）。
- **【类比推断】** 科研不端 Stapel → 阙疑要防"内部造假"：自己生成的验证数据也会被污染（637 实测 observer 被并发批次污染）。需**数据源隔离 + 校验**。
- **【类比推断】** 后常规科学 → 阙疑恰是"后常规"场景：高 stakes（系统判定影响大）+ 高不确定性（知识未定）→ 事实与价值不可分，需**扩展判定共同体**（人 + 机器 + 多源）共同判定。
- **【类比推断】** Popper 证伪 → 阙疑应以"可证伪"为知识准入门槛：不能设计反例检验的知识不应进入系统。
- **【类比推断】** Lakatos 进步 vs 退化纲领 → 阙疑的演进健康度指标：某验证策略是"进步"（预测新事实）还是"退化"（只解释已发生）？用此决定淘汰/保留某条规则。

## 死路确认

- **"科学是客观累积的"**：Kuhn 与复制危机共同打脸，知识有革命与塌方。
- **"同行评议是金标准"**：现实偏误、低效、同质，不能作为唯一判据。
- **"有名气 = 可信"**：马太效应使声望与质量脱钩。
- **"存在唯一正确方法"**：Feyerabend 证明方法论无政府反而有益。
- **"已发表 = 已验证"**：复制危机：约 2/3 不可复现。

## 对自我进化系统的含义

把阙疑自身当成一个**科学共同体**来治理而非一个判定器：以可证伪为准入、以可复现为校验、以 CUDOS 为元规范、允许多范式竞争、警惕马太效应与内部造假、在后常规场景下把判定权扩展到多元共同体。系统的"进步"应像 Lakatos 纲领那样可被"是否预测了新事实"衡量。

## 最值得搬的一个概念

**可复现性（reproducibility）+ 复制危机的教训**。

为什么是它：v21–v27 的阙疑系统最该内化的硬事实就是——大量"已验证知识"其实不可复现。把它落成机制：阙疑的**每条知识必须可独立复现，复现失败触发降级，且复现过程可审计**。这与方向 C 的"测试效应"、方向 B 的"激励相容"、方向 A 的"实测体检"共同指向同一件事：验证不是一次性的信任授予，而是可重复、可校验、可追责的持续过程。这给 637 的"诚实"一条最实在的操作抓手。
