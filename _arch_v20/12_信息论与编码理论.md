# 12 · 信息论与编码理论（语义熵 / 率失真 / 纠错码思想）

> _arch_v20 · 检索日期 2026-09-21 · 只读调研 · 本方向有仓内探针实证（probes/p03 Part1）

## 一、外部最新进展（2024-2026）

### 进展 1：信息论的基本单位从 bit 推向 token——语义信息论成型
- 华为 2012 实验室（arXiv 2511.01202，2025-11）：以率失真、有向信息、Granger 因果为起点，建立以 **token 为基本单位**的 LLM 语义信息论：预训练的有向率失真函数、后训练的有向"率-奖励"函数、推理期语义信息流，并给出 token 级语义嵌入的信息论最优向量化。【已查证】https://arxiv.org/html/2511.01202v1 （检索 2026-09-21；单篇理论预印本，非社区共识）

### 进展 2：语义熵作为不确定性/幻觉信号已进入检测工具箱
- HalluScan（arXiv 2605.02443，2026-05）把 Semantic Entropy 列为 6 类标准检测法之一；保形预测综述（皇家霍洛威等，106 项研究）发现**无 logit 方法**（自一致性采样、语义多样性等）平均覆盖误差与预测集尺寸反而优于基于 logit 的方法，能绕开 token 概率失校问题。【已查证】https://arxiv.org/html/2605.02443v1 与 https://khuong.uk/Papers/Uncertainty_aware_LLM.pdf （检索 2026-09-21）
- TECP（arXiv 2509.00461，2025-08）：token 熵作为免 logit、免参考的不确定性度量接入 split conformal 管道。【已查证】https://arxiv.org/html/2509.00461v1 （检索 2026-09-21）

### 进展 3：率失真进入"基础框架"重述期
- arXiv 2512.11279（2025-12）把率失真/量化重新表述为连续信息向离散空间的投影，"质量是失真的补"。【已查证，预印本】https://arxiv.org/html/2512.11279v2 （检索 2026-09-21；该文风格激进，作为动向参考而非定论）

## 二、对阙疑的范式级影响（5 维评估）

探针 p03 Part1 在真实毒样例攻击面分布（tools/poison_surface_map.json，124/124 drill；11 个攻击类型合计覆盖 83 个有分类毒样例）上计算：
- Shannon 熵 **2.879 bit**，归一化 H/Hmax=**0.832**，有效等效类别 2^H=**7.4**（名义 11 类）；最集中两类 A3（断言无判别力，25.3%）+A1（记录层伪造，22.9%）占 48.2%。
- 诚实注意：类型计数合计 83 ≠ drill 总数 124，有 41 个毒样例未在 attack_types 细分计数内（分类口径覆盖不全，本身是可观测性缺口）。

5 维评估：
1. **适用性**：中（作为度量语言），低（作为信任机制）。
   - 可直接用的三个信息论视角：
     a. **攻击面熵监控**：H/Hmax 随批次的变化 = 毒样例多样性指标，单一攻击类型占比上升意味着防御在过拟合已知形态；
     b. **语义熵当弃权信号**：对 LLM 生成的命题/讲解多次采样，语义熵高的进人审（接自由方向 A 的保形阈值），这是 2025-2026 免 logit 黑盒路线；
     c. **率失真定义"有损验证"边界**：任何抽样/快检都是有损压缩，率失真给出"给定失真上界需要多少检查"的语言，给逃逸率上界一个信息论解释（n 个样本携带的信息量）。
2. **颠覆性**：低。它不给新信任源，只给度量与阈值语言；"纠错码式自修复知识表示"（brief 设想）在阙疑这种语义内容上**不成立**——ECC 纠错的前提是已知码空间与汉明距离，自然语言命题没有，强行类比是比喻不是机制。
3. **成本-收益**：熵监控近乎零成本（p03 已实现）；语义熵需多次 LLM 采样，成本随调用量线性增长，在候选生成批量不大时可接受。
4. **反例**：
   - 熵高 ≠ 错、熵低 ≠ 对：模型对常见错误也能高度一致（自一致性在系统偏差上失效，这是保形综述强调 token 概率失校的同源问题）。
   - 攻击面 H/Hmax 高也不代表覆盖好：11 类都各有几个毒样例可以熵很高但 RULE-COVERAGE 只有 39/63（v19 G7），结构覆盖与类别熵正交。
   - 语义信息论 2511.01202 是单篇理论框架，其"率-奖励"等概念在工程上尚未验证。
5. **与现有框架关系**：度量插件（接 metrics_collector 与自由方向 A），不动判决层。

## 三、可落地建议

- **高**：把攻击面熵（H/Hmax、2^H、top-2 集中度）加入 poison_drill 报告，与 RULE-COVERAGE 并列——两类指标（类型多样性 × 规则覆盖度）一起看才不互相欺骗。
- **中**：LLM 候选生成的多采样语义熵作为人审排序信号（不是判决），阈值标定等有 ≥100 条人审标签后用保形方法做。
- **冻结**：ECC/自修复码式知识表示；把 token 级语义信息论引入 gate 判据（理论未成熟、工程无必要）。
