# 探针 p02：置信序列（anytime）vs 固定样本 CP — 逃逸率口径
输入：n=1406, x=1, alpha=0.05, 契约逃逸率 1/1406=0.000711

## A. Clopper-Pearson 精确区间复算
  双侧 95% CI        = [0.0018%, 0.3956%]
  单侧 95% 上界      = 0.3370%   （v19 G13 称 0.337%，此处复算）
  点估计             = 0.0711%

## B. Beta-混合 e-process 置信序列（任意停止时刻联合 95% 覆盖）
  n=1406,x=1 的 anytime 上界 = 0.9062%
  相对单侧 CP 上界放宽倍数     = 2.69x  （anytime 的诚实代价）
  轨迹（累积观测 0 逃逸时的上界，%）:
    n=   50 x=0  CP单侧= 5.8155%  CS=12.9381%
    n=  100 x=0  CP单侧= 2.9513%  CS= 7.3284%
    n=  200 x=0  CP单侧= 1.4867%  CS= 4.0646%
    n=  500 x=0  CP单侧= 0.5974%  CS= 1.8256%
    n= 1000 x=0  CP单侧= 0.2991%  CS= 0.9856%
    n= 1406 x=1  CP单侧= 0.3370%  CS= 0.9062%

## C. 连续偷看的虚报率（真实 p=0.01，每 20 样本看一次，看到 n=1406）
    事件=错误宣称『p < 0.01』；3000 次 Monte Carlo，种子 20260921
    CP 单侧 0.05 反复偷看经验虚报率 = 13.80%  (名义 5%)
    e-process/置信序列经验虚报率    = 0.00%  (理论 ≤ 5%)

## D. 0 逃逸前缀上达到 0.5% 上界所需样本量
    CP 固定口径: n=598   CS anytime 口径: n=2127   代价 3.56x
    含义：CS 用更多样本换来「每批都能合法看仪表盘」的权力。
