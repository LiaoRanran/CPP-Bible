## 一、外部最新进展（2024-2026）

### 进展 1：知识追踪（KT）从 BKT 走向"可解释多维状态"，LLM 任分析师
- CIKT（华东师大，arXiv 2505.17705，2025-05）：双组件——Analyst 从历史作答生成动态可解释学习者画像，Predictor 据此预测；按预测准确率反过来迭代画像。【已查证】https://arxiv.org/html/2505.17705 （检索 2026-09-21）
- 多粒度注意力 KT（ICCSMT 2025，DOI 10.1145/3795154.3795251）：item/session/skill 三层级表示 + SHAP 认知诊断，ASSISTments 上 AUC=0.9905；**疲劳水平与先前表现是主导预测因子**。【已查证，ACM 页面 PDF】https://dl.acm.org/doi/pdf/10.1145/3795154.3795251 （检索 2026-09-21）
- MERIT（华东师大/腾讯，arXiv 2603.22289，2026-03）：免训练，检索增强 + 认知图式发现 + 逻辑约束推理，消融显示逻辑约束起决定性作用。【已查证】https://arxiv.org/html/2603.22289 （检索 2026-09-21）
- 双图卷积 KT（PLOS ONE，2025-04）：学生图+技能图双结构处理稀疏与技能关联。【已查证】https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0317992 （检索 2026-09-21）

### 进展 2：掌握学习的产业共识：KT + 前置依赖图 + 资源推荐联合优化
- Attention-BiLSTM-KT（AISNS 2025，DOI 10.1145/3797161.3797200）：知识状态感知推荐，尊重前置关系，Precision@10 提升 18.7%。【已查证，ACM 页面 PDF】https://dl.acm.org/doi/pdf/10.1145/3797161.3797200 （检索 2026-09-21；MOOC 数据 300 人，样本小，结论谨慎）

## 二、对阙疑的范式级影响（5 维评估）

1. **适用性**：当前低，传感器接通后高。
   - 阙疑学习者镜像现状（v18/v19 实证【一方称：前序探针结论，本次未重验】）：kc_inventory 27 个 KC、bkt_solver 四参数、learner_behavior **0 真实事件**、behavior 文件 0 字节。外部 2025 KT 的所有进步都需要行为流作为输入——没有 y，任何 x 维度的模型升级都是空转。这与 v19 P1 判断完全一致，外部文献加强了它。
   - 外部文献真正改变的是**目标数据结构**：从单一掌握度标量，到至少三层（item 级作答 / session 级模式含疲劳 / skill 级掌握），并显式建前置图（阙疑已有 prereq_topo_check 与学习路径图，骨架不差）。
2. **颠覆性**：对当前项目低（无数据）；对"人学会"目标中-高（v18 钥匙的门轴）。多维状态能回答 BKT 答不了的问题——"他是不会，还是今天累了/在刷进度"（SHAP 实证疲劳是主导因子之一）。
3. **成本-收益**：现在升级模型 = 零收益纯成本；真实事件 ≥50 后（v19 开门数字），第一步不是换深度模型，而是把日志维度扩到会话/疲劳（时间戳、间隔、重试次数），这是低成本高价值的传感器设计变更。CIKT/MERIT 类 LLM 画像在数据量过百事件后再评估。
4. **反例**：
   - AUC 0.99 类结果几乎都在 ASSISTments 等大型公开数据集上，300 人 MOOC 研究自己承认样本小——单人/极少量数据上深度 KT 必然过拟合，BKT 反而更稳（偏差-方差权衡偏向简单模型）。
   - 可解释画像由 LLM 生成会引入幻觉画像（MERIT 之所以加逻辑约束正是此原因）——学习者诊断不能让生成模型自由发挥。
   - 目标错位风险：预测准确率高不等于教学有效，方向 9 的终点是学会 C++，不是预测下一题对错（v18 平台期诊断）。
5. **与现有框架关系**：未来替换 bkt_solver 的候选谱系，但当前 BKT 保留；kc_inventory/前置图/推荐器已就位，差的是传感器（方向 9 本身的结论）与外部独立验证（方向 1/7）。

## 三、可落地建议

- **现在（无外部依赖也能做）**：按 item/session/skill 三层**预先设计行为日志 schema**（作答、时间戳、会话 id、重试、提示使用），避免传感器接通时只能记裸对错。1 人天，纯设计。
- **开门后（真实事件 ≥50）**：先拟合带疲劳/间隔特征的简单模型与 BKT 做留出比较，赢了再换；不直接上深度 KT。
- **冻结**：LLM 自由文本画像作为掌握度判决、AUC 竞赛式模型选型。
