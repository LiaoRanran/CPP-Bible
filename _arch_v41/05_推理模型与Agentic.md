# _arch_v41 · 05 推理模型 / agentic 时代的错误模式变化（方向 5）

> 核心问题：推理模型错误类型如何迁移、agentic 多步新错误、长上下文效应，以及阙疑从"单步断言验证"扩到"轨迹验证"的架构问题。
> 诚实标注：【论文·实证】；【综述】；【第三方】；【推断】；【盲区】。

---

## 一、推理模型：浅错减少，错在"早期分叉"与"单步严谨"

1. **失败不是均匀分布的**【论文·实证】：Zhu et al. 分析推理轨迹发现错误源自**少数早期转换点（failure onset）**——此后轨迹局部连贯、全局错误；错误段伴随 token 熵尖峰；从同一中间状态分支重续仍可达正确解。GUARD 类熵感知分支推理据此成立。[v41-S38]
2. **四大失败类与难度无关**【论文·实证】：RFM（200 道证明题，R1/O3）：逻辑违规、隐含假设、论证含糊、证明不完整——分布跨模型、跨难度一致，属推理过程的根本缺陷；显式提示失败模式能改善但远不足。[v41-S39]
3. **链越长越可能错（反直觉）**【论文·实证】：VUB/哈佛对 o1-mini/o3-mini 的系统分析——控制题目难度后，推理 token 数与正确率反向；超长链是"卡住/循环"的信号而非深思；进步来自"想得更巧"而非"想得更久"。[v41-S40]
4. **复杂度一高即崩塌**【论文·实证】：LRM 在图推理上存在边幻觉、长度止损错；NeurIPS 2025 *Illusion of Thinking* 记录过度思考（早找到答案却继续走错误路径）、给全算法也不改变崩塌阈值——瓶颈在符号执行不在策略发现。[v41-S41/S42]

## 二、Agentic：子技能合格 ≠ 端到端成功

- **牛津综合（27 篇/19 基准）**【综述】：六失败簇——工具调用与参数错、规划与约束满足失败、长程上下文累积退化、多智能体协调失败、安全失败、测量效度问题；失败随任务长度**非线性复合**，脚手架不统一改善可靠性。单轮工具选择/短程导航/窄域编码确有真实进步。[v41-S43]
- **工具失败细化**【论文·实证】：ToolFailBench（1000 任务/5 域）区分 tool_skip（未执行/纯文本伪调用）、参数错、忽略返回值等，同样总分下失败画像迥异。[v41-S44]
- **失败定位机制**：Model-or-Harness 分类（工具幻觉/格式错/次优参数/选错工具/响应处理错）【论文·实证，S45】；Who&When Pro 等一批工作做自动归因——AgentRx 关键步定位平均 +75%、AgenTracer-8B 反事实回放、MAST 1600+ 轨迹/7 框架、FAMAS 频谱分析【论文·实证，S46】。
- 背景：METR 测得前沿 agent 50% 可靠完成的任务时长自 2019 年约每 7 个月翻倍【综述转引，S43】。

## 三、长上下文：简单检索已解决，"有效长度"仍短

- Google 实测 Gemini 2.5 Flash：单事实大海捞针在任意位置（含近上下文极限）全对——2023 式 LITM 在新模型简单问答上基本消失【论文·实证，S47】。
- 但**有效长度通常只有标称的 1/2–1/4**：RULER/NoLiMa 类去词法捷径测试中 GPT-4o 从 99.3% 跌到 32k 时 69.7%，32k 处 11 个模型跌破自身基线一半【第三方汇编，S48】。
- **lost-in-thought**：长 CoT 本身降低上下文检索能力；RecaLLM 以交错检索+约束解码做可验证复述【论文·实证，S49】。

## 四、硬映射

### 1. 从单步断言到多步轨迹：架构怎么扩？【推断】

- 验证对象升级为轨迹：**逐步过程判决 + 端到端结果判决 + 关键步归因**。学界 2026 的主流归因法（反事实回放/故障注入/频谱分析）[S46]与阙疑"证据可复现"哲学同构，可直接吸收为轨迹层算子。
- 四态语义需扩展：轨迹级会出现"部分步 fail""步间冲突""中途状态漂移"等新形态——现有半格/worst-wins 内核（656 PBT 已冻结）能否表达轨迹偏序，**未见规格**【盲区】。

### 2. 攻击图够不够表达 agentic 错？——节点类型不够【推断】

- 口径登记：brief 锚"**178 节点/388 边**"；本工作树 640c 权威源口径为"**121 节点/388 边**"。差异无法在现有文件内收敛【盲区】，不擅自取一。
- 现有边类型为命题级击败/辩护；agentic 错误需要时序边、数据流边（参数→工具）、级联边。MAST/六簇分类[S43]可直接做节点类型种子——**这是低成本高杠杆的动作**。

### 3. 推理模型自带验证：替代还是互补？

- 证据指互补：其"自验证"随链长退化[S40]、单步严谨性四类缺陷与难度无关[S39]——过程自我监督本身可错；外部轨迹审计的需求不消失。
- 阙疑位置：做**轨迹的独立审计方 + 账本持有方**；模型内建验证替代的是"它内部那一次检查"，替代不了独立判决与留痕（与方向 2 结论一致）。

### 4. 未来模型会不会自己长出验证步骤？

- 已经在长（RecaLLM、process reward 即是），但长出的是**自检**；阙疑的治理层（provenance/账本/人审）不与自检同层，不构成直接竞争。【推断】

## 五、直说：短板与风险

- 阙疑目前**完全没有轨迹验证设计**，agentic 时代其方法栈适用面在收窄；若 3 个月内不立项轨迹层，"验证 LLM 输出"的叙事会落后于行业（行业焦点已转向轨迹归因）。【推断】
- 攻击图节点/边口径的内部不一致（178 vs 121）应在立项前收敛，避免规格建立在漂移数字上。
- 有利：失败归因的工程方法（回放、注入、频谱）与阙疑现有证据管线同构，迁移成本低。
