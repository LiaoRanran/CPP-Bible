# _arch_v41 · 04 小模型 / 本地化时代的验证需求（方向 4）

> 核心问题：小模型 vs 大模型错误模式差异、离线部署对验证的新要求、验证器本身能否上边缘、推理成本下降后的经济模型。
> 诚实标注：【论文·实证】；【综述】；【厂商】；【官方】；【推断】；【盲区】。

---

## 一、小模型错得更多吗？证据分两层，不能一概而论

1. **原子事实层面：差距很小**【论文·实证】：OnionEval 实测 Llama3.2-3B 原子幻觉辨别 90.71% vs Llama3.1-70B 91.46%。小模型真正的短板是**上下文推理**（factual analysis 行、context reasoning 差），简单 CoT 即可大幅缓解。[v41-S31]
2. **长度归一化后：小模型幻觉率更高**【论文·实证】：30 语种/6 模型族的野外长问答研究明确"smaller LLMs exhibit larger hallucination rates"，但效应分散在具体任务上。[v41-S32]
3. **反直觉证据（必须并列）**：2026 研究 *Reliability Scales Inversely* 提出——规模扩大把响应开头的知识缺口收窄至 1/7，但**响应内知识退化随规模增长至 39 倍**；捏造会"雪球"，且模型自我监控对此盲。即：大模型错得更少但更隐蔽、更自信。[v41-S30]
4. 【推断】综合：小模型 = 错得更多但更浅、更易被机器信号抓；大模型 = 错得更少但更深、plausible 偏差更危险。**两类输出都需要验证，阙疑不能只盯大模型。**

## 二、本地化部署已是主流形态（2026）

- Ollama 为本地推理事实标准（176k+ stars），OpenAI/Anthropic 兼容 API、可完全气隙；隐私与数据驻留是欧洲最大采用驱动；Ollama/vLLM/llama.cpp 等均免费开源【第三方综述，S33】。
- 边缘硬件拐点：2026 紧凑开放模型（Nemotron 3.5 Lightning 30B MoE/3B 激活等）在 Jetson 上经 NVFP4+投机解码取得 6.28× 解码加速——**推理模型首次在边缘本地可跑**【官方，S36】。
- 边缘 LLM 高效推理论（清华 TST 综述）：投机解码 + 模型卸载是两条主路径【综述，S37】。

## 三、验证器本身能否上边缘：已有商业先例

- **Aare Verify Edge**【厂商】：完全在设备上运行验证管线——领域专用小模型（Phi-3-mini+LoRA，4-bit，~500MB）做抽取 + 精简约束求解器（<1MB）做判定；warm 验证 <100ms、运行内存 ~200MB、冷启 ~500ms。证明"边缘验证器"有真实市场且架构可行。[v41-S34]
- **AttestLLM**【论文·实证】：TEE 内对设备端 LLM 做水印/attestation——验证的是"模型完整性与授权"，与阙疑的"知识断言正确性"互补；说明设备端"模型身份锚"也是刚需。[v41-S35]

## 四、硬映射

### 1. 阙疑 813 行 + 0.59ms 够轻吗？——逻辑够，形态不够【推断】

- 判决逻辑：0.59ms（656 实测），比 Aare Edge 的 <100ms 预算还宽裕；
- 但**实现是 Python**：上边缘需要运行时（数十 MB）、冷启慢，无法作为嵌入式库链接。Aare 的做法（小原生求解器）指向同一结论：**Rust 重写内核不是洁癖，是边缘场景的入场券**（656 已冻结 Rust 边界文档）。
- 有利：阙疑证据已是 SHA256 内容寻址——边缘端可做**瘦验证器**（规则引擎+哈希核验，证据包预载或按需拉取），不需要在设备上跑编译器。L0"真机裁判"在边缘不可得时，靠冻结证据包复算，这一架构缺口目前**未见设计文档**【盲区】。

### 2. 验证谁的输出？

- 两者皆验，但**规则集应分层**：小模型侧重浅层高频错（语法/API/基础事实，机器可判比例高）；大模型侧重深层 plausible 错（边界/语义，人审比例高）。同一套内核、不同检测权重。【推断】

### 3. 经济模型怎么变？

- 推理成本快速下降 → 验证在总成本中的占比相对上升；验证侧也在小型化（MiniCheck 7B、Aare DSLM）。**单位验证成本下降速度快于单位推理成本时，验证才是净收益**——目前证据（S19/S34）支持这一趋势。【推断】

## 五、直说：短板与风险

- 阙疑目前**无边缘形态路线图**：Python 内核 + 编译器依赖，离开桌面环境即不可用；若声称"轻量验证器"，严格说只在逻辑层成立。【推断】
- 小模型输出的实测验证为 0：47 卡验证流程没有用 7B/8B 模型输出做过探针，"小模型错得浅"在阙疑域内是外推而非实证【盲区】。
- 有利：内容寻址证据 + 小内核的组合，与 Aare Edge 的商业架构同构，方向被验证。
