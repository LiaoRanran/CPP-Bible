# _arch_v41 · 10 多智能体 / 协作验证为什么没用（方向 10）

> 核心问题：多智能体辩论失效的机制、跨模型交叉验证何时有效，以及阙疑"人审+机器"分工的证据强度。
> 诚实标注：【论文·实证】；【技术报告】；【推断】；【盲区】。

---

## 一、同构辩论：增益是"投票"给的，"辩论"在添乱

1. **Cost of Consensus（2026）**【论文·实证】：10 个同构智能体 ×3 轮，三条失败路径——**谄媚从众**（多数答案采纳率达 85.5%）、**上下文脆弱**（同伴理由把原本正确的推理带偏，脆弱率达 70%）、**共识崩塌**（投票丢掉生成池中已存在的正确答案，oracle gap 32.3pp）；同等或更差准确率下多耗 2.1–3.4× token。[v41-S86]
2. **Debate or Vote（2025）**【论文·实证】：MAD 的增益主要来自多数投票而非辩论过程；理论上辩论动力学是**鞅过程**，保持每个智能体的期望成功概率——即辩论本身在期望意义下不创造正确性。[v41-S88]
3. **ICLR 2025 技术报告**：5 个 MAD 框架 ×9 基准，**无一能稳定胜过更简单的单智能体策略**，额外推理预算未被有效利用。[v41-S87]
4. **条件效应（KAIST 2025）**【论文·实证】：数学推理上 MAD 仅在任务更难/模型更弱时略有优势；**安全任务上协作精修反而可能提高脆弱性**。[v41-S89]

## 二、什么真的有效：异质血缘 + 结构化角色 + 匿名 + 独立验证

- **Council Mode（2026）**【论文·实证】：异构模型并行 + 结构化综合（一致/分歧/独有发现），幻觉率相对降 41.7%，TruthfulQA +7.5 分。[v41-S90]
- **EdgeJury（2025）**【论文·实证】：小模型（3–8B）角色专门化生成 + **匿名交叉评审** + 主席综合 + 主张级一致性标注；TruthfulQA MC1 76.2%（+21.4% 相对），幻觉类错误约 −55%。[v41-S91]
- 新闻摘要的跨平台认识论验证（多通道证据+多 LLM 陪审团）同样显示异质、排除自评（self-evaluation exclusion）是关键设计【论文·实证，S92】。
- 【推断】有效配方收敛为四要素：**异质血缘（错误不相关）、角色不对称（有专门证伪者）、匿名/盲（去谄媚）、验证权独立（综合者不持判决权）**。

## 三、框架层证据：多智能体协调本身是 bug 源

- 409 个已修 bug（LangChain/LangGraph/CrewAI/AutoGen/SmolAgents）【论文·实证】：自治编排的特有症状（意外执行序列、用户配置被忽略），根因含模型故障、认知上下文管理失误、编排故障——**多智能体的协调复杂度本身构成可靠性缺口**。[v41-S93]
- Open Agent Spec（Oracle，CAIS 2026）：同一智能体规格在不同运行时上准确率/延迟差异显著，框架选择是独立变量【论文·实证，S94】。

## 四、硬映射

### 1. 阙疑"不靠朴素多智能体辩论"的立场被强证据支持【推断】

- v33 的结论（多智能体朴素辩论做不通）在 2025–2026 被四个独立研究复现；机制（谄媚、上下文带偏、投票丢正确解）全部可查。这一立场可从"经验判断"升级为"有文献支撑的设计原则"。

### 2. 但要诚实区分：阙疑反对的是"同构辩论"，不是"多验证者协作"【推断】

- 真正有效的异质配方（Council/EdgeJury）[S90/S91]与阙疑架构**同构**：

| 有效要素 | 阙疑对应 |
|---|---|
| 异质血缘、错误不相关 | 独立重实现（628，纯标准库 RSA）、不同模型血缘的验证者 |
| 专门证伪角色 | 变异/挑战者、EV-FALSIFICATION 规则 |
| 匿名/盲去谄媚 | 盲测协议（642/647 blind，提示不可见来源） |
| 验证权独立、综合者不持权 | LLM 仅为证据来源，判决在内核+人审，过程账本留痕 |

- 即阙疑实质上是"**结构化异质验证委员会 + 人审主席**"的工程化，而非"辩论"的变体——这个定位差异在叙事中应讲清，避免被归入已被证伪的 MAD 阵营。

### 3. 人 + LLM 的最优分工【推断】

- 机器：可判定主张（执行/哈希/规则）+ 多验证者投票；
- 人：语义意图、分歧仲裁、责任承担；
- 禁忌：综合者（无论人还是 LLM）不得在无独立验证时覆盖机器判决——B1 保护器（冲突仲裁）应保持"只能触发升级，不能自产结论"，642 已如此设计，方向正确。

## 五、直说：短板与风险

- 阙疑目前的"异质"实际只有两层（L0 真机 + 内核/独立重实现）；LLM 验证者是否多血缘未见登记【盲区】——Council 证据表明血缘越分散错误越不相关，单一 LLM 触点是潜在短板。
- 匿名/盲协议在 LLM 触点的覆盖率未见文档【盲区】，存在谄媚效应进入判决链的路径。
- 有利：四要素中阙疑占三个半，结构比学术框架（2026 仍在补匿名与独立验证）更完整。
