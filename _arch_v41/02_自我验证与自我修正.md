# _arch_v41 · 02 LLM 自我验证 / 自我修正能力（方向 2）

> 核心问题：LLM 能否自检自改？自我修正的实证效果、裁判偏见，以及阙疑"UVK 不自证"原则的证据强度与过时条件。
> 诚实标注：【论文·实证】；【综述】；【推断】；【盲区】。

---

## 一、自我修正：内在 vs 外部反馈（证据高度收敛）

1. **Huang et al., ICLR 2024（Google DeepMind）**【论文·实证】：系统检验**内在自纠正**（无外部反馈）——推理任务上不仅不能提升，多数情形反而下降；Self-Refine/Reflexion 等报告的提升来自 oracle 标签/外部反馈，去掉即消失。核心悖论："模型若初答就能靠自检改对，为什么不一开始就答对？"多智能体辩论在等响应数下不优于 self-consistency。[v41-S13]
2. **Dark Side（清华/南洋理工，2025）**【论文·实证】：自纠正引发**答案摇摆（answer wavering）**——简单事实题上的 prompt bias，复杂任务上的过度思考/认知过载/完美主义偏差；缓解靠问题复述和少量 SFT，而非更多自检。[v41-S15]
3. **反方证据（必须并列）**：IoE/Confidence 研究（MBZUAI）——模型能感知自身回答的置信度，按置信度门控的"If-or-Else"提示可取得一致但小幅的提升【论文·实证】。说明"绝对不能自证"过强，准确表述是"**无外部信号、无置信门控时，内在自纠不可靠且常退化**"。[v41-S14]
4. **外部反馈条件下自纠有效**：Dou et al. 按错误类型+编译器反馈的自我批评两轮迭代提升通过率 29.2%[v41-S1]——**有效自纠依赖外部机器信号，这正是阙疑架构**。

## 二、LLM-as-judge 的已知偏见（2025–2026 新证据）

- **位置偏见 / 冗长偏见**：系统复核确认【论文·实证，S18】。
- **自我偏好**：DBG 分数（gold judgment 控制质量混淆后）证实裁判系统性高估自家输出，推理模型亦然【论文·实证，S16】。
- **标签即偏见**：仅贴 self/other 标签（不点名模型）即造成双向打分偏移——作者归属本身就是独立偏差源【论文·实证，S17】。
- **捷径偏见且不自知**：裁判受"新近/来源"线索系统性影响（recency bias、Expert>Human>LLM>Unknown 层级），但**裁决理由中几乎从不承认线索影响**，反以内容合理化——裁判的"解释"不忠实【论文·实证，S18】。
- v35 已核实：BabelJudge 九扰动、JudgeBench、CodeJudgeBench（斯瓦希里语顺序一致性 0.480≈抛硬币）。

## 三、校准方向的关键趋势：小而专的外部验证器

- **MiniCheck（Tang/Laban/Durrett, EMNLP 2024）**【论文·实证】：合成数据（C2D/D2C）训练的小模型达到 GPT-4 级核查能力、成本低 400 倍；提出 LLM-AggreFact（11 数据集统一基准）。[v41-S19]
- 但**通用小核查器有边界**：多步数值推理误判（PALADIN，3.8B 专用模型在真实场景反超更大模型）【论文·实证，v41-S20】；金融领域需专门合成数据（MiniCheck-FISCAL 7B 外部基准匹敌 GPT-4o）【论文·实证，v41-S21】；多跳推理需图结构数据（FactCG）【论文·实证，v41-S22】。
- 【推断】学界主流路径不是"让生成模型自证"，而是"**训练独立的小验证模型**"——验证外部化、专业化，与阙疑"独立验证者 + 独立重实现"同构。

## 四、硬映射

### 1. "UVK 不自证"对不对？

**对，但应限定口径**【推断】：
- 强证据支持"**当前生成式 LLM 在无外部反馈时不能可靠自证，且存在自我偏好/标签偏见**"[S13/S15/S16/S17]。
- 但它是**当前模型代的经验结论，不是永恒定理**：IoE 门控有小效[S14]，未来模型不可排除内建可靠核查。建议纲领表述从"永不"加操作化注释："凡验证者与被验证者同模型/同分布/同训练血缘，即视为自证，须独立投票+否决"。
- v39-00 已把"工具存在≠独立性存在"写入独立性四级刻度，与上述证据一致。

### 2. LLM 降为"证据来源之一"会过时吗？

- 现有证据显示方向相反：业界正把验证拆给独立小模型[S19-S22]，"生成/验证分离"在加强而非消失。【推断】
- 阙疑设计与该趋势**同构**：L0 真机（编译器/运行）就是外部 oracle，LLM 只是触发与解释层。

### 3. 若未来 LLM 能可靠自证，阙疑剩什么价值？

仍剩四层【推断】：
1. **账本与审计轨迹**（452 事件 Merkle + OTS）——自证不产生对第三方可核查的历史；
2. **provenance/治理**（谁、何时、依据什么改判）——监管要的是过程证据；
3. **独立性证据**（独立重实现、不同血缘验证者）——自证天然不具独立性；
4. **人审闭环**——责任主体在人。
即：自证替代的是"机器判一次"这一步，替代不了"审计 + 治理 + 责任"。

## 五、直说：站不住的点

- "**永不**自证"作为绝对措辞在科学上不可证且有反例边缘（IoE 门控小效）[S14]；建议保留口号、在规格层落为可操作判据（同源即自证）。
- 阙疑目前没有用 2025-26 的裁判偏见量化工具（DBG、九扰动）对自身 LLM 触点做校准——9 保护器中 B6（VSA 去同源）落地状态本工作树无法确认【盲区】。
- 有利：阙疑比学界主流早走了一步——MiniCheck 2024 才流行的"独立小验证器"，阙疑 628 独立重实现已在做。
