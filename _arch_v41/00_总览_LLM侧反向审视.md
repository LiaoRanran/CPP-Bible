## 二、跨方向六条核心洞察

1. **错误形态证据高度收敛**：LLM 主导失败是"可编译、不崩、但错"的 plausible 型；三套独立 taxonomy + 517 题 SO 实证一致。阙疑"机器判执行、规则管过程、人审判语义"的三层切分正打此痛点。
2. **"自证不可靠"是当前模型代的经验定律，但不是永恒定理**：内在自纠退化（ICLR 2024）、自我偏好/标签偏见（2025–26）证据强；置信门控有小效（反方证据）。建议把"永不自证"操作化为"同源即自证，须独立投票+否决"。
3. **验证在外部化、小型化**：MiniCheck 以 400× 成本差达到 GPT-4 级核查；0.5B–7B 域专用核查器成主流路径——与阙疑"独立验证者/独立重实现"同构，方向被行业反向验证。
4. **复合可靠性是模型能力无关的审计刚需**：0.95^20≈0.36；80% 可靠曲线比 50% 低 4–6 倍。模型在"点"上消灭错误，在"链"上放大审计需求；行业焦点正从点移向链（agentic 轨迹）。
5. **监管把"准确性 + 日志 + 人类监督"写成高风险法定义务**（教育域显式列入），而厂商事实性不在部署门槛——"厂商不管 + 监管要管"的三角缺口真实存在。
6. **护城河只能是账本，不是卡**：47 卡可被合成数据法快速复制（窗口 12–18 个月）；452 账本（判决演化层）在全基准生态中无对应物，且历史不可重建。

**口径声明**：Protocol 文本本工作树不可见（另一会话在建），RQ 具体表述属【盲区】。以下按 brief 与既有材料做**主题级**校准，RQ 原文到手后须回填：

| 推定主题 | 外部证据给出的校准 |
|---|---|
| RQ1（LLM 自检/自纠边界）| 强证据：无外部反馈的内在自纠不可靠且常退化；限定：置信门控小效、外部机器信号（编译器/测试）条件下自纠有效。结论口径应落"同源不可作独立判据"，而非"LLM 不能参与验证" |
| RQ2（验证外部化路径）| MiniCheck/PALADIN/FISCAL/FactCG 共同指向"小而专的独立验证器"；通用核查器在多步数值/多跳上有明确边界——域专用合成数据是关键变量 |
| RQ3（审计/监管缺口）| EU AI Act 高风险义务（准确性/日志/人类监督）+ 厂商门槛缺口，双证据成立；须限定阙疑产出是"证据载体"而非"合规认证" |
